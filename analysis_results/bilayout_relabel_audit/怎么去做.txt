第一步，先复制一份人工填写版，不要直接改模板：

cp analysis_results/bilayout_relabel_audit/b0_relabel_audit_worklist_v1.csv \
   analysis_results/bilayout_relabel_audit/b0_relabel_audit_filled_v1.csv

然后只打开 b0_relabel_audit_filled_v1.csv 填。先筛选：

dedup_primary = true

优先审这 90 行。dedup_primary=false 的 30 行暂时不填或只作备注，不进主统计。

第二步，按组审，不要混在一起看：

1. hard_prediction_failure + highest_g_score 的 dedup_primary 行
2. nominal_prediction_structure
3. soft_prediction_complexity

第一组主要看 Bi 是否减少跨门扩张和过度解析；第二组看 Bi 是否破坏正常样本；第三组重点找 undercoverage、OOS suspect、open-boundary ambiguity。这和现在 B0 文档里的组别解释一致。

第三步，字段填写规则建议固定如下。

hohonet_crossdoor_score / bilayout_crossdoor_score 用三档即可：

0 = 没有明显跨门/跨房间扩张
1 = 轻微或局部跨门风险
2 = 明显跨门/跨相邻空间扩张
NA = 图像或 overlay 不足以判断

布尔字段统一用：

true
false
NA

不要用 yes/no、1/0、中文，否则后面脚本容易出问题。

关键字段判定：

overextend_reduced = true

只有在 Bi 相比 HoHoNet 明确减少跨门扩张，且没有同时明显漏掉相机房间结构时才填 true。

overparse_reduced = true

用于 Bi 删除了 HoHoNet 中明显多余的折点、家具边缘、柱体/凸起误解析等情况。

bilayout_undercoverage = true

用于 Bi 过度保守，漏掉本应属于相机所在房间的墙面、角点、边界或大片区域。这个字段在 soft_prediction_complexity 里最重要。

bilayout_new_error = true

用于 Bi 引入 HoHoNet 没有的新错误，例如新跨门、新过度解析、奇怪闭合、明显错误截断。

both_wrong = true

用于 HoHoNet 和 Bi 都不能作为 enclosed target。

oos_suspect = true

只表示“疑似 OOS，需要排除或复核”，不是正式 OOS 分类。A 线 OOS gate 与 manual geometry reliability 仍必须分开。

expert_verdict 只能四选一：

accept_bilayout_enclosed
accept_with_minor_fix
reject_undercoverage
reject_ambiguous_or_oos

usable_for_B1 规则建议严格：

true:
  accept_bilayout_enclosed
  accept_with_minor_fix 且 minor fix 很小、边界方向明确

false:
  reject_undercoverage
  reject_ambiguous_or_oos
  both_wrong=true
  oos_suspect=true 且无法稳定裁决

第四步，先不要追求全填完。建议先做一个 20 行校准小样本：

hard/high-g 去重主样本：8 行
nominal：4 行
soft_complexity：8 行

填完后检查自己判定是否一致。尤其看这几个组合是否自洽：

bilayout_undercoverage=true 时，通常 expert_verdict 不应是 accept_bilayout_enclosed。
oos_suspect=true 且 open_boundary_ambiguity=true 时，通常 usable_for_B1=false。
both_wrong=true 时，usable_for_B1=false。
overextend_reduced=true 不能自动推出 usable_for_B1=true。

第五步，20 行校准后再填完整 90 行。
