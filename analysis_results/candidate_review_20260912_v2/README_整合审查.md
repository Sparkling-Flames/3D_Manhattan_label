### 当前填写方式：按房间／实际场景成组

最新v2的场景分类与同房关系按用户认可作为工作依据，不需要重新审核全部图片。“待定”指本轮是否采用，不表示同房关系不可信。重点复核用户特别圈出的门洞交界，并保留已有明确未决项；局部纠错不覆盖原记录来源。

完整方向与具体候选建议见[研究主线与选图方案](../../docs/thesis_main/研究主线与房间场景选图方案_20260912.md)。四条主线为人数增加与稳定过程、同房间收敛预测、相似场景标注与跨房间预测、人员子类与组合；相似场景包括卧室、厨房、开放空间及单独记录的门洞交界条件。

1. **整组采用判断**：待定、建议采用、满足条件后采用、暂不采用。它回答值不值得采用这个房间／场景，不是第几批开展。
2. **研究用途**：四条主线可多选，组备注写采用理由、拟用子组与未决条件；选择用途不等于修改图像分类或确认配对。
3. **逐图填写**：本图是否采用、采集安排分别选择；来源／检验身份留给标注完成后的离线划分。
4. **预期难度与计划总人数**：难度为简单／中等／困难（未填为未定）；人数仍为未定、0–8、9–15、16–20、21人及以上，含可复用历史。难度只是预期，不是结果，不自动分配人数。

**逐图采用与采集安排分开填写，不预先指定预测身份。**

| 填写项 | 选项及含义 |
|---|---|
| 本图是否采用 | 待定／采用／备选／不采用。备选表示有价值但暂不列入拟用清单，不表示下一批必做；不采用也只针对当前方案。 |

| 采集安排 | 待定／仅复用历史／需要新增标注。任何角色都可复用或补标；已有历史不足的依据图也可以补标。 |

筛图只确定是否采用、采集安排、预期难度和人数。困难图与稳定多簇候选均可进入离线预测检验；来源与检验身份由每次划分决定。

例如：同房A、B、C、D均可先纳入采集，之后反复划分依据与检验；不在审图页固定角色。近重复视点暂不采用则填备选。

**预期难度只有三档，另保留“未定”作为尚未填写。**

| 档位 | 审图时的预期（不是结果标签） |
|---|---|
| 简单 | 基本无歧义，预计较少人数后就能稳定。 |
| 中等 | 可以标，但可能出现歧义或画不好的情况；对应“小幅歧义”的设想，可能形成稳定的多个标法簇。 |
| 困难 | 预计在本次能够观察的人数内，标法或分布仍持续变化，难以确认稳定。 |

中等不必然多簇，“画不好”也可能是零散误差；困难不等于永远无法收敛。稳定多簇本身仍属于稳定阶段。三档记录研究者的待检验预期，实际结果可与预期相反，不得按是否符合预期改簇、调阈值、删图或重写原预期。若审图时参考过历史标注，在备注说明；这种判断不能冒称纯图像预测。难度不自动绑定人数，计划区间仍单独填写；不同观察人数下，要区分“截至该人数仍变化”与“人数不足、无法判断”。

预算分为“建议采用组”和“条件组”，每组也显示新增图片、复用来源、人数未定及新增区间。待定组不进入拟采用合计，替代图不自动计费。同图重复引用不能重复计费；用途或人数冲突时不能静默合算。21人及以上只有下限，容量不足仍提示，不能承诺达到该档。

候选应比实际采用量宽，但不是把所有候选都按小人数标一遍。当前112图以同房多视点为主，对门洞场景覆盖不足，后续选择应按当前方案从全648图补充相关候选，不能据现池声明各类已经覆盖。不同卧室仍是不同房间组；同一类别的跨房间比较不能冒充同房预测。

## 4. 研究设计仍需补齐的部分

**多视点价值与标注数量价值要区分。**A预测C／D／E与A+B预测同一批目标，能比较多一个来源的实际收益；若要解释为视点本身的收益，再加总人图数相同的比较，例如A的16份与A、B各8份。该例只用于说明对照原则，实际比较须有足够记录，并说明重复人员和来源观察长度的差异。

**大组值得审，但不能让uNb占据几乎全部证据。**增加同房视点可以观察房间内变化；不能替代不同房间、不同building的覆盖。来源很密集的小组和来源稀疏但能补充其他类型的大组，都有保留价值，按研究问题与实际预算取舍。

**困难图需要覆盖不同结果。**大分歧可能稳定形成几簇，也可能仍在变化；计算未知又是另一种情况。G027的晚期多簇线索和G197的起点／计算不确定线索不能都写成“已证明不收敛”。已看过历史结果的候选可作针对性案例研究，但不应据此估计普通图片中困难情况的比例。

**不要用目标结果反选图片或人员类型。**源／目标及人员分类所用资料应在评价前分开。若发现主空间确实不匹配，记录基于原图的修订及影响，保留原分析范围，不能因为预测失败才排除。图像分类描述看到的空间，不把预期标注范围定成唯一答案。

**人员类型与稳定分布是不同证据。**质量、时间、规则判断和Semi行为的组合仍待验证，不固定两组，也不强行平均。保留若干共同标注图以比较具名子类与同人数随机人群；每类人数有限时如实报告其实际观察长度，不要求每类凑到13或15人。短观察内稳定不能证明更多人加入后仍稳定。

## 5. 元标签建议能支持到哪一步

原始choices复核：1887份可用Manual都有Scope和Difficulty，Model Issue作答为0；574份Semi三项均有作答。Manual的Scope为normal 1447、开放边界235、几何95、错层84、信息不足26。Difficulty为遮挡1067、trivial 586、反射273、接缝217、低纹理171、画质106；它是多选原因，不是1—5分量表，也不能将各项比例相加为100%。详见[频次表](results/meta_frequencies.csv)。

Scope可辅助描述范围判断，也可在有独立最终裁定时衡量适用范围判断的表现；它不是完整的规则执行能力。Difficulty可提供解释线索，但没有控制图片和人员后的预测增量证据。标注后填写的Scope／Difficulty可以辅助分析已发生的分歧，不能假装是预测新图时已知的输入。Model Issue在纯Manual中是不适用，不能当作模型没有问题。

Bi-Layout确实区分在歧义处停止和向可见区域扩展的布局；它支持研究范围理解的差别，不提供本项目15人或20人的阈值。[论文](https://arxiv.org/abs/2404.09993)。Geva等研究的是NLP数据中的标注者特征及对未见人员的泛化；只能作为人员集中和泛化风险的相邻证据，不能推断本项目某语言组已有偏差。[论文](https://aclanthology.org/D19-1107/)。
