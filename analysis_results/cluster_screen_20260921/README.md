# 24图分簇筛查

[打开审核页](index.html)。可直接双击本目录的 index.html，图片和脚本均在本地，不需要联网。

本轮采用用户明确的规则：**多画或少画结构属于不同看法，应分簇；奇数点另行复核。** 不重新讨论这一原则，也不以少数表达自动判定质量差。审核对象是当前工作版，不是独立盲审验证集。

## 怎么填写

1. 先看“指定作答对”，可取消其中一人的显示单看，勾选点号，点击图像作局部放大。
2. 下拉判断只针对最初指定的两份：同一表达可同簇／不同表达应分开／对应需核查／暂不能判断。多画少画结构直接按应分开处理；局部定位偏差则判断是否足以分开。
3. 在文字中写明人员和点号。若查看“阻挡成员”“真人代表”或展开整簇，请将这些额外结论写在文字中，不把它们与指定两份的结论混淆。
4. 两种分簇可切换比较；3D只辅助，不能用规整后的模型代替原图判断。
5. 点击“导出本轮审核”，得到 **分簇筛查24图_我的审核.json**，完成后把该文件发回。浏览器会保存进度，也支持导入继续，仍建议导出留档。

所有答案初始为空，没有填入AI意见。页面保留人员与算法信息，因此不宣称盲审。旧审核只能作为只读参考打开，不能直接导入为本轮答案。

## 选图与来源

24张不同图片、12栋建筑，共338份Manual/OOS作答供整簇查看；每栋最多3张。指定对均为同点数、原人数至少8人的图片，分为：近邻被完整链接拆开4图、代表点同簇远邻4图、阈值外侧3图、阈值内侧3图、普通对照10图。普通对照包含相近及明显不同的作答，按固定种子抽取；这是有目的诊断抽样，不代表总体错误率。

从当前2444份／240图视图选取。沿用现有点数硬门、25.6px距离及两种成簇方法，不自动改变点对应。来源为已独立复核的冻结数据包，逐份原始来源和当前有效点保存在data.js中；派生包不替代export_label原始证据。

依列明的既往审核清单，保守避开89张图片，包括uNb-21、uNb-40等已经人工裁决的对应案例。对应翻转候选筛查后没有剩余符合条件的新图片，因此本轮没有凑入旧对应问题。奇数点和借用补点作答不进入本轮预测视图筛查，原有审核处置不改。每题保留完整上下绑定点号及原始身份，见REVIEW_MANIFEST.json。

全景原图优先复用历史Studio内嵌资产；历史页未覆盖的新图取已登记的本地PNG。本页面复用Panorama Studio、原审核面板及其导入导出校验；新增目录隔离浏览器存储和审核版本，不向旧页面追加题目。
