# 论文图表提纲（工作版本）

## 主问题
在既定任务与信息条件下，增加独立真人如何改变布局标注分布和少数表达覆盖？人员组成是否改变这种证据需求，图像/场景与已有模型信息是否具有可重复的预测价值？

不要将聚类研究扩展成独立算法论文。RC1只作为可审计测量：保留对应/资格/残差，给出必要敏感性和明确人工例外。

## 建议正文图表

1. **表1：数据覆盖**。真实人数、图片、原始Manual/Semi/OOS条件、阶段、可计算/不可计算、人工关联覆盖、新数据到达情况。分母始终明确。
2. **图1：测量与证据**。uNb-21的用户局部锚点及未确认完整映射分开；用原点号和残差表，不由距离重新认定物理结构。说明成对相近与整簇相容。
3. **图2：人数与分布**。固定高支持图片集，下一真人几何非覆盖曲线＋6/9/12°敏感性。附重复少数组后见发现曲线，明确后见与前缀重分簇的不同。
4. **图3：人员组成**。同图同人数ABCD/AABC，真实四人团队、相同留出真人。内部一致性和对外覆盖各一张，不将内部更一致写成完整代表性更高。
5. **图4：场景迁移**。共同人员的同房不同视点结果；不将展示组当独立房间。附模型特征留建筑基线、角点数消融与Bi单独结果。
6. **表2：证据状态**。历史探索支持什么、新数据需要验证什么、仍不可评价什么。辅助active time放补充材料，不混入距离。

## 新数据必须先冻结的事项

人员身份/独立首选版本；原始信息条件与初始化；图像/房间/建筑关系；追加输入截止日；9°工作版及6/12°敏感性；人工映射版本；目标评价人群和少数定义。若调整测量，应在新数据结果不可见前说明，否则称为继续开发而非独立验证。

前k人实验不读取剩余真人簇中心、图内事后修复或剩余人决定的事件规则。使用完整池定义的组只可标作回顾性发现分析。新半自动响应共享初始化，不能将条件比较自动解释为模型因果收益。

## 结果写法

写“在冻结历史池和工作分辨率下，新的不相容表达仍以某概率出现”，不写“20人后保证无新模式”。写“历史偏离档构成与严格几何分布存在关联”，不写“认真型收敛更快”。写“模型角点数/跨模型距离对历史目标提供增量”，不写“Bi双头解释了人类所有分歧”。

## 贡献边界

可辩护的组合贡献是：结构化标注的分布及人数过程，明确测量误差与对应例外，真实人员组成对过程的影响，以及可用图像条件下的迁移证据。局部最大距离、循环排序、完整链接与人员分箱本身已有方法背景，不单独宣称算法创新。
