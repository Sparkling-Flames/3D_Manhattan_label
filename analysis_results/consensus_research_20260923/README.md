## 数值表语义

统一墙带在512×256像素中心栅格计算，距离换算为1024×512等效像素。`mode=curve` 复用空间直线的全景投影；`linear` 为二维直线敏感性。失败不强行生成空区域。

`individual_quality.csv`：每份起点×两种边界×两版GT均保留一行，含 `status`；报告IoU、普通ERP面积质心的水平/垂直/欧氏位移、周期方向位移与一阶矩距离。`circular_R` 小意味着方向不稳定，圆周水平大位移不直接等于实际整体错位；一阶矩距离无像素单位。逐作答测量尚未去除图片效应，不直接称为人员能力。

`review_queue.csv`：全部起点×两种边界，整体异常排序为 `min(1-最近参考IoU,1-最近独立同行IoU)`，越大表示两边都远。它只用于安排视觉复审，无自动阈值或自动新排除；参考覆盖不全、同行不足和表示失败单列。同时保存 `peer_ious` 全部适用同行IoU、最近同行摘要和所有可用参考IoU。

`endpoint_pilot.csv`：每个同图同条件组、每算法、每GT保留端点。`member_ids` 是所收集的作答ID顺序，`k` 是收集的唯一人员数；`used_member_ids`/`used_k` 是实际参加聚合者，`raw_accepted_n` 是起点作答数。缺GT、无合法成员、重复人员或算法不可用均明确记录。此表尚无全前缀、随机顺序、支持图、概率图、区域文件、人员分类或同房预测结果。

`model_difficulty.csv` 是BiLayout两个头的曲线区域不一致量；这是候选难度特征，不是已验证的难度真值。`representation_failures.json` 保留表示失败原因，不能据失败直接删除原标注。

`numeric_summary.json` 为实际计数；`centroid_summary.csv` 和 `centroid_diagnostics.png` 展示可计算样本的质心量级；失败率需同时参考前述全量表。`gt_sensitivity_summary.csv` 对实质修订图的同一作答作两版GT配对比较。`handoff_manifest.json` 为实际包清单。
