# 六例质心、区域与角点顺序的视觉核验

2026-09-23。已逐一查看用户指定六例的原图、作答/GT区域、点号、面积差分；对三例另查看原GT连接与按x连接的叠加及地面投影。没有更改原始作答、人工裁决、GT、正式算法或全量结果。临时检查图验收后清理，保留本报告及 numeric_audit.json。

结论：质疑有实质依据。当前数值能复算，但不能直接当成完整房间空间范围的可靠度量。需分别解决区域表示的连接/可见性问题、局部点的语义与平面假设问题，以及质心的一阶矩信息损失和ERP接缝依赖。仅换成直线或仅修顺序，都不能保证质心能识别所有范围差异。

## 逐例视觉解释

- **S9hNv5qa7GM-05 / W037**：浴室主要几何范围的语义不是这里的核心争议。中间窗/淋浴墙相关上点明显低于房间顶边，下点也未沿房间底边；墙带在左/中部被压窄。当前mask相对GT漏掉约42.0%的GT墙带面积，导致水平中心右移约52.7px，垂直却只变1.86px。大质心差可由局部坐标错误造成，不等于选了另一个房间范围。
- **q9vSo1VnCiC-24 / W018**：厨房与右侧入口/相连空间的边界表达不同。右侧两角之间跨度约172.7度，当前曲线绕向图像顶/底部，显著放大二维墙带。当前多出相当于GT墙带56.6%的面积，差异偏右，产生约69.6px质心距离。GT本身另有按x排序改变连接的问题，因此数值混合范围表达与构造差异。
- **e9zR4mvMWw7-19 / W031**：卧室开口和走廊两边的范围表达差异明显，两个墙带的主要差异在左右两边分布不同。当前曲线质心距离157.08px，但同点的直线表示只有7.85px。两者IoU为0.515/0.724。不能不说明区域构造，就用一个大偏移值称其空间范围误差；这也不是直接证明直线正确。本图采用人工修订GT，其原环序不能由本次规范化结果反证已恢复。
- **S9hNv5qa7GM-08 / W036**：四对点主要落在洗衣间两端及近处门框，GT还描述卫生间里面及门洞转折。当前相邻两点跨约173.5度，连接后上边界接近图顶、下边界接近图底。作答墙带面积为GT的1.563倍，多出56.7%、少掉0.4%（均以GT墙带面积为分母），但新增部分上下扩张，新增区域平均位置仍靠近原中心，因此整体质心仅差6.91px。面积/形状差别大而质心接近是真实的一阶矩盲点。
- **uNb9QFRL6hY-81 / W037**：新增点位落在壁龛及其底部台面附近，属于需要明确标注对象语义的局部结构。当前构造器把每一对都当整间房的顶/底边界，让新增点改变左右相邻曲线，削去了不止壁龛小块的墙带（约32.9%的GT墙带）。减少部分的上下贡献抵消，垂直中心只差1.17px；总ERP距离18.05px，不能称全方向均不变。局部壁龛是否属于房间范围，需要标注定义和人工裁决，不能由这一个质心值决定。
- **B6ByNegPMKs-42 / W032**：相机处于门洞交界，可看到两侧走廊及近处墙角。人员点大多集中在远处走廊端部、靠近地平线；GT包含近处明显拐角，曲线在中间两段差别大。复杂的范围选择需保留讨论，但低IoU不是因为GT角点数量多就自动扣分。用本图GT在原空间直线上补点，把8对变16对，mask完全不变，IoU=1、质心变化=0；只有点代表的实际边界改变才影响面积重叠。

## 顺序问题：确有影响，但不是全部原因

`consensus_region_20260923.py` 的 wall_mask 会按x排序后相邻连接，不使用输入的真实房间环序。随机重排六例作答的点对各20次，输出完全相同。这只能说明输入排列被忽略，不能说明房间连接关系无关。

保留来源GT的上下点对身份，比较无向环边，可确认排序替换了：S9h-08的4/12条边、q9-24的5/12条边、uNb-81的2/6条边。不是简单从不同起点遍历或倒序。原始地面投影环均为包含相机的简单多边形；水平排序将部分转折改成斜跨连接。S9h-05、B6-42在本次检查中没有这个边替换；e9-19只可说明已经规范化的修订GT没有进一步替换，不能证明修订前环序正确。

进一步做了有限诊断：保持这三图来源GT连接、在共同地面平面假设下每条射线选择最近墙面，上边界使用同一条墙的源边。此操作区分原连接和可见墙带，不宣布为新正式GT，也不恢复未知的人员环序。S9h-08的IoU从0.636变0.615，ERP距离从6.91变6.50px；q9-24从0.620/69.60px变0.625/84.46px；uNb-81从0.669/18.05px变0.666/20.79px。S9h-08仍然是范围不同、质心近，不能指望仅修顺序消除该反例。

## 为什么质心会漏掉差异

质心只记录面积的平均位置。以G为GT、A为作答，新增E=A\G，减少D=G\A：

`C_A - C_G = [ |E|(C_E-C_G) - |D|(C_D-C_G) ] / |A|`

六例均按像素独立核对上述分解成立。大量差异若在中心两侧分布，或新增部分本身中心与原区域接近，最终位移可以很小；不需要计算出错。S9h-08的新增面积对水平偏移贡献仅约-0.61px，尽管新增面积很大。环绕相机的二维墙带质心也不是地面房间多边形的质心，更不是三维空间/体积中心。

普通ERP水平质心另依赖接缝。把两mask共同循环移动、保持区域对应和IoU不变，仅更换0/90/180/270度接缝，S9h-08的ERP质心距离依次6.91、34.04、9.42、43.63px；B6-42为17.93、131.06、43.35、122.43px。圆周方向避免这个切缝效应，但低R不稳定、同中心异形以及语义范围不足仍存在，不能视为通用修补。

提高到1024×512计算，六例IoU及质心距离只发生很小变化（数值见JSON）；当前发现不是主要由半分辨率栅格造成。

## 对当前方法的处置建议

1. 暂不把现有ERP质心距离用作人员权重或空间范围错误判定。保留作描述性诊断，既有结果标明当前表示，不能解释成完整空间质量。
2. 把“可见的投影墙带”“完整布局轮廓”“局部壁龛等结构”区分。已知GT环序应保留；未知人员/修订GT连接关系显式待审，不用x排序冒充拓扑恢复，也不能把原始点击顺序自动当真实环序。
3. 先核验区域，再比较IoU、面积/差异位置和质心；质心不能替代范围/形状差异。边界指标可作为文献候选，但本次不据此冻结新指标或权重。
4. 审查界面后续应能区分原连接、按x连接和可见包络；展示多/少区域及面积比，避免只看一根质心箭头。当前没有据此重新排除任何作答。
