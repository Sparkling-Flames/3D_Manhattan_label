# 空间范围裁剪工作台

用户请求的私有、浏览器本地工作台，首轮3张。原图来自现有GitHub仓库，资料绑定90ed861c5ee7db845a10b0bdad5f32d2184c0194。

- 在俯视图拖动/两次点击画切割线，绿色预览保留的一侧；拖端点微调，应用后可继续切割。
- 可在原全景照片地面点两处来设置同一切割线；照片地平线以上不转换为底面位置。
- 撤销/重做，浏览器草稿，导出/导入经原GT绑定和切割重放校验的JSON。
- 原GT不改，人员轮廓只作参照。不同GT分数未计算。裁剪仅定义底面；新封口上界尚需另行核实，导出永远 reference_ready=false。
- 半平面裁剪拒绝空、断开/自交及不含相机内部的结果，不自动修形。

检查：node --check dist/app.js && node qa-state.cjs
