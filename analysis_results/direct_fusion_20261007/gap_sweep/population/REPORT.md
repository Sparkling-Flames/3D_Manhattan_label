## 2026-10-08收到的逐图审核：身份与可用性分开解释

**后续已完成：**[7.5—9细扫与11图复审](refine_20261008/REPORT.md)。用户随后明确只需判断同一墙线及归类可用性，因此[新版工作台](refine_20261008/review.html)不要求位置判断或参数选择；下文三层区别仅供研究端解释，不是额外人审任务。

[用户原始导出](user_review_workbench_20261008.json)原样归档，来源为Downloads/墙线归类审核_20261007.json。177条中17图有填写，12图勾选完成，30条局部意见（12不确定、10同角应并、4异角应拆、4可接受）。这是人工意见的条数，不是30个独立墙角真值；本轮未据此自动改成员或统计参数准确率。

这轮暴露了审核界面的两个问题：整图“可接受”混合了身份判断和实际可用性；只能选整组，难以表达“组中某一份应移到另一组”。不要求用户重审17图，保留原话，按以下区别使用：

| 实际反馈 | 当前解释 |
|---|---|
| B6-47：7.5的G05与G11同墙线，9的G12可接受 | 有具体来源的局部同角证据，可用于后续对应比较，不扩大为整图认证 |
| yq-25、zs-05：同一被遮挡墙线，但跨度很大、对合并有疑虑 | 同目标判断与位置融合疑虑分开；不能仅因容忍自动拆分就改写为不同目标，也不等于中位数位置已获确认 |
| uNb-08：9仍有两种停止点，但算法做到这样可以接受 | 是允许残余问题的可用性判断，不是组内身份全正确 |
| jtc-12：部分拆分正确，另一处同角被拆散 | 不同局部可同时成立，不用整图一个标签覆盖它们 |
| q9-23：G05中P027勉强可合、P007明显不同；uNb-65指组中最左一份 | 属于成员级意见，不能把整组选中人员全部转成同／异约束；文字保留，未擅自绑定模糊指向 |
| wc2-53：G03与G04建议合并，但图整体不确定 | 两组合并含同人P001/R02176的pair2和pair3，当前同人不同节点不合组的假设不允许直接执行；需区分局部细节表达与身份，不按阈值问题硬处理 |
| uNb-72、uNb-78明确修订旧范围解释 | 保存为本次局部看法更新，历史comment不覆盖；其中78未勾选完成 |
| uNb-86借GT门口标法辅助判断 | GT可作为一种表达供理解，但有无GT节点不能决定参与者的目标；当前保留不确定 |

**后续最小审核口径：**先回答“这些观察是否表达同一个转折／停止目标：同／不同／不确定”；位置高低、远近或端点目标差异另写备注；最后才回答“自动结果能否使用／需少量人工”。同墙线不要求坐标准确，也不要求喜欢融合中心；不同停止点不能仅因靠近或算法总体可用就认成同角。确实看不出意图时留不确定，不为维持表面一致而强判。

当前算法已经逐两份人员原答进行允许缺点的环序匹配，再按组内两两相容成组，同人不同节点不合组。它利用上下距离、原配对与原环顺序，没有理解原图物体，也没有用GT作对应模板；跨人员相邻位置联动目前只用于异常提示。下一步先利用明确的局部反馈比较对应，把疑难处放回单人完整原环及其他人员表达中查看；工作台应补具体来源选择并分开上述问题。这些改动尚未实现，不再要求先取得全库完美人工真值。

本次仅归档与解释审核，未重跑几何、改变默认参数或自动套用审核。现有方法入口及项目地图已链接本报告，无需为这份原始回执另建正式入口。
