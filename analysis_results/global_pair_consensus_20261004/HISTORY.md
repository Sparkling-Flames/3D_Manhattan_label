# 全员点对共识的历史依据与复用边界

本页为2026-10-04的源码与保存结果溯源，不是本轮算法验收报告。当前目标是**同一图的全部当前人员形成一个全局点融合候选**；整份作答分簇用于解释差异，不先挑最大簇或各簇各做一份来代替这个目标。失败或连接歧义需要显式保留，不能为凑出唯一合法空间而选择最贴GT的结果。

## 1. 以前确实做过什么

[9/26八图原型](../union_branch_consensus_20260926/README.md)已经把全体人员的上下点对放进同一身份池，按上下端点球面角距的最大值作完整链接聚类。同一个人的不同角点不能被合成一个身份；某身份的支持数因此是支持人员数。2.5°／5°／10°是探索网格，默认5°没有完成语义校准。

随后它按“保留的身份及循环邻接完全相同”产生多条观测分支。主中心是分支内BEV底点与高度的逐坐标中位数；另有 `shared_feature_candidate`，使用跨分支所有当前人员的同身份观测求中心，但连接仍沿用该条分支。因此：**全员角点聚类和跨分支中心以前已经运行；全部高票角点生成唯一新环没有在这个原型中实现。**

旧八图默认5°得到130个精确分支，各图最大分支仅1—4人，暴露了身份识别与精确环签名的碎片化，不证明全员没有可融合信息。保存结果中19个多人分支的共享身份中心相对分支内中心，原GT IoU均值增加约0.0179，15增、4降；这是沿用观测连接的描述性证据，不是全员单共识已验证。旧资格、配对不足和借点处理属于当时输入；本轮以当前固定输入及独立票定义为准，重复坐标仍按不同人员的独立票保留。

旧 `_feature_union` 对同人节点置181°只用于禁止合并，不是实测距离；要保留这个约束和真实簇内角距。完整链接可能拆开一些成对近邻，并随人员增减改变已有身份归属；人数曲线每个前缀应只使用该前缀人员，不能使用全员身份池回灌早期结果。输入稳定排序、同角点同人一票及坐标相同的不同人员独立票应同时成立。

已有[旧核心测试](../../tests/test_union_branch_consensus_20260926.py)覆盖接缝、同人近角不能合并、完整链接直径、不同邻接、点支持不等于分支支持；这是可参考的验证对象，本页没有重新运行它们，也不把历史测试通过替代本轮算法验证。

## 3. 阈值、配对和环序的边界

旧[RC1配置](../clustering_release_received_20260920/config.json)的9°主值与6°／12°敏感性用于整份标注 `split_cyclic + complete`；top与bottom可以各自循环对应。旧[25.6px方法及开发审核](../cluster_validation_received_20260922/Pro原报告.md)使用1024×512画布中最大对应端点二维距离、周期横向处理，24图21项明确判断中成对符合20项、完整链接整簇符合15项。这些数值不能直接变成全员角点身份簇的5°依据；人工样例可作诊断，但不是独立校准集。

[人工对应原话](../clustering_numeric_received_20260920/evidence/latest_decisions.json)确认过uNb-21的一组对应与相近判断，同时明确反对用该例4.59°直接定全局门槛。独立top／bottom匹配也已有[10/1实验](../../research/layout_methods_review_20261001/pro/REPORT_zh.md)，但两端映射可能冲突；单端匹配成功不自动恢复原墙角配对。本轮可利用两端信息，必须保留配对来源与冲突状态。

原始作答继续保持已确认环，其余沿既有共享x默认序。身份中心位置不会自动决定正确邻接。若本轮全局候选采用共享x默认连接，应明确这是**新候选的工作连接规则**，保存 `ring_confirmed=false`，并检查自交、退化、重复方位及原图/3D；不能称已恢复物理拓扑，也不能因默认序可生成BEV就称顺序已确认。若采用观测邻接证据，则记录支持者、冲突及如何得到最终环；改序前后候选应可追溯，不以GT选序。

## 4. 本轮应从历史保留的解释

- 角点身份匹配门限、保留点的支持率门限、几何告警线是三个不同参数，不能都叫“5°投票阈值”。新支持率规则属于本轮新增方法。
- 全员人数、可提供点对观测人数、各点支持人数和最终整环支持证据分别保存；点中心是估计位置，不要求某人恰好标在那里，但不能说全部人员都投给了该新坐标。
- 逐点多数不保证这些点曾共同出现在一份完整标注，也不保证选点后能形成唯一合理环；少于三对、对应冲突或连接失败应给明确状态。
- 本轮可在ERP中直接融合完整上下点，再以BEV作共同评价、3D作诊断；不需要先固定整份标注簇，也不需要先证明旧多分支算法成立。
