## 怎么审核

1. 搜索并选择图片，先看原图；需要时点击原图放大。图片笔记只描述可见位置与结构，不自动生成历史类别。
2. 展开候选信息，选择Manual或Semi；对照旧类、新候选、实际人数、单人簇及不同稳定指标。
3. 下面历史面板按本轮d_mask=0.10完整链接分区查看真人点集，可逐人打开3D。3D沿用原始顺序，点集叠加使用人工已确认计算视图；两者不同时以来源说明核对。约束拟合不参与本轮分簇，更规整不代表正确。
4. 填你的类别与理由，必要时记簇含义和单人标法判断。未审核、暂缓与三档不适用分开；没有Manual/Semi历史的图片只能写图片观察，不能补造历史标签。
5. 定期导出JSON。导入按图片和条件检查版本及完整性；异常缓存保留，不静默覆盖。审核是对候选的判断，不要求符合算法或原106张tag。
