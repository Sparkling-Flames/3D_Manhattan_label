# 原图盲态可见特质：字段与使用边界

648张图片均已逐图查看；新记录为AI图像审查，未读取人员响应、质量、时间、分歧或模型预测，不覆盖历轮人工分类。图片身份仅从既有648图登记表取得，不把该表的描述作为此次目视证据。

本轮是缩略图可见证据初筛：每图最大508×254像素，首末各12张、中间每页24张。部分工具显示将整页缩至1755×1440；因此微小角点、细玻璃边缘和局部低对比区域可能漏检。reviewed=true仅代表实际查看，不代表高清复核、人工确认、GT或可用几何比例。适合作为A路线探索输入，并应与历史人工特质分别做敏感性分析。

| 字段 | 含义与枚举 |
| --- | --- |
| index | 既有648图登记表的零基序号，仅用于核查身份，不作为特征 |
| image_id | 原图唯一身份，不包含人员结果 |
| reviewed | 是否实际进行本轮目视；未查看不能填true |
| floor_boundary | 主体墙地交界在缩略图中的可追踪情况：present大部分可见；partial仅部分可见/家具遮挡；unknown无法确认。不是精确可见比例 |
| ceiling_boundary | 主体墙顶交界：present大部分可见；partial局部被梁、吊顶/隔断或其他结构打断；unknown无法确认。不把partial解释为困难 |
| corner_occlusion | present至少一处可见墙角/墙脚转折被家具、柜、窗帘、植物等遮挡；absent未见明显遮挡；unknown无法确认。不是所有角点的正确标签或计数 |
| connected_space | present通过开门、无门大开口、楼梯口或开放布局可见延伸区域；absent未见这样的可见连接；unknown门/隔断开闭或连接关系不清。不是已确认同房关系，不判断门后是否应纳入标注 |
| reflection_glass | present可见镜面、玻璃门/隔断/柜、明显玻璃外窗或类似反光表面；absent未见；unknown细节或材质不明。不是断言反射造成困难；百叶/窗帘不能据此保证存在或不存在玻璃 |
| low_contrast | present发现明显低对比/暗部使局部交界难以分辨；absent本次显示尺度未见突出该现象；unknown无法确认。absent不等于物理对比度高，不可当作像素测量 |
| evidence | 图像中实际可见现象的简短中文记录；不含总难度或人员结果 |
| reviewer | AI_image_only；不能改称人工复核 |
| review_basis | 记录本次图像显示尺度与盲态输入限制 |

所有枚举应作类别处理，unknown不能填成absent或数值零；也不能将present/partial/absent跨字段统一解释为好坏。总体难度、GT正确性、同房身份和范围选择均不由这些字段决定。当前字段主要是粗粒度存在性，组内变化不足的字段不应强行进入复杂模型。

重建核查页：`python tools/thesis_main/analysis/image_portrait/visual_traits.py --start 0 --count 12`。核查页只用于本地目视，不上传Git；本轮生成的28页已在交付前清理。

`resolution_recheck.json`保存索引0、32、…、640的21图独立复核记录。全部直接逐张显示原始2048×1024图片，无拼图缩小，未读取人员或模型结果。使用同一AI审查者，因此这是分辨率/重复审查敏感性检查，不是独立标注者一致性实验；不能用一致率推导准确率。

### 对字段的实际处理建议

- 可见连接/突出低对比在当前宽泛存在性口径下接近常量，本次抽检未发现它们主要由缩图误判造成。仍不应作为有效区分难度的连续指标；默认先作覆盖描述，训练侧低方差筛查后决定是否进入模型。
- 反射/玻璃的unknown具有分辨率敏感性，不能当absent。未抽检图片的194个原始unknown继续保留，不能批量用同房或其他视角补齐。
- 墙顶字段的两处纠正暴露了“有梁/结构复杂”与“实际不可见”易混淆；原初筛字段只能作为粗描述，不能直接解释为真正墙顶可见率。若论文要就边界可见性作主要结论，应另行固定分段可见率定义后重审，不从这21图批量推断其余图片。
- 墙地与遮挡字段在初筛表里完全关联，存在定义重叠；分析时避免将二者同时当作两份独立证据。这是测量设计限制，不能通过人为改标签制造独立性。
