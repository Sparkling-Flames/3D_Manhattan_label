# 结构化真人标注的多层分歧与收敛：独立研究结果

日期：2026-09-18。性质：实际执行的数值研究、方法原型及后续验证建议，不是最终语义分簇结果。代码与全部行级结果随本次 ChatGPT 会话的单文件 HTML 研究报告和 Python 程序交付；本目录保存可继续研究的结果摘要。

## 结论

不能继续把一个聚类编号同时解释成一个标注空间、一个结构理解与一种定位精度。建议以范围/闭合选择、结构表达、对应与局部定位、可计算性/OOS 状态等多层分布为研究对象，再研究真人数量及人员构成如何改变各层稳定性。正确性可另设评价通道，但不作为保留原始行为的门槛。点数差异有研究价值，却不自动等于范围差异；移除点数硬分离同样不自动产生正确语义分簇。

保留旧口径排除的人员后，39 图中 787/3,357=23.44% 的不同点数作答对墙带相近；其外为 1,380/4,807=28.71%。表示现象对是否排除旧人员不敏感。

反向检验：647 对不同点数但墙带距离≤0.10的作答中，406 对在某个 22.5° 水平窗口仍有超过20像素的边界最大侧差均值；旧同簇内也有346对达到该诊断条件。因此，直接去掉点数分离并继续只用全局 IoU，也可能掩盖局部结构变化。这些窗口/阈值是诊断设置，不是标定后的语义容忍度。

39 图中另有2,252对同点数跨旧簇作答，其中1,026对距离仍≤0.10。完整链接不要求每个跨簇点对都远，这不是实现 bug，却说明簇号不能直接当语义类型。例如 jtcx-05 六份 Manual 均8点，两个三人簇的九个跨簇对中八个仍相近。

构造性反例：在线性边界插入冗余一对上下点，6点→8点，墙带距离0，旧哨兵距离2。它反驳点数变化必然意味着范围变化；不证明真实额外点都冗余。

## 2. B6-22 的局部尺度与点配对

B6ByNegPMKs-22 Semi：24人全部8点，但有8个旧簇，故取消点数硬分离无法单独解决该图。24份标注的最小相邻角距为11.24–25.03px，各自间隔中位数约253.5–258.9px；同图的局部尺度变化远大于整图单一尺度能够表达的内容。这是标注几何诊断，不是独立原图角点密度或因果结论。

不建议直接把距离除以每份作答自己的最小角距：近零分母、错误配对、多点/漏点会同时改变尺度。候选应保留绝对偏移，并比较有下限、冻结来源的局部归一化，而非立即选定一个新公式。

旧几何会平均每对上下点的横坐标。原始数组也并非总按上下交替存储：781份旧入簇作答中638份使用原顺序配对，143份用横坐标回退配对。研究程序据已接受的归一化结果恢复端点身份，对39图全部817份可归一化作答均唯一恢复，没有把相邻存储位置直接当作配对。

恢复原端点、分别插值上下边界后，可比较作答对的原始/投影墙带距离绝对变化均值0.000436，最大0.025514；另5份该表示发生上下边界交叉，单列而非强行修复。因此投影确实隐藏一个误差通道，但不能夸大成当前分簇问题的唯一原因。

## 3. 文献驱动、已运行的部分匹配及环序约束原型

借鉴 GOSPA（Rahmathullah、García-Fernández、Svensson，FUSION 2017），把角点对表示为周期x、ceiling y、floor y；采用p=2、alpha=2，输出定位平方项与 c²/2×未匹配角点数。人与人的对称比较中，未匹配不自动等于哪一方漏标/多标，更不自动等于不同空间。

8,170个作答对×10/20/40px三种敏感性设置，共24,510项实际计算。无环序限制的最优匹配在这三个设置下分别有0/4/45项违反角点环向顺序。

随后实现了枚举循环切口的环序约束部分匹配动态规划。49个作答对×设置的违反均消除，涉及45个不同作答对，目标值均严格增加。30个小型随机实例与穷举最优值一致，最大平方目标误差1.46e−11；对称误差0，接缝旋转误差3.27e−11；100个本来满足环序的最优匹配，约束前后目标在数值精度内相同。

X7-19 W011/W015，c=20：无约束匹配8对，分数19.83；有约束匹配7对，分数22.35，定位平方项99.42、未匹配平方项400。更小的距离可能来自忽略循环结构的对应。尚未证明约束版本的语义准确率更高，也不宣称新约束目标继承GOSPA全部度量定理。

## 5. 真实有限人员池：不同投影的稳定性可相反

固定N人池，作答j有m_j个其他相容作答，随机观察n人后，下一份与已观察全部不相容的精确概率为：

P = (1/N) Σ_j C(N−1−m_j,n)/C(N−1,n)。

无需把重复排列当新样本。阈值相容不是语义等价，以下是池内组合诊断，不是新人员预测：

| N=24，先观察随机8人 | 新点数概率 | 新墙带不相容概率 |
|---|---:|---:|
| B6-22 Semi | 0 | 0.289873 |
| e9-32 Semi | 0.054348 | 0 |

固定类别下，累计分布每加一份作答都有 TV(p[n+1],p[n])≤1/(n+1)。从同一N人池无放回抽n人，E||p_n−p_N||²=[(N−n)/(n(N−1))]×(1−||p_N||²)。本轮穷举验证后式，最大误差2.78e−17。这是有限总体恒等式应用，不是新定理。相邻变化变小、逼近完整历史的末端归零，都不足以证明共识、质量上限或未来少数标法已被覆盖。

独立同分布示例：真实占比5%的固定标法，15人全部看不到的概率约46.3%；要有95%概率至少见一次需59人。不是建议每图统一59人，而是提醒先指定想保护的少数比例、人员总体与漏检风险。

## 6. 后续研究对象与验证

表示分层：范围/开口闭合；结构事件的保留、漏掉或部分表达；对应后的局部定位及上下不对齐；格式、可计算性、OOS/信息不足。不同层面可以同时成立，不强迫全部落入一个互斥簇。

39图作为开发与反例集。其外175图本轮仅提供数值覆盖，不能叫独立语义测试集。应建立多关系成对/局部审读标注，保留不确定及审读冲突；未评论图不自动视为干净。然后比较旧表示、去硬分离、局部差异通道、无序/有序部分匹配，在未参与选择参数的图片和建筑上验证少数结构保留与语义关系。

人员模型优先连续倾向、图片×人员交互与收缩；同人数下比较不同构成，控制图片与Manual/Semi/初始种子。ABCD对AABC可比较构成，AAB对AA同时改变人数，不能只解释为类型效应。重新组合真人不会增加独立证据。

停止判据区分：新范围/结构发现、比例区间、条件定位分布、无效作答概率与另行定义的质量收益。需要冻结表示后检验保留或未来真人；非拒绝差异不是等价证明。OOS不自动意味着永不收敛，也可能是稳定多峰或稳定错误分布。没有同人同图盲重测，不能把所有未解释成分称为个体不可约随机噪声。

仍需确定：分层语义关系基准、目标人员总体及采样机制、每层容忍度与最小少数比例、未参与方法形成的人员/图片验证、质量上限所依赖的参考政策与损失。106张人工难易tag保留独立对照，不作为强制拟合目标。当前没有经验证的新语义分簇器、人员类别或未来真人收敛预测器。
