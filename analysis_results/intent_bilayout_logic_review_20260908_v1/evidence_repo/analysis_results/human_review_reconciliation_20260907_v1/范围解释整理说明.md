## 对当前研究主线的意义

《与导师交流.txt》的文字记录明确涉及：多轮标注的瓶颈、不同场景下瓶颈的含义、整体分歧与少数结构解释的量化，以及混合人员结果的复用。导师没有要求每图选出一份正确候选。语音回忆中关于Bi和算法的内容带有不确定性，不按已定实验处理。

本次整理可帮助后续区分三个问题：

1. **结果是否稳定？** 这是已有响应分布、簇支持数或几何距离随人数变化的问题。
2. **稳定的是哪种范围解释？** 你的E/X及截断位置评论，可辅助解释已存在的簇，但需要连接到具体响应后再检验，不能直接重命名整簇。
3. **该解释是否符合规则，局部标得怎样？** 这是另外的质量与规则判断；共识、范围类型和正确性不能相互替代。

Bi可以作为比较输出的来源：有些图两头分开，有些图相近，有些图只覆盖潜在范围的一部分。是否足以承担两倾向模拟，需要后续证据支持。当前评论已提示二分类可能不完整，但还没有建立稳定的人群类型、噪声机制或收敛结论。

## 数据约定

`scope_comment_readings.json`为本次AI人工阅读提取，覆盖50个case；生成器逐条验证引文确实来自该case的原`notes`或`oos_reason`。没有范围条目表示本次未从评语提取到明确范围内容，**不是没有歧义或没有问题**。

| 字段 | 含义 |
|---|---|
| `scope_statements` | 可有零条、多条；不强制给整张图一个类型 |
| `kind` | `semantic_assignment`原文明确归类；`observed_extent`已显示范围；`potential_scope`潜在范围／预想；`output_comparison`输出比较；`rule_condition`规则条件／偏好；`scope_uncertainty`用户不确定性意见 |
| `target` | 保留原文对象，如W2、簇2、改后GT、其余；没有足够证据不替换成正式ID |
| `source_field`、`quote` | 原文位置和逐字摘录；保留“更像、可能”等限定 |
| `interpretation`、`qualification` | AI理解及其限制，待你确认；不是从模型名或旧选项自动生成 |
| `scope_label` | 仅原文明示归类时填`enclosed`或`extended`，其他条目为null；这仍是待确认的原文解释，不是最终语义真值 |
| `annotation_ids` | 本轮全部为空；后续明确原文所指版本后再连接，不能猜测“其余”或“簇2”包含哪些人 |
| `quality_excerpts` | 单独保留质量原文，不以“enclosed”推断正确，也不以局部瑕疵取消范围解释 |
| `final_user_decision` | 全为空；原始记录完成状态不改变它 |

`reconciled_records.json`新增`scope_reading`，原`human_record`不变。`VALIDATION.json`新增`scope_reading`覆盖计数；它的`new_visual_reviews=0`指本次评语整理。原有50张对照图、8张高清原图、6张透视的阅读记录属于前一轮，不能累计成新审图。
