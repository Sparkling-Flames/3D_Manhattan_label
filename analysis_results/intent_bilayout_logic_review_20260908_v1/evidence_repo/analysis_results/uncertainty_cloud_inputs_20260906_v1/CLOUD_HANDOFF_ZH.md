## 当前研究意图

用户与导师倾向于研究全景布局标注的不确定性。用户已知同图的真实标注会出现enclosed／extended不同范围，且两种情况都有：部分图片本身边界难界定，部分图边界较清楚但人员执行不同。研究要求为Manhattan和enclosed，但不据此把所有extended响应预先判错或排除，也不能反过来把它们自动叫作合法多解。

Bi-Layout两种输出的差异大小可作为候选模型指标，帮助检查范围解释差异。双头相同的图片也应作为对照：本包历史214图中47图原始双头坐标相同。这不是47张图像无歧义的人工真值。

“两倾向输出用于模拟”与“疲劳等工人状态模拟”是两条暂时分开的路线。用户回忆导师可能在讨论中转向前者，具体机制尚未确认。不要把enclosed=清醒、extended=疲劳，也不以工作流调度/POMDP作为当前任务的默认方向。

## 建议的分析顺序

1. **先检查测量。** 原始环序、点对对应、接缝、退化和规则范围分别处理。比较旧线性墙面带代理与物理投影一致的测量时明确名称和可计算条件；不能先选最容易支持结论的指标。
2. **复用已有真人分簇。** 主工作视图是extended73，旧42及legacy213只作注明版本的对照。先核对原成员、人数和阈值，注意旧42有一个raw-only版本。若重新聚类，必须另命名版本、说明必要性并报告与旧结果的差异，不覆盖原簇。
3. **检验连续关系和反例。** Bi双头差异是否与真人分歧、簇数量／支持比例或范围模式有关？特别检验“双头相近但真人分歧高”“双头分开但真人一致”两类反例。不得用Bi差异先定义图像歧义再用同一差异验证分类。
4. **检查簇与双头的关系。** 使用真实簇成员和实际模型坐标，允许一个簇、多个簇、两头都不贴近或无法解释。几何最近只叫作亲近度证据，不自动成为enclosed/extended语义判断；需要视觉判断时先实际打开原图及对应真人响应。
5. **区分场景与条件。** 报告building、Manual/Semi、自然/合成初始化及人员组成的支持；实体房间ID未知。跨图相同人员和同building多图的依赖要处理，图像等权与building等权不能混用。当前20人是资源属性，历史26人都可提供证据。
6. **随后才讨论模拟可行性。** 若真实人类模式与双输出的对应得到支持，可以提出两倾向混合的受限情景。先分清经验参数与假设参数。疲劳另列数据需求，不自动纳入该模拟，不把重采样当新增真人。

人数增加可能使“对分歧分布的估计”更稳定，而分歧本身保持非零。低分歧还可能是共同偏差。质量参考可帮助解释不确定性，但本研究不自动改写成只追求单一准确率或自动停止器。
