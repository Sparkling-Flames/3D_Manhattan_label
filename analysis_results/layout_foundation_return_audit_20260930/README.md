## 对建议的判断

| 建议或结论 | 本地判断 |
|---|---|
| 保留旧曲线的中心投影数学 | 同意。三维直线与正确大圆弧重投影等价；辅助平面高度本身不使曲率错误。分支和数值退化仍须处理。 |
| 显式邻接定义完整足迹，不能无条件按 x 排序 | 同意。顺序属于几何输入；循环起点和反向属于等价变化，任意换邻接不是。 |
| 将投影墙带与完整足迹分开 | 同意。完全隐藏的扩展无法靠可见投影 IoU 辨识；应换比较对象，不能扭曲曲线。 |
| 顶点中位墙高棱柱代理降为历史/诊断用途 | 同意，明确反例已经接入原函数复现。缺乏可信顶面时不宜将该代理解释为真实三维体积相似度。 |
| 明确当前列式墙带的适用含义 | 同意。它是确定的声明表示，但并非一般屋顶下的真实可见墙。墙顶不齐也可能来自标注误差，不证明存在起伏屋顶。 |
| 立即建设一般三维 mesh 渲染作为主指标 | 暂不建议。先明确屋顶是否有观测依据；任意补顶会引入新差异。网格目前适合作为已知合成实体的对照。 |
| 增加 physical_wall / scope_cut / unknown | 语义区分合理，暂不增加全量人工审核前置条件。声明范围边可参与范围比较；是否作为实墙遮挡是另一项假设。 |
| BEV IoU 为范围比较主候选 | 同意作为候选，未完成全量敏感性验证。它主要由 bottom 点决定，遗漏 top 偏差；近地平线深度还会放大像素误差。 |

双向覆盖率有助解释包含/漏出，但与 IoU 数学相关；同高棱柱的体积 IoU 等于 BEV IoU，都不能当作独立重复证据叠加加权。质心仍是辅助位置描述，不补齐隐藏范围、局部细节或对称变化的盲区。
