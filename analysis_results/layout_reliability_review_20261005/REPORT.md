### P2-1：高度包络漏掉参数变换的无穷根

位置：[continuous_metrics.py:20](C:/Users/ASUS/Downloads/layout_reliability_20261005_delivery/layout_reliability_20261005/src/continuous_metrics.py:20)、[height_envelope:126](C:/Users/ASUS/Downloads/layout_reliability_20261005_delivery/layout_reliability_20261005/src/continuous_metrics.py:126)。

高度交点方程变换为 t=tanθ 的多项式后，只求有限根；cosθ=0 的真实交点可能丢失。这会在未重新分段的区间内选错最小／最大来源。

独立反例：同一个半边长2的正方形底面，两份墙顶分别为 Y=1+0.1Z、Y=1−0.1Z，全部正高度。来源自身必在全部来源的高度包络内，越界量按定义为0。原程序却把两份来源各自判为 **0.4h越界**。仅在内存补入 π/2+kπ 的分割后，两者恢复为约1.11×10⁻¹⁶h。

这是核验器错误，不能解释为来源或压缩质量错误。建议补齐参数奇点事件，并加入“每个来源都在自身来源集合包络内”的性质回归及循环相位控制。修复应另存版本，不覆盖原交付证据。

**对已发表数值的实际影响：**本地已把两真图24个压缩状态全部用原包络及内存补点包络重算；逐状态差异为0，最大越界仍仅4.44×10⁻¹⁶h。另以20,001个方向直接计算逐人员min/max，原包络误差不超过1.78×10⁻¹⁵h。因此这批“未见高度越界”的观察仍成立；通用核验能力尚不能验收。

`depth_height_change` 的 `rational_extrema` 已补 cosθ=0 位置，不能把此缺陷扩展到它报告的所有高度变化。

## 4. 可以采纳什么，仍不能推出什么

可以暂用的基础是：

1. 在满足条件的完整当前名单上，保留精确分位曲线、来源和配对表示节点；精确表示的底面按相应阈值与Lee一致。
2. 编辑近似独立保存，逐项量化底面、顶部、高度、来源包含与节点数量的变化。
3. 锁底方案适用于明确要求保持既定底面的用途；自由压缩用于允许改变该底面的近似用途。两者不应仅按GT最高分选择。
4. 原名单域外时保留完整失败与其他可用表示；rPc/uNb并未被证明为错误房间。

“精确”是对所声明投票算子的精确表达，不意味着真实物理角点、唯一合理范围或最优GT质量。锁底保住的也可能是多数遗漏或细小噪声；它是用途约束，不是总体质量优胜证据。23.31%失去严格整列包含不等于23.31%质量错误或人员反对，约0.25px松弛只是幅度诊断。

本轮比较可信的研究增量是：**表示近似能改变原本很小的方法差；这种变化可以与人员输入本身的变化分别记录。** 两图开发材料、反例及可追溯工程还不足以单独证明期刊级普遍效度。“区域投票变点”“锁底删点”“三角不等式”也不能单独作首创主张。

|---|---|---|

| 搜索域 | 同一25／66节点环的保序子序列 | 有来源、兼容关系及有限连接备选的结构池 |
| 目标 | 在误差预算内减少表示节点 | 有依据地保留细节、排除错误并形成几何合理候选 |
| 少数细节 | 投票前已消失的结构无法恢复 | 正是需要保留为待检验候选的内容 |
| 人数支持 | 精确票的供者与压缩损失 | 局部供者、原完整标法、候选整体兼容分别计数 |

因此“精确共识测量＋压缩编辑”不能取代空间候选线。其可迁移部分是全路径保真、每次路径替换的来源与损失账本、循环起点检查；不能继承Lee等价、精确高度包络或整列包含保证。

关键假设也应拆开：**如果添加与删除穷举同一候选集合、采用相同可行条件和目标，最优集合不会因为搜索方向不同而改变。** 真正可能改善细节保留的是删除依据、目标／约束、可达候选域或有限搜索策略。比较时要分别控制，不能把“额外保护细节”的收益全部归于减法。

### 最小推进方案

先修复上述两个有限实现问题并完成小面板原图核验，然后可以立即开始局部候选实验；不需要先扩大人员分类，也不需要等通用复杂拓扑全部解决。

1. **固定小候选域。** 以既有0.4h凸起合成例作控制，并选少量已有审核的真实细节、范围替代和确认复杂环。每例先限定一至两个局部块，保留已观测路径及少量明确相容的跨接。候选池不是把所有点按x拼成“大房间”。对应若依靠人工，明确这是条件实验。
2. **同时保留原完整作答作对照。** 比较原完整标法、有限删改、相容局部重组。保留互斥范围，不要求一个候选同时解释所有范围。
3. **先穷举，再比较方向。** 同一小候选域先建立枚举参照，再以相同评价次数预算比较加法／减法搜索，区分剪枝、顺序与候选域影响。
4. **消融删除政策。** 在相同候选域比较仅几何残差／最少点、完整观测路径保真、有据细节保护。先列约束与Pareto结果，暂不冻结总权重。低人数本身不能证明该结构该删；低正交残差也不能证明删对了。
5. **同时记收益和新增错误。** 记录有据细节保留、错误结构保留／新增、遗漏与外扩、新跨接边及其观测依据、上下偏差、拟合前后残差、编辑量和失败。删点可能扩大空间，不能只看净面积或GT IoU。
6. **守住评价边界。** 生成和预算不读目标GT；完整候选不能继承局部票数。C由A删点得到，仍不自动获得A的10票。几何有效性、图像证据与人数支持分别报告。

这一小实验比继续增加多数轮廓的压缩变体，更直接检验用户“从丰富观测出发，有依据才删除”的原始设想。它目前仍是有价值的待检验假设，不应提前宣布成功或无效。
