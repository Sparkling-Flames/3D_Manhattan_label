# Lee共识的节点、比较用途与后续使用

2026-10-05。回应用户“Lee区域共识没有实际标注点，是否适合比较和后续使用”的问题。本轮读取现有四图展示的全员末步结果，未重算投票、使用GT指标或修改源标注。

## 结论

**当前Lee有底面边界坐标及其回投底点，缺少的是融合上点和物理墙角身份。** 原页面只绘制底边曲线，没有把已保存的顶点画成圆点。这是显示方式与输出能力两个问题，不能混为“算法没有几何结果”。

`lee_consensus_demos_20261003/demos.json`的`steps[].regions`已有完整GeoJSON区域；`steps[].erp_regions`已有每个分量／外环／孔洞的回投`vertices`及显示曲线。`region_projection()`明确保留所有环，没有取最近墙轮廓或补上界。当前点中心法的融合点也通常不是任何人实际点击的坐标，因此“是否有人点过这个坐标”本身不是使用门槛。

| 用途 | 当前Lee-BEV是否足够 | 必须保持的解释 |
|---|---|---|
| 底面IoU、遗漏／外扩、面积质心、成员变化 | 是 | 衡量声明空间范围；同图、同名单、同地面尺度及规则下比较 |
| 声明底边的连续边界距离 | 是 | 比较曲线或线段，不要求点数相同；不是角点身份匹配 |
| 底面区域存储、二维范围展示与后续几何运算 | 是 | 消费者须接受实际分量、孔洞及空区域，不能静默只取最大分量 |
| 少量节点的人工编辑 | 可作为起点，未验收便利性 | 精确表示可能节点很多；独立简化后记录图像／范围损失 |
| 物理墙角数、角点召回、上下对应 | 否 | 区域交点或数值分段不能当成已认证墙角 |
| 完整上下点对标签、顶部质量、墙高及完整三维 | 否 | 必须增加顶部构造与模型；仅底面不能唯一决定这些量 |

适合底面比较，不等于已经形成完整layout标注。把点融合输出也转换成声明BEV后可以作共同范围比较，但这个共同指标不能证明顶部或对应已经解决。缺失的顶部指标应为不适用，不能填0，也不宜将其混入一个完整质量总分。

## 本地核验

四图八份已有结果均为单个无孔多边形。本表排除闭环末尾重复的首点，计的是表示节点，不是物理角数。

|---|---:|---:|---:|
| B6ByNegPMKs-40 | 22 | 56 | 50 |
| uNb9QFRL6hY-53 | 15 | 72 | 72 |
| uNb9QFRL6hY-67 | 15 | 44 | 44 |
| yqstnuAEVhm-05 | 8 | 28 | 34 |

将已有ERP底点按连续1024×512坐标、共同地面Y=−1反解，依原分量／孔洞与环序重建区域。八份结果的最大坐标差为1.24×10⁻¹⁴h，最大对称差为3.85×10⁻¹⁴h²。检查容差为1e−9×max(1,原面积)，只用于浮点复核，不是标注容差。这确认已有底点能恢复同一底面，不表示恢复了真实物理墙角。

uNb-53的两条规则在近重合边界的对称差运算中各出现一次GEOS运行警告`invalid value encountered in symmetric_difference`。两输入均合法、输出有限，对称差为8.32×10⁻¹⁵h²；警告逐项保存，未修形、裁剪或静默忽略。没有因此声称严格的精确算术证明。

[regions_and_bottom_nodes.json](regions_and_bottom_nodes.json)保存原区域与去掉闭环重复点的底点节点；schema为`lee_saved_boundary_audit_v1`。`top_points=null`、`physical_corner_identity=not_established`；`boundary_rings`保留分量和孔洞，末点连接首点。此文件是已有结果的核验摘录，不替代研究输入真源，也不重新定义共识合同。

复核只使用每图最后一步的`members`、`regions`和`erp_regions`，核对名单与完整展示池相同；其他字段中的GT和历史分数未进入本轮计算。回投使用既有射线公式`rays`，地面点为`-ray/ray_y`；将每个环还原为Polygon／MultiPolygon后比较。没有重新选人、改变≥与>规则或简化边界。

## 下一步应怎样衔接

1. 精确区域继续作为范围证据和共同评价对象；底点与曲线作为它的可追溯表示。不要为了让它看起来像稀疏标注而直接改写精确结果。
2. 编辑表示独立压缩，同时报告底面增减与回投变化；此前0.05h却产生近9px列方向变化的案例已经说明单一三维预算不足以代表显示保真。
3. 在满足单值等条件的图上，可以继续采用已验证的“全员区域／曲线证据→同步上下节点”扩展。它需要完整上部观测及明确投票政策，不是从Lee底面自行推导上点。偶数阈值对偶仍须保持，不能把两处≥50%直接视为等价。
4. 复杂环仍分别保留完整声明范围与域外状态；Lee底面能计算，不等于完整上下构造适用。只有具有上下输出的方法参与顶部比较，完整标注的编辑与训练用途另外验收。
