## 核心判断

OSPA平均接近、逐点最近邻覆盖、局部一一匹配数量以及互斥整图分区是不同的测量对象。不能从某个开发配置表现较好直接升级为最终语义分簇。不同点数可能只是附近增点，也可能表达真实紧凑转折；同点数可能在局部一增一漏。用户的范围不同包括局部覆盖遗漏，不等于另一个房间或Bi enclosed/extended。

用户关于时间的实际问题是同一个人在同房/相似场景的耗时规律，不是时间相近则标法相近。本轮按这一问题重新分析时间比例；未将时间混进几何分簇。

## 本轮方法

OSPA1 c30 p1为旧平均点集指标；OSPA2 c30 p2加重大偏移，也加重点数差。Hausdorff H=max{max_a min_b d(a,b),max_b min_a d(a,b)}采用固定球面角距，检查每点附近是否有点，不匹配原作答内部的上下点，不相对旋转两份作答。半径3/6/9/12度为探索设置，不是语义阈值真值。

另计算半径内最大一一匹配数和等点数瓶颈距离。等点数瓶颈不能直接用于不同点数；分组控制中不同点数用阻断占位值180，不称为实测偏移。

完整链接保证簇内所有距离不超过阈值。真实代表覆盖则从剩余作答中选覆盖最多邻居的实际作答，取半径内成员，继续迭代。并列按邻域平均距离与固定顺序。它只保证到代表近，簇内直径可达约2倍半径；不能因簇少而宣称更正确。

## 对人数与不确定性的直接影响

不用全池簇中心，精确计算随机前k人与下一名未见真人的相容覆盖。每个目标有m个相容邻居时，未覆盖概率comb(N-1-m,k)/comb(N-1,k)。联合未覆盖通过两邻居集并集计算，并已用小样本穷举验证。

46张至少19人Manual图、k8、OSPA6、H9，按图等权：OSPA未覆盖19.73%，局部未覆盖28.68%，平均规则已覆盖但局部仍未覆盖9.30%。单列无借用补点版本：两份历史借用他人点的修复恢复原9/11点且人员仍在，OSPA未覆盖19.84%，局部仍28.68%，联合事件9.19%。18张高人数Semi联合4.43%，9张OOS联合11.61%。

这是固定人员池的几何覆盖诊断，不是池外预测、新语义模式概率或永久不收敛。不同阈值没有已标定相同语义严重程度。它说明单靠平均距离或簇编号可能过早认定已覆盖，不能只看累计曲线变平。

## 同一个人的时间规律

复用上一轮严格审计1971时间行及229条同房共同人员图对记录，身份/秒数/资格再次核对；未宣称重新审计全部原日志。11个图对至少5共同人员；19人图对的较长/较短时间中位比：q9-02/13=2.458，uNb-50/60=1.371，Uw-06/08=1.554，yq-31/32=2.188。

同房规律可能是绝对近似、固定倍率或仅排序相关。用其他人的两视角log比率估计倍率、留出一个人，再用该人源视角时间预测目标：q9绝对log误差1.000->0.769，但个人楼外历史基线更低约0.527。11图对等权：复制源时间0.705、图对倍率0.712、个人历史0.500。此简单同房迁移总体未胜出，不否定其他规律。

其他人两视角已知，故仅固定图对留人验证，不是未见图/未见房间预测；先后熟悉与重叠房间仍未完全控制。没有把基线校正说成准确因果剔除快慢，也没有把时间当认真度。
