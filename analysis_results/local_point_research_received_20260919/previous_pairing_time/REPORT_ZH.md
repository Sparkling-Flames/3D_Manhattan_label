# 先核准表示，再研究标注不确定性
## 12图审核、全量配对审计与 active time 初探｜2026-09-19

### 核心结论

本轮不继续扩展自适应尺度、语义事件体系或复杂模型。先解决一个已经证实的测量问题：b8-07的原始点很相近，但旧上下配对制造了明显不同的墙带。全量筛查发现34份同侧配对警报，不能把这些记录的旧几何分歧直接解释为人的分歧。

研究对象建议称为“标法及其分布”：包括局部区域覆盖、角点或细节增减，以及允许一定幅度的位置变化。不把每个簇叫作不同物理空间，不把用户问卷的Range字段等同于Bi的enclosed/extended。

暂不优先增加新算法。原仓库已有的不依赖上下配对的OSPA30，在原有6°分组阈值下，与本次可映射的23项成对审核关系一致，是值得优先保留的简单工作基线。但这不是独立准确率验证；旧案例仍有局部偏移被平均掩盖、成对相近却在整图分组中拆开的反例。此前优先推荐A3的依据不充分，本轮把它放回对照位置。

active time值得继续用于成本与行为描述，尚不适合掺进几何距离。它对部分同图耗时有预测信息，但这个收益没有在C1条件下重复；校正人员固有快慢后，同房时间相关明显减弱，且熟悉/顺序效应无法从当前资料中充分分离。

### 2. “范围不同”的含义：按用户原话，不强行套Bi

用户在e9-19指出“漏了中间”，在uNb-50指出“漏了浴缸区域的墙角”，这些都被填写为Range不同。因此这里的Range包括同一房间内部的覆盖变化，不只是越过门口进入另一房间。

不必先裁定“局部漏标算不算另一个空间”，才能研究这项差异。可以直接描述：本份作答没有表达某区域或角点；另一份表达了。增加门框、部分表达隔断、遗漏转折、不同闭合、明显错位，都可进入标法分布；不要求先证明它们是合理观点。关于认真程度、规则理解和内在空间认知，则仍不能由最终点集唯一识别。

本轮保留原问卷，不覆盖Range/Detail/Position。用于开发比较时，暂将11条“相近/接近”映射为宜相容，将12条“有增减或不同表达”映射为细粒度表达比较中的宜区分，1条仅说OOS而未评价相似性的记录保持未定。这只是一个明确的评价解释，不是用户已冻结的整图聚类真值。b8与wc相关“簇1/2/3/4”文字未保存所指方法，不能据此重建唯一整图分区。

### 3. 配对伪差异：b8-07的直接证据

原始导出点只有通用`Corner`标签，没有每点的明确ceiling/floor标签。旧`normalize_geometry`优先采用相邻原点配对：横向足够近、纵向有差值即可；随后用较小y充当ceiling、较大y充当floor。这个快速路径并不保证一上一下。

b8-07的W010/W014原序9、10是两个上点，11、12是两个下点；旧解析器分别把9/10、11/12配成伪上下对。伪事件的横向顺序在小幅坐标变化下翻转，又被周期插值放大。图像对照见`visual/b8cTxDM8gDG-07_pairing.jpg`。

仅对同一批点探索“上下半球各取一点、横向距离最小”的配对，不移动、不增加、不删除任何坐标，得到：

|W010与W014的比较|旧表示|条件配对对照|
|---|---:|---:|
|墙带1−IoU|0.200157|0.009747|
|64列窗口局部边界差，px|202.9375|4.65625|
|原A3归一化匹配分数|8.556136|3.314152|

更直接的反事实：把一份作答的坐标集合保持完全相同，只改变导出数组顺序，再送入旧解析器，W010与自己的旧墙带距离达到0.168555，W014达到0.169331。原点并没有变化，改变的是程序构造的表示。这证明了该处测量伪差异，不要求我们先认定新的配对是全图语义真值。

直接比较W010/W014未配对原点的球面最小匹配RMS约0.875°，瓶颈距离约2.048°。这些仍然记录了真实的小幅差异，没有把两份强行变成完全相同。

### 4. 影响范围：警报不等于确认错误，替代配对不自动应用

在W019/W026排除后的2,364份旧可配对记录中，34份至少有一个旧上下对落在水平线同一侧，涉及22张图：Manual27份、Semi3份、OOS4份。

这是依赖图像水平校正及上下边界假设的筛查，不是完整错误率：未触发警报不代表配对一定正确；触发警报也可能涉及原始漏点、不同层高或OOS，不能全部自动重配。

34份中，24份在固定水平线和原51.2px横向上限下得到唯一最小横向成本的异侧配对；2份有同成本歧义；8份上下点数量不平衡，不能采用该表示。所谓唯一是该数学成本的唯一，不是空间对应已经被专家确认。

主要消融只替换这24份，其他2,330份保持旧配对；对2,354份共同可比较记录、238个单元重新分组。未能比较的10份仍在原点与无序点集研究中保留，不能把它们当一致或零差异。

### 5. 简化分簇：先比较提交了哪些点，而不先重建“空间”

原仓库已有球面点集OSPA。将图像坐标转换为同图上的球面方向，在两份作答之间寻找点的一一对应，代价为截断的球面角距离，并对不同点数付出代价。它不需要先在一份作答内部配ceiling/floor，也不需要先生成墙带或人工ROI。

本轮复算的是已有设置：OSPA阶数p=1，单点距离截断c=30°；聚类阈值分别3°、6°、9°，保留点数门开/关两个版本。仍用完整链接，不让接近链条无条件串成一簇。30°是单点代价上限，6°是平均OSPA分数的分组阈值，不表示每个点都只偏了6°。

对于m≤n，使用：

`D(P,Q) = [min匹配 Σ min(30°, 点间角距) + 30°×(n−m)] / n`。

OSPA出处为Schuhmacher、Vo、Vo（2008）；本轮没有发明这一指标。原点RMS与瓶颈匹配只作为两个简单对照。无序点集不保存已知的墙连接；本数据没有明确记录最终墙连接，所以不能反向声称已恢复人的完整连接意图。

复算2,381份点集、20,672个同图同条件作答对，1,434个OSPA分区的同簇关系全部与冻结结果一致。对新审核的开发比较如下：

|配置|11项相近关系被放同组|12项差异关系被分开|
|---|---:|---:|
|A0旧配对墙带|8/11|12/12|
|A3聚类8|1/11|11/12|
|A3聚类12|5/11|5/12|
|OSPA30、3°、无点数门|9/11|12/12|
|OSPA30、6°、无点数门|11/11|12/12|
|OSPA30、9°、无点数门|11/11|9/12|

因此，继续把A3作为优先主基线的理由不足；现阶段优先检查已存在的无配对OSPA更直接，也不增加尺度学习或事件本体。

但上述表绝不能称作23/23独立语义准确率。12图是针对已有方法问题挑选的开发图；同一图和人员反复出现；12条差异关系中11条本来点数不同，11条相近关系全部同点数；部分用户文字带“好像”等保留语气。评价映射本身也尚未作为最终簇合同。它支持下一步优先级，不支持宣布胜出。

### 6. 保留成功与失败，不用好看的分组掩盖残差

本轮新审核支持例：q9-15的W002/W008被用户认为很接近，OSPA6可合并；W006在邻近机会增加一组点，又被分开。e9-19的中央区域有无表达、uNb-50的浴缸角与马桶区取舍，在该基线下也被区分。b8-07的W010/W014不再被伪上下配对拆开。

旧案例压力检查也有支持：rPc-20的W034/W037同为12点但局部集合不同，OSPA约7.844°，在6°下分开；X7-19仍得到3/1/1。但X7的3/1/1只对应局部存在性，W015对应异常仍需另记，两个单人组也不是两个已经稳定受支持的模式。

明确失败/限制之一：e9-16的W032/W006有一个明显不同的下点，一个在半高墙较低处，另一个在扶手邻近。OSPA约5.183°，6°下仍合并。这里应记录局部位置差，不再沿用旧报告笼统的“整个空间移到楼梯下方”说法。平均距离会稀释局部差异：八点中仅一点代价达到30°截断时，单点对总平均的贡献最多3.75°。因此一个平均分数不能认证所有局部都相同。

另一限制是成对相近并不传递。wc-59：W030/W027的OSPA=4.513°，W027/W006=3.152°，W030/W006=6.466°。阈值6°下，前两对相容，第三对不相容；不可能在一个互斥分区中同时满足这三条关系。完整链接保留整簇直径，因而W030/W027可能分开。这不是把连通分量换上去就解决，连通分量会反过来合并超阈值的两人。

所以应分别报告成对相容、整簇相容和新增人员下的分布变化。同一簇有2人只说明重复支持，不是整体分布稳定；一个单人标法可能值得研究，不因没有第二人而删除。少数簇、单人少是待检验结果，不能反过来决定阈值。

### 7. active time：先查资格，再谈规律

2,388份记录的时间状态：

|状态|份数|本轮处理|
|---|---:|---|
|owner_valid_complete|1,975|严格候选|
|complete with deviation|17|单列敏感性|
|partial session coverage|20|不纳入速度主比较|
|仅lead_time|297|不替代active time|
|active time缺失|79|保持缺失|

C1有780个task-worker时间上下文，逐ID、project、task、worker与冻结来源表连接，秒数和状态一致。源表Git文本采用LF，原摘要SHA是CRLF；还原换行后哈希一致，这是行尾差异，不是数据内容变化。

对其他阶段，用仓库原日志解析器和owner映射核查。1,975份严格候选中1,971份与该核对路径一致；4份C2-A-RP Block2的旧annotation-hardening脚本在task-worker与annotation片段汇总下有不同值（54/56、16/26、44/47、59/118秒）。这些并不自动是伪造或错误时间，属于汇总层级差异；冻结秒数没有改写。本轮主描述暂以1,971份来源匹配记录计算，4份单列。它们不参与下面要求同图至少5人的比较，因此不改变P1/C1结果。额外纳入17份deviation的敏感性也已运行。

不同人员固有快慢的基线取自“同阶段、同block、同Manual/Semi/OOS条件、目标建筑之外”的至少5份历史，使用log(active time)中位数。不用目标作答自己的时间估计自己的速度基线；无足够资料就不计算校正值。这借鉴响应时间研究区分person speed与item time intensity的思想，但本轮未拟合复杂IRT模型。

### 8. 时间的初步结果：有信息，但并非统一规律

**同图留一人耗时比较。** 对至少5位符合条件人员的图，留出一人的时间；比较楼外人员速度基线，与“速度基线＋其他至少4位同图人员的校正后时间中位数”。目标人的时间不进入输入。由于使用历史角色留出而非真实时间顺序，结果不是前k人在线预测，也不代表未来新人的效果。

|条件|图数|只用人员速度：图等权平均绝对log误差|加入同图其他人时间|变化|
|---|---:|---:|---:|---:|
|P1 Manual|30|0.541|0.462|改善0.079|
|P1 Semi|18|0.571|0.494|改善0.077|
|P1 OOS|9|0.524|0.491|改善0.033|
|C1 Manual|52|0.531|0.564|变差0.033|
|C2-B Manual|4|0.525|0.475|改善0.050，但仅4图|

这是自然对数误差，不是秒数或几何误差。没有据此声称显著、因果或跨阶段通用规律。将17份deviation加入C1敏感性后，该简单同图模型仍略差（约+0.014），只是覆盖和幅度变化。

**同房不同视角。** 使用已保存的支持同房关系，按图对去重，不将重叠展示组当独立房间。相同阶段/条件且至少一名共同合格人员的图对为31对；至少3人为25对，至少5人为11对，至少8人为8对。11对来自6个已有组标识，不等于6个已独立验证房间。

举例：uNb-50/60的19位共同人员，原始时间Spearman相关约0.896；扣除楼外人员速度后约0.216。q9-02/13的19人由0.532变为−0.423。Uw-06/08仍由0.802保留约0.486。可见“同房时间很像”有相当一部分是相同的人在各处都快或都慢；不能把原始高相关直接解释为房间规律。

熟悉效应尚未控制充分：11个高共同支持图对中9个的可见记录创建顺序完全同向；相机视点本身与先后熟悉经常混杂。created_at也不是所有历史预览/首次暴露的完整记录。本轮不把残余相关解释成同房因果效应。

**时间差与几何差。** 在同图同条件内，比较校正后绝对log时间差与不依赖上下配对的OSPA几何差；按图计算Spearman而不是将数万作答对当独立样本。各条件图级相关的中位数接近零，例如P1 Manual约−0.077、C1 Manual约−0.033、P1 Semi约−0.028。这个描述不支持“耗时越接近，标法就越接近”的统一规律，也不能证明所有时间信息都无用。

尚未完成的是“几何前缀 vs 时间前缀 vs 二者组合，对后续未见几何分布的增量预测”。本轮证据不充分到可以跳过这一步，直接把时间加权进分簇。

### 9. 当前可落地的研究路线

建议保留最小组合：可信的原始/有效点、简单点集相似度、具体差异的位置记录。分簇作为展示和模式支持统计，成对相容和局部残差同时留存。不要现在先恢复全部物理墙、强制识别每个门框，或按角点间距学习自适应容差。

对于b8式已证实配对问题，旧配对衍生指标不能继续用作人员差异的充分证据。全量重分簇前先保留警报，优先采用无需该假设的比较；若以后修正配对器，另建版本、重算受影响距离与历史曲线，不能把新点/新距离拼入旧快照。

OSPA6值得作为下一轮简化工作基线，A0/A3及现有点数门对照保留；平均值掩盖局部偏移的例子必须作为固定反例。它不是最终胜出算法，更不是天然空间类型。需要标定的是“允许多大的落点变化以及哪些增减必须被区分”，不是每张图要被分成几个簇。

active time暂作为独立成本/行为输出。后续研究AABC时，同样4个独立人员的组合可以同时比较分歧和合格active time总和，得到是否用更多时间换取重复支持的描述；时间不能定义认真程度，也不能改变一个本来不同的标法是否同簇。该组合结果本轮没有新执行。

Bi保留为局部范围政策候选与模型覆盖侧证；用户的局部遗漏Range不自动映射为enclosed或extended。本轮没有新增Bi实验。

本轮不是宣称不确定性的最终故事已经完成，而是消除了一个实质测量混杂，找到更简单可检验的基线，并证明时间规律具有条件差异。下一步应检验干净测量下“少量人统一、少数重复模式稳定、实际观察内仍变化”，而不是要求算法自动制造这三种外形。
