> 我们的分簇 不一定要根据不同标注空间分簇(意思是bi layout 的多种标法),而是根据标注的差异本身来评判,比如某些人 把一些东西识别为墙角,有些忽略

## 交给Pro的开放任务

### 1. 明确对应，再比较局部差异

探索上下绑定与top/bottom分开两条路线，比较按x排序逐项对应与自由一一匹配。不是要求用某一条路线获胜。提出排序、近同x、上下角色、点对横坐标与全景接缝的可解释处理，给出实际对应点号。循环移位若使用，只能是保持环序的编号对齐，不等于任意旋转坐标来降低差异。

同有效点数在本次严格整图表达分组中是硬约束，不同点数仍可做局部差异诊断。相同点数可能是一处多一组、另一处少一组；原数组点号不能直接当作物理对应。上下角色未定、奇数点、已确认恢复及OOS分别报告，不自动修点。按图学习尺度暂缓；局部窗口、误差汇总与阈值不预先指定，由研究提出依据及失败场景。

先前六图程序允许自由最优匹配，尚未验证按序方案。如果两方案端点对应相同，又都取所有偏差最大值，最终分数必然相同；要解释实际的对应约束变化，而不是仅更换名称。IoU可以是全局覆盖对照，不要求它优先，也不预设它应删除。

### 2. 从成对差异到整图分区

分别验证距离和分组规则，检查簇内混入、簇间过拆、近邻关系不传递及完整链接直径约束。两份很近并不意味着各自整簇可合并。不同点数门带来的成功单列，不归功于局部语义。允许提出其他有依据的方法，但报告它们牺牲了什么，不只提交总命中率或一个冠军。

现有39图、12图、已审核六图和本次六图都属于接触过结果的开发材料。不得改称独立测试集；以固定规则留出图片/房间进行数值泛化检查时，要交代既往接触范围，未经人工审核的结果不称语义正确率。新研究不要只挑能支持猜想的图片。

### 3. 单人支持与人员诊断

对同图同条件比较人员的单人簇比例及跨方法稳定性，保留分母、实际参与图数与共同图片覆盖，避免将困难任务更多误认为人员更差。查看多人簇中的异常成员；单人簇并不能覆盖全部异常。连续差异与人工确认错误可作补充，不把多数作答当作绝对真值。

区分稳定表达倾向、定位/漏角等可见错误、解析问题和原因未知。不要从一次几何作答断言能力或故意捣乱。可核查已有合格active time，但短时不等于敷衍、长时不等于认真；其原先“同一个人在同房/相似视角用时是否接近”的问题继续保留，不混入几何距离。保持现有W019/W026历史口径并明确报告，不新增自动人员排除。

请讨论两人重复支持、单人差异与有限观察内稳定性的关系，保留单人响应占比及具体内容，不删尾部后宣称全体共识，也不因单人簇存在就断言永不收敛。不以剔除几何异常者后的一致性提升循环证明方法正确。
