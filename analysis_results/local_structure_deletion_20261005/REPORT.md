# 真实复杂环的局部删改：首轮操作账本

2026-10-05。按运行前写定的[试验计划](../../docs/thesis_main/空间候选构造_局部删改试验_20261005.md)执行。程序与生成过程不读取GT，不改变任何原答。

本轮保留5份完整原答，并枚举51个“删一对上下点”的候选，共56个对象。来源为rPc-06的R00020、R01518、R01557及uNb-67的R02928、R02929；它们是已确认、声明BEV有效但非单值的复杂环控制，不是已判错的标注。

## 实际结果

51个删除候选中，50个多边形有效，48个仍将相机严格包含在内；16个扩大原声明底面，34个缩小，1个非法多边形仍保留。3个候选转为单值可用，但本实验不以此作为选优条件。

| 来源 | 方向残差优先政策 | 0.05h路径预算政策 |
|---|---|---|
| R00020 | 原答 | 原答 |
| R01518 | 原答 | 原答 |
| R01557 | 删除源点对6 | 同一删除 |
| R02928 | 删除源点对3 | 原答 |
| R02929 | 原答 | 原答 |

源点对索引为输入的零基`source_pair_indices`，不是图片里的自然语言角点编号。0.01h预算下五份都保留原答；0.1h的选择与0.05h相同。全部并列结果按规则保留，当前所选均唯一。

两个值得后续叠加查看的案例：

- **R02928删除源点对3：**固定原来源方向框架的加权偏差从16.7855°降至13.8675°，但丢掉1.6861h²原声明范围，与原答IoU仅0.76814；底／顶路径到跨接的最大偏差分别1.08056h和1.08184h。低方向残差并不足以支持这次删除。这里比较的是原声明范围，不是已经认定的真实房间。
- **R01557删除源点对6：**方向偏差从2.4281°降至2.1283°，路径偏差分别0.04262h、0.04895h，能进入0.05h机制预算；同时底面外扩0.04903h²，与原答IoU为0.98720。预算通过不等于细节可删，需看门洞侧部的局部证据。

51条新跨接均未找到在同图完整名单中上下端点同时严格相同的原边，51个删后环也未与某份原答的完整点对编码严格相同。因此没有继承原来源的票数。**这不等于无人认可或没有图像依据**；严格相同编码／端点仅是一个有限来源核验，不是宽容物理对应。

这些结果把此前合成例的警示落到了真实声明环：删除可以扩大区域，降低残差可以同时大幅损失范围；加入局部路径预算能够拒绝某些大改动，但不能自动认证保留下来的细节。

## 没有完成的部分

本轮仍是每份既定环内部的单次删除，尚未把多人结构组成候选池，也未建立不同人员物理角点对应或新跨来源连接。不能称为用户完整“减法算法”已经完成。

“有据细节保护”政策明确返回`not_run_missing_local_evidence`。四图原图已初看，尚未逐原边给出可操作的保留／删除证据；本轮不将图像印象或GT优劣反推为保护标签。下一步先审核上述两个局部窗口与复杂范围替代，再比较有限相容重组；详见试验计划。h为相机高度单位，三个预算均非已校准人类容差。

## 字段合同

`results.json`采用`local_structure_deletion_pilot_v1`。`sources`保留来源、选择理由和固定来源方向；`candidates`保留每个原答／删除候选的完整点对、源索引、被替换原边与新跨接。新候选`voting_role=not_a_person_vote`且`ring_confirmed=false`；原答基线保留既有确认。

`polygon_valid`和`camera_inside`分开；非法多边形的面积及方向量为null，不当0。`added_area_h2`／`lost_area_h2`相对该候选自己的原答，不相对GT。`floor_path_to_shortcut_max_h`／`top_proxy_path_to_shortcut_max_h`是原两段直线到新线段的单向最大距离，不是双向误差；顶部使用既定地面深度的三维代理。

`exact_endpoint_edge_donors`为上下3D端点1e−9绝对容差内相同的原边供者；`exact_observed_encoding_ids`为循环起点／方向不敏感、像素1e−9容差内的完整点对编码匹配，不是语义兼容票数。`bridge_not_on_source_boundary_h`不加buffer，报告新底边与本来源原底边界精确不重合的长度，不能解释为无图像依据长度。

`direction_residual_deg`是在原来源固定方向下的边长加权偏差，不移动候选点。`policies`报告每个规则的全部并列候选；未冻结人群共识方法、正式质量总分或删除阈值。
