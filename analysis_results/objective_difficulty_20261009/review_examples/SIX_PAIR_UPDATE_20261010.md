# 6点对、无遮挡或较少遮挡：工作分类更新

2026-10-10。用户明确批准阅读图片，将类似的6点对低遮挡图纳入简单。最新工作结果为[259图工作表](working_classification_20261010.csv)；旧自动结构类完整保留，不冒称新的全自动结果。

## 执行规则

6点对不再自动等于中等。普通候选图在当前参考目标下，主要转折和连接明确，照片无遮挡或只有局部轻微遮挡时，可经逐图看图归为简单。局部轻微遮挡指家具／设施遮住部分底端，但角线上部和相邻墙边仍足以判断位置，不需要凭空推断整处隐藏转折。此为定性图像判断，不虚构遮挡百分比；“H=1”或“H/N较小”不自动等于较少遮挡。

本轮通过者均为GT结构H=0；这不是说H=0就必然简单。H>0如需降档，应先核清照片中的隐藏角点、GT目标及表示，不能只看房间主体显得简单。尚未完成这类核清者保留旧档，不新增一刀切阈值。门洞、OOS、暂停及参考待核独立，不能套用本轮降档。原4点对规则及8点对以上结构规则本轮未全量重审。

## 来源、合同与复建

`working_classification_20261010.csv`以image_id为主键、259唯一行，继承score_recheck.csv所有字段；新增working_difficulty_class为最新工作类，特殊／待定留空，空不等于0分；classification_basis为legacy_structure_proxy、codex_photo_review_20261010或separate_or_pending；visual_review_reason为本轮图像判断理由，未审者为空。existing_coarse_class、raw_structure_class和N/H保持原值，不能当最新工作类使用。六条simple裁决绑定image_id、gt_object_id、N/H和旧类别，参考变化时脚本停止，不静默复用。

视觉裁决是Codex按用户授权进行的图片判断，不是独立人员盲标、纯自动几何分类或客观难度真值。没有用人员误差、融合曲线或拟合旧难度标签决定新分数。旧评分不覆盖；范围差异记录继续保留，尤其b8-07和rPc-17的简单判断只适用于当前参考空间。

复建顺序：recheck_scores.py → apply_visual_review.py → build_gallery.py（均在本目录）。apply_visual_review.py断言259唯一行、39条裁决、6条实际降档、身份／参考／N/H匹配、特殊组不赋三档及原复核表字节未改。图像证据为six_pair_review_1至4.jpg及six_pair_accept_check_1至2.jpg；为分析交付图，不是临时屏幕截图。

本轮未改GT、原结构算法、原主表、人员评价、正式资格及融合规则；没有全量认证照片可见性。需要区分旧自动结构代理与最新包含人工辅助式看图判断的工作分类。
