## 使用与保存

默认导航只遍历待审，可切换已确认只读或原始GT只读对照。确认或报告配对问题后只保存状态，保留当前图；点击“下一份”才切换。配对留到顺序复核结束后统一处理。`B6ByNegPMKs-40`、`X7HyMhZNoso-05`不重复召回。旧41–44及其他候选的尚未确认来源按同一规则补齐，提示保留原图号。

显示周期最短弧平均x后的坐标，y不变；不可配对不回退原点排序。人工GT未确认时默认按共享x升序，已有确认优先，固定“对N”身份不变。标签按实际显隐、宽高、边缘、点和其他标签重排，移开时保留引线。

“导出全部记录”沿用v3审核格式，保留接收历史；默认排列不属于源绑定，调整默认值不会使旧确认失效。冲突记录拒绝覆盖。`received_orders.json`保留双人历史及配对评论的派生解释；原始GT历史确认不计本轮任务。本地存储绑定页面路径，转移机器前导出备份。

“导出已确认连接数组”输出`matterport_connection_order_v1`，依确认环序逐对交替上点、下点，`closed=true`表示末对连首对，保存原固定点对索引、源点索引/标签、对象ID、GT来源及预处理方法。GT版本身份沿用v3绑定的来源路径和完整点集，不另造版本号。`confirmed_layouts.json`是生成时63份确认快照，新增确认需从页面重新导出；可另导出当前已确认对象的`label_cor`文本副本。

[字段合同](field_contract.json)约束上述字段。`source_objects.json`是本轮来源副本；补充人工GT仅在复核层，不扩展正式研究样本。不改变原始标注、GT、冻结共享x源、清洗裁决或分析资格；未筛入不等于人工验收。
