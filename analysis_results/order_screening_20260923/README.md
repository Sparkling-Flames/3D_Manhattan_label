3D脚印直接取既有原始射线重建，不进行约束拟合。非相邻地面边相交、退化/相机可见性问题按已有`issues`与几何边检测列出；当前相机可见性异常45份。形状宽召回阈值为最大/最小角点半径比`>12`（90份）、最长/最短边长比`>20`（169份）、紧致度`4πA/P²<0.04`（本批0份）。43份原始脚印缺失/不可计算显式列为`raw_3d_missing`。这些值依赖相机高度为1的平地假设，不能直接当真实房间形状。41份现有配对不可用和4份借用补点单列点位/配对风险。

**零交叉不等于环序正确。** 现有墙带与多数配对环按x排列，单值包络可能掩盖凹形墙体自身遮挡造成的真实非方位角单调连接。二维投影的交叉或尖角也可能是合理遮挡/真实墙角；家具遮挡角点一般不自动要求换序。原点号先后和现配对环不同只作低优先点击线索，不赋予原点击顺序拓扑真值。
