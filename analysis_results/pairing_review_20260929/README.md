## 操作

1. 只修正有问题的点对：依次点击上点、下点，也可用固定点号按钮。新对象默认不预填配对。
2. 点“本图检查完成”后，未改动部分按你确认无问题记录。整图没问题可零改动直接完成，不必配完全部点。
3. 确认留在当前图，点击“下一份”才前进；可切换全部34份查看和修改。未审、草稿、暂缓不会自动认定无问题。
4. 奇数点不阻止完成本次检查。确有缺点、多点或无法判断时可备注后暂缓，不自动补删点。
5. 完成后点击“导出配对审核JSON”，把文件交回。不要只保留浏览器缓存。

显示平均x前的有效点，坐标只读。配对必须按[上点,下点]填写，要求上点y小于下点y；不会按地平线强行判断上下，允许局部空间上端点在中线下方。页面连线只代表上下对应，不显示墙连接环和3D。

保存使用独立schema `pairing_only_review_20260929_v1`与独立浏览器键。新记录review_mode=corrections_only，pairs仅为局部修正，允许空集合；checked及untouched_points=accepted_without_correction表示本图检查完成。order_confirmed固定false，配对集合不定义环序，也不能当成完整配对表。

保存前检查修正点号有效、每点最多出现一次、上点y小于下点y；不要求覆盖全部点。旧缓存/导出保留，旧paired仍按完整覆盖校验；旧记录再次编辑保留legacy_full_pairing语义，不自动当成错误点对。损坏绑定或冲突拒绝覆盖，保存失败保留编辑并支持导出草稿。
