## 研究定义

用户的Range不同包括同一物理空间的局部覆盖遗漏，不能编码成不同房间，也不能对应Bi enclosed/extended。当前用“标法及其分布”描述：覆盖/遗漏、角点和细节增减、对应及定位差异。小幅坐标误差可与成对共识并存。无需先裁定每种局部差异是不是另一个空间；不必扩大为新本体。正确性、成对相近、整簇相容和人数增加后的分布稳定分别判断。

## 结论与下一步

本轮做减法：标法而非天然空间簇；先避免有问题的上下配对；优先保留现成无配对OSPA及固定反例，而不是继续堆尺度规则。对应/局部残差仍需记录，不以少簇、少单人或曲线平选阈值。active time独立报告成本/行为，暂不加权进几何分簇。人员AABC及同房规律仍是后续核心；本轮没有新验证AABC效应、几何时间联合预测或人数收敛终点。Bi双头不替代用户涵盖局部遗漏的Range字段。
