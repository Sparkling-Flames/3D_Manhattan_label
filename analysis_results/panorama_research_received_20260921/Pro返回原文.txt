## 一、当前不稳定，确实受到测量方式影响，但不能把这种影响直接称为错误

本轮主体采用最新的 **240图、2,444份独立可算作答、25人、22栋建筑**。描述池仍保留241图、2,481份；没有将不满足某项几何计算条件的记录从研究叙事中删除，也没有重新打开已确认的独立性事项。

重新计算的19,196个作答对显示：

| 诊断                           |                实际结果 | 可以说明什么                  |
| ---------------------------- | ------------------: | ----------------------- |
| 有效点数不同，先被整图硬门分开              |       7,748对，40.36% | 点数门对完整表达区分有很大影响         |
| 同点数、整图距离超阈值，但只有一个上下绑定角对超阈值   | 1,654／3,879对，42.64% | 整图不同经常不意味着各局部都不同        |
| 同点数远距对，经循环移位或自由一一对应后跨入25.6像素 |     18／3,879对，0.46% | 确有对应敏感性，但这项探针不能解释大部分远距对 |

**40.36%不能解释为“算法制造了40.36%的不稳定”。** 不同点数可能来自遗漏、额外墙段、范围延伸、冗余细分或实际多种表达，本轮没有进行足以区分这些原因的全库语义裁决。

uNb-21的已确认对应是一个明确反例：W006／W013这对作答，在采用用户确认的跨作答对应后，最大距离从 **92.57降到14.44像素**。这个修正有来源，应当保留；但自由匹配降低距离本身，不足以证明墙面邻接仍然正确。

完整链接与真实代表半径也不是两个可以仅凭“谁更早稳定”择优的方法。相同距离下，完整链接分开了1,864个阈值内近邻对；代表半径分开的近邻对少得多，却把766个彼此超阈值的作答对放入同簇。前者要求簇内两两相近，后者要求接近某个真实代表，**两者测量合同不同**。不能将代表半径下的单簇直接称为全体两两一致。

相关明细见包内 `pair_diagnostics.csv.gz`、`measurement_summary.json` 和对应修正前后记录。

## 二、“局部已有稳定意见，整图组合仍变化”有实际实例，但不是全库结论

uNb-47共有22份独立可算作答，其中同为14个端点的子池有12人。本轮只在这个子池内比较固定对应的7个局部角对与完整表达。

从这12名已有真人中无放回观察8人后，下一份已有作答未被覆盖的概率为：

| 对象           |   有限池未覆盖概率 |
| ------------ | ---------: |
| 完整表达         | **55.56%** |
| 7个局部角对的平均值   |  **6.62%** |
| 最不容易被覆盖的局部角对 | **25.05%** |

进一步对同样12名真人进行实际顺序重放，确实出现了**若干局部满足持续稳定规则，而整图不满足**的情况。因此，你提出的局部研究方向不是只有概念上的可能性。

但需要限制结论：在72个可计算的同点数子池中，只有这一例达到本轮“平均局部未覆盖较低、整图未覆盖较高”的强反差界限；没有一个达到“所有局部都低未覆盖、整图仍高未覆盖”。子池外的10份不同点数作答也不能被忽略。

因此，更值得发展的不是简单把整图最大距离换成平均距离，而是：

**分别记录局部存在／缺失、局部连续位置、多种局部表达，以及墙面连接；同时保留每名真人实际画出的完整联合表达。**

不能把各局部多数意见拼成一个从未有人画过的“真人答案”，也不能把局部覆盖充分等同于局部份额已经稳定。

## 三、人员差异不能被当前类别充分概括；连续画像在较窄目标上有信号

本轮人员预测严格隔离目标建筑，使用其他建筑上的历史形成画像，评价188图、2,350份作答、25人、21栋建筑。

这里预测的是**一个人相对于同图其他人，更容易还是更不容易出现不同表达**，不是认真程度、正确率或绝对质量。

对严格整图几何分歧，本轮连续画像使预测均方误差降低约 **1.00%**，但条件建筑重采样区间跨零；按画像正负离散化反而变差。既有Q、QT、QTSB和三轴等六种配置，也没有显示稳健的正向改善。

**不过，不能因此一概否定人员画像。** 对较窄的“点数分歧”目标，连续画像的误差降低约 **6.99%**，条件区间为正；离散化的改善则不稳健。这提示人员倾向可能更容易在具体结构表达维度上重复出现，而不是概括成一个跨图片通用的整图分歧类别。它仍是探索性结果，不足以确定最终分类方案。

### 相同配比，换真人，仍然有很大波动

在固定图片和8人团队规模后：

* 使用历史Q二分，相同配比内部仍保留约 **94.7%** 的团队分歧方差。
* 使用历史QTSB三分，相同配比内部仍保留约 **84.3%** 的方差。

这是实际真人组合的方差分解，不是模拟出新作答。大量组合共享成员，没有把它们当成独立被试。

因此，**AABC这类配比不能替代具体成员信息**。类别也许能描述部分倾向，但当前不能据此可靠预测任意同配比团队的表现。

### 换顺序，改变的是发现路径，不是已经收集的答案

例如7y-12的23名真人，在完整链接、尾段3人的200种顺序中，只有 **26.5%** 的顺序出现观察内稳定起点。只在这些成功顺序内部看，中位起点是20人。

只报告“中位20人稳定”，会掩盖其余73.5%的顺序。因此本轮保留成功比例、未达标情况和条件起点分布，没有用成功顺序的中位数代替总体结论。200条重放顺序也不等于200批独立实验。

## 四、你的“同房视觉上有关联”判断，得到部分数据支持

本轮只使用既有空间审核关系，不根据本轮预测成败重新挑选“相似图”。将“物理同房”与“物理同房且已有可比确认”分开后，结果如下。

### q9-02／13不能作为否定一切同房关系的反例

两图使用完全相同的23名真人时，U(8)分别为0和0.8667，差异确实很大。

但是，原人工台账G145**此前已经记录主视觉空间不同、范围存在明显差异**。这不是本轮看到失败后追加的解释。因此，它反驳的是“物理同房就足够预测”，不是“同房且主空间／范围可比时存在关联”。

对127个重叠视角对进行完全相同真人匹配后，平均视角差异只从0.2475降到0.2402。这说明人员不匹配不能解释这些视角差异的全部，也不能只靠统一人员配比解决范围问题。

### 持续起点人数，目前还不能可靠迁移

完整链接、尾段3人的宽口径同房分析中，64张目标图里，**没有源、目标两端都获得可识别起点的预测配对**。代表半径只有3张目标两端可判，且来自同一栋建筑。

因此，现在可以继续研究同房的分歧程度和表达覆盖关联，但不能把它写成“已经能够预测同房需要多少人稳定”。本轮没有删除未知目标后只在成功案例上计算漂亮的预测误差。

## 五、持续稳定的定义，正在实质改变结论

固定同一组110张至少8人的图片、变化门槛0.1、不设簇数和单人占比上限，仅改变尾段要求：

| 方法     | 尾段2人：起点可识别 | 尾段3人：起点可识别 | 尾段5人：起点可识别 |
| ------ | ---------: | ---------: | ---------: |
| 完整链接   |     36／110 |     20／110 |     14／110 |
| 真实代表半径 |     56／110 |     35／110 |     28／110 |

这说明稳定图数量对尾段和分区合同敏感。

但也不能说“不成功的全部只是未知”。例如尾段3人的完整链接结果，除了20张可识别，另有86张在该规则下未达标、4张仅有可能起点。**观察不足、重复支持不足导致不可判、观察内确实未达标，需要分别保留。**

还有一个重要的数学限制：固定分箱后，一次增加一份作答的份额变化上限是 \(1/(n+1)\)。因此人数增加到一定程度，一步变化自然变小。仅凭相邻曲线变平认定稳定，会部分测量“分母变大”，而不是发现新的经验规律。

本轮没有以更早起点挑选最终方法。建议把研究终点分开报告：当前一致程度、稳定多种表达、少数表达覆盖、局部定位波动、分区变化和观察内持续性，而不是要求一个“收敛人数”同时承担所有含义。

## 六、两条值得保留的进一步研究线索

### 模型结构特征比当前人员配比显示了更明确的增量

在同一64图、15栋建筑的U(8)评价面板，整栋建筑留出：

| 输入           |    平均绝对误差 |
| ------------ | --------: |
| 只用实际观察人数N    |     0.208 |
| N＋人员配比       |    约0.211 |
| N＋模型角数       | **0.129** |
| N＋模型角数与模型间差异 | **0.130** |

这值得进一步验证，但预测对象仍是有限历史池的U(8)，不是普遍收敛人数。本轮使用冻结模型特征，没有从网络权重重新生成全部特征，也未完成预训练数据暴露审计。因此不能把它称为完全外部验证或新人预测成功。

### 3D机制必须与具体实现对应，不能统一解释成像素距离

本轮检查了Studio原始射线／配对距离代理、旧`vis_3d.html`投影，以及更早的圆柱示意预览；它们不是同一种几何机制。

在原始代理中，bottom y决定地面交点距离，top端点再借用配对bottom的距离。因此，错误上下配对不仅影响局部2D距离，也可能改变top的3D位置；墙连接顺序则决定生成哪些墙面。

实际12,781个角对的±1像素机制探针中，bottom y的3D敏感度在约99.79%的有效角对上高于top y。但这个结果受具体投影和位移定义约束，**不能据此直接给二维距离增加统一bottom权重**。

另对46份按哈希选取的真实作答执行规整化拟合，39份成功、7份被阻止。成功也不代表正确；规整化本来就会压低部分差异。本轮同时保留原始输入、拟合结果、失败原因和残差，并实际执行旧JS投影函数核对，但没有冒称完成全库3D视觉验收。
