## 复算

在交付包的**新副本**中操作。复算会写该副本的`results/`、`logs/`和`figures/`，不写GitHub，不改原ZIP。安装Python依赖以及Node.js后，在本目录运行：

```bash
python -m pip install -r requirements.txt
python code/run_all.py --fresh --jobs 4
```

默认自动校验并解压`source_snapshot.zip`到`source_work/`。已有同版本解压目录时：

```bash
python code/run_all.py --source-root /path/to/unpacked_handoff --fresh --jobs 4
```

不加`--fresh`时，次序重放可复用源哈希、算法版本、种子一致的逐图缓存；其他分析仍执行。重绘图：

```bash
python code/run_all.py --plots-only
```

每步有独立日志，非预期错误立即停止，不能把部分输出解释为完整成功。不要把旧分支结果换个路径直接混用。本包固定种子20260921，实际200条25人全局无放回顺序，按每图可用人员投影；它们不是200批新被试。组合数较小时穷举，否则每图片×人数抽2000个唯一真人组合，不复制人员。
