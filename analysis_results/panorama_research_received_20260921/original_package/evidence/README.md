# 证据使用说明

`source_text/`是原源包中的逐字副本；`SOURCE_INDEX.json`记录来源路径、大小与SHA256。两份SOP、导师原文与归属纠正文档并列保存，较旧文字不覆盖最新用户要求。源HANDOFF_MANIFEST及DELIVERY_CHECK只是源交付记录，不替代本轮独立复算。

完整原始审核、有效点、模型特征与其他分析输入均在`../source_snapshot.zip`中保持原样；新距离和新结果在`../results/`。两份概念Library材料只记录阅读来源，不伪称其字节已复制入包。报告第12节另附核实过的原始论文完整书目及官方／作者全文入口。

未来首次补采表检查历史暴露只为避免把重复暴露称作首次；不重开已有本批独立作答确认。人工语义候选表须先回查原审核相同案例，有既定结论则沿用。
