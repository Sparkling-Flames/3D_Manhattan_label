# 2026-10-25 同图大块换类：13包独立审查

**主要计算和研究用途通过独立复核。本轮确实补强了“同一图片、相同背景与换人数下，跨类变化往往大于同类换人”的证据，可以保留四个明确条件。** 不要求所有图片或每名成员都成立；平均幅度、支持图/楼和具体机制同时报告。新条件不撤销旧结构、效率、混合配比和同房成果。

底层真人v2，新增效果域为普通Manual；Semi历史参与部分建类，本轮没有新增Semi替换实验。审查不改正式评分、参考、资格、OOS、标签或融合合同。作者报告与本审查分别保存，未用作者的新主报告覆盖本地现有主文。

## 2. 分类依据确实可复现，但四种用途不能混称

- **DSTRUCT**：Manual整体/困难结构、困难−简单响应，包括非冗余转折、短边、近共线冗余及参考角未对应比例；没有以Q/T建类，但也不是完全不使用参考的纯风格。ALL为8/39/12人、3人未知；困难时更多非冗余转折的12人是旧较多转折类的一个子集，整个分区不是旧三类的纯细分。
- **联合scope**：Manual困难响应、Semi最终结构/边界及普通图片scope回答残差。目标楼在两条件和scope中同步剔除。它确实实现了联合历史建类，并在普通Manual上验证了具体用途。**本轮没有加入错误初始化未改、识错/纠错等“盲信”行为特征。** scope表示回答倾向，不是范围判断正确率。
- **反推类**：由自然随机团队历史估计的人员融合响应角色。几何家族不以Q域聚类，联合家族增加Q响应。它描述当前算法、成员池和混合背景中的重复关系，不是脱离融合算法的纯个人属性，也不是每个人独立的因果贡献。
- 原答证据也成立：DSTRUCT_K3在困难图上，同/跨类非冗余转折差1.711/2.732，29/31图支持；固定原答点数后，上下界角距离仍有24/30图支持类间较大。类别不只靠后续团队Q被解释。

## 3. 新增价值和保留边界

1. **自身有区分，不等于全面超过旧类。** DSTRUCT与旧结构共同38图的额外gap为+0.973，21/38图、5/10楼支持。反推K3相对K2共同20图额外+0.604，13/20图、6/9楼支持。两项均匹配图、n/m和角色，实际D/XYZ并不相同。
2. **联合方案有用，不等于scope单域的增量已证明。** 确认扩展没有相应不含scope的MSDGEOM嵌套对照；无需因此取消联合分类，只在欲主张scope独立贡献时另做同支持比较。
3. **Q与定位区分最清楚，不能推广为所有形状分项。** 四条件BEV距离gap正图依次只有19/40、16/29、12/21、31/49。D10同/跨幅度也保持所选条件的分离，但没有重新用D10训练这些新类。
4. **类别块作用不限于某一个人。** 原7人块完整7选6：保留楼DSTRUCT的68/82锚点、scope的44/49锚点，删去任意一名目标成员后七种C−B均为正。这个结果针对两套前向类，不能移植成反推四人/七人核心也做过相同留一。
5. **人数增加不单调。** 固定XYZ的严格路径覆盖n10至实际上限n21；DSTRUCT固定容量队列在n21仍为同/跨2.846/5.987，44/57图、18/20楼支持。随后n28为直接AC，能观察大背景下类别块的作用，但没有B，不能冒充n28同类/跨类对照。
6. **劳动代价真实存在。** 四条件C−B记录时间分别约+5.94%、+10.86%、+2.67%、+4.39%，各有自己的时间支持域。历史类中心“相对更快”不保证目标图实际节时。时间也不是本轮新测生产工期。
7. **最终条件是内部比较后选出的工作条件。** 标签在目标楼外形成已核验，但具体方案、方向与n/m包括查看扩展表后的选择。可报告实测多数规律，不把整轮v2材料称全新外部盲测，也不预先假设未知人员或其它算法具有同样效应。
