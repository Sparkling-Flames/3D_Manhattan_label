## 2. 分类究竟依据什么

- **DSTRUCT** 使用 Manual 的整体/困难结构、困难−简单响应，包括非冗余转折、短边、近共线冗余及与参考角的对应。没有把Q或时间作为输入，但并非完全无参考的纯视觉风格：参考未对应比例本身是一个输入。
- **MSDGEOM_SCOPE** 使用 Manual 困难结构/边界、Semi 最终结构/边界，加上普通图 scope 回答残差和困难−简单回答差。五个域等权；目标楼在两种条件及scope历史中同步剔除。
- **本轮没有把“已知错误初始化未改、纠错响应”等所谓盲信特征输入分类。** Semi参与的是最终几何表达。不能把这一轮称为已经完成盲信联合分类验证。
- scope 域是同图片×条件×来源内的接受/拒绝回答倾向。它不使用scope正确率，也未把OOS和门洞的拒绝率混入主域。后两类仍在机会表分层保存。
- **RFUSE_GEOM / RFUSE_GEOMQ** 学习的是自然随机团队中成员参与与融合结构、边界/尺度，以及联合家族中的Q响应之间的关系。几何家族不以Q域聚类；两个家族都用共同完整响应团队，失败在库存中保留，未被填为Q=0。

## 3. 已独立确认的标法区分

普通Manual困难图，DSTRUCT_K2的非冗余转折类内/跨类原答差为 **1.5686/3.0496**，31/31图、15/15楼跨类更大。固定两份原答角点数量后，顶界距离 **2.2428°/3.3028°**，24/28图支持；底界距离 **2.6478°/3.4488°**，24/28图支持。

DSTRUCT_K3同样有多数规律：困难转折差1.7114/2.7323，29/31图支持；同点数顶界2.3222°/2.9870°、底界2.7081°/3.3650°，各24/30图支持。MSDGEOM_SCOPE_K4对应转折差1.6894/2.5911，29/31图支持。

这些证据支持“类别区分实际表达与定位”，不是只凭后续融合Q挑出类别；它们不自动等价于每个新增转折都正确。

## 4. 联合 scope 的采用与独立增量是两件事

可以保留 **MSDGEOM_SCOPE_K4 n20/m6，较高历史Q/较慢/更多转折方向** 的已算用途。报告的选择保留楼中，49图的同/跨幅度4.611/7.246、40图gap为正，是该联合方案的具体条件结果；同楼新图也有相同方向。

不能据此宣布“增加scope使分类更好”：确认扩展的10个方法中没有不含scope的MSDGEOM嵌套对照；现有最终共同支持比较主要对旧V3分类，不能单独隔离scope的作用。加入scope还会改变整个人员分区——ALL K4加前/加后ARI约0.415；不是给同一固定类仅加一个可解释标签。

scope20/6这个具体语义方向在screen为7.080/6.529，平均gap为负，虽然13/20图为正；后续更广支持才出现清楚正差。该差异值得保留，不能声称所有阶段都独立同向确认。**这不妨碍采用联合方案；若未来要主张scope自身的增量价值，才需要同支持嵌套比较。** 当前无需因此重开大实验。

## 5. 反推类的准确解释

建议称 **“由自然随机团队历史估计的人员融合响应角色”**。它描述在当前人员池、既定融合算法与随机混合背景下，某些成员参与变化和团队输出变化之间的重复关联。

它不是纯个人标法、不是某个人单独进入必然改变多少分、不是不依赖融合算法的能力因果效应，也不意味着同一角色成员可普遍互换。小核心类只有4或7人并不使其用途无效：整块进入与不同来源/背景的复现有实际价值，但不能把固定核心在多图重复当成已经换过许多独立核心人员。

自然混合团队的内部预测相对零响应基线改善约0.1%/0.7%，这说明本轮反推类不适合宣传为强精确预测器；它仍能提出可检验的极端构成与大块替换角色，实际ABC结果另行验证。

## 6. 选型与报告身份

目标楼在前向历史和反推嵌套lambda/拟合/聚类中均被排除，本次复算未发现直接目标楼标签泄漏。原始候选K2/K3/K4及反推K2/K3全部保存，未用目标融合Q直接反复重建标签。

但**标签楼外形成**与**最终挑选方法、语义方向和n/m**不是同一个独立性保证。后者有从确认表中发现的补充条件，交付 `FINAL_CONDITIONS_README` 已承认此点。因此四个最终推荐应称“完整有限比较中得到并有跨图/跨楼支持的工作条件”，不宜统一称为四个事先锁定后通过全新盲测的规则。

复杂方案没有必要在所有用途超过旧结构类或Q二分才可采用。应并列报告实际标法、严格同图差异、时间代价与具体适用容量，保留强透明基线。
