# 从真实随机混合团队的融合响应反推人员类别

本目录是本轮新增的反推路线。读取 main 提交 `972857b2b3f548316be215400e42d6ef6e639250`，底层仍为真人 **v2**。

这里学习的对象是：在同一图片、相同人数下，随机进入团队的实际成员变化，与**真实融合输出的结构、几何和质量变化**有怎样的关系。它不同于前面的原答特征分类，也不同于旧的单人/m2 替换关系学习。本轮已有分类全部保留，与本路线竞争比较。

## 2. 反推模型怎样工作

对某一图片、某一人数 n，以成员份额向量表示团队：进入者为 `1/n`，未进入者为 0。把成员份额和输出分别减去该图片×n 的自然混合均值，学习团队内变化。

拟合使用多输出 ridge：每栋楼等权，楼内图片等权，图片内所选人数等权，同图同 n 内按实际自然顺序次数赋权。这样大楼、长路径或重复终点不会自然取得更大权重。

输出分三域：

- **结构**：融合底面非冗余转折、短边、近共线冗余节点。
- **上下界与尺度**：底界/顶界 ERP 均值位置、底面积对数、高度对数。
- **质量**：冻结 B8L2、D10、底面 IoU、3D IoU及边界/方向/高度损失。

分别拟合全部、简单、困难图的人员响应系数；建类使用总体响应、困难响应和困难−简单响应。几何/结构家族不把 Q 域用于聚类；联合家族把 Q 作为独立域。各域做稳健缩放、两维主成分与等权归一化，避免字段多的域重复加权，再以同一 Ward 树切 K2/K3。

这里的人员系数是**随机混合背景下的融合响应估计**，不是个人原答 Q，也不是该人单独进入团队后必然变化多少。它提供候选人员角色，实际大块替换仍接受严格 ABC 检验。

## 3. 楼外形成标签及有限调参

每一个目标建筑的全部训练团队都被移除。lambda 候选仅 **0.1、1、10**，在剩余建筑上再做内部留楼预测，按结构/几何/质量域及难度平衡的响应误差选择。目标建筑不参与 lambda 选择、人员响应拟合、降维或聚类。

ALL 名单只描述当前总体，不能拿它代替目标楼的标签。K2/K3 均保留，没有借目标 ABC 效果决定 K。当前 v2 已被多轮使用，因此本轮属于内部楼外研究，不称外部盲测。

支持要求为：总体至少8图/3楼，简单至少5图/2楼，困难至少3图/2楼。W019/W026 无本轮正式团队历史，W022 不足，均未知；缺支持不作为零响应人员。

- **RFUSE_GEOM 的4人类：W109、W112、W126、W130。** 拟合中心表现为较多融合转折、底界向下/顶界向上的响应。

K3 的大类块允许新的较大规模比较；4人/7人类则按真实容量保留有支持的方向，不因人数少就取消。精确人数边界见 `REVERSE_STRICT_CAPACITY_BY_IMAGE_N.csv.gz`。可行性不是已计算事件，更不是穷尽成员集合的声明。

## 5. 训练侧检查支持什么

ALL 的内部选型结果：

|家族|选择的lambda|相对真实零响应基线的平均残差MSE|
|---|---:|---:|
|RFUSE_GEOM|10|约0.999|
|RFUSE_GEOMQ|1|约0.993|

自然随机混合通常覆盖人员构成的中部；这里总体预测改善不大，不能把它写成分类已带来大块替换收益。它也不能提前回答偏向某一类型的大块构成是否分离，因此四种标签继续进入同背景、同 n/m 的实际 ABC。所选 lambda、全部候选误差、零响应基线与分项均保存，没有只保留改善的字段。

零响应基线按每个内部留楼的实际响应方差计算，不假定归一化后等于1。相对于训练建筑方差的原始 MSE 可能大于1，不能误读为所有模型必然劣于零响应。

ALL 对22个楼外折的平均成员 ARI：几何 K2约0.970、K3约0.674；几何＋Q K2约0.889、K3约0.462。粗类成员较稳定，细类更依赖历史支持；这作为描述，不设成取消实验的门槛。

## 7. 复现

依次运行：

1. `code/prepare_natural_training.py`：从已保存的 population 包抽取自然随机普通 Manual 前缀与实际端点。
2. `code/learn_natural_fusion_roles.py`：内部选 lambda、形成 ALL/LOBO 响应与4方法标签，每个建筑完成即保存。
3. `code/describe_reverse_roles.py`：当前容量、分项检查、旧类对应和文件清单。

`code/complete_zero_baseline.py` 是本次补齐零响应基线的呈现脚本，只补评估分母，不改标签；最新主拟合脚本已内置同一正确基线。所有方法都沿用既定 GT、v2 资格、评分、环序和融合参数。本目录不产生替代质量算法或新融合门槛。
