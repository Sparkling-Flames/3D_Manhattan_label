## 分包与关联

- **04A1**：前向扩展与7选6的完整逐事件指标、精确ABC/DXYZ、请求、楼外标签、覆盖与完成记录。
- **04A2**：反推四方案探索和扩展的完整逐事件指标、精确成员与相应楼外标签。
- **04B**：上述四实验202,694个去重端点的全部标量、成员与失败状态。
- **04C**：同一批端点的必要几何与节点票数，使用team_key连接，不把每个事件的几何重复存三遍。

每条事件的event_id、pool_id和A/B/C_team_key可以直接定位端点。D、X、Y、Z及成员名单在EVENTS_EXACT中；实际换人数与类别人数向量同时保留。

所有阶段使用相同的正式v2参考、资格、环序、B8L2/D10与融合门槛。效果按Manual普通图片评价；难度沿用现有标签。前向分类使用Manual或Manual+Semi历史，反推使用历史Manual真实团队；没有将Manual与Semi原答合成一支评价队伍。
