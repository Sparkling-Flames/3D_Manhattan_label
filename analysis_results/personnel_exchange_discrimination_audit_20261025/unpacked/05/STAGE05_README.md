# 阶段05：固定成员块的人数路径与大团队换类

本阶段已完成两项有实际结果的规模实验，标签、X/Y/Z块及背景进入顺序均在计算前登记。

## 严格ABC人数路径

286条固定X7/Y7/Z7路径，n覆盖各图全部可行整数10…N−14，实际至21；共3,264事件、9,792个去重端点，其中8,934个本轮补算。每步给A/B/C加入同一个真实背景成员，m恒为7。

主要结果及全部分项见 `analysis/size_paths/FINDINGS.md`。固定n21容量队列，DSTRUCT_K3在n21同/跨Q幅度为2.846/5.987；本轮选型保留建筑子域为2.897/6.523。它提供同类/跨类区分证据，不能与下面直接AC混算。

## 大团队直接AC尾段

在严格路径的末端，原同类块Y7逐人进入A/C的共同背景，X7/Z7固定，m仍为7。共2,288事件、90图22楼、4,392个去重端点，3,820个本轮补算。n实际到28。

固定N35队列，DSTRUCT_K3 n28/m7在选型保留建筑中，C−A平均+4.016分，25/26图、9/10楼正向；52个登记事件没有C失败或相对A损失超过10分。全部阶段仍有负向和明显损失结果，完整保留。

**n28只有A/C，不存在可比B。** 本段证明大共同背景中7人类别块的定向作用，不冒充n28同类/跨类幅度差。完整结果见 `analysis/large_team_ac_tail/FINDINGS.md`。
