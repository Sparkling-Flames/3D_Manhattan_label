## 采用判断

重点条件为：困难结构历史三类的 **n18/m7**，真实团队几何反推二类的 **n12/m4**，团队几何与质量响应反推三类的 **n20/m6**，Manual／Semi／scope历史联合四类的 **n20/m6**。这些条件在各自实际容量范围内，跨类Q幅度约为同类的 **1.57—3.09倍**；共同20图上的反推三类幅度比仍约 **2.06**。完整支持、方向和反例见主报告。

不要求每类都人数相当：反推小类只有4或7人，恰好可用于有容量图片上的整块替换。最有价值的新结果是难度条件下可重复的标法差异，以及特定角色、规模、背景下的融合变化。质量改善多数伴随记录时间增加，不能包装成普遍省时。

严格ABC为 `A=D+X、B=D+Y、C=D+Z`，D/X/Y/Z两两不重叠。主幅度对照是 `|B−A|` 和 `(|C−A|+|C−B|)/2`；有符号BA、CA、CB分别报告。n28/m7是直接AC大队伍扩展，**没有同类B对照**，不混入严格ABC幅度结论。
