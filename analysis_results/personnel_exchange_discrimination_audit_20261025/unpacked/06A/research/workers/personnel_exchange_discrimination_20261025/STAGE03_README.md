## 设计与比较口径

严格ABC使用A=D+X、B=D+Y、C=D+Z，D/X/Y/Z四块互不重叠，X/Y同源类，Z目标类，三个替换块大小均为实际m。保留全部成员与类人数向量。

“同类幅度”是|B−A|；对称“跨类幅度”是(|C−A|+|C−B|)/2。另单独保存有符号BA、CA、CB，不能把幅度更大解释成质量更好。

本包完整保存的是登记的有限实验面板，不声称穷尽所有人员集合和进入顺序。小空间的目标7选6已全部枚举；更大空间保存实际抽取方法、精确容量、未覆盖数量及成员。
