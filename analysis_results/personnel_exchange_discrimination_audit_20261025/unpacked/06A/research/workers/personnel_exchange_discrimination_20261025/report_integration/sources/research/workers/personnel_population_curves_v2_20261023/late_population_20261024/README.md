## 固定比较什么

原始自然顺序已覆盖每图1到实际满员；此前主图仅展示到20人。本次补齐呈现和比较，未补造实验端点。普通Manual共177图，实际人数6—35；其中157图至少30人、92图为35人。每个普通Manual图片池保存24条自然顺序；k≥1共137,256条前缀，形成5,719个图片×人数统计行（其中k≥3仍为128,760条、5,365行）。

|固定范围|简单|中等|困难|总图数|曲线范围|各图满员人数|
|---|---:|---:|---:|---:|---|---|
|N≥20（旧范围，保留核对）|110|29|29|168|1、2空档、3—20|20—35|
|N≥30（当前主图）|105|25|27|157|1、2空档、3—30|30—35|
|N=35（后段补充）|71|13|8|92|1、2空档、3—35|35|

N是冻结实验中该图实际可用人员池容量（不是原始库存标注总数），k是当前参与融合人数。按容量选图，不按质量选图；每条曲线的候选图片集合固定。N≥30和N=35是重叠范围，不能当成两份独立验证，也不能把两个范围的均值直接相减解释成加人效果。满员单列为`stage=full`，其实际k逐图保留，不伪装成统一的第36人。

### 固定157图，低人数变化与后段同样重要

以下Q为每图在各人数处的可评分路径均值，再按同图变化汇总；严格共同路径Q同时保存在`paired_Q`。这些157图与后文20→30使用相同候选范围。

|---|---:|---:|---|---:|---|

|6→10|+1.728|139/157|0.07908→0.06018|155/157|2.999%→1.194%|
|10→20|+1.429|135/157|0.06018→0.03652|155/157|1.194%→0.929%|

**早段的质量增益更明显，后段仍持续减少成员波动。** 简单／中等／困难图3→6的ΔQ分别为+4.029／+7.582／+7.457，支持104/105、24/25、27/27图。困难图6→10平均−0.891（14/27图提高），10→20平均−0.248（14/27图提高），但对应V减少分别为25/27、26/27图。前段Q上升不保证失败率同步下降：困难图3→6不可评分率6.944%→12.654%。这与旧168图范围中的29张困难图结论相容，但支持范围不同，不把27与29混用。

单人点表示自然顺序中首位人员的原答基线；不同路径可能重复同一人，按原保存顺序权重汇总。2人点沿原合同暂停排序：Q/V缺失、`policy_deferred=1`、`unavailable=1`；非政策性失败标记虽为0，也不能解释为2人全部成功。主共识曲线从3人开始，不能跨2人空档画连续线。

### 固定157图，从30人到各图实际满员

满员实际30—35人；10张原本N=30的图也保留（因此差值可为0），不只选择还能增人的图。质量共同可评156图平均+0.294，98图提高、48图下降、10图不变。简单+0.042、中等+0.929、困难26个共同可评图+0.698。全157图失败率0.531%→0.637%，满员1/157图失败；困难层为1/27。

每图满员时24条顺序都使用同一支团队，并不是24支独立满员团队。有效满员输出的SD、V归零，P10等于自身Q；唯一无有效输出的满员图保持Q/SD/V缺失，失败为1。**满员零成员波动是有限人员池的设计结果，不表示误差消失。** 接近满员时可变成员减少也会压缩波动；这里描述实际有限池，不宣称发现普适最优人数或无需GT的停标规则。

## 文件与字段合同

- `POOL_INVENTORY.csv`：177个普通Manual图片池及原始难度、建筑、容量。
- `IMAGE_CURVES.csv.gz`：177图各自k=1到N的逐图统计；`attempts`为保存路径数（含政策暂停），`unique_teams`为同图同k实际不同成员队数；重复顺序保留原抽样权重。`policy_deferred`为图内政策暂停比例。
- `COHORT_IMAGES.csv`：三个固定范围的精确图片清单；范围间有重叠。
- `CURVE_SUMMARY.csv`：范围×难度×人数/满员；`images`为候选图片数，各`*_images`为该指标实际有效图片数；`*_building_equal`为先楼内图等权、再楼等权，主展示采用图等权。`actual_n_min/max`显示满员实际人数。`policy_deferred`为图等权暂停比例，2人处为1，其余已计算阶段为0。
- `LATE_IMAGE_CHANGES.csv`：范围×图片×前后人数。`Q_delta`为两端各自可评分路径均值之差，`paired_Q_delta`为相同路径两端共同可评差；`paired_Q_paths/recovered_paths/lost_paths/both_unscorable_paths`共同覆盖`attempted_paths`。全员相同队的重复路径不作为独立样本推断。
- `LATE_COMPARISONS.csv`：逐图变化按难度/全部汇总；`common_images`为该指标两端均存在的图片数，`cohort_images`始终保留完整固定范围。保存均值、中位数、正/负/零图片数和建筑等权变化。`from_mean/to_mean`使用相同有效图片；不是从另一个曲线范围取值。
- `VALIDATION.json`：本次读取、范围、旧结果核对和不新增实验的记录。

Q为保存的B8L2，D10同时保留在数据表。P10为图内可评路径Q的线性10%分位；SD为样本标准差（ddof=1）；V复用既有几何表的有效路径底面两两`1−IoU`均值，合法同队重复对应0。Q、几何与失败分母独立保留。`failure`是保存的非政策性不可评分标记，`unavailable`是Q缺失比例；k2政策延期作为明确空档保留，不伪装为失败或成功。失败不填Q=0，缺失V不填0。比例及比例差原字段为0—1；展示乘100，比例差的单位为百分点。

本次无新增显著性或置信区间结论；旧k≤20重抽区间不外推到30/35人。正/负图片数以1e-9作为数值零容差，仅避免浮点舍入，不筛选结果。
