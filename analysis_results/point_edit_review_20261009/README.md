## 最短操作

打开 <http://127.0.0.1:8769/> 后刷新现有页面。右侧固定显示**外部审核人的原始结论、完整备注及原点映射**；下面的“我的复核”显示用户自己的状态。外部建议保持只读，完成本条也不会自动应用其建议。

- 补点：选记录 → “＋ 补点” → 在原图目标位置单击一次。自动保存并退出补点模式；继续补点再点按钮。
- 删点：“删点” → 单击原点 → “删除所选点”。挪点：“移动点” → 按住原点拖动。稳定原p号保留，新增点使用独立ID。
- 排序：点“角点排序”时，若新草稿尚未修改，工作台按既有周期x规则生成**可撤销的候选上下点对**，立即显示可拖动卡片。拖动整组卡片调整连接顺序；橙色位置1、2…及相邻虚线随顺序改变，p号和坐标不变。候选配对需人工核对，不能当作已确认环。
- 原始109份中，94份点数和坐标允许直接生成x配对候选；14份为奇数点，另1份含越界点。不能生成候选时显示所有未配对点及原因；待审的非OOS问题可据原图补点、删点或修正坐标，再点“按x配对剩余点”；需要改配对时可手工解除并重新配对。OOS且至少8点不因奇数点本身强制修点，实际无法构成3D则保留并记为无法计算。至少两组可排序，全部有效点配对后才预览首尾闭合。
- “撤销上一步”撤销最近点操作或排序并保留轨迹；“取消当前操作”/Esc只退出鼠标或拖动模式，不撤回已保存修改。
- 编辑自动保存。“完成本条”标记自己的复核完成，“完成并下一条”随后跳到下一份；**无需勾选确认，无需填写理由**。备注选填；不确定时点“稍后再看”。这些状态只属于独立审核返回，未应用正式数据或恢复资格。
- 原始、历史、当前、草稿可继续在来源下拉框对照。已有草稿会沿用；只有实际点版本不同才让用户选择，历史删除不会被默默恢复。四份历史记录可以选“按历史生效版本开始（保留删除结果）”。
