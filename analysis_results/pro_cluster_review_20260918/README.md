# 从研究对象出发：真人标注不确定性与分簇探索

## 先读用户想研究什么

**随着真实人数和人员构成变化，标注分布在哪些方面趋于稳定、哪些差异仍在出现，以及这些现象与图片条件和人员行为有什么联系。**

用户强调：OOS、范围不唯一、漏标、多标、定位偏差以及不够认真准确的实际作答都有研究价值。审核中的“只接受某种情况”表示他认为更接近正确标注的规范偏好，不表示其他作答应被排除。正确性可以解释分歧，但不是研究价值的门槛；稳定的分布也可能含反复出现的错误。

导师书面交流谈到量化噪声量和标注质量上限、整体分歧分布及少数结构解释、不同场景的瓶颈，以及认真/粗心人员的独立结果组合。相关逐字引语与用户最新四点说明、点数约束补充见[原话记录](研究对象澄清_用户原话.json)。不确定的语音回忆不升级为确定要求。

“不同点数分簇”原先针对的是完整标注结果，不是空间身份。用户最新明确“也可以进行讨论，现在先不定死”。保留其“点数不同可能反映不同理解”的想法，同时研究多标、漏标、误点及表达粒度等其他解释。旧方法仍按点数强制分开，这只是历史实现，不是新研究的硬约束。

## 可探索的方向，不限定方法

可以重新讨论表示、距离、尺度、阈值、分层、聚类或不依赖离散簇的分析。以下是问题线索，不是必选算法、固定步骤或穷举清单：

- **大致范围、结构表达和局部定位怎样区分或共同描述？** 进入门后与停在门前；同一大致范围里加门框/柜体、漏凸起转折；选了相近边界但落点不同。这些可能混合出现，不要求互斥分类。点数相同未必同结构，点数不同未必不同大致范围。
- **是否需要图片级或局部尺度适应？** 用户特别指出B6ByNegPMKs-22角点很近；同样的坐标差在不同角间距下可能含义不同。可以考察相邻间距、角度、局部相对偏移或其他表示，同时检查归一化是否放大拥挤处的定位波动。全景周期接缝、对应关系、上下点x不对齐也可能影响判断。用户没有指定窗口、公式或阈值。
- **哪些差异是反复出现的个人表达，哪些与图像条件有关？** 用户多次指出W037增加门框/细节；这是跨图行为线索，不预先断言一种固定人格或所有情况下都如此。单次偏差不能单独证明不认真。
- **OOS与信息缺失下的标注分布怎样变化？** 保留台阶前截止、层差、弧形墙或不可见区域等争点。OOS是适用性/表示条件，不自动等于无法研究或永远不收敛。
- **“稳定”究竟指什么？** 新标法出现频率下降、标法比例稳定、局部位置波动以及质量收益变小可以不同步。可提出适合研究目标的测量与对照，不要求一个簇数或单一标签概括全部现象。

Bi-Layout的enclosed/extended可以启发开口处收束与向外延伸的对照，不能预先覆盖所有真人差异，也不要求每张图只有两种模式。见[原作者项目页](https://liagm.github.io/Bi_Layout/)与仓库已有审读。

优先案例包括B6-22、uNb-40/45、X7-19、e9-16、rPc-15/20、wc-60/67、uNb-36/52/63、Uw-06/23；其余原文也完整保留。用户没有提到的问题可能是遗漏，不得将未评论图片当作已确认无问题的对照。

欢迎Pro质疑上述工作表述、提出其他有依据的方向，说明现有资料能回答什么、缺什么，并列出需要用户视觉判断的具体问题。39图经过定向审查且已用于提出改进，后续验证需要明确哪些材料参与了方法形成。

## 新裁决与修正怎样保存

基础schema仍为`pro_cluster_review_key39_v1`，新增解释层不重写旧字段：

- `cases[].reviews`保留首次用户/一正记录；其旧`final_*`空值属于旧快照，不能解释为没收到本次回答。
- `cases[].user_adjudications`与`user_point_review`逐条保存本次原文；`user_review_original`保留完整原JSON。
- `research_clarification`保留用户最新原话、导师引语及来源；`research_request`是开放问题表述，没有方法白名单和点数硬约束。
- `visual_review`和`adjudication_issues`是实际视觉观察及此前提问，不是覆盖用户回复的最终真值。
- `responses`、`groups`、原始/有效点、旧距离与分区均冻结；`analysis_audit`仍有CSV字符串，不能用`bool("False")`读取。
- `review_ingestion`记录26项/4暂缓/8份点复核/0已确认/0应用，不把选择“最正确”自动转成数据筛选。

Project28/P1/task3081的新导出差异独立保存在`pending_export_update`：W002/4738的y从761.187969924812%更正为76.1187969924812%，28点不变；W018/4784删除越界点，21→20。包含修改前后result、身份和新点集，但`applied_to_geometry=false`。不要把新版点与旧矩阵视为同一计算版本。

uNb-52/W037的删点草稿`confirmed=false`；wc-67“按照簇1的第4对点补充”尚需精确定位。当前不执行修复。将来研究原始行为时仍可查看原始点；复原版本与原始行为分别记录，不因恢复几何而抹去误点/漏标现象。

旧`main_worker_included`及W019/W026筛选标记描述历史分析口径，不表示被筛记录没有研究价值。包中保留未入簇、无效和被排除记录；研究选用哪些口径应明确报告。没有可计算几何不等于没有行为证据，缺失也不能当零差异。
