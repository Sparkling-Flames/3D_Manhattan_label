## 4. 优先处理的技术问题

### 4.1 几乎共线的新增点，会被判成另一种完整结构

返回包定义：

\[
d=0.35U+0.30E+0.20R+0.15B,\quad \tau=0.12.
\]

其中 U 为未匹配点惩罚，E 为邻接不一致惩罚，R 为端点角距，B 为边界距离。它只在地面和天花同时满足 `1e-8` 相机高度单位的共线容差时消除冗余点。

本次构造一个正方形，在同一墙中间增加一点，向外移动极小距离 ε：

| ε（相机高度单位） | BEV IoU | 完整结构距离 | 是否过 0.12 支持门限 |
|---:|---:|---:|---|
| 0 | 1 | 约 0 | 是 |
| 0.0000001 | 0.9999999875 | 0.13888890 | 否 |
| 0.001 | 0.99987502 | 0.13897728 | 否 |

变化几乎完全来自点数和邻接的离散惩罚：新点一旦未被严格约掉，U=1/9、E=1/3，单这两项就等于 0.138889。一个很小的坐标变化造成支持判断跳变。

这不是说所有 2 对／3 对都应合并，更不是说 IoU 高就没有结构差异。它说明：**当前规则尚不能稳定地区分“同一墙的采样／噪声差异”和“值得保留的小尺度真实结构”。** 因此真实结果中的 1–4 票，不能直接解释成实际只有 1–4 人同意某种空间。

定位：`src/geometry_core.py:71`、`:121`；`src/search_core.py:26`。需要对比较视图建立有测量依据的多尺度等价规则，保留原始细节，不宜仅把一个 epsilon 调大后宣布问题解决。边界采样也应检查按弧长加权，避免加点改变同一边界的采样权重。

### 4.2 虚拟裁切节点污染了拼接候选的结构支持

本次让两个四角房间仅有一个角相差 `1e-6` 相机高度单位，在 **20°** 小窗口内调用原来的 `extract_path` 和 `splice_window`。20° 符合其不超过 30° 的小窗口条件。

结果：两个原房间的结构距离约 `3.9e-7`；拼接结果与基底的 IoU 为 **0.9999999625**，却得到 **0 票**，结构距离约 **0.25000032**。两个虚拟裁切节点留在六点环内，微小接头偏差使它们不能被严格共线规则消去；U=0.2、E=0.6，仅两项就贡献 0.25。

真实 11 个候选也有类似混杂：它们与各自基底的 BEV IoU 为 **0.9609–0.9955**，但仅 U/E 两项就贡献 **0.1853–0.2864**，全部超过 0.12。已独立重算其零支持。

真实窗口可能确有不兼容结构，高 IoU 不能代替逐处判断；本次没有证明 11 个候选都合理，也没有证明每个零票都仅由虚拟节点造成。但合成反例证明现有流程会把几乎相同的有效拼接判成零票。**所以这批零票不足以评价局部整体投票的潜力。** 返回说明已保留“当前阈值下”的限定，不过据此确定研究优先级仍然过早。

定位：`src/local_splice_study.py:13`、`src/geometry_core.py:121`。虚拟节点不应直接获得真实角点身份；仍应检查拼接接头是否产生有意义的新转折，不能一律豁免其实际几何影响。

### 4.3 局部细分不等于已经解决 2 对／3 对的一致性

`_path_equivalent` 在严格约掉共线点后要求相同点数、完全一致的转向符号，然后检查位置与高度。小角噪声能改变转向符号；真正等效的不同采样也可能不等价。`vote_window` 又按遍历次序逐组接纳，代表路径取组内第一条。当 A 与 B、B 与 C 兼容，而 A 与 C 不兼容时，这类贪心分组可以依赖输入次序。

这是源代码层面的风险，本次没有量化它对真实 13 个细组的影响。不能把 13 组直接解释为 13 种真实标法。下一步应检查人员重编号／输入置换不变性，并把粗结构存在、细路径类别、同类别坐标融合分开。

定位：`src/consensus_core.py:114`、`src/local_window_study.py:89`。

### 4.4 几何损失为零，也可能有严重局部问题

其墙高损失使用相对 MAD。正方形四个墙高设为 `[2.7, 2.7, 2.7, 8]`，原函数输出几何损失 **0**，同时输出相对高度极差约 **1.963**。后三维检查结果并非未报告，但这一异常没有进入排序损失。

因此需要区分稳健的整体离散程度与局部异常；保留 MAD 的同时给出离群角点和尾部误差诊断。在真实斜顶、非 Manhattan 或跨区域场景中，这些也只能是模型假设不合的证据，不能自动归咎于人员。

定位：`src/geometry_core.py:158`。

### 4.5 90% 人数＋10% 几何，不保证“人数永远第一”

若目标为 `0.9(1-n/N)+0.1G`、G∈[0,1]，几何的最大改善可以抵偿约 `N/9` 票：20 名可比较者时约 2.22 票，100 人时约 11.11 票。这个含义随人数而变。

返回包同时提供了严格人数词典序和一人容差，值得保留。对“有多少人采用这种标法”的描述问题，优先使用人数排序；在同票或预先声明的容差内再看几何。加权式用作敏感性分析，不能把 0.90／0.10 说成有经验依据的最终比例。多指标评价的 `.35/.20/.20/.15/.10` 同样尚无标定依据。

### 4.6 V3 的未知模式概率不能用作发现新模式的可信概率

原 `mode_posterior` 给每个已见模式加 0.5，另给未知模式固定质量 1。相同 20 人：

- 全部属于一个模式：未知概率 `1/21.5 = 4.65%`。
- 每人一个不同模式：未知概率 `1/31 = 3.23%`。

分歧更碎时未知概率反而下降，来自已见模式总伪计数增加。它是一个可以执行的固定桶平滑模型，不是根据新模式发现规律验证出的预测器。它本身数学计算没有错；错误会发生在把这项输出解释成已标定的新模式风险时。

定位：`src/model_core.py:29`。目前可以保留真实模式频率、单人模式比例和留出人员中的新模式出现率，不急于用该概率模拟真人标注分布。

## 5. 需要修正的研究逻辑：融合不要求已有一人提交完全相同的答案

原返回用 `110、101、011 → 局部多数 111` 说明局部支持不能相加成整房人数。这一结论正确。但它**不证明 111 是不合理拼接**：真实结构也可能就是 111，每个人恰好漏掉一个部分。反过来，也可能三个局部根本不可共存。仅凭这个符号例子不能区分两种情况。

因此要分别报告：

1. **已观测模式人数**：有多少人实际采用某个完整结构解释。
2. **完整候选兼容人数**：在明确的多尺度等价规则下，有多少个人标注与候选兼容；不同候选的集合可能重叠。
3. **融合结果的证据**：各局部观测、闭合与邻接约束、坐标不确定性、留出数据的一致性；它可以没有完全相同的原始提交。

后者不能冒充前者的真实人数；前者也不能成为否决后者的唯一门槛。**如果之前任务书中“重算整结构支持”的要求被理解成所有融合结果必须有整房票，我会收窄这项要求；这不应全归因于执行方。**

Lee 的融合思想允许组合不同人的区域，输出不受任何一个人的完整分割限制；其最大簇经验来自明确对象任务，不保证所有全景多空间解释的多数都正确。[Lee 等原文](https://ceur-ws.org/Vol-2173/paper10.pdf)

## 6. 对我们几条路线的独立判断

### 6.1 加法、减法与复杂结构

从复杂候选开始删点，确实可能在有限搜索中暂时保留更多细节；但没有一般保证。目标若奖励低残差、少量多数支持，删点同样可能删光真实的少数细节。删除凹角还可能扩大空间，不能理解成面积做减法。相同候选集合被充分搜索时，加法和减法只是路径不同。

所以应把创新候选表述为“有来源的局部结构候选＋多尺度等价＋受约束的多候选融合”，而不是把“做减法／用退火”本身作为创新证据。是否新颖仍需系统文献对照和实验优势，当前不能确认。

全局并集应该保存为带身份、邻接、来源和互斥关系的候选集合，不能默认它是一条正确闭合的环。当前从已观测环删点的限制是合理基线，但并没有验证完整联合搜索设想。

### 6.2 局部整体投票与 T/B

小区域整体投票值得继续；两对、三对既可能只是表示不同，也可能是真实不同细节，不能按点数直接合并或拆开。窗口要通过同一段墙或同一组结构锚点的对应确认；ERP 上相近不必然是三维同一结构。

T/B 绑定利于保持空间假设，完全拆分利于处理某一端的偏差；二者都不是普遍最优。较值得比较的第三条路线是：**共享点对身份和横向角度，分别估计 top/bottom 的噪声及坐标，再施加配对、闭合和高度的适度约束。** 这是下一轮假设，不是本轮已验证优胜者。端点 x 的平均需处理全景左右接缝，不能直接平均跨接缝的数值。

### 6.3 连线、IoU、质心、RMSE、残差

返回包对中心投影的判断基本正确：三维直线的视线位于过相机中心的平面，球面上对应大圆，ERP 上通常是曲线。正确次序和三维边必须先明确；换成样条、skybox 或体积 IoU 不会自动恢复被按 x 排序丢掉的邻接。

IoU 不是只适合语义分割；Jaccard 与 IoU 是同一交并比。关键是比较对象：ERP 墙带、球面可见范围、BEV 足迹与房间体积回答不同问题。球面权重修正 ERP 的面积畸变，却不能恢复不可见空间或邻接。3D IoU 需要可信闭合实体与共同尺度；零厚度墙线没有可用体积。高低不一的真实墙顶采用中位高度棱柱时，只能叫代理指标。

质心只是整体一阶位置摘要；相同质心可对应完全不同形状。RMSE 必须说明测量量、对应和单位；点对数相同不代表逐点对应正确。Manhattan 角残差衡量模型相容性，即使为零也可能是错误大小、错误范围的矩形。它们都不能单独替代真实性判断。

我建议先保留指标向量：范围覆盖／缺失与多余面积、边界偏差、对应角点误差、细节保留、几何诊断。质心只作补充解释，不先混成一个质量总分。

### 6.4 人员质量、图片不确定性与 GT

这次人员模型的因变量是 `log(1+点对数)`。它主要研究复杂度选择／计数风格；留建筑时未知图片效应回到零，留人员时未知人员效应也回到零。没有增益不能否定人员差异模型，更不能推出人员权重无价值；暂不据此学习票权是合理的。

GT 如果只有一个空间解释，偏离 GT 可能是另一种有效空间选择，也可能是错误、漏标或手工位置噪声。换成 IoU＋质心＋残差仍无法仅凭这些量识别原因。Bi-Layout 对 enclosed／extended 的区分支持研究多种空间定义，但不能替代本批图片的真实性审核。[Bi-Layout 原文](https://openaccess.thecvf.com/content/CVPR2024/papers/Tsai_No_More_Ambiguity_in_360deg_Room_Layout_via_Bi-Layout_Estimation_CVPR_2024_paper.pdf)

更可行的是先将人员表现拆成：空间选择倾向、给定空间解释后的定位与漏标、多图及重复任务中的稳定性。明确范围且审核过的参考图承担准确性评价；歧义图保留多参考／未决状态；评某人时不能让其标注参与定义供自己评价的共识。与其他人的一致性仍应称一致性，不能自动命名正确率。

有交叉分配和足够连接性时，可以在假设下估计图片、人员的加性成分；单人单图一次观测仍难区分个人随机波动、人员×图片交互和合理模式选择。少量重复标注、独立参考和跨图片验证比继续叠加权重更能帮助识别。众包人员与图片联合建模有文献基础，但不保证这些成分在当前数据中都能分离。[Welinder 等原文](https://papers.nips.cc/paper_files/paper/2010/file/0f9cafd014db7a619ddb4276af0d692c-Paper.pdf)

human-in-the-loop 可以用于有限的定义与验证：预先制定判据，盲化人员和支持人数，针对争议样本复核并保留一部分随机样本，允许多种合理解释及无法判断，记录复核者分歧。它不保证无主观性，但可审查；完全没有外部语义证据时，客观算法也不能识别“所有人一致地错了”。

### 6.5 共识曲线不必、也不应被预设为靠近 GT

简单图更快、困难图更慢、OOS／门洞图不收敛，应当是待检验假设。困难图可能稳定形成多个模式；OOS 也可能迅速形成一种共同解释；简单图也可能稳定地偏离 GT。不要据预期曲线调门限或先按结果定义难度。

建议分别画：全体 MV 的参考偏差；模式支持比例；模式内融合的参考偏差和位置稳定性；新模式出现／模式分裂合并情况。多模式不要直接平均角点。硬支持可能重叠，不能直接当成归一化混合权重。只有在互斥模式分配或规范的软归属下，才讨论按模式概率加权的总体偏差。最接近 GT 的候选可以另报为集合覆盖能力，但不能只报它，否则加候选就容易改善分数。

当前按最近邻尺度自适应，人数越多近邻越近，阈值可能变严，制造更多模式。这一负面发现很有价值；固定 5°也只是对照。校准规则应在独立数据上固定，再在每个目标前缀只使用当时可见数据。五次顺序重放不是五套独立人群，290 个状态更不是 290 张独立图片。

八图没有干净的简单图对照，且只覆盖四栋建筑，不能据此估计普遍的难度—共识关系。

## 7. 我建议的下一轮最小验证

1. **先校验表示与支持规则。** 同墙冗余点、接缝平移、循环起点与反向、输入人员置换、极小坐标扰动、虚拟裁切节点应有可解释的稳定性；真实小凸起、不同空间范围、不同邻接必须另设可分辨对照。规则不以让八图票数变高或更接近 GT 为目标。
2. **修正小窗口实验后再比较三条融合。** 相同窗口、相同候选、相同约束与预算下，对比点对绑定、T/B 分开、共享身份＋端点分别估计。输出完整闭合候选，不只统计点身份数量。
3. **保留简单基线，再扩展搜索。** 全体 MV、每个已观测模式的代表和簇内稳健融合先完整报告；随后尝试局部路径联合选择。小规模可穷举验证，再比较同预算的加法、减法、束搜索和退火。不能要求融合结果已被某个人完整提交，也不能将局部票冒充整房人数。
4. **补样本层而非只补算法。** 保留这八图作为压力测试，加入已完成审核的简单图和更多建筑；近角 2／3 对验证需要多张独立图片。排序未确认者保留条件结果，不借算法顺手全量修序。
5. **人员分析独立进行。** 先做解释条件下的误差向量和留出验证；未取得可靠增益前，每人等权。不依据点数多、残差小、属于最大簇等单一特征定人员质量。

当前建议：**保留 V1；修正并拆开 V2 的“描述模式”和“生成融合”两种用途；V3 暂限于探索，不进入人员评分、最终概率或票权反馈。**
