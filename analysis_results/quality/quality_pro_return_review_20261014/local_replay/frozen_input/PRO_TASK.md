## 不能丢的定义和意见

1. 质量主分评价既定平均x后的处理几何，配对和环序固定。保留原输入诊断；不得靠新修点、补点或另配对使错误变好。P05不授予新的原始X固定罚分。
2. D是优化共同正交轴的边长加权**RMS**。此前Pro L1实现不等价；特殊等边菱形自由轴数值恰巧相等不能推广。固定轴/固定边族的RMS公式与L1不同。任何新指标须另命名并核对定义。
3. 高度Hc是相对参考、依赖底面对应、去均高后的残差，不只表示孤立坏角点。保留整体高低、两侧倾斜、孤立异常三种控制。GT一般有小偏差仍按正确参考使用，除明显实质错误；台阶争议继续受限。
4. “结构＞局部高度＞整体高度”是可比误差下的偏好，不是任何幅度的硬排序。C01/C02接近、C03参考接近仍重要；P01范围较小但整体更好，不等于任意规整小矩形都应获胜。
5. T20说“可以稍微扣多一点”，仅是高度罚分方向；P04支持局部不平分量罚得更多，保留“如果没看错”，不扩写为整体排序。L01整体接近、3DB略好而2DA近GT，不能捏造数值分差目标。三者历史来源限制不因有意见而解除。
6. J04单底点引起明显三维畸变，但不宜近乎扣光，是总分/方向问题；不设最低10分。J01仍约28.72/29.50，其绝对量表担忧尚未解决；不倒推必须抬到某分。
7. J02后来发现集中两点，用户更正“这个分数也算比较合理”；原负面评论不能继续当有效约束。semi trap及未改预标注不混入普通manual校准。
8. 9份严重例外提供单列严重端约束，不能永久只旁观，但不恢复人员资格，不并入普通分布，也不设必须低于10。多数是混合错误，不是9个纯方向控制。
