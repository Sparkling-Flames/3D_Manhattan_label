## 人数与暴露限制

- 20总人数、5人后续窗口只能检查k≤15。要检验k20之后仍稳定，至少需要25名不同人员。20可以是现实观察上限，但不是质量/稳定性保证。
- G207的40号无Manual记录，但当前20人均已有Semi；不能认为它对旧工人是新图。
- G036目标37号当前20人只有5份可用Manual，另3人有其他已知暴露，只有12人未见于该snapshot；清洁补齐容量最多17。
- 0记录仅表示canonical快照没找到，不排除提交外的预览/任务暴露。新派发仍需实际台账。
- 9目标机械补到20共161份；统一新20人标目标为180份，目标动作只差19份，但新人校准和培训必须另计。
- 源图与新人目标的差异同时包括视点和人群变化。可以评价联合迁移预测，不应无桥接设计就声称隔离了纯视点因果效应。

## OOS和统计解释

OOS有研究价值，但不代表全部应补20份完整几何。G014已有两张各25人的图，优先研究已有Scope方向、代理标法与分布。表示不适用、范围不确定、参考未就绪和解析失败分开；不能用受限表示下的平台证明人类真实质量上限。

比较预测时，匹配同一目标、同源图数、同H与人员条件；对照总体历史、同楼其他房、同类型其他房及同房来源。源或目标未知保留分母。预期范围相近是选图条件，实际分歧相似是待检验结果，不能倒过来选择。

人员类型应在独立校准或训练房间确定；同图同人数比较组合，不重复使用同人凑比例。少数类概率计算仅是明确iid假设敏感性，不是当前人群实测概率。本文未替导师确定最终类型、RQ或成功标准。
