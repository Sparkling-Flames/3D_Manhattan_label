# 替换分簇后的同房预测对照（2026-09-22，探索）

结论：新候选没有带来同房预测误差的改善。可比同房的支持覆盖预测仍优于两个参照，但单人簇预测的优势变弱；不能由此判断新分簇更接近语义真值，也不能推出稳定所需人数。

## 比较的算法与固定条件

- 原基线：完整链接层次分簇。逐步合并最大跨成员距离最小的两个簇，在25.6px处切分。
- 新候选：直径约束＋二次亲近度全局分区。最大化同簇对的亲近度之和，权重为 `max(0, 1-d/25.6)^2`，要求同簇任意两份作答距离≤25.6px，并满足分区传递性。采用Pro原始MILP实现；不是最少簇优化，也没有奖励收敛。
- 两者均保留有效点数硬门、既定端点对应、1024×512像素尺度下最大端点距离及横向周期距离。没有新增上下点x均值规整，没有更改25.6px容差。
- 同一批当前有效标注、人员、同房关系、目标图、来源图及评价权重；未引入GT或模型变量。
- 复用已独立审计的Pro `07_rooms_and_collection.py`，只替换分区调用。实际求解24,604个不同的完整图或相同8人子集分区，全部获得原求解器最优证书。最优证书针对给定数学目标，不是语义有效性证明。

## 预测任务与结果

以同房的其他已标注图片指标均值预测目标图指标。目标图不进入自己的预测来源。三项指标为：

- `core3_mass`：最多三个、各至少两人支持的最大簇覆盖的作答比例，允许余下尾部；不等于簇总数≤3。
- `singleton_mass`：属于单人簇的作答比例。
- `pair_disagreement`：距离超过25.6px的作答对比例；不依赖分簇。

先在房间组内平均误差，再在建筑内平均，最后建筑等权。下表单位均为比例值上的**百分点MAE**，越小越好。两个面板有重叠，不是独立验证集。

可比同房中，21张目标图有5张的簇指标变化，16张的同房来源均值变化。固定预测后按建筑配对重采样3,000次，新减旧MAE的条件95%区间：覆盖率为[-2.70, 4.75]个百分点，单人簇为[-0.14, 5.83]个百分点。两者都跨0，样本不足以支持明确变好或变差。区间不包含采集、关系选择、人员池及算法选择的不确定性；5个建筑尤其有限。

新候选下，可比同房的覆盖率MAE为7.59个百分点；其他建筑参照为21.83，同建筑其他房间参照为25.50。相对其他建筑参照的改善条件区间为[6.58, 20.79]个百分点，仍有同房信息的探索性证据。

新候选的单人簇MAE为9.41个百分点，其他建筑参照18.30、同建筑其他房间20.89；相对其他建筑参照的改善区间为[-0.29, 18.09]个百分点。该指标的优势不再在这个条件区间中排除0。

成对分歧率的目标值、同房预测值和两个参照均逐项验证完全相同。这项同房关联不可能由本次分区替换造成。

## 同一批8人的补充核对

在同房两图中使用完全相同的8人，每个子集重新分簇。共同人数较大时沿用原固定随机种子，最多抽100种真实8人组合；这些组合不是新独立样本。

可比同房27对中，3对的“同一8人组合，两图是否都达到三大重复支持簇覆盖≥90%”一致性发生变化，均从两图同时达标变成仅一图达标，涉及S9-15/19、wc-22/29、wc-22/61。其余24对不变。27对有共用图片，不能视为27个独立房间。8人下90%实际要求8人全部被覆盖，不能据一次是否达标称作持续稳定。

已有反例uNb-72/87依旧存在：完全相同的8人，一图未达到该覆盖条件、另一图达到。新分簇没有消除同房不同视角的差异。

## 解释边界与下一步

分簇改变时，覆盖率和单人簇占比的目标值也改变。因此MAE是各方法所定义指标的可预测性，不能作为针对同一个独立真值的分簇准确率。不能以同房预测更准或更容易收敛作为选择分簇的方法标准。

这次计算预测的是分歧和支持结构，没有重新估计“第几个人开始持续稳定”。是否存在通用稳定人数仍未解决。主面板也未控制目标图与来源图的人员数量完全一致；相同8人是另外的描述性控制。

保留新候选作为分区敏感性方法，优先独立核验导致分区变化的图，继续核验距离、对应及容差；现有结果不足以替换默认算法，也不支持停止研究同房信息。
