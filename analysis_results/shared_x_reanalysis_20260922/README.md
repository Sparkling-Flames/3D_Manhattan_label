# 共享x后，两种分簇、同房预测与人数稳定性的四条件复算

日期：2026-09-22。探索性重算，不修改原始标注、人员资格或正式Paper A方法合同。

**主要结果：新全局分区的同房预测误差仍略高，但不能再概括成“收敛也下降”。完整人数重放中，新方法在部分判据下反而有更多图片保持稳定。共享x减少了一部分定位差异，但效果取决于分区和指标；终点重复支持、主簇优势、持续稳定必须分开。**

- 对既有可绑定角对取周期中点，保留y、点数、角对索引及环顺序；没有0.2触发阈值，没有跨人员平均。原始点保留，规整点另存。
- W037的`new_94_3635_7036_W037`（uNb-59，p3/p4孤立点）按人工原样保留，不强行配对。它原本就未进入2444份预测池，不是本次新排除。
- 全部3019份纳入作答的点处理审计：2978份有既有绑定并生成共享x版本，40份绑定未定，1份人工保留。这里含Semi，不能把它与无辅助预测池混成同一分母。
- 无辅助计算池固定2444份／240图／25人／22楼；其中9份人审绑定，2435份是既有唯一水平匹配的条件绑定，**不是逐份人工确认**。仍有配对假设需要后续核验。
- 2086份计算作答的坐标值发生变化，共17608个端点；处理审计包含12781个作答内角对。另外，237对跨作答距离跨过25.6，220对变近、17对变远，涉及46图。237计数的是跨作答对，12781计数的是单份作答内角对，二者不能相除。

## 2. 全员终点：主簇更大，不保证重复支持覆盖更高

新分区优化同簇对的二次亲近度总和，不优化少单人簇、90%支持覆盖、同房相似性或最早稳定。它可能让主簇更大，同时把原来一个两人簇拆出一名成员，剩下一人成为尾部。完整链接也可能因很小的距离排序变化产生较大的重分区；共享x后其近对被拆计数反而增加，不能把几何规整效果预设为全面改善。

## 3. 人数重放：不能再说新分区使持续稳定整体下降

固定110图／19楼、80条真实人员全局顺序，各图投影实际人员；每个前缀重新分簇。候选起点k≥4，检查起点对所有后续已观察前缀：最多3个各至少2人支持的簇达到覆盖要求，份额TV≤0.1，旧成员关系变化≤0.05，另要求后续h人。所有参数仍是探针。

共享x、h=3时，新方法的建筑等权稳定顺序比例增益：90%覆盖为3.05个百分点，条件95%区间[-0.92,7.85]；80%覆盖为5.11个百分点，[1.10,9.82]。区间只在现有固定人员、规则和计算结果上按楼重采样，未覆盖方法选择、多重探索和新人泛化，不是正式算法优越性证明。

同样的共享x、90%、h=3条件下，8800个图×顺序中，新方法让316条从未满足变为满足，157条反向变化。新增满足中304条原来受份额／成员漂移阻挡，12条原来受支持覆盖阻挡；失去满足中107条变为支持条件不满足，50条受漂移阻挡。**新方法可在改善重分区稳定的同时损失部分尾部支持，两个方向同时存在。**这些重放高度相关，不能当8800次独立实验。

仍预测终点的分歧与支持结构，不是预测起点人数。可比同房21图／5组／5楼；来源不包含目标图，先房间内平均误差、再楼内、最后建筑等权。单位均为百分点MAE，越低越好。

|---|---:|---:|---:|
| 原始／完整链接 | 6.93 | 6.94 | 15.88 |
| 原始／全局亲近度 | 7.59 | 9.41 | 15.88 |
| 共享x／完整链接 | 6.41 | 6.56 | 15.94 |

### 为什么同房误差增大，而人数稳定未必下降？

首先，优化目标不同。新方法按几何亲近度重组成员，不要求同一房间各视角的支持指标一致，也不直接优化支持人数。其次，一个视角的分区变化会同时改变它自身的目标值和它作为其他视角来源时的预测值。

实际例子wc-22／29／61：两种坐标下，旧wc-22为“4、2、2”，新为“5、2、1”；另两图保持“8”。于是wc-22的重复支持覆盖从100%降到87.5%，另两图仍100%。预测wc-22时，来源仍给100%；预测另两图时，wc-22又把来源均值从100%拉到93.75%。**一张图发生重分区，三张目标图的误差都受到影响。**8人时一人就占12.5个百分点，小样本会放大这种离散变化。

这三张图对共享x新旧覆盖MAE差的建筑等权贡献合计+1.67个百分点，大于最终净差+1.08，其他图片有改善抵消。对单人簇MAE差也贡献+1.67个百分点；另外7y3-08／12这一对因单人占比变化带来约+0.83个百分点。源图与目标图重新变化的代数分解见`room_error_attribution.csv`：共享x覆盖误差+1.08中，目标变化贡献约+0.81，来源变化+0.27；单人误差+2.75中，分别+1.64、+1.10。这是固定数据的数值归因，不是因果效应。

因此应分别报告几何分组、共识形态、动态稳定、同房可预测性。更一致／更可预测不自动等于语义正确；反过来，不同视角真实存在差异时，忠实表达这种差异也可能降低简单同房均值预测的效果。本轮没有独立语义真值证明哪一算法正确。
