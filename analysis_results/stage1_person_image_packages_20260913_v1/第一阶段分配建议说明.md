3. 每份语言压缩包是管理用合集。一个人只对应自己的清单，共用图片目录中的全部图片不是此人都要做的任务。必做和可选分别编号，同一房间在各部分内部相邻显示；不同人的房间顺序轮换。
4. 工作簿含研究者预期难度、历史和采用状态，供管理者核对。个人图片页不显示这些研究信息，也不显示他人答案、GT或模型标注。

压缩包与原图副本作为本地生成工件保存；本目录忽略规则仅排除这些大文件及渲染检查。机器表、清单、报告、工作簿与生成器可由Git跟踪，本次未提交或推送。

## 5. 可选任务不一定做，如何处理

**任务是否必做和图片能否用于研究分开。**自愿完成的真实标注有研究价值，但只有收到后才增加实际人数；未参与、跳过或未完成都不补零、不当成失败标注，也不复制已有人的结果。

建议先让人员决定是否参加、愿意做多少，参与后尽量按提供的顺序做，允许记录跳过；不要要求先浏览全部图片再自由挑最简单的。个人顺序已轮换，避免所有人都只完成相同的前几张。这是减少选择影响的操作建议，不取消自愿性质；实际选择、顺序、跳过和参与人数应保留。

| 完成整套可选20张的英文人员 | 新增可选份数 | 至少得到2份新作答的补充图 | 至少得到5份新作答的补充图 |
| --- | ---: | ---: | ---: |
| 0人 | 0 | 0 | 0 |
| 任意2人 | 40 | 15—19张 | 0 |
| 任意5人 | 100 | 22—25张 | 8—14张 |
| 全部10人 | 200 | 25张 | 22张 |

这里枚举了实际是哪几个人完成整套20张，不是随意挑一个有利组合，也不是参加概率预测。“至少2份／5份”只描述新数据覆盖，不代表形成一个簇或证明收敛。有人只做几张时，按实际逐图提交统计；不能用这张整套参与表代替。

分析时保存“历史＋必做部分”的结果，再单列加入可选作答后的变化。自愿者是否与不参加者不同，需要用既有人员记录检查；新门洞图只有英文侧自愿补标时，不能直接把变化归因于英文人员、人员类别或门洞难度。语言、图片与自愿参与方式在这里没有被独立随机分开。

## 6. 退出和人数上限

43张必做图中，37张还有至少一名当前未接触且未被安排该图的人，可以列为替补候选；这不代表对方在20／30张之外已答应增加工作量。

6张已用尽当前未接触的人员：G179-29、G184-26、G184-88、G057-04、G057-10、G202-26。其中G184-26、G184-88、G057-04现有人员最多到19，原目标20继续保留；其余3张安排完成后可到20。如果这些图有人退出，需要新的未接触人员，或接受本阶段实际人数；不能让旧人员重做，也不能把可选承诺当成替补承诺。

其他图按原区间上限／明确备注安排，但上限安排不是“无论退出多少都能保住上限”。退出后按实际人数和结果判断：实际低人数的有效统一共识仍可以记录，不统一判作无效或不收敛。

## 7. 数据核验与复算边界

- 找到了既有`historical_exposure.csv`和648图的人员接触清单；本次进一步回查24份原始导出中的3998条提交出现记录及115条草稿出现记录。两者都包含多快照重复，不作为独立作答数量。
- 当前480行必做、200行可选全部通过同人同图唯一性、既往提交／草稿排除、人员范围与每人张数检查。Manual与Semi都用于接触排除，只有当前可用无辅助作答进入Manual人数。
- W034另有5张只发现草稿、未发现正式提交的图，也按已接触排除。其余人员的已提交图片总表已列入工作簿，不输出实名或邮箱。
- 没有检查未保存的浏览行为、尚未提供的新导出和旧服务器异名账号，不能把“本次记录未见接触”扩大为绝对从未看过。
- 原始导出、用户原话与两条补充确认、原采用决定、正式方法合同和线上LS配置均未修改。图片包共用原图，不生成GT或答案覆盖图。

机器表`分配建议与核验.json`的schema为`stage1_image_package_proposal_v1`：`assignments.tier`区分required／optional；`baseline_credit`只给必做记1；`optional_offered`是提供名额，`all_optional_done_total`是全完成情景；`alternative_workers`仅为单图未接触人选。没有字段把提供名额当作实际完成。

复算入口：`tools/thesis_main/analysis/build_stage1_image_packages_20260913.py`；工作簿生成器：同目录`build_stage1_image_workbook_20260913.mjs`。定向测试验证重复接触／非本轮人员／草稿身份；完整生成过程验证480＋200行、每人30＋20／20张、上限、OOS和压缩包内容。工作簿29页均渲染，导出后重新打开核对合计及680行明细，未发现公式错误。文档索引和项目地图已登记为探索建议，不升级为正式派发合同。
