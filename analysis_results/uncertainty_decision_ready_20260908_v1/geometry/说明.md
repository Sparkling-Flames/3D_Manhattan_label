# 真人—Bi 地面对照：精度与点序读取敏感性

本目录仅提供数据准备和描述性核对，不产生工人分类、语义真值、歧义阈值或新增人工裁决。可复现入口：

```powershell

D:/anaconda/python.exe -m pytest tests/test_prepare_human_bi_comparisons_20260908.py -q
```

## 数据关系与字段

- `human_bi_comparisons.csv.gz`：2501 条 canonical × 2 种读取 × 3 种 Bi 表示，共 15006 行。主键为 `canonical_annotation_id,reading,representation`。人员、阶段、block、条件和 context 保留，不能把六种表达当成六个独立人。失败行仍保留。
- `human_reading_maps.csv.gz`：每个响应两种读取的原点编号映射（5002 行），点编号从 0 开始。不修改任何坐标。`serialized_adjacency` 只在原相邻点对内读取上下角色；`historical_pairmap_unaveraged` 是历史按横坐标配对的敏感性读法，不平均横坐标，不声称它恢复了作者原意。
- `model_floor_comparisons.csv`：380 张 × 3 表示；`legacy_integer` 沿用保存整数坐标，`pixel_center_integer` 按已核对的 Bi 导出像素中心约定加 0.5，`native_uv` 直接使用已保存的浮点地面 UV。**真人连续百分比坐标不加 0.5。**
- `user_confirmed_derivatives.csv`：另列用户确认点序的 9 行（3 来源 × 3 表示）。V33 另一视角 ann6154 → canonical `7fc54cc83e44fb28abe2`，是 1 份实际真人响应的派生；V07/V31 是参考来源，canonical 为空。不把这 9 行追加为新标注样本。原点序不被替换，点序确认也不是最终几何裁决。V33 两条百分比换算路径差异最大 2.84e-14 像素，身份核对使用绝对容差 1e-10，不是匹配不同几何。
- `comparison_coverage.csv`：逐表示与读取报告可计算分母。
- `response_precision_sensitivity.csv`：三个表示共同可计算的响应上比较亲近度变化。
- `context_precision_sensitivity.csv`：复用上一轮同 context 真人—真人地面均距，对 Bi 双头精度进行敏感性比较；`initialization` 是旧表字段原样留存，其 missing 类别不能据此解释为缺少实际初始布局，应连接本轮来源核对视图。
- `descriptive_associations.csv`：上述共同可计算 context 按阶段/条件及至少 2、3、5 名可计算人员分别给出 Spearman 描述相关。门槛仅作分母敏感性，不是推荐招募人数。没有 p 值、显著性或独立样本假设。
- `QA.json`：身份覆盖、同轴验证与原始数据未修改状态。

所有距离均为同相机高度规范下的地面多边形 **1−IoU**，不含天花板高度/分层信息，不是 3D IoU 或真实尺度。`d_enclosed` / `d_extended` 是真人到模型两头的距离；`d_bi` 是模型两头距离；`delta_enclosed_minus_extended` 为前二者之差（正值仅表示更接近 extended 几何）；`minimum_residual` 是两头均可计算时较小的距离。任一端不可计算时保留各端状态；部分可算距离可保留，但 delta 和 minimum 不进行单头代替。空值代表未计算，不是零分歧。

## 核查结果

两种读取每一种 Bi 表示的可计算响应分别为：原邻接 1597/2501，历史 pairmap 2335/2501。这个差别属于表示可计算性，不能把额外 738 行解释为“修好了 738 份标注”。

两种投影实现的第一坐标轴原本互为镜像。模型—模型 IoU 在共同镜像下不变，却不足以验证真人—模型比较。本入口将 native UV 投影到既有 `audit.footprint` 的同一坐标轴，并对 755 个有效像素中心模型多边形逐个做独立重建一致性检查；最小测试使用非对称四边形，避免对称形状掩盖镜像错误。

整数切换到 native UV 后，原邻接的严格亲近度符号变化为 748/1597，历史 pairmap 为 999/2335。其中原整数恰好平局的 570/742 条转为极小非零差异；非零方向真正反转的分别为 178/257 条。delta 改变量中位数约 0.00120/0.00123，最大约 0.03022。**这些是精度敏感性，不是人员行为变化；不能用严格正负给工人贴 enclosed/extended 标签。**

另用 1e-12 作为浮点数值零容差重新计数，上述 native UV 的计数不变；该容差不具有语义或实际差异阈值的含义。非零反向项的 max(|delta整数|,|delta native|) 中位数/90分位：原邻接约 0.001535/0.004240，历史 pairmap 约 0.001550/0.004256。因此，变化并非仅发生在机器精度的零附近，但其绝对量级仍小，不能称为工人语义倾向反转。

至少 3 名可计算人员的固定共同 context 中，双头差异与旧真人均距的描述相关：原邻接 0.2181 → 0.2477（151 context、134 图、16 building）；历史 pairmap 0.1885 → 0.2058（172 context、148 图、17 building）。这两种读取的分母不同，不能把它们的相关差别全归因于点序效果。同一图跨条件以及同一人员跨图重复出现；这些相关不提供独立样本统计推断，也不证明模型差异可以代替人的歧义。

Shapely 的 divide-by-zero RuntimeWarning 已逐步定位到 `numeric_warnings.csv`：共 3 个步骤记录、涉及 2 张图，全部出自像素中心同轴多边形一致性检查 `same_axis_polygon_check`。真人—模型比较、模型两头比较和用户确认派生的实际距离运算未触发警告（各表仍保留 `numeric_warning` 字段）。这 3 个检查结果均有限且在容差内；警告文本保存在证据表而不是禁用或将结果改零。所有标记可计算的真人—模型距离另已检查有限、位于 [0,1]（允许 1e-12 浮点误差），并验证 |dE−dX| ≤ dBi（允许 1e-10）。后续如升级几何库，应对同一输入再作核对。

## 本轮停止边界

当前数据已足以作为后续选择工人分层依据前的连续测量入口。尚未检验：哪些真人响应在语义上属于范围截断/扩展；这些倾向是否跨图、跨 building 重复；两头都不贴近真人响应时的具体原因。源点序的几何可计算不等于正确，用户尚未确认的读法不自动获得“正确”身份。
