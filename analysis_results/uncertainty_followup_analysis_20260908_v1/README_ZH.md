## 1. 资料范围与导师方向的理解

数值复算复用已核对的云端输入底座：214张历史图、26人、2501条canonical响应、270个图像／阶段／block／条件单元。没有从原导出重新构建整个底座，旧资格或退出身份没有用来统一过滤历史响应。当前20人只是独立的人数组成对照。候选图没有真人响应，不纳入真人分歧相关的样本量。

已有50图问卷与四条2026-09-08补充是解释来源；50图是探索性选择，不能据此估计总体歧义发生率。原始人工评论、AI提取和本报告观察分层保存。已有19条范围语义陈述连接到能唯一识别的显示对象；“其余”等集合称呼不擅自展开，代表标注的语义不推广给全簇。

结合导师原交流，合理的工作理解是关注场景条件、响应分布、少数解释、随人数变化的稳定性和瓶颈。**这是研究方向解释，不是已确定的论文方案。** 用户对语音交流中“疲劳模拟”和“Bi两种倾向”的回忆存在不确定性，两条路线继续分开。纯手工、纯机器、机标人校可以作为条件比较方向；当前模型输出不是随机受试者，历史Manual与Semi也不能自动构成可识别的因果实验。

## 2. 先区分读取可计算性与标注质量

复用了已有四种距离实现，原读取下270单元的真人平均距离与接收结果一致，最大绝对差小于1e-15，缺失位置一致。这个结果验证计算复现，不证明原几何读取解释正确。

| 读取路径 | 定义 | 地面轮廓可计算响应 |
|---|---|---:|
| serialized_adjacency | 按导出列表相邻两点组对；仅在组内判断上下 | 1611 / 2501 |
| historical_pairmap_unaveraged | 历史默认的稳定x排序、5%图宽邻近配对；保留每个原始坐标，不平均x、不截断投影、不使用本地覆盖 | 2363 / 2501 |

两种读取均可计算1606条，均不可计算133条；历史配对假设新增可计算757条，同时使5条失去可计算性。因而它是**读取敏感性假设**，不是757份已修好的标注，也不是给所有图提出改序。真实历史viewer还可能平均x或使用本地覆盖，本复算没有声称完全重现作者当时看到的显示。

地面指标为固定相机高度比例下的平面轮廓 `1-IoU`；其余包括球面墙带、旧线性墙带及立体角加权墙带。它们不是米制三维误差，几何可计算也没有验证曼哈顿约束或范围合规。V06近地平线端点、V13仅三个角的投影限制、V07/V31严重畸形预览应分别处理。

[读取状态](reading_status.csv.gz)保存全部失败原因；[条件覆盖](reading_coverage_by_condition.csv)及[读取转换](READING_TRANSITIONS.json)保留分母。原点序、原始导出与旧簇均未覆盖。

## 3. Bi差异与真人分歧：有条件的关联，不是通用判断器

下表均为地面轮廓距离、全部历史人员、各读取自身可计算集合的Spearman描述相关。extended73视图要求至少两份可计算响应；全量视图要求至少三份。两者样本选择不同，因此还保留共同响应集合对照，不能把差异全部归因于几何算法。

| 范围 | 原相邻读取：单元 / 图 / building；ρ | 历史配对假设：单元 / 图 / building；ρ |
|---|---|---|
| 扩展73单元视图 | 72 / 72 / 16；0.495 | 72 / 72 / 16；0.483 |
| 全量、至少3份可计算响应 | 151 / 134 / 16；0.218 | 172 / 148 / 17；0.189 |

在相同可计算响应集合上，扩展视图为0.489→0.480，全量151单元为0.217→0.196。因此，高覆盖选择集合中的正相关并非完全由这一读取改变造成，但外推到全部历史场景明显变弱。三个墙带指标也保留正的扩展视图相关；历史配对假设下约0.343–0.362，全量约0.066–0.142，且可计算分母更少，不能把它们当独立重复实验。

![范围选择与相关](association_domains.png)

条件异质性不能省略。在历史配对地面指标下，P1 Manual为ρ=0.627（29单元/12个building），P1 Semi为0.159（18/10）；全量C1 Manual为0.169（85/13），C1 Semi为−0.327（24/9）。这些差别可能混合场景选择、初始化、人员及测量覆盖，**不能据此断言Semi减少歧义或产生反向因果作用**。去掉合成初始化后的扩展视图ρ=0.529（66/15），全量ρ=0.203（166/17），只能说明这个粗排除没有消除全部关联。

`associations.csv`同时提供图像均值、building均值、building内秩中心化以及逐building留出诊断；没有将这些诊断称为置信区间。重复视角、同人跨场景和非随机条件分配仍限制总体推断。房间类别不是实体房间ID，不能把同building全视角合并成一个房间。

|---|---|---|

| V15 | 0.035 / 0.418（22/26） | 双头相近，真人明显分歧。最新补充仍无法判断中央门边结构；拼接扭曲是用户解释，因果未验证 |

## 4. 已有真人分簇可以复用，但旧簇数相关存在分母问题

扩展73单元中66个分区可评价，7个为 `not_evaluable`。旧表把后者的簇数记作0占位；它们不是“零种真人解释”。把这些0纳入后，Bi距离与簇数相关为0.478（72单元）；剔除不可评价占位后为0.576（65单元、16个building）。方向仍为正，但旧分母及其含义必须修正。详见 `cluster_count_validity_sensitivity.csv`。

复用了303个旧簇、1604名次的簇成员，没有重聚类。原读取下81簇全员可算、110簇部分可算、112簇无人可算；历史配对假设下为269、4、30。这里统计的是每个旧簇的地面计算覆盖；不能据此说原簇全部正确或算法已恢复语义。

`cluster_reading_sensitivity.csv`只在各簇可计算成员中选一个距离medoid作对照，明确记录原支持数与可计算支持数。该代表不是原人工代表，也未被命名为enclosed/extended。只有对成员层面的范围、局部结构和规则条件继续核对，才有资格讨论某个簇是否贴近某一模型头。

## 5. 15–20人：目前可做固定旧簇的覆盖敏感性，不宜宣布质量收敛

本轮补充了一个无需模拟随机噪声的精确计算：从已有固定分区的N名成员中等概率不放回抽k人，某簇被看见的概率为 `1-C(N-m,k)/C(N,k)`。所有簇的概率相加得到期望看见簇数；再除以该分区历史总簇数得到覆盖比例。它不对子集重新分簇，不测真值质量，也不预测新招募者。

为保证15与20人比较不更换场景，主表固定为当前20人均在旧簇成员中出现的**同51单元**：

| 人员池 | k=15：期望覆盖旧簇比例 | k=20：期望覆盖旧簇比例 |
|---|---:|---:|
| 每图全部历史簇成员 | 84.03% | 92.82% |
| 限定当前这20人 | 77.94% | 84.54% |

![固定旧簇的覆盖](fixed_partition_capture.png)

当前20人全取后仍不到100%，是因为部分旧簇只有当前名单之外的人出现过，不能解释成“这20人都标错”或“无限招募也不能提高”。增加新人能否出现新的有效解释，仍需未来资料验证。即便某个少数簇被发现，也不代表它合规或正确。

扩展73单元、旧成员数≥20的63单元、当前20人齐备的51单元，以及其他报告基于原始响应的57单元不是同一个分母。48个单元的原始响应人数与旧簇成员人数不同，说明旧簇保留了历史筛选范围；本轮不把那套筛选自动套到全部历史分析。原始质量曲线与本轮簇覆盖不是同一结局，不能拼成15–20人的质量停止规则。

## 6. 下一步建议，供你和导师选择

1. 先完成[两份异常GT预览的点序复核](点序与来源复核.md)，收到用户顺序后保存派生预览，再检验上下端点、地面投影及曼哈顿约束。V06投影问题单列。正常预览不开展全量改序。
2. 将V33另一视角的C1 Semi 6154、V20旧C1响应等作为有身份的具体版本对照，确认“范围改变”到底发生在哪段边界；保留跨视角关系，不提高同图独立人员数。
3. 优先检验已有簇内语义一致性及高/低Bi反例，允许同一范围类型内部有不同截断、角点数量或局部质量。现有代表上的人工判断可先用，只有确有必要才请人工核对其余成员，不重发整份问卷。
4. 数量推断在固定场景集合、固定人员池和明确结局下分别报告；building用于分组诊断。若将来招募新人，应把“新人带来哪些先前未见解释”与“旧人员重做的稳定性”分开记录。此处不指定招募人数或最终停止标准。
5. 只有模型头与真人响应类型的对应得到支持，才讨论两倾向模拟。疲劳另查真实时间、顺序、休息及重复任务资料；不把Bi两头硬映射成疲劳前后。纯手工／纯机器／机标人校先整理已有条件支持，正式比较设计由你和导师决定。

## 7. 数据字典与复现

生成入口：`tools/thesis_main/analysis/analyze_uncertainty_handoff.py`。使用现有虚拟环境与已安装numpy、pandas、scipy、Shapely、Pillow、matplotlib，复用接收包的距离函数和现有renderer，不需要GPU、权重或联网。完整复现需要本仓库的输入底座、接收数值包、已整理50图包和本地导出；这是本地接手分析包，不宣称是独立云端发布包。证据图使用现有高清图片及Windows字体；缺少图片的环境只能复算数值，不能宣称完成视觉检查。

```powershell
.venv/Scripts/python.exe -B tools/thesis_main/analysis/analyze_uncertainty_handoff.py
.venv/Scripts/python.exe -B tools/thesis_main/analysis/analyze_uncertainty_handoff.py --local-export-search
```
