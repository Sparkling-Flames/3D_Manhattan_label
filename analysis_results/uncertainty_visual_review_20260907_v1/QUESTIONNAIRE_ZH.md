# 三步审查问卷：怎么填、怎么保存

直接打开 [问卷入口](index.html)。一次只处理一张图，顶部可选案例或前后翻页。不要求现在就判断“是否具有固有歧义”。

1. **看原图**：先沿全景看一圈，再检查顶面、地面、门洞与遮挡；两端是同一接缝。填写看清程度、目前规则下范围是否容易确定。2048×1024是现有原始分辨率，点击图片看原尺寸；仍无法判断就如实选择证据不足。
2. **看布局与3D**：旧版标注全景、俯视、斜视直接显示。下拉切换Bi两头、HoHoNet、参考布局及已有真人显示代表。需要细节时打开高清叠图或新版交互3D；后者左窗原始几何、右窗约束拟合诊断。勾选问题类型，历史图再填写所示真人之间的差异。候选没有真人响应，第4题不适用。
3. **记录与保存**：备注可写“哪个区域／哪份布局／哪号点／还缺什么证据”。选择草稿、暂缓或本轮记录完成，然后进入下一张。第1、2、4题可以选不确定；第4题仅历史图适用。第3题和备注选填。疑似／认为OOS时有独立路径，见下节。

例如：第1题“部分看清”，第2题“暂时无法判断”；第3题勾选“范围不同”和“门洞、遮挡”，第4题“展示不足或暂时无法判断”；备注“右侧门洞后的区域是否纳入，需要核对规则”；状态选“暂缓”。不必为了完成而猜答案。

## 发现OOS时怎么填

在第①步“场景适用性”选择“疑似OOS”或“我认为是OOS（本轮审查意见）”，填写**具体区域、可见结构、与当前哪条规则冲突、仍待确认什么**。拿不准是否OOS就选择“暂时无法判断”。这里记录当前审查者的意见，不要求先得到导师确认，也不自动成为正式排除结论。

填写理由后可点“先记录OOS意见，前往保存”，再选草稿、暂缓或本轮记录完成。疑似／认为OOS允许不填第1、2、4题，未作答仍为空；可以继续看3D，已有答案不清空。若改回非OOS、无法判断或未选择，恢复原必答要求；若不满足会保留为草稿。理由不会因为更改选项而自动删除，按当前判断自行修订。

“所示标注都有疑问”评价标注版本；OOS评价场景对规则的适用性，两者分开。3D失败、看不清、模型分歧或投影线弯曲不能单独作为OOS依据。样本不因填写OOS而删除，历史数据仍保留供后续分析。

## 保存在哪里

- 填写时自动暂存在当前浏览器，同一个入口地址刷新可恢复；不会写回仓库。清除浏览器数据、换浏览器、移动入口或使用隐私模式都可能丢失暂存。
- 每次结束点击 **导出JSON备份**，将下载文件保存到自己明确的位置。换设备或以后继续时，用“导入JSON继续填写”。导入会先核对案例、图像ID和选项；覆盖已有答案前提示确认。
- **CSV汇总**用于阅读统计，不用于重新导入。CSV备注以公式字符开头时会加单引号保护；JSON保留原文字。
- 浏览器不能暂存时会明确提示；离开／刷新前立即导出JSON。暂存损坏时保留原值，避免自动覆盖；可用有效JSON备份恢复。
- 如需让我继续汇总，提供导出的JSON路径即可。页面不会自行改写原始标注、AI报告、簇或人工最终裁决。

## 字段约定

JSON顶层 `schema=panorama_human_review_v1`，`exported_at` 为导出时间，`records` 为已发生填写的记录；未填写的图片不自动补空记录。每条以 `case_id` 和 `image_id` 双重定位，含 `answers`、`updated_at`、`ai_advice_opened`。多次填写保留当前答案，不提供历史撤销版本；导出不同日期备份可保留自己的版本。

| answers字段 | 选项代码及含义 |
|---|---|
| visibility | clear基本看清；partial部分看清；insufficient证据不足 |
| scope | one_clear范围较明确；multiple_candidates不同范围待核对；rule_unclear规则适用不清楚；uncertain无法判断 |
| annotation_assessment | 选填：some_plausible至少一份可作候选；all_questionable所示都有疑问；not_all_checked尚未逐份看完；uncertain不能判断可靠性。旧备份缺此字段时补空字符串，不改旧答案。 |
| human_difference | similar所示较接近；local局部差异；scope范围差异；mixed多种差异；uncertain展示不足／无法判断；not_applicable候选无真人响应 |
| factors | 多选数组：scope范围、occlusion遮挡、local局部点位／角点数、rule执行、sequence预览点序、reference参考疑点、assumptions预览假设 |
| oos_assessment | 选填：in_scope目前适用；suspected疑似OOS；reviewer_oos审查者认为OOS；uncertain无法判断。均为本轮意见。 |
| oos_reason | 原文理由／待核对问题，最多100000字符；疑似／认为OOS且标记reviewed时须有非空白内容。 |
| notes | 原文备注，最多100000字符；允许为空 |
| status | draft草稿；deferred暂缓；reviewed本轮记录完成（并非最终正确或正式裁决） |

未回答的单选保存为空字符串；发生填写后未选状态时记为draft。空白与“不确定”不同。reviewed通常要求可适用必答题已填；疑似／认为OOS时改为必须写明OOS理由。未满足则保留草稿并提示。CSV展开answers，多选以 `|` 分隔。

AI内容默认折叠，不预填答案；`ai_advice_opened`只表示曾在该记录中展开AI栏，不能证明完整阅读或实验意义上的盲审。问卷可回头改答案，不建立先后观察的不可变记录。

AI栏现位于三步共同区域，任何一步都能展开并结合图片阅读；先显示本次高清与点序复看，再保留此前观察。可以不同意AI，理由直接写备注。若所有显示版本都有问题，选“所示标注都有疑问”，再分别记录它们相互之间是否接近，不必选出一个正确答案。

遇到奇怪的3D，先打开“仅原始点”，再对照“高清叠图（连接假设）”及旧预览。原点图编号从0开始；旧3D的pair编号是显示槽位。原序失败红线是脚本诊断线，不是作者画出的墙边。详细映射和50图本次意见见 [点序复查勘误](ORDER_REVIEW_ZH.md)。本入口现接入角点组顺序编辑；具体操作见下节。

## 解释边界与复现

浏览器检查：`node tests/uncertainty_review_questionnaire_browser.cjs`，使用与用户分离的临时浏览器；检查空白初态、3D和全部资产、刷新恢复、JSON来回导入、身份错误拒绝、候选不适用、必答限制、CSV保护、移动端宽度及暂存损坏保护。`questionnaire_qa/`截图中的勾选和备注均为测试数据，不是真人审查结果。本轮只改显示和记录入口，不增加视觉审查完成数。

## 交互3D：交换角点组

1. 在问卷第2步点“交互3D／调整角点顺序”，在新窗口“标注来源”选择同一份布局。新窗口不会自动跟随问卷下拉框的选择。
2. 打开右侧栏，找到“角点组预览顺序”。点选编号按钮后可前移／后移整组；也可输入完整排列并点“应用预览”。例如交换四组中的第2、3组：`1,3,2,4`。每个原始组编号必须恰好出现一次。
3. 编号按钮是从1开始的角点组编号；每组上下两个端点一起移动。映射表另列真实原始点ID，不要把组号、payload槽位和原点号混用。
4. 结合全景、白模／纹理查看变化，可随时“恢复原序”。右侧曼哈顿拟合不会沿用旧结果；可显示的表面仍只是原始射线假设下的代理。上下配对无法读取时，整组重排不能补救。
5. 切换来源、切图或刷新前，点“导出独立预览顺序记录”。回问卷勾选点序问题，在备注写布局名称、原始组顺序、变化及判断理由、导出文件名。问卷JSON与预览JSON分别导出，问卷不包含预览调整；预览JSON目前不支持直接导入，可按记录的顺序手动重放。

本页旧拼图、高清叠图和AI建议保持原来的证据版本，不随交互调整自动变化。没有任何排列被默认认定正确。

重发50图工具时仅复制共享源码中的 `index.html`、`studio.css`、`studio.js` 到每个 `cases/Vxx/hd/studio/`；保留 `data.js`、模型几何、原图与依赖文件。随后运行 `prepare_uncertainty_visual_review.py finalize` 更新问卷。无须重跑模型或约束拟合。验证见 [接入状态](STUDIO_ORDER_INTEGRATION.json)。
