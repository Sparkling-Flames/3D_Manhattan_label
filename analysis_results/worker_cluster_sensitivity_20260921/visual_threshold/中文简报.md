# 25.6 像素阈值与当前分簇的八例实际目视复核

本轮实际查看了八张不同全景的两份作答及相同位置的二倍局部图。结论是：**当前分簇把点数、对应、像素距离和全局分区的影响混在了最终簇号中；仅凭簇号不能反推表达语义。25.6 像素可继续作为候选测量尺度，八例目视不足以把它认定为语义边界。**

案例为有目的的机制取样，不估计总体误分率，不按收敛表现选阈值。前七图不在脚本明确列举的既有开发审核资料中；第八图 uNb-40 属于旧开发图，仅作机制复查。已明确排除人工裁定的 uNb-21，不覆盖任何既有人工结论。

前四对在25.5、25.6、25.7之间会改变两两相容判定，但原始作答语义不随这些数值变动。它们同时包含遮挡定位和可能的截面选择差异，说明语义不能只由统一像素距离承担。是否需要按局部可见性、结构或范围进一步表述，应在人工核验后判断。

建议保留的研究区分为：点对应是否可信；局部几何偏移；完整结构/范围是否相同；全局算法最终怎样分区。这里不新增正式分类、不调整阈值、不修改原标注。少数单例或点数差异仍保留研究价值。

主代理另行实看了 uNb-29、uNb-40 的全景及局部，认可上述近邻拆分和接缝起点错位的机制判断；这种重叠查看不代替用户语义裁决。其余六例由本子代理逐张查看。
