## 计算的是什么

本轮测量球面端点集与参考端点集的差异，不连接墙面，不推测丢失的最终角点顺序，不做3D IoU或曼哈顿合法性判断。

| 字段 | 定义及限制 |
|---|---|
| `ospa30` / `ospa60` | 球面角距最小代价一对一匹配，单对角距分别截断30°/60°，数量差按同一截断值惩罚，除以较大点数。越小越接近参考。两参数是已有方法敏感性，不是合格阈值。 |
| `matched_angle` | 不截断的最小代价匹配中，已配对端点的平均角距，单位度；缺失点不进入该平均，所以不能单独当整体质量。 |
| `absolute_count_rate` | 端点总数差绝对值/参考点数。是数量偏差代理，不等于墙面结构错误率。 |
| `missing_count_rate` / `extra_count_rate` | 相对参考点总数的净少点/净多点比例。不能定位漏标/多标墙角，也会漏掉数量抵消的错误。 |
| `chamfer` | 两向最近点平均角距，仅保存描述性对照，不用于挑选主结论。 |

无序点集相同只表示端点位置相同；不同邻接、墙体范围和非曼哈顿问题仍可能存在。反过来，范围解释不同也会改变这些距离，不能未经视觉归因就称作“不认真”或“能力低”。已知存在此类疑问的图暂不用于唯一参考计分；未知图暂信GT这一假设仍然重要。

## 验证方法及结果

分别在每个阶段/条件拟合工人效应和context效应。每次整栋building留出，只用其他building学习工人效应，在留出数据中比较同context、同训练连通分量、同一可预测人员集合的相对偏差。未在训练出现、或没有可比同伴的响应不进入该次预测，另列 `fold_audit.csv`。

指标为相对“所有人的工人效应均为0”基线的平方误差降低比例；负值表示变差。按响应等权与按building等权分别报告，后者先在每栋内取均值，再比较总体误差。这里是已有人员在其他building的相对偏差验证，不是新人员验证，也不是预测某building需要多少人。

| Manual验证（OSPA30） | 响应数 | 按响应误差改善 | 按building误差改善 |
|---|---:|---:|---:|
| P1全部可用26人 | 703 | +31.22% | +31.24% |
| P1仅当前20人，重新拟合 | 559 | +9.73% | +5.35% |
| C1全部可用23人 | 605 | +5.48% | −5.96% |
| C1仅当前20人，重新拟合 | 529 | +5.12% | −6.55% |
| 用P1预测C1，目标building从训练排除 | 605 | +3.61% | −14.83% |

OSPA60也呈现相同主要差别：P1全部人员按building改善31.02%，当前20人5.80%；C1全部人员−8.70%，当前20人−9.09%。因此不能只摘取P1全26人的较强结果。

C1分开参考来源仍未显示正的building等权收益：OSPA30仅暂信GT为−10.49%，仅已有人工参考为−7.83%。后者只有10图、4个building，证据范围很窄。这不证明参考来源毫无影响，也不是证明该研究方向不可行。

C1中其他指标也未同时取得正的响应等权与building等权收益。P1到C1的匹配点角距有小幅正收益，但只覆盖已配对端点，不能用这一项替代整体结果。没有根据验证集挑阈值或宣布显著性，没有校正多重比较或输出确认性p值；当前结果用于判断是否值得继续。

## 对第一种版本的判断及下一步

**数据与计算入口可行；稳定工人类别尚未得到支持。** 当前最可靠的表述是“相对给定参考的偏差及其可重复性”，而不是已经识别出稳定的高/低质量工人。

下一步优先检查C1中预测改善与恶化的具体案例，区分局部执行偏差、范围选择、GT疑问和图像本身难点；可以复用已有人工评语，不要求将全部图重审一遍。再考虑少量清晰图上的局部错误标签，检验更贴近“规则执行”的指标。是否需要额外标注及分类门槛，留待导师讨论。

当前没有必要为了得到类别而反复换距离或挑图。另一个方向“范围倾向”继续保留为解释变量；Bi双输出不在本次承担真值。第一种版本的限制不构成第二种版本已成功的证据，也没有检验building收敛人数。

可给导师的简短回复：

> 我先验证了更容易落地的第一种：用我复核过的参考，其余暂按GT正确，比较标注者的点位和数量偏差，并留出building看能否复现。P1全部人员有一定规律，但在目前20人和C1上明显减弱，因此暂时还不能划成稳定的工人类别。我想先保留连续差异，结合已有复核区分局部执行问题和范围选择，再看哪些特征能稳定复现。
