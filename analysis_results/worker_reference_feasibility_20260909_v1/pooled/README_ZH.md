# 所有历史标注合并：不按旧阶段或条件划分工人

后续[三组及更多组的验证](groups/README_ZH.md)：训练内分位数分档/Ward分组、成员敏感性与同图人员组合覆盖，不以能分组代替类型已成立。

2026-09-09。按用户新要求，P1/C1/C2、block、Manual/Semi均不作为分组、筛选条件或拟合变量。此前分阶段结果保留为历史对照，本页回答合并后的问题。

**合并后，参考偏差显示一定的跨building可预测性，值得继续探索连续工人差异；目前不能据此宣布稳定的工人类别。** 当前20人上的收益较弱且对度量参数敏感。

## 数据及方法

- 全部2501条canonical仍在输入审计中，不恢复旧资格筛选。参考政策不变：人工复核优先，其余暂信GT；已知参考问题、OOS/范围未决和响应不可计算记录仍保留及说明，不能强行计为工人误差。不是因旧阶段或人员排除规则而舍弃这些记录。
- 沿用上一轮2027条可计分响应，覆盖184图、22个building、26人。两组同人同图各有两份不同context作答，分别计算参考偏差后取组内均值，形成2025个人—图单元；不平均坐标，也不将重复作答当成新人员。其余2023份作答均只对应一个人—图单元。
- 全部阶段和条件混合，只控制图像差异，学习每个人的一个总体相对偏差。每次留出整栋building，训练只使用其他building；留出图内同一可预测人员集合用于计算目标、预测和基线。
- 20张图只有单个可比人员，不能检验图内的人员差异。因此全26人验证是2005个人—图单元、164图、22个building；不是用2027当验证人数或独立样本数。
- 指标、原始角点保留、参考解释限制与父目录报告相同。没有新增3D合法性判断或视觉审查。

## 实际结果

表中是相对于“不区分人员”的基线，预测平方误差降低的比例；正数表示改善。单位等权是人—图单元等权，building等权是在每栋内部先取均值再合并，不能把它解释为正确率。

| 人员范围/指标 | 人—图单元等权 | building等权 |
|---|---:|---:|
| 全26人，OSPA30 | +15.60% | +10.71% |
| 全26人，OSPA60 | +14.07% | +7.57% |
| 当前20人，OSPA30 | +6.79% | +4.00% |
| 当前20人，OSPA60 | +5.34% | +0.37% |
| 全26人，匹配点平均角距 | +12.02% | +11.84% |
| 当前20人，匹配点平均角距 | +3.63% | +4.67% |

全26人的OSPA30在12/22个building中改善，OSPA60在11/22个building中改善，并非所有building都能获益。不含重复作答的敏感性分析，building等权OSPA30改善10.72%、OSPA60改善7.57%，与主结果相近。

单纯点数差的证据更弱：全26人绝对点数偏差的building等权改善仅0.27%，当前20人为−3.90%。因此不宜把“多标/少标几个角点”单独当稳定工人分类依据。匹配点平均角距不惩罚未匹配端点，不能用它一项代替整体质量。

## 怎么理解和推进

合并回答的是“在这批混合历史标注中，一个人在其他building上相对参考更接近还是更偏离，能否被其已有作答预测”。现在对此有正的探索性证据，不能用上一轮C1单独表现不佳，否定这个合并问题。

该结果属于当前历史资料和参考假设下的总体表现，包含当时可能获得的机器辅助、经验及任务接触条件；不能直接命名为人的固有能力。这里没有再次按这些条件拆分拟合，仅说明合并指标的含义。也没有建立building收敛人数预测、新人员验证或显著性结论。

下一步可以用合并后的连续工人画像寻找可解释的差异及反例，结合已有复核区分执行偏差和范围选择；类别数量、分类门槛以及是否与收敛相联系仍需进一步验证。尤其要关注当前20人对指标参数的敏感性。暂不为得到类别而反复调参。
