## 方法

复用父目录2025个人—图单元，来源2027条可计分响应，184图、22个building、26人。对全部26人及当前20人分别检验，按OSPA30、OSPA60两项参考偏差，比较2、3、4、5组。

- `quantile`：训练工人效应的分位数分档，人数相对均衡；同值不强行拆分。
- `ward`：对训练工人的一维效应使用Ward层次聚类，切成指定组数，不预设均衡人数。它允许小组或单人组；指定k后能切出k组，不是天然类别数的证据。
- 每次留出整栋building，重新拟合工人效应并重新分组，用训练内每组效应均值预测留出图内相对偏差；没有用留出响应确定切点或组均值。
- 按偏差均值从小到大编号，不命名为认真、粗心、高/低质量。此处组内个体差异被同一个组均值代替。
- 全量拟合成员表供解释及资料覆盖检查，不是独立验证所用标签。逐次删掉一个building后的成员一致性只是一种敏感性，不是独立人群重复验证。

人数不平衡不是自动否决理由；关键是小组能否代表可复用类型、提供足够独立人员和相同图像覆盖。三组方案在个别训练折里也可能出现单人组。边界附近人员换档，不能解释为其行为真的改变。

全26人的2组最稳定地区分出24人与W19/W26这2人；后两人不在当前20人中。这不是要求排除他们，而是说明历史总体的稳定分隔不能直接当作当前20人的类型结构。
