## 结论

本次核对259图3152份人员标注，全部重新对应原始导出验证坐标。没有发现原先2986份完整点对与周期x相邻配对候选之间的点对集合差异。现有1272份排序确认中，本次比较发现需因点对变化撤销绑定的数量为0。这不证明所有语义配对或曲线都正确。

**确实存在本轮程序缺口**：用户要求“没手动改的按x重配”，但配对页面此前只保存明确手改点对，没有计算和展示其余x配对；不能用用户未改动来声称已经执行了x重配。此次接收时已明确记录该语义，并生成“明确配对＋剩余x候选”独立文件，未覆盖冻结数据或旧排序证据。

## uNb9QFRL6hY-36的具体原因

W010、W013、W014在2026-09-23的研究输入中links_zero_based就是null。9月28日共享x生成器发现点集未变后原样沿用null；并没有重新跑x配对。此前诊断按y=255.5分上下角色，P1/P2的y约256.70、257.25，因此被分入下点，导致上下数量不等。

按原点x位置，上下点对候选为 **P1–P3、P2–P4、P5–P8、P6–P7**。W010/W013本次只显式记录了后两对，前两对应按用户新澄清规则补算；W014显式记录了全部四对。该图用户已明确提出复查，因此不能以checked简单结案。

P1等编号是源有效点数组身份，并非x从左到右的排名，更不是固定相邻编号配对规则。这里需要区分点号、上下配对、墙面连接环序。

## 曲线异常与后续

配错上下点确实可能扭曲共享x和3D；但本次未发现完整配对与x候选的普遍差异，不能把所有曲线异常归到x配对。上述局部空间的“上端点”位于中线下方，即使点对正确也不满足旧水平地面/顶部角色假设；曲线还是3D边的全景投影，跨接缝或接近极点也会显得奇怪。

旧“顺序队列完成”仅对旧配对基线成立，不能代替本次配对结果的应用验收。本次生成审计候选，不自动更换已确认点对身份；后续应用配对/删点时须重算共享x，按真实点对映射检查旧顺序可否沿用。
