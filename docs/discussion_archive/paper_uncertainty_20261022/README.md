## 3. 整体定位
**面向多人全景布局标注的基础性方法与实证研究。**

整体逻辑是：先厘清人工布局的标注目标与适用边界，建立针对人工缺陷的质量测量和异构布局共识方法，再利用真实多人数据解释人员、人数、构成与视角怎样影响共识及其可靠性。

“基础性”指为后续标注、共识、训练标签评价提供问题定义、方法与证据，不指 foundation model；不要求每个零件从零发明，也不以相关领域从未研究过任何类似问题为前提。

## 4. 六个贡献方向
### 4.1 面向人工布局的质量评价方法
**用户明确强调的重要方法贡献。**
人工原始布局可能在范围相近时仍存在边界位置、墙面方向、整体高度和局部上下界不一致。针对模型预测设计或常用的布局重叠评价，并不自然等于充分的人工标注评价。

当时区分了两层局限：
1. 常用均高棱柱式 3D IoU 的几何简化可能抹平局部高低差异。平均高度接近，不代表原始局部高度合理。
2. 即使精确体积 IoU，小体积但必要的凹口、短转折被遗漏，也可能仅造成很小的重叠损失。

当时讨论的 B8L2 分项包括范围重叠、底边球面偏差、自身 Manhattan 方向一致性、整体高度偏置与局部高度不一致。正文应解释定义、组合、设计理由、实际响应及局限，而非只在实验设置中列一个分数。

**验证与主张边界：**
- 自身正交一致性不等于相对参考结构正确；总分不能冒充完整的必要细节判定。
- 不能仅凭与 IoU 排名不同证明更好，应有具体缺陷对照、合理指标基线、分项消融或独立判断。
- 方向重罚、局部细节遗漏等负例应保留。
- 不把非线性分项解释成固定可加的权重贡献。

### 4.2 面向异构人工标注的完整结构共识
**用户明确强调的另一项方法贡献。**
输入包含不同角点数、不同局部简化、环序、上下点配对和周期坐标，输出须保留人员支持与完整连接，或明确失败/不完整状态。

需要展开的技术链条：
1. 对应：哪些观察属于同一墙角或局部结构。
2. 存在支持：哪些人表达了该结构，支持人数与门槛是什么。
3. 位置融合：结构存在后，它应位于何处。
4. 连接：达票结构怎样形成有来源支持的闭合布局。
5. 失败与可追溯性：保留原观察、人员、节点和边的证据。

贡献不应被简化为“取中位数”。但匹配—聚合—重组的通用思路有前作，需论证全景完整布局中的具体增量。对应拆组、跳接及人工辅助边界都属于方法评价，不能隐藏。

尤其不能只用自己设计的质量分证明自己的融合更好，应同时保留既有指标、结构诊断或独立人工判断。

### 4.3 门洞交界视角：任务、视点与表示的适用边界
**用户主动提出的概念，不能遗漏或退化为普通难度标签。**

几何动机：相机恰在门框交界，低门楣与两侧空间分隔使得单独选择任一房间可能不满足内部视点条件；合并两侧又可能超出当前单室表示。房间本身仍可满足 Manhattan 方向约束。

必须分开：
- 房间几何是否服从 Manhattan 正交假设；
- 标注目标是否唯一明确；
- 光心是否在所选封闭目标内部；
- 门楣、过渡区与高度变化是否可由当前表示容纳。

讨论中的工作定义：相机位于或接近连接室内空间的门洞过渡区，可能造成单室目标不唯一，或光心与所选封闭布局的内部视点条件不相容；各房间本身可以满足 Manhattan 几何。

**边界：**
- 门楣低一截本身不等于违反正交性。
- “不跨门框”是须明确的任务规则，不是所有布局研究共享的几何定律。
- 区分可标、目标歧义、当前规则下表示不相容、待核验。
- 未经光心/目标边界核验，不说所有案例都恰在分界平面，也不声称仅 Matterport3D 独有。

价值在于避免把目标冲突直接归因于人员能力差；融合前必须确认人员是否在表达同一空间目标。

### 4.4 区分原答分歧、稳定性、质量与完整性，并解释机制
分别测量：
- 原始作答差异；
- 同人数换人敏感性；
- 增人过程变化；
- 相对参考质量；
- 输出结构完整性与失败。

一致、稳定、正确不是同一个概念，也不能把这些现象直接称为已完成随机/模型不确定性分解。

当时代表案例：
- **G046**：共同遗漏必要细节，融合可稳定地遗漏。
- **G057**：8→9 人使票数门槛变化，已有节点失选。
- **q9**：同角观察被对应拆组，票数分散，进一步影响连接。
- 节点集合未变但位置中位数改变的情况。

研究增量是将原答—局部支持—对应/投票/位置/连接—结果变化串联，识别人群差异和算法放大；不是仅凭“加人不一定更好”宣称新发现。修复自身流程缺陷也不自动成为新算法贡献。

### 4.5 人员标法与构成的条件性作用
人员分类与换人换类属于正式主线，不应缩成附录，但不要求找到普遍可互换的人群。

先解释人实际保留、简化、分段、偏移什么，以及有哪些机会支持；再固定图片、采集条件、总人数、共同背景与实际换人数，比较同类、跨类、块替换及配比变化。

分开检验：
1. 类别能否解释原答及融合变化的规律；
2. 某一换类方向是否带来质量、效率或结构收益。

跨类变化更大不自动更好，同类变化较小不代表完全互换。记录平均效应、图/楼同向比例、成员与背景重复性、失败和坏尾。分类解释与替换用途分别验证。

**后续边界更新：** 10月20日的“Manual和Semi分别研究”不应被固化为禁止联合发现类别。后来用户允许同一人的两种历史联合分类；但目标楼须在两条件中排除，替换、融合、质量、时间和失败仍按 Manual/Semi 分别评价。

### 4.6 图片条件及同房多视角
短边、窄小结构、自遮挡、门洞等条件改变表达机会，不只是一个笼统难度分。

同房研究询问一个视角上的信息能否帮助理解另一个视角：
- 房间内不同视角的平均标注质量；
- 同一人的质量相似性；
- 结构表达的迁移；
- 定位偏移是否同样可迁移。

当时讨论强调结构与定位的迁移可能不同；用户后来进一步明确平均质量与个人质量相似性必须居于中心，不能只做结构研究。

保留实际图/楼/人员支持与配对口径；相关性不等于因果或新房间泛化。选队、停止与结构研究作为有价值的补充保留。

## 6. 初步章节规划（讨论方案，非最终目录）
1. **Introduction**：人工标注差异、现有测量与共识不足、核心研究问题。
2. **Related Work**：布局评价、结构化聚合、人员差异与不确定性。
3. **Data and Problem Formulation**：数据、任务范围、门洞交界、条件、参考和各不确定性对象。
4. **Quality Assessment**：质量方法定义、分项与组合理由、基线及效度。
5. **Structural Consensus**：对应、支持、位置、连接、完整性、失败和消融。
6. **Annotation Patterns and Worker Types**：实际标法、图片条件、类别解释。
7. **Consensus Uncertainty Experiments**：人数、换人、换类、块/配比、风险及机制。
8. **Cross-view Transfer**：同房平均/个人质量、结构与定位相似性；篇幅有限可并入实验。
9. **Discussion and Conclusion**：何时加人、换构成、检查对应，何时先澄清目标；参考、人员池和算法依赖。

第4/5是方法贡献，第6—8是实证贡献；门洞交界进入定义与场景分析。整篇论文不押在必须找到完美分类上。

## 7. 当时的原创性与投稿讨论
以下仅复述2026-10-20判断，不代表最新投稿建议或录用概率：
- 初版偏实证时：认真收束后的 C 类为现实方向，B 类有条件争取，A 类支撑不足；不是“稳中C”。
- 补入质量与共识方法后：定位更完整，更有争取 B 类的基础，但不能仅凭 foundation 定位推定 A 类。
- 核心差距是相对近邻工作的实质增量、验证强度与结论适用范围，不是团队枚举数量。
- 候选分类多不等于创新强；重复团队事件不等于独立样本。
- 应保留有竞争力的替代聚合/对应基线、关键结构语义证据与诚实的内部验证身份，不以无限补实验替代清晰贡献。
