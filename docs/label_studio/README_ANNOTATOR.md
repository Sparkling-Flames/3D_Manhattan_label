# 标注说明

这个项目会分几轮做。你只需要按当前这一轮的要求完成标注，下一轮如果有新的任务安排，会另外通知。

**请特别注意两件事：**

1. **每次开始标注前，都先检查 `log_time` 日志是否正常发送。**
2. **不要点击无关的 project，也不要打开没有分配给你的 task。**

因为系统会收集标注时间数据，乱点无关项目或无关任务会污染时间统计。

## 0. 浏览器配置（只做一次）

为了让页面里的脚本、3D 预览和日志接口正常工作，先在浏览器控制台把这几项配好：

1. 打开 Label Studio 页面，按 `F12` 进入开发者工具。
2. 切到 `Console`。
3. 输入下面的内容：

```javascript
// 这个值要和服务端的 HOHONET_LOG_TOKEN 完全一致
localStorage.setItem("HOHONET_LOG_TOKEN", "hoho-20260228-zjw200408250904!");

// 这里填你实际能访问到的 Helper / Nginx 地址
localStorage.setItem("HOHONET_HELPER_BASE_URL", "http://175.178.71.217:8000");
```

> 说明：
> 输入完成后，按 `F12` 打开开发者工具的 `Network` 标签，刷新页面，查看 `log_time` 日志。
> 如果能看到 `log_time` 请求正常发出，并返回成功状态，说明配置成功。
> - `HOHONET_LOG_TOKEN` 是日志接口鉴权用的，客户端和服务端必须一致。
> - `HOHONET_HELPER_BASE_URL` 指向当前这台机器对外可访问的 Helper / Nginx 地址。

## 1. 开始前

1. 如果发了浏览器脚本，就先按要求装好。
2. 打开任务前，先确认你现在做的是哪一轮、哪一类任务。
3. 不用管额外的系统细节，按当前页面要求标就行。
4. **每次开始前，先刷新页面并检查一次 `log_time` 是否正常发送。**
5. **只进入当前分配给你的 project，只打开当前分配给你的 task。**
6. 如果 `log_time` 没有正常发送，或者你不确定当前 project / task 是否分配给你，先不要开始标，先联系管理员确认。

### 1.1 开始前必须确认

- `Network` 里能看到 `log_time` 正常发送
- 你当前打开的是本轮分配给你的 project
- 你当前打开的是本轮分配给你的 task

如果上面任一项不满足，**不要开始标注**。

## 2. 任务类型

当前 prescreen 里有三类任务。

### 2.1 manual

- 这类任务没有模型初始化。
- 直接从头标。

### 2.2 semi

- 这类任务已经给了初始结果。
- 你只需要在现有结果上修正真正有问题的地方。

### 2.3 OOS

- 这类任务先看 `scope`。
- 如果确定是 OOS，重点选对 OOS 子类。
- 不要把明显不属于主房间的图硬标成正常布局。
- OOS 只要能把范围判断清楚就行，不用像 normal 一样细抠角点。

---

## 3. 标注规则

### 3.1 只标相机所在主房间

只标当前相机所在的主房间，不跨门洞，不并入相邻空间。

### 3.2 门洞规则

- 如果门框、墙垛、转角清楚，边界就停在这里。
- 看到门后空间，不代表要把门后空间一起标进去。
- 不要因为 3D 看起来更完整就主动跨门扩张。

### 3.3 什么时候选 OOS

只有在下面这些情况，才选 OOS：

- 几何假设不成立
- 边界无法判断
- 错层或多平面直接进入主包络
- 证据不足，无法稳定闭合

楼梯、开口、局部内凹本身**不自动等于** OOS。  
如果主房间仍能稳定闭合，还是选正常。

### 3.4 OOS 的标注要求

- OOS 任务优先保证 `scope` 选对。
- 几何不要求像正常任务那样精细。
- 不用为了让 3D 更好看去反复微调。
- 只要标注结果能表达“为什么这张图是 OOS”，就可以提交。

---

## 4. 标注步骤

**开始标注前，先点 `duplicate annotation`，在自己的副本里改。**

### 4.1 调整角点

1. 先看 2D 图。
2. 调整角点到墙-顶、墙-地交界处。
3. 同一面墙的上下角点要尽量垂直对齐。
4. 如果是 OOS，做到能支撑 `scope` 判断即可，不必过度细修。

### 4.2 检查 3D

1. 点击 `刷新 3D 视图`。
2. 检查房间形状是否合理。
3. 如果 3D 扭曲，先回到 2D 检查角点位置和上下配对是否对。

### 4.3 填写标签

#### `scope`

- 必填
- 单选

#### `difficulty`

- 可多选
- 只表示这张图为什么难标
- 不表示这张图是否 OOS

#### `model_issue`

- 只在 `semi` 任务里填写
- 可多选
- `manual` 不需要填这个字段

### 4.4 提交

检查无误后，点击 `Submit` 或 `Update`。

## 5. 常见问题

### 看不到 3D 窗口

- 检查脚本是否启用
- 刷新页面再试一次

### 3D 没有更新

- 确认已经点击 `刷新 3D 视图`
- 确认当前页面确实有角点

### 无法提交

- 先检查 `scope` 是否已填写
- 再检查是否有必填项没有完成

### 页面有问题

- 先刷新页面再试一次。
- 如果还是不行，截图发给管理员。

---

## 6. 需要记住的事

- `manual` 是从头标，不看模型点。
- `semi` 是修模型，不是重画一遍。
- OOS 情况下先判断范围，不要硬凑正常布局，几何大致即可。
- 只标相机所在主房间。
- 不跨门，不并房。
- 每次开始前先检查 `log_time` 是否正常发送。
- 不要点击无关的 project，也不要打开没有分配给你的 task，以免污染标注时间数据。

有问题时，先截图，再联系。
