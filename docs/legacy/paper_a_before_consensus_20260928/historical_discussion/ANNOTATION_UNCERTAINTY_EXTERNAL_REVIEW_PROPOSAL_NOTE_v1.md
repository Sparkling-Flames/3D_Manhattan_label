# 标注不确定性实验：外部审稿方案简要记录 v1

状态：`EXTERNAL PROPOSAL / NON-NORMATIVE / NOT ADOPTED`

本文只记录本轮收到的外部审稿建议，便于与导师讨论稿逐项比较。它不是本项目的裁决，不代表已经接受其中的假设、阈值、概率或统计层级，也不修改当前方法合同、统计分析计划、T1/V1、Label Studio 配置或任何分发工件。

## 一、它保留的总体框架

- Study 1：用历史高密度 Manual 数据描述标注者之间的结构化分歧。
- Study 2：用同图三臂 `Manual / Correct-Semi / Wrong-Semi` 研究预标注如何改变分歧和最终质量。
- 候选规模：72 张图，分 3 批，每批 24 张；每图每臂 5 人，即每图 15 份结果。
- 每名标注者候选负担：18 Manual、18 Correct-Semi、18 Wrong-Semi，共 54 次，保留少量替补容量。
- 元标签候选：二元 Model Issue、主要错误家族、required correction、1–5 confidence；其建议不增加 `unsure`。
- 第一批只检查运行、manipulation 和标签可用性，不用不显著的 outcome 结果提前判断正式效应失败。

## 二、它相对当前导师讨论稿提出的主要修改

1. 将 Correct-Semi 与 Wrong-Semi 的最终质量差，和三臂总体分布差，一并提升为确认性主假设，并对两个主检验做 Holm 校正。
2. 要求 Wrong proposal 具有可计算的刺激强度合同；提出 `U(correct)-U(wrong)=0.08–0.10` 作为待验证候选带。
3. 将四类 Wrong 等量配置解释为人为的 `equal-family experimental average`，不外推成真实模型错误比例。
4. 建议以 validity-adjusted pairwise distance 处理结构无效结果：任一结果无效时距离记为 1，同时报告 valid-only 敏感性分析。
5. 要求拓扑签名不只依赖角点数，还考虑转向序列、闭合、简单环、seam/cyclic 不变性。
6. 不把平均分歧必须下降设为成功标准；总体检验后再区分有益收敛、错误同质化和有生产性的分散。
7. 区分 Study 1 的 42 张来源池与当前 41 张高支持分析总体，并要求对持续多峰候选做盲审后才允许声称“多个合理真值”。
8. 将标注者几何/质量异质性降为次级描述；现有数据更支持时间差异，而非稳定的几何型工人类别。
9. 对 Wrong proposal 的错误家族识别同时报告无条件识别率和在 `material_issue=yes` 条件下的分类准确率。
10. 用 Brier score、校准斜率/截距等评估 confidence；按错误家族冻结“成功纠错”的操作定义。
11. 把必须先填元标签再编辑的 Semi 条件明确称为 audited proposal-assisted annotation，限制外推范围。

## 三、其中仍未被本项目接受的内容

- `0.08–0.10` 的 Wrong 严重度只是外部建议给出的候选锚点，尚未由本项目的正式刺激生成与可编辑性试验冻结。
- 72 图和 5/5/5 是运营候选，不是由最终冻结指标的真实方差完成的正式功效计算。
- 建议中的“无需 `unsure`”与当前 LS 本地配置不同；本项目目前正以开发测试检查现有标签，不在此记录中裁决是否删除该选项。
- 文本给出的成功概率属于规划判断，不是可验证的实验结果，也不作为启动依据。
- RQ、主终点、多重比较、错误家族和纠错规则最终仍须由导师确认后另行冻结。

## 四、与当前工作的边界

本次实际执行的仅是“现有 LS 标签可行性开发测试”：从已标注图片中取少量样本，让既有中文标注者复用当前页面并反馈理解困难。该测试不验证上述 72 图方案，不估计效应大小，也不产生论文分析数据。
