## 1. 研究问题与采集方式

- 观察人数增加后，标注是否进入统一共识、稳定多簇，或在当前观察人数内继续出现新标法；标注质量、质量增益、分歧大小和分布稳定分别报告。
- 用历史标注预测同一物理房间其他拍摄视角大概在多少人后稳定；预测人数范围，不要求同一个精确人数。
- 研究相似场景不同物理房间的标注规律和预测。同building保留基线，不自动等同相似场景。
- 探索可解释人员子类，检验具体子类的稳定过程；每人独立采集后，复用同图真实作答组合ABCD、ACD、AABC等比例。AABC中的两个A为不同人员，不为每个比例重新采集。
- 比较历史来源预测与加入旧d_t、d_model_feat、可取得HoHoNet冻结层特征的预测。旧d_t先核对是否含目标标注信息，不能把标注后信息当纯图像输入。

所选图先完成各自实际计划人数，再离线轮换图片的依据／检验角色，并重排或无放回抽人；两种随机操作分别记录。考虑5:5、6:4及小组枚举，多张检验图；划分可参考已有风险和人数，不用检验结果选择成功划分。跨房间验证时，该次检验房间的标注不参与拟合或调参。重复抽样不增加独立图、房间或人员数。

## 3. 当前已确认的方法边界

- 实际8人有效统一共识可判断为观察内收敛；8不是最低人数。少人数图保留，不补造20人、不强制各图共同人数，也不统一再观察5人。N≤2仍在库存，通常不据此判断持续稳定。
- 稳定多簇也算稳定。已支持簇至少2名不同人员，合理单人标法保留研究价值；点数不同一定分簇。q=.95、距离算法、比例变化容差及起点算法未定为最终方法。
- 空提交、缺角、坐标无效、算法未知、人数不足、观察内持续变化分开记录。不能删去失败后声称全体共识，也不能由个别失败推导永不收敛。
- 人工确认的补点／删点沿用逐份记录；原始点集不回写，未经确认的奇数点不自动修复。参考其他人补点的记录保留派生来源，并与不补点计算区分。
- 图片按图像本身与主要呈现空间分类，不按“应该标的空间”分类；功能区、分隔关系、门洞、OOS分别记录。先楼内同房，再跨房汇总类别；可边观察边分类，验证时记录分类版本。门洞局部问题不推翻整套已核实同房和场景记录。
- 人员候选包括质量、有效操作时间、规则表现、Semi行为的15种非空信息组合，多种组数；另保留质量＋时间＋修改幅度方案。质量不等于规则执行，Scope和最终裁定只辅助部分范围规则。最终方案和名单未选定，不强行均分或仅限两组。
- 历史全部人员和未来参与人员分别验证。W011退出后续，W019/W026排除当前主分析，其余历史不因不在当前19人名单而删除。旧26／20人结果保持旧分母，不删一个名字后改称19人实验。
