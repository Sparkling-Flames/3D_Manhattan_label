\section{相关工作}

全景布局估计通常把房间边界表示为天花板线、地板线和墙角序列，
其后处理还必须满足角点配对、拓扑闭合和 seam 连续性等结构约束
\cite{sun2019horizonnet}。因此，有效样本上的几何相似度不能替代结构有效率。

众包质量控制研究强调工人差异、任务差异和共识的不确定性
\cite{dumitrache2018crowdtruth}。本文进一步区分外部 GT 正确性与同行一致性：
前者用于 Strong Global，后者只用于兼容性审计、聚合稳定性和并列决策。

序贯分配同时涉及“推荐谁”“何时追加”和“何时停止”
\cite{li2017optimalstopping}。本文的 V1 将推荐排序与共享的调度规则分离：
两臂使用相同的候选池、超时、替补、容量和 GT-blind 聚合合同，
唯一的政策差异是 Strong Global 与 Full-Integrated 的推荐顺序。
