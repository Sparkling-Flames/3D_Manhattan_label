# HRC C6.5 Global Hypothesis Probe Specification v1

## 1. Purpose

C6.5 is a shadow-only / audit-only global hypothesis probe specification.
It is not C3 expansion, not a constrained_v0 implementation, not C7 optimizer work,
and not an active runner or ranking change. It defines the safety contract for a
future finite global probe planner.

No candidate is generated by this spec. No active runner role is authorized.

## 3. Allowed probe families, design only

These families are contract names only. They must not be executed or connected
to active selection without a later reviewed skeleton and audit.

### global_height_reproject

- Input requirements: ordered pairs, projection config, explicit height summary,
  projection metrics, case contract.
- Allowed variables: top_y / bottom_y for explicitly eligible pairs.
- Forbidden variables: x, pair order, topology, corner merge/delete, active source
  metadata.
- Expected diagnostic fields: height residual before/after, max y delta, pair fold
  risk, hard gate status.
- Hard gates: protected pairs, y permission, split-level/multi-height conflict,
  projection config validity, no writeback.
- Provenance fields: source artifact path + sha256, height target source,
  case contract source, probe family.
- Why shadow-only: it changes global height assumptions and can visually overfit
  without C4 evidence support.

### direction_family_azimuth_snap

- Input requirements: wall direction metrics, direction_family_fit,
  parallel_family_residual, projection config, case contract.
- Allowed variables: finite azimuth-like diagnostic perturbation parameters in
  a manifest only.
- Forbidden variables: direct annotation coordinates, topology, corner merge/delete,
  active runner selection.
- Expected diagnostic fields: direction residual delta, parallel residual delta,
  unresolved edge count delta, C4 evidence diagnostic status.
- Hard gates: missing direction heading, protected pairs, self-intersection, pair
  fold risk, C4 conflict flag.
- Provenance fields: projection metrics path + sha256, direction source fields,
  finite probe grid version.
- Why shadow-only: direction residual cannot dominate unresolved edges, local
  orthogonality, or image evidence.

### floor_depth_balance_global

- Input requirements: projection metrics with floorprint walls, depth/balance
  proxy fields, case contract.
- Allowed variables: floor-depth proxy parameters in finite dry-run proposals.
- Forbidden variables: topology mutation, pair merge/delete, annotation patch,
  optimizer loop.
- Expected diagnostic fields: wall residual delta, unresolved edge count,
  floor polygon residual, self-intersection status.
- Hard gates: self-intersection, protected pairs, pair fold, missing depth proxy,
  projection metric contract failure.
- Provenance fields: source artifact path + sha256, proxy method, coordinate
  contract.
- Why shadow-only: this is still geometry proxy, not depth-plane evidence or
  GeoLayout reproduction.

### multi_pair_x_alignment

- Input requirements: ordered pairs, explicit column identity evidence, keep-distinct
  contract, seam guard, projection config.
- Allowed variables: x-only finite alignment proposals for explicit eligible pairs.
- Forbidden variables: y, topology, pair identity change, merge/delete/reorder,
  seam-ambiguous mutation.
- Expected diagnostic fields: x residual delta, keep-distinct margin, order risk,
  seam risk, C4 diagnostic evidence.
- Hard gates: column identity unavailable/conflict, keep-distinct collapse risk,
  seam margin risk, protected pairs.
- Provenance fields: column identity source path + sha256, margin source, pair list.
- Why shadow-only: multi-pair x movement can collapse dense-but-distinct corners.

### short_wall_preserving_floorprint_balance

- Input requirements: short-wall diagnostics, floorprint walls, protected/keep-distinct
  pairs, projection config.
- Allowed variables: finite local/global floorprint balance parameters that preserve
  declared short walls.
- Forbidden variables: deleting short walls, merging dense corners, topology mutation
  by default, active runner selection.
- Expected diagnostic fields: short-wall preserved/collapsed/newly-created status,
  floor residual delta, unresolved edge count, local orthogonality.
- Hard gates: keep-distinct collapse, protected pair movement, pair fold,
  self-intersection, missing short-wall contract.
- Provenance fields: short-wall source, case contract path + sha256, probe grid
  version.
- Why shadow-only: short-wall plausibility needs manual/evidence review before
  recommendation.

## 4. Forbidden operations

- topology mutation by default;
- merge/delete/reorder corners;
- active source replacement;
- annotation patch/writeback;
- worker-facing UI;
- accepted/downstream recommendation;
- optimizer loop;
- adaptive parameter update;
- lightweight ranker;
- direct C3 third family implementation.
