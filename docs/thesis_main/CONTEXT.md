## 阅读说明

- 每条术语先给一句话解释，再补怎么读和容易混淆的地方。需要精确取值时，以对应专题的字段合同和表格说明为准。
- 同一个字母在不同专题可能表示不同东西：D 可指图片难度、固定背景成员或方向残差，H 可指几何自遮挡或高度损失，C 可指结构条件、类别或 ABC 中的跨类队。页面和公式要带中文全名或下标。
- 术语里的“不是／不等于”是在说明测量边界，例如某个分数没有测什么；它不表示相关结果没有价值。

## 核心术语速查

短释义用于图表附近，展开说明用于悬浮、键盘聚焦或点击查看。关键单位、分母、条件和版本必须常驻显示，不能全部藏进提示框。

|术语|一句话解释|展开说明|
|---|---|---|

|相机拍摄点位 / 投影中心|拍摄这张全景图时相机所在的位置。|本研究把该点作为几何投影中心，BEV 示意图画的是它在水平面上的投影。讨论门洞时，要看这个点位与所选目标空间、封闭截面的关系。示意位置不是实测位姿；门框在画面中央也不能推出真实点位。展示文字统一用“相机拍摄点位”，原始字段和引文保留原词。|

|Sb / 底边角距|候选与参考底边在球面上的位置距离，单位度。|按冻结实现做双向平均最近角距，越小越接近。它不是逐个同名墙角的距离；角点身份错误时也可能出现较小的 Sb。|

|3D IoU 代理|用底面和角点均高构成棱柱后的重合程度。|它是冻结实现中的代理量，不是任意非平顶实体的精确体积 IoU。局部高低抵消时，这个值可能不变。|
|有效转折|排除近共线分段后留下的转折。|难度包采用 5° 转折阈值；如果某个分类使用别的定义，要显示该方案的定义。转折多不自动代表标得更对。|
|短边|周长占比很小的边。|难度包定义为边长／周长 <4%，且两端转折均 ≥15°。它用来识别容易被简化的小结构，不是质量分项。|

|MV50 / 票门槛|一个对应组至少获得半数不同人员支持才保留。|按当前全队人数 N 计算，即 2×支持人数 ≥ N：20 人需 10 票，21 人需 11 票；N=18 时 9 票是半数、10 票才是严格多数。同一人不重复计票；保留所有过线组，不选最高票组。|
|完整率 / 可评分率|完整率看实际输出；可评分率看指定测量是否可用。|两者都不同于正确率。节点不足、连接失败等沿实际状态；缺合法参考、不适用、未执行和暂缓另列。Lee缺顶部不等于底面失败，OOS缺正式Q不等于没有输出。各率常驻注明适用范围与分母。|
|楼外历史 / LOBO|评价某栋楼时，只用其他楼的历史来形成信息。|用来检验跨建筑适用性。它不是同房专用，也不保证对陌生人员有效；同房指用户已有的房间关系，不是同一栋建筑。|
|ALL 名单 / 楼外名单|全历史名单用于描述人员；楼外名单排除当前建筑历史，用于实验。|同一个人在不同楼外折可能分到不同类别。实验必须读取对应折的标签，不能用全历史名单替代。|
|工作分类 / 真实父子类|工作分类按当前历史和研究用途分组；真实父子类指细类成员完全包含于一个粗类。|OPPJOINT每折K4均嵌套在K3中，但分裂的父类随楼外折变化。主质量方向可跨越粗类；其收益不能全部归因于增加第四类。|
|结构方法族 / 楼外角色|分类依据相同，具体分区会随训练楼折变化。|V3_BEHAVIOR 下的 TURN2/3 与结构 JOINT4/5 各自保留类数和特征含义；结构 JOINT 不等于 V3_JOINT_QT。跨楼按历史特征角色对齐，不能直接拼接同号类别。|
|配比格 / 格内波动|配比格：各类人数相同的一组团队；格内波动：这些团队换具体成员后结果的差异。|配比相同不等于成员相同。比较时要同时看格间趋势、格内分布和实际支持的团队数；单格只有一队时无法估计成员波动。|
|严格 ABC 匹配|原队 A、同类换人 B、跨类换人 C 共享同一批保留成员。|A=D+X、B=D+Y、C=D+Z；三队人数相同、实际替换人数 m 相同，X 与 Y 类别构成相同。C−B 用来区分类别调整与同类换人的效果；不预设一定升质。|

## 质量算法：输入、损失与参数分别是什么意思（2026-10-25 核对）

本节按冻结实现解释主分 B8L2。先记三句话：

1. Q 是对固定参考的 0—100 几何工作分，不是正确概率。
2. 五个输入分别看底面重合、底边位置、自身方向、整体均高和局部高度。
3. 底面损失与方向损失按二范数组合，高度损失另外相加；缺输入、缺参考或真实失败时 Q 为空，不能记 0。

完整提示词条见[研究台词典](../../research/workers/personnel_main_figures_v2_20261023/GLOSSARY.json)。这里只解释当前主研究，以及阅读历史结果时仍会遇到的名称，不把历史候选公式混成当前算法。

### 五个实际输入

|代码字段／符号|测量什么|单位和读法|
|---|---|---|
|`iou_2d` / I|候选与参考底面的交集面积除以并集面积。|0—1，越大越重合；`iou2d100` 是同一指标乘 100。它不评价顶界和高度。|
|`S_bottom_deg` / Sb|候选底边与参考底边在球面上的双向平均最近角距。|度，越小位置越接近。它不是逐个同名墙角的距离；角点身份错误时也可能很小。|
|`dir` / D_dir|候选墙边相对自身最佳正交轴系、按底边长度加权的方向均方根残差。|度，越小越规整。轴系来自候选自身，不是 GT 墙向。|
|`Hmean`|候选沿底面周长加权均高与参考均高的相对绝对差，即 `abs(μ候选−μ参考)/μ参考`。|无量纲。0.1 表示整体均高相差参考均高的 10%；正负方向另查 `height_mean_ratio−1`。|
|`Hcenter`|扣掉整体均高差后，比较局部高度轮廓的双向相对均方根残差。|无量纲，越小越接近。`center` 指去掉均高，不是房间中心位置。|

`Hcenter` 的计算分四步：

1. 沿候选和参考双方的底面周长采样；
2. 按最近的底面位置匹配两边的高度；
3. 对两个方向分别求均方残差，平均后开方；
4. 再除以参考均高。遇到等距多解时，沿用最大平方残差规则。

临时高度平移只用于测量，不修改布局，也不证明匹配点属于同一语义墙面。`Hmean` 用边长加权均高；3D IoU 代理用角点均高，是另一种汇总方式，两个值不能直接互换。

### B8L2 怎样合成 Q

对 `I>0`，当前实现等价于：

```text
底面综合损失 F = (1/I − 1) + Sb²/32
方向损失 Ld = 1.5 × D_dir²/(D_dir² + 8²)
整体高度损失 G = (Hmean/0.8)²
局部高度损失 L = (Hcenter/0.25)²
Q = 100 / [1 + sqrt(F² + Ld²) + G + L]
```

各项在说什么：

- `F` 把底面区域不重合 `(1/I−1)` 与底边位置 `Sb²/32` 合并成一个底面损失；
- `Ld` 是方向损失，最大 1.5；
- `G` 和 `L` 分别是整体高度与局部高度损失；
- 分母里的 `sqrt(F²+Ld²)` 是二范数组合，不是各误差项按固定百分比相加。

Q 取 0—100，越高表示相对当前参考和规整要求的综合误差越小。`I=0` 时实现取连续极限 Q=0；缺输入、缺参考或真实失败时 Q 仍为空。B8L2 中的“8”对应方向尺度 8°，“L2”对应底面损失与方向损失的二范数组合。

|实现参数|当前值|它实际控制什么|
|---|---:|---|
|`direction_scale_deg`|8°|方向惩罚随残差增长的速度。方向残差等于 8° 时，方向损失达到上限的一半 0.75；这不表示 8° 以内都合格。|
|`direction_cap`|1.5|方向损失的渐近上限；不是从 Q 里扣 1.5 分。|
|`bottom_scale_squared_deg2`|32 平方度|Sb 平方项的除数。Sb 约为 5.657° 时该项为 1；不是 32° 容差。|
|`global_height_scale`|0.8|整体均高相对误差的换算尺度。Hmean=0.8 时 G=1；不是允许 80% 误差。|
|`local_height_scale`|0.25|局部相对高度残差的换算尺度。Hcenter=0.25 时 L=1。|
|`pooling_order`|2|F 与 Ld 按 `sqrt(F²+Ld²)` 组合；高度损失另行相加，没有一起池化。|
|球面采样数|每向 2048|底边距离数值积分的采样设置，不是质量容差或标注点数。|
|局部高度采样数|每向 4096|局部高度残差数值积分的采样设置，不是人数或几何合格线。|
|输出倍数|100|把质量映射到百分制；不是“结构正确的百分比”。|

例如仅整体均高相对误差为 0.8、其他项理想时 Q=50；仅方向残差为 8°、其他项理想时 Q 约为 57.14。例子用来说明尺度怎样改变损失，不是推荐可接受误差。

**D10** 沿用上述五个输入和合成方式，只把方向尺度 8° 改为 10°。相同几何下，它对同样的方向残差惩罚较轻，分数可能更高；这不表示标注或融合变好。已有补充区分两种情况：固定结果改用 D10 评分，以及按 D10 重新形成类别和选人；覆盖身份见[独立验收](../../research/statistics/research_closeout_20261022/METHOD_SUPPLEMENT_ACCEPTANCE_20261024.md)。

## 统计、预测与分类方法的术语补全

|名称|用普通话解释|研究中怎样读|
|---|---|---|
|MAE（Mean Absolute Error）|每次预测差多少，取绝对值再平均：`mean(abs(预测−实际))`。|预测 Q 时单位是分；预测 60、实际 70，单次绝对误差是 10 分。比较不同模型须使用相同目标、样本和聚合权重。|
|RMSE（Root Mean Squared Error）|先把误差平方、平均，再开方。|对大误差更敏感，单位与被预测量相同；不能把 RMSE 和 MAE 当同一个指标排名。|
|Bias / 有符号偏差|平均预测减实际，保留高估或低估方向。|正负可以抵消，接近零不保证每次都准。|
|Pearson r / Spearman ρ|Pearson 看数值一起线性变化的程度；Spearman 看排序一起变化的程度。|范围都是 −1 至 1。正相关不等于数值相等，也不等于预测误差小；看表时先确认用的是哪一种。|
|R²|相对声明基准的平方误差改善程度。|常见形式是 `1−残差平方和/总平方和`，可以为负。面板内相对变化的 R²，不等于陌生图片绝对 Q 的预测能力。|
|SD / 标准差|一批结果围绕平均值有多分散。|Q 的 SD 单位是分；它不是估计均值的不确定度，也不同于几何波动 V。样本不足 2 个时不可估。|
|P10、P50、P90 / 分位数|分布较差端、中位位置、较好端的代表值。|Q 的 P10 越高，通常表示低尾越好；分位带描述结果分布，不是置信区间。|
|置信区间 / bootstrap 重抽区间|按声明的抽样单位反复重抽，观察统计量有多不确定。|要注明按建筑、图片还是路径重抽；探索选型后的区间仍保留其内部分析身份，不等于外部验证。|
|Permutation / 置换参照|打乱指定关系，看随机参照下能产生多大差异。|必须保留设计约束，例如在同一来源内置换；它不是重新采到一批独立人员。|
|ARI|两套分类把相同人员分在一起的程度。|1 为相同，0 约为随机参照，也可能为负；类别编号换名不影响 ARI。|
|η²|固定结果的总变化中，配比格之间均值差占多少平方和。|算法是组间平方和÷总平方和；它描述配比能解释多少差异，不是预测准确率。总体没有变化时无定义，不称准确率。|
|Ward 层次聚类 / K|按特征相似性逐步合并人员；K 是最后保留几组。|可以切粗、细层；稳定切分不自动证明存在永久的天然类型。|
|连续特征 / 残差特征|保留原始连续数值／扣除规定图片或组平均后的相对表现。|同图中心化减少图片基线差异，不等于消除了所有混杂。|
|收缩估计|历史少时更多靠总体水平，历史多时更多靠个人记录。|用来减小小样本极端值对预测和选人的影响；具体权重由对应模型定义。|
|端点|一支确定团队的保存输出。|同图同人数、同规则下的一次完整融合结果。同一端点可以被多个事件引用。|
|路径|一次人员进入顺序。|一条自然或角色优先顺序，每个 k 形成一个前缀；路径之间共享成员，不能当作独立人员样本。|
|事件|一次对照，例如一次换人或一次换类。|事件有自己的 A/B/C 或前缀端点；事件数不是独立图片数，也不是独立团队数。|
|面板|固定研究条件内的一组比较。|固定分类方法、图片/图对、n、m、背景和候选池后的一组团队；面板内比较不能直接外推到陌生图片或新人员。|

### 自然人数主曲线怎样平均

**自然256保留每个目标池内的随机顺序身份。** 冻结v2为194个Manual池（177个普通图池、17个门洞池），原48条加独立208条；历史形成与核验见[256条人数曲线审查](../../research/statistics/pro_return_review_20261023/population256_20261027/README.md)。v2.1另接[新版自然人数结果](../../research/data/releases/v2.1/natural_results/README.md)、[两人点](../../research/data/releases/v2.1/two_person_natural256/README.md)和其它合法目标的分池结果。历史V3四种角色优先策略使用32条配对基础顺序，与自然256分别读取。

固定一张图片的实际人员池，每次随机打乱全体人员；同一条顺序内，每人只出现一次。依次取前k人的集合，按冻结算法从这组原答重新完成对应、投票、定位和连接。每个前缀都使用当前k人的原答，不把前一步融合输出当作新人的原答继续累积。相同团队再次出现时可以复用计算结果，但统计时保留出现次数。

平均分两步：

1. 在同一图片、同一k上，对多条路径的可评分Q求均值、P10和标准差；
2. 在声明的固定图片范围内，对上述逐图统计量等权平均，不同难度分别查看。因此总体P10曲线是逐图P10的平均，不是把所有图片的团队合并再取一次P10。

失败不填0。真实融合失败使用适用且已执行的尝试分母，未计算、缺参考等状态另列；某张图在该k没有可评分输出时Q留空，并报告实际有Q的图片数。比较人数区间时固定具有相应容量的图片集合，并注明共同可评图片；沿同一条路径的配对变化与两个成功子集的边际均值差是不同统计量。旧v2普通Manual的N≥30为157图、N≥35为92图；v2.1读取自己的逐池支持，已补的两人点不再写作当前缺口。展示保留低人数至实际满员。

**256条是蒙特卡洛顺序数，不是人员数或bootstrap次数。** 均匀随机排列在固定k给每个k人子集相同抽取概率；不同顺序可以抽中相同团队，所以随机曲线按实际出现次数计算，不能先去重再让每队一样重。单人、缺一人、满员及已经完整列出的有限小池，采用完整目录的精确有限边际；只有这些目录才按每支团队等权。研究同一次进入过程仍保留路径配对，独立边际不能替代实际路径。

旧v2的例子是：固定157张普通Manual图，3→6人平均Q提高4.914分，155图提高；实际失败率同时增加1.655个百分点。固定27张困难图，20→30人平均Q变化−0.175分，低尾P10提高4.246分、Q标准差降低4.676分；分别有24图低尾提高、25图标准差降低。均值、较差结果和换组波动回答不同问题。门洞17图6→10人平均Q下降1.006分，同时实际失败率下降13.534个百分点，17图的失败率都下降。

**抽样精度与团队波动分开读。** SD描述固定人数下团队本来有多大差别；MCSE描述有限随机顺序让均值估计有多大误差。增加进入顺序主要减小估计误差，增加每队人数则改变团队分布。固定157图的3人点，均Q的MCSE大于1分的图片从旧48条的122图降到256条的20图；P10经验区间半宽大于2分的仍有76图，单图低尾比总体均值更难估。路径重抽评估当前人员池内的抽样误差，建筑重抽考察换一组建筑后汇总有多大变化；两种区间各自标明，不能把前缀数或几何距离对数当成独立图片数。

满员时所有顺序回到同一成员集合及端点。相应指标可用时，有限团队分布的SD和几何波动V为0；无可用输出时保留缺失。这个零说明没有其他满员团队可换，不说明原答一致或布局准确。历史V3角色优先策略在相同最终池内调整进入先后，使用32条成对基础顺序，阶段比较固定共同人数点和图片权重。OPPJOINT已有小池精确策略，按自己的目标池和顺序报告；全库新家族策略尚未完成，历史32条不改称新家族验证。

旧24/48条、53个重点池的96/304条结果保留为历史及敏感性比较；旧48的困难20→30均Q+0.016等数字保留历史身份，当前比较应使用对应版本的结果。历史wc2-46案例仍解释有限目录的价值：96条路径虽然见过全部28支缺一人团队，出现频次仍不均，随机样本P10为97.387，完整目录等权后为52.406。增加bootstrap次数不会补出新的随机顺序，也不会修复少见团队尚未充分抽到的问题。几何V的随机路径估计与精确目录分母详见[几何口径核验](../../research/workers/personnel_population_curves_v2_20261023/sampling_precision_20261025/local_audit/geometry/README.md)。

## 共识中的点、失败与页面缺数据

墙线融合可以按四步读：

1. **对应**：把不同人员指向同一结构位置的观测连成身份组；
2. **投票**：按全队人数 N 判断每个身份组是否达到 MV50；
3. **定位**：对保留的组，用支持者位置的中位数估计坐标；
4. **连接**：用来源环序把保留节点连成闭环。

对应组不是已经认证的物理墙角；逐节点达票也不等于整环达票。

|名称／状态|发生了什么|页面显示什么|是否算真实失败|
|---|---|---|---|
|ERP|经纬展开的全景图，水平方向是方位角，竖直方向是仰俯角。|原图与布局叠加。|不适用；图上直线或曲线形状不能直接判断真实墙面是否弯曲。|
|Manhattan / 曼哈顿约束|主要墙方向属于相互正交轴系的布局假设。|布局的轴向与正交关系。|不适用；斜墙或多层顶底要单独判断，不能只看边线倾角。|
|节点 / 上下点对|一个竖向墙角对应一个上端点和一个下端点。|节点、点对和入选/失选状态。|不适用；完整评价至少 4 个节点，即 4 对／8 个图像点，不是 8 个不同墙角。|
|身份组 / 对应组|算法认为来自不同人员、指向同一结构位置的一组观测。|组成员、支持人数和票账。|不适用；误合并或误拆也会改变票数，组名不代表语义已确认。|
|来源建议环 / 连接|利用来源作答的环序，为入选节点寻找可采用闭环。|来源环、直接邻接和投影邻接。|不适用；逐节点达票不等于整环达票，未人工确认与算法未连成环是不同状态。|
|节点不足 / below_four|投票后保留节点少于 4 个。|入选、失选、支持票账。|是，属于当前规则下无法形成完整结构共识。|
|连接失败 / connection unavailable|节点数量够，但没有满足当前要求的连接。|实际节点、候选连接和失败原因。|是；不能擅自补线，也不能改称“点数不足”。|
|无效几何 / geometry unavailable|候选自交、退化或缺少所需几何。|保存的具体几何原因。|是；原答或部分诊断仍可能有研究价值。|
|参考缺失 / 评价不适用|输出或作答可能存在，但当前参考不足以评价，或 OOS 不宜用于正式质量排名。|缺失的是参考、资格还是用途。|否；不作为人员分歧或共识失败计数。|
|未计算 / policy deferred|该设计没有执行某次融合，例如既有人数研究的 2 人阶段。|状态标记和设计说明。|否；不是观察到的失败，不并入真实失败率。|
|未加载、未接入或上下文不兼容|页面当前图片、条件、参考或快照没有可加载的保存案例。|资料连接状态。|否；不能据此认定研究没算过或人员分歧大。|

**共识失败是结果，不应只显示成空白。** 节点支持不足和连接失败可以正面回答“这些人能否形成完整结构共识”；把它们与原答差异、身份组、支持票和门槛一起解释，才能说明人员分歧怎样进入输出。它们会发生在普通图和门洞图，不专属于门洞。资料缺失、评价资格与真实融合失败分别保存，缺 Q 不补零。

**结果层面的两个量：**

- `D(N)`：该图完整人员池按固定规则形成的实际共识，与参考的范围差异；越小越接近参考。
- `V(N)`：同人数换一组人后，融合结果的变化；越小越稳定。

满员时只有一个全员集合；唯一有效底面存在时有限总体`V(N)=0`，否则保持缺失，不证明原答一致、正确或人数最优。零波动也可以稳定地偏离参考：已有案例中，8→16 人时底面 1−IoU 从 0.1754 降到 0.0726（更稳），D 却从 0.2197 升到 0.2465（更远）。

**重名符号要带上下文：** D 可表示图片难度、保留背景成员或方向残差；H 可表示几何自遮挡代理或高度损失；C 可表示结构条件、类别或 ABC 中的跨类队；K 为类数，k 通常为前缀人数，在部分同房表中另指历史人数。页面显示中文全名，公式使用 `D_dir` 等有区分的名称。

## 当前口径：分类输入与效果条件分开（更新 2026-10-24）

**分类输入**可以是 Manual、Semi，或同一个人的 Manual＋Semi 联合历史。**效果评价条件**仍分 Manual/Semi，分别检验换人／换类、融合、质量、失败和时间。条件间特征联合时，保留来源、机会和缺失，目标建筑在两侧历史中同时排除。早期文档中“不得混合拟合”的限制已经取消，不再作为分类发现的约束。

**特征联合分类**（例如已核的 Manual 结构＋Q＋T 五类）和**跨采集条件联合分类**（Manual＋Semi）含义不同。现有单条件分类及质量／时间收益完整保留；跨条件联合已有 XCOND_GEOM、XCOND_GEOM_QT、XCOND_PAIRED 等历史候选及结果，现在按四套工作分类各自保留。2026-10-24 另完成 D10 联合类重拟合敏感性，未替换正式名单。

**替换实验条件**指分类方案、类别方向、n、m 和背景，不是新的分类方案。三组优先替换条件是具体实验条件，不是分类总目录，也不是淘汰名单。详见[人员总记录](人员标法分类与换类研究_总体进度_20261020.md)。

**读法：** 先看分类用什么历史特征、名单是 ALL 还是楼外折；再看固定了哪些条件（图片、n、m、背景、候选池）；最后才读质量、时间、结构和失败。三者混在一起，容易把“分类解释力”和“某次替换的效果”当成同一件事。

## 对象与条件

**人员作答**：某个人在一张图片和一种采集条件下提交的一份布局观测。每份作答绑定人员、图片、条件、时间与坐标；同一个人可以在多张图、两种条件下出现。

**图片条件**：图像显示的结构、遮挡、拍摄位置，以及可能的范围或边界解释。人工难度是对这些条件的一个判断。
_容易误读为_：把图片的平均参考误差直接称为固有难度。

**参考 GT**：有明确版本、明确目标口径的参考布局。它可能有遗漏、错误，也可能对应另一种可用范围解释。
_容易误读为_：不加区分地把 GT 差异都称为人员错误。

**Manual／Semi**：无模型预标注与有实际模型初始化辅助的两种采集条件。Semi 中的模型初始化是作答条件，不是另一名人员。

**OOS**：场景不符合当前标注标准，尤其曼哈顿或单一顶底面等假设。GT可能为产生符合约束的输出而将边界放在不符合真实结构的位置，因此不能用接近GT给OOS人员作正确性排名。边界可辨认或底面一致仍不恢复in-scope。斜墙／平面非正交、斜顶、多标高天花板、多标高地面等原因分别记录，可以并存；画面出现某结构与该结构纳入实际标注目标也分开。用户确认x8-01／09为G231同房的斜墙视角，另确认b8-19为斜墙，现共3图/2房间；角度不确定，不固定写成135°；这类可清晰表达，OOS标签不预定人员分歧大小。当前独立统计与人工复核见[28图清单](../../research/difficulty/difficulty_mechanisms_v2_20261020/scope_closeout_20261022/OOS_REVIEW_20261024.md)。

**门洞交界（2026-10-26用户澄清）**：相机在门框正下方或两个区域交界处拍摄。核心问题是拍摄点位与既定单室布局表示的相容性：两侧房间本身可以满足Manhattan方向约束，但在严格单室闭合规范下，仍可能无法同时忠实表达真实结构、目标范围和有效布局。画面中有门、是否跨门标注，均不等于这一拍摄条件。

相机恰位于所选单室的封口边界时，不满足当前表示要求的“拍摄点位严格位于目标内部”；部分方向不能获得该目标的正距离边界。移动封口会改变实际几何，合并两室则改变目标范围，门楣及两侧顶底高度还可能无法由单层顶底表示忠实表达。这里的关键发现是：房间满足Manhattan约束，并不保证该拍摄点位下存在符合任务规范的单室标注。

[Bi-Layout](https://liagm.github.io/Bi_Layout/pdf/3739.pdf)的enclosed／extended区分在开口处停止与向可见区域延伸的范围政策；本研究的门洞交界问题是上述拍摄点位引起的表示冲突，不能用两种范围政策概括或视为已经解决。OOS侧重场景结构本身超出当前标注标准；门洞交界侧重点位，两个属性分别记录，实际可重叠。

为满足输出格式而人为封口、忽略结构或移动边界，可形成受约束的近似标注；GT存在不证明严格可标，也不据此把参考差异全部归为人员错误。逐图是否确属这一退化情形仍沿已有证据判断，历史“可标／难标／未定”和参考资格不批量改写。用户指出MP3D中此类拍摄常见，当前不据此给出未经逐图统计的全库比例。

**可标性**：在当前目标和表示下，能否给出清楚、可执行的标注。门洞按可标／不可标／未定分别记录；“难标”不自动等于“不可标”，未记录也不等于已认证可标。可标性、人工难度、GT 适用性和实际一致性要分别观察。

**范围差异／细节差异**：范围差异是选了哪些空间；细节差异是同一范围内保留了哪些局部结构。一份作答可以同时存在两者；讨论难度或正确性前，先固定范围。

**历史 GT 结构粗难度（2026-10-09 工作定义，不是当前自动判级规则）**：在有效 GT 下，四点对且无结构自遮挡记简单，多于四点对且无结构自遮挡记中等，有结构自遮挡记困难；D=1/2/3 只是序数编码。这里的遮挡指声明实心墙底面模型中的射线横穿，不是 DINO／RGB 识别，也不包含所有家具或弱边界困难。OOS、门洞交界、可标性及暂停状态与结构类并列；特殊图单列展示，未知不补成普通。全体结构类总数不能当作普通图片的三档数。原图及旧判断对照见[21 图审查材料](../../analysis_results/objective_difficulty_20261009/review_examples/README.md)；主观核对不自动改写原分类。

**当前难度解释（2026-10-22）**：采用已有人工辅助粗分，并用转折、短边、几何自遮挡和定位负担来解释。超过四对点不自动判中等，H>0 也不自动判困难；研究单位绑定图片、目标范围／参考和作答条件。详见[难度与范围收尾](../../research/difficulty/difficulty_mechanisms_v2_20261020/scope_closeout_20261022/README.md)。

## 人员、团队与融合

**人员画像**：跨可比较图片的参考表现、时间、适用性判断及 Semi 修改行为等分项描述。
_容易误读为_：把一次上下半分组当成永久人员能力或已验证的天然类型。

**人员构成**：团队中不同候选人员类型的人数或比例；AABC 指这类构成，不指四份空间标法。

**单一融合共识**：对一张图、一个具体人员组和一种固定规则产生的一份融合结果；输出类型随方法而异。
_容易误读为_：用最大作答簇，或每簇各取一个结果，替代该人员组的完整融合。

2026-10-06 用户补充：共识应体现大家的观察，不保证必须像 GT。接近参考、保留合理结构是评价维度，不是用 GT 或一个精细个体反向改票的理由。rPc 玻璃外侧／内侧墙面可以是不同合理目标；yq 所示 P023／P010 是同结构细节偏差、P002 是简化，具体绑定见[局部人审](../../analysis_results/consensus_response_20261006/boundary_followup/user_review.json)。

**BEV**：底面空间的俯视表示。Lee 区域投票是融合方法，BEV IoU 是评价量，三者不同。

**原作答一致性**：不同人员实际提交的作答彼此有多接近。范围主量是固定全员并集归一化的两两对称差平均 R，辅以距离矩阵中的形态；它是主要观察，不能被融合稳定性替代。
_容易误读为_：固定池均匀随机抽组时，把期望恒定的组内平均两两距离，解释成人数必然改善或恶化一致性。

**融合范围的人员选择稳定性**：固定图片、人数、构成与融合规则，改变具体人员后，融合区域变化的大小。
_容易误读为_：把它简称为原始人员意见一致，或直接称为人员随机噪声。

**增人变化**：保留当前团队并加入一名剩余人员后，融合结果的变化。它和“同人数换人”回答不同问题：一个看加入，一个看替换。

**留出作答差异**：未参加当前团队的一名同池人员，其原作答与当前融合的差异 H；这是已有诊断量。它既不是增人后的融合变化，也不是未来新人员风险或标法数量。

**参考接近程度**：在声明的测量对象和参考版本下，作答或融合结果与参考的差异。
_容易误读为_：由范围接近推出完整布局、局部细节和三维都正确。

**全员融合结果**：该图当前完整纳入人员池，按固定规则产生的实际共识。实际范围／布局和 D(N) 是核心产物；唯一全员底面可用时V(N)=0，只是因为不存在另一个全员组；不可用时保留缺失。它既不证明正确，也不使实际全员输出／失败状态失去研究价值。

**空间候选**：有观测来源、表达一种范围或细节选择的完整布局备选。人数支持和几何可用性不单独决定其语义合理性。

**局部观察片区**：由一份已存在作答的短路径与端点直连围成，用于跟踪融合怎样保留凸出或填入内收的固定区域。当前两处为 Pro 事后选择，本地已接人数／构成；它不是空间候选、局部 GT、角点身份票数或通用细节准确率。

**角点身份簇／整份作答簇／人员子类**：分别指对应点分组、布局标法分组和人的分组；三者的成员单位不同。

2026-10-07 用户进一步澄清：**整份标法簇研究的是表达结构和细节选择。** 当前定义保留“不同点对数必分簇”，包含近共线墙面上增加装饰节点的情况，不预先删除共线点来抹去这种差异。同点对数不保证同标法，仍需看位置、对应和环连接。同一空间可以有不同标法；不同标法也不自动意味着错误、不同真实空间或不同人员能力。范围／上下定位质量另行评价。

**完整上下布局共识**：包含实际融合的上端、下端、配对和新环连接。Lee 底面区域是范围基线，不补猜顶点后冒称完整布局。独立端点、绑定点对和锚定混合是不同方法条件。

**多数支持与参考质量**：融合表达当前人员按声明规则支持标在哪里；自动融合不读取 GT，也不按最高 GT 分数挑输出。人工身份判断可以参考 GT，但须保留来源，不能宣称全部人审独立于 GT。最新[投票机制说明](topics/fusion/共识投票机制与三路线推进_20261007.md)区分以下口径：实体角表达支持、位置组人数、上下边际支持、共同原点对支持、上下边界和整对连接支持。

**点 MV50 投票**：对算法建立的候选身份组按不同人员计票，支持数 s≥ceil(N/2) 便保留，N 为完整纳入人员数。当前[交付](../../analysis_results/consensus_delivery_20261008/REPORT.md)先用逐作答匹配及原环建立对应，再投票、融合全部来源位置；历史绑定／独立原型主要按位置相容性成组。它不是只选最高票组，也不按精确坐标数票，算法组也不等于已认证实体。N=18 时 9 票是半数达票，严格多数为 10 票；未进入某组不能自动解释为反对真实墙角。自动与人工辅助分开保存。

**标法差异与定位差异**：是否表达某个墙角、采用哪种边界目标、空间范围或连接，属于结构／目标层面的标法差异；对应到同一实体角后，坐标分散先作为定位差异描述，不因距离大就自动新增一种标法。uNb-26／41 最新[人工判断](../../analysis_results/adaptive_point_20261007/expanded/USER_REVIEW.md)确认红色与蓝色是不同墙角，41 右下六份红色原点对为同角位置差异。这不改变“不同点对数分不同表达簇”的约定，也不认定同点数必为同标法；算法距离簇数不能直接等于语义标法数。

**局部自适应混合**：原有混合路线的一种具体化。根据局部对应证据，选择绑定点对或上下独立融合，再为已确定配对协调周期 x。2026-10-07 已有[原配对关联组件 v1 九图实验](../../analysis_results/adaptive_point_20261007/REPORT.md)，不是已验证的通用选择器；rPc 已知身份问题仍未修复。不能把点集中直接解释为同一实体角；同角离散与不同角间隔要分开。绑定原型本来就分别估计两端 y，真正的增量要说明对应、来源成员、配对、定位中哪一项改变。探索完整上下输出，不意味着点方法已被选为主试验方法。

**研究基准标注／处理前坐标**：用户认可的共享 x、已确认配对及既定环序，构成当前研究基准标注；导出原点另外保留。晚共享 x 实验只恢复处理前上下坐标，沿用配对、人员和顺序，融合后再投影到竖直点对；这不等于撤回全部清洗。共享 x 是当前竖直墙角表示的要求，不是所有三维表示都必须采用的规则。

**有限池人数响应**：在现有人员池中改变人数或构成得到的结果变化；池耗尽后的唯一结果，不证明未来新人员也会一致。

后续[41 橙／紫来源讨论](../../analysis_results/adaptive_point_20261007/expanded/g184/USER_REVIEW.md)进一步区分：同一墙线身份可以明确，上下端目标仍未定。位置差异是可测事实；“纯定位误差”或“不同标法”需要额外的目标依据，遮挡下不强行二选一。对上端偏高与下端偏低使用同一标准，算法颜色组不作为语义类型标签。
