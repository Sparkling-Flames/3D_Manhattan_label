# 全景标注不确定性研究：术语

本页固定研究用语；统一关系和状态见[研究模型](研究模型_人员图片与融合不确定性_20261006.md)。术语不替代已有人工裁决。

## 对象与条件

**人员作答**：某个人在一张图片和一种采集条件下提交的一份布局观测。

**图片条件**：图像所显示的结构、遮挡、拍摄位置及可能的范围或边界解释；人工难度是对这些条件的一个判断。
_避免_：把图片平均参考误差直接称为固有难度。

**参考GT**：明确版本、明确目标口径的参考布局；它可有遗漏、错误或与另一种可用范围解释不同。
_避免_：不加区分地把GT差异称为人员错误。

**Manual／Semi**：无模型预标注与有实际模型初始化辅助的采集条件。Semi中的模型初始化是作答条件，不是另一名人员。

**OOS**：相对当前任务假设的适配问题，不等于边界看不清或无法标注。非正交但清晰可标（已有x8-01／09）与结构／高度等表达困难分别记录；OOS标签不预定人员分歧大小。

**门洞交界**：相机处于门洞或门框交界附近的拍摄条件，可能造成范围或边界难定，也可能清楚可标、人员一致。房间仍可满足曼哈顿约束，与OOS分别记录并允许重叠。

**可标性**：当前目标和表示下能否给出清楚、可执行的标注。门洞可标／不可标／未定分别记录；已有“难标”不自动等于不可标。可标性、人工难度、GT适用性与实际一致性分别观察。

**范围差异／细节差异**：前者涉及选了哪些空间，后者涉及同一范围内保留哪些局部结构；一份作答可同时存在二者。

## 人员、团队与融合

**人员画像**：跨可比较图片的参考表现、时间、适用性判断及Semi修改行为等分项描述。
_避免_：把一次上下半分组视为永久人员能力或已验证的天然类型。

**人员构成**：团队中不同候选人员类型的人数或比例；AABC指这类构成，不指四份空间标法。

**单一融合共识**：对一张图、一个具体人员组和一种固定规则产生的一份融合结果；输出类型随方法而异。
_避免_：用最大作答簇或每簇各一结果替代该人员组的完整融合。

2026-10-06用户补充：共识应体现大家的观察，不保证必须像GT。接近参考、保留合理结构是评价维度，不是用GT或一个精细个体反向改票的理由。rPc玻璃外侧／内侧墙面可为不同合理目标；yq所示P023／P010为同结构细节偏差、P002为简化，具体绑定见[局部人审](../../analysis_results/consensus_response_20261006/boundary_followup/user_review.json)。

**BEV**：底面空间的俯视表示。Lee区域投票是融合方法，BEV IoU是评价量，三者不同。

**原作答一致性**：不同人员实际提交的作答彼此有多接近；范围主量为固定全员并集归一化的两两对称差平均R，辅以距离矩阵中的形态。它是主要观察，不能被融合稳定性替代。
_避免_：固定池均匀随机抽组时，把期望恒定的组内平均两两距离解释成人数必然改善／恶化一致性。

**融合范围的人员选择稳定性**：固定图片、人数、构成与融合规则，改变具体人员后，融合区域变化的大小。
_避免_：把它简称为原始人员意见一致，或直接称人员随机噪声。

**增人变化**：保留当前团队并加入一名剩余人员后，融合结果的变化。

**留出作答差异**：未参加当前团队的一名同池人员，其原作答与当前融合的差异H；已有诊断量。它既不是增人后的融合变化，也不是未来新人员风险或标法数量。

**参考接近程度**：在声明的测量对象和参考版本下，作答或融合结果与参考的差异。
_避免_：由范围接近推出完整布局、局部细节及三维均正确。

**全员融合结果**：该图当前完整纳入人员池按固定规则产生的实际共识。实际范围／布局和D(N)是核心产物；V(N)=0只因没有另一全员组，既不证明正确，也不使该结果失去研究价值。

**空间候选**：有观测来源、表达一种范围或细节选择的完整布局备选；人数支持与几何可用性不单独决定其语义合理性。

**局部观察片区**：由一份已存在作答的短路径与端点直连围成、用于跟踪融合怎样保留凸出或填入内收的固定区域。当前两处为Pro事后选择，本地已接人数／构成；它不是空间候选、局部GT、角点身份票数或通用细节准确率。

**角点身份簇／整份作答簇／人员子类**：分别指对应点分组、布局标法分组和人的分组；它们的成员单位不同。

2026-10-07用户进一步澄清：**整份标法簇研究表达结构和细节选择。** 当前研究定义保留“不同点对数必分簇”，包含近共线墙面上增加装饰节点的情况；不预先删共线点抹去这种差异。同点对数不保证同标法，仍需位置、对应和环连接判断。同一空间可以有不同标法；不同标法也不自动意味着错误、不同真实空间或不同人员能力。范围／上下定位质量另行评价。

**完整上下布局共识**：包含实际融合的上端、下端、配对和新环连接。Lee底面区域是范围基线，不补猜顶点后冒称完整布局。独立端点、绑定点对和锚定混合是不同方法条件。

**多数支持与参考质量**：融合表达当前人员按声明规则支持标在哪里，自动融合不读取GT，不按最高GT分数挑输出；人工身份判断可参考GT，须保留来源，不能宣称全部人审独立于GT。最新[投票机制说明](共识投票机制与三路线推进_20261007.md)区分以下口径：实体角表达支持、位置组人数、上下边际支持、共同原点对支持、上下边界和整对连接支持。

**点MV50投票**：对算法建立的候选身份组按不同人员计票，支持s≥ceil(N/2)便保留，N为完整纳入人员数。当前[交付](../../analysis_results/consensus_delivery_20261008/REPORT.md)先使用逐作答匹配及原环建立对应，再投票、融合全部来源位置；历史绑定／独立原型主要按位置相容性成组。不是只选最高票组，不按精确坐标数票，也不把算法组当作已认证实体。N=18时9票是半数达票，严格多数为10票；未入某组不能自动解释为反对真实墙角。自动与人工辅助分开保存。

**标法差异与定位差异**：是否表达某个墙角、采用何种边界目标、空间范围或连接，属于结构／目标层面的标法差异；对应同一实体角后，坐标分散先作为定位差异描述，不因距离大自动新增标法类型。uNb-26／41最新[人工判断](../../analysis_results/adaptive_point_20261007/expanded/USER_REVIEW.md)确认红色与蓝色是不同墙角，41右下六份红色原点对为同角位置差异。这不改变“不同点对数分不同表达簇”的约定，也不认定同点数必为同标法；算法距离簇数不能直接等于语义标法数。

**局部自适应混合**：原有混合路线的一种具体化，根据局部对应证据选择绑定点对或上下独立融合，再为已确定配对协调周期x。2026-10-07已有[原配对关联组件v1九图实验](../../analysis_results/adaptive_point_20261007/REPORT.md)，不是已验证的通用选择器；rPc已知身份问题仍未修复。不能把点集中直接解释为同一实体角；同角离散与不同角间隔分开。绑定原型本就分别估计两端y，真正增量需说明对应／来源成员／配对／定位何者改变。探索完整上下输出不意味着点方法已被选为主试验方法。

**研究基准标注／处理前坐标**：用户认可的共享x、已确认配对及既定环序构成当前研究基准标注；导出原点另外保留。晚共享x实验仅恢复处理前上下坐标，沿用配对、人员与顺序，融合后再投影到竖直点对；不等于撤回全部清洗。共享x是当前竖直墙角表示的要求，不是所有三维表示都必须采用的规则。

**有限池人数响应**：在现有人员池中改变人数或构成得到的结果变化；池耗尽后的唯一结果不证明未来新人员也会一致。

后续[41橙／紫来源讨论](../../analysis_results/adaptive_point_20261007/expanded/g184/USER_REVIEW.md)进一步区分：同一墙线身份可以明确，上下端目标仍未定。位置差异是可测事实，“纯定位误差”或“不同标法”则需要额外目标依据；遮挡下不强行二选一。对上端偏高与下端偏低使用同一标准，算法颜色组不作为语义类型标签。
