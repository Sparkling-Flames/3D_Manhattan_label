# 可直接粘贴给 Pro：全景区域与质心偏移的独立文献调研

请执行以下文献研究。不需要压缩包，不要假定能访问我的本地仓库或原图。先独立研究方法和证据，再评价现有实现；不要沿着以前Pro的结论寻找支持。没有视觉能力时不要裁决具体标注是否正确。

## 背景

我们研究360°室内等距柱状投影（ERP）全景布局标注。多人标记墙角与天花板/地板交点；每个已确认上下点对取周期水平坐标中点，垂直坐标不变。坐标以1024×512计，左右相接。存在遮挡、复杂房间及简单墙带不能表达的作答，不能强制规整为Manhattan后当作原始数据。

导师与我提出用GT相对IoU及面积质心偏移研究标注质量，进一步区分人员与图片差异。IoU＋质心是我们的设想，不是Lee论文给出的公式；是否组合、如何加权尚待验证。多人区域共识是另一层问题：随真人数量增加，共识如何接近GT。人员分类、真实人员组成和进入顺序仍保留。

当前基线：相邻上下边界用空间直线投影为ERP曲线，两条边界之间形成二维墙带；对照采用ERP直线插值。“复用曲线算法”描述区域构造，不是质心定义。当前在512×256统一栅格计算二值墙带IoU及等像素权面积质心，距离换算至1024×512；另算水平圆周一阶矩方向和集中度R。普通ERP质心受接缝影响；圆周方向在R接近0时可能不稳定。一阶矩向量距离、角度差、像素位移不能混用单位。

数据起点3019份、259图，Manual/OOS/Semi分开。GT为原始Matterport3D及研究者修订版，全局30张实质修订中28张在当前面板内；HoHoNet/BiLayout双头是模型参考，不是GT。先行曲线＋修订GT诊断中，Manual可评价2185/2265份，绝对垂直质心偏移中位数2.58px、P95 11.70px；圆周水平方向换算中位数14.06px、P95 268.86px。这只是未调整图片效应的成功条件描述，不能预设尾部都是真实错位，也不能称人员能力。本轮不提供原始数据，不能从汇总验证个体原因。

## 请独立回答

1. **区域应怎样构造？** 检索全景布局评估、球面分割和全景标注的原始文献及官方实现。比较空间直线投影、ERP直线、球面弧、可见表面/墙带，以及条件允许时的平面或三维布局表示。说明几何前提、配对与点序要求、遮挡及复杂/非星形房间的表达限制。不能将弯曲边界笼统称为样条或大圆，须核验公式和投影约定；不能仅凭二维点虚构真实三维连接顺序。
2. **不同“中心”分别衡量什么？** 调研面积质心、周期/圆周统计、球面一阶矩、内在/外在均值及其他有依据的位置描述。区分等ERP像素面积、球面立体角加权、真实表面面积与地面投影面积：测量目标和额外输入各是什么？中心是否存在、唯一，退化如何报告？为何适用于环绕相机一圈的墙带，而不是直接移植普通局部目标方法？
3. **质心提供了IoU之外的什么？** 查找分割/形状比较中位置、尺度、形状差异的分解，以及有依据的边界/位置指标。可检索边界距离、表面距离、距离变换、形状矩、运输距离等，但不堆指标名单。区分目标检测框中心与不规则区域面积质心，不能把框回归损失直接当成熟区域指标。给出同中心异形、同IoU不同位移、共同漏画及面积不平衡反例。
4. **能否解释为人员质量或不确定性？** 区分GT相对误差、稳定偏差、跨图波动、人图交互与单次作答随机性；如何控制人员所标图片不同？人工修订GT可能带来什么依赖？目标图GT可评价，但不得用于同图赋权/选阈值后再宣称外部有效。文献支持组合IoU＋位置指标，还是只适合并列报告？允许结论为质心不值得加入权重。
5. **与共识构造如何衔接？** 阅读导师推荐的Lee等2018《Aggregating Crowdsourced Image Segmentations》：https://ceur-ws.org/Vol-2173/paper10.pdf 。区分区域表示、真人支持率、聚合算法和GT评价四层。质心评估不是分簇，也不是论文tile构造。STAPLE、MAP-STAPLE、MACCHIatO等仅在相关时讨论，不能因其输出共识就推断更接近独立GT；完整报告或源码拿不到时如实列缺口。
