## 二、任务A：全量清查与整体异常候选

逐份对账3019份起点的原始点、有效点、版本、条件、绑定、借用、排除与待定状态。共享 x 在每份作答的每个已确认上下点对内计算，考虑左右周期接缝；y保持原值。不能跨人员平均坐标，不能把少量 x 偏差当作无需修正的理由。无法绑定的作答保留原因。

清查目标是非墙角、乱标等明显无效作答。恢复角点数量、配对、现有环序3D诊断、顺序线索及异常/单人小簇通道；逐份记录证据，旧标签仅在当前点集与配对一致时复用，点击顺序不等于真实环序。各通道取并集，不能以IoU作为唯一入口。另增加“角点配对正常但整体远离所有参考和其他人”的辅助筛查：同时输出与每种可用参考的差距、最近参考差距、同图同条件其他独立人员的全部差距及最近同行差距、可用同行数。同行不含自己、重复版本、已知借用导致的非独立副本；多种模型输出不算多份独立证据。数值候选按最近参考与最近同行差距共同排序，并输出全量表，不能只展示最差若干条。

**数值异常只生成复审候选，不自动删除。** flags、低IoU、模型自交、配对失败、GT冲突各自记录。明确既有人工错标裁决只有在作答及版本绑定明确时才应用；文字里的暂缓、未决、可选答案不能改成排除。选图／邀约不采用不等于删除历史作答；少数不同范围解释不等于乱标。没有视觉能力时不得断言“墙后遮挡”“故意乱标”等图像事实。输出复审问题和所需叠加图，交研究者与有视觉能力的本地助手裁决。

清洗前后结果并列，每人明确无效作答比例另报，避免删除差作答后把人员表现高估。未经本轮裁决的候选进入“保留候选”的主分析及显式敏感性版本，不能静默消失。

## 三、任务B：区域、IoU与质心的实际量级

主候选为全景空间直线投影曲线构造的二维墙带；二维直线连接是敏感性对照。核对已有几何函数的坐标约定，采用像素中心、统一分辨率与周期 x；人员、GT、HoHoNet、BiLayout enclosed/extended 用相同构造方式。二维上下边界的水平排列只是该表示的操作，不证明恢复了完整房间拓扑。同一方位多层边界等表示失败单列。

报告面积IoU、遗漏/多画、top/bottom边界差、面积质心偏移。质心使用区域像素面积，不使用角点平均；同时比较普通二维质心与水平圆周质心，保留圆周集中度。接近整圈墙带时，水平中心方向可能不稳定，大位移不能直接解释成整体大偏差。圆周一阶矩向量差可作为诊断，但不得称作像素位移。用1024×512等效像素、水平角度及归一化量报告中位数、分位数与逐图值，不能只给相关系数。

执行共同水平循环平移、微小边界扰动、同质心不同形状、跨接缝、分辨率变化的检查。曲线/直线、原始/修订GT分别报告。生成普通例与反例的区域叠加和质心箭头供本地视觉审查；无原图时明确仅为几何图。不要预先认定质心有价值。先分别分析IoU与质心，再比较仅IoU与组合指标；目标图GT不能用于给该图人员赋权。

建立人员×图片测量表，按共同图片比较及人员/图片效应区分分配差异；报告覆盖不足。一次同人同图作答不能独立识别该人员的重测随机波动；不把逐图STAPLE参数直接称为已剥离图像效应的人员能力。

## 四、任务C：Lee区域共识及替代方法

必须显式说明 `角点→区域→支持率→算法共识→GT质量`，分别保存真人支持率、合成区域、GT相对质量。Lee的tile思想是按多人区域重叠分块并聚合；固定栅格逐像素多数投票是该栅格上的等价实现，不要求另建复杂矢量分块器。

| 方法 | 实验要求与命名边界 |
|---|---|
| Lee 多数投票 | 支持率≥0.5为主，>0.5作平票敏感性；固定域，不逐法裁剪画布 |
| actual medoid | 返回一份真实成员作答，最小化到其他成员的平均Jaccard距离；并列按canonical ID确定，不用GT选代表 |
| 单正确率EM／greedy | 只有核对实现后才能标为适配版本；每人一个正确率且限制>0.5不是标准STAPLE；Lee完整技术报告尚未取得，不声称完整复现 |
| 标准STAPLE | 明确敏感度、特异度和真值先验；优先成熟实现，记录版本、概率阈值、迭代与失败，不用自创EM冒名 |
| MAP-STAPLE | 弱性能先验与外建筑校准先验分开；不能把STAPLE一个参数调整称为MAP，也不能把IoU直接填入敏感度/特异度 |
| MACCHIatO-Jaccard | 平方Jaccard距离的Fréchet目标与启发式优化；作者代码入口已知但本任务开始时尚未取得可核查源码。先获取核验，失败如实报告；不能用medoid或多数票冒充。邻域、连通分量、形态距离均须适配周期x，且不能承诺全局最优 |

仅用现有作答的方法与外建筑质量校准方法分组。分类、权重、先验、阈值只用目标建筑外的数据建立；目标GT只作最终评价。IoU加权和IoU＋质心加权的差别单独评价。GT oracle只作明确标记的诊断上界，不进入可部署方法排名。

分簇是独立因素：全体聚合对照最大簇聚合，保留其他簇及人数；横轴k仍是实际收集人数，另报使用人数。几何规整是后处理对照，不能一开始强制全部结果为Manhattan后归功于聚合器。

所有算法共用人员子集、当前前缀、区域、GT版本和图片面板。前k人不得读取未来作答确定tiles/分区或人员参数；固定全景栅格可预先定义。共同固定人数范围内使用固定图片面板，报覆盖变化。失败不丢分母：成功条件均值与成功/失败计数并报，无法定义分值的失败不得伪造IoU为零或成功；明确可定义的空输出按同一IoU规则处理。

曲线至少有：共识GT质量、增人后的区域变化、同人数不同组合差异。算法比较使用同图同成员的配对差值，建筑为主要泛化分组，重放与像素不算独立样本。固定集合的确定性算法终点相同是机械事实，不据此宣布质量上限。人员组合研究只重用真实独立人；同房预测继续保留，以已知房间绑定为准，不能把同建筑自动当同房。HoHoNet失败/复杂度与BiLayout双输出差异作为难度候选，用人类质量与曲线验证，不用模型自我一致性替代人工质量。
