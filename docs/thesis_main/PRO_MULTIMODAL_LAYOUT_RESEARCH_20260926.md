## 5. 表示、排序与投影：先验证上游

明确分开：原始点击编号、上下角点配对、物理邻接／环序、边的投影方式、区域填充、指标计算。任何自动处理都要保留其输入输出与失败状态。

1. 循环更换起点通常不改变闭合布局；改变实际邻接可能改变布局。按顺序首尾相连会天然形成闭环，但闭环不证明拓扑、可见性或物理邻接正确。单纯按 x 排序只有在布局可由该方式表示时才有效，同一方位多边界、隐藏角、遮挡或退化不能静默修复。
2. 区域重建失败不等于人员错误。重排序与移动角点是不同操作；展示原始几何和调整后几何，不能只展示最小残差解。
3. 在理想单中心球面成像中，三维直线与相机中心确定的平面和球面相交于大圆，ERP 展开一般为曲线。采用水平平面反投影时，还须检查其平面假设、射线方向和接缝处理。
4. skybox 是可用于渲染或表示方向的立方体映射；不能仅因存在六个面就自动推出实际图像拼接模型，或据此选择任意样条。Matterport 源图是否可按共同中心、已校正姿态和给定投影使用，须依据实际数据及官方资料验证。
5. 区分有几何依据的投影曲线、ERP 直线近似、图像证据驱动的边界估计及强制几何规整。当前合同保留曲线主候选和直线敏感性；探索其他方式不改变正式主候选身份。

小规模比较至少包含：现有连接算法、周期 ERP 直线对照、已确认邻接的空间直线投影，以及必要时单独标记的约束重建后再投影。若两种名称不同的方法在当前条件下数学等价，应说明等价性，不制造虚假方法差异。投影细节需由几何审查结果补充，本文不声明已核验当前所有实现。

## 6. IoU、质心、残差与 RMSE 分别测什么

请建立明确的“输入对象—坐标／尺度—参考—失败条件—输出含义”表，不以指标名称代替定义。

| 指标候选 | 必须明确的对象 | 需要证明或反驳的用途 |
|---|---|---|
| ERP 墙带 IoU | 配对与环序生成的上下边界所夹区域；固定栅格及周期接缝 | 区域差异是否被忠实表示，局部细节是否被总体面积稀释 |
| ERP 面积质心 | 当前展开图中面积一阶矩；不是角点坐标均值 | 是否提供 IoU 之外的有用诊断；接缝敏感性是否使跨图比较失效 |
| 圆周／球面质心 | 周期方向、面积权重、集中度或向量模长 | 是否存在低集中度退化；不能把不稳定方向直接换算成可靠位移 |
| 地面／体积 IoU 与质心 | 共用相机坐标、尺度和有效闭合几何 | 对真实占据范围是否更直接；不能用地面指标声称检查了 top y |
| 墙方向残差 | 原始地面边相对共同 Manhattan 坐标系的方向差 | 能否诊断连接／定位异常，何时只是在惩罚真实非正交结构 |
| 墙高残差 | 共同地面、相机高度及天花板假设下的估计墙高 | 高度不一致源于定位、模型不适用还是实际多层结构 |
| 点位 RMSE | 已建立身份对应的角点；缺失与额外点单独处理 | 能否表征位置误差，是否被不完整匹配或点数差异低估 |
| 边界／深度 RMSE | 同一物理对象或明确同方位规则下的曲线／深度 | 范围分歧是否被错误解释为点击误差；采样和尺度是否公平 |

IoU 与质心由同一个错误 mask 派生时，加入后者不能恢复上游已经丢掉的拓扑信息。3D 残差由同一组点得到，也不是独立扫描证据。可以研究三者联合，但先并列报告，再比较加入每一项是否产生稳定增益；不得先赋予质心固定正权重。

RMSE 必须先说明“与什么比较、哪些实体对应”。不可仅按数组下标配对，也不可把未匹配点悄悄丢弃后称整体误差很小。真实额外墙角、冗余细分点和遗漏结构应分别处理。相对 GT 的三维误差与自身模型拟合残差必须分栏。

存在多种经独立确认的合理参考时，可探索集合参考评价，例如在相应语义类别内比较最接近的有效参考，同时报告采用了哪种解释及覆盖情况。不能把所有观测簇都加入有效参考，以此让每个参与者自动正确；也不能只保留最容易提高平均分的参考。

## 7. 对几何规则的具体审查要求

### 7.1 共同方向、相机姿态和阈值

墙方向残差应相对共同的水平旋转角 α 定义，例如：

`r_i = min_k |wrap(theta_i - alpha - k*pi/2)|`。

α 应由明确的共同坐标或稳健拟合获得，不能将相机 x／y 轴天然当房间主轴，也不能每条墙独立旋转以得到零残差。明确相机滚转／俯仰、地面平面及相机高度的处理。

用户粘贴材料中 `<0.5°`、`0.5°–1.5°`、`1.5°–3°`、`>3°` 是第三方经验建议，未在本任务中校准。不得直接用于人员排除、真伪判断或正式分级。相邻正交、对边平行与共同方向残差可能共享信息，应检查重复计权；非四边形房间也不能直接套用“四点房间的对边”规则。

### 7.2 短边、近点和误差传播

屏幕上两点接近不保证三维距离接近。设地面边向量为 ΔP、长度 L、法向单位向量为 n_perp，点差协方差为 Sigma_delta，一阶方向方差约为：

`Var(theta) ≈ n_perp^T * Sigma_delta * n_perp / L^2`。

这解释了为什么相同位置噪声对短边会产生更大角度变化。接近地平线时，地面距离 `r = h*cot(v)` 的导数绝对值为 `h*csc(v)^2`，深度不确定性也会放大；所用 v 的定义和有效范围须与实现一致。

请比较原始方向残差、边长、投影敏感性以及经合理噪声模型归一化的诊断。噪声模型未知时只能做明确范围的敏感性分析，不能伪称置信区间已校准。不能靠无限放宽阈值让错误短边通过，也不能靠长度加权让所有小细节失去影响。

### 7.3 近 180° 与删除中间点

三点近共线不等于中间点标错。对三维地面相邻点 A、B、C，应检查 B 到线段 AC 的偏离、B 的投影是否落在线段内部、删除后的上下边界／范围／连接语义是否等价。地面近共线还不保证天花板边界或墙高表达等价。

使用循环邻接检查首尾；ERP 左右边界仅是展开接缝。不要通过 ERP 中看起来近直线、夹角近 180°、局部面积贡献小或点数过多自动删点。若删除是表达简化，原始点与映射应保留，且单独检验其是否确实保持评价区域不变。

## 8. 多模式与多级共识的比较路线

保留当前合同中的全体聚合与最大簇对照；新增多模式路线是额外研究，不将分簇改为所有方法必须经过的前提。

| 路线 | 最小实现／研究对象 | 要检验的失败方式 |
|---|---|---|
| A：单输出基线 | 复用合同中的 MV 两种平票、真实 medoid 及已核验的其他基线 | 把不同范围折成不合理中间解，或丢掉少数模式 |
| B：完整模式保留 | 保留不同完整标法，各模式先选真实代表，再研究模式内聚合 | 分簇受表示或阈值支配，近似模式被过度拆分，少数有效模式被吞并 |
| C：最大／最小点数增删 | 将用户提出的两个极端作为搜索起点，记录每次增删及支持证据 | 点数与范围不单调；候选非嵌套；两端搜索错过第三种完整解释 |
| D：局部支持与结构约束 | 同一范围／结构解释内统计局部支持，显式保持合法邻接 | 独立局部 MV 拼出没人支持且自交／断裂的混合布局 |
| E：几何规整敏感性 | 原始几何与明确约束拟合版本并行 | 残差变小但点离开真实墙角，或强制删掉真实非正交细节 |

“层级”需分成不同轴：支持强度层、范围模式层、细节分辨率层及证据有效性状态。范围模式不一定嵌套，不强迫构成由小到大的树。支持率和有效性状态不压成一个等级。

局部支持分母需解释：采用另一种范围的参与者可能没有该局部的可比投票资格；缺失、不可评价、明确不支持和不同范围选择不能统一当反对票。保留完整模式支持，防止局部投票丢失特征之间的共同出现关系。

BiLayout 的 enclosed／extended 可作为明确范围歧义的概念对照及可视化启发。请阅读原论文定义并逐图核对，不能把现有任意两个簇自动命名为这两类，也不能把该网络两头当独立真值。要检查其双头表示是否足以表达用户现有案例，或只能覆盖其中一种歧义。

## 9. 必须交付的小规模反例与受控实验

先构造最小、可公开复算的几何例子，再选择少量真实案例。合成输入明确标为合成，不替代真实人群实验；本节列出的是待运行检验，不是已取得结果。

| 检验 | 已知不变或已知变化 | 应观察的证据 |
|---|---|---|
| 同墙边增加准确中间节点 | 实际几何不变、点数改变 | 区域／深度保持不变；点表示差异可另记 |
| 循环更换起点与共同移接缝 | 相对物理几何不变 | 周期区域指标不变；ERP 质心若变，明确诊断限制 |
| 同质心异形与对称扩张 | 范围显著变、质心可不变 | IoU／局部差异检测能力，质心不可辨识反例 |
| 同 IoU、同质心、不同局部差异 | 全局摘要相同 | 证明联合摘要仍不足，检验空间差异图 |
| 只改 top、地面保持不变 | 上边界／墙高变化 | 地面指标失明，相关边界／高度诊断应响应 |
| 尺寸错误但完美正交 | 自洽但不接近已知真值 | 小 Manhattan 残差不能证明质量 |
| 真实斜墙与小凸起 | 相对真值正确但不完全 Manhattan | 不应由正交先验直接判错或抹掉细节 |
| 同像素扰动、不同边长／地平线距离 | 操作误差相同、空间敏感性不同 | 原始与不确定度诊断的差异 |
| 非嵌套的多种范围 | 点数／范围无包含顺序 | 最大／最小搜索是否遗漏完整候选 |
| 局部多数与完整模式冲突 | 局部特征均获多数，但联合未被支持 | 是否生成不合法混合；如何保留依赖关系 |
| 群体共同错误与少数正确细节 | 支持与正确性分离 | 多模式保留是否可同时揭示两者 |
| 重排、退化、自交、同方位多边界 | 有些输入不在表示能力内 | 显式失败和来源，不静默删行或归罪人员 |

真实案例面板应包含 `B6ByNegPMKs-11` 待核模式、同墙冗余点、局部小凸起、范围不同、GT 存疑及多层／非正交场景。先绑定当前版本和原图，再决定是否符合预设案例类别，不能为了凑类别改解释。已经用于本轮方法开发的案例不作为全新外部验证集。

## 10. 实验控制、输出与允许失败的结论

比较方法使用相同 canonical 作答、人员子集、进入顺序、图片面板、坐标、栅格及参考版本；一次尽量只改变一种因素。Manual／OOS／Semi 按合同分层，借用补点不计独立票，原始与人工修订 GT 使用同一划分分别报告。

当前前 k 人的输出只能用当前可用标注及预先可用的外部校准，不使用未来人员建立簇或选择候选。参数、人员权重与阈值在目标建筑之外拟合；目标 GT 仅用于评价，oracle 单列。推断单位按图片／建筑设置，不把像素、墙段或大量重放次数当独立人群样本。

保持缺失、表示失败、无参考、拟合未收敛、方法不可用、明确人工错误和待定分开。共同可评价集的配对结果与全范围覆盖／失败率同时报告，防止“只剩容易的图”造成假改善。

至少返回以下内容：

1. **问题定义与证据表**：实际输入、版本、参考和权限边界；逐条回应第 3 节假设；明确哪些现有源码／数据确已检查。
2. **最小代码与输入**：复用仓库函数；针对真正非平凡的几何性质留下最小可运行检查；给出实际命令与环境，不添加未使用框架。
3. **反例结果**：本节小实验的实际数值、几何真值和失败解释；无法运行的项标明原因，不用文字推导冒充实测。
4. **真实案例对照**：同坐标全景、俯视和 3D 视图；显示采用的配对／环序；控制叠色，能区分原始、参考与候选范围；交付图与临时 QA 截图分开，临时截图检查后清理。
