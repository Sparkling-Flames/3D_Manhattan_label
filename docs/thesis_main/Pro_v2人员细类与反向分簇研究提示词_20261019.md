## 方向一：Q、T与难度形成可解释细类

**难度要作为人员细分依据之一，而不只是最终结果的分层报表。** 例如整体高Q且快、困难图表现较好、困难图相对自身普通图更强、质量稳定但慢、绝对质量高但困难图相对优势不足。这些是候选现象，不是预定答案。区分“难图绝对质量高”“同难图相对别人好”“相对该人平常表现更好”，报告各自支持图数、建筑数和不确定性。难度标签沿用冻结人工审核及其来源，说明评级者是否见过作答；不根据本次融合结果反调难度。

- Q仅表达标注几何质量。保留绝对交付画像（均值、中位数、低尾、离散及分项）与相对质量，比较同图同条件同参考百分位、同任务中心化差值、任务调整/部分汇聚模型等合理基线。解释各自解决什么、损失什么，特别是排名对同伴构成、同分及不同任务池的依赖。不要只凭某模型更复杂而采用。
- T同时讨论直观的固定秒数阈值与同任务相对速度。当前60/180秒、90/240秒都是探索阈值；至少检验标签稳定、任务难度/标法复杂度混杂和尾部。来源时间9236份中，旧2019为继承的审计来源，新7217是用户处理后报告时间；只有440份同目标时间。不得用来源时间替补同目标时间，不补零或lead_time；先分来源检查可比性。
- 粗类用于理解，细类用于组合。连续画像、少量粗类、Q×T×难度细类应比较，而不是预设“四类是永久上限”或无限细分。稀疏类可以暂列证据不足；给出每类真实成员、覆盖、稳定性以及合并/拆分的解释。
- Semi盲信、scope、排除和结构错误等可作为**独立的继续细分变量**，不揉进Q或一个通用人员总分。新Semi已报告的错误预标注未修改与旧强证据机会分开；改动过不等于修正成功。缺初始化不能算净改善。scope回答倾向、语义相容裁定下的正确与否、实际空间选择是三件事；图片OOS标签不是人员scope金标准。目前相容历史裁定93份（保留记录89），全部属于有限in-scope机会，不能推出全体适用性判断能力或误收率。
- 建筑外预测验证为主，人员类型在评估目标建筑之前学习；分训练和验证，避免同房/同建筑泄漏。难度可观察但测试图上的人员实际Q不能直接用于该人的“预测选人”。可把这种使用目标答案的方案另列oracle上限。

## 方向二：从标法簇反向寻找人员规律

用户观察：某张图的团队融合效果可能更依赖成员实际标法簇，而不是其全局Q标签。高Q人员并非每张图都画到同一位置。请继续这条反向路线，不要以正向分类已做而替代它。

1. 先核查既有9月全局亲近度、10月绑定循环对应及后续分簇代码。用户人工大致偏好全局亲近度9°–12°，不同点对数分开；这只是探索依据，尚不是最终参数。采用既有同距离定义，完整链接作对照；不要把融合过程当聚类。报告距离的循环/反向对应、底部y与三维敏感性。可保留9°/12°敏感性而不在每张图另挑“最漂亮”的阈值。
2. 在当前可用图上建立**逐图局部簇**，保留成员、点数、几何分布与混合参考/范围的解释。簇编号只在该图上下文中有效，不能跨图直接把“簇1”当成同一人员类型；单例、簇大小和不稳定归属都要报告。质量高低不是几何簇定义。
3. 在同图、同k、同背景成员、同参考和同融合设置下，比较簇内换人与跨簇换人；再比较不同簇的构成比例、入场顺序、单一大簇与跨簇团队。直接枚举不可承受时，先固定抽样规则和随机种子，覆盖足够不同图与建筑。人数由v2支持量决定，考虑8/12/16/24等实际支持值，不退回仅4人或8图；不同k必须报告共同可比图集合。
4. 发现“某些簇内替换差别小、跨簇替换差别大”后，回头解释簇成员的Q/T/难度/Semi/scope与错误特征。**这一步是反向发现**。再检验这些人员特征能否在未参与发现的建筑预测标法选择、团队行为或替换影响。若只能解释当图答案而不能预测其他图，也属于有价值但有限的结论。
5. “换人没有影响”不能仅用不显著p值断言。先明确实际差异的容忍范围，报告差值分布、区间及失败/结构变化；区分端点质量近似不变、融合几何相似、细节保留一致。高Q组可能有共同遗漏，低全局Q也可能提供关键结构；接受反例。

## 两条方向最终如何接起来

比较随机、Q优先、Q+T、Q+T+难度适应、进一步加独立行为变量，以及实际簇构成的解释性/oracle策略。固定同图同k同参考后看B8L2/D10、底面/结构/高度、完整率、失败、来源时间成本与同k换组差异；实际保存每次成员、顺序、几何与失败原因。

把“人员画像能预测组合表现”和“知道这张图实际标法后能解释组合表现”分开回答。原答两两分歧R、同k换组V和质量不是同一个量，也不是图片/人员噪声的自动分解。不同路径或重复变体不是独立真人样本；主要支持量按图和建筑报告，建筑加权/房间组加权作敏感性。成对同房只能用已有直接关系，不能用同建筑或关系传递自动制造事实。

至少分别给出：v1固定记录上的复核、v2旧记录与新人扩充后的变化、固定成员只换B8/D10计量、换画像指标后重新分组/选人、旧人/新人时间来源敏感性。不要将它们混在一个“升级提升”结论中。
