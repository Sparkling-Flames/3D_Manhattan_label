## 已验证的运行入口

需要numpy、pandas、scipy、scikit-learn、pytest。在解压根目录运行：

```bash
python -B -m tools.thesis_main.analysis.pro_research_handoff_20260921 --verify
python -B -m pytest tests/test_reviewed_manual_20260921.py tests/test_new_manual_20260921.py -q
```

第一条在`analysis_results/pro_research_handoff_20260921/recomputed/`重新生成最新汇总与分簇并比较随包结果，不覆盖参考输入。实际隔离运行结果见交付目录`DELIVERY_CHECK.json`。历史脚本存在不代表所有旧入口都已移植；上面两条是本包承诺验证的入口。

最新`distances.json`只有终审池和图上距离；旧版还有`pool`与`sphere`字段，不能仅替换路径就使用旧收敛入口。新研究可从最新点集构造所需测量。人员原训练轴可用于重新拟合；回溯到更早原始日志的全流程不在本包验证范围。

## 仓库整理决策

原`codex/pro-clustering-ready-20260920`最新提交包含约100MB展开的新增分析输出；有用的报告、代码和证据保留，但大型重复轨迹不是新对话的必要入口。`research/personnel-replay-20260921`只额外增加一个导出旧快照的自动工作流，没有最新终审数据。

本轮基于main建立独立交接分支，只提交研究包、生成代码及清楚的入口，不带入旧导出工作流，也不重写或删除原分支。包保留最新数据、必要基线、训练轴、名单、审核和代码；省略大型逐次预测／前缀明细、空仪表盘、采集方案历次HTML、浏览器库副本和临时检查图。详细省略清单保存在manifest，历史成果仍在原分支。

包不包含原始active日志、凭据或完整全景图库。数值可复算不等于语义已验收；涉及物理空间的新判断需实际原图。新方法与结果另存，不覆盖原始数据、人工原件和历史结果。
