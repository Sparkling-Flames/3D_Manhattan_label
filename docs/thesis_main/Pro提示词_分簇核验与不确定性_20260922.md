# 给新 Pro 研究对话的提示词（2026-09-22）

请作为有独立判断的研究合作者，接续我的真人全景布局标注不确定性研究。仓库为 `Sparkling-Flames/3D_Manhattan_label`，使用 `codex/pro-cluster-validation-20260922` 分支，资料入口是 `docs/thesis_main/Pro云端资料入口_分簇核验_20260922.md`。你没有旧对话背景，请依据材料核实实际情况，不要照搬之前 AI 的解释。

我们的核心问题是图片／任务与人员共同造成的标注不确定性：固定合理人群，一张图会出现哪些表达、各有多少支持；换人员类别、比例、具体成员或进入顺序，观察结果会怎样变化。导师提出按人独立采集，再组合真实作答研究这些问题。我的“收敛”直觉是一种共识，或者少数几种具有一定人数支持的稳定表达，单人簇较少；并不要求所有人最后只剩一种答案。这个想法需要严谨化，但不要用一个更容易成功的指标替代它。

目前最优先的是弄清分簇是否可信，以及分簇方法和定位容差应如何确定。多画或少画结构，是全景布局标注中明确的不同看法，应该区分；奇数点会单独复核。同点数也不保证结构相同。现有方法使用上下点配对、固定对应、最大端点距离、25.6 像素探针，并比较完整链接与代表半径，这些都是工作方案，尚未验证为最终方法。请综合原图、实际点集、既有审核和数值证据独立判断，可以改进方法，也可以认为现方案经过适当校准已足够。

我刚审核了 24 张图：9 项可同簇、12 项应分开、3 项暂不能判断。人工判断也可能受到画面缩放、遮挡和显示方式影响。例如我把距离约 25.628 像素的一对判为分开，把约 26.007 像素的一对判为同簇；这可能包含视觉误判，不能据此否定距离阈值，也不要强行拟合我的每一项回答。原始选项和评论是诊断证据，可以提出有理由的复核。我们仍需要有依据、可复核的容差，尤其要处理遮挡／看不见位置的定位波动，同时保留实质结构差异。只展示两份标注有时上下文不够，24 图包中还保留了完整成员和原图供检查。

另一个值得研究的想法是：同一份标注内，同一竖直墙角上下两点的 x 原本应该相同或很接近，能否在分析时将它们规整到共同 x，例如取均值？我说的 0.2 是百分比坐标中的 0.2 个百分点，只是举例，具体阈值、适用条件和方法由你探索；不是把不同人的坐标互相平均。原始坐标保留，以便比较规整前后的影响。仓库标注脚本在生成某条 3D 预览路径时已经对配对 x 取平均，但原始点并没有随之修改；实际部署和使用情况尚未核实。这可能影响对误差与人员行为的解释，值得结合真实代码理解。

GT、HoHoNet、BiLayout 和其他模型都可能有误，本轮只作为必要时的辅助参考，暂时不纳入研究解释变量，不围绕它们扩展新的预测问题。BiLayout 的 enclosed／extended 在不少无歧义图片上很接近，并不稳定对应两类真人；导师认为目前这段认识已经足够。图片难度与分歧的联系可以作为解释线索，但暂不预设必须新增一套复杂难度分类。

在分簇可信的基础上，请进一步判断现有人员粗分类有没有解释力，人员差异、具体成员和顺序怎样影响稳定；以及同房间其他视角能否帮助判断分歧或所需人数。我的观察是假设：简单、封闭、边界清楚的同房视角通常容易取得一致，门洞交界或遮挡多的图分歧更大。请检验其成立条件和反例，区分“分歧程度相关”与“能预测持续稳定人数”。现有 W037 等人员的移除敏感性已提供；不要把单人簇多直接等同于质量差，也不要为了更早收敛选择删除人员。

最新描述数据为 241 图、2481 份；不借用补点的预测视图为 240 图、2444 份，25 人、22 栋建筑，已纳入 W006 补交，沿用 W019／W026 既有排除。所有作答独立性问题已经由我确认关闭，不再讨论。上一轮 Pro 返回、独立复核和修正结果都在包中，其中有人员配比模型外层留建筑隔离的修正，请分清原报告、修正结果和未经验证的解释。现有人工案例属于开发证据，不是独立验证集。

你可以自主选择方法与执行顺序，不必遵循一套预定实验清单。请实际开展资料允许的分析，保持研究问题清楚，不为得到好看的收敛结果选方法。分类、参数调整与评价应避免目标信息泄漏，重叠组合不冒充独立样本；观察不足就保留未知。新增结果另存并可复算，需要人工裁决时给出具体图、点位和争议，不必重复已明确解决的问题。

请用中文交付你的独立判断、分析证据及可复核代码，说明哪些结论可信、哪些仍只是线索，推荐的分簇与容差如何验证，以及下一步最值得投入的研究。也请回答：现在是否需要继续标注，若需要，补哪些同房视角、哪些人员或哪些重复覆盖最能解决当前不确定的问题？不要求凑出唯一阈值、最佳人员组合或确定的收敛人数。
