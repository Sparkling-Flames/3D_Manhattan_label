# 论文写作 SOP：避免 AI 化、防御性表述与否定尾句

版本：v1.2（2026-11-08）。适用范围：论文提纲、正文、摘要、图表说明、导师汇报稿、英文投稿。
不适用范围：研究合同、字段合同、审计记录、复现说明；这些文本需要保留完整的条件、分母和失败状态。

v1.2 新增：否定尾句规则；“不是 A，而是 B”限制；汇报页“最强数据”规则；英文写作规则。

本 SOP 不改变研究结论、数据、评分、资格或融合规则，只约束表达方式。

## 1. 目标

写完一段话，读者应该能回答：

1. 这句话的主张是什么？
2. 它对应哪张图、哪组人、哪个数字？
3. 条件是什么？
4. 哪个词是作者自己的判断，哪个词只是背景？

如果读者读完只记住“作者很谨慎”，这一段就没有完成。

## 2. 五条总原则

### 2.1 主句承担主张，从句承担边界

不要把结论放在最后一句，也不要用“不意味着/不能/不等于”把主句包起来。

- 差：`类别构成能够组织一部分结果差异，同时相同配比内仍有较大的具体成员敏感性。`
- 好：`类别比例能解释一部分团队差异；同一配比里换人，结果仍会明显变化。`

### 2.2 先具体，后抽象

顺序优先：人/图/团队/动作 → 数字 → 变量名 → 机制。

- 差：`该路径同时改变总人数、替换比例、背景成员和门槛。`
- 好：`这条路径一边加人，一边换背景，投票门槛也跟着变。`

### 2.3 一段一事

每段只回答一个问题。段落内部按“结论 → 证据 → 机制 → 边界”排列；不要在一段里同时讲定义、结果、限制和下一步。

### 2.4 段尾落在肯定主张上

段尾不要再补一句“这并不/不能/并非/不意味着”。读者记住的应该是发现、动作或机制，而不是免责声明。

- 差：`这些结果不能外推到其他建筑。`
- 好：`这些结果来自 22 栋建筑；跨建筑外推需要独立样本。`

- 差：`人数增加并不总是提高质量。`
- 好：`人数增加的收益集中在 3—6 人；20 人以后，平均 Q 基本持平。`

边界可以放在段中，或单独成“适用边界”段；边界段也以“适用于什么范围、下一步需要什么”收束，不用否定句收尾。

### 2.5 少用“不是 A，而是 B”

“不是……而是……”是强调句式，不是定义句式。它先树一个读者未必持有的 A，再给 B，篇幅翻倍，语气也容易变成辩解。

规则：

1. 先直接写 B；
2. 只有读者真会误解成 A 时，才用一句短句补 A；
3. 不要在同一段连续使用“不是……而是……”“并非……而是……”“与其说……不如说……”。

- 差：`问题不是人不够多，而是局部结构没有被汇总。`
- 好：`局部结构需要单独汇总；增加人数只改变投票基数。`

- 差：`这不是方法失败，而是参考边界问题。`
- 好：`参考边界偏离了真实结构；方法仍按局部支持汇总。`

- 差：`关键不是数量，而是构成。`
- 好：`构成改变了结果；数量主要改变均值。`

## 3. 交付前自检清单

逐项回答“是/否”，任一项为“否”就改：

- [ ] 标题写成“对象 + 条件 + 发现”；不用反问句、金句或口号。
- [ ] 每段第一句是这一段的结论，不是背景。
- [ ] 主语是人、图、团队、投票或数据，不是“路径/构成/证据/分类”在自我表演。
- [ ] 段末是肯定句；没有用“这并不/不能/并非/不意味着”收尾。
- [ ] 没有“不是 A，而是 B”“并非 A，而是 B”“与其说 A，不如说 B”的对比定义；先直接说 B。
- [ ] 一段内“不意味着/不能/不等于/并非”不超过一处。
- [ ] 每个术语第一次出现有中文全名或定义；没有未解释的缩写。
- [ ] 每个数字都有单位、分母或比较对象。
- [ ] 没有“进行/形成/体现/反映/支持/组织/构成/具有”这类空动词连续出现。
- [ ] 没有“首先/其次/最后”这种装饰性顺序词；真正的步骤才用。
- [ ] 没有“提分/低分队/救不了/奇怪的位置/换一半的人”这类口语或考试词。
- [ ] 朗读一遍，像人在讲研究，不像在念验收报告。

## 4. 禁用与慎用清单

### 4.1 装饰性连接词

没有真实顺序时，删除：

- 首先、其次、最后
- 值得注意的是
- 综上所述
- 不仅……而且……
- 一方面……另一方面……
- 在……背景下
- 具有……意义
- 为……提供了新的视角

真正的步骤、并列或转折才保留。

### 4.2 防御性词

控制密度，不是全部删除：

- 不意味着、不等于、不能、避免、不要求、并非、未必、可能
- “不是……而是……”“并非……而是……”“与其说……不如说……”

规则：

- 一段最多一处；
- 能写成条件就不写否定：`只在受约束 GT 有效时排名` 优于 `不能用 OOS 排名`；
- 事实性否定必须保留：失败、缺失、不可评分、OOS 不进入正式质量排名；
- 否定词放在段中或边界段，不放在段尾。

### 4.3 海报/信息图语言

- 提分、低分队、救不了、换一半的人、奇怪的位置、答案、真相、关键一步

这些词适合口头解释，不适合论文正文。正文用“平均 Q 提高”“低分尾部”“满员仍有 6/17 失败”“14 人换 7 人”“参考边界偏离真实结构”。

### 4.4 空动词与名词化

少用：

- 进行、形成、体现、反映、支持、组织、构成、具有、实现
- 指标有效支持、声明对象、构成间方差占比、研究问题与分类口径

处理方式：

- `对……进行比较` → `比较……`
- `具有……特征` → `表现为……`
- `该路径同时改变……` → `这条路径一边……一边……`
- `指标有效支持` → `该指标可评的团队`
- `构成间方差占比` → `配比之间的方差占总方差的比例`

### 4.5 模糊量词

- 多数、常常、有时、更容易、明显、较大

每个模糊量词后面必须能接：

- 多少/多少（如 42/57 图）；
- 和谁比（同类替换、另一人数段、自然顺序）；
- 哪个指标（Q、P10、SD、V）。

接不上就删掉，或换成具体数。

## 6. 标题规则

标题写“对象 + 条件 + 发现”，不写反问、金句、口号。

- 差：`同一张图，人为什么画得不同？`
- 好：`同一房间、不同视角：人员质量与结构表达的重复性`
- 差：`局部画错了，空间重叠率未必看得清。`
- 好：`局部高度抵消时，均高 3D IoU 仍然接近 1`
- 差：`前面加人常常提分，后面加人更多是在减少低分队。`
- 好：`3→6 人主要提高平均 Q，20→30 人主要降低低分尾部`

标题里出现“为什么/未必/有时/反而”时，先检查是否在制造悬念。

## 7. 数字规则

1. 一句最多三个数字；超过就拆句。
2. 每个数字至少带一个对象：`42/57 图`，不是 `42`。
3. 百分比要写分母：`Q 构成间占比 14.36%` 要说明“占 Q 总方差”。
4. 不同分母的数字不并排：不要写 `14.36%/85.64%`；写成“构成间 14.36%，构成内 85.64%”。
5. 大数字后面跟一句人话：`10,439 份作答、261 张图；其中 7,302 份进入正式质量分析。`

## 8. 术语规则

- 第一次出现给中文全名和缩写：`人员结构表达分类（DSTRUCT）`。
- 一个概念只用一个词；不要“换人/换类/替换/调整”混用。
- 同一字母多义时加中文名或下标：保留背景 D、人工难度 D、方向残差 D_dir。
- 内部代号（TURN3、ALL、LOBO、MV50）第一次出现要解释；正文不要只写代号。
- 斜杠只用于并列专名，不用于两个不同分母的数字。

## 9. 防御性写作怎么处理

### 9.1 一处集中，不逐句免责

每节或每章保留一个“适用边界”段，集中写清：

- 样本范围；
- 分母和失败状态；
- 哪些结论不能外推；
- 哪些是相关而非因果。

正文其他位置用条件句，不重复免责。

### 9.2 主句肯定，条件放从句

- 差：`这不能说明替换比例越大效果越大。`
- 好：`本轮 10—21 人的路径同时改变替换比例、背景成员和门槛；行间差反映的是三项共同变化。要估计替换比例的单独效应，需要固定背景和门槛的配对比较。`

第二句仍然准确，但先给对象和范围，再给下一步条件。

### 9.3 保留事实性否定

以下否定不要删：

- 失败、缺参考、不可评分、未计算；
- OOS 不进入正式质量排名；
- 满员波动为零不代表布局准确；
- 两个不同分母不能直接相减。

删掉的是“自我防御”，不是“事实边界”。事实性否定放在边界段中间，段尾回到“这些结果适用于什么范围、下一步需要什么”。

### 9.4 否定尾句

不要把“这并不/不能/并非/不意味着”放在段尾。否定尾句会让读者只记住作者在退，不记得发现了什么。

- 差：`因此，这些结果不能外推到其他建筑。`
- 好：`这些结果覆盖 22 栋建筑；跨建筑外推需要独立样本。`

- 差：`这说明人数增加并不总是提高质量。`
- 好：`人数增加的收益集中在 3—6 人；20 人以后，平均 Q 基本持平。`

- 差：`This does not mean that group size always helps.`
- 好：`In this sample, group-size gains concentrate between 3 and 6 annotators.`

处理顺序：

1. 把否定句改成肯定句；
2. 改成“条件 + 适用范围 + 下一步”；
3. 如果事实本身是失败/缺失，放在边界段中间，段尾回到观察到的现象或下一步动作。

### 9.5 “不是 A，而是 B”

“不是……而是……”适合口头强调，不适合论文里的定义。它把 A 先立成靶子，再给 B，读者要多走一步，语气也容易变成辩解。

- 差：`问题不是人不够多，而是局部结构没有被汇总。`
- 好：`局部结构需要单独汇总；增加人数只改变投票基数。`

- 差：`这不是方法失败，而是参考边界问题。`
- 好：`参考边界偏离了真实结构；方法仍按局部支持汇总。`

- 差：`关键不是数量，而是构成。`
- 好：`构成改变了结果；数量主要改变均值。`

只有在读者真会误解成 A 时，才用一句短句补 A；不要连续使用“不是……而是……”“并非……而是……”“与其说……不如说……”。

## 10. 段落模板

### 10.1 结果段

1. 结论：对象 + 条件 + 幅度；
2. 证据：数字/图/案例；
3. 机制：对应、票数、位置、连接、背景；
4. 边界：放在证据后、结论前；段尾回到主张或下一步动作。

示例：

> 14 人换 7 人时，跨类替换的 Q 变化幅度为 6.456 分，同类为 3.774 分；57 张图中有 42 张跨类更大。两类替换共享同一 7 人背景，替换块的成员与类别不同。50% 是本次的替换规模；最优比例仍需固定背景和门槛的配对实验。

### 10.2 方法段

对象 → 输入 → 步骤 → 输出/失败状态。不要先讲“具有重要意义”。

### 10.3 讨论段

跨结果的问题 → 证据 → 解释 → 条件。不要按结果小节逐段复述。

## 11. 改写示例

**例 1**

- 原：`该路径同时改变总人数、替换比例、背景成员和门槛。`
- 改：`这条路径一边加人，一边换背景，投票门槛也跟着变。`

**例 2**

- 原：`类别构成能够组织一部分结果差异，同时相同配比内仍有较大的具体成员敏感性。`
- 改：`类别比例能解释一部分团队差异；同一配比里换人，结果仍会明显变化。`

**例 3**

- 原：`局部画错了，空间重叠率未必看得清。`
- 改：`局部画错时，重叠率可能仍然很高。`

**例 4**

- 原：`表中是变化幅度；若报告方向，C−B 分别为 +6.040 和 +8.157 分。`
- 改：`表中是变化幅度；方向另看 C−B：全部阶段 +6.040 分，保留建筑 +8.157 分。`

**例 5**

- 原：`满员时换组波动为零，结构仍可能偏离真实目标。`
- 改：`满员只剩一个成员集合；指标可评时，换组波动为零。这个零说明成员不再变化；布局是否接近真实目标，要看参考边界是否覆盖真实结构。`

## 12. 审阅流程

1. **冷读**：不看数据，先读一遍，标出每段第一句；如果第一句不是结论，改。
2. **删元话语**：删“本节/表×列出/单独呈现/需要说明的是”。
3. **查防御密度**：每段“不/未/不能/并非”超过一处，合并或改成条件句。
4. **查否定尾句**：每段最后一句出现“不/未/不能/并非/不意味着”时，改成肯定句，或把边界移到段中。
5. **查“不是 A，而是 B”**：搜索“不是……而是”“并非……而是”“与其说……不如说”；先直接写 B。
6. **补具体案例**：每个抽象判断后面补一个人、图、团队或票账。
7. **数字核对**：单位、分母、比较对象、支持数。
8. **术语核对**：同一概念同一词；缩写首现解释。
9. **朗读**：读起来像人在讲，不像在念验收报告。
10. **第二读者**：让不熟悉该专题的人复述三段；复述不出主句，重写。

## 13. 交付前检查

- 标题没有反问/金句；
- 每段有主句；
- 段末是肯定句，没有否定尾句；
- 没有“不是 A，而是 B”“并非 A，而是 B”“与其说 A，不如说 B”的对比定义；
- 没有连续空动词；
- 没有未定义缩写；
- 数字都有分母；
- 每节最多一个边界段；
- 没有“提分/低分队/救不了”等口语；
- 没有为了对称而凑的三段式；
- 朗读通过；
- 全文术语表与 [CONTEXT.md](CONTEXT.md) 一致。

## 14. 例外

以下情况允许保留较强的限定和较长的条件句：

- 方法与资格定义；
- 失败、缺失、不可评分状态；
- OOS、门洞、GT 适用性；
- 统计分母与重抽单位；
- 与既有结果冲突的解释。

原则不变：**先让主句成立，再用一句话说明它在什么范围内成立。**


## 15. 2026-10-27提纲审阅补充

### 把人和动作写出来

检查“分类组织差异”“作用共同形成”“通过……表现”一类句子：说明换入哪些人、背景对具体结构有多少票，以及位置和连接发生了什么。抽象归纳之后接一个已核实的团队或票账案例；案例说明机制时标明条件，不把个例写成全体规律。

### 删去写作操作说明

“结果章按……组织”“单独呈现”“分开报告”“表中是”等句子，若没有提供实验对象或统计含义，直接删去或改成结果。表格标题和数据已经说明的内容不必在相邻段落重复；幅度与方向、总体与子集确有区别时，明确写出各自的比较对象。

### 把边界放到它有用的位置

连续段落都以“不能”收尾时，检查是否可以合并：先说明各自使用的图片、团队或分母，再说明比较所回答的问题。适用资格、缺失与失败必须保留；自然改写不能把不可比的均值改写成净效应，也不能把记录劳动改成实际交付时间。

### 改写后核对研究含义

- 限定实验规模、共同背景和图片支持；条件结果不写成普遍结论。
- 样本内嵌套细分的方差占比、预测能力、因果作用分别表述。
- “50% 是本次规模”不等于已检验最优比例；没有完成的配对实验不写成既有结果或既定安排。
- 涉及 Q 的判断同时交代参考适用性；完整、稳定和高分分别检查。
- 例句用于说明表达方式，正文仍回到源表核对数字、支持和案例。

## 16. 汇报页：故事优先，数据最强

### 16.1 一页一主张

一页只回答一个问题，页面结构固定为：

1. `RQn Findings: 主题`；
2. 一句加粗结论；
3. 2—3 个最强数字；
4. 一张图、表或案例；
5. 可选一个 quote box。

页面上的每一行都要服务这一句结论。不要在同一页同时放主结果、初始化检查、分母说明和另一套实验设计。

### 16.2 “最好的数据”怎么选

“最好的数据”指**事先定义、支持充分、方向清楚的主比较**；选择依据在看结果之前已经确定。

- 主页面只放 primary comparison；
- 分母、未知状态、备用设计放 notes 或 backup；
- 负结果如果是主结果，照常放主页面，不换成更好看的数；
- 不通过改分母、删图片或换比较对象让结果变大；
- 图表保留完整支持数，页面只突出其中 2—3 个。

### 16.3 小字边界不要上页面

以下内容放 notes/backup，不放在页面底部：

- `lower bound, not an error rate`；
- `unknown outcome`；
- `denominators differ`；
- `each comparison has its own image support`；
- `room relationship unknown`；
- 初始化检查、备用设计、失败状态的分母。

页面需要保留事实边界时，用一行 9—10pt 的来源说明；不要写成一段自我辩护。

### 16.4 页面收尾

- 页面最后一行用结论、数字或下一步收尾；caveat 放 notes；
- 不要用 `This does not mean...`、`cannot be generalized` 收尾；
- quote box 可以放作者自己的结论，但标 `KEY TAKEAWAY`；不要伪造参与者原话；
- 汇报页不写“本节将说明”“下面分三点”这类写作操作说明。

### 16.5 页面自检

- [ ] 这页只有一句主张；
- [ ] 页面上的数字都能回到 notes/源表；
- [ ] 最后一行是肯定句；
- [ ] 没有 `SEPARATE CHECK`、`lower bound`、`denominators differ` 这类小字；
- [ ] 没有“不是 A，而是 B”的标题或结尾；
- [ ] 负结果如果是主结果，仍在页面上；
- [ ] notes 保留了完整分母、失败状态和备用比较。

## 17. English writing rules (final manuscript)

These rules apply to the English manuscript, abstract, figure captions, and response letters. Write the final paper in English; keep the Chinese notes only as drafting support.

### 17.1 Sentence defaults

1. Put a concrete actor in the subject: annotators, teams, images, consensus, the reference.
2. Prefer verb + object over nominalization: `we compared...`, not `a comparison was conducted`.
3. One main claim per sentence. Split sentences that carry a result, a mechanism, and a caveat at once.
4. Use active voice when the actor matters; use passive voice only when the actor is unknown or irrelevant.
5. Keep one term for one concept. Define each acronym at first use; do not use internal codes in the manuscript.

### 17.2 Paragraph architecture

Use this order:

1. **Claim**: the finding in one sentence.
2. **Evidence**: number, figure, case, or table.
3. **Interpretation**: mechanism or comparison.
4. **Scope**: only if needed, placed before the closing sentence.
5. **Close**: return to the finding, implication, or next action.

Do not end with a disclaimer. The last sentence should tell the reader what the result means or what to do next.

### 17.3 Do not end on a negative

Avoid ending a paragraph with a sentence whose main verb is negated: `not`, `never`, `cannot`, `do/does not`, `without`.

- Weak: `These results cannot be generalized to other buildings.`
- Better: `These results cover 22 buildings; a separate sample is needed for generalization.`

- Weak: `This does not mean that group size always improves quality.`
- Better: `In this sample, group-size gains concentrate between 3 and 6 annotators; beyond 20, the mean is flat and the gain shifts to the lower tail.`

- Weak: `The method does not model reference error.`
- Better: `The method measures annotation geometry; reference error is handled in a separate audit.`

Factual negatives still belong in the paper. Put them in a boundary paragraph or a limitation subsection, then close on what was observed or what remains to be done.

### 17.4 Use “not X but Y” sparingly

Avoid the `not X but Y` construction as a default. State Y first. Mention X only when the reader would otherwise assume it.

- Weak: `The gain is not from team size but from structural diversity.`
- Better: `Structural diversity tracks the gain; team size adds little.`

- Weak: `This is not a failure of consensus but a limitation of the reference.`
- Better: `Consensus preserved local support; reference gaps remained a separate error source.`

- Weak: `Composition is not the main driver; specific members are.`
- Better: `Composition explained 15% of the variance; specific members explained 85%.`

Also limit `rather than`, `less about X than Y`, and `not only ... but also`. Use them when the contrast is the finding, not as decoration.

### 17.5 Hedging

Use one hedge per claim. Prefer scope to modality.

- Too much: `The results may potentially suggest that larger groups might possibly improve quality.`
- Better: `In this sample, larger groups improved mean Q from 3 to 6 annotators.`

Useful scope phrases:

- `in this sample`
- `for the 22 buildings`
- `under the constrained reference`
- `for the 69 common-evaluable images`

Avoid stacked hedges: `may potentially`, `might suggest`, `could possibly`, `appears to be consistent with`.

### 17.6 Numbers

1. Give the denominator: `42 of 57 images (73.7%)`, not `42`.
2. Give the comparison: `5.05 vs 8.93`, not `5.05 lower`.
3. Do not place different denominators in one slash pair. Write them in separate clauses.
4. Keep one decimal place unless the measure needs more.
5. After a large number, add one plain-language sentence: `10,439 submissions from 261 panoramas; 7,302 entered the formal quality analysis.`

### 17.7 Titles and captions

- Titles state object + condition + finding; avoid questions, slogans, and `Why...?`.
- Captions state what is shown, the comparison, and the support: `Mean Q by group size (171 images, 22 buildings).`
- Do not use a caption to smuggle in a caveat that the main text avoids.

### 17.8 Primary comparison and “best data”

The main text reports the prespecified primary comparison. Secondary comparisons, sensitivity analyses, and negative results go to a clearly labeled subsection or supplement.

Do not choose the denominator, image subset, or comparison direction after seeing the result. If the primary result is negative, report it as the primary result.

### 17.9 English pre-submission checklist

- [ ] Every paragraph ends on a claim, action, or scope statement in affirmative form.
- [ ] No paragraph ends with `not / never / cannot / without`.
- [ ] No `not X but Y` unless X is a real alternative the reader would assume.
- [ ] No stacked hedges.
- [ ] Every number has a denominator and a comparison.
- [ ] One term per concept; acronyms defined at first use.
- [ ] Titles are findings, not questions.
- [ ] The primary comparison is identifiable; secondary results are labeled.
- [ ] The final sentence of each section gives the finding or the next step.
- [ ] Read aloud: it sounds like a researcher explaining the result, not a reviewer listing caveats.
