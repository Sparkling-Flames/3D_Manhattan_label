# 人员、图片与区域共识统计分析计划

当前规范：`PAPER_A_METHOD_CONTRACT_CURRENT.json`，版本 `consensus_research_20260923_v1`。本计划是2026-09-23已授权的研究比较协议，不宣称最终算法、分类阈值或收敛阈值已验证。旧T1/V1统计计划完整见 [历史版本](history/research_before_20260923/docs/thesis_main/STATISTICAL_ANALYSIS_PLAN_v1.md)，旧v23合同的历史解释不追改。

## 1. 数据与推断单位

全量清查当前3019份作答；Manual、OOS、Semi分别保留条件，合并Manual/OOS时报告分层覆盖。canonical当前版本一人一票；借用补点另标并排除独立组合/预测。历史裁决按对象和版本应用，未决不自动通过或排除。原始点、有效点、共享x点同时可追溯。

清洗前后分别报告人数、图片、人员及每人无效数量/比例。异常距离仅排序，不能仅以低GT质量或少数意见删除研究对象。方法不可计算、缺参考、空输出、未收敛、不可用分别保留；不只报告成功子集。共同可评价集上的配对差与全范围覆盖/失败率同时呈现。

## 2. 测量与人员画像

外部质量主指标为GT-IoU，原始与人工修订GT分别计算。质心是面积一阶矩，不是角点平均；ERP位置依赖接缝，圆周方向依赖集中度R。先报告偏移像素分布、R及扰动/接缝敏感性，后判断是否可进入加权；不先验给质心固定正权重。

人员质量使用共同图片比较及人员/图片效应调整，报告每人的图数、建筑数与支持区间。单图STAPLE参数不能直接当作跨图能力。每人每图一次数据不能把交互与同人随机波动完全分离。人员分类仅在训练建筑拟合，未知或分类不稳定者保留，不凭本次目标图得分给其分类再测试。

## 3. 共识与信息条件

区域定义和全幅ROI统一。Lee MV采用>=50%，>50%作为平票敏感性；medoid选择真实作答；单正确率EM与经验greedy为显式适配，不称原作者完整复现。标准STAPLE与MAP-STAPLE分开，MACCHIatO先通过源码与周期空间操作核验。

只用当前标注的算法与使用外建筑GT校准的加权/先验算法分组比较。标准STAPLE输出为模型条件后验，MACCHIatO软场为优化结果，均不等同真人支持率。所有算法保留原始支持图。分簇只是全体/最大簇对照，不改变横轴收集人数；剩余簇人数另报。

目标建筑GT不得用于选算法权重、先验、阈值、人员类别。GT-oracle只能做明确限定候选空间的诊断上界，不能混入可用算法排名。对于同房预测，可将预先指定的已观测源视角信息作为输入，但目标视角GT和未来作答不得泄漏；这种任务与全新建筑无任何校准信息的任务分开。

## 4. 人数、人员组合与顺序

每图真人无放回重放；方法共用完全相同成员与顺序。小组合可穷举，过大组合保存抽样种子、抽样数、覆盖和重复误差，不谎称穷举。使用前k人重建当前共识/分簇，固定画布不依赖未来。相同成员集确定性算法的终点相同是机制属性，不是质量上限证据。

分别研究Q(k)=GT-IoU、相邻人数输出变化、同人数成员组合差异，以及人员类型比例的影响。总曲线在固定图片面板共同人数范围内计算，图片不足不补造后续人数。类型效应与具体成员效应分开；不复制真实人员补比例。

只有事先定义实际重要差值并获得支持，才能判定观测范围的平台；不显著不等于等效。当前不冻结平台阈值，不因未显著而持续加样本直到显著。

## 5. 图片难度及同房预测

HoHoNet预测错误、角点数、几何异常/经确认的退回，以及BiLayout enclosed/extended差异是候选难度信号。只需模型输出的特征与需要GT才知道的模型误差分开。比较全体、难度分层、单列难图后的固定面板曲线；剔除难图导致均值升高不解释为算法变好。

同房预测继续做；按房间/建筑隔离训练与目标，比较简单基线并报告覆盖与不明确结果。性能差按同图同成员配对，以建筑为重采样/泛化评估单位。像素、同一人群反复抽样和多个视角不能当作新的独立人员/建筑。

## 6. 方法验证与报告

检验一致输入、平票、共同遗漏、同质心异形、接缝循环平移、分辨率变化、非法数据和GT隔离。MAP先验强度须说明固定栅格尺度；MACCHIatO连通/距离操作须周期化。初始化、失败和运行耗时同时记录。

先用现有数据进行方法开发；已用于开发/人工定向审核的数据不冒称全新外部验证集。原始/人工修订GT敏感性沿相同划分重算。外部校准收益、图像模型信息收益和聚合本身收益不混为一谈。清洗数值队列、先行全成员比较与完整前缀/预测实验必须分别标明完成状态。
