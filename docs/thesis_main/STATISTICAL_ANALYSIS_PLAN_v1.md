## 3. 共识与信息条件

区域定义和全幅ROI统一。Lee MV采用>=50%，>50%作为平票敏感性；medoid选择真实作答；单正确率EM与经验greedy为显式适配，不称原作者完整复现。标准STAPLE与MAP-STAPLE分开，MACCHIatO先通过源码与周期空间操作核验。

只用当前标注的算法与使用外建筑GT校准的加权/先验算法分组比较。标准STAPLE输出为模型条件后验，MACCHIatO软场为优化结果，均不等同真人支持率。所有算法保留原始支持图。点位/细节分簇为独立研究；用于聚合时全体/最大簇仅作对照，不改变横轴收集人数，剩余簇人数另报。几何合理候选生成独立于工人共识，以观测保留及适用几何约束为目标；不能仅以优化残差下降证明有效。

目标建筑GT不得用于选算法权重、先验、阈值、人员类别。GT-oracle只能做明确限定候选空间的诊断上界，不能混入可用算法排名。对于同房预测，可将预先指定的已观测源视角信息作为输入，但目标视角GT和未来作答不得泄漏；这种任务与全新建筑无任何校准信息的任务分开。

## 4. 人数、人员组合与顺序

每图真人无放回重放；方法共用完全相同成员与顺序。小组合可穷举，过大组合保存抽样种子、抽样数、覆盖和重复误差，不谎称穷举。使用前k人重建当前共识/分簇，固定画布不依赖未来。相同成员集确定性算法的终点相同是机制属性，不是质量上限证据。

分别研究Q(k)=GT-IoU、相邻人数输出变化、同人数成员组合差异，以及人员类型比例的影响。总曲线在固定图片面板共同人数范围内计算，图片不足不补造后续人数。类型效应与具体成员效应分开；不复制真实人员补比例。

只有事先定义实际重要差值并获得支持，才能判定观测范围的平台；不显著不等于等效。当前不冻结平台阈值，不因未显著而持续加样本直到显著。

## 5. 图片难度及同房预测

不同模型角点数及差异、几何异常/自交/邻接敏感性、BiLayout enclosed/extended差异和冻结d_model_feat是候选难度信号。d_model_feat为参考特征库距离，不是难度真值；BiLayout双输出不是独立模型票，强制正交后零残差不证明简单。人工难度预期保留对照，OOS/门洞单列。预标注可得特征与事后人工改序、GT误差分开，不把后者用于无标注新图预测。固定面板比较，剔除难图导致均值升高不解释为算法变好。

本轮用户只要求粗略对应：先有基础曲线，再逐项看 d_model_feat、BiLayout双输出和已有图片划分，不立即合并建模。门洞交界的局部可能无法合理标注；OOS的GT未必适用。既有参考可靠性和分析资格独立保留，特殊场景参考距离不直接解释为人员错误；不把“简单更快、困难更慢”设为必须得到的结果。

同房预测为后续待执行方向；按房间/建筑隔离训练与目标，比较简单基线并报告覆盖与不明确结果。性能差按同图同成员配对，以建筑为重采样/泛化评估单位。像素、同一人群反复抽样和多个视角不能当作新的独立人员/建筑。
