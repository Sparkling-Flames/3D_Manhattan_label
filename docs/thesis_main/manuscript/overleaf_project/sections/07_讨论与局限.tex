\section{讨论与局限}

Full-Integrated 的目标不是让所有任务都个体化，而是在获得跨阶段支持时做有限调整，
证据不足时明确退化为 Strong Global。若政策差异可行性 gate 失败，
结论应是当前画像无法产生可识别的政策差异，而不是强行执行 V1。

研究受固定 PreScreen 合格工人池、P1 admission 的 range restriction、
有限 conditional support 和单一 operational reference 约束。
50:50 试验分布用于识别交互，不能直接代表生产任务分布。
共享工人池下的独立容量账本定义了本文的目标部署制度，其他容量制度需要单独验证。

外部事故处置只能解决不归责的运行中断，不能用于清理不利结果。
事后人工审核可解释 unresolved、GT 冲突和 OOS，但不得替换政策输出重新计算主效应。
