# 图片标注难度：跨领域定义、当前依据与补充复核

2026-10-28。用于研究讨论与方法核对。本次查阅原始论文、官方标注指南，并核对本仓库难度标签的形成记录；没有修改图片等级、参考、评分、人员分类或实验结果。

**2026-10-28本轮方向更新：** 用户不采用“人工判定表＋独立复核优先”的建议。固定面板楼外比较现已执行，建议保留三档作为既有工作分层，用可计算结构条件补充解释；未生成自动重现三档的规则，也未证明三档最优。六项几何是分列变量，不是一维难度分。结果见[实证报告](../../../../research/difficulty/difficulty_computable_comparison_20261028/README.md)；拟合前方案见[图片难度可计算依据与最小比较方案_20261028](图片难度可计算依据与最小比较方案_20261028.md)。现行等级不变。下文第4—7节保留上一轮建议身份，其中“最优先”不再代表本轮顺序；文献事实与方法史继续保留。

## 1. 文献中的“难度”实际有几种含义

不同研究测量的对象不同。同一棵树可以很容易被找到，却很难精细勾出轮廓。这是视觉搜索论文用来说明任务差别的例子。[Ionescu等，CVPR 2016，§1–2](https://arxiv.org/html/1705.08280)

|定义方式|具体回答什么|怎样获得|适合我们哪一部分|
|---|---|---|---|
|按可见条件分层|这项任务要求处理哪些不利条件？|结构数量、尺寸、遮挡、可辨认线索及明确判定规则|当前图片条件和粗难度的主要依据|
|按操作成本测量|完成指定操作要花多少劳动？|有效作答时间、交互次数，处理人员速度与工具差异|同来源的标注时间分析|
|按作答表现估计|排除部分人员能力差异后，这项任务有多容易出错？|多人响应及人员—题目模型|可选的表现难度分析|
|按算法表现定义|哪个样本让某个模型容易失败？|检测召回、分割误差或模型损失|模型难度，单独解释|
|按目标歧义判断|人们是否会选择不同但合理的目标？|明确问题后的多人判断及独立作答对照|scope、范围分歧；与操作难度分开|

可将本研究对象写成“图片在指定目标、标注规则和工具下的任务难度”。如果研究的是表现难度，还需要说明人员群体。Manual与Semi可以共享结构条件，但初始化会改变实际操作和表现。

## 2. 有明确操作定义的原始来源

### 2.1 KITTI：用可观测条件规定评价难度

KITTI目标检测评价同时使用目标框高度、遮挡等级与截断比例：

|评价级别|最小框高度|允许的最大遮挡等级|最大截断比例|
|---|---:|---|---:|
|Easy|40像素|完全可见|15%|
|Moderate|25像素|部分遮挡|30%|
|Hard|25像素|难以看清|50%|

这些是目标实例的评价条件，且不同级别的允许条件有包含关系。它提供了“用任务相关条件规定难度”的范例，并未给出全景布局的通用分档阈值。遮挡等级本身也包含标注判断。[KITTI官方评价说明，Difficulties部分](https://www.cvlibs.net/datasets/kitti/eval_object.php)

对我们最有用的是这种透明做法：保留每张图的原始条件，说明怎样得到等级；无需把所有判断都压成一个自动分数。

### 2.2 VOC2006：官方指南明确采用人工 difficult 判断

VOC2006指南记录：由单名标注者查看对象框内区域，主观判断识别是否困难，理由包括尺寸小、模糊、杂乱、严重遮挡或关键部分遮挡。这里的对象是“识别该目标”的难度。[官方 Annotation Guidelines，Difficult flag](https://www.robots.ox.ac.uk/~vgg/projects/pascal/VOC/voc2006/guidelines.html)

这个历史实例说明人工判定能够成为公开研究标签。它解决的是“能否使用人工判断”的疑问；我们自己的等级仍需要具体理由和复核记录。

### 2.3 ZInD：与本研究最接近的布局依据

ZInD在HorizonNet基线实验中，根据布局能否合理地从单个视点恢复区分simple与complex。论文将没有连续一串被遮挡角点的布局列为simple，并解释孤立隐藏角与连续隐藏结构的恢复差别。论文还按角点数、布局类型和顶面条件报告结果。[Cruz等，CVPR 2021，§4.1 Train/Val/Test Splits及结果表](https://openaccess.thecvf.com/content/CVPR2021/papers/Cruz_Zillow_Indoor_Dataset_Annotated_Floor_Plans_With_360deg_Panoramas_and_CVPR_2021_paper.pdf)

这为“不能只数角点，还要看隐藏结构与视点关系”提供了直接领域依据。它的分组服务于单视点模型恢复，不能直接替代我们的人工标注三档，也不能把simple改述成“全部四角且完全无遮挡”。

### 2.4 视觉搜索：用人的实际反应时间定义难度

Ionescu等让人判断图中有无指定类别，记录反应时间，处理个人速度差异，并检查人员对图片难度排序的一致性。图像属性是解释和预测变量，反应时间才是该任务的测量依据。[How Hard Can It Be?，CVPR 2016，§2.1–2.2；作者预印本2017](https://arxiv.org/html/1705.08280)

这篇研究适合说明“条件”与“实际困难表现”应分开。我们可以检验相同人员在某些条件下是否花更多时间，但不能把视觉搜索的时间处理规则直接用于已有的布局操作日志。

### 2.5 多边形标注：测量人工操作成本

Vijayanarasimhan与Grauman让人用多边形工具勾画主要物体，记录时间，按个人平均速度归一后汇总图片成本，再学习成本预测。论文中的易／难时间二分也是研究者规定的工作划分。[What’s It Going to Cost You?，CVPR 2009，§3.2.1及§4](https://vision.cs.utexas.edu/projects/active-prediction/vijayanarasimhan_grauman_cvpr2009.pdf)

这一任务与点选布局较接近。它提示我们可用同来源的劳动时间补充难度解释；花时长还可能来自补细节和更仔细的定位，应同时看完成内容及误差。

### 2.6 众包与心理测量：联合估计人员能力和任务难度

GLAD以二元标签为对象，同时估计人员能力、图片难度及真标签。其正确响应概率为 \(\sigma(\alpha_w\beta_i)\)，\(\alpha_w\)表示能力，\(1/\beta_i\)表示难度。[Whitehill等，NeurIPS 2009，§2及式1](https://proceedings.neurips.cc/paper_files/paper/2009/file/f899139df5e1059396431415e770c6dd-Paper.pdf)

项目反应理论（IRT）的Rasch模型常写作 \(P(正确)=\sigma(\theta_w-b_i)\)：人的能力越高越容易答对，项目难度越高越难答对。一个图像实例是TIM人脸身份匹配测验：197人完成225组三张人脸的判断，研究者用响应估计难度，并在其他人员和测试时段检验。[Jeckeln等，2023在线／2024卷期，IRT及各实验](https://link.springer.com/article/10.3758/s13428-023-02092-7)

我们可借鉴“人员能力与任务困难分别估计”的思想。布局Q是连续测量，还有结构、定位、范围及时间多个维度；为套二元模型而临时把Q切成对／错，会丢失信息。若后续确实需要表现难度，人员与图片的层级模型可以作为候选，而非此次必须新增的方法。

### 2.7 WIDER FACE与分割难度：模型困难要说明模型身份

WIDER FACE依据EdgeBox的检测率划分难度；每图8,000个候选框下，三组平均召回率为92%、76%、34%。这些是组结果，不能当作逐对象分组阈值。[Yang等，CVPR 2016，§3.3](https://www.cv-foundation.org/openaccess/content_cvpr_2016/papers/Yang_WIDER_FACE_A_CVPR_2016_paper.pdf)

Liu等的分割难度研究则以分割算法的F-measure为响应，低F-measure表示机器更难分割，再用图像特征预测。[Estimating Image Segmentation Difficulty，MLDM 2011，§1及§3](https://grail.cs.washington.edu/wp-content/uploads/2015/08/liu-2011-eis.pdf)

我们曾探索的HoHoNet特征距离与模型风险属于这类候选代理。需要与人的实际标注表现验证，才能解释人工任务难度。

### 2.8 前景分割：目标歧义与操作困难分开

Gurari等将“人们选择了不同前景目标”与“勾画同一个目标的细节很繁复”分开研究。边界复杂度相近的图可以有不同的目标歧义；论文使用多人直接判断，并与独立分割结果比较。[Predicting Foreground Object Ambiguity and Efficiently Crowdsourcing the Segmentation(s)，IJCV 2018，预印本2017，§1、§3.1–3.2](https://arxiv.org/html/1705.00366)

这与我们的范围分歧很相关：有人标当前空间，有人标相邻空间，首先要核对他们选择了什么目标。门洞交界的拍摄点位问题、OOS的表示适用性继续单列。

## 3. 当前三档已经有依据，但中间的判定步骤仍需补清

本地记录保存了真实形成过程：参考点对数和几何自遮挡初分，结合照片作视觉辅助复核，再采用研究者明确的人工修订。2026-10-16采用30条有效意见，其中26图改档、4图不变；后续继续衔接目标及单图修订。未复核图片继承此前版本。

这与“作者凭印象给整库随便贴标签”不同。现有不足也很具体：

|已有内容|还需要明确什么|
|---|---|
|参考点数、自遮挡与目标版本可追溯|原点对数、有效转折及不同目标的含义要分开|
|有逐图视觉记录、人工意见和改档历史|现行等级未全部按同一张简明规则表重新复核|
|区分结构表达负担和定位推断负担|“局部推断”“整体可控”“明显依赖推断”需要例图和可观察判据|
|有简单／中等／困难三档|“结构多但线索清楚”和“结构少但线索缺失”如何归档尚不够统一|
|有固定六转折及同人条件结果|这些验证具体条件与标法的关系，未独立验证全部三档判定|

依据：[分层形成记录](图片难度全量复核与分层标准_20261010.md)、[人工采用明细](../../../../research/difficulty/difficulty_user_adoption_20261016/README.md)、[当前单图修订](../../../../research/difficulty/difficulty_user_revision_20261018/README.md)。原记录含Codex视觉辅助、另一审核者意见及研究者裁定，论文方法应如实交代各自职责。

**5°有效转折、4%短边是后来结构条件分析的定义，不能写成最初人工定档时已执行的公式。** 文献同样只提供方法依据，不追认我们的具体阈值。

## 4. 上一轮未采用的优先方案：判定表（历史记录）

下面是建议新增的复核结构，尚未用于改写任何现行标签。

|复核项|应当记录的事实|为什么需要它|
|---|---|---|
|目标和条件|图片ID、目标范围版本、Manual或Semi、参考是否可用于该任务|同图换目标或换工具，任务已经不同|
|结构表达量|有效转折数、短墙段数量和位置、局部分支及连接关系|区分需要表达的结构数量与细节|
|关键定位线索|每处疑点可见的是顶角、底角、竖线还是邻接墙线；缺失哪部分|“有家具”本身不足以说明关键点无法定位|
|推断方式|直接可见、可由局部相邻线索约束、需要跨越连续隐藏结构推断|让他人知道中间判断依据|
|图像细节尺度|短结构的图像张角、可辨认程度；反光或弱边界只记录实际位置|物理上短和图像上难辨认并不相同|
|特殊适用性|门洞交界、OOS、范围未定、参考疑点分别记录|区分任务困难与目标／表示不适配|

重点采用两个解释维度：

- **结构表达负担：**需要辨认并连接多少必要结构，细节如何分布。
- **定位推断负担：**原图能直接提供哪些定位线索，剩余部分要靠怎样的推断。

两维先分别记录。三档标签用来概括这些事实，不必立即规定两维相加的分数。对于“角点多但清楚”与“角点少但证据不足”的冲突，先保存两维及具体理由，再用复核案例确定统一规则。

需要特别保留的对照：柜子挡住底角、但顶角和相邻墙线清楚；底面几何自遮挡为正、但局部结构仍有足够线索；四转折的远端短墙；多个连续隐藏转折。这些例子比“遮挡多就是困难”更能约束判定。

## 5. 上一轮建议的规则复现性研究（历史记录，非当前优先任务）

### 第一步：整理规则和锚点图

从既有理由提炼判断项，为每个关键判据准备正例、反例和边界例。校准阶段只看原图、指定目标和允许的参考线索，不展示Q、人员简化率、类别名单或融合曲线。用于讨论规则的图明确记为校准图。

这一步回答“规则具体指什么”。上一轮曾建议优先开展，本轮未采用该优先级；已先完成可计算条件的实证比较。

### 第二步：两位熟悉任务的人独立复核

规则固定后，让两位复核者各自记录条件及三档意见，保留裁决前的两份回答。覆盖三档、不同结构数量及容易混淆的边界案例；校准图与正式一致性评估分开。样本范围按可用时间确定，不把一个任意抽图数说成统计保证。

报告三档交叉表、完全一致比例、相差一档及相差两档的数量；有序等级可补加权kappa，并说明权重。若刻意多抽中等／困难和边界图，清楚写明这是分层复核，未经权重调整的总体一致率不代表全库。

两人一致说明规则较容易复用；规则是否对应真实困难，还需看第三步。Codex可以准备材料和指出冲突，不能替两位人类填写独立判断。

### 第三步：用现有作答检验，少量补聚合即可起步

固定六转折33图、1,023份作答中，无短边且H=0、有短边且H=0、H>0三组的图片等权简化率分别为10.7%、29.8%、55.7%。两项同人比较各有47人，分别32人与36人增加简化。这是已有的实际证据；对应3°／5°／10°转折定义的检查也已保存。[结果及来源表](../../../../research/difficulty/difficulty_mechanisms_v2_20261020/RESULTS_SYNTHESIS.md)

补充时优先检查：同一人员在不同结构／可见条件下，结构遗漏、定位误差和同来源劳动时间怎样变化。人数曲线另按固定图片集合观察。保留方向不一致的指标，而不是要求所有指标随三档严格单调。

如根据这批作答调整新规则，应将其作为开发数据，再用未参与调整的人员响应或图片检验。已有标签与已有结果的关系仍可以回顾性报告，不能改称预先冻结后的全新盲验证。

## 6. 对现有结论和人员分类的影响

**补清定义不会自动推翻现有研究。** 固定六转折的短边／自遮挡结果按具体条件计算，原答、团队端点与256条顺序也已保存。

若复核后需要改等级，按依赖关系更新：

|变化|需要更新什么|
|---|---|
|只补理由与文献，等级不变|方法说明、例图、术语和讲解稿|
|部分图片改等级|难度分组统计及相应曲线重新聚合；原有端点通常可复用|
|改动影响人员方法的困难／简单条件|检查DSTRUCT、RFUSE、DBOUNDARY、DJOINT、MSDGEOM及scope联合类的特征、支持与楼外拟合；RFUSE还需检查内层alpha；保留旧版实验身份|
|新分类进一步改变实际选员|先查已保存团队；仅缺失的必要团队才涉及新增融合|

所以值得补的是明确的分层复核。是否进一步重算人员分类，由实际改档范围决定，不先展开全库重算。

## 7. 上一轮讨论稿（历史记录，当前采用说明见顶部实证报告）

> 图片难度不是图片自带的一个统一分数。已有研究有的按尺寸和遮挡分层，有的测量人完成任务的时间，也有的从多人作答估计难度。我们的任务是恢复指定空间的完整布局，因此重点看两件事：要表达多少结构，以及原图能提供多少定位线索。现在的等级由几何初分和人工复核逐步得到，短边、自遮挡与同人标法变化已有数据支持。当时建议下一步统一判定表并开展独立人工复核；该优先建议随后未被采用，现阶段已完成几何条件比较。

讨论时可以明确提出：**将“难度”作为需要解释和验证的任务属性；将转折、短边、可见线索等作为具体条件。** 这样既保留三档的组织作用，也让读者知道到底哪些条件与标注差异有关。

## 8. 本次核查范围

三名子智能体分别查阅人工标注与视觉搜索、视觉基准、众包与心理测量；主线程复查核心原文定义，并对照本地方法史和已有结果报告。KITTI、ZInD与WIDER的部分依据来自官方页面／论文的搜索索引全文摘录；其他关键条目读取了原文方法部分。本文没有复算文献数据，也未进行新的人类一致性评估。

文献可支持本研究选择怎样的定义方式。三档之间的具体界线，仍需由本任务的规则、例图和复核说明。
