## 1. 用户目标与范围

用户希望检验：同一房间布局结构相近，虽然视角会改变可见范围和难度，整体标注质量或人员表现可能仍有相似规律。主动寻找能迁移的规律，同时报告不相似的房间、视角和人员；不能为得到相似结果删图、择人或挑划分。

|研究|要回答的问题|比较／预测对象|
|---|---|---|
|A 同房质量|不同视角的平均质量、分布、人员排序是否接近？|图片质量及逐人差异|
|B 多图历史迁移|已知多数视角，能否估计剩余视角的平均质量？历史图更多是否更好？|留出图片均值、分布及房间内变动|
|C 人员重放曲线|同样人员按同样顺序加入时，不同视角接近GT或参考终点的趋势是否类似？|真实融合过程及留出曲线|
|D 个人质量预测|已知人员历史及同房源图表现，能否预测此人在留出图上的Q？|保留原个人Q支线并扩展多源|

T并列研究，源报告耗时与目标匹配耗时分开，不解释为认真程度。人员类型及同类人员规律待分类验收后接入，本阶段不扩展其它人员变量。OOS排除（含OOS与门洞重叠），门洞交界单列；参考／范围不适用和失败原因照实记录。

## 2. 统一阈值：历史图片严格超过50%

用户已确认“>50”指**历史图片占房间可分析图片的比例超过50%**，不是重复次数、人员数或质量分数。

令有直接分组依据的可比视角集合有N张合格图，历史H、留出V互不重叠且覆盖该集合。主规则为：

`|H|/N > 0.5` 且 `|V| >= 1`，即历史张数 `m = floor(N/2)+1, …, N-1`。

统一的是比例准入，不是各房间固定相同历史张数。**所有符合条件的m均做，最低严格多数为统一报告起点，再比较所有更高实际比例。** 不按最终误差事后只保留最好比例；无需额外铺设60%、70%、80%等会产生取整重复的标签。

|7张合格图的例子|实际历史比例|验证图数|历史组合数|
|---|---:|---:|---:|
|4张历史|57.1%|3|35|
|5张历史|71.4%|2|21|
|6张历史|85.7%|1|7|

七图共63种划分。历史图片求均值与顺序无关，因此枚举组合；人员重放才枚举／抽样排列。同图可在不同划分轮换角色，但每次都严格分开历史和验证。

N>=3进入多图主设计；N=2保留成对研究，不放宽多数规则。一张历史图保留辅助基线，用于衡量多源提升。各指标先冻结合格图片集合及N，再划分；同时记录原声明组图数和有效图数，不依分数表现改变分母。

高历史比例意味着验证图片减少。各m先对相同目标图汇总其所有可用历史组合，再比较误差；不能拿不同目标构成比较“历史更多是否更好”。若后续应用必须选择唯一比例，在训练建筑选择、外层建筑评价，同时报告历史获取成本。本轮先完整回答比例与收益的关系。

## 3. 分组与人员支持

采用[已有用户分类接口](../../../../research/same_room/relation_adoption_20261016/CROSS_MODULE_RELATIONS.json)、原组、声明子组及明确合并组。G编号可以重叠，不等于唯一房间；建筑也不是房间。不得由A—B、B—C关系推导新A—C事实。相同有效图片集合去重并保留来源，不把重叠集合拼成更大房间。

2026-10-19只读可行性盘点：从 `candidate_adoption.json` 取支持物理关系且范围可比的声明集合，连接v2 `shared_records.csv` 的合格池、普通manual、现用目标匹配和 ordinary_primary 质量，每图至少3名有效人员；检查组内每对有已采用、范围可比、无实质冲突的直接关系。有效图片集合去重后有 **9个至少3视角的声明集合**，图数分布为3张×3、4张×3、5张×1、7张×1、11张×1。它们可重叠，**不是9个独立房间，也不是最终研究总覆盖**；正式盘点还需对照原组及明确合并来源并输出逐组清单。

上述集合全组共同人员数为0人×2、1人×1、7人×1、9人×2、12人×1、29人×1、30人×1。v2支持扩大研究，但成对交集大不代表全组交集大。

- **固定共同人员面板**：可支持的整个视角集合固定同一批人员，比较均值与配对重放。主配对重放至少3名共同人员；合格池内k=1、2保留，沿用k=2解释限制。
- **实际覆盖面板**：各图用各自合格人员池，研究实际均值迁移及可用曲线；记录人员组成，不把所有差异归因视角。全组交集不足时继续做均值／个人预测，并在有直接依据的支持子集做配对重放。

两种面板分开报告，不以最严格全组交集阻塞全部研究。新旧人员分列并保留合并覆盖描述，不按预测效果重新分类。

## 4. 实验定义

### A／B：质量与多图历史迁移

第一基线：每张历史图先算人员Q均值，再对历史图片等权平均，用来预测每张留出图均值。不能混池全部历史作答，让人员更多的图片自动获得更大权重。共同人员、各图实际人员两种口径分别计算。

逐划分保存历史／留出图片、人员支持、历史估计、每张目标真实均值、带符号误差与绝对误差；描述中位数、分位数及人员排序。比较各m的MAE、偏差和划分间波动。均值接近、分布接近、排序一致分别解释，不强制压成一个“相似”标签。

对照依次为无房间信息的训练历史均值、单张同房历史、多张同房历史。有确认异房或其它背景对照时，匹配历史图片数量、人员支持及可用图片条件；关系未知的图片只称未知关系对照。对照不足不阻塞主实验，也不据此声称同房特异性成立。

### C：真实人员重放及曲线迁移

复用现有已验证融合实现及过程接口，明确算法、数据、参考与输出身份。v1过程只作历史对照；缓存复用检查完整输入绑定，不能直接改称v2。

固定共同人员池P和同一批排列π，各视角在k处使用同一人员前缀P_k实际重新融合。前缀不读取后来成员或GT来选择输出，不以平滑线代替失败节点。先复用可核验排列；新增路径建议预先固定种子及256条配对排列的首轮预算，小池排列总数更少则全部枚举。运行前写入实验清单并报告抽样波动；此预算仅针对新配对路径，不覆盖旧Lee子集均值实验的精度合同。

最小曲线预测器：**逐k对历史图片的质量曲线等权平均**，预测每张留出图同一路径的质量。先做直接基线，再判断有无必要加入简单历史水平校准。逐路径配对与所有路径平均曲线分别交付，不能用平均趋势替代路径相似性。

|观察量|定义|
|---|---|
|GT质量水平|同k的B8L2及适用几何分项，D10匹配敏感性|
|增益形状|各曲线减自身k=1后比较增益方向／幅度，不拉伸人数轴|
|波动|相邻k变化、质量回落、同k不同路径的变化|
|参考终点差|Q(k)−Q(P)的带符号差及绝对差，Q(P)为该固定池全员结果|
|曲线预测误差|历史预测与留出曲线的水平差和增益形状差|

**全员结果是参考终点，不是理论上限。** 部分组合可超过它；GT质量与融合自身变化不同，不强制曲线单调。最高观察分数也不自动是稳定上限。

目标图自己的k=1及全员终点只能用于事后形状／终点描述，不能输入绝对曲线预测器。以后研究达到目标所需人数时，先在训练侧定义目标和持续条件；本轮先交付连续曲线，不等待阈值研究。

人员池不同的补充曲线按共同绝对k比较，支持数逐k报告，不外推缺失k或按各自最大人数缩放横轴。全组固定池与局部子集固定池分开，不能拼成假想大池。

### D：个人Q预测保留并扩展

保留[已完成的v2个人Q预测](../../../../research/same_room/same_room_v2_prediction_20261019/README.md)。多源特征先用本人在H中多图的Q均值／残差及源图其他人员背景，继续比较历史基线、直接迁移、加同房模型。本人未答历史图记缺失，支持不足单列，不因此整组删除均值研究。

学习参数、人员画像、模型和阈值选择在目标建筑外完成。外层测试建筑内预先指定H允许作为同房条件输入，V目标质量只用于评价；每个划分重新遵守隔离。源Q已知是条件预测设定，不等于无GT部署。

旧“4→16人预测误差下降”是源信息预算实验，属于D补充，不是C的融合接近GT曲线。历史图数m与融合人数k是两条轴，分别变化和记录。

## 5. 枚举、计权与检查

当前盘点最大11图，严格多数历史组合共1023种，均值阶段可全部枚举。历史均值和曲线聚合复用已算结果，不为每个划分重复重算同一人员前缀；融合按唯一图片、成员集合、算法及参考绑定缓存。

每个m先对同一目标图的不同历史组合误差求均值，再形成组内结果。组重叠保留来源；建筑汇总先对同一目标图的重复组来源作等权聚合，再目标图等权，最后建筑等权，组明细另报。跨m使用共同可评价目标面板，完整覆盖另列。组合、路径、图对数量不能当独立房间样本数。

报告建筑方向、效应大小、划分分布；建筑支持足够时补建筑级不确定性。图片区间、组合波动、总体推断区间分开命名。少量建筑仍可给个案与实用预测证据，不因不能认证普遍规律而停做。

最小检查：历史／目标图隔离；严格多数且留出非空；目标标签不进特征；同路径人员顺序一致；固定m/k的目标支持可核对；评分／算法／输入匹配；失败缺失不填零；OOS、门洞及旧训练限制不放宽。

## 6. 推进顺序与交付

1. **组级清单与划分表**：固定v2声明组、各指标有效图片、人员支持及排除；枚举严格多数历史划分，交付逐组逐划分记录。
2. **先完成均值迁移**：A/B全覆盖，D保留旧结果并做最小多源扩展；交付各历史比例误差、建筑方向、成功与失败视角实例。
3. **实算配对重放**：先覆盖全组共同人员充分的集合，再做有支持的直接子集，完成C的绝对曲线、形状与终点比较；不等人员分类或异房对照全部齐备。
4. **综合解释**：固定目标面板比较更多历史的收益，同步补已有支持的背景对照。负结果检查视角、范围和人员组成，不通过更换阈值消除。
5. **人员类别后接**：分类验收后复用相同设计比较同类／混合人员，不提前认证稳定类型。

新实验包分别交付均值、个人、曲线结果，附组级覆盖／划分、逐建筑误差、代表性视角与路径图、来源和字段合同。分别回答“质量是否接近”“曲线是否类似”“能否预测”“更多历史是否有用”，不只给一个总误差。

## 7. are-you-sure 审查记录

### 审查决定（Decision）

**修改（Modify）**：采用多图历史—留出设计，修正上一轮偏向个人Q预测的范围；统一严格多数规则，个人支线与真实重放并列。

### 有效性

v2现有包提供成对描述和个人预测，不能替代真实融合路径。旧[曲线报告](../../../../research/same_room/same_room_quality_curves_20261015/README.md)明确是逐k子集平均，且七视角组全组共同人员仅2人；当前v2只读盘点支持扩展，但仍须逐组分配研究，不由图对人数外推整组。

### 简单性

历史图片均值／逐k平均曲线是足够直接的首个基线；复用评分和融合。枚举实际m比设置取整重复百分比简单。旧报告显示多张背景图均值可胜过单张同房源，说明应匹配信息预算，而非先造复杂预测器。

### 后果

重叠组、重复划分放大表面样本量；全员终点不保证最优；源Q已知不是无GT部署。保留来源、建筑汇总、终点定义和输入边界即可处理这些风险，无需推迟已有支持的研究。

### 修订建议

按第6节实施，所有可行的严格多数历史组合完整报告，更多历史是否更好由结果回答。当前只完成目标整理、只读可行性盘点和文档同步，新多图预测／融合尚未运行。
