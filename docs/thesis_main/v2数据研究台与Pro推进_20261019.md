## 两条研究方向都继续

**正向方向：Q×T×难度产生可解释细类。** Q的绝对交付与相对表现并列；难图绝对质量好、相对同图他人好、相对本人平常更好，分别定义。“难度纳入细类”不是只做难图汇总表。连续画像作为信息底座，粗类用于解释，细类用于组队，不预先限定最多四类。当前相对Q与时间阈值为探索设置，不是已验证能力等级。Semi、scope、排除及结构错误可继续细分，但不揉成Q或通用综合分。

**反向方向：从当图标法簇出发。** 沿用既有距离，优先研究全局亲近度9°/12°，完整链接作对照；不同点对数分开。先比较固定背景成员时簇内/跨簇换人及簇构成，再回看成员Q/T/难度等特征，最后用未参与发现的建筑检验是否能预测。簇号是图内编号，不能直接跨图当人员类型。分簇、融合与质量评价分别承担不同职责。

两条方向最终比较同图同k下随机、Q、Q+T、Q+T+难度及进一步细分策略。直接用当图实际标法选择的方案另列解释性/oracle结果，不能混为人员历史画像的预测成功。接受高Q组合共享遗漏、簇内换人也会变、跨簇不一定变坏等反例。
