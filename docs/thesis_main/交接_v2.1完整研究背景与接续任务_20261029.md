## 2 用户真正要研究什么

用户把不确定性分成图片一侧和人员一侧：图片结构、可见条件、拍摄点位、目标空间和表示约束影响标注；不同人员又会选择不同范围、保留不同结构、画在不同位置。质量评价和完整共识是两项方法，用于衡量并研究这些差异。

主线应串成：**任务与原答差异 → 质量评价 → 完整结构融合 → 图片条件与难度 → 人员画像和分类 → 混合配比及类内/跨类换人 → 人数与进入顺序 → 同房重复性 → 门洞和OOS。** 各专题可独立产生结果，不以某个人员分类的分差大小代表整项研究价值。

必须继承的要求：

- 独立判断Pro、Dot、旧报告、代码和用户猜想，查实际数据。用户允许得到负结果，也允许挑选有意义的方向；选择应来自比较，而非先凭直觉认定一种方法最好。
- “好看的结果”后来已明确为**有解释的差异**：升质、降质、节时、费时、几何和结构变化都算。不能把任务重新收窄为最大Q收益。
- 采用多数和条件规律，不要求每个人、每张图都满足。个别反例可以提供机制，不应自动否定整条发现；平均效应和正向人数/图片数分别报告。
- 人员类别是当前数据中的工作分类，不是永久人格或唯一真类型。允许多套合理分类回答不同问题，但希望有一个容易解释的主方法。
- Manual为主、Semi为次。允许使用同一人的Manual、Semi、scope等历史联合建类；质量、融合、时间和失败结果按条件分别评价。
- 原先换1—2人不足以回答整体构成问题。需要真实人员池中的完整有限配比、大块/半数替换、类内换人及背景变化；不只比较地面BEV，要看质量各分项和其它有意义的输出。
- 原答分歧、同人数换组后的融合波动、同一路径增人的变化是不同问题。不能用一种替代另一种。
- “同房”是用户已有的直接物理房间关系，不是同一建筑，也不是浴室/走廊等同用途。新人、新房间和不同融合算法的普遍推广不是当前任务；不再自行扩展此类验证。
- 需要人工判断时可以问用户，但先追查原记录，不重复要求已经完成的空间或GT确认。真正缺少的判断要给具体图、目标、候选和原因。
- 学习效应已通过教学视频和练手题尽量控制。用户明确不再研究这个变量；不宣称训练证明学习效应为零。
- 外部粗审只采纳有效的实验与逻辑建议，不把其保守清单全部转为必做实验。人工质量偏好是诊断意见，不以Q与主观判断“高度一致”为目标；失败/缺Q不填0。
- 文档和讲稿讲人话，条件、比较对象和结论写清。避免“提分”“救不了”“证据组织了差异”等口号；不要每句附免责尾巴。按[写作SOP](SOP_论文写作_避免AI化与防御性表述_20261027.md)执行。
- 论文提纲通常只给具体修改方案，未经新授权不改Word提纲或代写正文。研究台保留所有有价值内容，由用户和导师再取舍，不限最终论文篇幅。

### 3.6 v2与v2.1的继承关系

### 8.3 团队大小、替换比例与门槛

严格ABC定义A=D∪X，B=D∪Y，C=D∪Z；X/Y同类，Z目标类，每块m人且四块互斥，每队n人。需n+2m名不同人员、来源类≥2m、目标类≥m。因此35人池、m=7时n最多21，不是只采集了18人。

同类幅度`|Q_B−Q_A|`，对称跨类幅度`(|Q_C−Q_A|+|Q_C−Q_B|)/2`；跨类减同类表示区分度，CA或CB表示方向。C落在A/B分数之间时，对称跨类恰为同类一半；这类Q反例可以同时有更大几何变化。

固定n增m、固定XYZ加D、直接AC、完整配比是不同实验。固定7人块10—21人的路径已有70%、50%、35%、33.3%等比例，旧队新评分结果保留。n18/m7共同背景有11人，但不是每个结构都有11票：门槛9时，固定对应下背景0—1票即使补7也不足，2—8票可能由替换改变选留，9票以上已达票；对应、位置、连接仍会变。

zs-16固定21人只改10/11票门槛，B节点6→5、Q92.467→45.844，而C不变，是算法离散决策的机制例，不是人员能力突然变了。n与m比例改变时应同时看这些机制，不把所有变化解释成类别优劣。

## 10 其它研究主线不能丢掉

### 10.1 两项方法各自的证据

Q基于底面IoU、底边角距、自身方向残差、均高误差和局部高度误差。B8L2与D10只在方向尺度8°/10°不同；D10分数较高不等于更好。完整公式和参数见[统一模型第4节](研究模型_人员图片与融合不确定性_20261006.md)及[术语表](CONTEXT.md)。真实I=0的实现连续极限可为Q=0，与失败/缺参考填0完全不同。

3D IoU对照必须保留。人工点对可能不严格自洽，均高棱柱IoU可能淡化局部高度错误；不能扩写为所有现有评价都看不到局部误差，HorizonNet还含墙面/深度评价。创新点依据具体测量能力和真实响应，不靠宣称旧方法全面失效。是否“首次”需专门文献证据，本交接不新作优先权判断。

完整融合包括周期对应、独立人员支持、位置估计、来源连接与输出状态。v2.1共同面板48池138队三法，普通Manual墙线法相对medoid n4均Q+7.109，n16−5.567；方法贡献保留，同时呈现适用条件。Lee没有顶部不是底面融合失败，人工确认对应不能混成纯自动成绩。历史2t7-06、e9z-19、q9-30有限案例保留版本，不重复充当当前全域基线。

失败有科学价值，但需分清真实无法形成结构、连接失败、缺参考、未执行、方法不提供测量、延期和网页没找到兼容保存结果。页面“没有兼容已保存融合”不是该图实际融合失败的证明。实际失败也不单凭一个状态证明一定由高人员分歧造成，要接票账和结构。
