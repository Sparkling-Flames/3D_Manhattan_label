**v1已经具备开展完整一轮有限实证分析的材料。当前主要缺口是新旧证据定义衔接、结果消费同步和少量实现问题，不是没有数据或必须等待v2。** 融合208图、同房9对过程、人员策略和门洞过程均有真实底表。大量路径提高了对当前人员池的观察覆盖，但没有增加独立图片、建筑或人员。

人员Pro的总体框架值得采用：绝对质量、连续任务调整Q、Q/T描述类别及带机会分母的可靠性证据并列；当前没有足够依据建立通用人员总分。不过，**不宜原样接收其全部可靠性标签和最新进度陈述**。发现了漏读审核措辞的实际问题，以及scope和严重失误归因需要收窄的地方。Pro的7图组合实验仍有价值，但属于较早的固定面板；“同房过程为0”不能描述当前仓库。

本轮核查了报告、关键代码、实际表和原线程近期指示；独立复算Q效应与预测、核对跨模块主键、重汇总关键分母，并运行6个相关测试文件。未重新生成全部融合几何，也未逐图认证所有自动墙线身份。数值复现、数据衔接和研究结论有效性分开判断。

## 3. 人员Pro：需要修正或降级的部分

### 3.1 修改后仍有问题的审核记录漏了两条

Pro的`study/reliability/build_correction_ledger.py`第27行只用字符串“没改对”生成`reviewer_residual_after_edit_statement`，漏掉两条“这个改了一点模型的预标注,但是还是不太对”。

|人员／图|object_id|应保留的证据|
|---|---|---|
|W035／B6-10|b62a4df9e1645fe7|审核者指出改了一点但仍不太对|
|W037／B6-10|717840fe8221eba6|同上|
|W037／e9-39|28935ccbb578589d|“这错误预标注他也没改对”，Pro已识别|

三条当前源裁决都是`usable`，不能改称invalid；也均不属于六任务的实际缺陷gold。最小修正是按对象和原评论保留三条审核证据，并说明机制尚未完全指定。不能把它们直接加进156次明确缺陷机会的分母，也不能因未纳入强gold而删掉审核意见。修正后再接入人员解释表；原Pro包保留不改。

### 3.2 288→156及39→25不是同分母的结果更正

旧人员包的288次机会以历史trap标签为基础；新Pro采用六个专家实际缺陷任务。二者必须保留证据强度和人员覆盖的桥接：

|---|---|
|旧288与新156共同|144次|
|旧独有|144次natural trap标签；缺本次采用的实际缺陷gold|
|新独有|12次，W019/W026各6次；历史排除人员可进入行为证据，但不恢复主训练/融合资格|
|旧36次未改与新25次未改共同|20次|
|旧未改独有|16次natural trap标签|
|新未改独有|5次，均W026|

旧39还含上节3条改后仍有问题的评论，不能与新25次“已知初始坐标缺陷且未改”直接比较。新156次中的131次已改、具体缺陷是否消除未知，不能计算成修复成功率。旧自然初始化问题仍作为单列线索保留，并非被证明无错。

### 3.3 Scope“误拒”必须保留兼容筛选的条件

Pro的`recover_scope.py`采用历史明确in-scope、当前scene为clear、非OOS等条件筛面板，并未重新独立裁定每个当前目标空间的scope真值。因此38/286 Manual、10/78 Semi，宜表述为“历史明确可标且与当前clear标签兼容的面板中的误拒”。

W030的9/11是该面板的可核查事实，也值得解释，但不足以直接判定其一般范围判断能力差。门洞、开放边界、多空间和不可观测性的当前定义不能由这11图替代。后续优先检查涉及范围政策变化的少数任务；不必把全体作答重新人工打分后才能推进。

### 3.4 25条具体记录不应一律称独立确认的严重个人错误

新25包含旧10，新增15来自同一批85条历史剔除记录的重新文本编码，并非新增15次观察。较宽68还包含未给机制的不接受和政策歧义。因此建议使用“具较具体个人错误依据的历史剔除记录”，另保留严重性依据、政策相容性和未知。

两个例子说明边界：W031／7y-13“标的太歪”、W033／Uw-10“偏得离谱”包含主观幅度判断；后者还有图级范围歧义。W001／Uw-08（`f21c670566821ce7`）评语为“oos,但是他只标了3个点”，scope台账同时为正确拒绝。当前[标注员说明](../label_studio/README_ANNOTATOR.md)第72、105行允许OOS只做到支持范围判断；需核对当时任务要求，不能直接把这种几何不完整推广成一般严重质量失误。本轮维持原清洗裁决，只限制研究归因。

审核接受表示当次可接纳，不等于“已证无错”。1024/1067等可判集合仍受定向审核选择影响；由这些记录拟合的概率不能称总体错误风险。也不能把几何剔除、scope拒绝及初始错未改的事件并集变成第二轮扣分。

### 3.5 Pro的状态快照不代表当前仓库

Pro融合实验来自旧7图主面板，报告“同房完整过程为0”；当前已核实208图融合、9对同房过程。应保留Pro的固定构成实验，与最新广图策略结果并列；不能用旧覆盖说明否定新交付，也不能将新覆盖回填成Pro当时已完成。
