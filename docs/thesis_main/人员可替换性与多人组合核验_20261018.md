## 2. 高Q且快，是否更有规律

**有局部、可复算的信号，值得保留为候选细类。** 下表以高Q快人员为锚点，每个k只比较同块两臂均有底面的背景，先图内平均再8图等权；V是融合底面的1−IoU。行内可比较同类／跨类，不据这张非固定链表推断人数因果效应。

|人数|同为高Q快的替换V|跨其它类替换V|同类V更小的图片|
|---:|---:|---:|---:|
|6|0.0500|0.0735|6/8|
|8|0.0372|0.0790|6/8|
|12|0.0197|0.0253|3/8|
|16|0.0312|0.0685|5/8|

这支持“某些细类中的人员相对更可替换”，不支持“同类换人不变、跨类必变”。高Q快类内完整几何严格相同率在四档仅0%、4.17%、3.125%、0%。相对Q三档整体的同类V反而各档都大于跨类V；不能泛称任意细分都有规律。三种方案抽到的锚点和替换者不同，也不能把两者直接当作同样本预测优劣检验。

稳定性与质量收益分开：高Q快对其它类的方向表统一为“高快−对方”，保留每图正负。比如6人时相对高Q慢的平均质量差+2.53，但7张质量可比图仅3正4负；12人时相对低Q慢平均−1.05（5张质量图）。不能由平均V较小推出始终更准确。

人数口径已纠正：全描述画像高Q快有3人，按目标建筑外画像各图池为2—4人。前轮B6-11和rPc-06恰有4人，但各只有一个纯高快四人集合，不满足“至少两个可替换集合”的抽样条件。此次是在大队中的一个席位检验高快人员，并未生成不存在的6—16人纯高快队。

## 3. 本图实际作答分簇的作用

8图191份原答生成2185个成对范围距离，并重放两类探索性分簇：范围相似簇只看底面距离；结构标法簇严格按点对数分层，保持上下点绑定和现有环序，再看位置。不同点数不因范围近就合为同标法。范围0.1／0.2／0.3、结构6°／9°／12°分别作敏感性，阈值未用融合输出或人工偏好调优。

32个图片×人数条件中，28个“原答距离—融合替换V”的Spearman相关为正，范围−0.220至0.657。当前图上画了哪些结构，确实与换人影响有关；这只是重叠替换对的描述关联，不是独立预测准确率。111对原答底面距离≤0.2但点数不同，说明范围相似不能代替结构相同。

同时核对了既有全员状态的1047个节点成员：比如Uw-09某身份组仅11票，而全池门槛为12。替换同一质量类的人仍可能改变节点支持、定位或连接。子集会重新对应，不能拿全池簇当作所有子集已知身份；本轮实际重放保留身份与几何变化，而不是按全员结果推测。

16人反例`SWAP000927`固定15人，仅将同属低Q快的W010换成W012，两个结果都是4节点，但V=0.4673，B8L2从14.41到26.15。节点数相同不是内容相同。更多实例与原答／融合叠线在离线页中，结果后挑选的例子不表示总体发生率。

## 4. 反向发现可互换关系能否迁移

用户提出先从输出发现可替换人员，这可以作为探索。此次用背景0发现，背景1复核，同图、同人数、同替换人对保持；背景之间仍有重叠，16人时平均共用10.91/15名背景人，不能称独立新样本验证。

- 背景0完整几何严格相同的21个机会，背景1有19个完整可比，其中17个仍严格相同。21机会含重复人数／方案，不是21独立人对；18个机会的两份原答底面本来就相同或数值等价，不能包装成已发现新人员类型。
- 背景0范围V≤0.01的451个机会，背景1有445个可算，343个仍≤0.01；最大变化达到0.755。这个阈值是探索标尺，不是经验证的稳定线。
- 跨图同人员对×人数有680个单元，其中344覆盖至少2图、最多5图；已列出支持和变化，尚未强行聚成全局人员类型。

下一步应保留两层类别：楼外人员类别作为先验，当前图的结构标法和节点支持作为实际行为，再观察不同人数及支持比例的共识。若继续从互换关系发现新人员细类，应在发现建筑形成规则，在另外建筑固定规则检验，并与Q／T类别使用完全相同的交换对比较。不要把“用于定义类别的稳定”又当作类别有效性的证据，也不要求类别内每个人在每图都完美。
