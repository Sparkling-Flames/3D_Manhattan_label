# 人员多变量反向分型：双线任务与验收（2026-10-19）

## 当前目标与状态

用户最新目标：寻找几个稳定、可解释的人员类别，使多数有支持的图片及团队背景下，同类成员相互替换的融合结果通常相近，而跨类替换产生更明显、可重复的差异。允许先在探索数据中发现类别，再解释和验证；不预设类别一定存在，也不把“所有同类都不变、所有跨类都大变”作为唯一成功标准。

候选变量包括绝对/相对Q、低尾与波动、T、难度适应、Semi修改/纠错表现、已知错误预标注未改的盲信证据、scope回答倾向及相容裁定、历史标法和具体错误倾向。不是只交叉Q/T/难度；不预设最多四类，不将这些变量揉成一个总分。

本次已完成任务划分、输入可用性核对和文档索引更新；下述A/B新实验尚未启动。用户自行向Pro提供提示词并提交GitHub main；Codex不代发Pro、不提交或推送。数据、评分公式、准入及人工裁决不变，N1仍未接入。本文件是探索研究工作安排，不升级为规范worker tier或采集SOP。

## A：Pro具体任务

1. **两个候选来源都保留。** 正向以Q/T/难度/Semi/盲信/scope及标法特征形成可解释候选；反向先在训练建筑建立人员共簇、结构行为和替换效应关系，再寻找人员分区，最后解释这些类。禁止把反向路线简化为再测一次原Q/T标签。
2. **类别数由支持量和验证表现选择。** 4/6/8/10可作候选范围，不是强制数量。类别至少要有真实可替换人员及足够共同图/建筑；单人类、无比较机会类和低覆盖人员单列，不能以它们抬高类内稳定率。报告分区稳定性时按人员对共类关系比较，不能直接比较任意类编号。
3. **关系不强制传递。** A≈B、B≈C不保证A≈C；检查整个类内部的尾部风险。全局硬类别作为主要候选，同时比较基础类别＋难度/Manual/Semi条件细类。条件必须可解释且有支持，不能为每张测试图另定类别。
4. **分训练与验证。** 延用目标建筑外框架；特征变换、支持门、类别数、阈值、模型选择和类别解释均在训练侧完成。需要调参时用训练建筑内的划分。全量类别仅作描述，逐折类别用于评估；训练图和验证图清单保存。v2已有多轮探索，不能称全新外部盲测。
5. **发现类与解释类分别验收。** 如果用历史换人关系发现的类有效，但Q/T/行为特征解释不了，报告解释不足；若简洁特征规则逼近分区，再独立验证该规则。不能事后给类起一个好听名字就称可解释。
6. **消融与负结果。** 对相同可比人员/图/背景，比较Q基线、旧QT/QTD、多变量正向类、反向类；分别移除Semi/盲信、scope、难度、标法特征。区分类别效用、选人质量收益和成本取舍，不用一个目标失败否定其它目标。

## Semi、盲信与scope的证据边界

旧574份Semi有初始化；156个确认错误机会、25个错误未改。新525份缺逐份初始几何；284个报告错误机会、45个报告未改。两层分开计数，没机会/没证据不是零盲信；编辑不等于纠正。任务调整后Semi最终Q与净改善可能重复表达同一效应，不双计权重。

scope有9845份回答，但相容裁定仅93份（保留89），全是有限in-scope且均正确；当前这项正确率几乎没有区分人员的有效变异。允许研究回答/拒绝倾向和空间选择模式，不能称OOS识别能力，也不把图片OOS标签当个人金标。只有明确同任务/条件可比较时才解释人员差异，防止把任务分配或批次来源切成伪类别。

## 验收与人工介入

同时检查：类内变化及坏尾是否下降；类间差异是否有实际意义；类别在训练建筑变化后是否稳定；是否跨足够图/建筑有效；解释规则能否用于其他图。小类覆盖损失、反例和条件依赖必须报告。实用成功不要求所有人硬归类，也不把区间跨零解释为等效或类别不存在。

人工介入只在需要校准“变化是否重要”的代表性叠图、既有未决参考/结构语义时提出具体案例，不把用户复审当整个数值研究的前置。单人面对同图的重复标注噪声，目前无足够重测设计，不能由跨图变化直接估计。
