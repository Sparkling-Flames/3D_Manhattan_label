## 2026-10-21当前要求与仓库核验

**用户最新澄清：反推是一种探究方法，不是唯一必选路线。** Q、T、难度、scope、Semi可任选2—5个变量域组合，用来发现并解释人员类别；结构表达也是有价值的候选依据。这里的2—5指变量域数量，不是类别数，也不要求每个域只有一个指标。五域共有26种二至五域子集；应逐项核对支持和研究状态，不能把大量算法/类数变体当成已覆盖这些子集。研究期待是找到“同构成换人通常较近、改变类别构成产生可重复差异”的有用分组；该期待用于提出问题和评价候选，不用于事后强行做出正结果。

三种路线可以竞争或结合：①多变量正向分组，②从跨图原答关系或训练侧团队效应反推分组，③结构/位置尺度特征分组。Q/T等既可参与分组，也可事后解释；不再限定为现有M类的解释栏。**纠正此前进度遗漏：10月20日已经实现真实替换关系反推，后续还有直接m2块学习；缺的是系统的大团队构成评价与有用分类的进一步确证，不是反推代码尚未实现。** 反推也不是其它路线成功的前置条件。已有Manual/Semi工作分类继续保留，是否最终主用须看整体构成效用及可解释性。

### 下一轮人员研究的共同验收目标

1. **补齐变量域覆盖账，而非强制一种算法。** 对26种子集分别登记已有候选、实际支持、是否仅筛查、是否进入构成验证；补做有支持而未研究的组合。可用交叉分层、聚类、交互模型、反向关系或其它有效方法，也可保留连续特征对照。单变量与结构类是有用基线，不预设类数或保证细类有增量。
2. **以整体构成、大团队、配比和类别块为主。** 逐图按真实类别容量研究可行总人数/人数向量、跨粗类及同粗类内细类替换；同类容量不足允许部分替换。单人替换用于机制补充。比较类内/类间变化幅度时对齐实际换人数m，或明确给出m响应；整体跨类整块效应仍可独立保留。
3. **分别完成并登记构成与成员的枚举。** 列出所有可行配置、独特成员集合、需要研究的加入过程；确定性融合的相同集合只算一次。先用现有缓存和实测吞吐估算成本，再扩大覆盖；算不完的精确报告未完成空间，不能把抽样改称全部。全员只有一个集合，不能用零波动证明分类有效；小类容量只有一个团队时类内波动不可估计。
4. **评价原答、融合及各质量分项。** 沿用当前冻结B8L2/D10及其分项，比较适用3D代理、上下界/位置、局部转折/结构、范围、完整率和失败；分清正确性与稳定性。先报告真实类别构成的总差异，再用历史Q、T、来源、难度等匹配或消融解释附加信息；不以Q配平为所有效用研究的前置要求。
5. **支持解释与反例同时交付。** 逐类列人员、定义、机会支持、代表原答和失败案例；细类须说明比粗类/连续变量多解释什么。盲信仅在相应错误初始化机会下解释；scope回答倾向不等于裁定正确率；个人筛除原因不等同严重错误率。分类可用Manual/Semi单独或联合历史拟合，实际效果分别评价；明确分类输入条件和评价条件，缺少某域不补成零，也不因此丢弃其余有用证据。
6. **探索可以积极，结论必须可追溯。** 训练/发现侧可反复搜索有前景方向，目标建筑之外生成类别，记录选型过程；在冻结检查上报告好坏尾、方向不一致和失败。已经反复使用的v2留出只称内部检查，不重新包装成从未见过的数据。新候选不覆盖旧标签或追改原评分/资格。
