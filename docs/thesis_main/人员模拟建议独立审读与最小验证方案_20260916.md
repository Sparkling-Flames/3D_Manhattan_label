# 人员模拟建议：独立审读与最小验证方案

日期：2026-09-16。性质：历史假说讨论备忘与既有原型审读。**用户最新要求先搁置相关假说，此前授权的Pro探索现暂缓；下文保留当时判断与备选设计，不作为当前执行方案。**[旧提示词](../../analysis_results/image_portrait_20260914_v1/prompts/PERSON_TYPE_HYPOTHESIS.md)同步标为暂缓。当前按[独立真人采集、离线组合及新增15人各50图规划](第一阶段执行与人员分类续研说明_20260913.md)理清主线，不改变正式协议。

## 1. 判断及研究位置

用户最新讨论方向是：**结合图片信息和既有候选人员分类，用简单的类型条件模型模拟各类人员的标注分布，再检验不同人员组合随人数增加的不确定性与收敛过程。**分别研究标注前预测、观察前k名真人后的更新、完整历史的描述与审核。它不以额外采集多种备选标法为前提；备选采集只是以后可能讨论的一项扩展。现有数据支持检验的可行性，尚未证实这项完整假说；仍按上一条用户要求暂不纳入正式方案。

这延续了当前“图片本身的难度条件 → 人员如何解释和定位 → 不确定性与收敛过程”的主线。图片条件可能影响可见候选、不同范围选择的概率及簇内波动；人员历史可能解释同一图片上的选择差异。三者都需要留出真人验证。

导师书面原话支持受控模拟、量化噪声与质量上限，以及先独立采集每个人、再组合ABCD／AABC。关于算法模拟分心、疲劳的内容来自用户明确标注为不确定的语音回忆；不能把它升格为导师已要求的动态模型。来源：本地《与导师交流.txt》。现行边界见[研究要求清单](用户研究要求核对清单_20260913.md)、[稳定性SOP](相似场景标注稳定性分析SOP.md)第11节及[本轮任务](历史作答难度粗分类续研任务_20260915.md)。

**真实作答重组与生成式模拟应分开保存。**前者直接研究已采人员构成；后者提出未观察作答的预测。后者通过检验后可增加预测覆盖，但不会增加真实人数或替代当前采集。

### 1.1 用可观察的作答过程承接“难度”问题

不必先为每张图确定一个独立于人员与规则的总难度真值。可以研究给定图片、人员类型和标注规则时，点数／范围选择、簇内定位、失败及稳定过程分别怎样变化。质量与分布稳定仍分别记录；一致的答案也可能存在共同偏差。

106张人工tag继续作为研究者预期与独立对照，不作为这项生成模型的训练真值；旧实验difficulty继续停用。图片信息仍是核心输入，不能退化成只看人员类型而忽略图像条件。

|信息条件|模型可使用什么|验证对象|
|---|---|---|
|标注前，k=0|图片分类、可见特质、冻结模型表示／布局提案，以及目标房间外形成的人员类别和历史参数|各类人员在目标图片上的真实作答分布；目标图真人答案不参与候选构造或拟合。|
|观察前k名真人后|以上信息，加这k名不同人员的身份／类型及实际作答|尚未暴露的其他真人，以及后续新模式、重复支持、比例和定位变化。每次重新抽样是一场独立回放，不能跨回放累积全部目标答案。|
|完整历史描述与审核|该图全部已观测真实作答及来源|解释和审核图片条件、人员构成与实际过程的联系；此时发现的模式或修正不能回填为此前预测已经知道的信息。|

三个信息条件可以在已有历史中离线检验，第三项不是一组额外预测数据。已知人员跨新图与同类型新人员的推广分别验证；后者还需留人员，并仅凭允许的校准历史确定新人类别。

### 1.2 最小模型：图片条件、类间倾向、类内变化

已有人员分类包括多种信息组合及组数，目前不是唯一固定ABCD。候选分类须在训练侧形成并保留缺失／不确定身份，不用目标房间的表现为其分型或挑类别数；分类选取与简单模型调参均不读取最终留出结果。

建议先比较不分型、类型条件、连续人员特征三种简单方案。类型条件方案可以共享一个基础模型，再加入类别参数和少量图片×类别交互；各类资料不足时共享估计，避免为每类都拟合一套高维模型。比较的是类别能否解释并预测新作答，不是能否把已有答案分开。

生成拆成两步：先预测结构／范围候选的选择概率，再在选定候选内模拟几何偏差与波动。第一步可从可比较的结构类别或候选特征入手，尝试带正则化的逻辑回归；这是现有工具支持的简单分类方法，适用性仍待本数据验证。[官方方法说明](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html)。各图临时簇号没有跨图语义，不能直接把“第1簇”当作统一训练标签；模型提案也不能自动成为人员类别。

第二步只在相同点数、可靠对应的几何表示中使用类内经验残差或少量偏移参数。保留类内人与人之间的变化；跨图模拟同一个人时，其个人参数应保持一致。无效作答单独记录。候选只来自当前允许的信息，未覆盖模式单列，不能从隐藏真人预先取出完整候选库。

### 1.3 AABC和反复抽样的准确含义

- **同一轮真实组合内不放回。**AABC中的两个A是两名不同真人，例如A1、A2、B1、C1；每人复用其在该图的一份独立作答。缺少相应人数时记录不可组合。
- **不同轮之间可以恢复人员池再抽。**下一轮可抽A2、A3、B2、C1；一个人可以在多轮出现。因此“每轮抽完放回，再重组”可以成立。比较AABC与ABCD时固定总人数；研究人数增长时另记每步构成，同一条增长轨迹每次增加一名尚未出现的真人。
- **同一轮有放回bootstrap另作估计不确定性用途。**重复抽到的同一人不能计为两名不同人员，也不能据此形成“两人支持”的真实模式。应保留图、房间、人员重复结构；bootstrap不是直接沿用AABC真实组合的替代操作。
- **从已拟合分布生成虚拟A1、A2是模型模拟。**可研究其预测的组合，但两者不是新增真人证据；参数不确定性、类内差异和条件独立等假设另记。

回放时先锁定待检验人员，再在允许的种子池中抽前k人；同一比较使用相同目标及相同种子。若允许跨回放轮换种子／检验身份，每轮独立拟合或更新，最终按图和人员的重复结构汇总，不能把回放次数当独立样本数。预先规定AABC是设计构成，也不等于自然人群类型比例。

### 点数遗漏的可复算定义

使用[最新A—E输入](../../analysis_results/image_portrait_20260914_v1/cloud/image_links_after_review_20260915_v1/run_b02a97e2/inputs/)的`group_index.json`和`pairwise_geometry.npz`。按条件筛选有效人数19—24；只用保存的确认后点数，不修补原始记录。

某图有n名不同人员，点数类别c出现n_c次；从中均匀不放回抽k人。剩余作答中属于种子未见类别的期望比例为：

`U_k = sum_c [ n_c × C(n−n_c,k) / C(n,k) ] / (n−k)`。

组合数不可取时该项为0，再对图片等权平均。这里测的是**未覆盖的观察作答**；不能直接叫遗漏了多少“合理解释”，也不是未来人群的已知真概率。同点数内仍可能存在不同几何／范围；备选的合理性及失败原因需要另外审核。

## 3. 旧模拟器的限制，以及新版究竟在做什么

旧`simulate_annotators.py`的保守分支固定HoHoNet点数、裁剪扰动，失败时回退原布局。个人残差仍可能参与生成，不能说“完全没有人员差异”；但学到的三模型偏好没有参与结构选择。若真人点数分布为p、输出固定为c₀，则`TV(p,δ_c₀)=1−p(c₀)`。换随机seed或多生成标注不会消除这个限制。

旧评估还从人员画像池有放回抽取50个模拟身份，并非逐一预测该图实际作答名单。因此其误差同时包含生成规则及人员构成差异，不足以证明人员特质没有用。

新版`personalized_simulator_v2.py`做了更有针对性的第一步：从楼外共同图片估计人员间相似性，对目标图少量真人答案重新加权，并可混入HoHoNet与Bi两头。其嵌套留楼调参、种子人员与剩余人员分离、Manual／Semi／OOS分别拟合都适合保留。

但它目前是**少量真人条件下的分布预测原型**，仍有以下范围限制：

- 候选来自种子几何和三路模型；没有生成新的簇内几何、单独的未知模式概率、失败过程或参数后验。重新加权也不能发现候选集合之外的模式。
- 当前输出是点数Brier、点数TV和核评分；尚未实现完整的模式发现、重复支持、比例／定位稳定及“过早预测稳定”的过程检验。评分改善不能直接改名为“收敛更准确”。
- 核函数汇聚无序端点，不能识别端点配对／连接关系。实测同一批端点改配对后核相似度仍为1；需配合现有几何、配对和分区指标，不能单独验收完整布局。
- 模型混合按模型输出路数分配权重。Manual目标46图中9图的Bi两头完全相同，Semi为8/18，OOS为1/9（坐标容差1e−7像素）。这会给重复候选重复权重；需要候选去重／合并敏感性，不能称三份独立证据。
- 新版下载图片元数据，但本轮拟合主要使用人员几何关系及三路布局，没有检验648图特质、DINO或DA3的图片条件增量。因此不能认为已经完成图片—人员交互研究。
- 新版评分只消费有效几何；对应目标池另有Manual 8、Semi 4、OOS 4份无效作答。预测有效几何可以单独成立，完整作答模拟必须另外报告这些失败，不能默认为不存在。

## 4. 对两段建议的保留、补充与修正

**保留“先候选、后概率、再几何”的生成划分，备选采集为可选扩展。**当前讨论优先复用已有真实首选、图片信息与人员候选分类。一个人独立首选与被询问后的备选是不同证据；备选可扩展候选库，不能按条数估计自然人群比例。已收数据没有备选时，不能声称已验证“主动列举备选”的收益。若以后增加这项采集，应先锁定首选并记录额外时间，在同预算下比较。

**人员模拟有价值，首先检验可重复的低维差异。**已核对的共同图支持足够开展历史相似性原型。下一步需判断相似性是否随门洞、边界不全、主空间等改变；全局相似性高不保证在每种图片上都相似。连续画像原型也不替代已有质量、时间、规则、Semi的15种组合，以及“质量＋时间＋修改幅度”和多组数分类候选。

**“合理解释”和“实际作答模式”不能混称。**模拟人类作答分布需要保留规则错误与失败的发生机制；研究合理多解又需要局部审核支持。稳定另一种范围、系统性几何偏差、偶发失败可分别发生，不应压成一条认真程度轴。

**解析概率正确，但依赖固定模式与条件独立。**给定每人的模式概率，可以直接计算未出现、恰好一人、至少两人支持的概率，减少无意义采样；这不计算随前缀重新聚类的分区变化，也不验证各人的联合分布。共同的图片信息缺口及参数不确定性仍须保留。

**后验不确定性的教学例子正确。**Beta(4,2)、生成50份时，保留参数不确定性的比例标准差为0.188562；固定概率为2/3时为0.066667。这是模型假设下的例子，支持“不应凭多生成而虚假确信”；不是本批人员的实测规律。

**疲劳放在后续条件分支。**当前包有26,057条事件审计记录，不能说完全没有时间资料；但事件存在、累计有效时间、已观察任务序号与完整连续工作经历是不同东西。新时间脚本从原导出恢复`created_at`，按提交间隔推工作段，适合探索来源和关联；这些工作段尚不能直接解释为疲劳／恢复，其他未收录工作和真实开始时间仍可能缺失。当前优先验证静态人员信息；时间关联也不能替代向前预测检验。

文献边界：本次核对了[Welinder等2010官方摘要](https://proceedings.neurips.cc/paper_files/paper/2010/hash/0f9cafd014db7a619ddb4276af0d692c-Abstract.html)及[Probabilistic U-Net官方摘要](https://papers.nips.cc/paper_files/paper/2018/hash/473447ac58e1cd7e96172575f48dca3b-Abstract.html)，分别支持多维人员建模、条件多解分布学习的可行思路。前者以潜在真实类别估计为目标，后者训练视觉生成网络；都不直接验证本项目的少量真人模拟方案。本次未进行这些论文全文复核，也未据其增加新模型训练任务。

## 5. 可选验证设计（不是Pro必须照做的步骤，尚非正式方案）

1. **先审查已有新版分数及输入名单。**取得`score_summary.csv`、`paired_increment.csv`、`training_only_selection.csv`和逐图结果，按相同目标、k、名单比较。历史数据已反复探索，结果属于开发证据；待当前新标注到来后再做独立确认。
2. **优先检验图片×人员类型的增量。**按第1节分别评价k=0和k=2—8（含8）；在同信息条件下比较不分型、候选类型条件、连续人员特征，k>0时增加种子等权重放基线。人员分型、参数及层选择都在训练侧进行。分别消融图片信息、人员信息及候选扩充，检验改善来自哪里；不把新增k名真人的信息收益误归因于模型结构。
3. **把评价接回过程。**每图使用实际人数；剩余真实人员依次暴露，比较新点数／新几何、至少两名不同人员支持的模式、模式比例变化、簇内定位变化及预测区间。使用明确版本的稳定性算法，检查误判过早稳定。已支持模式固定的解析曲线与逐前缀重聚类结果分别报告。
4. **检验图片条件能否解释成功与失败。**优先用已记录边界信息、主空间、模型反馈，检验它们对前述过程的增量及人员交互。用局部审核确认代表性机制；39图重点审核可提供案例，但其经过筛选，不能代表全648图发生率。106人工tag作独立对照，旧实验difficulty继续停用。
5. **仅在前述有留出证据后扩展。**可再加入少量可识别的簇内几何参数、模型与图像表示、时间状态。DINO可作为图片条件候选；DA3多视角几何仍沿用未通过的有效性检查，不借模拟绕过限制。超过真实观察人数的曲线标为模型外推。

主验收问题：对同一批隐藏真人，新增信息是否减少模式遗漏、改善比例与定位预测，并降低错误宣称稳定的风险？稳定多簇仍可稳定，合理单人标法保留；模拟个体不会计入真实“至少两人支持”。预测失败也有研究价值，应定位在图片缺候选、人员概率不准或簇内几何模型不足哪一层。

## 7. 与导师沟通：初步线索与待验证假说分开

本节按最新讨论改为“图片×人员类型条件模拟”。额外列举备选不再作为开头或必要采集步骤；先说明已有人员候选分类可以怎样用于预测，以及用真实留出作答验证哪些过程。人员类型仍是候选，模型能力仍待证明。

可直接使用的讨论稿：

> 老师，我最近结合图片分类和历史标注，初步看到一些线索：同一房间即使用同一批人标，不同视角的分歧和稳定过程也可能不同；固定人数后，不同人员构成的结果也有差别。边界信息不完整与后续继续出现不同几何标法存在关联，不过这些还需要新数据验证。
>
> 所以我想讨论一个更具体的方向：结合图片信息和已有的候选人员分类，用简单模型学习各类人员的标注倾向及类内差异，再模拟不同人员构成下的标注分布和人数增长过程。这样可以先研究“什么图片条件对什么类型的人容易产生分歧”，不必先给每张图定一个统一的难度真值。
>
> 我考虑分成三部分：标注前根据图片和人员类型预测；看到前k名真人后更新对剩余人员的预测；完整历史用于描述和审核。AABC等组合可以从已独立采集的真实人员中反复抽取，每次组合内保持不同人员，用来检验模拟是否能恢复少数标法、比例变化和实际的稳定过程。这仍是待验证假说，暂不纳入正式方案，现有采集继续。
