## 1. 导师原意：直接文字与后来转述分开

仓库保存的[导师交流原文](../../analysis_results/pro_research_handoff_20260921/导师交流原文.txt)第33行明确写道：

> 7/8/7这个比例，有点不理想，如果能确认一个具体人群子类能收敛才最理想。

同文件第35行提出独立采集A、B后直接组合；第51行进一步解释ABCD是人员类型，AABC是不同类型的人数比例，按人独立采集后再分析，不为每种组合重复采集。

这支持三个研究问题：某个具体子类自身是否较一致；增加同类人员后是否趋于稳定；混合不同类和不同人数比例会怎样。它**没有规定必须把全体分成三个组、必须均分、所有子类必须同时收敛，或已经证明“认真／不认真”是可用的真实类型**。“先粗后细”也可探索，但没有直接文字要求必须采用层次分类。

已核读桌面现存《与导师交流.txt》（用户本机核对原件；仓库副本见上文），上述文字与仓库副本一致。该文件后部新增的“最后导师提议”是用户明确标注为记忆可能不准确的转述：GT、IoU与质心用于人员质量，改研究consensus及人数曲线，并写明“人员分类这块，忘记讨论了”。因此，后一次讨论没有直接否定此前的子类问题，也不能被写成导师要求停止时间、scope和Semi研究。

## 2. “子类收敛”至少有三种不同检验

| 检验 | 实际问题 | 当前如何衔接 |
|---|---|---|
| 分类名单重复性 | 换一批校准图，还会识别到相似的一群人吗？ | 连续画像、排序、具名子类名单重合或整套分类一致性；它支持可解释性和迁移，但不是组内收敛本身 |
| 子类内部标注模式 | 同图上，这一类人的标注是否较集中，或形成可重复的少数模式？ | 历史分簇结果是这项问题的证据；当前可先用BEV两两区域差异描述，必要时另研究模式分簇 |
| 子类的融合人数过程 | 只从这一类抽人，增加人数后融合怎样变化、是否接近GT？ | 当前Lee等权融合，分别报告参考IoU、同人数换成员的区域差异、相邻人数的融合变化 |

原文字中的“收敛”没有唯一给出公式。结合当时的分簇讨论和保存结果，历史主要落实为第二项及随人数增加的模式持续性；随后consensus讨论为第三项提供了新的实现路线。**不能把旧“若干簇持续稳定”直接改名成“Lee融合已稳定”，也不能只用名单重复性判断导师的问题已经回答。**

三项不要求同时一次解决。名单边界不稳定的候选仍可做条件探索，保留每个训练折实际成员和未定状态；只是不能把它包装成永久类型或独立确认结果。更一致也不必更正确，低变化还可能是共同偏离参考。

## 3. 质量、时间、scope、半自动：以前确实已做过

主要来源是[四块信息初轮报告](../../analysis_results/worker_four_block_exploration_20260910_v1/README_ZH.md)、[冻结的探索设置](../../analysis_results/worker_four_block_exploration_20260910_v1/PLAN.json)、[放开组数的扩展](../../analysis_results/worker_four_block_exploration_20260910_v1/group_count_extension/README_ZH.md)及[具体子类稳定性报告](../../analysis_results/worker_four_block_exploration_20260910_v1/subtype_stage_validation/README_ZH.md)。

| 历史信息块 | 原来实际计算什么 | 今天能保留什么，不能怎样改名 |
|---|---|---|
| Q：参考偏差 | 无辅助作答相对适用参考的OSPA30点集偏差，考虑任务差异 | 保留参考表现路线；它不是当前BEV IoU，也不是逐条核实的规则错误率 |
| T：有效时间 | 合格冻结日志的active time，使用log(1＋秒数)并考虑任务差异 | 保留相对快慢画像；不把快等同粗心、慢等同认真，不混用lead_time |
| S：scope判断 | 对明确可标与不可标图片，分别计算误拒绝与误接受 | 保留适用范围判断；不是BiLayout enclosed/extended偏好，也不覆盖全部边界规则 |
| B：Semi行为 | 实际展示的初始化到最终标注的改动量；初始参考偏差减最终参考偏差的净改善 | 保留修改与收益两个分项；小改不必漏改、大改不必改善；初始化需来源绑定，Manual不补成0修改 |

历史采用Q、T、S、B四块的15种非空组合；各块总权重相同，S和B各有两个数值也不会自动双倍加权。初轮固定二分，后来放开到可分类人数的一半；后续20人考察2—10组，全部26人按资料覆盖调整。Ward自动分类没有人数相等配额，单人组和人数不足均保留。**固定二分曾是分析者增加的限制，历史扩展已经纠正，不能再以一次上下半检查概括整个分类研究。**

在[子类回放记录](../../analysis_results/worker_four_block_exploration_20260910_v1/subtype_stage_validation/REPLAY_QA.json)中，保存了57张至少7份无辅助作答图上的303套分类配置，实际去重为5,448个图内人员子集、35,065个场景和130,160条曲线行；每图200条进入顺序。303是配置数，5,448是重复利用的子集数，都不是新增人员或独立发现数。分类排除整个目标建筑，子类与随机对照在同图、同人数下比较，不要求其他所有子类也够人数。

另有[修改幅度—时间—最终质量三指标方案](../../analysis_results/worker_rule_triad_20260910_v1/README_ZH.md)，三项来自同一批Semi响应；这不同于上表将Manual质量／时间与Semi行为分块组合。后续20人范围实际支持16人、325条留建筑验证响应，连续三轴在修改／用时／最终参考偏差预测上的误差改善为27.71%／52.47%／13.37%；三轴三分为22.40%／24.62%／4.92%。这些数字是各自预测目标的改善，不是收敛率，也不能将不同单位收益相加成总优劣。

## 4. 旧证据揭示什么

### 4.1 分类名单与组内稳定不是一回事

旧20人、互不重叠建筑两半重复100次时，质量中位数二分的ARI中位数约0.113，时间二分约0.789，Q＋B约0.244（80次可比）。这是整套分类的重复性，不是分类准确率或标注一致率。具名子类的名单Jaccard另算，T较快／较慢子类约0.889／0.909，不能与ARI混为一个指标。

只有9张明确不可标scope图，两半各至少6份记录的主要求不能同时满足，S及含S四项联合没有可比的主重复性结果。放宽要求的分析只是诊断，不能写成主验证通过。历史四块结果中的Q＋B质量预测改善3.66%，按楼探索区间约−0.12%到7.99%，既不能确定优势，也不能判定Semi毫无价值。

### 4.2 已有具体子类稳定证据，且会与质量方向不一致

本次直接读取[具名子类汇总](../../analysis_results/worker_four_block_exploration_20260910_v1/subtype_stage_validation/named_subtype_summary.csv)核对以下旧结果：`current20 / T / 2组 / time_low / q95 / H=8 / k=3 / reference_allowed`。

- 时间较快子类在39图中有18图达到该历史判据，同图同人数随机对照为8图。
- 代表标注的旧参考偏差为4.0563，对照3.8080；偏差更大，并未更接近参考。
- 这不是“时间快更好”的证据，而是**一种可辨识子类可能更易形成稳定表达，却未改善参考质量**的例子。

当时要求候选起点后至少观察5名人员，H=8只能检查到k≤3；两个各至少2人支持的簇至少需要k=4。因此这张8人表不能证明稳定多簇起点。另有4张图在H=21、k=15或16时发现稳定多簇案例，保存顺序支持为162—168/200；重复名称引用同一人员子集不算独立证据。

## 5. 与10月3日连续画像／构成实验的关系

[当前24人×10图报告](../../analysis_results/worker_profiles_20261003/REPORT.md)已经建立BEV IoU／面积质心画像、外建筑校准及固定4人0—4位上半成员的精算。[返回审查](../../analysis_results/worker_review_20261003/REPORT.md)进一步检查了名单变化、替换和面积误差／成员波动。这是有效的新证据，但其问题范围是一个具体质量分组基线。

它尚未完成：当前Q／T／S／B多条候选线、具名子类随人数变化的融合曲线、当前表示下子类内部模式、相邻增人的稳定速度。Pro关于上下半不稳定的判断应限定于所检验的数据和分法，不能推出其他粗类都不值得探索；旧子类的积极结果也不能自动推翻新结果。

因此保留三种并行分析形式：

1. **连续画像：** 不强行切类，检验画像与目标图表现、条件贡献的联系。
2. **粗分类及具体子类：** 检查少数事先说明的Q、T、Q＋T，以及有覆盖的S、B／Q＋B候选；可以只研究有解释力的子类，允许其余人员未定。
3. **混合人员构成：** 固定总人数改变类别比例，再固定比例更换成员；所有候选仍等权Lee融合，暂不同时引入人员权重。

它们互相提供证据，不要求先找到永久类型才允许研究组合。分类方法和组数必须先于目标结果说明；可以探索多种方案，但完整保留覆盖和失败，避免按目标曲线最平或IoU最好反向选人。

## 6. 下一步的小步实施建议

**先补齐现有信息的来源和覆盖，而不是立刻重复303套搜索。** 当前覆盖盘点已有相同24人×13张Semi图、6栋建筑，但这只证明最终标注的共同覆盖，不证明每条实际初始化、合格时间与scope已完成新版绑定。优先复用历史冻结来源，逐字段核对人员身份、任务条件、实际初始化和裁定；时间缺失不补lead_time、Semi缺失不填0、存疑GT不用于给人员判错。

随后在同一批目标图上做一轮规模有限、明确为探索的对照：

- 连续BEV质量画像继续；Q粗类、T粗类和Q＋T各给出定义和覆盖，S及B在来源足够的面板单列，不为凑共同面板静默删人。
- 在目标建筑外校准；每个可行子类保留实际成员池，按同图同人数随机池作对照。跨候选比优劣另用共同图／共同人数面板，人数不足保留而不判失败。
- 每类报告单份作答间的区域差异，以及Lee融合的参考IoU、同k换成员区域差异、相邻k增人变化。MV50／严格多数并行，奇偶平票效应随图说明，不用平滑曲线抹掉。
- 阶段一先给曲线和案例，不预先设“足够人数”。分簇在需要解释单峰／多模式时补充，不作为当前子类融合的前置门槛。
- 再加入两类混合比例；根据覆盖逐步扩人数和候选，保留连续画像对照。若出现有解释力的模式，再用留出建筑检验；当前已被反复开发的数据不能宣称全新盲测。

本轮仅完成原意、来源、保存结果和下一步问题的核对。没有重跑旧303套实验，没有更新人员标签、重新估计active time或运行新子类曲线。新文档的地图／索引由主任务统一同步。
