# 共识投票机制与三路线推进

更新：2026-10-08。本文区分当前实现、已验证结果与下一步方法；不是新的规范合同。研究总框架见[统一模型](研究模型_人员图片与融合不确定性_20261006.md)，输入见[数据说明](研究数据说明_来源预处理与用途_20261006.md)。

## 1. 融合要回答什么

**给定一张图和当前纳入的N名人员，表达这些人按声明规则支持标在哪里。** GT只作输出后的外部评价，不参与对应、计票、定位或连线选择。更接近GT、输出更多角点，都不能单独证明更忠实于人员共识。

“墙角线”指一对上下端点表达的竖向墙角，不是两角之间的墙面。须分别判断：哪些观察表达同一处、多少人表达它、上下标在哪里、最后怎样连接。同角位置分散不自动属于不同标法；同一墙角的玻璃顶与天花板也不能直接当作同一目标的定位误差。

主输入继续使用用户认可的**已预处理点对与既定环序**。晚共享x只作独立敏感性对照；协调两端x使用周期中点，不能跨接缝直接算术平均。每个团队形成一个主共识；合理空间候选研究另行保留。

## 2. 当前点方法到底怎样投票

所有路线按不同人员计票，一人在同组最多一票，分母为该图完整纳入的N人。MV50保留支持数≥ceil(N/2)的组；18人时9票保留，严格多数则需10票。不是只选最高票组，也不以该角已标人数替换N。

| 实现 | 成组、定位与输出 | 当前限制 |
|---|---|---|
| 当前交付：共同身份＋直接融合 | 逐两份作答按上下距离、原配对和允许缺点的环序匹配，再建立多人相容身份组；全池MV50后对全部同身份来源取坐标中位数 | 自动身份仍会拆散／误合；允许明确来源的人审分区和人工顺序，不把算法组视为已认证实体 |
| 历史绑定点对 | 以上下球面角距离的较大值作距离，完全连接聚类且同人不同点不合组；达票后用周期展开x中位数及各自y中位数 | 位置相容组不是已知实体身份；同角分散可能拆组，层次聚类也不保证找到所有最大支持子集 |
| 上下独立 `split_unique` | 上下分别成组、达票、估计位置，以原点对建立关联，再协调共享x | 当前要求所选上下组都有唯一对侧关联，否则无完整候选；这是原型政策，不是独立融合的必然要求 |
| 上锚／下锚 | 仅用一端建立对应、计票，带回原配对另一端定位 | 另一端来源人数不证明该端目标或位置也获多数支持 |
| 自适应v1 | **已达票**组的关联组件中，恰有一个上组、一个下组、至多一个绑定组且存在共同原点对时用独立结果，否则保留绑定 | 看不到全部未达票拆组；无竞争达票组不等于对应明确，尚非通用局部自适应 |

当前入口：[全员融合 `fuse`](../../tools/thesis_main/analysis/consensus_delivery_20261008.py)，工作参数`gap=7.5`（匹配中跳过一个节点的代价，与角距离同量纲；不是组内最大距离7.5°）。下列历史实现用于比较，不表示当前要同时维护四条必选流程。

历史代码：[绑定与环诊断](../../tools/thesis_main/analysis/global_pair_consensus_20261004.py)、[独立／锚定](../../tools/thesis_main/analysis/point_route_panel_20261005.py)、[自适应v1](../../tools/thesis_main/analysis/adaptive_point_20261007.py)。

**计票与连线还需分开解释：**

- 上表历史四类实现的候选环按融合中心x排序；新共同身份原型使用来源环建议或人工顺序，并独立保留未排序节点。另存几何检查和来源邻接。可绘制、无自交或端点达票，都不是环序已确认。
- 独立／自适应当前仅用上下共同来源映射环，因此已有边票是“共同来源中的边支持”，不代表全部上端／下端参与者。不能直接与绑定的边票比较支持强弱。
- 原作答直接相邻、删除未选节点后形成的投影相邻、算法新建连接不是同一种证据。
- 中位数是代表位置，中心处可能没人恰好标过。上端9票、下端11票、共同来源6票须分别报告，不能说整对11票。

## 3. 用户提出的两层投票，与现有实现的区别

当前已接通的流程是：**自动建立候选墙角身份 → 数表达人数 → 在同角观察内估计上下位置 → 来源连接或人工顺序。** 未解决的是自动身份的可靠性，而不是这几个步骤尚未实现；位置相容或匹配成功均不等于真实身份已经确认。

18人中15人表达同角，却因位置分成8＋7两组而都未过9票，说明对应限制使当前MV未统计到实体表达人数；它没有推翻“固定正确单元后按人计票”的规则。反过来，为了凑多数直接合并两组也不成立。

G184的41例中，用户认为红6、橙3、紫5共14份都想表达同一墙拐角。9°下红6已完整成组但未过9票；独立上组9、下组11、共同6。其余4人的对应仍不能按缺席这14份就判遗漏。颜色组不是已认证标法类型，橙色低下端与紫色高上端应按同一标准解释。

位置融合必须声明是**全部纳入观察的折中**，还是**局部模式的代表**。前者可以作为基线，但不能称为某个语义目标获胜；后者必须有实际选择规则并保留支持数。无需先让人工给全部高低差异分类，已有uNb同下端、玻璃顶／天花板例即可检验明显目标混合。

## 4. Lee区域MV与点MV的区别

[Lee等《Aggregating Crowdsourced Image Segmentations》](https://ceur-ws.org/Vol-2173/paper10.pdf)第4—6节研究普通对象分割；BEV是本项目的迁移表示。所有人员轮廓叠加形成不重叠tile，每人对每个tile记内／外，至少50%包含它便纳入。不是全员交集，也不需要先找角点。论文另有谱聚类取最大簇选项，本项目全员等权基线没有采用该人员筛选。

不加“必须形成某种完整layout”等约束时，区域MV满足：

\[
F_{\rm MV}\in\arg\min_F\sum_i\mu(F\triangle A_i).
\]

某tile有s票，保留代价为(N−s)倍面积，删除为s倍面积；平票MV50纳入。这是固定空间单元上的总对称差最小化，不是IoU最优或GT最优。项目Lee BEV输出底面，没有上端；既有人数与难度结果不能直接推广为完整上下点对结果。

## 6. 点对融合的数学定义：先有共同单元，再投票

### 6.1 对应与存在票

第i人的观察为\(A_i=(a_{i1},\ldots,a_{im_i};E_i)\)，\(a_{ij}=(x,t,b)\)，\(E_i\)保留原环。算法从当前人员的观察建立分区\(\widehat\Pi=g(A_1,\ldots,A_N)=\{C_c\}\)，每个单元拟表达同一处墙角／节点，**不是已认证物理实体**。近共线装饰节点也不能只因空间相近就抹去。

同人不同节点不合组是当前表示假设，不是物理证明；一般计票按不同人员去重。对应证据可联合周期x、上下残差、原配对、共现与部分路径。不能按x排序、固定第j对或简单连通块替代对应；首轮保序匹配已实算，更一般的结构证据与对应冲突仍待解决。

\[
b_{ic}=\mathbf1[\exists a_{ij}\in C_c],\quad
s_c=\sum_i b_{ic},\quad z_c=\mathbf1[2s_c\ge N],
\qquad
z\in\arg\min_v\sum_{c,i}|v_c-b_{ic}|.
\]

这是**固定对应后**的二元经验分歧最小化，不证明对应正确，也不能反过来任意合并身份降低损失。b=0只表示未提供已匹配观察，不能认作主观反对；对应未决单列，不伪装成确认遗漏。候选覆盖、误合和人工复核量共同评价，不能只接受极少简单点便宣称方法有效。

### 6.2 条件位置与三路线

对保留单元，观察经验分布及位置估计写为：

\[
\widehat Q_c=\frac1{s_c}\sum_{a\in C_c}\delta_a,\qquad
\widehat\theta_c\in\arg\min_{\theta}\int\ell(\theta,a)\,d\widehat Q_c(a).
\]

这里按每人一份同角观察定义，\(\theta=(共享x,t,b)\)。平方损失给均值型折中，坐标L1给中位数型代表，局部支持最多的邻域给另一种带尺度的模式规则。周期坐标须单独处理；当前medoid锚定展开中位数未证明对所有圆周分布都是全局L1解。

| 路线 | 需要比较的实际操作 |
|---|---|
| 绑定 | 联合上下对应／联合模式与来源选择 |
| 独立 | 同身份下，上下各选来源／位置，再协调共享x与配对 |
| 自适应混合 | 根据局部观察选择上述操作，记录切换依据，不按GT选分支 |

共同身份先行是拟研究流程，不是对现有`split_unique`的改名。相同成员与可分离损失下，绑定／独立估计可以相同；收益必须来自真实操作差异。

若15/18人表达某角，其中8人选某模式，应报告存在15/18、条件模式8/15、全体模式8/18；“最多模式”不等于全体多数。互斥完整类型的均值按类型人数加权等于直接全体均值，不能再按人数重复给每个成员加权。

### 6.3 完整输出与人数研究

\(F=(C_+,\theta,r)\)：达票节点、上下位置与闭合连接。当前比较固定MV节点和定位，再检验连接；无适用完整环则连接r暂缺，仍交付节点及位置；人工顺序复核按第5节另列。为闭环增删节点或调整中心，须定义为另一融合政策。逐角多数不推出整环也获多数直接支持。

对k人子集S，\(F_S=f(A_S;\text{对应、存在票、定位、连接规则})\)。对应只用当前S；先用全员预建身份再给小组用，属于全员辅助实验。原作答R、换组V、GT参考差D和实际全员输出分别保留，不能改名为已经分离的图片／人员噪声。
