# 墙线融合共识：当前方法

更新：2026-10-08。保留原文件路径以兼容既有引用。当前执行见[操作SOP](融合共识操作SOP_20261008.md)，结果见[交付报告](../../analysis_results/consensus_delivery_20261008/REPORT.md)，人员与图片研究见[统一模型](研究模型_人员图片与融合不确定性_20261006.md)。

## 1. 目标与当前路线

把当前人员对“应该标在哪里”的观察汇成一份共识。自动计算不读取GT，也不以GT分数挑选对应、节点、位置或连接。人工辅助按实际参考材料记录，不宣称全部盲于GT；例如rPc三目标判断曾参考GT。GT仍用于后续评价，辅助结果与自动结果分开。

> 已预处理点对与原环 → 同一墙线的候选身份 → 全池存在票 → 同身份全部成员的位置融合 → 来源建议或人工连接。

“墙线”指上下点对所表达的竖向墙角或停止／转折位置，不是两角之间的墙面。相同目标的位置偏差可融合；不同停止／转折目标不能只因接近而合并。同一位置上的不同上端目标可保留差异说明，当前估计是全体来源的折中，不是自动语义模式选择。

**绑定、上下独立、自适应是形成现路线的历史设想和原型，保留为可选对照，不再是三条必须完成的任务。** 当前联合上下信息与原环找对应，再用同一批成员分别估计上下位置；未采用上下独立身份、不同端点来源集合或自动局部切换。少量人审不等于自适应算法。

## 2. 对应、投票与定位

每人观察为 \(A_i=(a_{i1},\ldots,a_{im_i};E_i)\)，点对 \(a=(x,t,b)\)，\(E_i\)为原环。当前人员的对应分区为 \(\widehat\Pi=g(A_1,\ldots,A_N)=\{C_c\}\)，算法组不自动等于已认证实体。

双人匹配使用上下球面距离的平均值、环起点／方向搜索及允许跳点的动态规划；多人组要求组内各对观察均有匹配支持，同人不同点不入同组。工作参数`gap=7.5`是跳过一个节点的代价，不是组内距离半径。具体见[对应代码](../../tools/thesis_main/analysis/ring_correspondence_20261007.py)。

\[
b_{ic}=\mathbf1[\exists a_{ij}\in C_c],\qquad s_c=\sum_i b_{ic},\qquad z_c=\mathbf1[2s_c\ge N].
\]

MV50按全N计票，每人最多一票，平票保留。固定对应时，它最小化逐身份的二元分歧 \(\sum_{c,i}|z_c-b_{ic}|\)；这个解释不证明对应正确。未匹配观察不等于该人主观投反对票。同角拆散应修对应，不能为凑票混合不同目标或缩小分母。

保留组对全体来源每人等权：以联合上下距离medoid展开周期x，取x中位数及上下y各自中位数。输出两端共享x；这与单份作答预处理的共享x不是同一步。周期歧义保留未决。9°上下位置分组仅作诊断，不筛成员或再次投票。中位数可能无人恰好标过，也不保证对应某一语义目标模式。

## 3. 连接、人工辅助与不完整结果

节点及其支持、中心独立交付。自动顺序取覆盖全部保留节点的来源投影环中支持最多的一种；并列留标记，无完整来源环则允许人工排序。原直接邻接和跳过未选节点后的投影邻接分别保存。逐节点达票不证明整环达票；原答确认不传给融合环，x排序不普遍证明合理连接。

人工明确同角／异角时重建来源分区，仍用原全N计票和相同定位规则。顺序确认绑定具体节点及坐标。N=2保留节点、暂缓排序。

不足4对可记录为当前人员池和规则下“未形成完整共识”，先保留已知对应限制。不得强补点、填零或删除该图来美化结果；达到4对也不保证一致或正确。几何可算、完整性、身份可用性、人工顺序确认分别解释。

## 4. 奇偶人数与后续曲线

当前MV50门槛为 \(\lceil N/2\rceil\)：7、8、9人分别需4、4、5票。奇数没有二元平票；偶数半票保留是明示政策。固定身份时，随机重排平均不能消除该政策的奇偶效应；实际子集重算还会产生对应变化。

[Lee等2018，§4](https://ceur-ws.org/Vol-2173/paper10.pdf)明确规定tile获至少50%支持纳入；它研究普通对象分割，本项目将其迁移到BEV。[众包真值推断研究§3](https://dbgroup.cs.tsinghua.edu.cn/ligl/crowdsourcing/papers/vldb17-quality.pdf)用随机平票；[HADES附录B](https://aclanthology.org/2022.acl-long.464.pdf)特意用偶数来暴露争议。文献没有统一政策，不能为使曲线平滑而暗改规则。

下一阶段保留全部k，标记奇偶、半票节点和不足4对比例；可复用对应结果做严格多数对照，不按GT优劣反选主规则。每次对子集重新对应与固定全员身份后抽票是不同实验；自动轨迹终点不能接入人工辅助终点。明确评价分母及不可用原因。完整安排见SOP第9节，尚未启动。

## 5. 冻结版本与历史入口

当前[交付入口](../../tools/thesis_main/analysis/consensus_delivery_20261008.py)固定7.5，重新接收人审不会自动重选参数。`--replay-calibration`只复现开发选参，输出到独立历史目录；不覆盖当前交付和原选参记录。

参数、MV50及中位数是本阶段工作选择，不表示全库最优或自动正确率超过90%。方法可用不要求所有困难图生成完整布局。
