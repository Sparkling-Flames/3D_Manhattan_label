## 1. 原意与论文中心问题

用户提供的 `C:/Users/ASUS/Desktop/与导师交流.txt` 应优先读末尾“最后导师提议的尝试方向”。这一部分仍是用户回忆，不是导师逐字审定的研究设计。其核心是：用参考评价帮助区分人员表现和图片条件，研究不同图片上的共识人数过程及其参考接近程度；同房预测可以暂缓，人员分类在最近一次交流中没有展开。早期模拟人员、新采集与初始化讨论不自动恢复为主线任务。

当前最适合收束的中心问题是：**在不同图片条件下，增加人员或改变人员构成，怎样影响全景布局共识的成员稳定性、参考质量与输出完整性，哪些差异仍然保留？**

建议以实证研究为主，将四模块组织成同一证据链：可信且适用的质量测量 → 原作答差异 → 人数过程 → 人员构成 → 剩余分歧及适用边界。四个模块不必分别成为四项算法创新。

图片条件不等于纯数据噪声，人员差异不等于纯人员随机噪声。每人每图一次作答不能完全分离人员与图片交互、单次随机变化、范围解释和参考误差。当前[统一研究模型](研究模型_人员图片与融合不确定性_20261006.md)声明变量和问题，并未拟合出唯一的噪声分解。

### 核心不足

当前瓶颈是构念和权衡是否合理，不是缺更多参数网格。共同轴方向量D描述边与一组正交方向的接近程度，不足以表达墙间关系；其严重尾项已有完整Q响应反例。Sb是双向平均球面底边距离；Hm与Hc分别涉及整体均高和相对参考的局部高度，Hc还依赖底边对应，不能全称为自身起伏。

J04/R03274目前约7.25分，高度实际扣分约0.034分，主要争议在方向与总分，不能用只改顶部点的控制替代。T20“可以稍微扣多一点”应保留为高度方向性依据；P04限制局部不平与其他分量的相对取舍，L01限制过度拉开，J02旧偏好已撤回。不为案例设臆造的目标分或统一最低分。

9份严重例外来自W029/W032/W034/W037，其中7份混合三点对、漏结构等错误，不能当成9个纯方向实验。它们应参与严重端约束，同时不恢复正式人员资格；逐份、逐图报告，避免rPc-09的3份作答被当成3个独立场景。

原282留出中已知148份曾进入融合诊断，剩余部分不能未经核查便宣称全新盲测。少量序数偏好即使全部满足，也不能赋予Q等距量表含义；“提高5分”及平台阈值仍依赖量表选择，应保留IoU与分项敏感性。

多参考沿用既有人工指定、局部结构族判断及模糊时的底面接近兜底，不按最高Q选目标。参考版本敏感性与多个合理空间不同；只确认新底面时不能嫁接旧顶面。路线见[质量推进方案](topics/quality/质量研究推进方案_20261013.md)。

## 3. 图片难度

当前[范围优先工作表](../../analysis_results/difficulty_scope_preferred_20261011/current_259.csv)为144简单、30中等、38困难、5待核、42特殊单列。这是固定目标范围后的几何与视觉准则粗分，含Codex视觉判断，不能称为独立盲标或全自动固有难度。

当前212张普通三档与视觉负担低/中/高完全对应（144/30/38）；在这批图上尚未证明几何量在视觉编码之外提供独立增益。结构自遮挡H是声明底面在不透明墙假设下的几何性质，不等于照片中人的实际可见性。42张特殊中OOS25张、门洞19张、重叠2张；“未标特殊”不能认证普通。

共同24人十图按新表已经变为6简单、1中等、3困难，旧报告的5/2/3保留为历史版本：q9-32中等转简单、e9z19中等转困难、rPc-06困难转中等。重新接入时须同步范围版本，而非只替换类别列。

上一轮将新类别接到历史覆盖表作可行性诊断：N≥8为57简单/13中等/6困难；N≥16为26/12/5；N≥20为26/7/4。它不是当前质量资格下的正式面板。高人数困难图少，中等图明显集中于uNb建筑，不能把建筑、人员覆盖和难度混杂解释成纯难度效应。

## 4. 人员分类与构成

已有[24人十图画像](../../analysis_results/worker_profiles_20261003/REPORT.md)、每图10626个四人组合、两图各134596个六人组合，以及39图构成研究、32图加人和选人比较。因此人员模块有实证基础，不能写成尚未开始。

但现有证据更支持条件性、连续的人员表现，尚不足以证明稳定天然类型。历史嵌套校准按目标建筑外训练，在该次程序内部并非直接泄漏；整套方法开发已经反复看过这些数据，仍不能称全新独立验证。

- [人员子类研究](../../research/worker_subtype_returns_20261004/README.md)中的约10.7%/10.9%是预测IoU的平方误差相对下降，不是IoU或融合质量提高相同百分比；收益集中于部分建筑和人员。
- 9/24人在留建筑检验中会换类别；不重叠建筑半分的二类一致性很低（历史两参考口径ARI约0.071、-0.016）。某些较稳定的Ward类别只有2名高表现者，无法支撑高人数的子类内过程。
- 六人类型构成解释的组合差异约0.70%/6.50%，不能据此说人员无价值，也不能由组合均值推出因果协同；同一类型比例中具体成员仍重要。
- 历史高表现四人组IoU均值约0.7848、低表现组约0.7435，但相应成员替换SD约0.0674、0.0593，质量更好未必更稳定。
- 32图的同人数选人收益有依据，但未计入校准成本，不能直接称最省预算方案；旧结果需对齐当前指标与目标后再引用。

扩展条件视图有962份完整manual、24人、115图、116个图片—参考单元，仅4个单元全员共同，不意味着只能用这4个单元。上一轮检查人员—单元图为单一连通分量，276对人员最少共享8单元；移除4个全员单元后仍连通，最少共享4单元。每人覆盖11–54单元且有19个单人单元、11个双人单元，说明能做更广条件比较，同时要处理覆盖不均。这不证明每个留建筑折都连通或分配随机。

建议主分析采用连续表现及一个事先说明的粗分策略，在目标建筑外校准，比较同人数随机组、按人员策略选组与增人数。报告分类/名单对校准建筑的敏感性；Q/T/S/B历史画像按实际帮助保留附录，不必全部重做。人员类别不要直接命名为认真或粗心。图片固定效应与图片层面的难度变量不能未经识别设计同时解释为独立效应。

## 5. 融合共识

当前[墙线全员交付](../../analysis_results/consensus_delivery_20261008/REPORT.md)固定WORKING_GAP=7.5，177个有效自动结果和43个人工辅助版本共220个版本，178池中另1池输入失败。最终177份含134份自动与43份辅助；17个两人池暂缓，160池人数至少3。自动和辅助不能混成自动正确率。

对应、存在投票、上下定位、连接承担不同职责。逐节点达票不能保证整个环被多数人以相同连接支持。上一轮读取自动结果：160个N≥3池中157有完整来源投影环，19个最佳环支持低于半池、其中2个只有1个来源；3个没有完整来源环，1个自动结果少于4节点。这是连接证据的限制，不直接等于19个结果错误。投影邻接还可能跨过未保留的来源节点。

当前全员产物已交付，当前墙线版本的完整逐k过程尚未接通。历史Lee人数、构成和选人结果真实存在，可以作为底面范围证据，不能直接当墙线上下完整布局结果。对应拆散、投票删除、连接不足及表示失效均可能导致失败，不全归为人员分歧。

冻结220版本的[质量下游审计](../../research/quality_downstream_audit_20261013/README.md)为144完整、1仅底面、75待绑定或受限，正式融合范围资格仍为false。成员或上下文的质量限制不能自动取消独立票；不从个体路由直接继承融合参考。

后续最小补充是在预先选定、有覆盖依据的固定面板上，用同一组嵌套人员前缀重建当前对应、投票和连接，再与Lee做共同底面比较，另报真实上下输出。小人数阶段不得借全员身份、GT辅助顺序或未来人员；人工辅助终点单列。失败保留分母，两人政策单列。

V(N)=0是有限池全员只有一种组合的结果，不证明正确、达到人类上限或未来新人员也稳定。人数平台需事先说明实际重要差值与持续区间；不显著不等于等效。现有重放是组合独立采集的已有作答，不是人类反复讨论修改。

## 6. 建议的论文结构

暂定题目：**全景布局众包标注的不确定性：图片条件、人员构成与共识人数效应**。

|研究问题|主要观察|必须避免的扩大解释|
|---|---|---|
|RQ1 原作答差异与图片、人员条件如何关联|原作答分歧、参考分项质量、范围/结构差异、覆盖|把条件关联称为纯噪声来源或因果分解|
|RQ2 增加人数怎样改变共识|同人数换成员差异、相邻人数变化、参考质量、完整输出及失败|把稳定等同正确，把有限池端点等同人数上限|
|RQ3 固定人数时人员构成有何作用|随机组、选人策略、具体成员、校准建筑敏感性|把事后类型称天然能力类别，把选人收益称无成本收益|

正文先交代数据、预处理与参考目标，再说明质量指标的适用性与关键反例，随后回答三个问题。大网格、历史模型代理、全部人员画像与特殊案例细节放附录。合理空间多解用于解释剩余分歧，不强行合并成唯一语义真值。

若把墙线算法本身列为主要创新，需要另外补独立对应/连接评价、人工成本和足够的算法比较。当前建议先以实证研究为主，保留墙线完整布局的有限人数验证；既不把它宣称通用最优，也不从论文中完全移走。

## 7. 收束所需的最少工作

1. 按用户既定顺序完成普通粗调、门洞细调及普通回归，冻结有依据的质量工作版本，保留分项与必要敏感性。
2. 给各研究面板绑定同一对象、参考范围、难度版本、质量版本与用途；不同问题不必强行取一个极小的全交集。
3. 补一个当前墙线版本的有限逐k实验，逐项解释对应、连接、质量与失败。
4. 将人员策略比较放回同图、同k、同参考与建筑外校准下，与加人比较。
5. 独立复核的规模与论文声称的泛化程度匹配；已有开发证据足以支持有限条件研究，不足以认证通用量表。

不要求参数唯一最优、稳定天然人员类型、所有困难图都慢、覆盖全部OOS，或得到所有图通用的充足人数。当前工作更适合进入测量效度和跨模块对齐阶段，尚未达到可直接宣称全部主要结论已验证的阶段。
