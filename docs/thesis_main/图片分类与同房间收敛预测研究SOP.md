## 1. 真正要检验的问题

最新使用原则（2026-09-12）：用户确认当前v2表为最新入口，AI的普通场景分类与同房审查较准确，可用于本轮选图；不要求全面重新亲审。主要纠错对象是用户特别圈出的门洞交界，另外保留表内已有明确未决项。工作分类的可信度与“是否人工逐字段确认”的来源记录分开，不能把局部门洞问题扩大成所有场景／同房关系都不可用。

**研究线一：同一个物理房间、不同拍摄位置的全景图，是否具有相似的标注收敛过程？能否用一张历史图的标注，预测另一张图的整体表现？**

按2026-09-12用户澄清，本轮要建立的预测配对须同时满足：**同一物理房间，且两图视觉主空间一致**。视觉主空间指两图主要呈现的实际空间范围，而非仅有相同的功能名称、装修或家具；不要求像素构图相同。仅属于同一房子、能互相看见、相互连通，或分别以同一大开放布局的不同区域为主，不足以确认这类配对。物理空间身份与是否符合当前配对范围分别记录；不能因为不符合配对范围便断言物理上不同房。

用户进一步明确：在上述条件满足后，优先考虑**预计标注空间相近、范围歧义及信息困难也相近**的配对。这些只是基于原图的预期，实际标注范围、分歧和收敛仍是待检验结果，不能挑出已经表现相似的图片再验证相似性。主空间一致但可比性未明者保留为基础候选；同物理房而主空间、范围或信息条件有明显差异者保留作对照。优先候选的效果只适用于该筛选范围，不能外推为所有同房视点的效果。

例如，历史图在约8人后进入稳定阶段，并在后续20余人的观察中保持稳定；同房间的新图是否也会在大致相近的人数附近稳定？研究对象包括阶段类型、进入阶段的人数范围，以及后续增加人员时的变化，不要求恰好同一个人数收敛。

需要区分以下情况：

| 观察情况 | 在本研究中的含义 |
|---|---|
| 达成共识并保持稳定 | 一种稳定结果；“共识”的操作判据须事先说明 |
| 稳定形成几个标法簇 | 也是稳定阶段；存在分歧不等于未收敛 |
| 在已有较高人数下仍增加不同标法、分布仍变化 | 有限观察范围内尚未稳定，不能推断永远无法收敛 |
| 人数、观察长度或几何计算不足以判定 | 无法判断，不自动并入“仍在变化”或“已经稳定” |

“出现新的单人标法”和“形成至少两人支持的簇”分别记录。支持人数门槛不等于标法真实性：使用两人门槛时仍保留单人结果，以检查是否掩盖少数标法。点数不同必须属于不同标法簇。图像分类不决定这些计算结果。

**相似场景主线中的交界研究：**独立统计处于两区域交界的图片，研究其范围选择与标注分歧，以及这些交界图片的标注表现是否相似。这里的相似性具体比较哪些量尚待明确，可探索分歧结构与收敛过程，不能先假定所有交界图都难标或都不稳定。它是相似场景主线中的独立条件，不把该主线缩减为只有交界图片。

**相似场景标注与跨房间预测（明确主线）：**汇总各楼房间，按图像本身探索较粗的室内类型，并另设交界属性及统计。交界图仍保留其室内类型，例如卧室＋交界候选；也可按交界属性汇总为跨房间的相似场景候选。普通类型与交界统计可交叉，不强行互斥，也不把交界候选直接算成已确认交界。卧室、厨房、开放空间、门洞交界等相似场景的标注规律与跨房间预测是本轮明确主线；已有同building结果为比较基线，不代替上述研究。

难标、分歧大、收敛不稳定和结果错误分别检验。交界图有研究价值，不因难标或分歧大而整体删去；质量较低需要独立质量依据。

## 2. 图片分类为什么要做、分别记录什么

分类用于建立可检验的历史图—目标图关系，并描述可能影响标注的空间条件。分类本身不是预测有效的证据。

| 对象 | 判断依据与用途 |
|---|---|
| 同一物理房间及预测配对 | 从原图固定结构及相对位置核对物理身份，再检查两图视觉主空间是否一致；两者都满足才能确认当前研究的预测对 |
| 较粗图像类型 | 按原图的功能和空间组织探索；用于后续跨房间预测 |
| 功能组合与主要呈现区域 | 功能可多选；主要呈现区域单独说明，如“起居为主，厨房次要”。这不是后续采集优先级 |
| 拍摄位置与信息条件 | 分开记录空间交界、可见范围不足、遮挡等；用于分析分歧 |
| 后续采集优先级 | 区分同房预测与相似场景用途；不优先采集不等于不同房、不属于某类型或从历史评价中排除 |
| 每张图内部的标法簇与稳定性 | 来自人员标注，是待预测、待解释的结果 |

客厅、餐厅、厨房等功能名称不必对应独立的几何房间。同一开放布局可以包含多个功能区，不因拍摄重点不同自动拆开；反过来，仅能通过门洞相互看到或走通，也不足以合并为同房间。

以上开放布局原则用于认识空间组织，不代表整片开放布局中的图片都能互相组成预测对。此前“整体开放布局关联”或多个开口串联出的宽泛候选，应保留为检索线索，按两图的视觉主空间重新核对；不得通过候选的传递关系自动合组。是否符合配对范围须在查看预测效果前判断。

历史粗类包含：卧室、卫浴、起居与休闲、厨房与用餐、通行与连接、工作与学习、储藏与家务辅助、特殊用途、开放复合空间、无法判断。旧值作为人工历史保留；当前不再用“开放复合空间”替代主要区域，改用本文开头的功能、主空间与逐对分隔关系。附属书桌、座椅不自动构成独立功能区；旧“厨房与用餐”大类也不意味着每图都含烹饪设施，功能字段仅写图像支持的内容。

同房信息可以补充局部视点对整体空间的认识，但应注明对照推断；仍为候选的同房关系不能传递成整个开放大组的确定身份。左右顺序差异须考虑全景旋转和接缝，不能单凭反向观感断言不同房或断言数据经过镜像处理。

归组依据是原图及可核实的物理空间关系。关于“我会标哪里”的评论用于揭示范围歧义，不直接作为统一的正确标注答案，也不据此反过来定义房间。**不得依据目标图收敛曲线是否相似、预测是否成功来决定归组。**

## 3. 空间交界处的工作定义

“空间交界处拍摄”要求有证据支持相机处于两个可区分区域的交接位置；实际门洞、宽开口或带高差的空间过渡可分别核对。靠近交界但偏在一侧、看见多个连通空间、模型跨门扩张以及普通走廊拐角，不自动满足这一判断。是否发生范围歧义另外记录，不能以难标本身定义交界。

其中单独区分：

- **门洞内拍摄：**有证据支持相机位于实际门洞的边界位置；不要求从RGB估出精确几何中心，无法确认时保留疑似。
- **其他空间交界：**例如宽开口或高差处的过渡位置。墙端、功能区相邻或转弯本身仍不足以认定相机位于交界，需记录位置证据。
- **近交界但暂不归入／位置不明：**单独保留近处开口、可见区域和范围疑点，不把这些图混入交界候选数量。

本批用户指定的低优先级交界候选为：B01的7y楼02、B07的jh楼14、B13的q9楼13、B15的uNb楼02。这个清单只对应本批新增决定，不抹去此前其他图的判断。“回”字走廊拐角目前建议另记通行空间转折／范围歧义，不仅因转弯就计为两区域交界；该项为AI建议，尚非用户最终确认。

以上是待统一复核的描述规则，尚不是已经验证有效的分类器。位置证据、研究者预期的歧义、实际标注分歧分开记录，避免因为看到了分歧才反过来认定“交界处”。图像弯曲、近处物体变形与可确认的拼接缺陷也分开，不凭投影观感直接判为拼接错误。

现有页面的“门洞内”选项保持原义；更广的空间交界情况先写评论，不把旧选项静默扩大解释。

3. **先核对楼内物理空间与主空间。**并排展示候选的两张或多张原图，比较固定墙体、开口、窗、设施及相对位置，活动家具和相似装修仅作辅助。同一物理房间可有不同拍摄重点，但当前预测配对还须核对视觉主空间一致；只查看一张图不能确认配对。疑似配错编号时，继续在该楼寻找其他候选，不只否定眼前一对。

## 6. 分类完成后怎样检验

以“一张历史图预测另一张图”为基本比较，同时优先安排多视点房间中的多目标预测，并比较增加历史视点是否有帮助。汇总所有符合预先规则的预测对，不能只展示个别成功案例。预测时不读取目标图标注来选历史图、拟合预测或调阈值；目标图标注仅在预测完成后用于评价。重复抽取人员顺序时说明抽取方法、次数和汇总方式，不能将回放平均曲线说成真实唯一的标注顺序。

同房间来源与总体历史、同楼其他房间、同类型其他房间，在可比较的历史图数和人数预算下比较。报告阶段判断、人数范围、观察终点、无法判断的比例及过早宣布稳定的风险。只有2–3图的房间可以形成预测对，但反复留图、反复抽人不会增加独立房间数；效果汇总需要保留房间、building及人员重复出现的依赖。

同一位置附近的近重复视点和明显不同拍摄位置应分别描述。目视发现uNb24／83视点非常接近，这类配对可保留，但不能用其效果代替较大视点变化下的预测效果；未用相机坐标量测位移。成对处于同一连接口、但无法确认归属同一实际房间的图片，保留作交界／连接场景线索，不强行提升为同房预测配对。

同类型预测另留出整个目标房间的标注；若要声称适用于新building，还须留出目标building。空间交界条件作为独立属性比较，不能用未控制的差异直接宣称因果关系。后续补充人员可用于检验当前预测，但历史参与者回放和新人验证分别报告。

用户认为某些同房视点的标注重点或范围差别较大，因此暂不优先用于下一轮同房标注；这不影响它们参与相似场景候选整理。此决定先记为采集优先级。既有同房评价不能因为结果差异明显而静默删图；若开展范围更可比的子集分析，需要明确子集依据并保留全量对照。最新整组评论已明确uNb02排除后的28／44／80为相近子组；仅在探索性选图表区分该子集，02原图、标注和门洞对照仍保留，不裁定GT。
