# 图片分类与同房间收敛预测研究 SOP

讨论版 v3 · 2026-09-11，按开放布局、主要呈现区域和独立交叉复核要求修订。当前有两条研究线：同房标注收敛相似性／预测；交界处标注歧义／相似性。本文记录研究意图和图片复核流程，不表示假说已获数据支持，也不改写正式 Paper A 方法合同、GT、人员资格或派发协议。稳定性计算沿用[相似场景标注稳定性分析SOP](相似场景标注稳定性分析SOP.md)，具体数值判据仍须在验证前明确。

## 1. 真正要检验的问题

**研究线一：同一个物理房间、不同拍摄位置的全景图，是否具有相似的标注收敛过程？能否用一张历史图的标注，预测另一张图的整体表现？**

例如，历史图在约8人后进入稳定阶段，并在后续20余人的观察中保持稳定；同房间的新图是否也会在大致相近的人数附近稳定？研究对象包括阶段类型、进入阶段的人数范围，以及后续增加人员时的变化，不要求恰好同一个人数收敛。

需要区分以下情况：

| 观察情况 | 在本研究中的含义 |
|---|---|
| 达成共识并保持稳定 | 一种稳定结果；“共识”的操作判据须事先说明 |
| 稳定形成几个标法簇 | 也是稳定阶段；存在分歧不等于未收敛 |
| 在已有较高人数下仍增加不同标法、分布仍变化 | 有限观察范围内尚未稳定，不能推断永远无法收敛 |
| 人数、观察长度或几何计算不足以判定 | 无法判断，不自动并入“仍在变化”或“已经稳定” |

“出现新的单人标法”和“形成至少两人支持的簇”分别记录。支持人数门槛不等于标法真实性：使用两人门槛时仍保留单人结果，以检查是否掩盖少数标法。点数不同必须属于不同标法簇。图像分类不决定这些计算结果。

**研究线二：交界处标注歧义／相似性。**独立统计处于两区域交界的图片，研究其范围选择与标注分歧，以及这些交界图片的标注表现是否相似。这里的相似性具体比较哪些量尚待明确，可探索分歧结构与收敛过程，不能先假定所有交界图都难标或都不稳定。它是用户明确提出的一条研究线，不再仅称为附带的分歧分析。

**后续相似场景归类：**汇总各楼房间，按图像本身探索较粗的室内类型，并另设交界属性及统计。交界图仍保留其室内类型，例如卧室＋交界候选；也可按交界属性汇总为跨房间的相似场景候选。普通类型与交界统计可交叉，不强行互斥，也不把交界候选直接算成已确认交界。跨房间同类型预测仍为后续问题，已有同building结果为比较基线。

难标、分歧大、收敛不稳定和结果错误分别检验。交界图有研究价值，不因难标或分歧大而整体删去；质量较低需要独立质量依据。

## 2. 图片分类为什么要做、分别记录什么

分类用于建立可检验的历史图—目标图关系，并描述可能影响标注的空间条件。分类本身不是预测有效的证据。

| 对象 | 判断依据与用途 |
|---|---|
| 同一物理房间／连续空间 | 从原图中的固定结构及相对位置核对，建立同房间预测对 |
| 较粗图像类型 | 按原图的功能和空间组织探索；用于后续跨房间预测 |
| 功能组合与主要呈现区域 | 功能可多选；主要呈现区域单独说明，如“起居为主，厨房次要”。这不是后续采集优先级 |
| 拍摄位置与信息条件 | 分开记录空间交界、可见范围不足、遮挡等；用于分析分歧 |
| 后续采集优先级 | 区分同房预测与相似场景用途；不优先采集不等于不同房、不属于某类型或从历史评价中排除 |
| 每张图内部的标法簇与稳定性 | 来自人员标注，是待预测、待解释的结果 |

客厅、餐厅、厨房等功能名称不必对应独立的几何房间。同一开放布局可以包含多个功能区，不因拍摄重点不同自动拆开；反过来，仅能通过门洞相互看到或走通，也不足以合并为同房间。

本轮粗类包含：卧室、卫浴、起居与休闲、厨房与用餐、通行与连接、工作与学习、储藏与家务辅助、特殊用途、开放复合空间、无法判断。连续开放、多功能组织明确时使用“开放复合空间”，不再与“待定”合用。附属书桌、座椅等不自动把普通卧室改成复合空间；“厨房与用餐”这一大类也不意味着每图都含烹饪设施，功能字段仅写图像支持的内容。

同房信息可以补充局部视点对整体空间的认识，但应注明对照推断；仍为候选的同房关系不能传递成整个开放大组的确定身份。左右顺序差异须考虑全景旋转和接缝，不能单凭反向观感断言不同房或断言数据经过镜像处理。

归组依据是原图及可核实的物理空间关系。关于“我会标哪里”的评论用于揭示范围歧义，不直接作为统一的正确标注答案，也不据此反过来定义房间。**不得依据目标图收敛曲线是否相似、预测是否成功来决定归组。**

## 3. 空间交界处的工作定义

“空间交界处拍摄”要求有证据支持相机处于两个可区分区域的交接位置；实际门洞、宽开口或带高差的空间过渡可分别核对。靠近交界但偏在一侧、看见多个连通空间、模型跨门扩张以及普通走廊拐角，不自动满足这一判断。是否发生范围歧义另外记录，不能以难标本身定义交界。

其中单独区分：

- **门洞内拍摄：**有证据支持相机位于实际门洞的边界位置；不要求从RGB估出精确几何中心，无法确认时保留疑似。
- **其他空间交界：**例如宽开口或高差处的过渡位置。墙端、功能区相邻或转弯本身仍不足以认定相机位于交界，需记录位置证据。
- **近交界但暂不归入／位置不明：**单独保留近处开口、可见区域和范围疑点，不把这些图混入交界候选数量。

本批用户指定的低优先级交界候选为：B01的7y楼02、B07的jh楼14、B13的q9楼13、B15的uNb楼02。这个清单只对应本批新增决定，不抹去此前其他图的判断。“回”字走廊拐角目前建议另记通行空间转折／范围歧义，不仅因转弯就计为两区域交界；该项为AI建议，尚非用户最终确认。

以上是待统一复核的描述规则，尚不是已经验证有效的分类器。位置证据、研究者预期的歧义、实际标注分歧分开记录，避免因为看到了分歧才反过来认定“交界处”。图像弯曲、近处物体变形与可确认的拼接缺陷也分开，不凭投影观感直接判为拼接错误。

现有页面的“门洞内”选项保持原义；更广的空间交界情况先写评论，不把旧选项静默扩大解释。

## 4. 逐图复核流程

1. **先处理已有争议。**逐条阅读用户评论，并核对选项。23条队列已分组讨论并收到剩余15项的批量反馈；最新决定见[批量反馈整理](../../analysis_results/scene_image_exploration_20260910_v1/批量反馈整理_20260911.md)。未决事实冲突单列；“待我复核”不能倒推为未看。其余全量复核从保存记录继续，不重头开始。
2. **核对身份。**每条保留building、楼内图号、完整image_id和原始split；旧页面C编号另记，防止把案例号误当图号。
3. **先核对楼内物理空间。**比较固定墙体、开口、窗、设施及相对位置，活动家具和相似装修仅作辅助。同一房间可有不同拍摄重点；疑似配错编号时，继续在该楼寻找其他候选，不只否定眼前一对。
4. **记录决定和不确定性。**区分已确认同房、已确认不同房、暂不合并且身份待定；注明是谁的判断、依据及未解决问题。一个空间的视觉联系不等于最终房间归组。用户作最终人工分类，证据和疑点同时保留。
5. **再汇总粗类型。**先核对valid/test，不预设每房必有2–3张；未配对图不能视为已经确认没有同房图，train补查可作为后续工作。允许边观察边合并、拆分类型；每次修订写下判据和受影响图片，按新版回看已有分类。
6. **保留原始填写。**评论与选项冲突时保留双方，另记解释及讨论结论。原始JSON和正在填写的HTML不覆盖。进入预测验证前固定分类版本及评价方案；已看过标注的案例如实标记，不能追溯宣称盲法。

本轮执行清单固定为648图：145图新增逐张原图查看、465图按新标准重新目视简审、38图沿用近期讨论不重判。简审可用原比例、单图宽至少900像素的大图板，拿不准再开原图；查看方式逐图记载，不能用旧笔记代替本轮目视。新增／拆分同房、实质粗类更改及交界候选交另一复核者独立检查，双方意见并列保留。新增反证即使涉及原先未标争议的图，也进入待确认范围。

统一提示词及字段说明见[本轮复核统一要求](../../analysis_results/scene_image_exploration_20260910_v1/本轮复核统一要求_20260911.md)。新页面将原始评论、主审建议、交叉意见、后续人工填写分别保存；已讨论的38图以原讨论来源单独保留，不把未定事项自动改为最终确认。

按用户后续要求，表单版本2预填主审判断：检查无误可直接保留。蓝色表示与初始值相同，橙色表示改值，改回恢复蓝色；颜色不等于已审核状态。状态只由用户手动选择，不随其他字段修改自动重置。旧填写优先于预填，导出分别保留初始值、实际输入及合成的当前分类，具体字段见统一要求；既有v3导出仍可导入。

简要记录格式：**图片身份｜同房候选及空间证据｜当前决定｜粗类型｜交界位置证据｜范围／信息疑点｜用户评论与选项冲突｜日期**。没有把握可写“待定＋原因”。

## 6. 分类完成后怎样检验

首先检验“一张历史图预测另一张图”，汇总所有符合预先规则的预测对，不能只展示个别成功案例。预测时不读取目标图标注来选历史图、拟合预测或调阈值；目标图标注仅在预测完成后用于评价。重复抽取人员顺序时说明抽取方法、次数和汇总方式，不能将回放平均曲线说成真实唯一的标注顺序。

同房间来源与总体历史、同楼其他房间、同类型其他房间，在可比较的历史图数和人数预算下比较。报告阶段判断、人数范围、观察终点、无法判断的比例及过早宣布稳定的风险。只有2–3图的房间可以形成预测对，但反复留图、反复抽人不会增加独立房间数；效果汇总需要保留房间、building及人员重复出现的依赖。

同类型预测另留出整个目标房间的标注；若要声称适用于新building，还须留出目标building。空间交界条件作为独立属性比较，不能用未控制的差异直接宣称因果关系。后续补充人员可用于检验当前预测，但历史参与者回放和新人验证分别报告。

用户认为某些同房视点的标注重点或范围差别较大，因此暂不优先用于下一轮同房标注；这不影响它们参与相似场景候选整理。此决定先记为采集优先级。既有同房评价不能因为结果差异明显而静默删图；若开展范围更可比的子集分析，需要明确子集依据并保留全量对照。例如uNb02目前只是“同房预测可考虑排除”，尚未执行排除，其台阶与墙角解释作为用户假说保留，不自动裁定GT或改标注。

人员分类、独立结果组合以及HoHoNet特征仍是相关探索线，不在本文中重新确定类别或模型层。图片归组完成不等于这些方法已有效。
