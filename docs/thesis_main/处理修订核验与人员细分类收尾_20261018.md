## 4. 现在需要的人工查看及后续顺序

离线页面上方有6组对照按钮，包含同构成最大变化、纯类正反例及门洞跨构成节点变化。**现在值得用户查看这6组**，重点记录：哪一组保留了必要结构、哪一组错误连接或切掉重要区域、分数方向是否符合实际观感。它们按结果后挑选，只用于解释，不能当准确率或代表性样本。查看时可切ERP／BEV／3D；两侧独立适配范围，不直接比较屏幕面积。
