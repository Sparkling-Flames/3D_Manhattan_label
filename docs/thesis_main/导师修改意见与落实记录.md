# 导师修改意见汇总

本文件仅汇总导师提出的修改意见，持续按讨论主题补充，不记录执行状态、编译结果或编辑者判断。图号指讨论时的稿件。

## 一、整体篇幅

正文压缩至 12–14 页，不包含参考文献等内容。围绕重要内容安排篇幅，避免局部去重后整体仍然过长。

## 二、摘要

### 1. 背景、问题与整体方案

- 摘要中研究目的的分量不足，应先交代可靠全景布局数据的背景，再说明现有数据或标注手段存在什么问题、为什么难标。
- 按“背景—冲突或疑问—解答”组织：背景解释问题由来，随后明确研究困难，解决方案回应这些困难。
- 不应在描述人员差异后直接跳到“提出两个方法”。先让读者理解整项工作是一个整体框架，再介绍其中的方法分别解决什么问题。
- 直接并列两个方法可能让读者误认为它们是竞争方案，需要解释其职责和相互关系。
- 不用空泛的“针对上述问题”替代具体动机；提出的困难应与方法和创新点对应。

### 2. 结论选择与量化支撑

- 摘要无需全面罗列所有结果，应区分主要与次要发现，优先保留关键结论。
- 主要结论应有量化证据，让未读正文的读者理解其重要性，而不是前面大量报研究规模、后面只作定性概括。
- 可以用代表性数据或案例支撑关键观察，不必把每项支线都塞进摘要。
- 摘要需要回答为什么做、做了什么、如何做，以及这项工作的价值为何值得发表。
- 结尾说明研究意义和适用对象，形成完整收束。

### 3. 数字与关键词

- 数量表达应统一，优先使用阿拉伯数字，避免同一段同时出现 22 和 twenty 等写法；全文也需注意一致性。
- 斟酌 human annotation variability 与 variation：前者偏可变性质或程度，后者偏实际变化与差异，应按研究对象选择。
- 共识关键词需要清楚体现人群对结构的共识，避免让读者误解为结构本身的共识。导师提出 crowd structural consensus 作为表达方向。
- 关键词应稳妥、专业，不应让读者在入口处产生不必要的术语疑惑。

## 三、图片与排版

### 1. 标题位置与 LaTeX 规范

- 按论文实际使用的 Elsevier 模板处理图片和标题，不以生成整张图片替代规范排版。
- 子图标题应位于对应图面下方，并由 LaTeX 排版，而非预先生成在图片里。
- 总图注同样遵循模板样式，检查全部图片中的普遍性问题。
- 图面质量之外，格式和细节也会影响审稿人对论文完成度的判断，应避免可见的拼接感和不规范处理。

### 2. 图 4：从公式重复转向直观解释

- 原图重复方法公式，未能直观解释几何问题；正文已有公式，不必再在图中排列一次。
- 不为做图而做图，也不要求所有分量及合成 Q 都汇总到一张图。
- 选择适合视觉表达的几何改变，例如覆盖范围变化，展示具体形状如何改变。
- 可以构造受控案例，明确表现“几何怎样变—指标怎样变—最终分数怎样变”。
- 至少用两种可对比状态，让读者看见明显几何差别及对应分数，而非只有抽象说明。
- 使用区分清楚的颜色；相关形状都应清晰可见，避免一方显眼、另一方难辨。
- 直观展示优先，不为把所有内容汇总进图而增加不必要的版面。

### 3. 图 6：同样避免重复方法说明

- 图 6 存在类似图 4 的问题，应增强实际过程的可视化，而非再重复公式或文字流程。
- 图示应帮助读者理解方法怎样产生结果，而不只是复述方法内容。

### 4. 占地与清晰度

- 图形排版需压缩，图 10 可采用单行展示，图 13 同样处理。
- 充分利用电子审稿可以放大查看的条件，确保图件高清，减少不必要的多行排列和占地。
