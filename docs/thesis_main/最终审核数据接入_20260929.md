## 字段合同

| 字段 | 含义与限制 |
|---|---|
| `preprocessed_points` / `links_zero_based` / `point_labels` | 源点身份顺序下的平均x坐标、固定配对及固定标签；保留原始数组，不随环序重编号 |
| `points_1024x512` / `matterport_links_zero_based` | 最终使用环序的Matterport上/下交替数组、对应数组内配对；末对与首对相连。不可配对时均为null |
| `ordered_source_point_indices` / `ordered_source_pair_indices` | 最终数组回溯源点及固定点对的零基索引；不得用源links索引最终数组 |
| `original_export_indices` / `repair_evidence` | 有效点回溯原导出；补点为null并有修复来源。所有中间点保留，近180°不自动删除，可能表达较小空间停止边界 |
| `order_status` / `ring_confirmed` / `order_record` | 人工确认、默认未审、原始GT参考分开；记录绑定平均x点及固定配对 |
| `final_review` / `review_evidence` | 当前清洗、顺序、几何、范围和细节字段及原评语/历史来源 |
| `main_quality_gate` | 沿用`worker_quality_gate`及原`analysis_gate_reasons`。2030份`candidate_pending_geometry`仅为待方法核验候选 |
| `main_consensus_gate` | 沿用`consensus_group`及范围政策；`main_candidate`不是最终方法资格。必须同时消费清洗、待定、独立票限制和方法失败信息 |
| `independent_vote_eligible` / `independent_vote_reasons` | 保留且没有已应用他人补点的独立完整票候选；待定不自动恢复。供体证据见`borrowed_point_provenance` |
| `geometry` / `method_evaluability` | 前者沿用当前3D表示诊断；后者仍为`not_assessed_per_method`，3D失败不等同所有二维方法失败或人工错误 |
| `gt_version` / `images[].references` | 按原始GT和人工修订GT分别绑定。没有修订GT不伪造、不以原始GT冒充修订GT |
| `images` / `room_registry` | 逐图分类及覆盖、完整历史同房分组和候选证据；未确认同房不按建筑合并 |

OOS、门洞独立维度，允许共存；`not_recorded`不表示否定。空间/细节分别保留结构化标签、已有台账、历史comment候选，覆盖标记说明尚未穷尽；候选不升格为裁决，不向同房其他图片传播。模型未改坐标与用户明确误导评语分开，原始证据仍见[最终统计索引](../../analysis_results/final_review_summary_20260929/index.html)。
