# 构成方差与 DSTRUCT 衔接的提纲同步

2026-10-26。本页将已完成的有限成员面板衔接放入现有论文主线，不替换整篇提纲，不重开算法或实验。证据来自[本轮实际重聚合](../../research/workers/dstruct_composition_bridge_20261026/README.md)。主文继续保留几何质量评价与完整结构共识两项具体方法，以及真实人员的独立实证研究。

## 方法部分

1. **任务与原答**：定义图片／场景条件、人工表达、参考资格和表示边界。原答分歧不能由团队输出波动全部替代。
2. **质量方法**：展示实际输入分项、归一化、合成公式及 D10 改动位置；不是只用 Q 代表黑箱。既有 IoU 比较保留，明确规整棱柱近似与自由人工局部不协调的区别。
3. **完整融合方法**：周期对应、独立人员支持、位置估计、来源连接，以及实际失败状态；不是只用 F 代表黑箱。
4. **人员与团队实验**：DSTRUCT 的历史特征、缩放／域平衡与楼外建类，RFUSE 的响应输入及算法依赖；继而定义固定图、人数、背景和实际候选团队分布。K3 主解释、K2 粗层保留。
5. **本轮构成统计对象**：固定背景，12 人取 6 人完整 924 队；把全队类别人数向量作为分组。给出总方差＝构成间＋构成内的一行恒等式、实际团队权重、指标有效分母和图→楼等权规则。不可评分和实际融合失败分开定义。
6. **ABC／AC 与人数路径**：保留原实验对象、实际替换人数和支持。有限团队分布、自然增人路径及抽样误差是不同对象，不混用数字。

- **图 A：构成间与构成内方差**。同一 231 个 Manual 面板上，新 K2、K3 与旧结构粗／细层并列。主 Q 占比分别为 10.06%、14.36%、12.96%、14.02%。K3 构成内仍为 85.64%。图题写“同支持的有限面板分解”，不写“分类预测准确率”。
- **图 B：同一面板的全部配比**。均值点、格内 25%—75% 和 5%—95% 分布、有效／全部团队数及单队格标志。用已有 7y-21 示例接回历史图，而非为新分类重新挑最好图片；完整 231 面板和全格表进入可浏览交付。
- **紧接一段难度解释**。困难图 K3 的 Q 构成间方差为 13.3156 分²，简单图为 1.2541 分²，但占比分别 13.81% 与 19.07%。绝对差异和相对占比并非同一问题。转折占比困难 22.44%、简单 2.72%；中等仅 3 图，不外推。
- **随后保留固定背景替换与门槛机制**。构成分解本身不说明变化方向或因果作用；ABC、固定 XYZ 背景、定位和连接证据负责解释这些具体过程。旧配比结果、旧进入策略、同房三层与 RFUSE 不因本轮改名。
- **资格与风险附列**。状态账保留 1,263 个未完整可评团队关联及原因；时间使用自身 130 面板／31 图／21 楼支持，不与全部 Q 分母拼接。

可用的结果概括：

> 在相同实际团队与楼外标签支持下，DSTRUCT 三类构成组织了约 14.36% 的质量方差和 21.98% 的实际转折方差；多数质量波动仍来自同一构成内的具体成员差异。新三类与旧细层的总体解释比例接近，说明它的价值在于将困难条件下的原答表达与团队结果衔接，而非取代成员层面的机制解释。

## 讨论部分

围绕研究发现综合讨论，不按结果小节重复：

- 人员比例能组织部分差异，但不保证同类成员可互换；平均配比与具体成员支持应共同报告。
- 难图可能同时扩大构成间与构成内差异，比例较低不等于类别作用更小。
- K3 是 K2 的折内嵌套细分，描述占比增加存在数学必然性。此轮未新增响应预测，不能把楼外标签使用等同于完成新的预测验证。
- 质量算法和融合机制使这些差异可诊断、可追溯；不能把无输出、缺参考和表示不适用合并成一个“失败”。
- 自然人数接近满池时变异归零来自有限成员空间，不证明准确性；均值、低尾和成员敏感性的已有发现保留。
- 门洞与 OOS 保持目标—视点—表示相容性及真实人员响应的独立位置，不降格为统一限制段。
