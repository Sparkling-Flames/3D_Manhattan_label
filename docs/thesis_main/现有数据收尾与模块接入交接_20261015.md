## 1. WQ现在能否使用

可以使用 `WQ-LS08-20261014` 作为有版本的研究工作指标，无需等到质量模型成为唯一最终方案。保留同参考现用3D IoU及原始分项，不能将WQ解释为正确概率或已经验证的通用人类等级。

现工作式为：

`Q = 100 I / (1 + I K)`

`K = Sb²/32 + 1.5 D²/(D²+37.5) + (Hm/0.8)² + (Hc/0.25)²`。

`D`为自身最优共同正交轴下的方向残差，不是相对参考的墙面夹角误差。用户关于IoU与方向联合处罚偏重的意见仍是待研究问题；当前接入不代表已经解决。不能只把分数转成五档，就宣称修正了几何测量。

用户最新决定是保留两版调参：一版沿现有WQ结构研究参数；另一版允许实质改进测量与组合。两版均可研究，不预定必须由哪版胜出；后续以同输入、同参考、同资格比较人员及融合结论。先普通粗调，再门洞交界细调，不以门洞低分符合预期作为优化目标。小GT差错沿用户口径仍当GT正确，主观粗档用于整体核验，不要求逐例拟合。

## 4. 当时的接入推进顺序（部分已完成，非当前任务队列）

1. **先固定现有数据的比较面板。** 质量与难度线程核对参考目标，融合线程明确各条轨迹的评价参考，人员线程检查可比较的同图同参考单元。不能因参考未决把整项研究停住；可用部分先做，其他部分明确保留。
2. **并行补两类主要结果。** 人员线程建立WQ／IoU／分项画像，保留连续量和候选粗类；融合线程在保存轨迹上补质量曲线，难度线程按固定粗类分层。分别呈现参考接近度、原作答分歧和成员变化，稳定不自动等于正确。
3. **再做人员构成实验。** 在目标建筑之外建立人员画像，固定图片、人数、融合算法及参考，以相同基础团队的一人同类／跨类替换比较组成与具体成员的作用。先执行覆盖支持的规模，不一次铺开全部Q/T/S/B组合。子类内部更稳定是可检验问题，不是必须达成的筛选条件。
4. **两版评分完成后做同集合敏感性。** 比较画像、粗类及融合结论是否改变。可以保留主分析与敏感性两套；若结论依赖评分选择，应如实解释其测量含义，不能以哪版更符合预期来择优。质量细调不反向改变融合算法。
5. **收束论文这一版。** 形成数据流和分母表、指标解释及核验、难度—人数曲线、人员构成—成员波动对照，以及未解决范围/表示限制。现有数据若不能支撑某个分组效果，报告有限或不明确的结果即可。同房预测后置，不是收尾前置。

## 5. 什么叫现有数据“搞定”，以及何时加新数据

完成标准是现有台账有去向、可评价集和未决集可追溯、核心分析能重跑、所用评分/融合/参考版本明确、主要结论及两版敏感性已整理。不是3152份都必须产出完整分数，也不是每张图都得到理想结果。

现阶段不导入新数据、不混入当前参数开发。收尾后新增批次单独编号，沿用已确定版本先评价，旧结果保留不覆盖。可以用新增数据检查既有规律是否保持；若再据新数据调参，应将这一部分重新标为开发资料，不继续称独立验证。新旧条件、人员或图片分布若不同，分层报告。
