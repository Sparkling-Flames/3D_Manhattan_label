## 本次发现的旧规则与参数边界

1. 三份当前文档开头已有新要求，但部分正文仍写W19／W26归属未定。现行段落已改；旧页面计数保留历史注明。
2. 图片SOP曾把明确OOS、疑似和争议统一写“待定”。现已改为明确排除、疑问暂缓、非OOS保留，并保留图／组作用范围。
3. 分析SOP第5节的共同人数和窗口要求未在标题处明确“历史算法”。现已标明，不能覆盖当前8人共识判定。
4. 每块6份／3楼、等权、Ward、200次重排等是历史探索实现，不是用户要求永久使用的参数。后续可有依据地修订，并记录版本。
5. 旧质量中位数二分不能冒充“规则执行程度分类”；保留简单粗类候选，不等于已经选择质量法、规则法或旧名单。

## 未定事项与不能直接采纳的推断

- **最终稳定判据未完成定稿。**8人有效统一共识可按当前研究口径判收敛已明确；更少人数何时足够、多簇的比例允许变化多少、单人新标法如何影响阶段判定、q阈值和起点区间算法仍需明确。文档记录不等于已据此重跑实验。
- **人员最终分法未选定。**包括信息块、三轴方案中时间与修改量的条件对应、组数、阈值及最终名单；要报告缺数据的人，不能按“哪个结果更收敛”制造类别。
- **已经有逐人人图建议，尚未实际派发。**英文必做30＋可选20已由用户明确；中文每人20张为当前建议。新增人员、实际完成、可选参与和退出后的替补仍未兑现；不擅自取消已采用图。具体见[第一阶段分配建议](../../analysis_results/stage1_person_image_packages_20260913_v1/第一阶段分配建议说明.md)。
- **两条原想法保留为讨论，但不作为数据事实。**少人数共识可以计为收敛，却不能复制成更多独立人的标注；空提交或缺角应记录失败，但出现失败本身不能直接推出整个分布不收敛。以上是统计／数据解释边界，不改写用户原话。
- **历史研究结果的状态保持原样。**本次没有审计每个旧实验是否完全实现全部要求，尤其三轴方案、最新同房／同类型预测及最终Word，不能因清单写有条目就宣称已完成。
