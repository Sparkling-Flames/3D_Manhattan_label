# 相似场景标注稳定性分析 SOP

更新：2026年9月9日。本文是当前历史探索的统一方法入口；结果只维护[一份分析结果](../../analysis_results/multibuilding_threshold_stability_20260909_v1/分析结果.md)。不改变正式Paper A合同、人员资格、实验派发或阶段协议。

## 1. 研究对象

已有相似场景的标注，能否帮助估计另一张图大概需要多少人，标注分布才逐渐稳定？

本研究当前直接将同一building内的图片定义为相似场景分组，并据此开展留图预测与后续标注集准备；不以另行确认同室或同类房间为前提。每图独立形成簇，跨图预测人数／稳定曲线，不预测共享的具体类别。稳定形成多个簇允许算收敛。布局正确、分歧大小、分布稳定是不同问题；有限观察内未稳定不等于永远不会稳定。

不按目标曲线相似程度挑图，不为避免新簇而改点或调阈值。源图支持不足可以作为预先说明的设计限制，但目标图未知不能从评价分母中消失。

不自动修复未经确认的奇数点；唯一可删除候选只说明解析器删除后能计算，不证明那一点是手滑。几何不可评价不等于乱标，也不一律由点序导致。

## 4. 簇定义与稳定定义

有效点数不同必分不同簇，这个硬条件同时用于完整池、所有前缀、距离兼容、成员变化和验证。不仅改点数标签，受影响坐标的距离必须重算。

同点数几何并列采用q=.975/.95/.925/.90/.85/.80和无序球面点集OSPA30≤6°。q越低合并越宽，角距阈值越高合并越宽，两者不是人数／置信度／稳定容差。保留q=.95作为固定展示值，不因效果选最好看的q。

q依赖历史上下点配对和推定边界；最终墙面连接未保存，不得说q已确认墙面意图。两份28点原搜索截断现由连通分量求解恢复，目标、配对条件、全图歧义规则和原点序快速路径保留。算法搜索效率修复不是人工改点。其他q缺失保留未知，不低值填补，也不先删掉再把子集称完整图。

每张图投影同一批200条全局人员顺序，从1人逐个加入；前缀独立分簇。每个k检查随后h=1/2/3/5人的每一个前缀j：

1. 旧成员同簇关系改变的对数／旧成员总对数不超过epsilon。k=1无人员对，约定0不构成一致性证据。
2. 对后续分区的每簇C，比较前k人与前j人的份额，TV=0.5×Σ| |C∩前k人|/k − |C|/j |，不超过epsilon。
3. 没有簇相对k从支持<m跨到≥m；k时至少有一个≥m支持簇。

epsilon=.05/.10/.20，m=1/2/3全部保存。低支持簇仍参与成员和份额变化。m表示重复支持，不是真实类别票数；支持跨越也可能来自重分区，不能都叫新语义类。稳定多簇不因簇数>1判失败。

所需任一分区非唯一、搜索截断、包含q无效响应或k支持不足，记unknown；不得并入changing或stable。每个节点三状态和为200。L=stable/200，U=(stable+unknown)/200，是未知状态边界，不是置信区间。

人数摘要以80%排列达标为候选：从k起所有保存节点持续过线。分别对L与U求起点；相同有限值为identified，不同有限值保留区间，保守端未过线单列，U也未持续过线为窗口内未达到。无后续响应另列无窗口。有限区间如[1,2]包含信息，但k=1未满足m2支持，不能称1份足够。候选人数均是事后摘要，不是实际停止保证。

## 5. 人员口径对照和低人数分析

两组使用相同参数及全局人员顺序。各自完整人数结果保存，但直接对照须先以同图两组较小N截断到k≤N−h，并重新求人数，避免样本末端截短影响。共同N仍不控制人员组成，不作个人因果解释。

高人数入口按可计算不同人员≥16在结果前确定；两组仍同样55图。低人数141图全部保留，人数实际1–7，只在能容纳后续窗口时计算。不能因N少而预先叫它不稳定，也不能把h1稳定当成长窗口稳定。

短窗口延长检查用高N图：同图／排列／k的h1/2/3对h5，k=2/3/4、k+h≤7，q.95/.925/OSPA。固定m2、epsilon.1，输出逐图与汇总3×3状态转移、条件率及有效分母。h5包含早窗，这是历史延长检查，不是独立新人验证，不直接给低N图贴稳定类型标签。

## 6. 跨图预测

先分图，不用固定1/3或2/3人员切分限制所有图最多分析15人。每张图完整可算人数都进入该图自身回放。

10楼各有至少2张高人数图，共50图。每楼枚举全部非空源图及互补目标图，共4404种有向划分，uNb12图为4094种。源图平均稳定曲线预测目标曲线，不预测目标具体类别。目标完整响应只用于评价，不进入源图筛选或参数选择。

每楼采用所选图最小N作为共同预算，h5下k到N−5。两个人员口径对照还使用同样图集、楼内共同N和同样楼外来源身份。当前共同N为20/22/23/24，k到15/17/18/19。楼外匹配源图数量和N，最多50组；不足则枚举。大量重叠划分不是独立实验。

误差区间为：
下界=max(0,L预测−U目标,L目标−U预测)；
上界=max(|L预测−U目标|,|U预测−L目标|)。
先按节点和目标图平均，再汇总划分。全未知[0,1]不能因误差下界0叫准确预测。人数误差仅在双方候选人数都identified时计算，并同时列覆盖及未知。源图数all的汇总不把uNb4094次重复当作4094个独立场景。

若进一步测试新人员泛化，再单独设置2/3、60%、1/2等人员留出，同楼同人跨图保持同组，逐图报告H/V和可评价长度。9名验证者不能独立验证20人的稳定曲线。此轮没有完成新人员独立曲线或两类预测模型，不将它们写成已经验证。
