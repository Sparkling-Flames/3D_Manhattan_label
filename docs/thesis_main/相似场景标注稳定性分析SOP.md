## 1. 研究对象和问题

研究链路为：原始作答与人工裁决 → 清洗及同人角对共享 x → 统一区域 → 区域共识 → 与 GT 的差距、人员变化和人数曲线。人员分类、真实成员组合及进入顺序仍是重点，分簇是可选方法对照，不是所有共识的前置条件。

分别回答：人员标注在给定图片上的质量如何；控制图片差异后人员表现如何；怎样把多份区域构造成共识；相同人数不同成员为何产生不同结果；新增人员后共识是否更接近 GT。人与人一致不代表正确，接近 GT 也不表示全部人达成一致。

## 3. 区域、IoU 与质心

统一构造二维墙带：上边界与下边界之间的像素区域。主候选采用空间直线投影回全景后的曲线，二维直线插值作为敏感性对照。人员、原始GT、修订GT及模型必须用同一构造器、分辨率与坐标规范；复用 `lib/misc/panostretch.py` 的空间直线投影核心，不另写视觉近似来冒充同一方法。

全景左右周期相接；所有插值、距离、邻域、连通分量及后处理均检查接缝。无法唯一构造墙带、同方位多层边界或退化情况保留原因，不默默转为空区域或判为坏标注。二维区域路线不要求补交三维房间角点连接顺序，也不自动把困难结构规整为Manhattan房间。

IoU为交集面积除以并集面积。质心使用区域面积，不用角点平均。先分别报告垂直偏移、水平接缝问题、圆周质心方向及集中程度。近乎环绕一圈的墙带，水平圆周方向可能极不稳定；方向差不能无条件解释成整体移动的像素数。普通平面质心、圆周质心和圆周一阶矩向量差分别标注单位与含义，后者不是像素位移。

IoU＋质心是导师与用户提出的人员质量研究。先检验质心在同质心异形状、平移、边界扰动、接缝旋转和真实叠加图中的解释，再比较仅IoU与组合方案；不预设组合必优，不冻结尚未验证的权重或人员阈值。

GT主敏感性使用原始Matterport与人工修订两版，30张修订清单及实际交集逐项记录。不使用HoHoNet自带GT替代该对照；HoHoNet/BiLayout输出是模型参考。修订变化对单份质量、人员排序及共识曲线分别报告。

## 4. 以 Lee 论文为起点构造共识

[Lee等论文](https://ceur-ws.org/Vol-2173/paper10.pdf)将多个人的区域叠加形成不重叠tiles，依据每人是否包含该tile选择共识区域。给定当前k位真人的区域A，保存支持率 `f(x)=sum(1[x属于A_r])/k`；多数投票共识取 `f(x)>=0.5`。统一栅格上的逐像素投票与该栅格内相同支持组成的tile投票等价，不必引入多边形布尔运算系统。

分别保存真人支持率、算法共识区域、共识与GT的差距。STAPLE等算法的概率图不冒称真人支持率。

|比较项|实施与解释|
|---|---|
|Lee多数投票|至少50%主基线；严格超过50%作平票敏感性。两人时前者可能是并集，不隐去该现象。|
|真实作答medoid|选择与其他作答总体Jaccard距离最小的真实区域；并列采用稳定作答ID规则。检验合成是否优于选代表。|
|单正确率EM、greedy|已有实现保留为Lee思路适配，不称完整作者复现；对照论文、实际目标函数及代码，缺少技术细节明确记录。|
|标准STAPLE|估计敏感度、特异度及潜在真值，使用成熟实现；逐图参数不是已经剥离图片难度的人员能力。|
|MAP-STAPLE|性能先验为独立实验；弱先验、外建筑GT校准先验需分别验证，不用改普通STAPLE阈值冒充MAP。|
|MACCHIatO-Jaccard|验证平方Jaccard共识目标、启发式求解与作者实现；周期邻域/连通性适配通过后才加入正式比较，不保证合法房间结构或全局最优。|
|人员加权投票|仅IoU校准与IoU＋质心校准对照；权重依据目标建筑之外的数据建立。|

[STAPLE](https://pmc.ncbi.nlm.nih.gov/articles/PMC1283110/)、[MAP-STAPLE](https://pmc.ncbi.nlm.nih.gov/articles/PMC3079852/)、[MACCHIatO](https://www.melba-journal.org/papers/2023%3A013.html)的论文结论不直接转为本数据优势。现有单正确率EM不是标准STAPLE。MACCHIatO部分实验以生成共识为参考，不能据此证明更接近独立GT；未取得可核验实现时记录缺口，不宣布算法已运行。

分簇作为全体聚合/最大簇聚合的附加对照。论文中的IoU谱聚类与本项目局部结构分簇不是同一算法，分别记录。结构多画少画仍有描述价值；保留尾部、其他簇及支持人数。横轴按实际收集k人计费，同时报告实际参与聚合人数，不删除人员后混淆成本。首轮评价原始聚合输出，几何规整另作后处理对照。

## 5. 人员画像、组合及曲线

逐份对GT的质量与跨图片人员画像分开。建立人员×图片测量表，使用共同图片比较及可识别的人员/图片效应调整；报告样本支持、覆盖和不确定性。当前通常每人每图只有一次作答，不能据此唯一分离人员随机性与人图交互，也不由稳定低质量推断动机。

人员分类仍比较既有候选，保留未分类及支持不足。人员类别、组合权重、模型参数和特征选择只使用目标建筑以外的数据；不让目标GT参与给人员赋权。AABC仅为示例，两个A必须来自两个不同真人，人数和比例不限四人；具体成员、类别比例和顺序分别研究，不复制一份作答当多人。

共识曲线共用相同图片、人员子集和顺序前缀，前k人拟合不读取后来人员；固定图像栅格可预先定义。并列报告接近GT的质量、相邻人数区域变化、同人数不同成员差异和尾部支持。固定面板用于人数间公平比较，各图完整可用轨迹另报，避免人数增加导致图片组成改变。确定性算法在相同最终集合上的一致是构造性质，不称发现质量上限。

置信区间与预测评价按建筑/房间依赖处理，不把全部作答视为独立。未达到目标、观察人数不足、算法失败和GT不适用分开；最终方法不以更早变平、更多共识图或显著性为选择依据。

## 6. 实施、视觉复审与验收

[Pro任务](PRO_CONSENSUS_RESEARCH_TASK_20260923.md)包括清洗数值审计、区域与质量测量、共识构造比较。Pro可计算和排序，不替用户裁决原图语义。收到结果后本地复算，再由用户与本地助理审查原图/区域叠加/质心示例；已审、未审和暂缓逐项保存。
