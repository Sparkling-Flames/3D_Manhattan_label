## 3. 一个完整、但仍待确认的研究结构

候选总问题：

> 在固定任务规则与信息条件下，独立标注人数增加时，响应分布、少数结构覆盖和代表参考质量如何变化？这些过程如何受到图像与人员组成影响，已有信息能否预测新任务的稳定过程，并在新增人员中得到验证？

这是一个总问题下的相连部分。下面使用A／B／C作为讨论标记，不映射或改写正式Paper A已有RQ编号。

| 部分 | 具体问题 | 需要的证据 | 当前进度 |
|---|---|---|---|
| A：人数与稳定过程 | 增加独立人员后，何时形成持续单簇／多簇稳定，何时在预算内仍变化？代表质量是否同时改善？ | 每图重复响应、固定度量与窗口、稳定／未知分开、质量参考单列 | 已有大量历史回放及具体例子；正式阈值未锁定 |
| B：人员组成 | 相同图、相同人数，不同操作性表现档及配比，是否改变分布和代表结果？ | 分类校准独立于目标评价；组合使用不同真人；同图同人数比较 | 有连续人员差异和候选分档；稳定天然类型及统一组合收敛验证未完成 |
| C：场景与预测 | 同楼图是否具有可预测的大致稳定人数范围？标注前图像特征能否进一步解释楼内差异？ | 留出目标图；比较范围宽度、覆盖与误差；同楼、楼外及图像特征基线；新增人员验证 | 同楼预测整体增量未确认；历史数据支持继续检验范围预测及图像信息的增量 |

人员分类是B的测量工具，不必把“发现天然四类”当成所有实验的前提。HoHoNet特征是C的候选输入，不必成为另一个与主问题脱节的模型工程任务。新增人员用于检验A／B／C的可重复性与适用范围，而非为每种配比再实施一次实验。

### 始终分开的三个结果

1. **分布稳定：** 新增人员后，簇关系及比例在指定窗口中是否变化较小；允许多簇。
2. **少数结构覆盖：** 是否仍发现有重复支持的新解释，或已有资料是否漏掉一部分解释。它与主要分布稳定有关，但不相同。
3. **代表参考质量：** 选出的代表标注与当前参考有多接近；稳定多簇不能直接称高／低质量，分布稳定也不保证参考正确。

导师说的“噪声”和“质量上限”还需要操作定义。观察到的分歧可能同时包含合理多解、规则误解、操作误差和参考问题，当前点集距离无法将其完整分解。现阶段可研究有限预算下的经验瓶颈、边际收益和预测能力，不能预设已经估计出不可约噪声或绝对质量极限。

## 4. Building方向的继续分析依据，具体是什么

直接证据见[现有数据核对](../../analysis_results/convergence_hypothesis_review_20260909_v1/README_ZH.md)。例如在uNb同楼统一N=23、q=.95、h5、m2、容差.1、80%排列持续达标下，存在5／5人、8／8人、17／15人的候选起点，以及末节点仍明确变化、unknown为0的图；17／15人的例子在稳定时具有至少两个m2支持簇。

完整分母是12张高人数图，两个人员口径下均为5图确定候选人数、3图观察窗口内未达标、4图unknown。包含W19／W26时，5个候选为[5,7,8,9,17]；排除后为[5,5,8,8,15]。已识别子集中确有4图集中在较低人数区间、1图较晚的线索，值得继续分析；但4图只占全楼4／12，不能称“大多数楼内图都在5–9人收敛”。unknown也不能计成不收敛。以上为当前q度量和窗口下的探索结果，不是所有度量均一致的结论。

这些差异不能直接否定“大概人数收敛”。5人和8人是否足够接近、15人是否属于同一实用范围，需要先说明预测用途和可接受误差；不能看到结果后任意放宽范围。不同命题应分别检验：

| 命题 | 现有证据如何评价 |
|---|---|
| 同楼图的收敛人数是否集中在可用的大致范围 | 尚需直接检验；有不同候选起点不等于缺乏集中性，也没有证明已经集中 |
| 同楼图之间可能存在某种统计联系 | 合理可检验；需保留楼内差异，并报告未达标和无法确定的目标 |
| 同楼信息比楼外信息更能预测目标 | 尚未确认；必须直接比较预测误差与覆盖 |
| 结合图像信息，可以识别同楼不同稳定情形 | 有可用数据和候选输入，尚未完成预测验证 |
| 不同情形一定就是三个固定类型 | 尚无证据；速度、单／多簇和预算内未达标不能强制合并成天然三类 |

因此，“有理由继续”来自明确的待预测现象、可做留图验证的数据和标注前特征；目前不能说已证实或已否定building的大致人数规律。

“大概”应落实为可评价的预测：例如输出目标所需人数的范围，同时报告范围多宽、覆盖多少留出图、多少图在现有预算下仍无法确认。很宽的范围容易覆盖目标，却未必帮助安排人手。还要比较不使用building的通用范围：若所有楼都差不多在同一范围，可能存在总体规律，但building未提供额外信息。当前稳定率中的“80%排列持续达标”是单图候选起点规则，不等于“大致范围覆盖80%的房间”。

历史可用无辅助资料为196图；高人数资料为55图、15楼，其中10楼50图可作楼内留图。已有HoHoNet缓存并集覆盖214张历史图，但87个重叠图在两缓存中数值不同。统一图像来源和特征规则后，可以先比较少数固定特征；不能把旧风险分数直接命名为人的收敛难度。

### 预测任务应说清输入与输出

- 无目标标注的预测：使用历史源图、目标图的图像特征和building信息，预测目标在预算内稳定的可能性、候选人数范围或稳定曲线。
- 使用少量目标响应的预测：明确已看过前r名人员，再预测后续变化或尚需人数；这是一种额外信息条件，需要计入预算。
- 同楼预测：已知该楼其他图片的历史数据，预测该楼留出图。若目标属于完全新楼且无该楼源图，就不能称作使用同楼历史的预测。

至少比较一般历史规律、同楼历史、图像特征、图像特征＋同楼历史。若最后只有图像特征有用，结果支持图像条件预测；同楼增量仍应如实报告未发现。未知目标保留并报告覆盖，不能只评价少数已确定人数的成功图后声称整体可用。

## 5. 新增人员应承担哪些验证职责

用户已明确还会补充人员。以下是建议的数据结构，不是已经定下的派发表、样本量或人员比例。

| 数据部分 | 谁标哪些图 | 回答的问题 |
|---|---|---|
| 历史探索 | 已有人员、已有图片 | 定义候选测量、识别现象、开发并留出检验方法 |
| 新人校准 | 新人在独立校准图上标注 | 用事先规定的规则测量新人连续表现或操作性档位；不使用目标评价图给人分类 |
| 桥接验证 | 新人标一部分旧图 | 相同图像的早／晚／多簇等历史现象，在新人中是否重现 |
| 楼内新图验证 | 同一批新人标同building的新图 | 旧源图对新目标是否有预测力；对照同批新人旧图，帮助区分换人与换图 |
| 可选新楼验证 | 新人标未用于方法开发的新楼图 | 更远的外推；不是当前必须同时做的第三套完整实验 |

**最值得保留的是“桥接旧图＋同楼新图”由同一批新人覆盖。** 如果只让新人标新图，结果变化同时包含人员变化和图片变化，不容易解释。桥接也不是完全消除混淆的因果设计：规则、工具、初始化等信息条件变化仍须记录。

可以把已有较早、较晚和未达标图作为有目的的诊断桥接。这能检验不同现象，但不能据此估计自然图片中各类型的真实比例。新目标不能按已经看到的收敛结果筛选。

“按人采集一次”是指一次组织独立响应，再后处理复用；每个人仍可标多张图，各组合仍需在相同图上有足够不同人员。AABC需要两位不同A人员，不能复制一个人的结果。新增总人数足够，也不自动保证每个细类都能形成长曲线。

### 防止把验证变成再次拟合

1. 在看新目标结果前，明确分类规则、稳定定义、比较方案和缺失处理。历史分档可以用于制定规则；新人的类型须从独立校准资料得到，不按目标结果重新切出漂亮分组。
2. 若旧图用于历史现象的新人员复现，可以用其历史曲线作比较；若声称严格预测未见目标图，则不能把该目标自己的历史曲线用作输入。两种问题分别报告。
3. 若先用新人桥接结果调整模型，再预测新图，须将调整过程预先规定并计入预算；另列“只用历史资料”的基线，不能把适配后的表现冒称零新人信息预测。
4. 验证时不能只收集到预测停止点便宣布成功。若候选k=x，至少还要有判据要求的后续观察窗口，才能检查其后是否持续稳定；当前20人的旧建议不能替代这个支持条件。9名新人无法独立验证20人曲线。
5. 对照采用共同图、共同人数和相同验证支持，预先规定任务顺序与人员组成处理。大量排列、重叠组合不增加独立人员或building数量。
6. 不为保证出现平台调q、修改点集、删掉困难目标或改变人员类别。若在预算内未稳定或不能评价，分别报告；这些也是研究结果。
