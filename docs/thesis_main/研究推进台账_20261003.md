# 两条研究线：已完成分析与逐步推进

更新：2026-10-03。规范真源：[当前方法合同](PAPER_A_METHOD_CONTRACT_CURRENT.json)，版本 `consensus_research_20260923_v1`。本台账不新增资格、人员类型或难度阈值。

## 论文主线

共同基础：可靠的几何表示与质量测量、固定融合算法。

- **A线：难度与人数曲线。** 已有粗难度及场景分类下，人数增加后的参考一致性、融合稳定性是否不同？
- **B线：人员分类与组合不确定性。** 同人数下改变类型比例；同人数同类型比例下更换具体成员，结果与波动怎样变化？
- **后续联系：** 困难图片是否更依赖人员构成，组合效果是否随图片条件变化？

“不同类型一定增加不确定性”“困难图一定更慢收敛”均为待检验假设。先共同图片、同图比较和跨图观察；人员/图片交叉效应模型仅在分配不均衡妨碍比较时评估，**不作为研究主线或前置步骤**。分簇、局部路径、合理空间候选及同房预测不阻塞两条线。

## 二、本轮完成的一步：把参考均值算到明确精度

新结果另存，不覆盖原16排列。N≤9全枚举，大组只在k=1、2、N−2、N−1、N枚举，其余使用计算前确定的16384个独立均匀排列。同一组的两种规则和参考共用排列；MC按出现频次汇总，旧去重均值保持历史原样。完整排列和人员序号映射保存，可复算。

全员tile只用于离线积分细分；子集票只读子集成员，目标GT只评价。代表性子集用原函数重新切tile对照；不改变线上/当前前缀算法的信息边界。均值误差界控制的是所有326个MC参考均值的计算抽样，不是人群CI；0.02是本轮计算分辨率，不是实际重要差异或人数停止阈值。

当前仅可说某些图的固定参考均值上升或下降，不能直接归因图片难度、人员类型或视觉对错。MV50奇→偶只能扩张、偶→奇只能收缩，IoU方向仍依赖增删位置。遗漏/外扩解释差异方向，不叠加成独立评分。
