## 研究目标与三个问题

2026-10-05执行更新：Pro已返回，独立审查与[两处本地修复](../../analysis_results/layout_reliability_fixed_20261005/REPORT.md)完成，原数值几何结论未被推翻。用户再次明确的空间候选目标已单列为[局部删改计划](空间候选构造_局部删改试验_20261005.md)，并已有五份真环51个操作候选的首轮结果。下表RQ2／RQ3及历史S3／S4保留，当前先补局部图像证据、对应锚点和有限相容重组；不把三RQ的顺序理解为禁止这一独立探索。该安排不修改正式合同。

总问题：在多人全景布局标注中，如何形成可追溯的空间共识，人数和成员差异怎样影响它的参考质量与稳定性？场景粗难度保留为解释维度，人员类型不要求先证明为永久天然类别。

| 问题 | 要回答的内容 | 证据职责 |
|---|---|---|
| RQ1 完整共识与测量 | 投票证据怎样转成上下配对边界及连接；表示和压缩保留或改变什么 | 当前优先。几何推导、源环核对、反例和真实小面板 |
| RQ2 人数过程 | 增人是否更接近参考，是否减少同人数换成员差异，相邻增人变化多大 | 基础达到可解释、可复算后，复用136图结果，分别报告三个终点 |
| RQ3 人员和场景解释 | 同图同人数下画像、构成、具体成员能解释多少差异；粗难度关系是否可分离 | 目标建筑外校准、相同池容量随机对照、实际共同覆盖 |

研究链条是“明确共识对象和评价 → 观察人数过程 → 检验成员和场景解释”。连接、坐标、指标不各自扩成一条平行论文主线。同房预测、模型难度预测、全面Q/T/S/B搜索、一般复杂拓扑和真实体积恢复后置，保留历史证据。

## 当前证据与需要修正的表述

1. 最新精确弧原型在规定条件下，使用全部选中人员构造可序列化上下配对边界。节点可能是曲线交点或同步分点，不自动是物理墙角。它目前只有两张完整人员池实算和明确域外控制，尚无全库成功率或视觉效度证明。
2. ERP的t票下边界对应BEV的n−t+1票边界。满足域条件时，Lee≥50%兼容精确底面应与原Lee相同。此比较验证等价性，不以BEV IoU证明新算法胜过Lee。顶部、来源、局部事件与编辑表示才是新增对象；压缩后的变化单独报告。
3. 适用域不止“单值”：当前原型要求连续坐标、共享经度、上下严格跨地平线、非零且小于半周的逐边经度跨度、合法声明BEV及同向一周。方法不适用不等于人员错误。rPc-06确认环不能为适配而重排。
4. 正量、共同地面、同方位、同名单、同秩条件下，精确融合高度处于人员最小—最大范围内，并保留共同恒定平顶。压缩不自动保持该性质。dot斜顶反例的一个方位已被本地独立复算；两张真实例未越界不能推广。
5. 弧长均值的分母可因新增振荡变大，均值下降不能独立证明整体改善。保留双向分项；单值域可研究固定经度测度的上下误差与事件极值。增加这些诊断不意味着已得到最终质量总分。
6. 参考接近、同人数换成员稳定、相邻增人变化是不同终点。固定池全部用完时成员波动为零是机械事实；组合数不是独立样本量。8→20人的约0.0038平均IoU增益不等于8人足够。
7. 当前难度标签已修复，旧分组摘要不能当最新结论。先用保存的逐图结果重新汇总，不能因为标签变化重跑全部投票。没有明确三档不等于没有审核。
8. 约11%的既有画像收益是相对分数预测SSE下降，非融合IoU收益；收益集中，不能写成多数人员画像可靠。高Q提高平均参考表现不保证更稳定，高Q普遍更不稳定也未成立。

本地上一轮实际做了：当前统一输入与外部包29份标注、2份原GT的381项关键字段核对，未发现差异；3人和24人名单匹配；少量内存阈值／整池失败控制，以及斜顶一个见证方位。外部32测试、29份完整重放仍是外部证据，本地没有重新全跑。窄峰0.13707°是单向均值，双向约0.06854°；原型质心实现只有距离标量，不能声称已输出方向向量。

## 创新定位与相关原文

这是初步定位，不是首创认证。以下文献用于界定已有内容，不要求为了增加基线立即接入其全部模型。

| 来源 | 已有内容及本项目关系 |
|---|---|
| [Lee等 2018](https://ceur-ws.org/Vol-2173/paper10.pdf) | 已有tile区域投票。当前借用等权区域聚合，保留全员；BEV到完整配对表示是本项目具体扩展 |
| [HorizonNet 2019](https://openaccess.thecvf.com/content_CVPR_2019/html/Sun_HorizonNet_Learning_Room_Layout_With_1D_Representation_and_Pano_Stretch_CVPR_2019_paper.html) | 已有上下逐列边界与角点存在性分开表示；不能将逐列表示本身称新方法 |
| [Chan 2003](https://tmc.web.engr.illinois.edu/ii_focs.pdf) | 曲线排列第k层是经典问题；交点之间取分位属于这一结构 |
| [Bi-Layout 2024](https://arxiv.org/html/2404.09993v1) | 已研究enclosed／extended范围歧义；其多候选对GT取优评价不能用作本项目单主共识的生成规则 |
| [Welinder等 2010](https://proceedings.neurips.cc/paper_files/paper/2010/hash/0f9cafd014db7a619ddb4276af0d692c-Abstract.html) | 已有多维人员能力、偏好与任务差异研究；仅分类人员不构成创新 |
| [Reinke等 2024](https://www.nature.com/articles/s41592-023-02150-0) | 指标与任务目标不匹配、离散化等局限已有系统研究；本项目需证明空间任务中的实际后果 |

本地独立观察：对z(θ)=a sinθ+b cosθ，在cosθ不变号区间除以cosθ并令x=tanθ，可转成直线a x+b的排序；负号区间反序。因此解析分位弧有用，但不宜单独宣传为全新共识理论。

最有希望的贡献组合为：第一，条件明确、来源可追溯的区域到上下配对边界构造及近似损失说明；第二，在真实多人全景标注中量化人数对参考质量、成员敏感性和增人变化的不同影响；第三，检验画像／构成／具体成员及场景条件的解释力。第三项允许阴性结果。工程可复算与数据整理支撑这些贡献，不能替代它们。

## 下一轮Pro的具体研究任务

### 全员精确表示与压缩

先核对四图完整名单，不把rPc-06旧两人失败例当成24人完整实验。源环、坐标和人员票保留；确认复杂环不重排。对普通适用例，区分Lee兼容等价性与真正的新增顶部／来源信息；对不适用例保留整个名单和原因。

对精确与压缩输出，研究上下连续最大偏差、BEV变化、派生高度和整列包含关系。像素误差预算不直接是人类容差；包含人数变化不是错误率。沿用原包预算可作可比起点，但允许Pro提出更合理的表示或压缩方案，须说明所保留性质、代价及反例；不预先要求实现复杂优化器。

“解析构造”与“浮点连续误差证书”分别说明。近重合、接缝、窄事件及近地平线控制按实际疑点选择，不重复已有大扫描。精确结果是原始证据层，近似编辑结果独立；来源不能把上、下边局部供者相加成整墙共同认可。

### 指标反例的实际影响

从四图的实际标注和候选中比较分项指标，定位发生分歧的具体区间。对单值域可加入固定经度测度的上下误差积分与事件极值；不要退回只检查固定512列。复杂环继续用声明边和BEV等适用对象，不强套单值指标。

关键问题是：已知反例揭示的局限，在这些真实案例中是否足以改变方法或压缩判断？允许“未观察到实质影响”，不为了产生亮点制造新排名。GT只在候选、参数政策和输出保存后评价；原始GT为主、已有修订版本若可得则同图另报，不挑更有利版本。

### 创新判断和后续实验选择

用原论文区分经典性质、任务适配、可主张方法贡献和仍缺证据的实证主张。允许质疑本方案、Pro旧报告及dot解释，不以支持既定路线为目标。优先回答哪项新增研究最能改变当前判断；不把文献数量或重复测试当深度。

在完成必要方法研究后，提出恢复RQ2／RQ3的最小实验设计：估计目标、比较集合、单位、终点、失败处理和所需资料。下一轮不同时扩大人数曲线、人员分类、同房和模型难度搜索；如发现必须改变顺序的实质理由，提供依据和替代顺序。
