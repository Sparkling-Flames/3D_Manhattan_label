# 全景 layout 研究方向

2026-10-03用户澄清优先于下方10/2顺序：共同基础为可靠表示/质量和固定融合；A线研究“粗难度与人数曲线”，B线研究“人员类型、比例与具体成员的不确定性”。两线先分别推进，最后联系。人员/图片交叉效应模型是可选调整，不是主线创新或必须先完成的步骤。详见[已完成分析与推进台账](研究推进台账_20261003.md)。

2026-10-02 更新，承接用户最新要求：逐步推进，先固定表示与等权 tile 投票，观察人数变化，再分别增加质量维度、人员类型和粗难度解释。规范真源为 [PAPER_A_METHOD_CONTRACT_CURRENT.json](PAPER_A_METHOD_CONTRACT_CURRENT.json)，版本 `consensus_research_20260923_v1`。历史实验不追改；当前探索不等于最终算法、权重或人员分类已验证。

## 1. 研究对象分开

| 方向 | 要回答的问题 | 解释边界 |
|---|---|---|
| 点位与细节分簇 | 角点位置、细节表达和邻接形成哪些相似模式？ | 簇不直接等于一种合理空间；范围变化也可能影响点位 |
| 空间差异 | 标注形成的区域、位置、形状和墙面相差多少？ | 差异大小不自动说明原因或人员对错 |
| 工人融合共识 | 综合实际作答得到什么，随人数和构成怎样变化？ | 多数、稳定、接近GT是不同概念 |
| 合理空间候选 | 多人的局部观测能组成哪些几何可信的完整layout？ | 几何自洽不等于视觉正确，也不要求整房多数支持 |
| 人员质量与分类 | 调整图片条件后，哪些跨图表现差异可重复？ | 单图误差、速度或一次排除不直接等于能力 |
| 图片难度 | 图片和模型特征能否解释或预测标注困难？ | 点多、模型失败、远离GT不单独定义难度 |

范围差异、细节差异和定位偏差可同时存在；不同研究用途不强制共用一种距离或等价关系。

## 2. 先固定连线与表示

在理想中心投影下，不穿过相机中心的三维直线投到球面为大圆弧，ERP中通常为曲线。同端点、同弧分支、同坐标约定下，正确球面连线与三维直线重投影应一致。先核对实际skybox/ERP映射、相机调平、像素约定，再核对邻接、接缝、遮挡和填充；不按哪种曲线更接近GT选表示。

旧墙带函数按x重新排序，因此可能忽略输入环序；这是表示的性质，不是IoU的性质。已有新旧比较还改变了像素约定，必须控制变量。区分可见ERP墙带、完整BEV足迹和封闭三维空间；隐藏结构不同而投影相同，不应靠修改曲线强行区分。

非星形空间、相机在区域外、近地平线和非水平顶面分别说明适用条件。不可计算不自动归为人员错误，不静默补点、排序或规整。

## 3. 空间差异采用互补指标，不先合成总分

| 候选指标 | 含义 | 局限 |
|---|---|---|
| ERP墙带IoU | 图像投影覆盖重合 | 受连线、投影与遮挡影响 |
| BEV IoU | 平面区域重合：面积交集/面积并集 | 小细节会被整体面积稀释 |
| BEV面积质心差 | 区域分布中心的位移 | 对称变化可完全不移动质心 |
| 三维体积IoU | 有效封闭体积的重合 | 依赖尺度和高度模型；棱柱代理不冒充精确体积 |
| 墙面/边界差异 | 哪段墙移动、增加或缺失 | 需说明对应、采样、未匹配及局部尾部偏差 |

初步研究向量为 **[BEV IoU，BEV面积质心位移，墙面/边界差异]**，有效体积可得时增加3D IoU，ERP IoU作投影对照。该选择是待检验方案，不是已验证评分。

面积质心为区域内坐标的面积平均，不是角点均值；同一边增加采样点不应改变它。ERP质心依赖接缝，圆周质心低集中度时不稳定，均作为辅助。比较共享相机坐标、朝向和尺度，不分别对齐消除待测差异；缺绝对尺度时用共同相机高度单位，不称米。Jaccard与IoU仅在对象及测度相同时等价。

**两个空间的差异D(A,B)与单个结构的残差R(A)分开。** 同中心、同高度的4×4和8×4矩形，BEV IoU为0.5、质心差为0，方向残差均可为0。方向残差不能替代空间差异；这些全局量也不能自动区分范围选择、细节增减与定位误差。

## 4. 三个算法方向独立验证

### 点位与细节分簇

研究定位抖动、两对/三对近邻结构、凸起、共线插点及同点不同邻接。点数相同不保证对应；匹配处理循环起点、反向、周期接缝，并报告未匹配及覆盖，不能最近点多对一吞掉结构差别。先验证距离连续性与输入置换稳定性，再比较聚类，不预定点数不同必分或必合。

几何等价与标注表达等价分开：同区域可有不同细节表达。近180°点可能是冗余采样或另一停止区域节点，保留原始身份、邻接及来源，不按共线自动删除。

### 工人融合共识

Lee框架是叠加分割得到tile，再用MV、EM、greedy等选择区域；MV是聚合规则，不是聚合后额外增加的步骤。同投票域、阈值和栅格下，tile与逐像素MV表达相同多数选择。

保留全体等权MV（>=50%），以>50%检验平票影响；最大簇聚合只作对照，不默认丢弃少数。共同漏标、偏简单、稳定偏离GT均可成为结果，不能为接近GT补票。现有EM/greedy适配不称原论文完整复现。

区域mask不自动成为合法角点环。原始融合与配对/闭合/几何恢复后的结果分别保存。绑定点对、拆开top/bottom及混合融合是layout扩展；局部两对/三对可作备选整体路径，分别统计结构存在、路径类型与坐标融合。仅bottom获支持不自动给top补票；上下差距过大不强配，接缝处使用周期x平均。

每人每处至多贡献一份相应证据，点多不增票。整模式人数、候选兼容人数、局部票和算法软场分别报告，局部票不相加为整房票。

### 几何合理候选：减法与局部重组

目标是有观测依据的几何合理空间，独立于工人共识。Manhattan适用时，方向、墙高、上下对应、闭合和自交是核心约束；人数另报。比较三层：原完整作答筛选、原候选最小删改、多来源相容局部结构重组。

可研究约束形式：

`F = {L：环与邻接合法，R_geo(L)≤τ，D_obs(L)≤ε}`。

在可行集合内比较删改成本、细节保留及观测覆盖，保留不同候选。D_obs针对相容局部观测，不能强求互斥停止边界同时成立；未解释观测、删点与移动分别记录，不能只挑易拟合观测压低误差。阈值和成本尚未确定。

全体点并集是带来源、邻接和互斥关系的候选结构，不是一条默认正确的环。删除凹角可能扩大空间；同一完整候选集合下加/减法只是搜索路径不同，有限搜索的细节保留优势须实测。退火或启发式不是独立创新依据。

残差相对共同Manhattan主轴计算；拟合后零残差须同时报告拟合前偏差和移动量。短边方向不确定性在小误差条件下大致随位置误差/边长增大，不用统一角阈值淘汰细节；墙高稳健离散度同时报告离群值。OOS/门洞和非正交适用边界另定。

算法有效性须另看细节保留、错误新增结构、观测改动及留出证据，不能用优化残差后的残差下降自证。是否具创新性仍待文献与实验检验。

## 5. 人员质量、分类与图片难度

GT差距是参考一致性；几何残差是自洽性；对应点/边界误差是条件定位指标。不能把其中一个直接当人员总体质量，也不能剔除全部未对应部分制造高质量。RMSE需有效对应，点数相同不充分。

人员研究复用质量、active time、规则、Semi的历史单项及组合，加入明确审核排除数量、比例和原因。区分复核排除、历史未纳入、图片限制与方法失败；报告作答/审核覆盖和场景分母，定向审核比例不称总体错误率，缺失不填零，active time不与lead_time混用。先连续画像，再检验分类的稳定性和增量价值。

调整图片条件、按房间/建筑留出；目标数据不参与其人员分类或权重校准。无同人同图重复作答时，交互和随机点击波动不能完全识别，不宣称彻底分离数据与人员噪声。

难度候选包括不同模型点数及差异、自交/邻接敏感性、BiLayout enclosed/extended差异、冻结d_model_feat。d_model_feat是参考特征库距离，不是难度真值；BiLayout两输出不是独立模型票；强制正交后零残差不证明简单。预标注可得特征与事后人工改序、GT误差分开。

2026-10-02 用户澄清：只需要粗略对应，不建立精细综合难度模型。保留原图片空间分类、人工难度预期，之后分别检查 d_model_feat 大小、BiLayout enclosed/extended 差异与曲线的联系。门洞交界既很难标，也可能存在局部无法按规则合理标注；OOS 的 GT 未必正确或适用。两者作为困难场景解释，同时保留适用性和参考状态，不能由低 GT-IoU 直接判人员差，也不一概宣布所有 OOS 的 GT 错误。沿用既有审核，不新增全量 GT 重审。

旧106张人工难度预期（49简单、41中等、16困难）核对覆盖后作对照，不当真值。稳定多簇仍可稳定；OOS/门洞单列，不预设不收敛。不通过调簇、阈值或删图使“简单快、困难慢”成立。

## 6. 执行顺序与验证关口

| 顺序 | 工作 | 必须先明确 |
|---|---|---|
| 1（当前） | 固定 BEV 表示，真正切 tile，以等权 MV≥50% 重放人数；>50%只查平票 | 沿用预处理、确认环/默认x和现有资格；只用当前k人切分；原始/修订参考单列 |
| 2 | 检查曲线与覆盖，扩大图片；再单独补充边界、质心、上下轮廓及三维分项 | 不一次混入全部指标，不先合成总分；区分参考距离与几何自洽 |
| A线 | 基础曲线补强后，连接已有图片分类与粗难度，再分别看d_model_feat和BiLayout | 不等待人员分类；共同人数范围，参考适用性与难度分开 |
| B线1 | 可靠参考范围内、共同图片上的人员表现，再判断分类是否稳定 | 同图比较、跨图观察、建筑留出；效应模型按需，目标图不用于给参与者分类 |
| B线2 | 同人数比较类型比例，同类型比例更换具体成员，再比较人数 | 不复制真人；成员差异、GT距离、增人变化分别报告 |
| 两线联系 | 比较不同难度下人员构成作用是否不同 | 两线基础结果足够后开展，不先建包揽全部变量的模型 |

分簇、局部路径和几何合理候选是独立探索；同房预测后置。它们不构成当前 tile 与人员研究的前置关口。

## 7. 输入与不变边界

GT明显错误沿既有审核，不重新研究GT谁对谁错；原始/人工修订版本分别报告，不挑近的版本。GT细节省略仅部分复核，未标记不是阴性，自动发现为次次要研究。范围、细节、OOS及门洞标记不从缺失推为否定；无原图的Pro不裁定视觉合理性。
