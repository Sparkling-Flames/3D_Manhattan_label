## 1. 整体研究原意

研究对象是曼哈顿全景 layout 标注中的不确定性：人员表现、图片及其空间解释、人员与图片的交互，以及测量和融合方法自身造成的差异。不能把整个研究缩减成一种融合算法，也不能只保留人数曲线而丢掉衡量方法的问题。

用户原本提出：**用 GT 作为参考，通过指标和算法衡量工人标注质量，再研究人员差异、人员组合、人数与图片难度之间的关系。** 用户希望独立研究人员不确定性时减少图片因素的干扰，反过来也一样。这是研究目标，目前没有完成严格的人员／图片噪声分解；GT 偏差也不能直接等同于人员固有能力。

连线、曲线、质量评价、共识和空间候选算法都有实际职责：帮助在可比较的对象上衡量差异，并分清定位偏差、细节差异、范围差异与错误。它们本身值得研究，但不等于所有人员分析都必须等待通用融合算法完成。

减法的核心意图是：**从已有观测中寻找合理的不同空间范围、不同细节的布局候选**。从并集删点只是构造方式之一，不能窄化为“点越少、残差越低越好”，也不能用全员多数共识代替这项研究。合理范围差异可能也是人员与图片交互的信号，不能为了“去噪”全部清除；同样不能把所有差异都解释成合理多解。

## 7. 表示、连线和质量衡量

依据：[布局地基](布局表示地基与坐标核验_20260930.md)、[指标回应](../../analysis_results/layout_metric_response_20261001/REPORT.md)、[三维质量探查](../../analysis_results/layout_3d_quality_probe_20261002/REPORT.md)、[可靠性审查](../../analysis_results/layout_reliability_review_20261005/REPORT.md)、[本地修复](../../analysis_results/layout_reliability_fixed_20261005/REPORT.md)。

- 声明 BEV 足迹、按方向取最近正向交点的首交墙带、单值 ERP 上下带不能在复杂环中互换。BEV IoU 衡量声明范围；质心是面积质心，不是顶点均值或图像中心。
- 既定邻接下三维直边的球面／ERP 投影可核验，但同一投影不唯一决定深度、墙高，也不证明端点本来相邻。
- 固定列采样和 p95 可能漏掉窄局部事件；按弧长平均的边界距离可能被新增微小振荡的分母稀释。公式无误不意味着可单独排序质量。
- 派生高度同时受上下端影响；固定周界不能唯一确定内部顶面和真实体积。明确顶面模型下的 3D IoU 仍有用。
- 精确投票与有损编辑压缩分开保存。压缩满足像素预算也可能改变高度包络或来源支持，不能自动继承精确结果全部性质。

这些是衡量工具的实质进展，不代表已冻结统一质量总分、权重或误差归因规则。

## 8. 共识路线及当前实现

### Lee 区域投票

以完整选中人员池的区域成员关系投票；≥50% 与 >50% 分别说明，不能默换阈值或只用最大簇。结果有多边形边界及顶点，但顶点不自动是物理墙角，也不含完整上端信息。它适合声明范围比较和区域基线，不能独自替代可编辑上下角点 layout。

### 精确上下曲线与配对表示节点

在单值、共同地面／坐标及跨共同地平线等条件下，全员曲线投票可以转成可回投的上下配对表示节点；有两个真实完整人员池及合成控制的证据。偶数人员时 ERP 与 BEV 阈值存在对偶，不能把两种“50%”视作同一对象。新增节点可能只是曲线交点或上下同步分点，不是物理角点认证；复杂非单值环仍在适用域外。GT 结果没有证明此法全面更好。

### 用户的点身份／上下点对融合

用户希望比较“原始人员角点 → 跨人员身份簇 → 支持票数 → 融合中心 → 完整标注”，不要求先给整份作答分簇。已有绑定、上锚、下锚、拆分对照；原配对来源仍保留，不能把两端各自的票数称为联合配对票数。

历史八图使用 complete-linkage，距离为上下球面角距最大值，同一人员在身份内至多一票；中心是 BEV 坐标分别取中位数、另取高度中位数。当前点路线中心使用周期 x 中位数及 top_y／bottom_y 中位数，不能混称同一个中心算法。用户“最中心”未指定唯一数学定义。

当前新融合环的 x 排序是一种构造，未自动确认邻接；点身份、中心、连接与完整环支持是不同问题。不能为新算法方便重排已确认源环。见[方法溯源](点投票与区域投票_方法溯源_20261003.md)。
