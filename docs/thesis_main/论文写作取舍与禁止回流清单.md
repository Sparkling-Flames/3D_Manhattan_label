# 论文写作取舍与禁止回流清单

最后更新：2026-11-13。状态：持续维护。依据：作者在本线程的明确决定及随后确认的采用方案。

## 使用与更新规则

- 修改、润色、审稿接入和打包前先读本文件。它记录写作取舍，不是研究数据或算法合同。
- 最新明确决定覆盖较早安排。旧文件仍存在、审稿人重复建议、多个 AI 意见一致，均不构成作者重新授权。
- 表中“正文不展开”不等于删除实际方法事实；补充材料仍须准确，不能把有人参与的过程冒称完全自动。
- 允许提出新的、有证据的科学质疑；不得把本清单当作拒绝事实核查的理由。与既定取舍冲突时，说明具体主张、证据、缺口及最低修复，先讨论再改变方案。
- 更新时直接维护下表的当前结论，并在末尾记录日期、条目编号、作者新决定和被覆盖安排。不复制整份旧清单，不将废弃叙事重新堆入当前文档。
- 不新增未确认的审批、盲法、独立评估、仲裁、预注册或实验事实。

## B. 不接受的研究定位变化

| 编号 | 项目 | 当前写作方向 |
|---|---|---|
| B01 | 共识改成 Q 排行榜 | 研究多人观察如何进入结构、位置、上下边界和连接；参考 Q 全面领先不是贡献成立的唯一条件。 |
| B02 | Q 验证只剩相关性 | Q 是大致几何评分；构造案例与真实缺陷反馈为主，总体等级、相关性和方向一致率为补充。 |
| B03 | 同房只讲质量迁移不佳 | 重点为同人结构习惯、简化、短细节和具体转角，宏观统计与个例并用；保留质量预测负结果，但不让它取代主线。 |
| B04 | 画像本身取代分类换类研究 | 画像服务分类、同类/跨类替换、混合、具体成员与背景作用；不收窄为选高质量人员。 |
| B05 | 两项方法降格 | Q 与配对角点共识分别保留问题、定义和验证，作为独立贡献。 |
| B06 | 改成心理或拼接误差研究 | 不凭审稿要求更换研究目标，不编造心理因果解释。 |
| B07 | 广义已有共识否定创新 | 具体比较任务与机制，不能仅因他人也做聚合而撤回本研究贡献，也不声称数学不可替代。 |
| B08 | 专家与人数绝对定律 | 采用“此时继续增加人员可能收效有限，需要专家协助”；不声称任意数量普通人都不如专家。 |

当前贡献结构：两项方法、门洞交界定义、人数分布效应、成员构成与背景作用；四个 RQ 保留个体表达、人数、成员重组和跨视角的实证分量。参考复核承担研究基础与具体发现的职责。

## D. 必须先讨论，不能自动实施的任务

- D01：改变论文路线、RQ、主要贡献或验证目标。
- D02：新增心理问卷、界面 A/B、新人招募、线上部署或大型重跑。
- D03：新增角点身份核验、融合参数敏感性、取消人工纠正消融等研究。
- D04：把进一步加强的建议直接升级为投稿必做门槛。
- D05：为追求 AI 小修标签持续扩大基线、消融和程序报告。

这些任务并非被宣布永远无价值；需说明服务哪项实际主张及现有证据不足之处，经作者讨论决定。

## 交付前检查

1. 只按当前有效正文及补充判断，不把未使用文件当作已采用结论。
2. 清除交付中无关旧问卷流程、未使用 medoid 章节和过时结论；保留必要数据与实现，不靠追加免责注释代替清理。
3. 检查 Q 验证主次、分类与换类、人数、背景、同房、门洞、Semi 和劳动内容是否保留。
4. 不把 AI 判级或三人一致当作科学证明，也不将作者已否定的安排写成编辑遗漏。
5. 区分正文精简与真实程序遗漏；不能为简洁编造自动化、独立性或实验事实。
