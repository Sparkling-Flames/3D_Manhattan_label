# CSCW Fig. 2 作者要求与取舍

整理于 2026-11-21，供恢复绘图讨论时使用。导师发言单独保存在[第二轮审稿意见](导师审稿意见_第二轮.md)。

## 这张图要回答什么

Fig. 1 用壁炉说明个人标注如何改变房间几何，壁炉留在 Fig. 1。Fig. 2 是整项研究的总览。初读者应能追踪标注者在界面上作出的决定、工具给本人的反馈、提交以后研究者如何组织多人的作答，以及四个研究问题各自怎样得到回答。

## 必须让读者看懂的关系

- **两种起点。** Semi 打开时已有初始标注，标注者检查已有角点和墙线，可以保留或编辑。Manual 打开时只有全景照片，标注者从零选择转折并放置上下端点。即使遮住两个模式名称，画面本身也应足以区分。研究先开展 Semi，后在另一批全景上采集 Manual。
- **个人与工具。** 画面应把一次有意义的操作与工具的响应联系起来。例如，人在二维全景上放置点对，可以在自己的三维预览里检查对应墙角并回改。最终提交坐标能说明画出了什么；具体编辑过程只在有操作记录时作为个人事实陈述。
- **提交后的人的作用。** 标注者分别独立作答。研究者按问题选择哪些作答可比、如何组队、固定什么以及改变什么；程序据此计算。图中应能看见这些选择的实际含义。只有本人预览回到标注者，团队分析发生在提交之后。
- **两项方法。** 几何质量 Q 衡量个人或集体布局与指定参考的几何差异。配对角点结构共识从多人对同一墙角的上下点对中确定支持、保留结构并汇总位置。总览交代各自的输入和可见输出，详细公式、票数明细和验证由后续方法图承担。
- **四个比较。** RQ1 比较同图上不同人的表达，以及 Semi 中的给定布局与个人提交。RQ2 在同图、同一人员池内增加人数。RQ3 在固定规模下改变成员构成，分析具体换人与保留成员的作用。RQ4 在同一房间改变视角，观察个人选择和团队效应怎样延续。图上只需要足够识别各项设计的线索。

## 构图与交付

导师肯定原图的研究流程，允许大幅重构表现形式。三个大框、参考图的环形、左右双栏以及某个具体案例都不是既定版式。按审稿人的阅读顺序安排主次，箭头应有清楚的起点和去向。参考图可借鉴的地方是人物、界面、操作和结果彼此对应。可用适量小人和短文字辅助理解，控制总信息量，使读者在正式栏宽下仍能一眼抓住主线。

交付可分组编辑的源文件。全景照片可替换，点对、墙线、人物、箭头、文字、方法示意和 RQ 元素可分别选择和调整。总图注及需要的子图标题用 LaTeX 放在下方。可用换一张底图、移动一个端点、修改一条文字来检验可编辑性。候选供讨论，由作者决定是否接入正文。
