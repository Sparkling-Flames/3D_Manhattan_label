# CSCW Figure 2 独立设计任务

请阅读随附的 CSCW 正文、导师第二轮反馈及参考图，直接交付一版新的英文 Figure 2 候选。对象是首次接触本研究的 CSCW 审稿人。请让他仅凭图就能讲出：一个人如何把全景上的判断变成三维布局；自己的作答提交后，哪些人的观察共同决定一段墙是否出现；研究者怎样比较这些作答。自行决定构图，与另一位设计者独立完成。

## 先核对研究事实

1. 人的工作分两种。研究先开展 Semi。参与者看到给定布局，可以保留或编辑；部分起点错误留在提交里。随后在另一批全景上开展 Manual。每个人从空白布局开始，在自己识别出的墙角点击上、下端点。工具把这份个人作答渲染成三维布局，人可以查看预览并修改端点。两种模式不可画成同一张图先后必经的两个操作。
2. 以一个能辨认的局部串起二维和三维。例如图 1 中，一人跨过壁炉画直墙，另一人沿壁炉两侧画出转折。可以裁用其中一处，让同一个位置在全景、轮廓和三维房间里保持对应。界面素材见所附截图；具体标注与重建结果以论文原图为准。不要把示意性的房间环境当成某位参与者的原始界面记录。
3. 每个人独立提交。研究者在提交后离线把同一张全景的多人原答组成团队。人能看到的是自己的三维预览。团队输出在后台产生。区分这两个三维布局，避免出现多人在线同绘、系统实时向个人推荐团队答案或专家接力精修的箭头。
4. 两项方法承担不同任务。Q 将个人或集体布局与该空间的指定参考比较，可以用一处边界偏移或高度差表达“测量哪里”。配对角点结构共识将多人对同一墙角的观察对应起来，按不同人员的支持保留转角，并分别汇总上下端点的位置。画出“谁标了同一处 → 共享布局的这段墙”；Q 不参与选角点。使用原例中的几何、人员和计数，不要把不同图中的作答拼成一次真实团队实验。
5. 四个 RQ 用比较动作呈现。RQ1：同图比较个人作答，Semi 还可比较初始布局与提交。RQ2：固定同图人员池，增加人数。RQ3：比较成员配比，并在匹配换人时固定其余成员。RQ4：同房间换视角，观察同一人的结构选择和相同成员替换的结果怎样变化。让读者看清什么保持相同、什么发生变化；无需堆样本数、公式或结果表。

## 图面和交付

人手上的任务和屏幕的响应应占最清楚的位置。请把 supplied layout 具体画出来，并让读者能用眼睛追到一次操作产生的空间变化。选择清楚的主阅读方向；个人预览后返回修改可用局部回箭头。后台两个方法可并列，四个比较可用简短英文动词配小示意。导师参考图仅展示怎样把一次交互讲清楚，其角色、反馈机制和版式都不属于本研究。

本轮不使用 Image-2-PPT 或 AutoFigure。请直接用可编辑 SVG、TikZ 或原生可编辑 PPTX 设计；轮廓、箭头、文字可分别修改。真实全景和现有模型使用原素材。以 CSCW 稿的实际栏宽检查可读性；总图注与编号子图标题在 LaTeX 图面下方排版。交付可编辑源文件、矢量 PDF、英文图注、英文无障碍图像描述，以及一份简短的素材出处清单。请提交独立候选文件，不覆盖论文正式图。

交付前遮住图注自查：读者能否指认给定布局、人的一次操作和个人三维预览？能否指出多人数据何时第一次相遇？能否分别指出 Q 的参照对象和共识方法保留下来的几何？能否看出加人、换人和换视角是三种不同的比较？
