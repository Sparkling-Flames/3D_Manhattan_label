# Sonnet 三评独立复核：IJHCS 适配与最终修改方案

日期：2026-11-09。对象：当前 37 页 `main.pdf`、LaTeX 正文、有关补充材料及本轮三份审稿。本文是修改方案，尚未改动正式稿。

## 审查决定（Decision）

**修改（Modify）：保留 IJHCS 为合理投稿目标，保留现有研究路线、两项方法和四条主要贡献；修改证据组织、比较目的、章节衔接与少数图文。**

被审查的方案是“依据三份审稿，把论文改为新增交互系统评价、扩大基线与统计实验、收缩现有研究”的整体建议。它不能原样采用。三份报告提供了有用的读者反馈，也混入了事实误读、不同研究问题之间的替换和未经证实的要求。“三位都判大修”不是三个独立实验，也不是期刊编辑决定。

### 有效性

现有研究能够回答：在具体全景标注任务中，图片条件和人员表达如何经计算汇总形成不同布局。评审将交互贡献限定为新界面及其用户试验，与期刊公开范围不符；将 medoid 说成没有顶部、将 Q 概括成没有标准指标比较，也与现稿不符。有效修改应让现有贡献容易被看见，并修正真正的叙述混淆。

### 简洁性

最小完整方案是重新安排已有证据和解释职责，复用已完成的统计诊断，做局部图文调整。新增心理问卷、留出全新人、加入模型作投票者、把所有失败赋零、给全部数字做统一校正，都不是当前问题的默认解决办法。

### 后果

照单采纳会把“人如何标、怎样形成群体布局”改成“一个新工具是否优于旧工具”，并使两项方法退成普通分析工具。相反，只批评审稿而不改善呈现，也会继续让读者错过验证与条件结论。因此本方案保留发现的力度，同时把比较对象、证据层次和用途放到读者需要的位置。

## 1. 到底适不适合投 IJHCS？

**适合继续投，适合的身份是人工空间标注的实证与计算研究。无需为获得投稿资格，临时改成心理机制或界面可用性研究。**

Elsevier 的官方范围包括交互技术的设计与使用，并列出用户行为实证研究、计算交互、HCI 评价方法、社会计算等方向。它没有规定每篇都必须开发新界面或开展界面 A/B 实验。[IJHCS 官方范围](https://shop.elsevier.com/journals/international-journal-of-human-computer-studies/1071-5819)

已核对的发表先例提供更具体的参照：

| 文献 | 实际研究 | 对本文定位的意义 |
|---|---|---|

(2017), *Incentivizing social media users for mobile crowdsourcing*, IJHCS 102:4–13 | 用 Barcelona 的真实 Flickr 活动轨迹评价人员匹配与预算分配方法 | 离线人员记录和计算组织研究可以属于该刊；其任务匹配与激励问题比本文集中，且属于专题，不能据此保证本稿录用。[出版页](https://www.sciencedirect.com/science/article/abs/pii/S1071581916301203)、[作者全文](https://social-dynamics.net/docs/crowdsourcing.pdf) |

本文已有与期刊相接的实际内容：从头绘制与初始化编辑、Scope/Difficulty 反馈、同人不同图的表达、同房结构习惯、局部观察的计算汇总、人员重组与记录劳动。这些内容研究人在计算工具中完成复杂任务的行为及结果。

**真正的投稿风险是这些内容被过长的方法铺垫和分散的结果遮住，而不是缺少一个叫作“交互系统评价”的章节。** 如果作者要另行宣称新界面提高了效率或在线工作流优于现行流程，才需要对应的前瞻评价。当前可以明确提出设计依据与待实施的用途。

本判断依据公开范围和具体发表先例，属于投稿适配判断，不是录用概率预测。本轮未取得可完整读取的最新投稿指南，因此不把期刊格式、声明或伦理手续说成已全部验收。

## 2. 三份审稿哪些成立，哪些不成立？

阅读依据包括当前 `sections/03_study_context_and_design.tex`、`04_methods.tex`、`06_group_size.tex`、`07_composition.tex`、`08_viewpoint_scope.tex`、`09_implications.tex`、`10_discussion.tex` 及 Supplement C。统筹线程另行核查了 medoid 实现和研究证据。

| 审稿判断 | 独立判断 | 正文应怎样处理 |
|---|---|---|
| 没有新交互系统，所以不适合 IJHCS | **绝对判断不成立。** 官方范围和发表先例均不支持这个门槛 | 用现有标注行为与计算汇总结果建立 HCI 贡献，不添加未经研究的注意力、信任或锚定解释 |
| medoid 与 BEV 都不能提供顶部或完整布局 | **事实错误。** medoid 按底面相似度选人，保留该人的上下端点与完整环；BEV 是底面区域输出 | 明确“选择依据”与“输出内容”。顶部研究解释底面选择留下了什么人员差异，不称 medoid 没有顶部 |
| Q 没有标准指标对比 | **汇总说法错误。** 原始第三评实际上承认与均高棱柱 IoU 比较，只是要求更多增量比较 | 保留同批人评 Q/IoU 相关 0.945/0.739、同图方向 104/109 与 84/109、全九人敏感性、构造案例及深度/角点例证。不能据此泛称 Q 全面优于所有指标 |
| Q 人评用于调参，验证循环 | **现有材料不支持该指控。** 正文已说明参数固定后验证，问卷没有改动公式或参数 | 将开发选型、已知几何响应、真实标注评价分工集中说明。开发例若用于展示响应，仍可有效；只有宣称独立留出检验时才需要独立样本身份 |
| 保留多数支持只是执行了自己的规则 | **部分成立。** 保留率能说明支持如何进入输出，不能独立证明物理角点对应全部正确 | 区分对应、支持保留、连接和参考几何；结合真实案例、顶部观测、完整输出率解释新增能力。共识比较继续围绕群体观察表达，不转为 Q 排名 |
| 类别与结果同源，必须留出新人 | **混合了两个问题。** 结构类别的特征差异部分属于定义；目标楼外拟合后在目标图的质量、换人和混合结果不是同义反复。留新人改变了“已有人员历史”的用途 | 明确类别从历史行为获得，主要结论来自目标图及团队重组。候选类别的探索性选型与 LOBO 的目标楼留出分别说明，不把类别称为独立随机处理 |
| 独立样本只有 22，所以全部统计均不可靠 | **过度概括。** 建筑外推、固定图内团队分布和随机排列计算误差是不同目标量 | 在方法集中交代估计对象；主要结论引用已有楼级区间与路径诊断，不把数万团队当数万人 |
| 有限池自动导致后期 P10 提高 | **不成立。** 满员时成员集合唯一，组间波动消失；P10 和 Q 的方向并不因此必然提高 | 前置 C10 的容量分层与删满池结果；保留当前人员池内的结论，不宣称新人员总体已收敛 |
| 缺完整输出应该记 Q=0 或统一 IPW | **不采用。** 缺几何与有效几何零重叠不同；IPW 也需要目标量和缺失机制假设 | 并列报告可评 Q 与所有尝试的完整且可评率，使用已有共同可评路径配对结果。若另研究失败成本，应另定义决策效用 |
| 所有结果必须统一多重比较校正 | **部分成立。** 对正式显著性主张应明确比较族；描述均值、方向支持数与机制案例不等于数十个独立拒绝检验 | 审核实际显著性语句，必要时按已定义比较族处理。不能事后把探索研究改称预注册，也不以统一校正替代效应与条件解释 |
| 同房个人习惯整体很弱，可删 RQ4 | **不成立。** 全域状态一致率受“都无细节可省略”影响；短边机会、同源他人对照、局部对应与定位反例回答不同问题 | 保留“结构机会使习惯更明显”；不得用同用途或 Q 残差弱相关反证结构习惯 |
| 门洞筛查提升来自更换参考 | **混淆两组实验。** 固定 17 图筛前筛后使用共同 whole-space 参考；单图分空间另用各自人员和参考 | 在图中直接标清两行的比较对象，保留盲筛点数不足/不可解释原答及已选案例 |
| Discussion 首次给出劳动结果、RQ4 包办门洞/OOS | **组织问题值得修。** 不是数据无效，也不要求扩充 RQ4 | 劳动可留 Discussion，但标题和导航须明确它含离线组织策略分析；跨视角回答 RQ4，门洞/OOS解释任务与表示条件 |
| 全文没有同意说明、没有局限性 | **前者不符现稿；后者把没有专节当成没有内容。** 当前已有招募、记录时间告知、研究使用同意、报酬，边界分散在各节 | 保留简短事实说明，必要时汇总适用范围。正式审批或豁免不填未知事实，数据代码声明按实际共享安排补 |
| 图 12 重叠、度数丢失 | **本轮评审三未看图，主持人已判为抽取误报** | 不据此改数据或重画 |
| 三条参考文献未引用 | **成立。** 本轮再次比对引用键确认 | 删除无实际用途的条目，或在确实需要的论述处引用；不能为保留列表而硬加文献 |

此外，不能因为另一个领域使用过投票、聚类或环路，就判定本文没有方法贡献。相关工作比较应逐项对照计算对象、输入、对应关系、输出要求和研究问题。也不宜反过来声称 Polygon Consensus 与本文完全无关：它是相邻的几何聚合先例，不能直接替代全景上下点对及真实人员研究。方法新意应落在具体新增能力及其验证上。

## 3. 主线与支线：保持这一次的含义

**主线：**可靠的布局数据需要明确参考目标并修正标注错误。面对同一全景，人们对范围、结构和位置仍有不同表达；我们提出几何质量评价与结构共识方法，研究图片条件、人数和人员组成怎样改变这些表达及其群体结果。

四条主要贡献继续为两项方法、人数规律、人员构成规律。人员构成必须写已经得到的发现：具体成员与保留背景影响结果，同配比仍有差异，混合既能补回结构也能损失结构，同一替换可随背景翻转。

| 支线 | 在论证中的职责 | 不改成什么 |
|---|---|---|
| 同房 | 检查结构习惯在另一个视角能重复到什么程度、哪些信息可复用 | 用一个 Q 相关系数裁定“个人无价值” |
| 门洞、OOS、参考 | 区分人员作答差异、目标选择、拍摄点位、表示适用性和参考错误 | 将全部情况混为困难图片或低质人员 |
| Semi 与交互条件 | 说明从头绘制与检查初始化的任务不同，展示已确认错误怎样保留或修正 | 推导未经测量的心理机制，或宣称已经验证新工具 |
| 选人、停止与劳动 | 评价已有历史如何服务标注组织，并计入获取历史的成本 | 宣称所有策略都省时或线上部署效果已确认 |
| 拼接与几何约束 | 解释可见线索与规整模型的协调问题 | 把 Manual 设计唯一归因于拼接，或把全部端点差异归因于视觉理解 |

## 5. 防止再出现“自我承认莫须有错误”

此前如果把“没有做另一种研究”直接写成“本研究缺乏依据”，属于审查判断越界。以后按三层处理：

1. **事实错误直接纠正。** 不把错误的审稿前提写回正文。例如 medoid没有顶部、Q没有对照、全体数据无法追溯、问卷按分数反评分，都不能作为正文自认问题。
2. **真实条件放在最相关的位置。** 例如自动与辅助排序、已知人员池、参考目标、记录劳动范围，定义一次并在必要图注引用。不要每个结果后再加一句免责声明。
3. **新的研究问题留在其用途处。** 新人推广、心理机制、在线流程、模型重训练需要相应研究，但不自动成为现有方法及实证发现的缺陷。

当前 Discussion 的拼接段将“端点偏差成因未测量”插入三个几何约束的说明，削弱了段落主张。可直接说明配对、墙向和顶高是不同约束，继而说明界面应如何保留可检查的判断；本文没有作成因归因，就不必在这里主动辩护。

人工辅助时间未记录、特定停止策略成本较高等真实信息仍应保留。可以把辅助时间归属放回辅助流程说明，避免读者误以为它改变了另一组已报告劳动比较的分母。语言压缩不能消掉负结果或改变成本范围。

不恢复此前已经否定的内部版本/早晚数据集、库存修复审计、程序等级变化等叙事。不用新的“局限性”专节把这些重新引入。
