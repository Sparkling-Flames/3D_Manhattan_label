## 优先顺序

1. 补充 A 与 B 的多面板源图普遍在图内上方嵌有面板标题，C 图 3 也有。先从原绘图代码导出无标题子图，再由 LaTeX 排在各自图面下方。轴名、符号键、数据标注和界面截图里的控件标题继续属于图内内容。绘图使用原代码、原照片和原 3D 模型。
2. 正文首选精修共识图的中位数到输出的对应，再优化 Q 图中的受影响几何；沿用各自原例、原数值和单一读图方向。
3. 人数、换人和门洞曲线优先修正横轴、图例分组和比较对象。正文单排图可通过重新分配宽度处理小字，勿靠全图缩小节省版面。
4. 空出的版面留给研究发现。两稿的 Discussion 各用一项补充证据承载次要结论，本次只对明确的正文图注和指引作文字修正。

## 人数图的读图边界与逐图稳定阶段

两份投稿稿的 Q 示意图和共识定位面板可由[共用绘图入口](../../../../tools/thesis_main/analysis/draw_tomm_cscw_method_panels.py)重建：传入任一投稿目录的 `figure_package/panels` 路径即可。脚本沿用原房间、0.50 m 的两个端点编辑和六人的合成观察。受控房间的 0.30 m 顶角例与 0.40 × 0.60 m 凹口例取自[八组受控几何计算表](../../论文提纲_LaTeX_20261028/supplement_sources/geometry/input/q_iou_eight_cases/results_all.csv)。

正文人数曲线汇总固定的 171 张图。另一个逐图分析覆盖 206 张普通全景图，用每张图的整条平均 Q 曲线回看稳定阶段。从 3 人起逐一检验候选人数；从该人数到本图满池的所有均值，最高与最低之差须在容差内。后面还须至少能增加 5 人或人员池的 15%（向上取整，取较大者），区间内每个人数至少有 64 条可评分路径。满足条件的最早人数是该图的起点。
