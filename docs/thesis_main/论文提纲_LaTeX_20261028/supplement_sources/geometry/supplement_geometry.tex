{\Large\bfseries Supplement A: Controlled geometric perturbations\par}

Eight families, 66 archived configurations

S1 / C1: Uniform ceiling-height changes\\
S2 / C2: Balanced local height changes\\
S3 / C3: Concentrated versus distributed height errors\\
S4 / C4: Collinear resampling of unchanged geometry\\
S5 / C5: Shear versus translation\\
S6 / C6: Near-wall versus far-wall displacement\\
S7 / C7: Omission of a narrow alcove\\
S8 / C8: Non-orthogonal reference geometry

The 66 configurations vary height, position, direction and local structure.
Points show every configuration and lines connect observations. IoU is
multiplied by 100; dimensions are specified in each panel.

The prism comparison uses the arithmetic mean of corner heights. C2 also
shows the analytic volume IoU of the solid with a planar tilted top, and C4
shows the perimeter-weighted-height prism comparison. Added point pairs
subdivide existing straight boundaries while preserving their wall turns.

C8 uses a non-orthogonal reference to isolate the effect of Q's internal
direction requirement alongside its reference-relative measurements.
Together, the controls establish responses to specified geometric changes.
