Pro的主式有机制依据，但其严重尾部和整体高度尺度是研究选择，并非可靠人评唯一识别出的参数。J04支持重新检验严重端的总体量表，不证明四次尾项必须删除；J02修正后不再支持原来对局部方案的负面结论。当前没有足够理由把任一新候选升为正式赢家。

## 2. 评价对象：保留两个层次、几个分量

**主Q明确沿用既定平均x后的几何、既有配对与环序，不改成原始端点评分。** 这与最新Pro一致。本轮不把原始X/E加入主分，不另开原始误差调参；历史确曾探索原始X候选，但最新主式未采用，P05也没有给固定罚分授权。证据见[处理后口径核对](../../research/quality_processed_input_20261013/README.md)。

**原始输入层仅旁列诊断**：记录配对、点序、冗余/缺失、上下x差、预处理移动及复核依据。可信配对但x不一致可以沿既定预处理评价；没有可信配对则不能猜配对生成完整Q。大X不充分证明错配，小X也不认证正确；诊断不自动改几何分或人员资格。

**条件几何层**在明确参考下报告范围覆盖、底边定位、自身方向规整、整体均高偏差、局部高度残差和连续候选分。缺顶面仅报告底面；参考不确定则显式暂定或保留候选结果，不用最大Q决定参考。

**多参考继续执行用户既有筛选顺序**：明确人工指定优先；否则检查区分空间的局部角点及相邻连线，先识别表达的结构/候选族；局部残缺、斜跨或模糊时再用底面接近兜底，并保留不确定。具体数值阈值只是Pro实现选择，不能冒称用户阈值。T30四空间中R02962已人工指定D；W031/R03258和W034/R01412只确认包含延伸，限制A/B族，未人工选定A或B。最新局部规则见历史`PRO_PROMPT.txt`第七节；不是重新开始制定参考规则。

**两种“多参考”不可混用**：本次150份“双参考补算”指loader保留的原始/修订GT版本，用作敏感性列；用户批准的两个或四个合理空间由独立候选登记管理。计算各参考的对照分不等于正式路由，更不允许挑高Q充当目标。已有人工作答/局部规则形成的主参考保持，旧参考完整分不得补到只有确认底面的新空间上。

这些分量先保留，不等于永久规定每一项都必须进入同一个总分。特别需要区分：

- **D测共同正交轴下的规整程度，不测全部结构正确性。** 正交漏分支也可能D=0；合法非正交目标不能直接套此惩罚。漏结构另作诊断，先核实其真实影响，再决定是否需要新项。
- **局部高度Hc是相对参考、依赖底边对应的残差，不等于只看自身顶面方差。** 底点漂移、对应变化与局部高度错误可能共同影响它。
- “墙间结构＞局部高度＞整体高度”在可比错误下是合理设计方向，不能扩写为任意幅度都强制如此；归一化、实际损失和最终分数响应要一起看。
- 用户觉得2D大部分点接近、但3D严重歪斜，是两个评价对象产生分歧的证据。先并列解释，不立即增加一项平均2D误差来把总分抬高，也不因3D低分否认其余标注确实接近。

## 3. 分阶段实施与完成条件

2. 将Pro的35图参考登记、429份路由来源与当前3152份账本按object_id关联。922与429只有24份交集，不能把它们当同一母表。已有人工指定优先；已知限制继续保留；自动路由只产生可审查候选，不把“局部支持高”当成概率正确。
3. 输出每图/建筑的新增覆盖、仍阻碍的原因和可复用旧审核；完整Q、仅底面、原始输入诊断分别计数。W019/W026严重线索单列，逐份标签与配对证据齐备才讨论数值例外。

### 阶段B：冻结少数候选，定位真实分歧

主要比较保留旧`P_tied_quad08`、Pro的`J_main_hill_tail12_g1_l025`与简式`J_simple_power8_g1_l025`，加同参考现用3D IoU。局部`J_local_joint_hinge10_w2_s8`只在短局部大偏差与广泛偏差的分歧例中作诊断，不再扩大搜索家族。

所有分数使用同一输入与参考；参考纠正另做“旧/新参考×旧/新公式”四格归因。原始输入诊断和分项损失随结果展示，不直接据总分给人员分类。当前看起来稳定的排名不是选择模型的独立理由。

复用已做控制，仅补会影响决策的缺口：

- 整体升降、局部起伏、底点移动的对照，区分真实高度错误与投影/对应耦合；优先复用旧配对控制，缺哪种对照才补哪种。
- 轻微到明显结构偏差的连续响应，以及局部大偏差和广泛小偏差的真实代价；不把C01/P01几张图转成角度阈值。
- 正交窄分支遗漏等方向指标盲点，检查在合资格真实manual中的发生情况。先保留局部边界/结构缺失诊断，不直接给最大距离或点数差加权。

完成条件：形成少量能区分候选的真实失败模式和分量归因，允许候选各有所长或无明确赢家。控制预算相等不等于人的感受等严重，不以控制通过率认证优先级。

### 阶段C：只请用户处理能改变决策的少量问题

先消化旧有效回执，只有剩余取舍确实会改变候选选择时，才从合资格真实manual中形成必要的小批审核。覆盖实际未决的方向/总分、高度与二维/三维冲突，不预设题数，不重复已明确偏好；同时保留代表性案例，不能只挑最支持某个模型的分歧。

参考归属问题与质量比较分开提问；隐藏算法名和分数，允许接近、不确定、无法判断。旧曝光题仍属于开发证据，不能因为新页面隐藏分数就恢复成独立验证。最终未曝光验证按已有房间/建筑记录保护；确无合资格未曝光证据时明确承认缺口，不重切旧留出。

只有当反馈对某一失败模式形成重复支持，才局部调整相应响应，并记录可能牺牲的其他表现。J04不直接导出分数下限，T20不直接导出新整体高度系数，近似相当不编码成精确相等。

完成条件：能排除至少一种解释或确认仍不可识别。证据仍不足时维持冻结候选和不确定性，不以得到唯一参数为硬目标；好/明显/严重的通用等级切点继续暂缓。

### 阶段D：接回人员与既有融合研究

在上述同参考、可比条件层重评分人员和已有融合输出。人员按共同图片/条件比较，报告覆盖和建筑敏感性；将manual与semi、自动与人工辅助分别报告。不能由全库均分推人员能力，也不把参考修正造成的涨分算作人员进步。

先复用Pro已交付的60个可算冻结融合终点及本地旧结果，按新用途规则筛选；其余不可算继续保留。只有真实人数、成员、进入顺序及对应几何序列齐备后才画人数过程，缺序列不由终点插值。评分变化不触发更改融合算法。

## 4. 本轮明确不做的事

- 不再大规模扫参数；不为J01–J04或T20指定目标分而调参。
- 不把semi trap/未改模型记录混入主校准，也不删除真实manual严重错误以取得漂亮排序。
- 不把路由成功当完整质量合格；不拼接未确认顶面，不擅自修改GT或正式排除。
- 不直接把原始诊断、2D接近、3D几何强行合成一个新总分；先确定评价对象及实际分歧。
- 不以开发集逆序更少、分数上涨或数值复现成功宣称普遍优于IoU。
