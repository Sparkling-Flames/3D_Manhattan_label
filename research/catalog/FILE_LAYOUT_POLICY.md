# 当前研究文件布局

用户在 2026-10-21 明确要求：当前关键分析代码、报告、表格和数据以普通目录文件提供，拉取后可直接读取和运行；旧版、错误版等历史材料可以使用 ZIP 归档。

- 活跃报告与代码采用 `.md`、`.py` 等原文件；关键表采用普通 CSV/JSON。不能只把它们藏在总 ZIP 内。
- 大表可以按实际指标、图片/人员池等语义分片；每片是自带字段的有效文件，并有清晰索引。不要以 ZIP 字节片充当常用数据接口。
- 修改交付布局时同步检查加载器、引用、复现命令和研究目录。应验证普通目录路径不再要求旧 ZIP 存在，而不只是添加一份解压副本。
- 旧包、错误候选、原始提交凭证保留来源身份；不为整理文件擅自删除历史。原始数据分发归档与当前分析产物分别判断。
- 格式转换不改变输入资格、参考、分数或实验结论。用哈希、字段/行数、重要重放检查证明一致性。
- 格式修复独立提交，不把未审查的新 Pro 成果混入。
