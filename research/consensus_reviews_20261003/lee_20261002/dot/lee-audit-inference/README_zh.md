# 固定 BEV、等权 Lee 投票：独立数学判断与补强

## 结论先行

1. 新报告最主要的数学解释成立：≥50%与>50%都是平均面积对称差的最优解；去重子集等权均值在当前均匀、无失败抽样下不是天然有偏；B+D及有限池恒等式正确，但N=1必须特判。
2. 下一步应优先把固定人员池的参与人数曲线算可靠。支持补12图，但不支持把“新增边界指标”变成前置条件，也不支持把更多计算重放当成新增真实人员证据。
3. 新发现：奇偶方向不仅“可能产生起伏”，而是嵌套前缀的硬机制。MV50奇数→偶数只能扩张，偶数→奇数只能收缩；strict相反。应先把曲线的方向、平票与抽样误差分清，再解释人数效果。
4. 新发现：源输入177份足迹中，153份关于共同相机原点严格星形，24份不满足；12组中7组全员共星形。这7组的任意成员子集、任一现行阈值融合均不可能产生孔洞。其余5组仅表示该保证不适用，绝不表示已经找到孔洞。

## 1. Lee原文能支持什么

Lee等2018年论文第2页§4明确定义MV保留至少50%人员投“yes”的tile。tile由输入分割叠加形成；EM、greedy及最大聚类预处理是分别说明的机制。第3页人数变化结果来自46个对象、9幅图、每对象40份分割的实验，不能直接变成本任务的人数改善保证。

“多数票最小化平均面积对称差”是下面逐点证明得到的数学解释，不应写成该4页正文已经给出的优化定理。该正文也不证明MV最优化IoU。

来源：[Lee et al., Aggregating Crowdsourced Image Segmentations](https://ceur-ws.org/Vol-2173/paper10.pdf)。本次阅读了完整解析文本；未依据无法显示的截图作视觉判断。

## 2. 平均面积对称差，不是平均IoU

固定k人，支持率p(x)。候选区域C的平均个人面积对称差为

J(C) = ∫ [p(x)+(1−2p(x))1_C(x)] dx。

每个位置独立选择：p>1/2纳入，p<1/2排除，p=1/2任意。因此≥与>50%都是最小化解。这里只对“无额外拓扑/表示限制的一般可测区域”成立；若另加单一角点环、无孔、正交或固定顶点数约束，不能直接继承该最优性。

一个无平票反例：等面积tile A、B、C、D、E，三人分别画A、ABC、ABDE。多数结果AB的平均个人IoU是5/9；改选ABC为26/45，更高。与此同时，AB的平均面积对称差4/3小于ABC的5/3。两个优化目标确实不同。

另一个人数反例：真值仅A，三人各画ABC、ABD、ACD。每个人IoU均为1/3，3人多数为ABCD、IoU=1/4，比所有个人都低。精确人数曲线为

- MV50：1/3 → 1/4 → 1/4
- strict：1/3 → 1/2 → 1/4

这是数学存在性反例，不是本数据的质量结论，也未暗示用参考选择人员。它说明即使没有数值误差，平均对称差最优仍不保证参考IoU随人数提高。

## 3. 奇偶方向是确定机制

令阈值t_k在MV50下为ceil(k/2)，strict下为floor(k/2)+1。

- 当t_{k+1}=t_k，原本被选中的位置不可能因增加一人而被排除，只能扩张
- 当t_{k+1}=t_k+1，原本被排除的位置不可能因增加一人而被纳入，只能收缩

所以MV50从奇数到偶数扩张、偶数到奇数收缩；strict方向正相反。代码穷举到10人全部二元票序列，32776项判断通过。

这给原change_mean一个更具体解释：每一步的1−IoU来自单方向增删，而不是同一步任意位置漂移。可以补“增加面积/删除面积”方向，不应把交替起伏直接归因为新加入人员可靠性变化。

若全池N人、某tile有r人支持，当前k人支持数j服从Hypergeom(N,r,k)，下一人均匀从余下人员选取。若阈值不变为t，改变纳入状态的概率为

Pr(j=t−1) × (r−t+1)/(N−k)。

若阈值从t增到t+1，改变概率为

Pr(j=t) × (N−r−k+t)/(N−k)。

它等于该tile两次被纳入概率之差的绝对值。因一步中各tile改变方向一致，平均对称差面积等于两次平均融合面积之差的绝对值。独立有理数检查1276项通过。注意这不是平均Jaccard距离的公式，因为后者分母随机。

## 4. 去重等权：不是偏差问题，但有明确目标

固定k共有M=choose(N,k)个成员子集，R条独立均匀排列在该k产生R次独立均匀子集抽取。设U为抽到的不同子集集合。

条件于|U|=m，U是M个子集中的简单随机m子样本。因此去重均值的条件期望和无条件期望都等于全M子集均值。对称性也给出E[1{S∈U}/|U|]=1/M。

去重均值还是原始重复计数均值在“已见子集集合”条件下的条件期望。因此在这些假设下，其均方误差不会比保留重复计数的均值更高。独立小例子精确验证：两者期望同为0.4357142857；去重方差0.0452827381，小于重复计数方差0.0517517007。这不是本12图方差估计，仅是可复算性质检查。

条件m时，均值方差为(1−m/M)S²/m，其中S²是M个子集分数的有限总体方差（分母M−1）。失败若与分数相关、非均匀抽样、或者根据结果挑选重放批次，以上原目标无偏结论就不能自动保留。原实现无失败的证据应明确限于实际核验范围。

成员差异还要定义抽样目标：原member_distance平均不同子集之间的距离。若改成两次独立抽取（允许两次抽中同一子集），期望会乘(M−1)/M。k=N只有一个子集，此时“不同子集间平均距离”没有实际配对，源码记0是约定；这不是自然人群收敛证据。

## 5. 有限池支持场：恒等式正确，解释须精确

按正的固定面积s归一化，B_k=∫(p_k−1_G)²/s，D_k=∫p_k(1−p_k)/s。有

平均个人对参考的面积对称差/s = B_k + D_k。

N≥2、k人均匀无放回时：

- E[B_k] = B_N + (N−k)/(k(N−1)) D_N
- E[D_k] = N(k−1)/(k(N−1)) D_N
- E[B_k+D_k] = B_N+D_N

因此B_k随k的期望下降与D_k的期望上升本身主要是这些恒等式，不应再次被宣传为新发现的准确性/不确定性规律。B不是估计量的统计偏差，D也不是可分离的人/图随机效应。

k≥2时，U_k=2k/(k−1)D_k恰好为当前k人全部无序对的平均对称差/s，且E[U_k]=2N/(N−1)D_N，即全池无序人员对分歧。这个明确的有限池目标是“无偏”应指向的对象；不是声称D_k本身无偏估计D_N。

N=1时只有k=1，支持率没有抽样方差，D_1=0，B_1等于该单人对参考的归一化对称差。上式含N−1的表达必须直接特判，不能计算0/0。当前12图确实含一个N=1组。

## 6. 平均遗漏/外扩可以精算，平均IoU不能取巧

每个tile的纳入概率可以用超几何尾和精算，所以平均融合面积、平均参考交集、平均遗漏和平均外扩都能不靠MC得到。一次全员划分可作为这些离线积分的细分基底；只要每个子集的纳入规则仍只看子集投票，细分不会改变其理论结果。此优化不代表必须改变原实现的当前成员分区契约，也需要数值一致性核验。

但E[I/U]通常不等于E[I]/E[U]。例如两个候选面积分别1、2，均完整包含面积1的参考，平均IoU为3/4，而平均交集/平均并集为2/3。精确平均面积不能冒充精确平均IoU。

单个输出的遗漏o、外扩e（都除参考面积）满足IoU=(1−o)/(1+e)，但把平均o和平均e代入得到的是另一指标。报告同一输出的两个方向有解释价值，不是额外独立评分证据。

## 7. 孔洞问题：本数据已有更强的可检验条件

一般简单多边形都含相机，并不能保证多数结果无孔洞。但若每份输入都关于同一相机点星形，则对任一点x，支持x的每个输入也支持相机至x的整段；该段的票数至少与x相同。因此任意正阈值结果仍关于同一相机星形，尤其不会产生孔洞，也不会变成彼此分离的多个组件。

在逐射线表示中，每人给半径r_j(θ)，票选等价于逐射线选半径顺序统计量：奇数为中位数；偶数MV50为上中位数，strict为下中位数。这是有条件的独立核验/计算路线，不是建议立即替换已实现的tile基线。需要注意，仅离散角度采样不能自动声称精确重建连续多边形。

本次直接对固定提交的input.json做检查：

- 177份均通过非相邻边不相交的简单多边形检查
- 153份相机原点严格在多边形kernel；24份不满足；无近边界不确定项
- 24份里有4份相机位于区域外：R03288、R03285、R03293、R03396
- 其余20份相机在区域内，但不是关于相机星形
- 以下7组全员共星形，所以该组任意成员子集的现行两种输出均保证无孔洞：7y3sRwLe3Va-08、7y3sRwLe3Va-12、7y3sRwLe3Va-26、B6ByNegPMKs-40、B6ByNegPMKs-42、e9zR4mvMWw7-16、jtcxE69GiFV-30
- 另外5组：2t7WUuJeko7-07、7y3sRwLe3Va-06、e9zR4mvMWw7-19、jtcxE69GiFV-12、yqstnuAEVhm-31。这里只是全员共同星形保证不成立；未检查或宣称这些组已经产生孔洞

计算方法：对于简单多边形，按有向面积统一朝向后，原点在kernel当且仅当原点在所有有向边的内部半平面。采用源JSON十进制坐标字面量的精确有理数进行方向、相交和符号检查；只将有向边距离转浮点用于报告和近边界提示。提示容差为1e−10乘max(1,最大顶点半径)。这是对给定坐标的确定性几何检查，不认证测量真值，不恢复舍入前坐标，也不改变任何记录、共识或质量资格。

## 8. 我建议的下一小步

### 先固定估计目标

每个现有image/condition/gate组，主要目标是“从当前有限人员池均匀抽k个不同真人，其融合结果的分布/均值”。它是描述性反事实重组，不是未来招募人员的总体学习曲线。

### 把12图重放做成有界数值研究

1. 全部N≤9组直接穷举。当前6组人数是1、5、7、8、8、9，所有非空子集合计1180；不必只精算8人组后继续对这些小组做MC。
2. 余下6组先给精确的平均面积/遗漏/外扩、支持场和奇偶方向；它们便宜且不会产生MC误差。
3. 真正需要MC的IoU均值、相邻变化和尾部分位数，先定“多大误差会改变对曲线的判断”。用试运行估计计算量后，做预先固定大小的独立验证批次；或用适合序贯停止的置信方法。不能一边反复看普通固定样本区间、一边在满意时停止，却仍声称原有覆盖率。
4. 两种平票规则使用相同子集作配对比较。跨k比较按完整排列/独立批次保留联合依赖；不要把同排列的所有前缀当成独立重复。
5. p10/p90是子集分布的分位数，不是均值的误差条。均值MC精度够，不表示尾部位置已稳定；报告尾部分位数不确定性或在样本不足时不解读细小尾部差别。
6. 保存成员集、抽样设计、随机种子、失败记录及精度结果。对失败保持原分母口径；不要根据参考得分删除不利子集。

### 什么时候该停止这一步

当主要下降/反转/奇偶结论在预先选定的实际分辨率上能被计算精度支持，或者精确结果表明差异小到无研究意义，就停止继续增加重放。此处停止的是计算估计，不是宣称最佳真人数。当前没有预算/收益阈值或未来招募分布，不能从全员端点或16次排列拟合一个“足够人数”。

底面边界指标之后是否优先，应由“面积是否遗漏了研究关心的局部差异”决定。它与当前表示兼容，确实比贸然加入体积少假设，但这是后续测量选择，不是完成参与人数基线的逻辑必需品。

若研究问题升级为未来人员总体的数量规律，需要明确人员招募分布、跨图片/建筑抽样、人员重复和条件分层，保留独立评价或外部复测。更多排列不会增加这些信息。当前阶段无需为此先建立复杂人员模型。
