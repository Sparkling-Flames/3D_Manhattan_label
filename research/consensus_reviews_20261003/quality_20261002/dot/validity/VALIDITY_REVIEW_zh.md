# 指标效度独立复核：判断对象先于指标排序

## 我的结论

返回报告提出的“固定 GT 下的声明范围一致性”可以用 BEV IoU 作主终点；我支持这个**有明确范围限制的命题**。它尚不能自动升级为“整体 layout 标注质量”的主标尺。上轮廓位置和必要局部墙体也是任务要求时，应与范围一起构成必报、能阻止“总体高质量”结论的评价维度。没有经过任务校准的总权重时，保留分项或部分排序，而不是用某个单值替代全部质量。

我也不主张因为三维来自同一批二维点，就把体积指标排除。**在真正规定为水平顶面棱柱的任务中，模型体积就是该棱柱的交并比；其与 BEV 的次序反转可能正是正确的体积判断。** 非平顶反例证明适用域有限，不证明体积在适用域内没有价值。

因此，我的建议是：范围研究用 BEV 主终点；整体标注质量用范围、局部边界、上/下定位的预先声明组合报告；水平棱柱体积作为模型条件明确的辅助终点；新增最近墙高残差暂限探索性诊断，先处理歧义和数值积分问题。局部路径或聚类不是启动这条主线的前置条件。

## 2. 新结果：哪类分歧才是指标有效性问题

### 2.1 核心对照：完全符合平顶模型，排序反转仍然合理

GT 是边长 4h、高 3h 的方形棱柱。作答 A 的平面范围均匀放大到 BEV IoU=0.9，高度仍为 3h。作答 B 的足迹完全正确，高度为 4.5h。

|终点|A：范围扩大、高度正确|B：范围正确、高度偏高|
|---|---:|---:|
|BEV IoU|0.900000|1.000000|
|棱柱体积 IoU|0.900000|0.666667|
|上轮廓 RMSE，512 高图像像素|4.232817|44.204178|
|下轮廓 RMSE，像素|3.153346|0.000000|
|自身墙高 RMS|0|0|
|自身最佳轴残差|0|0|

这里体积是明确合成实体的真实体积交并比。若问题是足迹一致性，B 更好；若问题是棱柱占据空间一致性，A 更好。两种排序都能完全符合各自定义。没有预先确定任务损失，不能把次序反转当成体积改进的证据，也不能当成它失效的证据。

这同时证明：

1. BEV 与底面边界完全正确时，上部仍可严重偏离，因此它不能单独认证整体标注质量
2. 零高度起伏、零正交残差只能说明提交自洽，不能说明它与 GT 一致
3. 高度来自原二维点，不等于高度相对于“仅保留足迹”没有新增评价信息；新增的是任务相关信息表达，不是新增独立传感观测

返回报告已经把 BEV 主终点称为“范围一致性”，也明确拒绝仅凭两次实际排序反转选优。这个表述应保留，不能在摘要或后续人员分类中悄悄扩大。

### 2.2 几乎完美的面积交并比仍能漏掉长局部边界

在 4h×4h 方形内切入宽 0.02h、深 3.8h 的细凹槽，再用完整方形作为遗漏该凹槽的作答：

- BEV 和等高模型体积 IoU 都是 0.995250
- 双向边界距离 p95≈1.402641h，采样最大距离≈1.5h
- 上/下轮廓 RMSE≈53.5067/58.2943 像素

被删除的面积只有 0.076h²，但相关墙边很长。这不自动证明这种凹槽是实际任务里的关键结构；它精确说明**面积权重**与**墙体定位/必要结构权重**是不同取舍。若任务要求保留必要局部墙体，边界和轮廓必须有能力否决“整体优秀”结论。

### 2.3 投影轮廓也不能取代声明范围

两个含隐藏上延支路的简单正交多边形，面积分别为 20h²、23h²：

- BEV IoU=20/23≈0.869565
- 最近墙逐列投影的上/下轮廓完全相同，墙带 IoU=1
- 将方位采样提高到 65536 列后，最大轮廓差仍约 10^-16 弧度

这不是普通像素分辨率碰巧漏掉的差异。相机看到的首交墙相同，隐藏范围不同。报告已经披露逐列表示不能描述所有隐藏墙几何；本检查支持 BEV 与投影分项互补，而不支持任选一种一劳永逸。

## 3. 体积模型、信息依赖与模型适用性

### 3.1 什么几何量被算出来了

当前量是“足迹 × 周长平均墙高”构造出的平顶棱柱交并比。它由 A、B、I、H_A、H_B 完全决定，不能解释成新的独立观测。高度相同则它恰好退化为 BEV；不高于 BEV 是公式结构，不能据此声称更严格因而更有效。

如果同一地面、共同高度尺度和水平顶面假设确实成立，它是对应模型实体的正确空间交并比。若顶面不水平，它仍是明确的代理，但不是任意实际房间体积；未知内部屋顶也不能从边界唯一恢复。

补充一个已知内部顶面的数值：三角形足迹 [(-1,-1),(8,-1),(-1,2)]，顶面 H=3+0.5x。面积为 13.5h²，面积平均高度 4h，真实体积 54h³；周长平均高度约 4.435854h，代理体积约 59.884031h³，高约 10.896%。这个非平顶合成例用于区分周长积分与面积积分，**不是对平顶适用域内算法的反证**。

### 3.2 共享误差并不禁止报告多个相关终点

在 r=4h、H=3h 处，(r,H) 对 (α,β) 的 Jacobian 是：

```
[-17.0, 0.0]
[ -8.5, 5.0]
```

独立给 α、β 各 0.25 原域像素的标准差，传播后 r、H 的相关系数约 0.861934。有限差分核验 Jacobian 最大误差约 1.9×10^-10。

这是一种示范噪声模型，不能用它替代真实人员点击噪声估计。它说明范围、推导高度、top 三维位置可能重复响应同一 bottom 偏移；把这些当成几次独立错误加权或把几个检验当独立会误导。它**不**说明相关终点不能同时报告，也不排斥针对明确决策代价校准一个相关的多维损失。

### 3.3 模型自洽不等于任务有效

平顶残差小，不能验证照片确实满足平顶假设，也不能验证高度正确；上面的 A/B 均自洽但均有不同偏差。适用性判断应由既定场景信息、照片/参考模型政策和事先规定的诊断联合支持，不能看哪个指标排序好再选样。所有适用/不适用/不能判断的分母必须留下。

## 4. 新增墙高诊断的两个具体问题

这些定位在**返回包新提出的辅助诊断**，不归因给固定上游的周长均高实现。报告已披露近邻可能匹错；下面量化仍需补足的处理。

### 4.1 有限弧长采样不等于解析弧长不变性

在边长 4h 的同一方形底边放一个宽 0.02h、高于平顶 2h 的三角形顶线脉冲；其他顶线高度 3h。没有改变足迹。真实连续弧长墙高 RMSE 为：

`sqrt((2 × 0.01 × 2² / 3) / 16) = 0.040824829h`

代码每方向只采 512 点，间隔 16/512=0.03125h，比整个脉冲还宽。

- 原环起点时，新增墙高 RMSE≈0，整个脉冲落在采样间隙
- 仅把相同环的起点转到脉冲顶点，变成 0.0625h
- 提高到 131072 点，两起点分别约 0.04082512h、0.04082574h，收敛到解析值
- 当前解析周长平均高度始终约 3.00125h，不受起点影响

这里选择窄而陡的合成顶线是为了暴露数值性质，不是声称当前真实数据频繁存在此形状。其含义是：不能把均匀弧长采样的好处说成任意固定 N 的严格几何不变性。代码的 `sampled_max_error_bound_h=L/(2N)` 可约束到边界的几何距离采样最大值误差，因为该距离是 1-Lipschitz；它**不能**直接界定带高度斜率或近邻跳变的墙高残差误差。

建议对这项诊断增加环起点/方向测试、N→2N 的收敛测试；或做分段、自适应积分并报告数值误差。原包相反斜顶的约 1.633h 结论不因这里的极端例而失效。

### 4.2 近邻歧义不只是采样精度问题

代码 `nearest_boundary` 在等距目标边间用 `argmin` 选第一个边，没有并列/近并列标志（副本第 85–100 行）。

**精确几何检查：**目标是 x=±2、y=±10 的长方形，顶线 H=4+x；源是相机位于内部的 L 形，多一段 x=0、y∈[0.5,2.5] 的边，源顶线 H=2。该整段源边与左右目标墙等距，但对应高度分别为 2h 和 6h。仅将目标环循环移两点：

- N=512：新增墙高 RMSE 从 2.788874h 变成 2.558016h
- N=32768：仍为 2.788867h 与 2.558723h
- 目标环移位恰为半周长，偶数 N 下目标采样点集相同，差别来自对应墙选择
- 极限平方 RMSE 的差为 16/13；提高 N 不能解决多解定义

**重要限定：**上述严格反例直接使用合法、精确的 3D Geometry。将同一设计先转 ERP、再重建时，极小浮点不对称打破了严格等距，本次两个环编码结果都约 2.558016h。因此不能声称当前真实数据或该 ERP 往返样例已经出现同样的循环次序翻转。

另一个邻墙点探针表明，横向仅移动 2×10^-6h，可使选择的高度从 2h 跳到 5h，而两次最近距离都只有 0.009999h。这个不稳定性解释了为何只看“距离很近”不足以建立墙身份。

建议先返回最近距离、近并列候选/间距、歧义弧长占比和有效匹配覆盖；歧义区允许返回残差区间或不可用。不要默默取第一个边，不要把不可配段赋零。若后续确需语义墙面对应，再比较受约束对应方法；无须把那项研究提前变成范围评价的准入门槛。

## 5. 我建议真正执行的端点和判定规则

### 5.1 固定评价合同

保留已定 GT 版本、保存坐标、环序、共享坐标系和资格分层。术语用“参考一致性”，不把一次处理后的提交直接说成未经处理的人员能力。计算失败与未审核来源应分别记录，不静默删除、不给一刀切零分。

### 5.2 端点设置

1. **范围主终点：**BEV IoU；方向性覆盖和新增/缺失面积作解释，不能将它们重复累加
2. **整体质量必报维度：**双向物理弧长边界距离/尾部，分开的上、下角度轮廓误差及尾部。若研究声称整体 layout 质量，上部与必要局部墙体不能只作为可以忽略的附录
3. **条件性空间终点：**周长均高差、起伏、平顶模型体积；清楚标明模型和适用/未知状态
4. **探索性诊断：**最近墙高差。在歧义处理和数值稳定性通过前，不承担人员分级或优劣裁决

底轮廓、BEV、边界等允许相关，因为它们回答不同测度/呈现方式的问题；不声称每个都是独立证据。局部轴拟合是自洽诊断，不是评分奖励。

### 5.3 可操作的结论规则

- 只声称“范围提高”：比较 BEV，并明确这是范围结论
- 声称“整体更好”：至少所有预先规定的关键维度不出现超过任务校准容差的实质退步，同时至少一个维度改善；冲突保留为权衡或不能判定，不强排总名次
- 容差未完成校准前，仅给分项数值、效应区间和描述性部分排序；不能把随手选的 5px/5°或 0.05h 当合格线
- 某辅助表示不可用时保留原因和分母，不能仅凭其缺失判断该份作答错误；总体质量结论按必需维度的可判断性给出“证据不足”
- 进入人员/图像效应时，各端点分别或联合建交叉模型，调整共同图片分布并报告不确定性。对多端点的正式检验需预先规定推断规则，不能把相关结果当独立重复确认

这些是可执行的报告规则，不是未经授权建立新 GT 或强制用户采用一种质量偏好的替代品。

两位审核者在看指标前，先依据既定任务说明明确范围、必要局部墙体和上/下定位的判据；看原图、保存环和既定参考，隐藏人员、指标值、冲突层及左右顺序。分别评各维度偏离程度，并允许相近、双方均不可接受、无法判断。不要用“你总体更喜欢哪个”暗中创造一个没有定义的总损失。

随机对和定向冲突对分开汇报，保留审核分歧。作答对共享图像和人员，不按 24 对独立做显著性推断；12 图也不足以同时调阈值、选权重并声称外部验证。这个试点的停止成果是：确定下一版必报端点、找到失败型及需校准的容差。若要宣布正式人员分类或总分有效，还需独立建筑/图片上的留出验证。

## 7. 文献用途边界

- [Metrics Reloaded](https://www.nature.com/articles/s41592-023-02151-z)支持从任务、结构及输出性质选择指标的原则，并不是全景标注的指定标准。本报告的具体端点取舍是依据当前任务和反例作出的判断
- [Boundary IoU](https://arxiv.org/abs/2103.16562)的作者研究展示了面积交并比对某些边界差异不敏感，支持另查边界质量的动机；不能直接继承其带宽为本任务合格阈值
- [HorizonNet](https://arxiv.org/abs/1901.03861)使用逐列 floor-wall、ceiling-wall 等表示，支持这里分上/下轮廓的表示思路；其存在不证明该表示能衡量所有隐藏几何或处理当前全部可见性情况

本报告的关键数值来自独立合成计算；不是从上述文献推测出来的实际数据结论。
