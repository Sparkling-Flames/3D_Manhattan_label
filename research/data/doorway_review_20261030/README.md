## 双边界预切

已逐图检查20张原图及底面，并为每图提供空间1、空间2的初始范围。每个空间独立记录停止边及保留侧，允许两条停止边之间留下门框厚度区域，不要求经过拍摄点，不要求两个空间恰好拼满原GT。

10图按参考中门口附近的两个转折坐标建立两面草稿，10图原参考未明确表达两面，采用所在轴范围2.5%的初始间距供调整。这个间距是界面初始建议，不是测量的门框厚度。每图均标明来源；尚未经用户审核，不用于评分或作为正式GT。

原图查看区同步投影裁后底面及停止边（粗线），可旋转全景。先选空间1/2，拖动俯视图彩色方块平移停止边；也可在俯视图或原图地面点两点重定位。水平/垂直开关可关闭；翻转保留侧、撤销、恢复本图预切及清空当前空间可用。只投影底面，不假设顶部形状或高度。

四项分类为：空间1、空间2、全部、都不符合（看不懂）。点击即保存，没有确认按钮。两空间未完成时前三项禁用；边界改变后保留旧选择及边界快照，提示重新查看。

## 保存与兼容

浏览器本地保存使用doorway_review_v2，与旧v1缓存分开。旧单线迁移为两个同位置边界，已有分类保留；未分类且无切线的旧空白占位使用新版预切。已有用户修改不自动被新版建议覆盖，可按图选择恢复本图预切。

导出包含全部20图，包括未访问的预切草稿。导入同图记录替换该图草稿，其它图保留；导入前建议先导出备份。版本和参考身份不匹配、未知标注、无效坐标或无效空间拒绝导入。用户首审后由Codex复查，不自动采用。

## 数据合同

JSON schema=doorway_review_v2；cases以image_id为键，包含reference_id、reference_version、cuts、note、answers、proposal_note。cuts为两个独立条目，每项为null或{line:[[x,z],[x,z]],side:1或-1}；spaces导出两个裁后底面（未完成为null）。answers以object_id为键，记录label、cuts快照、updated_at。exported_at记录导出时刻。全部指原参考整体范围，不证明原GT正确。

数据来自v2.1 reference_catalog、difficulty_records、quality_inventory及冻结v2 evidence points。复用旧多空间geometry.js与研究台geometry-view.js；旧工作台相机必须在区域内部的要求不用于门洞两侧裁切。原答、GT、绑定、资格、评分、CURRENT均未修改。
