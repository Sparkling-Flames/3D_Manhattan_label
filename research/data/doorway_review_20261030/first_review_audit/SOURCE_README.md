### 4.1 页面里

- 最下方逐份核查：`#answers` 切 35–38 份工人作答，按钮显示当前判定，颜色表示可用/需修正/无法判断；
- 快捷键 `1 / 2 / 3` 判定，`N`/空格 下一份。

### 4.2 JSON 字段

```jsonc
{
  "schema": "doorway_review_result_v2",
  "counts": { "total": 20, "reviewed": 20, "verdicts": 708 },
  "cases": [{
    "image": "2t7WUuJeko7-07",
    "cuts": [ {"line": [[-100, 0.021], [100, 0.021]], "side": -1},   // 空间1 停止边
              {"line": [[-100, 0.088], [100, 0.088]], "side": 1} ],  // 空间2 停止边
    "precut": [ ... ],                    // 原始预切，便于追溯改动
    "verdicts": [ {"record_id": "...", "value": "fix|pass|unsure", "cuts_hash": "...", "at": "..."} ]
  }]
}
```

- `side` 语义：法向 `n = normalize(-dz, dx)`；保留侧满足 `side * cross(A,B,p) >= 0`。`side=-1` 保留法向负侧，`+1` 保留正侧。
- `verdicts[].value`：`pass`=可用、`fix`=需修正、`unsure`=无法判断。
- `cuts_hash` 是该次判定时的边界指纹：与当前 `cuts` 不一致 → 页面提示「边界已改，旧判定需重看」。

## 6. 坐标与判定口径

- 原图：ERP 等距柱状全景，**1024×512** 坐标系；页面 canvas 按 1.5 倍显示为 1536×768。
- 俯视：BEV 米制 `(x, z)`；相机在原点、朝 `-z`。
- 停止边：直线 + `side`；空间 1、空间 2 各有独立停止边，两条线之间是**门框厚度区**（本批 0.015–0.425 m）。
- 相机通常正好落在门洞中，状态栏显示「相机位于停止边上」属正常。
- 判定三档口径：能用该图当前切分支撑 → **可用**；有明确错误（漏墙、角点偏移、两空间被合成一个等）→ **需修正**；点缺失/坐标不可用/图像太糊 → **无法判断**。
