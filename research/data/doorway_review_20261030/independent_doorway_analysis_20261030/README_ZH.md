## 2. 不要静默替换范围规则

原面积规则用停止线两侧的**无限半平面**：f1≥0.85且f2≤0.10为空间1，反之为空间2；两侧均≥0.15为全部；其余保留未知。独立代码在原始边界下复现全部708条旧分类，并对586条可校验的旧自动面积证据复算，最大绝对差1.11×10⁻¹⁵。

最终切线可按同一规则刷新，得到上表519明确。另作的有限多边形相交敏感性把每侧限制为最终GT内区域，**会额外惩罚外扩或几何失配**：与最终cut方案相比，75条基础自动标签不同，未定从34变107。该实验说明这不是等价实现，不能用有限多边形默默替换原范围初判，或当作新增乱标/排除名单。有限相交结果仅用于检查“范围”和“几何贴合”混淆风险。

17张主图的34个有限区域独立复核：互相重叠面积为0，GT外面积最大1.78×10⁻¹⁵（数值精度）。两处相邻/首尾重复点仅在计算中去重，无位置移动或几何修复；这不证明真实门框、顶部或实体墙语义正确。

**20→28人的反例：** 直接读条件均值是29.054→30.897（+1.843）；但17条可评分路径只剩4条，其余13条失去Q。共同可评分4条在20人的均值为36.873，到28人30.897，**配对平均变化−5.976**。这不是Q计算矛盾，而是有效分母改变；两端均值不能替代共同路径的配对差。

24条路径在k≥3都曾完整、也都后来失去完整；21条还曾从不完整恢复。相邻步骤共有86次失去与66次恢复（路径事件，不是独立试验）。增加人数并不保证结构输出单调完整。满员24条记录是同一支32人队重复，不是24次独立失败。

17图满员端点为11完整、6不完整，完整者条件Q均值45.789；Q≥80只有1/17，Q≥90为0/17。这是库存描述，不外推总体概率。缺Q保持缺失，不能填0。
