### 2. 自动归属没有完整对应“只标空间1、只标空间2、全部”的语义

本次用本地原面积规则、最终停止边及整体参考独立复算：17 张完整 GT 本身，13 张判为 both，7y-06 / q9-13 / jtc-12 为 borderline，**b8c-08 的完整 GT 被判成空间1**。b8 的两侧比例为 95.9009% / 3.4370%，而 jtc 的完整 GT 比例为 10.5015% / 87.3407%。

这是可直接复现的构念问题：当前标签识别主面积在哪一侧；它不能可靠区分“大侧占绝大部分但确实包含小侧”与“只标大侧”。因此即使每项计算都对，当前分空间曲线仍只能解释为此自动规则及人工保护标签下的条件结果。不能全部写成人已经明确选择某个空间。

Pro 已披露这一反例，但披露没有消除它。Dot 将它作为语义保留意见是正确的；对于用户原本要研究的空间选择，它与 13 份旧资格一样重要，不宜只当论文末尾的小限制。

如需“实际空间选择”层面的主结论，优先针对这四张面积不平衡图及相关自动侧标签，依据固定结构、另一侧关键角点与停止边开展不看 Q 的复核，保留人工裁决；采用明确的新归属版本后仅更新受影响池。不可按哪个参考分数更高来反选空间，也不可把所有自动结果一概判错。本次未改用户标签及冻结人员池。
