## 工件与字段合同

`AUDIT.json`为汇总；`record_audit.csv`为逐份检查；`pool_inventory.csv`为新增图片×条件覆盖；`PREPROCESSING.json`为本批派生坐标入口（路径相对仓库根），坐标载荷为`preprocessed_annotations.json.gz`。本批输入和派生坐标可从GitHub获取；它们不包含账号姓名映射。

派生载荷schema为`v2_new_batch_preprocessed_coordinates_v1`，objects包含全部7217份新增记录，使用与库存相同的object_id。`before_preprocessing_points`保存收到的坐标；`preprocessed_points`及`points_1024x512`保存平均后坐标，沿用收到的点索引、配对和boundary_next_pair_indices；不改变非坐标字段。`preprocessing_status=blocked`时两个计算坐标字段均为null，原因在`preprocessing_blockers`，禁止回退到平均前点作正式输入。逐份CSV同步这两个状态字段。预处理ready与disposition、quality_status独立消费；这份增量坐标包不是已经接齐参考及资格的完整research_analysis_bundle。

逐份表的`object_id=v2:new:<annotation_id>`为本次内部命名空间；`disposition`仅为`retained_user`或`excluded_by_user`。`scope_raw`原样保存，`scope_normalized`只做词形转换；`quality_status`明确待评分或已排除。几何标记仅代表检查结果，不自动改变disposition。时间来源固定记录为用户已处理、尚未回放日志。Semi空值不转成false。排除记录的`matching_retained_annotation_id`只表示同人同图同条件，不能证明提交顺序。

复现：`python -m tools.thesis_main.data_prep.intake_workers_v2_20261019`，默认读取仓库本地received副本。7项接入测试覆盖保留/排除分离、重复保留阻断、点配对与单环、周期平均、y及输入不变、重复处理不变、对跖/未配对阻塞和三对点不自动排除；另运行原共享x函数的既有定向测试。全批生成时校验点数、y、共享x及重复处理不变。
