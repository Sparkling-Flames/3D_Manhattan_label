## 使用与不可覆盖规则

1. 直接查看现有结果可用原路径；严格复现v1时，将ZIP恢复到**新的空目录**，保留内部仓库相对目录，然后向现有loader显式传入恢复后的`analysis_results/research_input_20261017/manifest.json`。不要解压覆盖工作仓库或旧快照。
2. 评分、参考和人员报告使用同一恢复树下的文件。不要在v1标注上无提示地接入最新参考或最新人员名单。
3. 此目录的冻结负载和RELEASE清单不覆盖。数据增加或旧记录更正进入v2新目录，并保存新增／更正／资格／参考变化账本；只有完成核验后才推进上级[CURRENT.json](../CURRENT.json)。当前尚无数据v2。
4. 新算法可以评价相同数据v1，但结果另存并声明算法版本，不能覆盖原B8L2/D10。固定v1画像迁移与v2重拟合分开报告。

本包不复制原图、全部原始active-time日志、完整历史实验库或Python运行环境；原图沿现有资产，时间保存当时审计值和来源，原日志仍在本地真源。它足以恢复冻结输入和当时结果，不宣称是从所有上游原件端到端重建的独立安装包。
