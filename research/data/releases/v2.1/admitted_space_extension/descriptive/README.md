# 其它合法空间：原答质量与人员历史的描述性补充

本目录只读取已保存的 v2.1 原答评分和 31 个新增同目标人员池，不重新评分、融合或拟合分类，也不改原库存及 263 个原池。原答库存中有 8,154 份原正式质量记录；另有 231 份符合此次同空间分析条件的记录（Manual 227、Semi 4），合并为 8,385 份。五份不足三人的候选不进入本次分析。对象 ID 两范围无重叠。

## 汇总方式和文件

- `POOL_SUMMARY.csv`：原有与新增各条件×图片×目标参考×质量用途的记录数、独立人数、Q/D10 均值及各指标支持。`POOL_TIME_BY_SOURCE.csv` 将记录时间按来源人群和时间来源分列。
- `SUMMARY.csv`：原有、新增、合并三种范围，按 Manual/Semi 和质量用途分开。每个指标先在同一图片的同一目标内平均，再对同图各目标等权，最后对图片等权。每项分别列有效记录、目标及图片数；没有可用值的目标不会被填零。
- `PERSONNEL_COMPARISON.csv` 和 `PERSONNEL_HISTORY_CHANGE.csv`：逐人分别列三范围的 B8L2/D10 图片等权均值和支持数，以及合并减原有的差。这里的“历史”指保存的绝对质量描述，**不是分类模型中经同图同行调整的 q_history**。不同范围的图片支持可变，差值不等于固定图片上的人员变化或能力提升。
- `TIME_BY_SOURCE.csv` 和 `PERSONNEL_TIME_BY_SOURCE.csv`：来源人群及 `time_provenance` 分开汇总，不将记录秒数当作新测量的生产工时；缺失时间不填零。各文件中 `*_records`、`*_targets`、`*_images` 是对应指标的有效支持。
- `TRAINING_RECORD_IMPACT.csv`：每份新增作答在已有 DSTRUCT 输入和 V3 行为、质量、时间历史中的实际状态。`TRAINING_COVERAGE.csv` 为条件层计数。布尔列描述**当前已存输入**，不是模拟新增后模型结果。
- `CHECKS.json` 记录范围及未做融合、未拟合的边界；脚本是 `tools/thesis_main/analysis/summarize_admitted_space_descriptive_20261029.py`。

新增空间的难度列一律为“未分级”，不能把同一图片当前主目标的难度标签挪给另一目标。原有记录保留原标签。原答的当前目标来源难度只作为上游字段保存，本目录不用于对新增目标分层。

## 实际覆盖与需要接续的依赖

当前 `condition_classification/RAW_CONDITION_RESPONSE_RECORDS.csv.gz` 来自原 8,154 份池内记录；231 份新增作答在这个 DSTRUCT 输入中均为 0。若要把新增空间正式纳入 DSTRUCT，须先确定这些目标的难度及资格，再按对应目标参考补齐表达与参考诊断，并复核同图同行中心的分组；只改输入记录数量不能视为分类已更新。现有脚本按 `image_id,condition` 计算同行中位数，新空间与原空间混合前必须明确是否改成同目标分组，不能静默改变原模型合同。

`joint_history_classification/BEHAVIOR_RECORDS.csv.gz` 中已存在全部 231 份。Manual 224 份、Semi 4 份符合现存 V3 行为历史训练过滤；Manual 3 份不满足。已有结构行为类因此并非完全未见这些作答。当前版本这些新增作答的 `quality_usable` 均为 false，B8L2 同行残差均缺失；符合行为过滤且具有时间历史残差的为 Manual 186、Semi 2。V3 的原 `KEY` 包含 `reference_id`，同图同行对照保持目标身份。

若按新授权把这 231 份正式质量接入 V3 联合历史，应先核对新资格与目标内 Q 同行中心，随后评估人员 Q 支持、楼外折、分类及依赖选队是否变化。时间残差和既有行为特征已有部分覆盖，不应把它们全部当作新增训练数据；难度未分级也不应直接归为简单或困难。本目录只识别依赖，**没有重算这些分类**。

例如普通 Manual 的图片等权 Q：原范围 69.01（6,512 份、206 图），新增空间 56.65（227 份、28 图），合并 68.62（6,739 份、206 图）。这三个数字的空间构成不同，差异不是单独修改参考的因果效应。Semi 新增仅 4 份、1 图，不宜泛化。
