# 沿用图片难度后的依赖补算

2026-10-30。按用户确认，**每张图片一个人工难度**，沿用`v2.1/difficulty_records.json`。不同空间继续分别绑定参考、组队和评分，不为其重复评级。31池/30目标/28图的难度缺口已经解除；没有新增人工等级。

本目录是该变更的当前分析入口；父目录和作者原包保留补算前结果。原主目标8,154份、其它空间231份的身份和正式库存不变。分类方法不定案；这里更新既有候选的输入、特征及下游敏感性，不从新结果反向选择方法。

TARGET_DSTRUCT K2/K3/K4的全数据人员分组保持不变，但楼外折部分改变。K3旧/新楼外分区ARI中位数约0.946，部分折最多6名共同已知人员在最优类别编号对齐后改变。论文实验使用各自楼外标签，因此不能用全数据分组没变来推断下游都不受影响。

**半队多数规律保持。** 50个14/7事件和21个20/7事件不再满足更新标签的严格类关系，但仍是原工作分类下的真实实验。原完整结果与新合法子集并列；两者支持不同，均值差不能称为难度修订的因果效应。难度分层及质量、结构、遗漏、延伸和劳动分项见[分层](HALF_BY_DIFFICULTY.csv)、[分项](HALF_DIFFICULTY_COMPONENTS.csv)，各指标保留独立可评图数。逐事件判断见[合法性](HALF_EVENT_LEGALITY.csv.gz)，汇总见[HALF_SUMMARY.csv](HALF_SUMMARY.csv)。

固定X/Y/Z、两端均满足更新标签的背景比较也已接续：75条配对中63条可评，48图/18楼；14→20人时GA平均−1.915、GS −1.995、C−B −2.844。增加背景后换类差异平均减弱；这里包含背景嵌套与背景成员也替换两种情况，分别见[MATCHED_BACKGROUND_SUMMARY.csv](MATCHED_BACKGROUND_SUMMARY.csv)，不能全部称为纯加人效应。

**同房主要发现保持。** 更新TARGET K3的C2→C3方向10/5为322个已存在物理事件、295个六端共同可评、19图对/7楼，19/19图对C−B为正、18/19两视角均正。其事件库范围与筛选变化要明确写出，不能把322说成新采集或新融合。14/7仍10事件、6个六端可评、2图对；目标七人块固定。12/6另有86事件、67个六端可评、7图对，作为补充保留。见[双视角汇总](SAME_ROOM_HALF_SUMMARY.csv)与[逐图对](SAME_ROOM_HALF_PAIRS.csv)。

**快慢概括仍需保持条件性。** 当前TARGET K3匹配从105对变为100对。困难相对简单的慢者转折优势由+0.0198变为−0.0537（53/100正），短边优势由+0.0103变为−0.0289（55/100正）。多数正方向与弱负平均可同时存在，不写成慢者总体更充分，也不据此否定原63对固定支持中的规律。见[重算结果](speed_difficulty/CURRENT_SAME_PEOPLE_SUMMARY.csv)。

完整配比与同房配比继续回答“类别组织了多少差异、同类内部仍有多少成员波动”。对应结果见[主目标Manual](composition/primary/ALL_METHOD_COMPARISON.csv)、[Semi](composition/semi/ALL_METHOD_COMPARISON.csv)、[其它目标Manual](composition/other/ALL_METHOD_COMPARISON.csv)、[不改分类的难度分层](UNCHANGED_METHOD_DIFFICULTY_SUMMARY.csv)及`same_room_composition/`。新标签下同房主预算K3的Q构成间占比约28.19%，构成相关约−0.052，仍不支持把精确Q收益跨视角重复当作普遍结论。

`LABEL_CHANGE.csv`比较当前保存的MAIN45工作标签与本轮标签；其中原RFUSE存在历史范围差异，不能把所有差额归于难度。`RFUSE_GRADE_ONLY_LABEL_CHANGE.csv`额外固定原扩展范围，单独比较补等级的影响。各法全数据分区仅用于描述，实验一直用楼外折。

## 4. 真正剩余的缺漏

1. **用户正在做的门洞分空间评分、保留/排除双版本与GT专题**：等交付后接入；本轮对既有门洞面板的标签附属汇总不替代该专题。
2. **同用途52条旧内折预测的环境复现差异**：本轮难度映射不影响它，继续保留；当前环境的主分析和归因对照已有。
3. **最终分类之后的新选队设计**：当前是现成团队、有限面板与合法子集的完整接续；重新选队的同房ABC、大池进入策略和匹配容量/背景的Q-only额外价值，仍属于待定的新实验，不冒充本轮完成。
4. **从纯仓库全量冷启动融合重放、缓存依赖与研究台完整浏览器验收**：不由本轮定向补算自动解除。
5. **少量语义解释**：VFua-04的特定节点是否为镜面/柜体/墙体，仅在采用这一解释时才需人工；数值、票数和失败状态已有。没有新增图片难度审查任务。
