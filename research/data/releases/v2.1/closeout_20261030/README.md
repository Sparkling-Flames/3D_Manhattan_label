## 3. 门洞双版本交付后接入

用户继续制作，本轮不代筛记录、不改参考。收到材料后执行两条分开的比较：

|问题|固定|改变|必须保留的结果|
|---|---|---|---|
|核心规律是否依赖明显乱标|图片、目标、参考版本、算法与评价规则|全部记录/人工排除记录|同人数比较及各版满员；均值、低尾、失败和有效支持|
|任务目标或参考修订的影响|同一批作答或同一批团队及算法|原/修订参考；不同目标另层比较|逐原答/团队配对变化，不能混入筛人作用|

接入需有图片/池/目标ID、参考版本、记录ID与人员ID、保留/排除状态、问题证据与理由、排除单位及适用范围。若仅排除一份作答，不自动扩展为排除该人员所有记录；不同合理空间、低Q或与多数不同不直接等于乱标。

筛除后的同人数分析会改变候选成员与可行团队，需要共同支持说明；两版各自满员同时改变人数与成员，单列为实际可用人群结果。若清洗与参考同时改变，优先形成两因素交叉对照，至少保存固定参考筛人、固定作答换参考两个可识别比较。

OOS、门洞拍摄点位、参考不可见墙线与实际漏标分别解释。未核查连续视角来源时，只描述本图不可直接观察的结构。用户提到的re-annotation文献尚未确认，外部提供的近似论文不代替原文。本轮不采用该外部链接或其文献结论。
