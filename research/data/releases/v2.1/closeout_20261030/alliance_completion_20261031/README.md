## 原结论保留多少

在普通Manual主目标、排除未知类别背景变体的**205张共同可评图**中，比较全部可分类人员合并队与当图可评纯类队中的最高Q：

|指标|冻结标签|图片难度更新后的候选标签|
|---|---:|---:|
|至少一支纯类队优于全类别合并队|173/205|169/205|
|全类别合并队优于所有可评纯类队|32/205|36/205|
|全类别合并队Q减最佳可评纯类队Q，图片等权均值|−6.386|−6.051|

这里“全类别合并队”覆盖该池全部已分类人员；有未知人员的背景变体另列，不能无条件叫所有原始标注者。这里的“最佳”是事后描述，不是能预先知道的选队策略；纯类候选至少3人，且必须可评分。某类不可评分不当作零分，其状态保留在结果表。

**主要发现保留：更多人或合并全部类别并不保证优于某支纯类队。** 具体名单与局部排名有变化，205图中6图在上述比较的胜负方向上改变。它不意味着所有纯类都优于全类别，也不说明TARGET已成为最终最佳分类。

其它合法空间在24池/23张共同可评图中，至少一支纯类更好的图片数从6变7；全类别减最佳纯类的平均差从+1.200变为−0.078。该层继续单列，不并入205图主目标结论。含未知背景的2张图单列，原/新结果均未改变。

1,166项成员集合不变的联盟，其分数逐项相同。新旧对照仍分别记录参考、条件、池、类别组合、未知背景、有效人数与输出状态；原来因类别变化不再是完整联盟的旧团队保持冻结身份。
