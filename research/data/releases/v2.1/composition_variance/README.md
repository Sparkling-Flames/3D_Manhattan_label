# v2.1 固定团队构成方差

复用原231个Manual面板、40图、22楼，每面板完整枚举12选6的924队，共213,444条关联、213,442个唯一端点。只更新受参考修订影响的40,655个端点；原团队、背景和时间证据保持。未将新增参考池伪称为原有限枚举面板。

`DSTRUCT_K2`、`DSTRUCT_K3`沿用冻结v2楼外标签，`DSTRUCT_K2_V21`、`DSTRUCT_K3_V21`使用v2.1楼外重拟合标签。两组使用相同实际团队、当前评分及共同已知标签支持；旧结构粗/细分类作为原方法对照。

K3的Q构成间占比：原v2为14.3627%；仅更新评分为14.3748%；同时更新标签为13.4109%，对应构成内86.5891%。这是逐面板有限团队方差按图片、建筑聚合后的比例，不是全库质量解释率或预测准确率。构成内占比较大仍支持“相同配比下具体成员影响结果”，不构成分类无效的证据。严格ABC的替换操作效果需在独立事件结果中解释。

原4,620条逐面板统计先按原端点、原标签复现，最大误差5.69e-14；新方差分解恒等式最大误差1.50e-13。所有面板共用已知标签支持，未知团队为0。精确验收值见`CHECKS.json`。

输出字段：`PANEL_VARIANCE.csv.gz`保留总、构成内、构成间方差及有效团队数；`CONFIGURATIONS.csv.gz`保留每种配比的均值、分位数、有效与缺失数；`TEAM_CONFIGURATION_LINKS.csv.gz`保存新标签下每队配比；`SUMMARY.csv.gz`按图片后建筑等权聚合。零方差的占比为缺失；无有效时间记录也为缺失，不能显示为零方差。
