图/楼跨支持重叠，不能直接相加；完整计数见 `SUMMARY_CHECKS.json`。每个支持目录保存实际事件、指标、角色中心及同图/同楼层次汇总。端点重用40,588队，只有当前设计中未保存的158,507队按原算法计算。旧标签固定团队重评分保存在 `../event_reaggregation/`，两者回答不同问题。

`BA=B−A` 为同类成员替换，`CA=C−A` 为跨类替换，`CB=C−B` 为二者结果的有向差。`cross−within` 比较变化幅度，不等于有向质量改善；同一参数格的 `CA` 与 `CB` 也不能互换。原分项、几何距离、失败、时间、背景梯度和具体成员块波动均保存，不以Q净收益作为分类唯一依据。

`summary/METHOD_N_M_COMPARISON.csv` 保留方法、阶段、团队人数n、替换人数m以及各指标实际支持；`FAIR_ROLE_COMMON_POOL_DIFFERENCES.csv.gz` 用于角色共同图片对照；`RISK_TIME_SUMMARY.csv` 及 `ALL_OUTCOMES_*` 保留风险与非评分结果。不能只选收益最大的方法，或将不同支持的绝对均值排名当成公平优劣。

配比方差仍是另一实验：固定231面板当前K3的Q构成间占比13.4109%，描述全体有限团队的分布；本目录描述固定背景和替换操作的效果。前者不是预测准确率，后者不是全库方差解释率。
