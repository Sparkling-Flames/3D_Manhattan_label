# v2.1 当前楼外角色的顺序策略

当前V3_BEHAVIOR/V3_JOINT_QT楼外角色用于稳定重排已保存的自然基序；保持同一池、同一基础路径逐前缀配对。它们不是DSTRUCT或RFUSE标签。基础路径、抽样层和角色中心均可从 `../current_policy_design/` 回查。730,028个唯一团队中613,008个已有端点复用、116,187个按原算法补齐；833个历史延期的策略两人团队仍单列未执行。

`original_common32/` 使用原157个候选普通Manual图中四种当前角色均有效的153图。old16由原old8和后续8条构成，new16为原后续16条，pooled32为二者合并；不能解释成32名人员。`added_reference32/` 为新增参考池中四种角色共同有效的26个普通Manual图、10楼，保存first16、second16、added32；它们不是历史old/new样本。

两项主分析沿用原固定人数点支持、成对整路径统计及2,000次重抽。固定图片的路径不确定性、固定路径估计的建筑重抽分别报告；不能将二者合成一个区间。统计回执与完成状态见各目录 `CHECKS.json`。未取得该回执的目录不视为汇总完成。

`secondary/` 为258池逐角色的次要描述，包括Semi、门洞及其它范围，保留每种角色自己的有效池；原old8和新增32路径分开。N=3的原精确排列只保存6条，不能补成8条。次要范围没有额外bootstrap，不能冒充四角色共同支持的主分析。

两人独立自然路径及其单点区间位于 `../two_person_natural256/`；它们不能填入未计算的策略配对。原策略阶段从合法k≥3起，k=2保持not_executed与空值，不写作失败或零效果。当前标签重选策略与 `../policy_frozen_design/` 的旧标签固定队重评分分开解释。
