少转折数量本身由参考转折数与原答转折数共同定义，而参考转折数也是输入，因此这部分预测收益不能单独当作几何条件的因果证据。比较“几何”与“单转折数”时，少转折数量仅再改善3.89%，其配对建筑区间跨零；“三档＋几何”对是否简化的增量是另一项需要并列保留的证据。

旧来源时间仅878份／132图，新来源时间仅5005份／204图，分别建模；均为原记录的来源时间。缺失不填零，不把来源时间称为当前修订目标的精确作业时长。所有模型对每个响应采用相同有效支持。区间是5000次已保存楼外损失的配对建筑重采样，训练折互相重叠，属于回顾性比较。
