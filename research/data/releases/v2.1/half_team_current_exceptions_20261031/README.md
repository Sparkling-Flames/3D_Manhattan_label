## 2. 为什么未达到预期

每张图在`CASES_ZH.md`给出当前计权结果、几何距离、转折、三项损失、合法事件及锚点票账。以下解释按证据层次使用：

- **同类换人本身变化较大。** 当C位于A、B之间，GS恰为−|B−A|/2。这是幅度定义下的直接解释，C仍可能高于B。其它图中C高于A、B，但平均CA与CB也可能仍小于AB。
- **定位与分项抵消。** 三队可保留相同节点数，边界、方向、高度损失仍会变化。不同分项方向相反时，总Q可小幅变化；不能将节点数量相同写成输出相同，也不能把几何变化大直接写成质量改善。
- **新增结构不保证升质。** S9-09当前4个事件中，C平均增加2个有效转折，C−B约−17.498；边界损失增加，方向和高度损失降低。锚点C入选6组而A/B各4组，均有完整源环；另有近参考候选未达票。这是结构选择及分项变化的实例，不能只用“点更多”解释质量。
- **少量不升质图有不同表现。** X7-19的C−B约−0.575、平均转折不变，边界和方向损失增加；X7-07一事件可评但C−B约−3.564，另一事件C无连接，两种状态均保留。后者不能只展示可评均值。
- **通过半数门槛不等于形成完整环。** 当前保存的no_connection端点均已有已选节点位置，但覆盖全部已选节点的投影源环为0；其原生原因是`no_source_ring_covering_all_selected_nodes`。S9-12另有A/B只有3个入选节点的`below_four`事件，属于节点数量不足。两种失败不混为一谈。

**新进入清单的两张图：**

|---|---|---|---|
| 7y-26 | 89.886 / 94.546 / 96.862 | 4.659 / 4.646 | 当前仅保留一个合法事件，GS约−0.014；C继续升质，三队均6个入选组且有完整源环 |

它们不是新发现的算法失败。更新合法支持改变了图片均值；其同类改善已很明显，对称跨类平均距离未超过它。与旧36图相比，保留28图、移出8图、加入上述2图；[成员变化表](OLD_CURRENT_IMAGE_MEMBERSHIP.csv)逐图记录当前是否仍有合法事件。

## 4. 人工复核与解释边界

本轮数值关系、票数和连接状态已有直接证据，**不需要重新判图片难度，也不要求重审全部30图**。若正文进一步断言VFua-04某节点对应镜面、柜体或真实墙体，才需提供局部原图和节点号做语义判断；当前解释停在可核查的候选、支持和源环，不以尚未确认的物体语义解释总体规律。

逐事件轨迹说明算法在哪一步发生变化；它不单独识别结构能力相对历史Q的因果贡献。Q-only公平对照仍按原结论使用。研究台为自包含离线HTML；本轮程序检查与真实浏览器视觉验收分别记录。
