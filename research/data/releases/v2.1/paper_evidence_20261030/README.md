## 3. Discussion与人工审查

OOS既有独立统计可继续使用：表示约束问题与门洞拍摄点位、空间连接和目标选择分别讨论。用户在做的门洞分空间评分和完整保留/人工排除双版本，交付后按相同图片、目标、参考与指标比较核心方向、幅度、低尾和失败。筛除依据、人员名单、参考版本分别留档，不以低Q本身判定乱标。另报全可用支持，避免只报告筛查后有利样本。

GT专题区分：①跨视角推断隐藏墙线与单视角可见证据不一致；②参考实际漏标。前者需先明确任务是否要求完整空间，后者用具体遗漏核对。用户案例交付前不替其完成判断。“Re-annotation（2026）”待准确题名与原文确认后引用。

人工审查优先[30目标卡片](TARGET_REVIEW.html)。另外VFua-04 W125节点5—8需要在解释“墙体还是镜面/柜体”时查看；Q/T uNb-01、uNb-43只有要归因到真实漏墙时再审查。两类问题均不阻塞其已测质量、劳动或无连接状态。36案例里的通用人工提示不等于36个必做任务。
