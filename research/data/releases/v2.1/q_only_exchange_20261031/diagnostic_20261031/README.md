# DSTRUCT与Q的关系、不同选员事件及逐人难度画像核查

2026-10-31。本轮复核现有代码与保存结果，只做定向再聚合；没有重分类、重评分或新融合。主对照仍是父目录冻结的Q_RAW；Q_PEER作为敏感性保留。选员不同子集属于事后诊断，不替换原208事件的政策估计。

## 1. 分类是否主要区分高低Q

**当前C3与其余人员的主要分界确实高度对应历史Q，但三类不是按Q直接划出的三个等级。** 二者必须同时说明。

实际代码`research/workers/personnel_v21_reselection_20261029/classification/code/build_target_aware_candidates.py`中，TARGET_DSTRUCT采用`M_STRUCTURE_LEVEL`和`M_STRUCTURE_DIFFICULTY`两域：有效转折数、短转折边、近共线节点、未匹配参考节点比例，分别取总体、困难及困难−简单响应，共12项；逐图/参考/条件中位数中心化、域内缩放/PCA、域等权后Ward聚类。类别编号按困难转折等结构特征排序。Q和时间不进入这两域，资格门槛也不按Q数值高低划分。

**但“未匹配参考节点比例”依赖GT及9°匹配门槛，混合反映遗漏和定位。** 它及其困难响应占输入12项中的3项；这不等于它贡献了25%的聚类权重，域内PCA会重新组合特征。因此“没有直接使用Q”成立，“完全不含质量相关信息、纯粹按自由标法分类”不成立。当前TARGET更准确的解释是“结构表达及参考匹配表现的条件响应分类”。本轮没有做特征消融，不能宣称某一个特征单独造成了高Q分界。

独立复算20个本次对照所用楼外折：每折先人员等权类均值，再折等权平均。

| 工作类别 | 楼外历史原始Q均值 | 困难转折相对同图中位数 | 总体短转折边相对同图中位数 | 总体未匹配参考节点比例相对同图中位数 |
|---|---:|---:|---:|---:|
| C1 | 65.215 | −0.636 | −0.030 | +0.0506 |
| C2 | 66.389 | −0.396 | +0.009 | +0.0291 |
| C3 | 80.648 | +1.876 | +0.350 | −0.0410 |

20/20折C3均高于C2。类别间差异占人员历史Q方差的比例，20折平均63.70%（范围54.49%—65.95%）；用原始Q区分C3/其它类别的描述性AUC均值0.978（范围0.920—0.994）。AUC仅描述两组排序分离，不是新人员或目标楼预测准确率。折重复使用人员，不作20个独立实验，也不据此给出独立样本显著性。这里的63.70%是**人员历史Q**的组间方差占比，与有限配比解释团队Q的百分比不同。

C1、C2的平均Q接近，近共线残留、困难表达和参考匹配则存在不同；C3同时较多表达、较少参考匹配缺失且历史Q高。对第三方意见的判断：65.2/66.4/80.6及20/20方向准确；“并非直接按Q分档”准确，但需要补上参考匹配特征这一重要限定。“更能识别必要结构”“定位能力更好”可作为待检验解释，不从类均值直接推成因果机制。workflow用途仍需以实际选队证据界定。

## 2. 选人不同的事件到底改变什么

以下数值统一为结构方案−Q_RAW。两政策都相对于A替换7人；但它们相互比较时，35个不同选员事件**全部仅相差1人**，也就是14人队仍共享13人，20人队共享19人。这不是另外一个“两个完全不同的七人块”实验。

| 范围 | 14/7 | 20/7 |
|---|---:|---:|
| 选人不同事件／图片／建筑 | 28／16／11 | 7／7／6 |
| 类别配比相同，只换同类具体成员 | 15事件 | 6事件 |
| 类别配比也改变 | 13事件 | 1事件 |
| 两政策共同可评事件／图片 | 24／15 | 6／6 |
| Q正／负／基本相同事件 | 6／17／1 | 2／4／0 |
| 转折数相同事件 | 22/24 | 5/6 |
| 子集图片等权平均Q差 | −0.296 | −1.998 |
| 子集图片等权IoU3D100差 | −0.495 | −2.577 |
| 子集图片等权转折差 | −0.033 | −1.000 |
| 子集图片等权边界损失差 | +0.000679 | +0.012461 |
| 子集图片等权方向损失差 | −0.003743 | −0.030083 |

该子集重新进行背景→块→池→图聚合，图片内可用事件与原完整样本不同；其−0.296不能直接代替全样本+0.0619，也不能简单乘28/147还原总体。Q_PEER诊断有34个14/7不同事件、7个20/7不同事件，另见同表，不依据两个基线哪个更有利来更换主结论。

**多数差异是转折数相同下的几何变化，少数事件发生结构保留改变。** 不能因为转折相同就称几何相同，也不能因为同属C3就认为具体成员可互换。边界损失和方向损失的平均方向不同，不将“几何改善”压成一个无定义的结论。

状态也确实改变：14/7不同选员子集中，1事件仅结构方案可评、1事件仅Q-only可评、2事件都不可评；20/7另有1事件仅Q-only可评。具体状态见`DIFFERENT_SELECTION_EVENTS.csv`，未给不可评端点填0。

## 4. 对分类与50%换人结论的影响

- **保留：** 更新工作标签的14/7严格合法支持，67共同Q图上同起点跨类额外幅度+4.037、对称额外幅度+3.767、C−B+6.380。它测得的是这批不同人员块的综合作用；不是本轮同政策之间仅换1人的效应。
- **明确收窄归因：** C2→C3既改变结构表达，也换入整体历史Q较高的人。不能把上述约6分全部称为“与质量水平无关的结构类别贡献”。Q-only公平对照已显示，在这些背景下直接按历史Q选人可达到近似平均质量。
- **保留50%的设计意义：** MV50为≥50%，七人块可独自达到14人团队的候选门槛；达到票数只是结构保留的条件之一，具体候选对应、定位和连接还影响输出。一个成员就能改变结构或可评状态，说明背景和临界支持值得解释，不是要求全部七人始终画同样内容。
- **不急于换方法：** 当前结果支持“结构表达与匹配表现的解释分类”，同时揭示高结构类与高Q的高度关联。最终比较DSTRUCT/RFUSE等候选时，优先看原答解释、不同成员和背景下的输出差异；不再用“换入C3升质”单独证明分类优于Q选人。本轮没有新增参数搜索或宣布最终分类。

## 6. 复现、字段与边界

脚本：`tools/thesis_main/analysis/diagnose_v21_structure_q_20261031.py`。命令：`python -X utf8 -m tools.thesis_main.analysis.diagnose_v21_structure_q_20261031`。4项测试通过：`python -X utf8 -m pytest tests/test_v21_structure_q_diagnostic.py -q`。

`DIFFERENT_SELECTION_EVENTS.csv`将父表配对结果与逐事件具体移出/换入人员、类别和原答连接；`*_delta`仍是结构−Q-only；`centroid_distance_h`为两融合质心的欧氏距离，以相机高度归一化，不是米。事件中非Q指标仍按自身非空值聚合，分母见summary。`removed_raw_*`/`added_raw_*`在Q_RAW中各对应1个人；Q_PEER若多人不同则为所涉人员均值。

`WORKER_DIFFICULTY_CURRENT.csv`中`Q_record_mean`为记录均值，`Q_image_mean`为先同图目标等权再图片等权，`relative_rank`为同图/参考/条件内归一化质量排名再按图片平均。当前普通Manual每人每图恰有一份归属目标记录，两种Q均值相同；仍保留目标身份，不跨空间混合评分。难度偏好是同一人员困难/非困难的相对排名差，而非Q分数差。

未改参考、原答、图片难度、分类、选员、融合或协议；没有进行因果分解、特征消融、重新选型或任务分配验证。所有复算来自本地实际数据，不沿用第三方摘要作为数值真源。
