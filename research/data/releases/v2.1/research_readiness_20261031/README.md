## DSTRUCT与RFUSE：沿用v2的一正一反研究关系

采用职责已确定，沿用当前图片难度更新后的楼外标签，不重新调参或重贴旧实验标签：

|方向|研究起点与作用|回答的问题|
|---|---|---|
|DSTRUCT正向|从原始标注的转折、短结构、近共线表达、参考对应缺失及难度响应形成类别，再通过配比和换人观察共识变化|人怎样标，这种标法差异怎样影响共识？|
|RFUSE反向|从人员参与不同自然随机团队时的融合几何响应构造响应角色，再回到人员块、背景、票数、定位与连接解释输出|哪些人员组合怎样改变共识，原答差异经过融合后怎样表现？|
|JOINT/OPPJOINT联合画像与用途|组织结构、质量、劳动等联合表现，用于人员画像及进入顺序相关研究|人员有哪些联合特征，怎样组织参与顺序？|

DSTRUCT与RFUSE是一正一反的互补解释，不是互相竞争的替代方案，也不是将RFUSE降为可有可无的附录。正反指研究从原答特征或融合响应出发的方向，不表示RFUSE是算法逆运算或已识别个人因果贡献。RFUSE角色依赖融合算法；几何响应类与含Q响应类仍按实际版本分别说明。DSTRUCT不直接输入Q，但包含参考匹配信息。

v2已明确“主要解释方法采用DSTRUCT_K3；两套融合响应类是核心效果对照”，并以B6-47的背景票数与响应核心案例说明二者分别回答“怎样标”和“怎样影响共识”。v2.1继承这条研究组织关系，旧成员、参数和效应数字不直接搬为新版。来源：[v2分类职责与解释](../../../../workers/personnel_classification_guide_20261025/README.md)。JOINT的既有画像/小池结果照实保留；新大池进入策略仍按用户安排暂缓，职责采用不等于新实验已经完成。
