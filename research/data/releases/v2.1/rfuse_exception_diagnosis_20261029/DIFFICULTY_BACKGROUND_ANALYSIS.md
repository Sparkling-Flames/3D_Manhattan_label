# DSTRUCT 反例中的难度、结构条件与共同背景

2026-10-29，基于 v2.1 已保存结果独立重聚合。不改标签、参考、评分；没有新增融合。

结论：**反例没有集中在困难图。当前18人换7人的7张反例中，5张跨类与同类差距不足1分；在固定7人替换块的背景路径里，同一图片的差距正负也常随背景改变。** 所以不能把负 gap 简单归因于“图片太难”，也不能据一张负 gap 图否定整套分类。

本文 `gap=跨类平均绝对Q变化−同类绝对Q变化`。负 gap 的意思是该条件下同类换人的 Q 变化更大，**不是**换入目标类必然降质。下文1分只用于描述差距大小，没有把它当显著性门槛。

## 3. 同一图片沿10—21人背景路径会不会翻转

116条固定替换块路径均登记了总人数10—21的12个位置，共1,392条路径事件。替换块X/Y/Z固定，三队同时添加共同背景，替换比例从70%降到33.3%，MV50门槛由5票升至11票。

直接读已有逐人数可评汇总，58图中34图 gap 曾正负翻转。但其中少数路径有不可评位置。为避免比较集合随人数变化，本次进一步固定 **全12点ABC均可评的108条路径**：

- 覆盖55图；固定这些路径再逐图平均，**30/55图** gap正负翻转。
- 其中 **10/55图**同时出现低于−1和高于+1的gap，属于有明显数值幅度的翻转。
- 如果进一步只取每图两条路径均完整的53图，结果仍为 **29/53图**翻转，**9/53图**两侧都超1分。
- 因此背景改变确实能伴随同图比较关系改变，并非全部来自零附近抖动或缺评分分母变化。

这条路径同时改变背景成员、总人数、替换比例和门槛，不能单凭此表把翻转归因于其中某一个。归因到具体投票结构需要结合对应节点/连接票账；当前统计无需为此重跑融合。

## 4. 可采用的解释

分类揭示的是在给定方向和团队背景下，多数图片存在的构成差异。图片难度能帮助描述何处更容易出现反例，但当前证据显示，**反例也会出现在四转折、无短边、无几何自遮挡的普通图里**。类别内部具体成员的差异，以及背景改变后的结构保留和位置融合，同样需要观察。

本次不把RFUSE小核心的机制结论套给DSTRUCT，也不把历史冻结路径记成当前新分类的完整验证。单图显著性未估计；这里报告完整分母、真实幅度和固定路径复核结果。
