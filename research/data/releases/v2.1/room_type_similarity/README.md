# v2.1 同用途不同房间复算

使用既有 `room_type_similarity_20261027` 图片预测、人员画像和保护一般历史的用途增量方法，整栋建筑外留出；不重跑融合、不拟合新分类。`inputs/` 为隔离后的 v2.1 适配输入；原答坐标按 object_id 复用原冻结输入，参考/绑定/质量/难度来自 v2.1。脚本为 `tools/thesis_main/analysis/rebuild_v21_room_type_20261028.py`，各 part 分别为 inputs、image_prediction、personal、protected、summary。人工用途关系保留旧来源；建筑与原答身份不因更换参考而改写。

## 支持和数据变动

普通 Manual：原177图、22楼、5719原答均仍有支持；v2.1新增29图、11楼、793原答，合计206图、22楼、6512原答。原161图/21楼跨楼重复用途固定集保留；v2.1重复用途为190图/21楼、6029原答。图片支持由 `inputs/SUPPORT.csv` 保存。新旧结果中的原177图仍以各版本各自全部合格训练数据重新拟合，故不是隔离单一变化来源的控制实验；新增图不能作为 v2 的已存在结果。

共复用10439个原答几何，7951条已有参考诊断；2480条重新计算参考相关诊断，8条无可用绑定参考。重新计算292个参考的几何特征（其中部分旧参考原特征文件未覆盖）；用途标签未修改。新Q/D10及资格、难度和实际参考从v2.1读取。输入检查与精确计数见 `INPUT_CHECKS.json`。

## 证据与界限

- `results/image/LOBO_IMAGE_PREDICTIONS.csv.gz`：12方法×2指标×206图；模型、内折选择、分支持汇总和建筑重抽见同目录 `LOBO_*`。预测目标建筑未参与该折训练。
- `results/personal/`：Q、D10、转折的逐人楼外预测、折内选择和汇总；D10沿用Q选出的正则强度。`results/protected/`：独立用途偏差、逐折内层选择和基线核验；不将人物和用途作用合为统一惩罚。
- 旧177图和新29图的各自结果使用同一个v2.1全支持模型；模型训练同时受到新质量、资格、参考和pa4难度变化影响。无法以该对照区分各因素贡献。
- 主线程已从当前原答独立核对4944条图片预测的目标/误差与90150条三图Q对照，后者最大差8.53e−14；训练均值检查确认目标建筑未参与该折训练，见`INDEPENDENT_CHECKS.json`。该核对不代表外部验证或独立重写模型拟合。已有代码强度、种子和支持规则保持；未运行旧口径训练门控、Semi次要结果、时间专题或案例渲染。
- 同房不同视角与同用途不同房间是不同问题；本页只报告后者。无论坐标或分数缺失均不补零、不将不可评分解释为融合失败。

## 共同人员三图对照

沿用相同源建筑、同难度与参考几何匹配，要求目标图与两张来源图至少3名共同人员：4975个事件，覆盖190张目标图、21栋目标建筑，来源153图、17栋、58人（共同人员中位12人）。按目标图等权，Q共同人员均值差的同用途减不同用途为 +0.858，68图为负、122图为正；按原方法2000次建筑重抽区间约 [−0.949, 2.397]，跨过0。该对照不支持据此断言同用途更相似或更不相似。具体事件、各制度和指标的结果分别在 `results/image/MATCHED_THREE_IMAGE_EVENTS.csv.gz`、`MATCHING_COVERAGE.csv` 和 `MATCHED_CONTRAST_SUMMARY.csv`。

## 原有范围与扩展范围的归因对照

[补充对照](reference_only_attribution/README.md)固定原161张评价图和当前v2.1运行环境：原177图按原内折流程选参，几何/几何+用途Q MAE为4.6574/4.4837；全部206图为4.5181/4.6811。用途增量由+0.1736变为−0.1630，配对变化−0.3367，建筑重抽95%区间[−0.666,−0.077]。此变化包含扩展训练图片及随之变化的模型选择；固定旧超参的对应增量为+0.3366与+0.1230。因而不能把方向反转简单归因于顶高更新，也不能据此否定原始同用途关联或人员分类。区间固定已拟合楼外预测，没有每次重新拟合。

当前环境重跑206图的412条预测、308条候选误差均复现。历史v2的内折选参直接重跑有52条预测不一致，历史与当前scikit-learn版本不同，具体原因未确定；原旧折配置固定后的354条预测仍复现至2.99e−12。该限制保留，不影响上述同一当前环境下177/206范围对照。
