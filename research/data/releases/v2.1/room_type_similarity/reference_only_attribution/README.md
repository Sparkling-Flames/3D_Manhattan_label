# 同用途图片预测：原有图片与新增图片的归因对照

固定原有 177 张普通 Manual 图片的身份，并在原先 161 张跨建筑重复用途图片、21 栋建筑上评价 Q 平均绝对误差（MAE，越低越好）。几何和几何＋用途使用同一原有候选模型族，目标建筑不参与该折拟合。两种对照分别为：固定 v2 实验各折已选定的模型和超参数；按原内层建筑分组交叉验证重新选择模型和超参数。重新选参沿用相同的 7 个候选、5 折和 MAE 选择规则，没有新增候选，也没有新增融合、评分或图片抽样。

| 输入与训练方式 | 几何 MAE | 几何＋用途 MAE | 加入用途的 MAE 改善 |
|---|---:|---:|---:|
| 原 v2 数据，177 图，旧折超参数 | 4.5673 | 4.1882 | +0.3791 |
| 冻结原 v2 预测，仅换 v2.1 实际值 | 4.5623 | 4.1832 | +0.3791 |
| v2.1 数据，原有 177 图，旧折超参数 | 4.5339 | 4.1973 | +0.3366 |
| v2.1 数据，原有 177 图，原内折流程重新选参 | 4.6574 | 4.4837 | +0.1736 |
| v2.1 数据，全部 206 图，旧折超参数 | 4.6399 | 4.5169 | +0.1230 |
| v2.1 数据，全部 206 图，原实验内折重新选参结果 | 4.5181 | 4.6811 | −0.1630 |

最后一行是已有结果，不是本次固定超参数模型。固定超参数下，177→206 图使用同一 v2.1 数据版本和相同目标图，只改变楼外训练中可用的图片范围；新增图属于目标建筑时仍从该折训练中排除。用途增量变化为 −0.2137，按同一目标图片配对、整栋建筑重抽的 95% 区间为 [−0.3953, 0.0158]。固定超参数的 206 图增量本身为 +0.1230，区间 [−0.1617, 0.5427]；两者均包含零。

沿用原内折选参流程时，177→206 图的用途增量从 +0.1736 变为 −0.1630，配对变化为 −0.3367，建筑重抽区间 [−0.6662, −0.0769]；177 图增量本身的区间为 [−0.0800, 0.4489]。这个比较包含训练图片范围变化及其引起的内折选参变化；固定配置的对照则不包含后者。建筑重抽基于已拟合的楼外预测，训练折彼此重叠，属于回顾性敏感性分析，不是重抽后重新拟合模型。

原 177 图的 v2→v2.1 更新不仅包含参考和评分，还可能包含资格、特征及已确认难度的更新，因此这一步不是单独操纵参考的因果实验。206 图的原有重新选参结果同时改变折内模型选择；固定旧超参数的 206 图对照表明，训练范围与选参对比不能混为一个单一原因。所有比较均为内部楼外模型误差差异，不是原始同用途关联，也不是人员分类有效性的检验。

环境复核：当前运行使用 scikit-learn 1.2.2；原 v2 记录的版本为 1.8.0。当前环境重跑 v2.1 全 206 图的原选参流程，412 条预测及 308 条候选误差均与已存结果一致（最大差均小于 1e−8），因此本次 v2.1 177→206 的选参对照具有同环境复现支持。但对原 v2 数据直接重跑内折选参时，354 条预测有 52 条与原保存结果不同，308 条候选误差均有差异；差异原因尚未确定，不能仅归因于版本变化。固定原折配置时，354 条预测仍可复现。详见 `NESTED_ENVIRONMENT_CHECKS.json`；不把跨环境选参差异解释成数据更新的效应。

原 v2 的 177 图、两方法共 354 个预测重新拟合后与冻结预测最大误差为 2.99e−12；旧折配置、目标建筑隔离、同图支持和误差计算通过定向检查。`MODEL_COMPARISON.csv` 为同表结果，`PURPOSE_INCREMENT.csv` 为各条件内增量与建筑重抽，`PAIRED_INCREMENT_CHANGES.csv` 为同图配对的条件间增量变化，`PREDICTIONS.csv.gz` 和 `FIXED_FOLDS.csv` 保存逐图预测及固定折配置；`NESTED_FOLDS.csv`、`NESTED_TUNING.csv`、`NESTED_INNER_SPLITS.csv` 保存新 177 图选参过程，`CHECKS.json` 保存支持与复现计数。
