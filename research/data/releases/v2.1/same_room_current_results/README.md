# v2.1 当前同房共同人员与换类结果

有限面板、大块换类、几何距离、成员敏感性、历史Q共同支持及背景/人数路径的统计均已完成。当前关系入口为227对：原155对保留，另接入72对既有人工采用的直接关系，其中9对范围可比。没有使用关系传递闭包，也没有把新出现的OOS待裁定关系升级为主分析。

有限设计中有217对进入2,659个实际可行面板，涉及127图、19楼；当前结构标签及原有面板团队身份核对不变。当前联合Q历史标签已更新。92,342条成员团队关联对应182,555个端点；主预算replicate0共542个面板。响应分解108,094行，源视角转移111,020行。精确变化比较保留19,972个有限分层、2,759,767个比较事件和4,412条候选案例。普通范围与其它采用状态分别报告。

大块设计为62,964个双视角ABC事件、310,709个唯一端点、377,784条端点引用，缺失引用为0。六臂Q共同可用56,673事件，时间共同可用28,437事件，Q/时间联合23,430事件；Q不可用端点6,595个，不能补零。377,784行AB/AC/BC角点比较全部生成，复用保存的团队几何，没有为此新增融合。

固定A与固定XYZ路径分别保存12,492和22,074个阶段转移，共34,566个；质量比较要求两阶段×两视角×ABC共同有效，Q共同支持29,032、Q/时间联合11,460。固定XYZ路径仍改变实际背景成员，不能当作只改变单个抽象比例的干预。

来源与读取：

- `finite/response/`：构成和成员方差、跨视角关联及源到目标的比较。
- `finite/exact_changes/`：同构成换成员和混合类别块的有限比较，保留原阈值及敏感性。
- `large/results/`、`sensitivity/`、`geometry_summary/`、`history_q/`、`anchor_paths/`：原六步分析结果和回执。
- `../same_room_current_extended_design/PANELS.csv`与`../same_room_current_large_design/STRICT_ABC_EVENTS.csv.gz`的`support_origin`区分原关系和新增既有关系；大块事件结果保留该列，有限面板结果可按panel_id连接。合并范围的总体值不冒充固定原155对的比较。

旧设计同队重评分见 `../same_room_frozen_design/`；原1954面板当前标签分析见 `../same_room_current_labels_results/`。本目录新增可行面板及当前联合标签选队后的结果与它们分开。角色、空间、几何机制与质量方向均应结合看待，不只统计Q提升比例。
