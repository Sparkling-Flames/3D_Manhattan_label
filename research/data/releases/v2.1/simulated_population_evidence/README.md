## 先看配比分布，再看实际替换

Manual主目标包含231个固定有限面板、40图、22楼，213,444个面板—团队关联；每面板固定背景和12名可变人员，完整枚举12选6的924队。45配置共同已知域为182面板、38图、22楼、162,708个团队关联，其中Q可评161,580条。它是这批已登记有限空间的完整枚举，不是每张图全部人员的所有组合。

同一共同已知域上的Q构成间方差占比，按源表的面板→目标→图片→建筑汇总方差后取比：

|分类|Q构成间方差占比|
|---|---:|
|OPPJOINT K3|11.13%|
|OPPJOINT K4|12.85%|
|TARGET_DSTRUCT K3|14.92%|
|RFUSE_GEOM K2|6.34%|
|MSDGEOM_SCOPE K4|17.87%|
|V3_JOINT_QT粗类|18.28%|

这些数值描述类别配比组织了多少有限团队差异；余下部分是同配比内的成员波动。它们不是质量提高比例，也不是预测准确率。OPPJOINT的已验证换人用途不等于它必须在全部配比指标中最高；V3、结构、边界和融合响应分类的不同用途均保留。嵌套细分会机械增加样本内构成间占比，须同时看格内团队数、分布及实际替换。

配比格展示均值、分位数、极值、SD/IQR及有效队数，并与失败/不可评分母一起读取。单例格无法估计格内成员波动。质量、几何和来源匹配时间分别保留有效支持；不把缺失填零。Manual主目标、其它合法目标以及Semi分开呈现，未知正式难度不复制另一个目标的标签。

## 换人链条控制了什么

|环节|固定什么|改变什么|主要读数|
|---|---|---|---|
|严格ABC，含半数及超过半数|同目标、每队人数n、背景D、替换块大小m|同类X/Y与跨类Z|同类/跨类幅度、C−A、C−B及实际支持|
|固定原A扩大m|同一个原团队A、n、登记块序列|替换人数m，D随m相应变化|C和B分别变化，及净差变化|
|固定XYZ改背景成员|n/m和X/Y/Z|同规模背景D的实际成员或类别席位|背景对C、B和净差的不同影响|
|固定XYZ增加人数|替换块及其人数m|嵌套背景D与n、投票门槛|同一块在不同人数中的条件作用|
|较大团队直接AC|声明方向、目标和实际团队设计|A到C的人员调整|C−A、分项、几何、时间和状态；不补造同类B|

例如OPPJOINT的20人队m2→6在49张共同可评图上，C平均提高2.398分，B提高2.301分，净增量0.097分，38/49图净增大。固定六人块从n12加背景到n20时，在17张共同图上净差却平均减少2.567分。两项改变不同，不能合成“换得越多／人数越多必然更好”的规律。

## 各分类的统一证据要求

每个配置都以同一表头查看：实际标法与成员来源、Q及分项、几何、来源匹配劳动、输出状态、正式难度与结构条件、正向支持和反例。结果表保留方法、目标范围、方向、n/m、图/楼/团队分母和源表路径。已有原答可追溯与已有精讲机制案例分开；某配置未进入重点扩展不等于其广筛没有结果。

失败、完整输出不可评、单指标缺失分别沿用实际字段并解释。方法自己的有效范围与共同范围分别呈现，不能直接按不同支持的均值排序。多数方向、平均幅度和反向尾部共同报告；例子解释机制，不替代总体统计。

## 是否需要新增实验

现有数据已经覆盖配比、具体成员、半队/更大块、固定原队、背景和直接AC。应先用这套已存证据回答当前“不同人员组成怎样改变融合结果”的主问题。本轮完成整理后，新增实验仅针对尚未被现有设计回答的主张：

- 若要主张OPPJOINT优先进入在大人员池全过程更有效，才需要该分类的大池策略；现有换人结果和历史V3策略不能代替。
- 若要主张按OPPJOINT重新选出的同房严格ABC可跨视角重复，才需要新选队设计；已有OPP固定面板重聚合可作为前置证据。

这两项不是采用现有模拟人群结论的前提，本轮未运行。各模块的复算与展示检查以实际CHECKS文件为准；源包归档检查不冒充全部原生融合重放。
