## 如何从一个配比格找到所有实际成员

1. 在 `CONFIGURATION_INDEX` 中确定 `dataset + method + panel_id + support + class_counts`。C1/C2 等编号属于该建筑外折，不能跨楼按编号合并为永久角色。
2. 用同一键在 `KEY_DISTRIBUTIONS` 查均值、分位、极值和格内有效团队数。需要其它指标时读取该行 `source_file`。
3. 在 `SOURCE_INDEX` 查成员路线。其它空间直接使用 `team_vectors_path`。原主目标采用无损紧凑三表：按 `team_link_id` 连接 index/codes，再以 `method + vector_code` 查 book；码 0 是未知，不是一个新类别。
4. 根据配比向量和支持域筛出 `team_key`，连接 `members_path` 取得全部人员，连接 `endpoints_path` 取得该队保存的 Q、几何和记录时间。面板背景及变量池在 `panel_path`。

共有 159,943 条“方法×面板×支持域×配比格”记录；其中 Manual 原主域 132,282、Semi 原主域 7,355、其它 Manual 20,300、其它 Semi 6。完整源分布共 7,388,267 行，各行还区分指标和时间来源；这些行数不是互不重复的人群数量。索引保留全部格，关键分布仅抽取三项指标以便读取，所有其它指标均有可定位源表。

## 分布、失败与复算边界

格内 `teams=valid_teams+missing_teams`。均值和分位只使用该指标有效团队；失败或未知时间不记零。只有一个有效团队时，`sd/iqr/range` 保持缺失，不能把它当成稳定。零总方差面板的解释比例为缺失，也不能当作 0% 或 100%。`failed_teams` 继承 `failure=1-complete_evaluable`，表示完整输出不可评；评分状态和几何状态仍在原端点表，不能一概称原生融合失败。

记录时间须全队可用且秒数为正，并保留单一来源。包含多个来源的 `time_source_kinds` 不混成可比时间。03A 的源材料曾修正时间宽表的来源列；这里直接读取保留 `time_source` 的长表，不沿用合并来源的旧列。

复算从保存的成员和正确楼外标签重新形成每个完整团队向量，核对背景＋变量向量、每格条件组合数，再从保存端点独立计算三项关键指标的逐面板组间/组内方差和逐格分位，并与交付源表逐键比较。汇总遵循面板→目标池→图片→建筑等权，最后相除；不平均逐格或逐面板比例。其它指标的完整来源已读取登记，但不宣称全部 47 指标都做了独立数值复算。
