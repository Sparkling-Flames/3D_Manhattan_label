# 已有模拟人群的换人证据链（v2.1，2026-10-29）

当前数据支持按条件报告的多数规律：一些楼外历史角色之间的人员替换，在多数图片上提高融合质量；替换比例、背景人员及原团队规模会改变收益。这里把半数与超过半数替换、固定原团队扩大替换人数、固定替换块改变背景或人数、较大团队直接 A→C 连在一起。它们回答不同问题，不合并成一个方法排行榜。

本目录只读取已交付的真人原答、分类标签、注册事件和保存端点，重新核对身份与关键统计。没有重新分类、重新融合或新增模拟实验。03 阶段完整配比由本证据总入口的构成模块解释；本目录主要连接 05 全局广筛、07 重点与规模扩展以及 06 机制实例。

此处的 45 配置是 Manual 分类的统一换人矩阵；`condition=semi` 行仍保留其原有类别来源，不自动当成 Semi 自身分类。Semi 自身四种分类的完整配比及八维来源请从[构成证据入口](../composition/README.md)和[构成源索引](../composition/SOURCE_INDEX.csv)读取。它们未设计成与 Manual 45 配置相同的一套 ABC 广筛；这是研究设计不同，不能标为“证据缺失”而无声删掉。

## 先看覆盖，再看结论

- [45 配置证据矩阵](METHOD_EVIDENCE_MATRIX.csv)：每法同样列出实际标法、质量、质量分项、几何、劳动、失败/不可评、难度和反向实例；还列出半数、超过半数、固定 A、背景、人数路径与直接 AC 的实际覆盖。
- [八维覆盖明细](METHOD_DIMENSION_COVERAGE.csv)：360 行，分别给注册事件、可评事件、可评图和楼、缺失数、字段及来源。`available` 表示证据存在，不表示效果有利。
- [逐 n/m 的实际多维数值](ALL_DIMENSION_N_M_RESULTS.csv)：保留每配置、条件、范围、角色方向、n、m 下的 Q 分项、几何、匹配来源劳动和失败/不可评统计。Q 主结果及分母已独立复算；其他维度为明确标注来源的交付汇总，未声称逐项全部重新计算。
- [正式难度数值](FORMAL_DIFFICULTY_RESULTS.csv)、[结构条件数值](STRUCTURAL_CONDITION_RESULTS.csv)：保留具体均值、有效图数、正向图数和严重损失计数；正式难度未知不改填结构条件。
- [所有环节条件汇总](CHAIN_SUMMARY.csv)：各环节独立一行条件，保留图片及建筑支持，空字段表示该设计没有那个比较。
- [完整检查记录](CHECKS.json)与[源文件索引](SOURCE_INDEX.csv)记录本轮实际检查的边界。

45 是配置数，含 K 值及等价分区。按所有折的人员分区逐一比较并忽略类别编号，共有 44 套不同的完整分区轨迹；`RFUSE_GEOM_K2` 与 `TARGET_RFUSE_GEOM_K2` 全折等价。单折还有其他等价配置，不能把 45 个数当作 45 种完全独立的思想。

05 的设计 frame 选中 100 池、84 图、17 楼；实际产生严格 ABC 事件的是 88 池、78 图、17 楼。后者有 69,485 事件、142,270 个去重标量端点。实际广筛范围不是全部 225 个原主目标图片的穷尽搜索。每种配置的覆盖不同，矩阵保留实际计数。

## 1. 半数和超过半数替换已有直接证据

令 A=D∪X、B=D∪Y、C=D∪Z，X/Y 是同源类中互斥的两块，Z 是目标类块，D/X/Y/Z 全部互斥。各队人数 n，替换块人数 m。已有结果不限于换 5 人：

| 广筛切片 | 条件行 | 注册事件 | 配置覆盖 | 实际 n/m |
|---|---:|---:|---:|---|
| 恰好半数 m/n=0.5 | 813 | 10,387 | 45 | 4/2、8/4、12/6、14/7 |
| 超过半数 m/n>0.5 | 575 | 3,383 | 45 | 含 10/7、12/8；小池含 3/2、3/3、4/3、5/3 |

完整明细为[恰好半数](EXACT_HALF_CONDITIONS.csv)、[超过半数](ABOVE_HALF_CONDITIONS.csv)和[全体 n/m](GLOBAL_ALL_N_M_CONDITIONS.csv)。这些计数保留 Manual/Semi、原主目标/其他合法目标以及不同角色方向，不能跨行相加成为“独立图片数”，也不能把小池结果当成大团队证据。

重点扩展有更强的指定方向覆盖；下表的正向是各图平均 C−B>0：

|---|---:|---:|---:|---:|---:|
| OPPJOINT_K4，Q 历史角色 1/4→4/4 | 12/6 | 172 / 56 | 56 | +8.05 | 52/56 |
| DSTRUCT_K3，结构角色 2/3→3/3 | 14/7 | 170 / 72 | 71 | +6.55 | 66/71 |
| TARGET_DSTRUCT_K3，结构角色 2/3→3/3 | 10/7 | 192 / 85 | 85 | +8.32 | 78/85 |
| TARGET_DSTRUCT_K3，结构角色 2/3→3/3 | 12/4 | 968 / 179 | 178 | +5.23 | 153/178 |
| OPPJOINT_K4，Q 历史角色 1/4→4/4 | 20/5 | 378 / 88 | 88 | +3.28 | 83/88 |

来源为[重点全部条件](FOCUSED_ALL_N_M_CONDITIONS.csv)。12/6 和 14/7 是半数替换，10/7 超过半数；12/4 和 20/5 分别回答反推结构与较大背景下的小块替换。它们各自支持多数规律，不能互相冒充。

OPPJOINT 12/6 的同类幅度为 |Q_B−Q_A|，跨类幅度为 (|Q_C−Q_A|+|Q_C−Q_B|)/2。共同可评的 161 事件得到等图平均 4.03 和 10.02，47/56 图跨类幅度更大；C−B 的 165 可评事件得到 +8.05，52/56 图正向。两种支持分母和含义不能混写。

本轮用实际 05B frame 和实际 05A 事件图片名单分别核对了“广筛外”身份，两种判定在重点 56 图上完全一致。30 图不在实际广筛图集中，28/30 图 C−B 正向，等图平均 +6.69；详见[逐图 frame 核对](OPPJOINT_12_6_SCREEN_FRAME_CHECK.csv)。这是同一研究数据上的扩展证据，不改称新独立人群的外部验证。

## 2. 固定原团队 A，扩大 m：已有到 8 人的路径

[实际路径表](FIXED_A_ACTUAL_PATHS.csv)逐路径记录原队固定、每个真实 m、最小/最大替换数和是否达到/超过半数。OPPJOINT_K4、OPPGEOM_K3、TARGET_DSTRUCT_K3 都有以下实际规模：n=12 的 m 覆盖 1–8，n=20 覆盖 1–7，n=26 覆盖 1–4。不是每图都有这些全部 m，须读具体路径及其容量。

共 1,947 条固定 A 路径、10,184 对 m 变化。X/Y/Z 使用注册的嵌套前缀，未替换的 X 仍留在 D 中。因 A 固定，能直接问“同一原队多换人是否进一步改变质量”。在 B_small/B_large/C_small/C_large 四端点共同可评后，分别计算 ΔC、ΔB、Δ(C−B)=ΔC−ΔB。

## 3. 固定 X/Y/Z，改变背景 D 或团队人数 n

[固定 XYZ 改变背景](FIXED_XYZ_BACKGROUND_CONDITIONS.csv)共有 3,252 对，n、m 和替换块不变，比较较低/较高目标类背景席位。它直接表明已有背景会吸收或改变换类收益：OPPJOINT 12/6 在 25 个共同可评图中，ΔC≈+0.08、ΔB≈+1.10、Δ(C−B)≈−1.02，仅 5/25 图净增量为正；20/5 的净增量约 +0.05，27/64 图正向。这并不推翻原先 C−B 的多数改善，而是说“再增加目标类背景”不保证继续放大它。

[固定 XYZ 嵌套增加 n](FIXED_XYZ_NESTED_N_CONDITIONS.csv)共有 46,851 对。这里 X/Y/Z 完全相同，D 仅新增人员，A/B/C 同时扩队。OPPJOINT 的 Q 历史角色 1/4→4/4、m=6、n12→20，在 17 个四端点共同可评图上，ΔC=−3.40、ΔB=−0.83，净增量 −2.57，5/17 图为正。TARGET_DSTRUCT 的结构角色 2/3→3/3、m=7、n10→18，18 图的净增量 −1.07，5/18 图为正。

因此可说已有数据中替换块相同、背景扩大时收益可能减弱；不能只拿不同 n 下不匹配的均值作证明。人数变化同时增加真实背景成员并改变投票阈值，当前路径没有把这两个机制完全隔离。

## 八维证据怎样追到真实原答

[每配置原答案例](METHOD_ORIGINAL_CASES.csv)为全部 45 配置各选取正向与非正向 C−B 的真实已登记实例，共 90 行。选择是在各符号组中取接近中位数的事件，保留原方法、角色方向、范围、n/m、目标、A/B/C 人员、对象 ID 及端点键。它是可检查入口，不是对各法收益的统一排名；反向角色自身的负值不能冒充推荐方向的失败率。

[链条代表实例](CHAIN_CASES.csv)把固定 A、固定 XYZ 背景、固定 XYZ 人数及直接 AC 的真实正/非正实例连到变化前后的团队原答。[已绘制机制案例](PREPLOTTED_MECHANISM_CASES.csv)保留原 06 案例身份。没有单独绘制机制图的方法仍有完整的楼外名单和真实原答，这是展示缺口，不是标法研究缺失。

原答读取方式是打开行中的 `original_snapshot`，按 `pool_id` 找到 `images` 元素，再按 `worker_id` 或 `object_id` 找到 `records`。其中的 `points` 是该目标下的预处理真实标注，`reference` 是该池评价参照。对象 ID 由这两份快照的人员映射恢复，案例不会将其他分类的方法结果重新贴标签。

难度维也有具体数值，不能只写“有难度数据”。例如广筛 OPPJOINT 12/6、Q 角色 1/4→4/4 的 C−B 在简单/中等/困难分别为 +6.60、+5.58、+17.69，正向图为 11/11、7/9、3/5；困难层的幅度 gap 只剩 2 个三端点共同可评图。详细结果及有限独立复算见[难度重点核对](DIFFICULTY_KEY_CHECKS.csv)。不能从困难层较高均值直接宣称难图更受益，也不能因有负图取消其条件内结果。

## 计算和字段合同

事件先在目标池内平均，再将同图池等权聚合，最终图片等权；建筑均值在图片均值上再按建筑聚合。所有条件固定 `method + condition + scope + role_direction`，并加该环节的 n/m 或变化端点。没有跨 Manual/Semi、主目标/其他目标、角色方向和设计阶段混算方法优劣。

- `registered_*`：注册总数；`*_valid_events/images/buildings`：该指标自身的有效分母。有效图不等于原始总图数。
- `net_CB`：Q_C−Q_B；`change_CA`：Q_C−Q_A。它们不强制 A/B/C 三者同时可评。
- `within/cross/amplitude_gap`：三端点共同可评。`cross=(|C−A|+|C−B|)/2`，`within=|B−A|`，gap=cross−within。
- `delta_C/delta_B/delta_net_CB`：前后四个 B/C 端点共同可评；最后一项严格等于前两项之差。它表示增量，不是变化后最终 C−B。
- `positive_images`：该图平均值严格大于零。损失分项和劳动时间的正值不自动表示好，须按变量意义解释。
- `A/B/C_failed`：交付分析中的缺 Q 标志；`incomplete`、几何状态及不可评原因另列，不把所有缺 Q 叫作同一种融合失败。源统计中的 failure-or-loss 指标保留其组合定义，不能和单独 Q 损失率混用。
- `record_time_*_source_matched`：来源匹配的原答劳动量变化。缺失时间不补零，不改称融合运行时长。
- `replacement_band` 严格区分 `exact_half`、`above_half`、`below_half`。固定 A 路径显示其实际 m；直接 AC 不补造 B。
- 八维表里的未进入固定 A/直接 AC 扩展，表示该配置未被该扩展设计选中，不表示该法无研究或无法分析。

所有输出路径字段是仓库根相对路径，目录内表名另作导航。`SOURCE_INDEX.csv` 列出来源文件，`METHOD_ORIGINAL_CASES` 和 `CHAIN_CASES` 的对象字段是快照内定位键，不是外部文件路径。

目前没有必要为了证明“已有半数、超过半数和大队换人数据”再启动新实验。先读本目录的全部条件和真实实例即可。若论文要回答更强的问题，具体缺口是：

1. 要估计多域分类超出简单 Q 选人的额外价值，需要同容量、同背景和同可用人员的 Q-only/Q-top-N 对照。它不影响已验证指定换人在多数图片上的变化事实。
2. 要声称大团队的跨类幅度高于同类，需要那些大队条件下有可行同类 Y 的 ABC 对照；已有直接 AC 不能替代这一估计量，是否能做取决于真实类别容量。
3. 要分别解释“背景成员”和“阈值”导致的变化，需要另行固定其中一项的机制实验；现有嵌套 n 不能单独归因。
4. 要将超过半数、尤其 m=8 的稀少条件普遍化，需要更多同条件图片支持。当前先按实际支持报告，不用少量反例否定已有较充分条件的多数趋势。

未知正式难度、未单独绘制的案例、时间来源不匹配分别是标签、展示和可评性缺口，不能通过新融合自动补齐。本轮没有启动 OPP 新大池策略或同房 ABC。
