# 两人自然前缀补充

本补充沿用 v2.1 已保存的自然进入顺序：来源池须有至少 3 名有效标注者；每个合格普通或门洞 Manual 池保留 256 条路径及重复团队频次。两人团队沿用原对应、MV50 投票、中位位置和来源连接；只在本补充的独立进程中解除旧包装的两人候选覆盖与评分延期。原冻结结果与通用融合入口未改动。

`pools/` 保存每个不同成员对的结果与节点支持数；`PATH_LINKS.csv.gz` 保存前两位和第三位入场者；`PAIRED_PATH_RESULTS.csv.gz` 保留每条路径的质量、状态和 1→2、2→3 同路径差；`IMAGE_RESULTS.csv`、`SUMMARY.csv` 分别按图及按图/建筑汇总。`K2_CURVE_OVERLAY.csv` 是供曲线使用的独立补充表，身份为新补算的 256 次路径估计，不应与旧版两人延期记录混称同一实验版本。

Q 与相邻人数变化按各自的共同可评分路径计算；失败、参考不可用和其他不可评分状态保留，缺失不填零。`single_support_fraction` 是所保留节点中一票节点的比例，不是人员投票准确率。原先完整人数曲线的 1 人基线和 3 人端点用于配对；此处没有更改它们。人数组合未全枚举。

本次覆盖 223 个图片池（206 普通、17 门洞），57,088 条路径、43,257 个不同两人团队；49,768 条路径可评分，7,304 条未连接，16 条底面不可评分。同路径 1→2 和 2→3 分别有 49,768 和 49,632 条共同可评分路径。普通 Manual、N≥30 的 v2.1 固定范围为 171 图、22 建筑，图片等权下两人平均 Q 为 74.47；1→2 与 2→3 的共同可评平均变化分别为 +4.23 和 +3.61 分。这些差值的可评分路径支持不同，不应直接相减解释加速或减速。

`K2_IMAGE_INTERVALS.csv` 和 `K2_AGGREGATE_INTERVALS.csv` 给出单点 95% 区间。按原自然曲线的相同分层、路径顺序、种子和 2,000 次整路径重抽计算；各图片 1 人及 3 人的全部重抽结果与既有缓存逐次一致。总体分别给固定图片的路径区间和固定路径估计的建筑重抽区间，原有／新增／合并分开；1→2、2→3 各按自身共同可评分路径计算。这些单点区间不属于先前不含 k=2 的整曲线同时带。
