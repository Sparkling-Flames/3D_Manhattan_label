## 构造方法与保护范围

确认裁切优先用未舍入源3D在相机坐标下的共同轴。e9z-09只采用05:59:52.604Z最终裁切，不从回执批量覆盖其他范围。已确认共线／精度内视图从20261016保存版本复用，保留原号及边来源；若中间点存在顶部高度折点则保留该点。原始保存点、保留点、几何转折分别记录。

人工GT以**用户保存的环**确定初始共同轴，在保持边方向归属的角度邻域内，最小化所有顶点的平方位移。给定轴时，通过整环水平边／竖直边的共享坐标约束联合求解，不逐点独立吸附；不拿MP3D形状或最终Q决定修形。该解是固定环序、边方向归属下的局部受约束最小位移，不是任意拓扑的全局最优。优化中不满足环有效性的试探角度被拒绝，最终候选逐项重新验证。

上下同一竖线，完整参考的每个保留顶点高度不变；未完整参考沿用用户授权的源顶高。真正斜墙/OOS不强改。人工GT的大残差不自动被解释为精度误差；参考点正确性仍须结合原图与修订意图复核。

预先记录的工程筛选同时要求最大移动≤0.1像素、≤0.002相机高度、对称面积差≤0.05%；它只筛选43空间的微小候选，不是新评分容差，人工GT即使满足也保留待复核身份。所有修正未写回原GT。方案见[PLAN.json](PLAN.json)，30份扩展见[MANUAL_GT_EXTENSION_PLAN.json](MANUAL_GT_EXTENSION_PLAN.json)。
