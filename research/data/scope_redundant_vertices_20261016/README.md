### 旧空间的点

[scope_views.json](scope_views.json)保留旧环、新环和逐旧点关系：同坐标的新顶点、新边上的中间点、新目标内部的旧点、新目标外的旧点。这是明确的坐标关系，不是自动推定墙角对应；有坐标偏移时不得把旧点位置不同直接等同于遗漏。

新空间的结构要求从**该target_id的新环**计算，不再追加旧GT已经排除的墙角。旧GT和另一个合法空间仍保留各自点位，不能全局删除；也不把人员作答超出的部分自动裁掉以提高质量分。

### 严格共线点

`exact_floor_view`去除数值精度内的中间直线点，保留输入环向、起点对应和原编号映射，并核对底面面积与边界未改变。它不合并不同空间身份。

`paired_view`另检查沿底边弧长的高度线性插值：只有底面和顶部都等价时才给出可精简的完整点对。底点共线但顶部折起的点继续保留；无完整顶界时`paired_view`为null，不能从预览或平顶假设补出完整参考。本包2个完整等价参考是wc2-03和wc2-61。

### 精度内近共线点

原坐标以1024×512 ERP的0.01像素精度保存，反投影后可能留下非常小的转折。例如6个当前uNb目标的中间点转折约0.0011°—0.0204°，拉直对应约0.0003—0.0057像素位移。

`precision_floor_view`同时要求：转折不超过0.05°、投影位移不超过0.01像素、三维垂距不超过0.001相机高度，且投影在相邻端点之间。它输出删除点、每点偏移、面积差与边界最大距离。这是**结构显示/诊断的精度内简化视图**，不是严格几何恒等，也不是已证明的物理共线。当前没有把这些近似坐标写回GT或B8L2参考，不能用它消除明显的小凸起、短墙或高度折点。

0.05°与0.001h为筛查上限，0.01像素对应现有存储量级；并非用人评拟合的质量容忍参数。不同来源精度或更细结构任务应重新核查，不将本规则推广为任意数据的通用容忍度。

## 下游怎样使用

1. 先按原target_id绑定空间，再读取本包视图；同图多个空间不得按最高分挑选。
2. 结构点数/结构覆盖使用该目标的转折视图，不再要求恢复旧目标中被排除的结构。严格值与精度内诊断值分别记录；后者尚未直接覆盖当前难度N_turn或人工类别。
3. 完整评分只在上下几何等价且参考合格时考虑点对精简。原B8L2主线仍用冻结输入，本包不悄悄切换入口。
4. 新Pro应将精确/近似冗余与真实结构错误分别检查。保留`introduced_scope_edges`及其映射，不把人为裁切边自动当实体墙。合并一条新边时，其原边编号列表保存在`edge_source_indices_1based`，不能因删点丢掉边来源。
5. 新增空间继续运行同一整理器；本包不处理尚未登记的草稿/未确认空间，也不授予它们资格。
