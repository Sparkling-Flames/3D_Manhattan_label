# 连续几何条件相对二档、三档增加了什么

后续缓存补充已完成：[结构条件人数曲线与DSTRUCT定义敏感性](structure_sensitivity_v1/README.md)。它另用既存团队曲线与端点，比较原版、仅整体结构及几何条件响应的K3定义；不修改正式标签。几何条件有助于解释尾部与稳定性变化，但不能保证平均Q提高；替代名单改变后，旧严格ABC须重新判定合法性。以下原答楼外预测实验保持原身份与结论。

2026-10-28。**采用建议：保留现行三档作为粗粒度组织方式，采用连续几何条件作为结构表达的补充解释；不据本次结果改成二档，不用几何模型替代正式难度标签，也不建立跨结构、定位、时间的统一难度分。** 本轮执行此前推荐的最小比较，全部复用已有结果，无新增融合、评分、人员分类或人工采集。

**定义边界：** 本轮没有产出能够自动重现全部三档的规则，也没有证明三档是最优或客观难度标准。仅比较两种既有档位合并，不代表穷尽所有二分方法。六项几何分别作为解释变量输入模型，不是新的一维难度分。

## 1. 先回答研究问题

连续条件增加的主要信息是：**同属一个粗档的图片，需要表达的结构数量不同，少画的幅度也不同；在此基础上，短边、自遮挡与张角还能提供有限的额外信息。** 这种增量不能扩大成“几何条件已经客观测出人的整体难度”。

|响应与预定损失|三档|仅几何|三档＋几何|仅几何相对三档|加入几何后的改善楼数|
|---|---:|---:|---:|---|---:|
|少转折数量，MSE（转折²）|1.73382|1.16638|1.16662|误差降低32.73%|18/22|
|是否少转折，Brier损失|0.06971|0.07315|0.06330|误差增加4.93%|15/22|

最后一列比较“三档＋几何”与三档，不是“仅几何”。不同响应的损失单位不同，不能横向相加。所有损失均在留出楼上计算，先每图平均，再每楼平均，最后楼等权；降低百分比是**预测损失的相对降低，不是解释方差比例、正确率增量或人的质量提升**。

完整数值：[SUMMARY.csv](SUMMARY.csv)、[COMPARISONS.csv](COMPARISONS.csv)。后者包含各模型与人员/来源基线、两种二档及单转折数的比较，不仅展示有利结果。

## 2. 结构增量有多实质

少转折数量的定义本身含参考转折数，参考越多，可能少画的范围越大。因此32.73%的改善有明显的结构数量尺度成分，不能全部归给“隐藏结构更难”。加入单转折数对照后：

- 单转折数模型MSE为1.22832；完整几何为1.16638，再降低**5.04%**，15/22楼改善。绝对损失改善0.06194，建筑重采样区间[0.00125, 0.13323]。
- 是否简化：几何相对单转折数Brier损失降低**10.22%**，18/22楼改善；但几何仍未超过三档。三档加几何相对三档降低**9.20%**，15/22楼改善，绝对改善0.00641，区间[0.00084, 0.01247]。
- 三档加几何对未匹配比例降低5.24%，16/22楼改善，但绝对改善区间[-0.000009, 0.001627]跨零，证据弱于转折数量和是否简化。

因此可采用“连续条件补充结构响应解释”；不可采用“所有维度都是连续几何更好”。本轮没有逐项消融，**不能将联合增益分别归因于H、短边或张角中的某一项**。也没有把少转折自动当作遗漏真实必要墙角的语义错误。

改善并非各档一致。按原档分层，几何相对三档的少转折MSE：中等0.75178→0.70410，困难6.25387→3.92518，简单0.04877→0.07619。是否简化的几何模型在中等更好，在简单和困难更差；组合模型的总体改善不能解释成每档都提高。组内各自按图、楼等权，不用这些分层数直接拼接总体。[GRADE_SUMMARY.csv](GRADE_SUMMARY.csv)

来源分层中，少转折数量的改善在新、旧来源均存在；三档加几何对是否简化也在两来源都降低损失。Q则未出现相同的一致增量。这里复用同一次楼外预测按来源分层，不是声称完成了独立来源迁移验证。[SOURCE_SUMMARY.csv](SOURCE_SUMMARY.csv)

## 3. 为什么这次不合并成二档

预先比较了简单／非简单和非困难／困难两种合并，未按结果选择更显著的切点。相对这两种二档，三档对是否简化分别降低损失25.53%、14.45%，各有16/22、18/22楼改善；Q误差分别降低4.46%、5.94%，18/22、19/22楼改善。时间与局部偏差收益小且不一致。

这说明现有中等层在部分响应上保留了二分会丢失的信息，**不说明中等已被证明是一种独立的自然类型，也不追认所有人工判定边界都是唯一正确的**。两种二档均没有在主要响应上提供稳定的简化收益，目前缺少承担信息损失而改档的理由。

本次用的是相同基线和固定低复杂度模型；结论是这组有限比较的采用建议，不是对所有非线性模型或所有二分方式的优劣证明。

## 4. 定位和劳动量目前不能作强解释

定位诊断是先用三维底点射线角距离进行一对一匹配，仅保留≤9°者，再取人员底点y减参考底点y的平均值，最后取绝对值。它是1024×512坐标下的像素偏差；正负误差可以抵消，不含完整水平定位误差，更不是每角绝对误差平均。5719份都有至少一个匹配，但**1278份存在未匹配参考角**，所以同时报告未匹配比例。来源代码为 `tools/thesis_main/analysis/same_room_structure_transfer_20261020.py::geometry_features`；本轮只读保存结果，没有重新匹配或评分。

时间单独按两来源拟合：旧来源仅usable的801份/114图/21楼/23人，新来源reported_processed的4424份/175图/22楼/35人。另494份没有可用来源时间，原因分开保留，未填零；旧来源801份中只有418份具有目标匹配时间。本次比较的是**原记录劳动时间**，不宣称当前目标的精确作业时长，也不混合旧active-time与lead-time。

新来源时间的几何模型比三档差19/22楼，最差VFuaQ6m2Qom楼的MAE增加0.59667。该楼含14/16转折、多短边图，是外推局限的具体警报；尚未单独证明误差由哪一个特征引起。加入三档仍未消除时间退化。不能因结构预测改善就声称标注时间也被解释。

## 5. 固定设计与数据身份

- 主面板：普通Manual177图/60人/22楼/5719份。简单114图3751份，中等32图988份，困难31图980份。与冻结ACTUAL_POOLS逐池成员集合、pool_n、object_id、参考及当前目标逐一核对。
- 三个层级不能混用：参考特征是输入条件，现行等级是待比较的历史分层，原答结果是响应。正式标签、目标、几何及质量值未修改。
- 外层22楼留一。测试楼的记录不参与拟合、标准化或人员效应估计。5项非时间响应有2份来自该折训练中未出现的同一人员，其人员效应按0处理并保留；时间没有此情形。详见[FOLD_SUPPORT.csv](FOLD_SUPPORT.csv)。
- 同一模型家族：加权岭线性回归，人员与来源效应作为共同基线，alpha固定1、截距不惩罚，无调参。训练每图总权重为1。数值变量只用训练楼的均值/标准差标准化；三档按名义变量编码，不当等距数值。
- 几何共6列：5°有效转折、H、短边数、最小水平张角、有无短边、条件短边张角。无短边的张角只在设计矩阵中置0，并有存在指示；不把它解释为测得0°，真实缺失不补0。H与H/N未同时加入。
- 预定7个模型：人员/来源基线，两种二档，三档，单转折数，几何，三档＋几何。是否简化的线性预测截断至[0,1]，其他响应保留原预测。所有模型在各响应上支持完全相同。
- 旧、新来源时间各自独立；Semi未拟合，因该最小方案以Manual为主且Semi困难仅1图4份。门洞、OOS及其它特殊用途没有混入。

冻结设计：[PLAN.json](PLAN.json)。它在首次拟合前落盘，但已有数据曾被探索，**这是回顾性楼外比较，不是新的盲验证**。区间来自5000次配对建筑重采样、固定种子20261028；只重采样已保存楼外损失，不重新拟合。训练折互相重叠，因此这些是条件性描述区间，不是独立外部总体或因果效果保证。没有对多响应进行显著性筛选。

## 6. 明确采用与停止范围

1. **采用**：连续几何条件用于解释结构数量差和粗档内部的简化机会；报告主效应幅度、改善楼数与反向情况。三档＋几何在是否简化上有实际增量。
2. **保留**：现行三档、已冻结DSTRUCT及所有人数曲线/严格ABC身份。当前证据不要求重分人员或重跑端点。
3. **不采用**：把纯几何预测值升级为正式难度分；宣称连续几何全面优于三档；合并中等以追求更清晰展示；从本结果推出定位、时间或整体质量都改善。
4. **本次即可停止**：无需新数据或全量人工重判。若下一步研究重点转为定位难度，应先获得不抵消误差且保留匹配支持的定位响应，再判断是否值得增加照片线索；这是另一项有明确测量目标的任务，本次未展开。

## 7. 将来改难度时，人员方法的依赖与成本

本节只读核对方法代码，不启动重拟合。难度改变会影响的人员方法不限于DSTRUCT；必须按实际改变的图片、训练折和特征重查，不能预断所有名单一定改变，也不能预断RFUSE不受影响。

具体来源：

- [RFUSE实现](../../../analysis_results/personnel_exchange_discrimination_audit_20261025/unpacked/03/reverse/code/learn_natural_fusion_roles.py)：22、45—46行分层；78—109行内层alpha；112—130行响应、资格及编码。资格为总体≥8图/3楼、简单≥5图/2楼、困难≥3图/2楼。

- [scope联合实现](../../../analysis_results/personnel_exchange_discrimination_audit_20261025/unpacked/03/classifications/code/build_scope_increment.py)：14—19行资格及困难响应；25—38行联合轴方向和名单。

三种成本应分别说明：

1. **只增加结构条件分组，目标、成员与标签不变：** 重聚合natural256/精确边际和已有端点；无需重拟合人员方法。保持共同图片支持，历史V3 policy32不改称新类验证。
2. **改难度并采用新的人员标签：** 检查以上方法的画像、响应、资格和楼外拟合，重算名单，再重判严格ABC中X/Y同类、Z跨类及背景D的关系。同一实际团队端点仍可复用；配比与方差按新标签重聚合。
3. **依据新标签重新选队：** 先查端点缓存，只有必要的新团队缺缓存时才新增融合；不因改档就全量重算。

冻结旧标签的实验结果继续作为原版本证据保存，不因未来重新分档而作废。新旧结果必须带各自的标签、支持及团队身份；本轮未改变任何正式难度或人员资格。
