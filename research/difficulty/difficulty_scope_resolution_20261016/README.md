## 这次怎样理清分歧

过去把不同原因统称为“难度分歧”，处理不够充分。现在分为四类，不能混用解释：

1. **目标空间不同**：先绑定范围，再比较难度。S9-09和zsNo-13的新旧分类不构成同一任务误判率证据，旧范围评分也不能直接用于新范围。此类问题本次已处理，不再要求用户重复确认范围。
2. **参考GT有问题**：这是参照问题，不是困难证据。4张待修正GT继续排除；uNb-36仍待定，不因其它图改档而解除。
3. **同一目标，对整图负担判断不同**：此前22处等级分歧已按用户明确指示采用，逐图台账记录旧类、裁定类、现类、N/H和旧视觉依据，不再笼统标为“未采用、等待裁定”。其中6张困难→中等主要提示局部隐藏角被赋予过高权重；16张中等→困难提示多转折、辨认和连接负担可能被估低。两类原因是证据支持的解释候选，不是已测定的因果分解。
4. **特殊条件或标法歧义**：OOS、门洞、其它人选择不同空间分别保存；有不同标法不直接证明哪个GT错误，更不自动代表不可标。

因此当前论文逻辑应为：**先固定目标与参照有效性，再从结构表达和定位推断两个维度作粗分，最后记录人工复核裁定。** N/H是解释特征，不是足以完全重现等级的公式。局部隐藏角不必然困难；可标也不等于简单；多点结构即使有线索仍可能操作繁复。

标签上的分歧已经依用户裁定落实，允许保留中等／困难边界的判断差异。不能据改档本身断言原规则一定错或人工一定对，上述原因归纳也不能解释每张图的全部差异。若以后需要更强方法证据，可另做独立复核；它不是当前工作粗分继续使用的前置要求。不能将同一份裁定当独立测试集，也不能根据后续质量均分是否单调再次反推标签。

论文可表述为：“我们在固定目标空间并排除已知参考错误后，根据结构表达与定位推断负担进行人工辅助的粗粒度分层。分层用于区分整体任务条件，而非精确刻画单张图片的固有难度；中等与困难之间允许存在边界案例和判断差异。”这不等于声称完全客观、普遍一致或精确分解出图片不确定性。
