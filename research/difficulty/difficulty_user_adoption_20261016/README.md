## 3. 分类依据：两个负担共同解释

|维度|具体含义|证据及边界|
|---|---|---|
|结构与操作负担|需要辨认和表达多少必要转折，点位及连接关系是否繁复|所选范围的转折数N可计算；复杂关系仍需结合图像，不以一个点数阈值决定所有图|
|定位与推断负担|目标角位是否直接可辨，遮挡后能否由墙顶线、竖线、邻接关系约束；是否需补足不确定的必要结构|H作为几何自遮挡提示；照片线索与材料/边界性质辅助解释。H不是全高照片遮挡的测量|

当前三档的解释口径：

- **简单：结构负担较低，定位线索明确。** 四或六个必要转折，主要角位可直接定位，或只有少量家具遮住底部而仍有明确墙线约束。六角不自动升为中等。
- **中等：需要局部推断或一定操作，但整体任务仍可控。** 少量隐藏角、局部窄转折可由相邻结构约束；存在H>0不自动升为困难。
- **困难：整体表达负担较高，或必要结构定位、连接明显依赖推断，也可以两者叠加。** 多点、多处转折和复杂空间辨认即使H=0仍可能较难；“理论上能推断”不代表操作轻松。

这是一套**解释当前粗类的工作标准，不是能完全重现全部人工等级的确定性公式**。未按用户等级拟合N/H阈值，未反向修改旧推断负担记录，也未逐图编造新的视觉理由。人工裁定和几何特征分别保留。

## 5. 特殊条件与GT错误

- OOS单独记录表示适用性：非正交但可标不自动归困难，更不自动视为不可标。
- 门洞交界单独记录目标边界与可标性；范围明确后可保存条件式难度，特殊样本不混入普通三档验证。
- GT错误先排除；空间未定、疑似OOS及其它既有暂停也不因填写等级而解除。

## 6. 可用于论文的方法表述

> 本研究将图片难度定义为给定目标空间下的布局标注任务负担。在采用已确认空间范围、排除已知参考错误后，结合参考几何的必要转折数、几何自遮挡提示及图像中的角位定位线索，对任务进行简单、中等和困难的粗粒度分组。分类同时考虑结构表达与定位推断负担，并经人工复核修订；OOS与门洞交界作为独立条件记录。分类过程中不使用作答质量得分或融合表现拟合类别。

方法史应如实说明：几何初分、Codex视觉辅助判断、另一审核者意见和研究者局部裁定逐步形成当前标签。当前版本属于**几何特征辅助、人工复核修订的工作分类**，不能称为纯自动客观难度真值，也不能用同一份人工裁定再证明分类与人工高度一致。

后续先固定v4标签，再观察不同组的表现；中等与困难不一定呈严格单调。若论文要求更强客观性，需要另做不看本版等级的规则复核，而不是隐去现有人工介入。
