## “竖着切”的正确语义

用户确认的是**整个空间体的竖向边界**。二维多边形P是该边界的水平投影，不是只改地板而保留旧范围的墙和天花板。数学上，对给定场景空间V，所选范围为：

`V_selected = { (x,y,z) in V : (x,z) in P }`。

因此范围外的顶角、墙线、隐藏分支都不应继续计入新目标的难度。P的边界在竖直方向贯穿空间；本轮不把该边界误作必然存在的实体墙。

**范围确认与精确三维几何完备性是两件事。** 旧导出字段 `floor_region_confirmed` 和 `top_boundary_pending`保留原值用于追溯；另增 `space_scope_confirmed=true` 与 `scope_semantics=whole_space_vertical_boundary`表达用户当前语义。`top_boundary_pending=true`只说明文件未提供独立核验后的完整顶角坐标，不再解释成用户只确认了地面。没有据二维范围捏造天花板高度或强制上下等高。

主数据 `floor_scope_update` 现含本日四图的增量，保留前两图原回执来源，新增两图来源为 `scope_receipt_20261015_1.json`。完整回执中的旧状态不覆盖此前已确认范围。难度表中其余35图沿用既有来源，统一执行整空间竖向范围语义。
