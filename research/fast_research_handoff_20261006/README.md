## 2. Codex：只补一个有研究增量的计算

24人×10图的同图比较、建筑留出、固定4人组合，以及两图六人组合都已有结果，不重复计算。下一步建议补 **k=8**，沿既有楼外校准的12／12分组及等权Lee，比较上半成员数 **0、4、8**；与k=4的0、2、4构成作相同比例对照。保留已有MV50与严格多数两规则：k=8门槛为4／5，k=4为2／3。已有四人结果的成员波动方向受这两种规则影响，增加这个解析比较会影响结论，成本又低。

复用已研究过的tile超几何覆盖概率，求期望遗漏、外扩和两次抽组的区域对称差；报告逐图结果及图片等权汇总。沿用固定参考面积归一化偏差、固定全员并集归一化成员差异的既有解释。**不把期望交集／期望并集写成平均IoU，不把两次换组的差异写成增加一人的变化。** 原GT为主，已有四张双参考图作同图版本对照即可。k=4对应量优先读已有结果，缺失项才补算。

这是一项固定人员池内的构成实验，不证明人员类型可迁移；Q上下半只是本轮省力基线，也不取代原来T／S／B等子类设想。若构成收益小于同构成换人的差异，也作为结果交付，不继续调切点。

图片条件只做两件低成本工作：

- 展示本线程已经重汇总的52图人数／难度描述；不重跑136图几何。
- 对十图逐图结果，带上已有范围／细节说明、模型点数和模型输出差异，解释失效是否集中于某些图片。十图不足以拟合多特征难度模型；离线模型输出不能直接当作实际预标注。

## 3. Pro：质量解释与可使用输出一起看

**质量解释**从已做过的12图指标实验、195份三维实验中取3—4个能区分问题的真实例子，优先覆盖范围选择、局部细节、上下／深度耦合，按原人审和原图解释数值。选择依据是问题种类和现成证据，不按哪个指标表现更好选例。交付“已有判断—测量反应—增加了什么解释—仍分不清什么”。允许删去没有额外解释作用的指标，不要求每类都找到正结果。不新增统一加权总分，也不把低相关或更低的3D IoU当作有效性证明。

**完整共识**先复用 `2t7WUuJeko7-06` 或 `7y3sRwLe3Va-04` 的现成Lee、精确上下曲线、点方法输出。相同人员池和原规则下分别比较范围、上下边界及表示节点；Lee只有底面范围，曲线节点不自动等于墙角。没有必要为了三方法齐表，在e9z/wc2上新造一套曲线适配器。

**不同空间候选**从e9z或wc2择一个病例，先保留完整原作答／既有观测分支；确有局部证据时至多增加一种有限删点或路径替换。输出完整布局、改了哪一段、来源、保留／丢失的范围或细节。原作答存在只证明有人这样标，不自动证明合理；GT距离和多数票都不能单独裁定另一空间不合理。若这两图只有对应错误证据，没有合理多空间证据，直接改用12图面板已有scope案例，不继续硬造候选。

rpc的10/24局部组、B6By的120°搜索域问题已有清楚结论，只保留作机制解释，不再扩大人员审核账本。e9z的5°／9°限制和12°例外分开保留。
