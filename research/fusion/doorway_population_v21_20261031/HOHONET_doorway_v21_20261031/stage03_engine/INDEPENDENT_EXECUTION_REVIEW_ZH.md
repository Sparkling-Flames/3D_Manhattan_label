# 门洞 v2.1：冻结引擎与最终执行的独立门禁审查

## 结论

本轮最终计算通过精确成员、目标参考、物理端点复用、重评分覆盖、质量分项、状态及文件完整性检查。审查没有修改原始点对、人员池、分类、参考选择规则、融合函数或任何实际质量值。

仓库源固定在 `d4c73943ae58476880bf3ceb7b774e4ec59a95b5`。已登记 259,310 个唯一物理团队、259,917 个目标评分；426,752 条自然前缀和 4,884 条精确有限集合链接均能回到其精确人员集合、目标空间和冻结自然排列。最终导出没有缺请求或重复物理身份。当前 `stage04_computation` 下全部 1,109 个 gzip 文件均有读至 EOF 的回执，包括端点、参考恢复评分层、冻结设计和最终标量表。

该检查证明执行与规定一致，不把唯一团队目录的总体比例解释为逐图等权曲线结论。图片、人数、有效评分、建筑和成员池支持应采用 `stage05_results` 的相应分母。

## 采用的计算口径

冻结融合间隔为 7.5，MV50 为独立成员支持数 **≥ ceil(n/2)**，没有追加 N1。逐团队检查了成员无重叠、人员身份唯一、最小支持、节点支持长度及物理输入散列。原始环序和源点对索引保留，没有重新按角度排序。

`n=1` 使用原答评分接口，没有把原答替换成单人融合；`n=2` 使用现行独立补充的实际 MV50 融合，旧主曲线和置信带仍应排除 n=2。小池 N≤10 的非空子集全部枚举；大池精确单人、N−1 和满员边际保留；自然过程使用 256 个已冻结路径，同一原始排列过滤出筛后和兼容子池。

B8L2 与 D10 调用冻结 `working_models.score`。对 IoU2D > 0，命名损失块为：

- `F = 1/IoU2D − 1 + S_bottom_deg² / 32`；
- `Dβ = 1.5 × dir² / (dir² + β²)`，B8L2 的 β=8，D10 的 β=10；
- `H = (Hmean/0.8)² + (Hcenter/0.25)²`；
- `Q = 100 / [1 + hypot(F,Dβ) + H]`。

L2 合并的是底面块和方向块；高度块随后相加。分块不是固定百分比贡献。IoU2D=0 时使用冻结公式的连续极限 Q=0；缺分项不按0补齐。

`dir` 是该原答或融合结果相对于**自身最佳正交轴**的残差，不能改称相对参考主轴偏差。参考构造保留当前已采用的坐标和轴；没有为提高质量重新拟合轴。

## 状态必须分开解释

以下为唯一物理团队目录计数；不同 n、图片和设计范围的覆盖不同，不应直接当作图等权成功率。

|端点阶段|完整可评分|少于四节点|无连接|底面非法|完整几何不可评|
|---|---:|---:|---:|---:|---:|
|原答 n=1|584|不作为融合尝试|不作为融合尝试|0|0|
|独立 n=2 补充|1,808|0|3,088|1|1|
|主融合 n≥3|204,830|31,190|15,354|2,448|6|

运行异常为0，但实际未形成完整共识和输出不可评分的情况存在，不能写成“没有融合失败”。同一物理团队在多个合法目标上评分时，最终状态冲突为0。

最终259,917个目标评分中，207,569个有完整Q；52,348个缺Q分别落在上述少于四节点、无连接或非法几何状态。缺完整参考数量已经为0。数学意义上的真实Q=0数量为0；最小正B8为0.000176360873。展示时四舍五入为0.00的数不能解释为真实零分。

冻结原生计算会为部分低于四节点的三角候选提供底面量。共有24,724个目标端点出现这种可测候选；它们仍未形成完整共识。例如7y3sRwLe3Va-06满员n=34只有3节点，候选IoU2D为0.3267384165，底边界距离10.905077°，完整Q为空。主完整底面曲线已要求 `complete_floor_evaluable`，原候选值单列为诊断；此门禁没有改动原Q或给缺Q补0。

另有完整底面而顶部非法的情况，例如7y3sRwLe3Va-06某n=2团队已经形成4节点闭环，但 `wrong_hemisphere` 导致 `invalid_full_geometry`：底面可评，完整Q不可评。这与少节点或无连接不同。

13条历史hold原答的环序确认旗仍保留；例如v2:new:100168为default_unreviewed/ring_confirmed=false，原答完整Q诊断可算。单人端点中的历史确认gate不能解释为实际融合失败，也没有借本轮评分解除其旧正式资格标记。
