# 两份墙线人审：评论、三维对照与顺序诊断

两份回执按同一标准分析，保留原选项和原评论。旧选项较粗、新选项较细，不解释为评价标准不同。本轮不采用旧的非正式审查结果。

**结论：一些被提出合并的组确实具有不同几何表达，保留分组有依据；也发现明确的组内表达混合与疑似不必要拆分。角点环序会影响部分对应，但尚未发现足以认定原答顺序错误的证据。**

## 覆盖与解释方式

两人各完成72图，合计110条局部评论。按图片、组和具体观察选择完全一致去重后，是30图中的99个案例；同图不同选择仍可能重叠。两人均未留下局部问题的42图包括随机样本40/60图、诊断样本2/12图。无局部问题记录不等于逐观察身份全部验证正确。

本轮结合原图、原始点对、三维投影、原答共现及已保存匹配关系，逐项形成分析判断：38例分开有依据，13例疑似不必要拆分，34例看不清或混合问题，13例原答问题单列，1例确认局部表达混合。这是评论案例的整理，不是算法错误率，也不是新增人工标注。看不清的保留当前分组，不加入已确认正确的计数。

## 一例明确的组内表达混合

uNb9QFRL6hY-79的G1共34人，原图中形成两套明显位置表达，各17人。两套横坐标范围分别为178.76–195.15与210.18–222.73（1024宽坐标）；融合中位横坐标202.67落在两套表达之间的空隙。底面投影也呈分离。

这支持“当前组混合了两种位置表达”的判断，不能归为纯显示误差。进一步将其命名为两个不同物理墙角，仍需区别家具边缘和相邻墙体交界的指向。两套各17人的支持均达到34人池的半数门槛；没有实际拆组重算输出或Q。[原图与底面对照](C080_mixed_modes.png)

## 角点顺序到底影响了什么？

子智能体固定同一距离矩阵和7.5跳过代价，对四个重点案例的全部9条缺失跨组对应，比较循环保序匹配和自由一对一匹配。

- VFuaQ6m2Qom-07：3条缺边中2条在解除保序后恢复，证明环序约束确有影响；仍有1条未恢复，不能说解除顺序便能合组。
- pa4otMbVnkk-10、uNb9QFRL6hY-45、wc2JMjhGNzB-26：其余6条均未恢复，涉及邻近角点竞争及原答增删结构。
- 9条的起点平移与整环反向检验均不改变结果。涉及的13份原答底面环没有自交。因此不是简单的起点编号或顺逆时针问题，也没有依据自动按横坐标重排。

本阶段环序用于两人原答匹配，后续source_ring用于连接已达票节点，两者要分开。自由匹配代价更低不等于物理对应更正确。[完整诊断和逐对证据](ORDER_DIAGNOSIS.md)

## 对方法论证有什么作用？

这批审核支持结构指向与几何表达分开评价：同一墙线可以出现有意义的深度或高度差，二维邻近不足以判定错误拆分。同时，完整环对应和完全链接分组会让少量缺边阻断合组；宽容纳的匹配也可能把两种位置表达并入一组。两类失败均已有具体证据可追踪。

例如uNb9QFRL6hY-45的两组为5人、16人，当前35人池门槛18，两组均未入选；若后续确认应合并，21名不同人员的合并支持会过门槛。这说明拆分可能影响结构入选，但本轮没有用假设合组替换真实输出。

可以把本轮作为正式人审的解释与失败分析，展示合理分组、疑似碎裂和明确混合。现有结果尚不提供全体角点身份准确率，也不证明7.5是最优参数。继续收集人审时沿用现有工作台；不应把99个评论选择再次全部交回用户复核。
