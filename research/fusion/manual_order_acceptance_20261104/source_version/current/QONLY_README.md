## 结论及论文影响

**既有结构换类能够升质的结果保留；在本轮固定候选、背景与换人数量的对照中，没有显示它比直接按楼外历史 Q 选人具有额外的平均 Q 优势。** 两种政策高度重合是实际结果：14/7 有119/147个事件换入七人完全相同，20/7为54/61；平均共享6.810、6.885人。这既解释了多数输出相同，也说明当前定向结构组与高历史质量人员有较大重合。不能将两者差异小解释成所有分类无用，也不能将既有 C−B 的升质完全归为结构类别的独立作用。

主比较的效应统一为“结构方案−原始Q方案”，按背景→替换块→池→图逐层平均，图片等权，区间为2000次建筑整群重采样的百分位95%区间。

相对Q敏感性（Q_PEER）对应差值为+0.2287 [−0.3536,+1.2420]及−0.1135 [−0.3859,+0.0005]，未改变判断。区间跨零不构成统计等效证明；当前工作条件的直接观察是效应很小且大量选员相同。

对论文而言，半队替换仍用于解释不同人群怎样改变共识；本项用于界定“结构方案的选人用途”。结构表达、成员、背景及同房重复性的既有证据不因此撤回，新增的表述是：**在该既有强方向与固定候选支持内，简单历史Q选人基本复现了其质量水平；额外选队收益尚未显示。** 此结论不涉及 OPPJOINT 重新分类，也不比较所有可能的结构选队政策。

## 历史Q匹配与个别差异

政策对照不等于“保持历史Q相同后的类别效应”。原X/Z七人块在固定3分caliper下做最大不重复匹配，14/7最多匹配3人，20/7最多2人；没有完整七人匹配。另对排除D/X/Y后的C2/C3候选容量检查也无七人可匹配，但该池C2已被互斥要求明显耗尽，尤其20/7仅余0—1人，不能据此宣布整个研究人群无Q重叠。分别见`ORIGINAL_BLOCK_HISTORY_OVERLAP.csv`与`Q_OVERLAP.csv`。本轮未强行构造失去原条件的Q匹配实验。
