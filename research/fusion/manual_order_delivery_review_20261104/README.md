## 结论：平均x预处理没有遗漏

当前函数shared_x_reanalysis_20260922.shared_x针对**同一个上下点对**，按1024像素周期最短弧求x中点；上下y不改变。每一份原答分别处理。融合时，再在各个对应身份组内，用medoid锚定的周期中位数计算共享x，top/bottom y分别取中位数。它不要求所有x接近的不同节点都具有同一个x。

pa4otMbVnkk-18的F2对应node_001，F9对应node_010。此处“F2/F9这对点”实际是两个节点、四个图像点。各自上下x均相等：
