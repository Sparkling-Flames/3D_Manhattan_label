# 门洞／OOS：计算与用途分开

2026-10-16用户补充后的版本 `fusion_compute_use_separated_20261016_v2`。本包覆盖原18个冻结来源池的7,320个路径状态、6,693个唯一成员子集。没有重新融合、调参或增加图片；上一级及10月15日结果保留原值、原用途版本。

## 用途

- 门洞继续计算完整条件分数，原参考、成员资格和目标绑定限制仍保留。
- OOS在资料齐全时计算B8L2、WQ及同参考均高棱柱IoU，全部仅作诊断。不得用于参考质量结论、算法优劣比较、人员排名或以低分评价人员。非正交的方向惩罚尤其不具质量解释。
- OOS不导致几何稳定性资料整体删除；可计算底面的换组变化仍可研究。几何可计算也不证明墙线对应和连接正确。
- x8-01的GT问题及来源池暂停仍保留。本次32个诊断状态只是把此前未计算与数学不可算分开，没有解除排除。

## 失败与人员数量怎么读

[覆盖表](coverage.csv)同时按路径状态和唯一子集列出完整数值、仅底面、点数不足、缺连接、参考不足、几何失败及政策未运行等实际出现的类别；零计数不伪造数据行。两人暂缓是未运行，不是数学失败。本包六张特殊图未出现点不足或仅底面结果，不代表全库不存在。

输入是已预处理、已配对的冻结池，本模块没有重新覆盖所有原始未配对作答，因此**不能声称全库上下不配对数为0**。这类来源失败已由[全库计算台账](../../../statistics/b8l2_usage_v6_20261016/calculation_ledger.csv)统计。本模块只保留自己实际处理的分母。

[逐人覆盖](worker_coverage.csv)覆盖24名人员、377份图×人员来源记录；其中52份属于OOS。初版203份“已知质量用途限制”是旧成员限制快照；新版全库已解除门洞整类暂停，不能继续把203称为当前排除数，差异见下节。[逐份用途](member_usage.csv)保留每条原因和投票资格。这是18池内的已知限制数量，不是全库人员排除总数，也不是377份单人质量都重新测过。不能把参与一次失败的融合团队记成这个人的标注失败；不能把质量不纳入等同于融合投票排除。

## 文件与复算

- [路径状态](trajectory_usage.csv)、[去重子集](subset_usage.csv)：`*_numeric`为数值列，包含OOS；OOS的旧名称B8L2/WQ/IoU3D100列在本用途视图留空，避免误入既有质量汇总。
- `reference_quality_scene_allowed`仅表示完整数值且场景／来源池未禁止；不是最终比较资格。原留出、目标绑定、人员限制及`primary_comparison_eligible`继续单独保留。
- [字段合同](FIELD_CONTRACT.json)解释计算状态、用途和分母。
- 复算：`python -m tools.thesis_main.analysis.wall_consensus_usage_20261016`。复用已存分项；此前被政策暂停的OOS只对已存几何补测，不重建共识。

验证：4项相关测试通过；输出核对7,320路径、6,693子集，OOS不进入质量比较列、k=2无完整数值。未重跑融合、未扩大图片、未改历史分数。新版全库分母及逐人排除已完成，见[统计交付](../../../statistics/b8l2_usage_v6_20261016/README.md)及[27人用途覆盖](../../../statistics/b8l2_usage_v6_20261016/worker_usage_summary.csv)。
