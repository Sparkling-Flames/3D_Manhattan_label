## 与研究问题的关系

总体问题是增加实际标注人数后，质量与不确定性怎样变化，改善瓶颈是否随图片条件及人员构成变化。三个不同用途是：质量研究单份作答及跨图人员表现；分簇描述点位、细节与邻接的分歧模式及少数模式；融合共识研究综合实际作答得到什么以及随人数的变化。减法和局部重组另用于生成几何合理候选，不等于工人融合共识。

IoU、质心和边界差异可用于描述与固定 GT 的差距，但不自动成为人员能力。局部路径对应只是候选工具，不是区域 IoU、质心或区域 MV 的共同前提。导师交流笔记含直接对话和明确标注为记忆整理的尝试方向；不把后者升级为已定算法，也不把“简单快、困难慢”预设为必然结果。
