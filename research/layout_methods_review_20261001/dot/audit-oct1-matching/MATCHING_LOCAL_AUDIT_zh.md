# 匹配、局部路径与加点噪声：独立审查

## 结论

这份返回结果有实质研究价值，其最重要的克制结论应保留：无序点集不能表达环邻接；两组加点试验没有证明保序更准；top/bottom 独立匹配确实可能冲突；两对/三对问题必须先定义物理路径与支撑方向。不能把报告已经明确披露的“非真人噪声模型”“尚无自动跨人分块”“只做独立实现”等限制重新包装成被隐瞒的问题。

但推荐 B 方案还不宜直接投入自动分类。有一项会产生假几何差异的集成问题，以及两项确定的输出可靠性问题：

1. **优先修复：角窗裁切到局部分类之间缺少共同门点方向对齐**。同一合法房间仅反转环编码，即可被判为局部几何不同
2. **中优先级：并列最优匹配数量被低报，且随无意义的起点变化**。错误直接出现在包内用于说明保序价值的示例中
3. **中优先级：局部均值和覆盖是未加权采样统计，不是弧长统计**。只加共线点，不改变路径，便能把覆盖从 1.98% 改成 91.0%

以上不推翻报告中的真实局部不一致案例、6/45 冲突、96.25% 覆盖或 11/30 冲突计数。它们限定了当前原型可安全使用的范围。

## 1. 高优先级：局部分类集成遗漏方向归一

### 位置

- `src/matching.py:58–91`：角窗返回原物理环方向的路径
- `src/run_local_research.py:41–48`：直接比较两条裁切路径
- `src/run_order_and_hybrid.py:12–21,35–38`：直接计算有向 Fréchet，并据其上下界判定
- `REPORT_zh.md:128`：把环反向视为同一环；`146`、`150`：宣称实现局部几何三态及 geometry/expression 分离

### 可执行反例

房间为 `p=[[-2,-2],[2,-2],[2,2],[-2,2]]`，相机在原点，合法简单闭环。另一输入仅为 `p[::-1]`。分别提取相同跨接缝窗口 `[970,1035]`：

- 周期绑定匹配成本：0
- 两条裁切路径 Hausdorff 下界：约 2.22×10⁻¹⁶h
- 未对齐方向的 Fréchet 区间：[0.8182408738, 0.8232408738]h
- `epsilon=.01h` 时：`geometrically_distinct`
- 将 B 的路径按同一门点顺序对齐后：`geometrically_close`

这是同一个连续局部边界，错误来自入口/出口在数组中的角色交换，不是结构不同。

### 准确界定

**不是 Fréchet 定义错误**。`classify_path` 的注释已说仅适用于已声明的共同开放路径门点；对真正有方向语义的路径，反向本来就可能是差异。问题在于角窗调用链未满足/检查该前提，也未把周期匹配识别的反向传入局部流程。

两组现有真实比较本来就明显不同，反转不改变其“不同”结论，但会任意改变 Fréchet 数值：R03398 比较从 0.8689168962h 变到 2.9845902955h；R00705 比较从 2.5303603133h 变到 4.1347965008h。因此不能声称已证明现有真实图被错判。第一组的 Hausdorff 下界约 0.869h 本身已独立支持“并非同墙多一个采样点”。

### 修复建议

由已核实的入口/出口门点 ID、物理支撑边和共同环方向统一路径方向，再计算有向 Fréchet；若对应门点不明，则返回未决。不要在具有真实方向语义的任务中无条件取正反向最小值。加入完整的“原环→反转环→角窗→分类”回归。

## 2. 中优先级：并列最优映射被低报

### 位置

- `src/matching.py:27–28`：每个 DP 单元只保留 `np.argmin` 的一个前驱
- `src/matching.py:49–51`：只统计各旋转/反向各自那一条回溯出的映射
- `REPORT_zh.md:128`：说返回“并列最佳映射”
- `results/order_counterexample.json`：`equally_best_maps=1`

### 包内现成反例

A 是 `[[-3,-3],[3,-3],[3,3],[1,.7],[-3,3]]`，B 是 A 的 `[0,1,3,2,4]` 重排，σ=4px、gap=2。独立穷举得到两条成本均为 4 的最优映射（下标从 0 起）：

- `[(0,0),(1,1),(2,3),(4,4)]`
- `[(0,0),(1,1),(3,2),(4,4)]`

返回程序只报告 1。把 A 的数组循环移位，几何和环均不变，报告数依次为 `1,2,2,1,1`，选中的映射也会改变。

### 影响与不影响

最优成本没有算错；返回其中一个最优解也合法。错的是把候选回溯中的不同映射数当成全体并列最优解数，这会产生虚假的对应唯一性，影响未来稳定锚点或冲突判断。

本次把真实 45 组参数的 bound/top/bottom 共 135 次求解与全前驱枚举比较，没有发现这些真实设置的并列数有误；6/45 冲突仍成立。故这是可复现的原型缺陷，不能据此反推现有全部数字不可信。

### 修复建议

在 DP 中保留所有等价最优前驱，并对映射身份去重；若担心组合爆炸，可输出明确的歧义标记/下界和截断状态。不能把少数候选数命名为完整的 `equally_best_maps`，也不能只返回一个数却声称已经返回所有并列映射。

## 3. 中优先级：局部均值/覆盖仍受原点密度支配

### 位置

- `src/geometry_core.py:69–73`：每个原线段至少一个样本，保留所有原节点
- `src/geometry_core.py:79–80`：直接 `da.mean()` 与 `(da<=.01).mean()`
- `REPORT_zh.md:74,150`：建议按弧长表达、分开几何与节点表达

### 可执行反例

A 为水平线 `[(0,0),(1,0)]`，B 为斜线 `[(0,0),(1,1)]`，步长 .01h。A 的 `[0,.001]` 子段改为 1001 个等距共线点，其余仍直连 `(1,0)`。连续几何完全不变：

| A 的表达 | `mean_a_b` | `coverage_a_001` |
|---|---:|---:|
| 2 个原节点 | 0.3535533906h | 0.0198019802 |
| 1002 个原节点 | 0.0327863771h | 0.9100817439 |

对应真正的弧长均值为 `1/(2√2)=0.3535533906h`，弧长覆盖为 `.01√2≈1.4142%`。稀疏行的覆盖本身只是有离散误差的近似；密集行的 91.0% 则是严重的原节点密度加权。

### 准确界定

该反例**不破坏 Hausdorff/Fréchet 数值界，也不翻转当前 `classify_path` 的判定**，因为判定仅使用 Fréchet 上下界。`polygon_metrics` 的固定均匀周长采样是另一段实现，也不能一并判错。

问题在局部 `path_metrics` 已输出而容易被当作几何比例的均值/覆盖。若坚持保留其现状，必须明确称“该采样规则下的样本均值/样本覆盖”，不能等同受影响弧长。

### 修复建议

保留全部原点身份与用于最大误差保证的顶点样本；另外对均值采用弧长权重积分/求积，对覆盖统计使用分段弧长测度或有误差控制的均匀弧长采样。分别检查 max、mean、coverage 的不变性，不要以 max 的测试通过代替全部字段。

## 4. 噪声试验与方法比较：成立之处和边界

### 4.1 已确认成立

- 两条被插入的 floor 与 wall-top 三维中点误差均小于 10⁻¹⁵h；“上下同时在原线段上”不是虚假的 ERP 线性插点
- 横坐标扰动在 top/bottom 共享，纵坐标独立，横坐标按 1024 取模；实现符合报告描述
- 无序绑定使用与周期绑定相同的端点成本、同样每个未匹配节点 gap=8；dummy assignment 正确实现“两端放弃付两次 gap”
- 300 对噪声输入在保存输出中，unordered_bound 与 cyclic_bound 的正确数、错误数、漏配数、匹配数及插入点误配数全部相同
- R00705 的 4px 条件为 231/240=96.25%；split 冲突为 11/30=36.7%，与报告一致
- 冲突同时检查“同一个 A 被 top/bottom 指向不同 B”和反向冲突，未漏掉多对一解释中的另一侧问题

### 4.2 已披露的设计限制，不应冒充新发现

只有 2 个基础几何、每个只选 1 条边，30 次重复是已知身份的算法噪声试验，不能代表真人/不同房间总体性能。报告第 5 节已明确这一点，也主动否定了“保序全面更准”。

`σ` 每档被设为该档生成噪声标准差（`run_insertion_noise.py:27,32–33`），这是使用已知噪声尺度的条件性能，不是固定参数部署性能。但两种绑定算法使用相同设置，**不构成偏袒保序的一方比较**。未来应另外做训练/校准集确定参数、测试集冻结参数的比较。

球面角距离的单位换算为 `σ_px·2π/1024`，与垂直方向 `π/512` 一致，成本和 gap 均无量纲。该成本不是像素高斯扰动的精确似然（纬度因子和 top/bottom 相关性），报告已承认。不要把这个限制错报为像素与弧度单位错误。

### 4.3 本次新增的轻量披露建议

噪声输入未做拓扑/几何资格分层。重建 300 个输入发现 R00705、4px、第 15 次（从 0 起）产生 1 个 `invalid_footprint`。其余 299 个为合法简单足迹且相机在内；部分合法输入不再满足相机 kernel 条件，不能等同于无效多边形。

这不使“已知身份端点匹配”试验失效，也不改变上述无条件数字。但应保留每次输入的资格字段，分别报告合法几何与拓扑已改变的压力测试，避免读者把全部 300 个误解为合法房间的纯定位扰动。不要事后为了改善分数而删除该样本。

### 4.4 目标值可比性的具体边界

- 周期约束的可行映射是无序映射的子集，因此无序的最小**同一**惩罚目标不应比周期的更差；成本更低本身不说明更符合结构真值
- 包内同点异环示例是有效反例：无序完整匹配成本为 0，周期最优成本为 4，几何不同。它证明信息缺失，不是泛化准确率试验
- `run_order_and_hybrid.py:28` 的 `unordered_cost` 只加匹配边成本，没有未匹配的 gap；当前示例恰好全匹配，因此 0 是正确的完整目标值。若以后复用到部分匹配案例，应加上 `gap·(n+m−2k)`，不能拿这个条件成本与 DP 完整目标比较
- split_top、split_bottom 与 bound 使用的证据不同，不宜直接把三者 raw cost 排名解释成一种通用更好/更差。报告当前主要比较身份计数与冲突，做法合理

## 5. 局部两对/三对、180° 与混合建议的客观评价

- 真正 ±90° 转向数的奇偶性论证成立：同入口/出口方向下转向和模 4 相同，模 2 即限制转角数奇偶性。它不适用于直接比较原节点数，也不能用于不同支撑切向的真实窗口；报告明确区分了这些前提
- 报告的真实 3 对/2 对窗口是诊断案例，未把事后选窗称为代表性样本，未把未人工确认的参考环当成不可质疑真值；这是合理限制
- 近共线底点不保证顶部同样共线；代码对 top 用三维弦距而非错误的 ERP 直线弦距，逻辑正确。至于节点是否是有语义的停止点，几何数据无法证实，报告也只说“可能”并建议保留来源
- 绑定骨架、单端支持/冲突、整段替代是合理的研究路线，但还不是完成的多人算法。当前 `hybrid_local_geometry_decisions` 主要是 bottom/BEV 路径的几何距离三态，并没有完整实现 top/bottom/方向/互斥联合兼容图
- 报告明确说自动锚点、共同块和最终簇协议未验证；建议把“推荐研究方向”和“可直接上线的自动方法”继续严格分开

## 6. 正面回归结果

60 个独立小矩阵测试中，原 DP 的周期/反向最小成本与对所有保序部分映射的直接穷举一致。旋转 B 即可表达任意固定 A 起点下的循环对应；未发现周期接缝漏解或 gap 边界重复收费。正方形角窗改变环起点、将角窗整体加 1024，路径保持一致。

真实 135 次端点模式测试中，无匹配的运行有 28 次；程序按 0 覆盖、RMSE=None 输出，而不是把空匹配包装成零误差。这支持报告关于小 σ 可能导致低覆盖的警告。

这些是明确测试通过的范围，不能外推为所有参数/不合法输入/所有连续曲线的证明。
