# 局部邻接证据最小检验：计算前计划

2026-10-06。依据 are-you-sure 修订意见，先检验邻接是否有增量，不直接开发完整结构匹配器。本计划写于本轮新数值计算之前；三个窗口已用于开发，绝非盲测。

## 固定输入与问题

沿用 `research/layout_reliability_20261005/pro_original/inputs/` 四图完整池，以及 `research/point_route_review_20261006/human_review.json` 的原话与纠错。每个已审观察作为查询点，与该图每个其他人员的全部点对比较；不先筛到5°内，不因未达多数而删观察。不读取GT。

本轮只问：同一查询点的相邻两个原点对，是否有助于排除近邻异身份，是否同时损害已知同身份？这是即时邻点诊断，不是两对／三对路径等价算法。

## 预定比较

- A：查询点与候选点的端点球面角距，分别使用top、bottom和两端最大值。
- N：双方前后各一对邻点的对应距离最大值；比较同向和反向两种对齐，取较小值，并保存两个值与数值并列。源环不重排，方向对齐只用于比较。
- B：`max(A,N)`，与A使用同一角度尺度。该简单政策要求查询点和邻点同时兼容，不学习权重；不能把它叫物理身份认证。
- 保存各目标人员内A/B的所有最近候选和每个人工指定候选的排名；其他候选未审核，最近不等于正确。
- 1／2.5／5／7.5／10°逐项报告已审核正负关系的兼容变化。所有阈值未校准，5°仅演示；不按结果挑最佳阈值。不将三个窗口合成准确率。

rpc与2t7的指定三点为同角点正关系；rpc旧紫色仅相对A/B为负关系。unb只对A与B/C记上端目标不同，下端三点按暂定同处记录；B/C同上端目标不直接扩大为已认证角点身份。全池未审成员不补标签。

## 重要反例与验收

1. 同一环反向、换起点、跨接缝平移，不应改变A/B；并列方向须保存。
2. 查询角点不变，只在邻接边上插入一个真正共线的点：连续边界不变，N可以变化。该控制用于检验即时邻点规则会否误伤不同分段表达，不能为让控制通过而删掉插入点或改公式。
3. 确认环、默认未审核环分开显示。当前四图中rpc24与unb15为确认环；2t7的3与7y3s24为默认未审核环。环确认不证明跨人身份。
4. 输入坐标、来源索引、环、人数和资格保持不变。构造阶段不读取人工答案；人工记录只选开发查询位置及事后解释。没有新分簇、投票融合或成环。

## 停止与接续条件

若B损害同身份或仅通过拒绝更多候选排除异身份，不将其直接接入融合；保留正负证据。只有找到可解释增量，才设计与开发窗口分开的验证面板。若证据不足，准确列出需审核的关系。后续两对／三对必须比较连续路径及内部细节，不能将本轮的一跳邻点匹配冒称已经完成。

工具与结果分别放在 `tools/thesis_main/analysis/point_context_probe_20261006.py` 与 `analysis_results/point_context_probe_20261006/`。正式合同、SOP、源标注和GT不变。


## 用户新增要求：阈值敏感性（追加，非原事前计划）

用户提出应通过敏感性分析选择合适阈值。本节在看到上述即时邻点的开发结果后追加，不能冒称未见结果的预注册。

除五档展示值外，对已审核关系的所有实际距离转折点逐区间检查兼容变化；分案例、分top/bottom/pair、分A/B报告，不选择有利的档位。若同一案例同时具有正负关系，计算能够保留全部正关系且拒绝全部负关系的开发区间；只有单类判断时明确不可确定双侧区间。这是开发可分性，不是最佳门限或独立验证结果。

局部两观察的距离门限，与完整链接组内最大距离门限是不同操作。即使局部存在可分区间，也必须另行核验完整人员池的分组、支持和输出，不能直接移植。后续应在与当前开发图分开的审核窗口上选择／验证参数，综合漏配、混入、未决及细节保留，必要时分top/bottom建模；不以GT分数、达票人数或单一成功率选值。
