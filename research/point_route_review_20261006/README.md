## 独立研究任务

1. 先复核现有诊断，不预设其解释正确。区分局部三点可容纳、现有整组不能合并、替代分区是否存在、点支持是否达票、完整环是否可形成。检查固定层次聚类的早期合并和同人约束分别造成什么，不能由一次整组合并失败推出所有对应不可能。
2. rpc：在完整24份人员池上研究有限替代对应／局部重新分配。先明确局部域、域外固定成员及其限制，再比较现有分区、一个无需人工答案的最小替代策略、明确使用人工约束的辅助策略。未使用人工标签的自动输出与使用标签的结果必须分开。禁止把正确三人单独当作全员共识、把他们强行归组后宣称自动成功，或遗漏被挪走成员和新冲突。
3. unb：下端由用户暂定同一墙角；A上端标矮玻璃顶，B/C标玻璃延伸到天花板处。研究同一下端身份如何保存不同上端目标及各自来源。几何多峰只是待解释候选，不能自动命名其语义；不直接平均两种目标，不把底部9票复制为某种顶部9票。哪种边界应作为任务答案尚未决定。
4. 2t7作为已有同角点定位差异的开发对照；rpc旧紫色点作为异身份混入对照。7y3s可检查副作用，但没有相应人工标签，不能当已验证负例。三个审核窗口都是开发例，不得称留出集。
5. 给出支持和反对替代策略的证据。检验输入重排／人员编号改变、微小扰动、多个等价解、同人多点、上下端分歧及接缝；只做能检验主张的控制，勿堆测试数量。对所有预先规定参数和失败状态完整报告，不用GT或这几个窗口挑选最佳阈值。
6. 将对应、中心估计、支持票数与连接分开。若生成新环，独立检查原邻接依据、顺序、自交、有效性及新增边；不按x排序掩盖复杂环，不选最大整份作答簇作前置，不自动认证物理角点。局部两对／三对的结构对应若超出本轮能力，应明确未解决，不能静默删除多余点。
