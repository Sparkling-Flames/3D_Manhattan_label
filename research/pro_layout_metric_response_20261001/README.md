## 坐标、尺度与解释边界

输入点为共享1024×512域，按保存环序交替top/bottom。原始GT生产为连续C；人员/人工GT最终LS百分比按C画布映射解释，不恢复未知初始化phase。明确原生HoHoNet为像素中心P，同射线P=C−0.5；未知来源不猜测。改变尺寸时C直接乘s，P用`(x+0.5)*s−0.5`。输出ERP固定按栅格中心采样，独立于输入phase。

相机原点、朝向和离地高度1共同固定，长度单位h、面积h²，不称米，不分别对齐两份layout。BEV是声明底环面积；列式墙带是最近底墙首交加线性墙顶代理，不是一般屋顶真实可见性。失败、相机外/边界和缺参考保持原状态，不补点、删点、封顶或填零。

near_three_pairs是两端共线路径与三角形尖凸中点的对比，同时改变点数、几何和角度，不代表真实正交2对/3对完整规律，更未验证局部整体投票。0.5px floor RMSE汇总4个底点，只有SE变化，单个SE位移为RMSE的2倍；近地平线场景是更大的合成房间，不是同房人员能力比较。真实Manhattan未计算是共同轴未定义的本轮设计边界：各layout仍可独立拟合最佳轴求自洽残差，但该残差不替代跨layout结构距离。真实RMSE缺对应身份，不由点数相同建立对应。
