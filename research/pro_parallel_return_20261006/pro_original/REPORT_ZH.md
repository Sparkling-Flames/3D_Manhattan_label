# 特殊场景全员共识与局部细节：六图独立结果

2026-10-06｜依据本次附件最新研究模型｜Manual；109份纳入作答，来自24名不同人员

## 主要发现

**非正交并没有阻断这批数据的区域共识，但“清楚可标”不等于每个人的边界坐标相同。** x8-01与x8-09均成功形成全员范围，保留原观察中的斜段，没有强制正交。两图原作答两两IoU中位数为0.848、0.856；仍有定位和简化差异。它们同属G231，不能作为两个独立房间，也不能把5人与24人的差别解释成人数效应。

**可标门洞至少有两种不同的实测情况。** uNb-47基本沿已有“全体选择两侧完整区域”的方向形成共识，但坐标并非完全一致；jtc-12同时存在范围取舍和几何差异，全员输出仍遗漏原参考40.96%的面积。不能把两者合成一个“门洞更不一致”的结论。

**rPc-06的全员面积改善主要来自减少外扩，而不是减少遗漏。** 原GT口径下，从平均单人到MV50全员，遗漏43.97%→44.92%，外扩6.94%→3.74%，总面积差D才从0.5091降到0.4865。因此“融合更近参考”不能被解释成“细节漏得更少”。

**yq-32确有面积改善与局部短转折未完整保留并存，但壁炉大轮廓是被保留的反例。** 全员MV50对修订GT的IoU为0.9252，右侧门前短折返仍被压成混合斜线；原、修GT在这个局部自身也采用较简化的封口。不能用该版GT给细节恢复背书，也不能把整个壁炉都说成被融合删掉。

**uNb-47另有比“门框高度不同”更具体的参考问题。** 两版足迹在叠图中呈明显方位差。只做一次预先从图形判断的+90°诊断旋转后，原GT与修订GT的IoU由0.3883变为0.8683。这支持检查该图的参考方位对应关系，不证明源文件错误。所有主表仍使用未旋转的原GT，未替换、选优或修改参考。

上述数字分别来自本轮四图终点计算、附件既有两图完整区域，以及本轮局部读数；不是新的大面板验证。证据定位见[S1]–[S6]和结果CSV。

### 2.2 uNb-47：同一范围选择不等于同一坐标，更不等于参考正确

已有评论的具体内容是：相机略在门框前；若只标浴室，没有人这样标，人员都纳入左右两侧／相机后方区域。这个范围选择判断沿用原裁决，不从一个低R重新推导。[S1，uNb-47 scene_evidence]

完整叠图显示，多数原作答沿同一大体围合，输出保留了两侧区域和中央浴室方向。原答面积却从1.6644到3.0650 h²，两两IoU中位数只有0.7525，平均最近边界距离0.0955 h。因此可以说“范围选择大体一致”，不能说“边界定位完全一致”。

同一全员输出对原GT的D为0.8688，对修订GT为0.1234。原图叠加还显示原GT多个方向的转折与原答并不重合，并非只少了略低门框的上界。为检验这个直接影响解释的疑点，本轮仅将原足迹绕相机+90°作一次诊断，不搜索角度、不缩放、不平移：原／修GT间IoU由0.3883到0.8683，与全员MV50的IoU由0.4104到0.8726。

该结果只提示方位对应需要核实，不能据分数变高宣布修好了GT，也没有把旋转结果写进主表、GeoJSON或人员评价。**当前该图宜用于原答分歧和实际范围共识描述，不能把原参考0.4104直接解释为集体漏标。** 门框高度目标属于另一层；Lee没有上界，本轮对此不评分。

### 3.1 局部面积诊断的定义和证据层级

从原图与已有评论先定位问题，再选有具体点号的连续原路径。将路径与端点连弦之间的面片作为只读观察窗口：rPc使用R01557的p2/p3/p4；yq使用R02256的p10/p11/p12。连弦不加入原标注，不参与投票，不产生新候选，也不宣称它是“无细节真值”。

这两个窗口面积分别为0.099462与0.174296 h²，是原GT面积的1.39%与0.96%。它们是事后案例解释窗口，不是独立冻结的验证集或已校准细节容差。

保存每位人员在窗口中的实际面积覆盖比例，供查看少数表达和混合状态。**该比例不等于确认同一细节的票数**；一份大范围作答也可能覆盖小片，却根本没有画出所研究的转折。因此不把这些面积支持转写成“几人正确识别墙角”。

### 3.2 rPc-06：大范围差主导总分，小折返也没被完整恢复

原图在玻璃末端、地台和远端梳妆台之间可见多个接合位置；原评论已指出GT进入玻璃浴室内，但梳妆台与玻璃连接处遗漏部分细节。[S1，rPc-06 scene_evidence；S2]

原作答并非只是在同一已知角点附近抖动。R02452在该局部给出较简单转折，R01905有额外局部节点，R01557具有明确的p2→p3→p4短折返。这里不将不同点数自动判为不同实体，也不把三份几何合并成同一结构的三票。

R01557小片全部属于该原作答范围。MV50只覆盖其中39.53%，丢失0.060143 h²；严格多数只覆盖24.78%，丢失0.074814 h²。输出仍有小三角或折线，不应说“没有节点”，但它们不是原短折返被完整保留的证明。

附件人数结果还显示：MV50的原参考遗漏从单人均值43.97%增至全员44.92%；严格多数增至46.44%。全局D改善来自外扩压缩，不能解释成“增加人数纠正了漏标”。这个案例整体参考IoU本就约0.53，不是“其他都已正确、只剩一处微小细节”。

需要定位程度时，使用同一现成最近边界距离思路，沿R01557原短路径取512个等弧长中点。对MV50／严格多数／原GT的平均距离为0.0917／0.1120／0.2643 h。这说明融合在局部几何上比原GT更靠近该观测，但**距离更近仍不能证明短折返的身份与拓扑被正确恢复**。这里只证明测量对象不同，不能据此确立新的人员细节分数。

### 3.3 yq-32：大壁炉保住了，小门边转折仍被部分压平

原图可见壁炉凸出的围合，以及右侧门前的退进墙面／短转折。用户原评论明确指出有人忽略壁炉、简化右侧复杂墙角，并说明修订GT在最靠近门口的小区域提前停止。[S1，yq-32 scene_evidence；S2]

**壁炉是负对照，不是失败案例。** R01439的四对原作答没有表达完整壁炉凹凸，但全员M/S都保留了大尺度壁炉轮廓。因此“有人漏细节”并不意味着“融合必然漏掉该细节”，也不支持把壁炉错误归入本轮消失部分。

右侧则不同：R02256 p10→p11→p12保存了内收短转折；R01095和R01029也有相应区域的更细原路径，但位置不同。MV50与严格多数在该段形成多个来源混合的斜线，未完整复原任一列示的短回折。原GT与修订GT在这个小位置几乎重合，都采用较简化边。

诊断三角片位于R02256原范围之外；遗漏该内收细节会把这个片“填成室内”。MV50填入0.122920 h²（70.52%），严格多数填入0.100905 h²（57.89%）；相对该观测应叫局部外扩，**不是地面面积遗漏**。两版GT各自填入约99.13%，所以拿它们评分会倾向奖励这部分填充，而不能单靠高IoU惩罚细节简化。

这并不认证R02256的坐标就是正确墙线。它提供的是明确反例：局部有真实图像与原评论支持的问题、现有详细原路径、实际共识和两版简化参考，四者不是同一个对象。这个小片不足原GT面积1%，全局均值很容易弱化它。

沿R02256完整p9→p10→p11→p12→p13路径，至MV50／严格多数／两版GT的平均最近边界距离约0.1122／0.0612／0.1493 h；严格多数在这条观测路径上更近，同时仍没保住短回折。这个局部结果不能推出严格多数在别处或别图也更好。

## 4. 怎样改变对“分歧—融合—参考接近度”的解释

原作答R描述人本来画得有多不同；实际F_all描述区域投票留下了什么；参考D描述相对明确版本目标的面积差。三者不能互相替代。rPc的例子尤其直接：总差缩小可以与遗漏增大同时发生。yq则说明，总差明显缩小也不保证局部转折被完整保留，且细节缺失可能体现为外扩而非遗漏。

场景名不能代替这些测量。两种可标门洞呈现不同形态；非正交同房两视角仍能产出清晰区域。已得到的是这六图的条件描述，不是“所有OOS/门洞更一致或更不一致”的规律。

当前应继续用方向性面积项解释人数／构成结果，同时把已有明确细节位置与实际全员区域放在一起。对yq这样的案例，高参考IoU不宜作为“细节已恢复”的成功标志。对rPc，不宜把降低外扩的收益写成减少漏细节。

应停止三种替代推断：由全员V=0判人员一致；由局部节点很多判细节恢复；由GT接近度改善判全部边界目标正确。本轮没有重跑V或新增人数曲线，也没有放弃单团队单共识规则。
