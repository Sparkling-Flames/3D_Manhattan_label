# Pro 质量方法研究交接（2026-10-02）

本包提供当前本地实现、嵌入输入、结果和测试，供独立研究与复算。研究目标是建立可靠的GT参照标注评价，支撑人员与图片影响分析、人员分类，以及不同人数和人员构成下的融合质量与不确定性研究。

## 当前优先级

本次用户最新说明优先于下方历史路线快照的执行顺序：连线、空间表示和质量算法是主线基础；排序后的3D是这一基础的延续。先厘清如何评价作答，再研究人员与图片影响。共识沿已有Lee论文路线；分簇和局部路径是按需工具，几何合理空间候选是独立探索，不是人员研究前置条件。

具体研究方法开放。已有BEV、质心、边界、墙高、方向残差及水平顶面体积均是候选或诊断，不是要求Pro沿用的答案。算法数值可复算不等于评价方法有效；17份改序改善来自两张定向图片，不能外推。

## 数据边界

输入已经预处理，使用最终配对和共享x。人工确认环保留，其余人员环按共享x默认升序；原始GT保留来源环。默认未审不等于错误或不可用。代码不重新预处理、不批移坐标、不重新裁定GT或资格。源身份、条件、资格和失败状态随嵌入记录保留。

当前完整台账为3152份人员作答、259研究图、27人；本包仅含固定12图的195份作答，不适合直接估计全体人员能力或人员/图片效应。完整数据入口在仓库的analysis_results/research_input_20260929/manifest.json，由load_current_bundle读取；本包不包含该完整加载链。

390行中253条可计算、117条参考缺失、20条因作答几何不可用。两种GT版本分别报告，不挑更近者。长度单位为共同相机高度h，而非米。体积为水平顶面模型结果，顶面不是实测；部分几何性质由重建假设强制成立。

## 独立复算

在本目录运行，Python 3.10及以上：

```sh
python -m pip install -r requirements.txt
python -B verify.py
python -B -m pytest tests -q -p no:cacheprovider -W error::RuntimeWarning
```

verify.py只读校验文件清单、前轮嵌入结果、本轮全部对象诊断、390行指标、17组改序及其参考对照、CSV字段和数值。不会重新选样或追溯完整源表。源表绑定是本地交付核验的范围，不能冒称独立包重新完成。不要调用实验生成器的全量CLI，那个入口需要完整仓库bundle。

本包源码以当前工作区逐文件复制；仓库根目录的旧实现不能代替本包。没有原图，不据几何和评论裁定视觉正确性。历史归档里的搬迁前绝对路径不作为当前运行入口。

本包不含另存的Pro提示词；研究目标在交接对话中提供。
