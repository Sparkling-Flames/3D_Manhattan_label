## 输入与几何边界

七份都有 `existing_verified` 配对；环均为 `default_unreviewed`，`ring_confirmed=false`。这允许复现存档处理结果，不能等同于人工确认了连线意图。已知资格障碍未命中不表示当前参考重新验收。参考始终使用既有有效链，没有按哪个质量分更高来选择。

七份的当前共享前点恰好与原始导出同值；这不能推广到其他已修订记录。`inputs/review_inputs.json` 保留三个版本、源索引、既有配对、原环和冻结坐标。配对未知的作答没有被加入本图册并强行三维评分。

本图册没有发明不共享x的三维房间。橙色曲线只是沿存档环连接当前原始射线。绿色参考、蓝色结果的ERP投影分别与存档二维点复核，误差均小于 `1e-9` 像素。按固定相机高度公式逐点算出的顶点竖直坐标与冻结坐标之差小于 `1e-10 h`。相机在v=0，地板在v=-h，墙高为h+v；ERP的top y大，不必然代表实体顶点低。

关键真实反例为S107：门外第3对的top y较大，但底点接近地平线，重建深度增加，顶部v/h约0.88568，高于其余约0.50432–0.59506。局部图显示底点在洗手柜立面附近，实际墙地角被遮挡，因此不能把高顶结果全部归因于顶部点。

T07的最大上下方位差所在处，参考有两个相邻折转，当前上下点的方位分别接近不同转角。它同时包含局部结构表达和位置问题，不能当纯X残差实验。

## 复现

依赖Python 3、NumPy、Matplotlib、Pillow；无需网络。

```bash
python render_user_figures.py --review-dir .
python build_review_documents.py --review-dir .
```

第二步默认只在写完并检查用户版后，才读取研究用候选子集，避免分数进入用户版。`inputs/research_candidate_subset.json` 记录候选来源SHA256。若需要接回主研究完整表：

```bash
python build_review_documents.py --review-dir . --candidate-json ../analysis/results/candidate_scores_39.json
```

`prepare_review_inputs.py` 用于从父研究的完整正式输入重新提取精确子集；它需要旧研究恢复目录和原图索引。已经随包提供的 `inputs/` 足够重绘和重建两份HTML。

程序只重绘当前独立输出。`results/source_checks.json`、`results/per_case_analytic_geometry.json`、`results/render_geometry_limits.json` 和 `results/document_checks.json` 分别记录来源/投影、逐点几何、绘图坐标范围和匿名检查。`figures/manifest.json`及`FILE_MANIFEST_SHA256.json`提供文件校验。

用户版无外部图片、脚本或网络依赖。新图使用真实原图和精确数据生成，没有生成式图像内容。尚未收到本轮新人工回答；这套材料没有改变任何旧回执或正式资格。
