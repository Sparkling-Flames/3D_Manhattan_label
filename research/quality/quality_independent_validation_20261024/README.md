## 计算方法与官方实现核对

复用冻结 B8L2/D10 五分项和 `quality_core/geometry_metrics.py` 的布局标准指标；另核对本地 `lib/dataset/dataset_layout.py:cor_2_1d` 与官方 [HorizonNet eval_general.py](https://github.com/sunset1995/HorizonNet/blob/master/eval_general.py)（2026-10-24读取的master）。单元检查验证本地边界结果与该仓库官方边界函数相符。

官方 IoU3D 先把顶界换算为角点高度，再用平均高度棱柱求交；**其深度评价另按每一列的顶/底边界渲染**，因此能响应局部高度，不能说所有旧指标都只看均高。深度是布局角点合成的 layout depth，并非 Matterport 实测深度。

本次对每个真实输入先按冻结连续坐标还原原3D几何，再投影到 HorizonNet 所需的像素中心坐标。两侧均以相机高1归一，legacy深度采用同一1.6米相机高；同时保存 `layout_depth_rmse_camera_h=RMSE/1.6`。逐个顶部顶点保留，未把局部高度差压成平顶。完整配对、底面是否有效、相机拍摄点位是否严格位于底面内部，以及上下半球是否相容，分别记录状态；缺失不填0，也不调用几何修复来获得指标。

50份人工题目原答均可计算适配指标。B8L2/D10由原分项按冻结公式复核；legacy底面IoU与同几何冻结IoU最大绝对差为8.9e-7（float32数值差）。输出同时保留底面IoU、角点均高棱柱IoU、底边角距、自身方向、整体/局部高度、逐列深度RMSE/δ1、底角9°精确率/召回和最小分配角距。这些量职责不同，没有重新调参数，也不要求B8L2在每个实例领先。

另复用 S1/S2/S3（凹口失去/恢复和多余凹槽）及 S09 近分异形，共12个已曝光团队端点；全部冻结分数重测误差小于1e-7。S2 A→B底面IoU仅0.8414→0.8451、B8L2 75.03→78.80，底角9°召回0.5→1，布局深度RMSE 0.2359→0.1851米；这些是真实团队同时改变多项几何的比较，不能把分差归为单独角点恢复的因果效应。S09 A/B的B8L2为51.30/50.01、底面IoU为0.906/0.777，但深度RMSE为0.333/0.234米，显示不同量可能排序相反。已有两个接近地平线底点的±2像素控制也补齐6行legacy指标，见 `BOTTOM_POINT_CONTROL_METRICS.csv`；不从小像素变化推导统一容差。
