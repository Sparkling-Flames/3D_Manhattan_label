## 关于“方向＋IoU双重扣分”的独立判断

用户最新假设是：“如果方向不对，IoU肯定也不对；二者合用可能重复处罚，使扣分过重。”它是需要严谨检验的研究问题，不是本交接预设成立的结论。

现式为 `Q=100I/(1+IK)`，`K=Sb²/32+1.5D²/(D²+37.5)+(Hm/0.8)²+(Hc/0.25)²`。I>0时令`O=1/I-1`，可写`Q=100/(1+O+K)`；I=0时直接按原式Q=0处理，不能除零。

必须区分：同一种几何扰动影响多个分项；分项存在统计相关；两项测量信息重复；组合在研究效用上过度处罚。这四件事并不等价。代数上相加、相关性高或删一项分数上升，都不能单独证明重复处罚，也不能证明不存在重复。

当前D衡量自身正交轴残差，不是参考条件下对应墙面的3D夹角误差。因此用户的直觉与实际D并非同一定义：正交矩形整体转动可以保持D=0而与固定参考IoU下降；合法非正交参考与自身完全相同时I=1但D可以大于0。后一个例子用于限定测量语义，不拿非正交OOS例强迫拟合普通层。

需研究的是：在适用范围内，方向项究竟提供了IoU／边界距离没有表达的哪些质量信息，以及为这些信息付出的分数代价是否合理。允许审查重建指标定义、参考条件化、容忍区、组合或权重，也允许证明保留当前模型更合适；不预先指定解法。对近正确区域、单一误差变化、方向族塌缩、表示细分与细节遗漏等性质给出明确数学依据与适用条件，并与真实作答响应对照。数学性质不能替代实证，实证相关也不能替代数学解释。
