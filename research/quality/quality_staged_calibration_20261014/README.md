# 普通粗调、门洞细调与回归（2026-10-14）

本轮依据统筹线程中用户直接授权“继续调参”“先粗调，后用门洞交界细调”执行，接续[诊断交接](../../../docs/thesis_main/topics/quality/质量两轮Pro诊断复核与调参交接_20261014.md)。先前“只准备、不调参”阶段的文件原样保留。所有结果是研究工作版，不替换正式算法、人员资格、参考或融合。

## 当前决定

普通574份manual与9份严重例外分开比较后，暂选`hill_global08`：去掉方向四次尾项，保留共同轴加权RMS方向及有界Hill响应，整体高度尺度0.8、局部0.25。它与旧`baseline_quad08`数学相同，是恢复已有候选，不是发明新算法。整体尺度越小，惩罚越大。普通版先写入`WORKING_COARSE.json`，随后执行门洞五组邻近比较，最后仍保留中心，见`WORKING_FINAL.json`。

公式：`Q = 100 I / [1 + Sb²/32 + 1.5 D²/(D²+37.5) + (Hm/0.8)² + (Hc/0.25)²]`。D继续是现有优化共同轴加权RMS，不接入Pro的L1定义。Hc依赖参考及底边对应，不等于自身顶面方差。缺高度不生成完整Q；原始上下x差只作诊断。

## 回归与未解决问题

门洞比较后回算574普通、9严重、151控制及历史诊断；中心与冻结普通版583份逐份分差<1e−10。现有P01、弱等级及已知控制结论保持。583份同参考旧3D IoU已对齐旁列，未冒称重新全量重建；3D IoU不是人评真值。

1. J01仍约28.72/29.50，绝对分数量表意见尚未解决；不能称所有意见均已满足。
2. 去尾项减少D的支配作用，没有解决D在墙族坍缩时下降的语义盲区。已测控制单调不等于普遍结构正确。
3. T20/P04/L01历史意见只作有来源限制的回归诊断，不恢复semi/trap或参考受限样本的普通拟合资格。
4. 92份门洞held未被补成假数值。下一步只在确有用途时处理参考绑定或集中审核代表性分歧，不重审所有样本、不扩网格。
5. 本轮没有重新调整融合、发布正式人员评分或用OOS调参，也没有新二维量。优先检验工作版对既有总分分歧的解释，再决定是否需要新测量。
