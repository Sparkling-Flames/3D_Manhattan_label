# GQS-20261016-v2：数学定义与测量合同

本文档定义本轮实际执行的三套研究评分，不是对现有正式成绩的覆盖。入口：`src/geomscore.py::score_pair`；参数：`config.json`。所有方案都用固定作答—参考绑定；没有最高分选参考、几何配准、正交吸附或补造顶点。方案标签 QA/QB/QC 与旧 A10/B8L2 不是同一个算法。

## 1. 输入及表示等价

相机位于原点，相机离地高度归一化为1，底面y=-1。输入明确的、成对的bottom3d和top3d，同对点具有相同x,z。底面是有序简单多边形；墙顶高度为H_i=topY_i+1>0；相邻顶点间按真实墙边弧长线性插值。这里定义的是外围墙带高度，不推断一个未知的内部屋顶曲面。

有限坐标、简单多边形、非零边、相同底平面、垂直配对必须成立，否则返回不可评价。低层score_pair报告相机是否在内；正式清单入口拒绝相机外置的输入。本次244份均在内，不因该入口新增删除。闭合重复端点仅在高度一致时去重；不通过buffer(0)、重排环、补齐顶点修复无效输入。

沿同一直墙插入点p_j=(1-t)p_i+t p_k，0≤t≤1，保持底面不变。只有同时满足H_j=(1-t)H_i+tH_k，整个外围墙顶轮廓也不变。因此：底面共线只足以去掉一个底面结构事件，不能不看高度就删除整对点。

实现保留完整高度折线；`exact_floor`只为底面方向/形状计算去除数值共线点。其相对叉积容差1e-10是数值容差，不是“可以忽略的真实细节”阈值。环向统一逆时针及编号起点统一不改变空间位置。

## 2. ERP反投影及误差放大

采用当前快照对应的studio连续坐标，不混用像素中心+0.5约定。标准坐标宽1024、高512：

- θ=2πx/1024；β_f=π(y_bottom/512-1/2)。
- β_c=π(1/2-y_top/512)。
- r=cot β_f；X=-r sin θ；Z=r cos θ；bottomY=-1；topY=r tan β_c。
- 墙高H=1+r tan β_c。

一般相机高度h时，r=h cot β_f，H=h+r tan β_c。

因此dr/dβ_f=-h csc²β_f，δr/r≈-δβ_f/(sinβ_f cosβ_f)。接近地平线时深度反推病态。bottom y改变r，也会在top y固定时改变H。top y在固定底点时只改变顶部高度；单个x改变底点及邻边方向，所有x共同平移则是整体yaw，不改变夹角。

在512高图上底点下移2像素，对应0.703125°。β_f=5°时r下降12.396%；20°时3.694%；45°时2.425%。这来自明确定义的投影，不是相机高度真实标定或图像拼接可靠性的证明。

## 3. 共用范围与高度量

底面集合记P_A、P_R，I=area(P_A∩P_R)/area(P_A∪P_R)。这是BEV多边形IoU，BEV本身不是评分名称。任何形状项的不变性都不用于改变此IoU的原始空间坐标。

令外围墙边弧长为s，总周长L，墙高函数为H(s)，则：

μ=(1/L)∫H(s)ds=Σ_i l_i(H_i+H_{i+1})/(2L)。

这是边长积分均高，精确保持共线插点不变性，不是顶点高度的简单均值。

定义最近边界投影π_R(p)=argmin_{q∈∂P_R}||p-q||，反向同理。实现若有并列最近段，按规范化环的段顺序选择首个；这种几何歧义可能造成微小不连续。

局部高度差：

```
e_l² = 1/2 * [
  (1/L_A)∫_{∂P_A} {[(H_A(s)-μ_A)-(H_R(π_R(s))-μ_R)]/μ_R}² ds
 +(1/L_R)∫_{∂P_R} {[(H_R(s)-μ_R)-(H_A(π_A(s))-μ_A)]/μ_R}² ds
]
```

整体高度差e_m=|ln(μ_A/μ_R)|。

共用高度处罚：

```
L_H = [max(e_l-0.02,0)/0.20]²
    + [max(e_m-ln(1.05),0)/ln(2)]².
```

其含义是：对2%参考均高以内的局部RMS差和5%以内的整体高度比偏差设置容忍带，局部起伏的响应更强。局部项是相对参考的中心化差，不是作答自身平整度；参考本来不平但完全复制时不扣分。它对给定对应下的全局高度平移不敏感；不是对任意非平高度剖面的比例缩放严格不变。

限制：不同底面间的最近边界对应不一定是正确物理墙身份；底面差异很大时，局部项可混入对应误差。归一化使用参考μ_R，因此不宣称作答/参考交换下完全对称。它是本轮重新计算的`local_error`，不等于旧`Hcenter`，不得混名。

均高精确积分；局部高度与方案C采用沿整圈弧长中点采样，每段步长≤0.01h、至少256点。超过30000点直接不可评价。整圈采样而非每个输入边等点数，避免冗余点获得额外权重。细化到0.0025h的244份结果另附。

## 4. 方案A：对应夹角 + 有上限的结构辅助差异

### 4.1 三个尺度与对应关系

对作答和参考分别在ε/h∈{0.01,0.03,0.06}下做闭合折线简化。实现用最远原始点对作为双弧锚点，再递归保留超过容差的原始顶点；不插入交点。简化若无效，保留原多边形并报告fallback。随后只去严格共线底点。

这是评价副本，原始作答及用于IoU/高度的几何不变。三个尺度等权平均降低对单一阈值的依赖，但仍存在硬简化阈值跳变，不能声称具有任意扰动下的全局连续保证。

每个事件的有符号转角α_j∈(-180°,180°)从前后墙边计算。保持凹凸符号兼容和环上顺序，做部分一对一匹配。目标先最大化匹配数m，再最小化匹配点总欧氏距离；不将角度残差加入对应选择目标。这样避免“角度不对所以主动不匹配，从而逃避角度处罚”。遍历循环起点，不进行坐标配准。

边长支撑w_j=min(l_before,l_after,0.5h)。配对权重为两端事件支撑的较小值。不存在可比较转角时为NA，而不是满分。对不同复杂度布局，最大匹配优先仍可能错误对应重复凹凸；这是本方案的已知弱点。

### 4.2 夹角误差

同凹凸符号下，有符号转角差的绝对值等价于内部夹角差。各尺度：

```
E_angle(ε) = Σ_pairs w_ij min{ [max(|α_i-α_j|-3°,0)/20°]², 4 } / Σ_pairs w_ij
E_angle = mean_ε E_angle(ε).
```

`angle_RMS_deg`是容忍和截断之前的加权RMS描述量。总处罚必须按逐角残差计算，不能用RMS代替上式，因为容忍/截断与平均不交换。

### 4.3 结构辅助预算

每尺度计数差异E_count=1-2m/(n_A+n_R)。这是匹配后剩余事件比例，不是原始角点数差值。

位置只用于选择对应会遗漏“同样的凸起搬到别处”。因此保留独立、弱的粗位置辅助量。把底角射线规范化为单位向量，配对球面距离为d_ij：

```
c(d)=1                    d≤15°
     (45°-d)/30°          15°<d<45°
     0                    d≥45°
E_place=2 Σ_pairs(1-c(d_ij))/(n_A+n_R)
E_struct=mean_ε[E_count+E_place] ∈ [0,1].
```

位置偏差不进入夹角误差，也不被改名成结构消失。E_count与E_place分别输出。两个量共用一个弱预算，而非再叠加强位置重罚。15°/45°是本轮工程起点，不是实际点击精度容忍度。

最终：

```
QA = 100 I exp[-E_angle-L_H] (1-0.15 E_struct).
```

单独结构辅助最多减少其余分数的15%，不是固定15分，也不是所有几何损害最多15分：大面积缺失、严重夹角失真仍由I/E_angle反映。刻意避免“小的正确正交细节没标”压倒主要空间和角度质量。若极重要结构面积小、其余角度仍正确，本方案可能过宽；本轮深凹槽反例保留。

## 5. 方案B：转角函数整体形状

按单位周长s∈[0,1)记录沿逆时针边界走动时的累计切线角T(s)，并以T(s+1)=T(s)+2π延拓。Arkin等(1991)定义的平移/旋转/比例缩放不变形状距离可写为：

```
d_T = min_{t∈[0,1),a∈R} sqrt ∫_0^1 [T_A(s)-T_R(s+t)-a]² ds.
```

对于固定t，a是差函数的积分均值。本轮独立实现精确的分段常数积分，穷举顶点对齐事件t=s_Rj-s_Ai mod1，不使用原论文的快速扫描实现，也没有运行第三方turning-function代码。两个事件之间平方项积分关于t线性，均值关于t线性；去均值平方损失为凹二次式，因此区间最小值出现在端点。另用1001个均匀shift的独立较密网格核对6对图形；离散网格只是上界检查，不是独立证明整套实现无误。

d_T转为角度后：

```
QB = 100 I^0.7 exp{-[max(d_T-2°,0)/60°]²-L_H}.
```

它不需要角点个数相等，对同一边上插点天然不变，能感知短墙及相对边长的变化。形状分支可忽略整体yaw/平移/统一缩放，范围分支I仍保留这些差异。它包含角度和相对边长，不是独立于IoU的“纯结构项”，也不是逐面墙身份指标。没有消除反射差异。

已知失败：对正方形外框上把同样凸起搬到相邻墙，图形可由整体旋转互相得到，d_T=0，仅IoU变化处罚，工作分98.71。这是主动选择相似变换不变性带来的代价。重复高频小折线如果总周长显著增加，也可影响归一化弧长，不保证对任意噪声密度不敏感。

## 6. 方案C：连续双向墙边距离—法向误差

在两方向上沿边长均匀采样，取最近边界投影。切向量由0.04h弧长窗口的两端连弦给出，退化连弦使用原包含段方向。两边均CCW，比较切向夹角等价于一致法向约定下的法向夹角θ∈[0°,180°]。

```
l_d=min(max(d/h-0.03,0)/0.30,1)²
l_n=min(max(θ-5°,0)/25°,1)²
E_wall=1/2 [mean_{∂A} max(l_d,l_n)+mean_{∂R} max(l_d,l_n)]
QC=100 I^0.7 exp[-1.5 E_wall-L_H].
```

该量评价双向边界的距离/方向吻合，以受影响的墙长加权。它借鉴Surface DSC的双向容忍理念，但不是原始Surface DSC，也不是Boundary IoU。每点max只能避免同一点距离、法向简单相加，不会自动与IoU去重。

该工作尺度在全局偏移、统一缩放、旋转时较严；例如仅旋转10°时QC52.50，N06旧评较好但QC57.75。因此当前不推荐C作为本任务主分，而可保留为更偏边界测量/返工检查的另一研究目标。

## 7. 当前尺度并非人类普遍阈值

容忍度和量级是公开工程先验，未以B8L2均值/分位数/旧分数为拟合目标。变化过程保留：seed方案A没有粗位置预算，导致搬错墙的凸起得98.16；v2将其单独纳入有上限的辅助差异。seed方案B的25°尺度把小凸起遗漏罚至45.34，因此改为60°，并保留45°/75°敏感性；该调整依据“局部细节应较温和”的普通几何控制，不是人类绝对分数真值。两项都属于探索性设计，不能当成事先注册且盲校准。

依旧没有学到一套普适的“90=好、60=一般”边界。总分是几何效用指数，不是正确概率、工人可靠概率或专家通过概率。
