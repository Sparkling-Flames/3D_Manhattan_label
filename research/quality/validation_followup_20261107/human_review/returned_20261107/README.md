# 九份质量问卷验收（2026-11-07）

## 采用判断

本轮问卷支持Q对整体质量和部分具体几何缺陷的解释。漏画选项与转折缺失、位置选项与边界误差存在对应；高度选项没有显示清楚的对应。结合八组受控几何实验和既有尺度敏感性结果，可以把Q作为有明确几何依据、可复算、经过实验验证的任务质量指标。

按用户要求采用**最终等级和最终缺陷选项**。用户进一步指定将`20261107_answers_v3.json`（R01）单列，主分析采用其余8人，同时保存全部9人的敏感性结果。R01单列因为判断尺度明显宽松，不认定其答卷错误或无效，也不按Q相关性继续删除其他人。好／中／差是粗略判断，不要求与60／80分界一致，不要求同等级内部Q相等。评价过程允许查看分数及暂定分档，因此本轮是最终评价反馈，不称为全程隐藏分数的独立盲评。原始答卷不改动，初始等级只保留为来源字段。

## 缺陷选项与几何是否对应

每份标注先统计明确缺陷判断中勾选该选项的比例，“无法判断”不算“没有缺陷”。主分析8人共有438条明确的单标注缺陷判断，允许多选。统计相关以60份原答为单位。

|选项|勾选次数|实测观察|结果|
|---|---:|---|---|
|漏画|143|参考有效转折数减原答有效转折数的正部，5°判转折|选项比例与缺转折数的Spearman相关0.570；至少半数明确判断勾选的15份标注，缺转折中位数2，其余45份为0|
|位置|259|底面边界角误差S_bottom|相关0.294；至少半数勾选的45份标注，误差中位数2.242°，其余15份为1.450°|
|多画|45|多余转折、超出参考的面积比例|相关分别0.264、0.225；没有标注达到至少半数勾选|
|高度|29|Hmean、Hcenter及其合成高度损失|相关分别−0.155、0.001、约0.000；未见清楚对应|
|连接|19|未收集具体错误边位置|保留记录，不把“多边形可计算”当成连接语义正确的证明|
|未发现明显问题|56|整体Q|至少半数选择该项的4份原答平均Q94.38，其余56份平均55.50|

转折缺失是解释性结构指标，不是给B8L2新增的扣分项。漏画还可能涉及范围、墙段或位置，因此点数相同也可能被勾选漏画。位置选项与自身方向残差相关0.334，但方向残差不等同于位置误差。高度项的测量能力主要由受控几何实验说明，本轮人评不能写成所有分项均得到对应验证。

问卷没有逐墙圈选，当前回答的是缺陷类型与几何测量的关联，不裁定每一票指向哪个墙角。详见`DEFECT_COMPONENTS.csv`、`DEFECT_RELATIONS.csv`。

## 能支持的论文表述

受控几何实验说明指标测量什么；真实原答问卷补充整体质量、漏画和位置问题的解释；父目录已有B8L2、D10及预设变体对人数与换人的敏感性检查。三部分共同支持“Q具有可解释的几何基础，能够用于本任务的质量比较”。

客观性落实在几何定义、固定计算和可重复验证；参数表达对不同误差的取舍，不把它写成唯一正确的权重。人评是补充证据，不作为唯一真值，也不要求每份等级与Q完全一致。已有均高棱柱IoU是有意义的基线，应保留；不必为了凑排行榜去寻找完全同任务的现成算法。评分验证与共识方法的基线实验分别说明各自能力。
