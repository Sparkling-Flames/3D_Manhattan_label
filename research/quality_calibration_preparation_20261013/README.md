## 3. 新控制发现：方向残差与墙间夹角并非同一个量

控制固定参考、上下x、所有top y、点对及环序，只改变bottom y，再完整重建三维。单个点移动为两倍预算；多个点交替正负移动为一倍预算，故二者bottom y RMS相同。**相同像素RMS不等于相同主观严重度**，只用于分离集中/分散误差及投影放大。不是修复真实J04。

狭长矩形的多个底点控制出现如下响应，正负对称各一组：

|bottom y RMS|底面IoU|Hc|共同轴方向RMS D|已知矩形角点相邻转角偏离90° RMS|当前Q|
|---|---:|---:|---:|---:|---:|
|8像素|0.8031|0.0773|18.82°|43.62°|9.39|
|16像素|0.6232|0.1778|11.44°|65.66°|16.86|

二维位移加倍，底面接近程度、高度及已知矩形墙角都变差，但方向残差下降，当前总分提高约7.47分。两组结果保存于[响应发现](RESPONSE_FINDINGS.json)，不是新增人评排序。

共同轴由约82.27°变为14.09°，但不能只归咎于轴重选：即使固定参考0°轴，残差仍从20.34°降至18.15°。**每条边靠近任一正交轴，并不保证相邻墙角更接近90°**；边可以靠近另一个轴或趋于平行。这是指标语义和总分权衡问题，不是通过几个参数就能自动证明修好的数值错误。

因此后续要先明确D在评价什么，再比较尾项强度。这里的墙角诊断仅适用于构造的四个真实矩形角；真实标注可能含180°停止点、凹角或合法非正交，不据此直接新增统一90°罚项，也不要求所有到GT的位移增加都必须机械降分。

J04继续保留在普通manual基线，当前Q约7.25，高度实际扣分仅约0.034；它仍是方向/总分争议，不能由顶部角点控制替代。未给J04重新匹配或修点，也未将“一个bottom y导致”当作本轮已经独立证实的真实因果结论。

## 4. 调参开始后的固定推进和验收边界

1. **先方向与总分。** 以J04/J01、新底点控制和已有真实分歧为依据，区分单点投影放大与多处歪斜。先检查少量有机制依据的方向响应；若仍无法兼顾，再比较组合方式，不同时改多个机制。
2. **高度意见同时保留。** 1.0/0.25只是工作基线；T20适度加重仍是有效方向，P04与L01分别限制相对取舍和过度拉开。整体高度严重端缺口明确报告，不借不可靠参考填补。
3. **严重端真正参与。** 9份严重例外参与独立分层的弱等级/回归约束，不能永远旁观，也不能为了维持目前个位数而阻止合理修改。普通总体与严重反例的目的、权重和分母分别报告。
4. **明确什么算进步。** 同时报告P01明确偏好、C02/J01不确定、J04最新边界、严重端、T20/P04/L01代价及不可算变化。C01/C03/C04等semi历史意见可作机制和回归旁证，不能偷偷变成纯manual硬约束。不以某一例涨分、24个非独立弱等级比较无逆序，或控制满足设计来认证普遍有效。
5. **二维量最后再决定。** 先利用现有IoU、底边距离及逐边残差检查信息损失。新增二维指标需明确点数不同、漏点、多点和匹配歧义的处理，不能用简单平均让重大结构错误被许多正确点抵消；原始x仍不入Q。

未来有少数方案形成可解释、稳定的折中，即可确定工作版本；无需等到参数唯一最优。若尚有能改变选择的取舍，集中审核，隐藏算法名与分数，问哪份整体更好/是否接近及主要问题，允许无法判断。此次没有提前制造待审队列或要求用户重复已明确的偏好。
