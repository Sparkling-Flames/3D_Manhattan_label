## 2. 公式实际改了什么

基线与主式都使用相同的底面IoU、底边距离和局部高度尺度0.25。主式只在旧方向Hill项上加`(D/12)^4`，并把整体高度尺度从0.8放宽至1。

主式和简式都使用`Hm² + (Hc/0.25)²`，其他底面项也相同；两者仅方向项不同：主式为旧Hill加四次尾项，简式为`D²/64`。同一作答、同一参考下，两者高度损失相同；最终“高度导致的扣分”仍可能不同，因为底面损失改变了总分分母。这种分数压缩不能解释为投影耦合被解决。

对962份完整结果，主式相对基线：

- 分差中位数−0.059，平均−1.298，86份下降至少5分。
- 方向改变的精确代数贡献平均−1.392分，最大降分20.702；整体高度放宽平均补回0.095分，最多2.234分。局部高度参数没有改变。
- 简式相对基线分差中位数+3.128，333份上升至少5分。因此它广泛放宽普通样本方向惩罚，不是仅修补严重尾端。
- 按每图先求平均，再等图观察，主式平均变化−1.346、简式+2.530，方向一致；这是描述性检查，不是统计显著性或质量提升认证。

代数贡献定义为`-100 × I × (新损失项−旧损失项)/(旧总分母×新总分母)`，各项之和精确等于总分差。它只适用于此处同分子、加和分母的冻结候选，不是因果解释。5分仅为易读的变化幅度，不是人工质量等级阈值。

## 3. 原评论揭示的关键混杂

962份完整结果中，547份带既有图片或作答范围/细节标记；415份没有记录这些标记，后者也不等于人工确认干净。两层均保留条件结果，不把所有范围差异自动排除，更不把条件诊断全量拿去拟合。

全局高度相对偏差达到20%的32份中，**26份集中在B6ByNegPMKs一栋建筑**。20%只是覆盖统计切点。按整体高度单项影响挑出的前三图恰好都是该建筑走廊，旧评论分别注明不同停止点/位置。它们不能直接成为“人员整体高度错误”的纯案例。

## 4. 已有高度证据应如何使用

[Pro校准报告](../quality_pro_joint_archive_20261013/source/calibration/CALIBRATION_REPORT_ZH.md)的T20：旧顶部距离主导的v1.1分数16.72，基线72.56、主式74.29，无高度项77.81；目前仍因高度扣约3.53分。它支持纠正旧顶部项过度主导，不要求把新分数继续抬到某个目标。

P04在固定局部尺度0.25时仅约束整体尺度大于约0.74346，不能唯一识别为1。现有manual开发11条弱等级是3轻微、8明显、0好；五项约束包含同一C02配对的三个观察角度与P05非评分语义诊断，不能当五个独立高度偏好。T20/P04继续作历史机制证据，不混回当前manual拟合。

[既有控制报告](../quality_pro_joint_archive_20261013/source/experiments/REPORT_ZH.md)中，相同球面预算的优先级检查，主式与基线都为29/30；同三维位移预算都为13/16。它们不证明新主式全面胜过基线，等几何预算也不是等主观严重度。局部Hc能识别角点均高棱柱IoU漏掉的局部起伏，这不等于胜过真实非平顶面体积IoU。

## 5. 参考变化不能归功于公式

150份既有双版本作答的主式分数差绝对值中位数5.95、最大38.38。它们不是150份新增独立验证，也不说明哪版更正确。不能据此取高分或宣称整个数据集主要受参考影响。

进一步追溯找回144/144份历史修订GT绑定：旧`current_components.json`都记录了具体参考与当时可用状态，空绑定是旧922子集截断造成的信息遗漏；**不能再写成“以前从未有参考”**。但同源`target_alignment_ledger.json`也将144/144标为范围混杂，全部有图像范围差异，因此恢复历史条件结果不等于确认当前主目标。七图分别为UwV83HsGsw3-09、q9vSo1VnCiC-32、yqstnuAEVhm-32、uNb9QFRL6hY-63/65、yqstnuAEVhm-31、q9vSo1VnCiC-01。

`HISTORICAL_REFERENCE_BINDINGS.json`保存原zip、精确成员路径、144份参考字段和原目标对齐记录；`RESULTS.json:historical_fixed_reference_replay`现仅保留其中121份普通场景，另23份uNb-63 OOS隔离；关联已完成的当前几何补算，不重新选参考。yq-32旧限制为`restrict_primary=false`的非自动复核提示，不误升为硬排除。当前962份汇总与这144份历史条件对照分开，后者不因找回绑定而自动进入拟合。

当前313份普通manual路由记录中，旧/新参考与旧/新公式四格均可比较的有95份完整、312份底面。其中参考发生改变的只有1份完整、218份底面。**多数空间变化仅支持底面归因，不能据此声称完整质量随参考修正改善。** 缺顶面的参考不补分。

同图同参考下，主式与简式有220对排序互换，分布47图；其中18对在两式下分差绝对值均至少2分。不同配对共享作答，不能当220个独立审核结论；2分只是筛查幅度，不是显著或可感知阈值。

## 6. 执行决策与交付

1. 继续冻结候选，不切换正式算法；主式/简式的争议先定位为方向响应争议。
2. 高度研究先检查走廊停止范围、底面对应与参考版本，保留全局和局部两项。避免用同楼的多份走廊样本反复校准整体高度系数。
3. 144份旧固定参考已找回并接回结果；继续按七图已有范围证据解释，不自动采用修订版作为每份作答的真实目标，也不要求重审144份。
4. 消化上述旧证据后，才从跨建筑、参考明确的同图比较中提出少量人工问题；不要把极值表直接发给用户当“纯高度错误”。当前没有必须立即人工回答的问题。
