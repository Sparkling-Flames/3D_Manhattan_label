## 怎样核验

- 选择“较好／较好与一般之间／一般／一般与较差之间／较差”之一即可，备注可不填；轻微偏差可以仍属较好，不需要猜精确分数。
- 参考或范围不适合评价、看不清／暂不能判断另设选项，不归为较差。
- WQ分数默认隐藏，允许主动展开；保存第一次展开时的已有档位。隐藏分数不等于此前从未曝光，也不称独立盲测。
- 答案自动存入当前浏览器。中途和完成后可导出 `quality_coarse_review_20261015_v1.json`，交回本线程即可；导入功能可恢复此前导出。未回答不算认可或负面意见。
- 普通在前、门洞在后；不强制锁住跳转，防止无法判断的个案阻塞后续。门洞先检查目标是否可比，再给粗档。

## 选择依据

数值和参考绑定来自[联合审查1145表](../quality_joint_closeout_review_20261015/JOINT_COMPARISON_1145.csv)，几何实际取当前 `load_current_bundle()`，使用仓库已有冻结几何转换。44份全部保留原WQ，没有重新评分。

普通32份由两部分构成：24份在WQ四个分位区间各选6份、每图一份，固定随机种子20261015；另4张图各选2份WQ/IoU有明确反序的作答，共8份压力例。普通合计28图，避开上轮8张开发卡涉及的图片、明确目标暂缓及原留出。分位区间仅用于覆盖抽样，不是预设质量档位；按固定随机顺序显示，不按分数排序。压力例不能用来估计总体误判率。

门洞来自115份一般条件层，覆盖全部10张图片，每图先选1份，再补2份分数两端的作答。Q01/Q02明确范围诊断及其他完整数值中的目标暂缓不进入本批。门洞仍是条件参考比较，不因入选就认证其目标已完全适合；用户可在页内再次标记范围问题。

这是一批开发性粗核验，不是独立泛化测试。普通层先定粗档，之后查看门洞是否存在系统性差异；不把单例偏好当硬拟合目标，也不自动修改人员等级。后续如用本批确定分档线，需另留图片检验，不能再把本批拟合程度当独立准确率。

## 文件及回执合同

- `manifest.json`：schema=`quality_coarse_review_20261015_v1`，44张单作答卡；每张保留作答、图片、参考对象和参考依据。普通N01–N32、门洞D01–D12。
- `selection_provenance.csv`：选样角色、固定数值及原用途／资格字段；不向页面提供预期人类档位。
- `geometries.json`：当前输入点与显示几何；`scores.json`保存WQ与同参考IoU来源，页面只可选展示WQ。
- `data.js`：页面离线读取的固定材料；隐藏分数是界面设计，不是访问控制。
- `photos/`：本批38张原图的原字节副本，独立目录便于窄范围本机预览。可从原图目录重建，不需要再次纳入Git。
