## 哪些结论成立

**“得分制”不必是新模型。** `s_j=w_j/(w_j+p_j)`再取加权调和平均，恰好返回`100/(1+Σp_j)`，权重抵消。它可以用于等价展示，但不能声称35%的方向权重已改变方向的重要性。

**本轮算术组合确实允许其他优点补偿很严重的单项错误。** A的扣分形式为`100Σ[w_j p_j/(w_j+p_j)]`，每项有上限。整体高度仅给5%预算时，即使高度差无限大，只要其余项理想，仍趋近95分。RA加上范围约束后修复范围趋零仍高分的问题，却没有修复高度项过早封顶。明确几何控制中，四倍房高的A为95.02、RA为92.89、WQ为6.64、同底面的棱柱3D IoU为25。这说明“整体高度相对次要”被实现成了“无论多错都只能少扣”；不需要先要求真人给这个例子精确分数，便能识别该额外假设。

**局部高度诊断有必要与原始3D IoU区分。** 本地`eval_layout.py`和[作者公开实现](https://raw.githubusercontent.com/sunset1995/HoHoNet/master/eval_layout.py)都用角点恢复的平均高度计算棱柱交并比；它不是任意起伏顶面的真实体积积分。固定底面与角点均高的局部顶部起伏可以不改变该IoU。这支持报告局部误差，不认证某一种绝对扣分必然正确。

**结构测量的区别有用，但尚未形成已验证的替代总分。** 共同正交轴规整性、参考相对的相邻墙角、墙体遗漏是不同问题。它的角度函数保存凹凸角区别、要求显式对应并报告覆盖，在显式合成控制中有价值；没有在真实331/718条上重建新对应和角度测量。合法非正交自比、窄分支遗漏的反例限制D的解释，不能据此断言所有普通样本方向项失效。

## 不能扩大解释的结论

1. 本轮验证的是一套分项映射、三个试验权重和A/G/RA组合，不是穷尽所有得分模型。不能把“不建议这两个算术候选”扩大为“所有得分制都不行”。
2. 权重采用相同完美点附近的一阶损失敏感度设计，微小损失的一阶效应不会因35%与5%而相差七倍。它主要比较中、大误差的补偿和封顶，不能称为已经完整实现用户的“夹角＞范围＞局部高度＞整体高度”偏好。D本身有上限，因此其名义35%也只是最大扣分的预算上界，并非实际必能扣满35分。
3. A在同一分项下不低于WQ是公式性质，平均分上升不是识别改善；WQ在某些控制更低，也不证明它的人类效度更好。真实角度误差能否可靠取得仍需解决。
4. 原包的人员表只按各人所做不同图片的记录均值排序，没有共同图片面板或图片条件校正，最低5条也是本轮设置。恢复来源后能输出排名，不代表已得到可采用的人员能力排序；本次不采纳该排名。
5. 引用文献主要支撑布局表示、范围歧义和一般组合方法，没有提供独立外部人评样本验证本项目权重。已核查[Bi-Layout摘要](https://arxiv.org/abs/2404.09993)所述两种范围；[OECD出版页](https://www.oecd.org/en/publications/handbook-on-constructing-composite-indicators-methodology-and-user-guide_9789264043466-en.html)确认文献来源。本轮未逐页复核其全部文献插图，也没有把四项引用称为完成了广泛的外部质量案例验证。
