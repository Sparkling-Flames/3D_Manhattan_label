## 四、旧校准证据存在什么问题

1. **来源混合**：旧24条等级包含13条manual、5条semi trap、4条来源待核semi、2条已确认非trap且改过的semi。Pro的`build_evidence()`没有按这些来源分层。旧结果可以留作历史开发结果，不可声称满足用户最新的主校准政策。
2. **排除状态没有等同于拟合屏障**：922条数值输入中有15条当前gate为excluded；它们不是W019/W026，也不意味着15条都进入拟合。旧24条等级与这15条无交集；22项约束中有3项涉及它们：P04高度比较、P02处理后等级、P03处理后等级。其中P04会进入旧搜索器的条件比较；P02/P03的等级型约束没有被该`build_evidence()`分支转为拟合比较，不能夸大为三项都直接影响优化。
3. **人工意见有版本**：J02的原排序/拉大分差意见已被用户后续修正；保留历史回执，关闭其当前排序用途。J04/R03274最新为明显与严重之间，新输入视图暂停其旧T13单一硬等级，不擅自换成另一个等级。J01、J03的不确定不能转成强制胜负或参考指定。
4. **有效人评仍有限，但不能因误解字段进一步删减**：574份manual条件开发交集中，原24条含13条manual；暂停T13最新边界意见下的旧硬等级、排除T22范围混淆的主拟合用途后，保留11条旧弱等级和5项比较约束。约束不是独立审核数。先前“只剩1条等级/3项约束”是错误收窄，不再作为推进依据；当前仍没有新独立人评支持唯一参数或通用等级切点。

P04“局部不平比整体偏低更应罚”的研究方向仍有价值，但旧数值配对涉及semi trap和已排除作答，不能直接作为新主池硬约束。应在合资格真实作答或明确标明的控制实验中核验同一机制；不因此否认用户的观察。
