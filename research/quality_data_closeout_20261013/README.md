## 3. 高度与底面对应已实际核查

[高度专项结果](../quality_height_correspondence_20261013/README.md)覆盖962份当前完整结果及121份历史参考对照，共1083份。Hm/Hc几何复算最大差`7.22e-16`；最近底边同距取最大/最小规则的影响至多`1.49e-13`，不是本批问题的来源。

这同时限制两种过度解释：不能把所有高度差异当人员错误，也不能以范围混杂为由认定高度差异都是假象。分解只作解释，未把它新增为罚分项；主式与简式高度参数相同，二者差异仍来自方向项。
