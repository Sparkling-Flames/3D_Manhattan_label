# 高度校准准备与五候选小范围比较

2026-10-13。三项准备已完成，随后按预先写入的[设计](DESIGN.json)比较了五个高度尺度组合。**当前保留主候选的整体尺度1.0、局部尺度0.25作为工作基线，未认定它们最优，也未替换正式算法。** 五个候选都通过已有明确总质量方向；现有证据不能唯一识别高度尺度。继续扫参没有依据。

## 1. 完成了哪些准备

1. **核查测量响应。** 复用48份旧高度控制，新增62份几何控制，覆盖两轴倾斜、正负单角点异常、严重整体升降、均高偏低叠加倾斜及零误差。旧`local_height`实际上是角点交替高低，不能替代两侧倾斜实验。新控制独立按线性边界积分核验均值和方差；Hm误差小于1e-10，Hc最大绝对误差3.90e-8，单因素幅度增加时五候选均不涨分。原几何不变。
2. **固定数据与证据。** 574份manual、70图、19建筑；逐份检查现有条件许可、人员/参考限制、原留出和场景阶段。207份有明确普通场景记录，367份沿用既有条件开发许可；后者不能称逐图认证正常。11条弱等级为3轻微、8明显，没有“好”级；5项约束只有C02、P01、P05三个问题组。近期5份完整问卷及台阶1份仅评论保留原义，不转成分数目标。全部人评仍为开发证据。
3. **先写选择规则，再计算候选。** 固定底面、方向项、尾项、参考、点对、环序和高度二次幂，只单独改变整体或局部尺度。P01明确总质量方向为回归关口；C02接近不拟合为精确相等，分项偏好不升级为总质量偏好。弱等级、分数分布及按建筑留一均作诊断，不因分数普涨或逆序减少自动选优。

原282份留出未重切，已知其中148份进入过新增融合诊断；既不声称282份全盲，也不认证其余134份全盲。本轮未使用留出作答调参。门洞第二阶段，OOS不拟合，R00977台阶暂缓，原始x诊断不进入Q。GT轻微问题沿用正确工作参考，明显错误及既有限制保持。

## 2. 三类高度异常的实际响应

Hm是相对参考周长均高的偏移；Hc是去均值后、依赖底面对应的高度残差。在**同一底面、平顶参考**的控制中，Hc等于周长加权高度标准差。这个等式不能推广到任意不同底面的真实案例。

下表固定正方形底面，参考墙高2.6个相机高度，其余误差为零；角点位移以参考墙高为单位。分数仅展示函数响应，不是人工认证质量等级。

|控制变化|Hm|Hc|主候选分数|
|---|---:|---:|---:|
|两侧分别高20%、低20%|0|0.1633|70.09|
|仅一个角点高20%，其余不动|0.05|0.0645|93.53|
|整体高60%或低60%|0.60|0|73.53|
|均高低25%，再叠加两侧±20%倾斜|0.25|0.1633|67.15|

因此：

- **倾斜没有漏检。** 两侧相抵不触发均高项，但触发局部项；仅看平均高度确实会漏掉它。
- **孤立角点并非纯局部误差。** 不改其他角点时它同时改变均值和起伏；不能为了让它成为“纯局部”而先平移其余角点。其分数高于同峰值的两侧倾斜，来自影响边界范围较小，不是数值故障。是否轻罚过头，仍缺对应的人评严重度证据。
- **Hc不识别错误形态。** 在上述同底面条件下，不同形态只要去均值RMS相同，就得到相同Hc。调局部尺度会同时放大倾斜和孤立异常，不能让算法单独偏爱或重罚某一种形态。暂不新增峰值/倾斜重复罚项。
- **几何支持长度有影响。** 狭长矩形同为角点±20%，沿短轴倾斜Hc约0.1862，沿长轴约0.1366；边界上维持较大偏差的长度不同。这是周长加权测量的含义，不应误判为旋转不一致。
- **严重整体高度可检出，但处罚是否足够未被验证。** 纯整体偏差60%仍约73.53分。它与±20%倾斜接近，是当前设计的结果；不能从“单调且可算”推出惩罚合理。正负对称也只是当前相对高度测量的性质。

## 3. 五候选比较结果

尺度越小，惩罚越强。五候选都保持同一底面分数；没有搜索方向参数、交互项或等级切点。

|候选|整体/局部尺度|相对main最大绝对分差|574份中变化≥1分|P01正确方向分差|
|---|---|---:|---:|---:|
|main|1.0 / 0.25|0|0|24.98|
|整体稍强|0.8 / 0.25|1.20（降）|5|25.01|
|整体稍弱|1.2 / 0.25|0.67（升）|0|24.96|
|局部稍强|1.0 / 0.20|2.29（降）|15|24.26|
|局部稍弱|1.0 / 0.30|1.32（升）|3|25.38|

11条弱等级导出24个非独立比较，五候选均为0逆序；移除任一涉及建筑后仍为0。**这是证据分辨力不足，不是五个公式都已验证正确。** C02分差约1.98–2.43分，无人工认可的精确容差，不能按更小者机械选优。按图片/建筑等权汇总也已保存，不让作答数多的图直接主导整体变化统计。

开发池Hm中位数约3.11%、95分位14.38%、最大25.24%；Hc中位数1.72%、95分位6.14%、最大22.32%。尤其是**严重整体高度错误缺少当前主池覆盖**，不能用这一轮分布稳定来宣布严重端可靠。调整整体尺度在主池影响很小，在严重控制上却可以明显改变分数。

最新五份可解释高度案例另列诊断：R01977/R00961/R00848主要对整体尺度敏感；R02135/R00687对局部尺度更敏感。这与“两侧倾斜/成片高差、部分整体偏低”的反馈相容，但不是完整语义对应认证。其中只有R00687属于574份；其余保留原范围限制，不因这次审核自动加入拟合。R00977没有重评分。

## 4. 历史意见和严重反例没有丢失

主比较后检查发现旧主池入口没有包含L01，因此在计算历史旁列分数前补记设计说明：**T20/P04/L01及9份已有数值的严重例外只作诊断，不改变主池或选优规则。** 这一附加检查不是事前盲测。

- T20主候选74.29，本轮五候选72.50–75.30；没有回到旧顶部项过罚的16.72。不能据此指定T20应得多少分。
- P04五候选都保留“局部不平那份高度损失更大”的历史方向。P04涉及semi trap/排除作答且跨图，只作机制旁证，不能混入纯manual拟合，更不能转成总分排序。
- L01两份当前均为semi，继续隔离。主候选B−A约4.20，局部稍强约5.18、稍弱约3.65；“三维B略好、整体接近、二维A近GT”仍不提供数值分差目标。全域加强局部项会放大这类差距，应保留这一代价。
- 9份已许可严重例外的主候选约1.56–9.16分，五候选整体范围约1.56–9.38；没有因本轮高度邻近调整普遍抬成高分。另7份缺配对/数值仍未硬算，人员排除状态不变。

## 5. 当前决定与下一步

**保留main作普通场景工作基线，记录可比邻近范围；不强行选新参数。** 本次证据能证明分量的计算含义与局部响应，不能给严重程度定量标尺。总体优先顺序继续保留，但不能变成任意幅度下的绝对排序。

下一步先从既有可算普通manual中找能覆盖较大整体高度偏差及单角点异常的真实案例，核查它们的参考、底面与资格；不能把semi或未决范围案例偷偷补进来。确实没有适合的真实证据时，明确说明缺口，再集中提交少量形态清楚的控制/真实对照，只问“哪份高度问题更影响质量、差异是否明显”，允许接近或无法判断。先不重复审核总体偏好、不造目标分、不继续扩大参数网格。

门洞阶段可以用此工作基线逐图作描述，但**不能借门洞低分的预期弥补普通样本严重端证据不足**，也不能据此提前作人员等级判断。当前无需用户立即补填问卷。
