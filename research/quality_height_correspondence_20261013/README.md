# 高度案例的范围、底面对应与顶部视线核查

**最新人审解释优先：** [审核回执与澄清](../quality_scope_resolution_20261013/REVIEW_FINDINGS.md)。R01977有“一侧低，另一侧更低”的可见高差，不能因Hc较小当作视觉平整案例。大部分案例需按两侧倾斜/成片高差理解，不直接归为孤立坏角点；GT轻微问题仍按正确参考处理。

2026-10-13。已检查962份当前条件完整结果及121份恢复历史参考的范围混杂结果，共1083份；原23份uNb-63 OOS已移至单列历史诊断。没有改变输入点、配对、环序、参考指派或评分参数；缺确认顶面的217份仍只保留底面。

## 已核清的计算问题

- 从当前完整loader的处理后坐标重新建立几何、复算整体均高与局部中心化残差，最大差`7.22e-16`，与已有结果一致。
- 最近底边对应使用既有连续边界采样及双向积分，4096点/方向。比较同距匹配的最大与最小高度残差规则：仅一份有数值上的不同高度并列，对Hc的最大影响`1.49e-13`。**当前异常不是同距取最大规则造成的。** 这不证明最近底边就是语义上的同一堵墙。
- 另外沿每个作答角点的水平视线求参考底边交点，5440个角点中5175个只有一个正向交点、265个有多个；937份作答全部角点唯一。多交点保留歧义，不自动挑最近或得分最高者。这只是另一层诊断，不更改原Hc对应。

## 诊断如何区分底面深度和顶部视线

相机高度归一化下，底面y=-1，墙高满足`h = 1 + r × tan(顶部仰角)`。对唯一的参考底边射线交点，保留作答顶部仰角、仅在代数上代入参考深度，比较它与参考在该视线上的高度。

原高度残差可逐点精确拆为“深度变化贡献＋参考深度下的顶部视线残差”。没有生成修复后的layout、没有重新算一个更高Q，也没有假定参考语义必然正确。所列RMS按有唯一交点的角点等权，**不同于按周长积分的Hm/Hc**；它用于定位来源，不能替代主分。分量RMS不能相加当总RMS。

前三份整体均高都比既定参考低，且自身局部起伏较小，符合“整体偏低但相对平”的数值特征。它们确有走廊停止范围评论，然而代入参考深度后残差并未明显消失。因此撤回“范围差异足以解释这些高度差异”的任何暗示：**范围混杂应保留，但不能据此抹掉独立存在的顶部视线差异。** 仍不能仅由该差异断言人错或GT错，因为停止面及顶界的语义目标未由此认证。

局部案例也有实质信号：后三份作答自身高度标准差分别约为参考均高的7.48%、7.61%、8.96%；参考自身标准差分别约0.0051%、0.0009%、0.0018%。原Hc与这些自身起伏相近，且改用参考深度并未消除顶部视线残差。这支持继续保留局部高度诊断，不支持把所有局部起伏归咎于最近底边对应。Hc仍包含双向对应权重，与自身方差不是同一个定义。

R00977还带有走廊停止位置与曼哈顿解释的旧评论；R00687仅有解释层默认版本说明，未找到非空人工参考争议。全部原评论、有效参考ID、当前几何限制和数值均在RESULTS逐份保留，不把历史措辞新升级为排除裁决。

## 对质量算法的含义

1. 整体高度与局部不平需要继续分开报告。当前候选已能数值区分这两类，不应因T20而删掉整体高度约束，也不应因范围混杂而取消全部高度评价。
2. 暂无理由修改最近底边的同距规则。要解决的是语义目标与投影耦合的解释，而非修补一个本批数据未显示影响的数值细节。
3. 新的顶部视线分解只作核查，**不加进总分**，避免与已有Hm/Hc重复处罚。参数强弱仍需参考明确的比较证据，不能让这六份同楼/混杂案例决定阈值。
