# 3D IoU的适用边界：控制示例与真人旁证

2026-10-14。入口：[可旋转示例页](EXAMPLES.html)。6个合成控制和1组既有manual旁证，默认折叠指标与解释，支持同步旋转、缩放、坐标刻度和相机标记。示例用于说明测量机制，不调参、不改正式质量算法、参考或人员资格。

## 核实后的论点

**HoHoNet评估中的底面多边形＋角点平均高度棱柱IoU，不足以单独代表自由人工标注的完整质量。** 不能写成“3D IoU本身无法比较不规整几何”，也不能将“人工标注大多歪斜”作为本轮已验证的频率结论。

HoHoNet沿用HorizonNet布局表示和后处理，但一般曼哈顿布局可以有多墙、凹角。`lib/model/modality/layout.py`默认`post_force_cuboid=False`，一般布局无效时才回退四墙长方体；统一高度由`z0/z1`和`infer_coory`构造。网络原始输出与约束后的最终输出应区分。“全部都是立方体比较”不成立。

`eval_layout.py:test_general`从底面得到多边形P，再对逐角恢复高度取均值H，计算：

`IoU = area(P∩G) × min(Hp,Hg) / [area(P)Hp + area(G)Hg − area(P∩G)min(Hp,Hg)]`。

在共同地面、竖直墙和水平顶面下，这个公式是相应棱柱的体积IoU；对于不平顶，代入均高就是一个摘要表示，不能冒称原顶面围成体积的精确交并比。底面仍保留多边形形状，并非被自动替换成长方形。它能响应歪斜造成的区域变化，但没有独立表达角度、局部错误分布和任务语义。

## 固定控制与结果

所有合成例均以相机为原点、地面Y=-1、h为相机高度；尺度不是实测米。S01/S02/S05参考为4h×4h、房高3h。每个坐标和绑定见[examples.json](examples.json)。

|例|控制|均高棱柱3D IoU|能够说明什么|
|---|---|---|---|
|S01|同底面，平顶3h vs 两侧倾斜的2/4/4/2h|100% / 100%|均高相同使局部高度信息消失|
|S02|宽度缩小10%的矩形 vs 剪切平行四边形|90% / 90%|相同体积接近度不能唯一说明墙角规整性|
|S03|保留 vs 填平0.2h宽、1h深凹口|100% / 98.75%|小体积的结构遗漏在IoU中权重小；是否应重罚取决于任务|
|S04|外侧范围参考下，外侧目标 vs 内侧目标|100% / 66.67%|参考口径影响评分；仅在两目标预先获接受时才构成合理多解|
|S05|同底面，平顶3h vs 统一增至6h|100% / 50%|正对照：IoU确实能识别整体高度错误，仍有保留价值|

S01顶面明确为连续斜平面`height(x)=3+x/2`，因此没有封顶三角化歧义。预测和参考体积均48h³，交集44h³，并集52h³，真实体积IoU=11/13≈84.62%。此处将“均高实现失去局部信息”与“体积IoU的一般性质”严格分开。对于非共面多个顶点，真实体积还需事先声明封面规则，不能任意三角化后当作唯一真值。

S02剪切系数固定为`4(1−0.9)/(1+0.9)=4/19`，不是通过人员偏好调参。墙角偏离90°约11.89°。它只构造等IoU不同结构的反例，不宣布规整但缩小者一定更优。S04是条件示意，不给真实图新增参考；已有内/外侧目标讨论见[术语](../../docs/thesis_main/CONTEXT.md)，实际多参考须沿用独立认可的目标选择依据，不逐作答挑最高分。

## 面向论文的主反例（补充）

主图：[PDF矢量图](PAPER_COUNTEREXAMPLE.pdf)／[PNG](PAPER_COUNTEREXAMPLE.png)。数值：[paper_counterexample.json](paper_counterexample.json)，schema为quality_iou_paper_counterexample_v1，仅包含合成来源说明及三形状的高度、角点高度RMSE、均高棱柱IoU和明确平面封顶的真实体积IoU。均使用同一个4h×4h底面和3h平顶参考；单位、视角和尺度一致。

|形状|四角房高/h|均高棱柱IoU|角点高度RMSE/h|真实体积IoU|
|---|---|---|---|---|
|a 完全正确|3,3,3,3|100%|0|100%|
|b 轻微统一偏高|3.1,3.1,3.1,3.1|96.77%|0.1|96.77%|
|c 明显两侧倾斜|2,4,4,2|100%|1|84.62%|

**a与c是等分反例**：正确与显著错误无法区分。**b与c是排序反转反例**：四个对应顶部角点的绝对高度误差都扩大十倍，实际体积重合也更差，均高棱柱IoU却更高。底面、目标范围、参考和角点对应完全相同，不用新总分或偏好权重定义优劣。这里的排序反转相对于明确的顶部定位误差和真实体积重合，不扩展成所有可能质量维度的严格支配。

可用于论文的表述草稿：

> 为检验均高棱柱3D IoU对人工标注局部高度误差的辨别能力，我们固定底面及参考布局，构造顶部高度不同的标注。完全正确的平顶标注与角点高度分别为2h、4h、4h、2h的倾斜标注均获得100%的IoU，尽管后者的角点高度RMSE为1h，且按其斜平面构造的真实体积IoU仅为84.62%。进一步地，角点高度仅统一偏高0.1h的标注获得96.77%的IoU，低于上述倾斜标注。这说明，将逐角高度压缩为均值会产生局部误差不可辨别及相对几何误差的排序反转，因而该实现不宜直接作为未约束人工标注的唯一质量度量。

一般性原因：固定底面、正高度及同一参考时，指标仅依赖角点高度的均值。任意总和为零的高度扰动，在仍满足可计算条件时均不改变其分值。取高度族`[3−d,3+d,3+d,3−d]`，`0≤d<2`可保证所有顶点高于相机，均高棱柱IoU恒为1，而角点高度RMSE为d。因此结论不是只对人为挑出的d=1成立。

这组构造证明测量遗漏的存在，不估计真人标注发生频率。真实数据中的对应发生与人类整体判断仍用P01等独立列示，不能把合成反例冒称工人实测。论文主论证优先用此图；等IoU但不同底面规整性的S02及目标范围S04适合作补充讨论，单独不足以证明整体质量差距很大。
