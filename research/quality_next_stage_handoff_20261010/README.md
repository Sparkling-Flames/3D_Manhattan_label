## 当前质量基线及已做研究

现行 `geom_quality_research_v1.1.0`：

Q = 100 × BEV_IoU / [1 + (S / 4°)² + (Hstar / 0.5)²] × R

S为上下边界球面误差的合并RMS；Hstar = max(Hmean, Hlocal)，局部双向高度RMS机制已经实现。R = 1 − 0.15 × [D²/(D²+5²) + F²/(F²+2²)] / 2，其中D为方向残差、F为平坦残差。5°和2°是损失尺度，不是“合格/不合格”阈值。质心不进入现行Q；3D IoU是对照指标，不是这个公式的直接项。[冻结代码与参数](../quality_scope_comparison_20261010/frozen_engine/core/quality_v11.py)

旧冻结全量3152份中2979可评，已有参数敏感性、旧组合提高G权重探索，以及0.15→0规整消融；不能称“从未调过参数”。该消融实际规整扣分中位1.704、P90 4.936、最大8.832分，属于旧输入事后机制诊断。用户未批准取消规整。现v1.1的0.15/0.30/0.45加重对照和分阶段方案尚未执行，不存在已验证的胜者。[旧结果精确入口](SOURCE_MAP.md)
