# 人工审核方案草案

目的：取得独立于候选分数的质量判断，校准严重不规整惩罚及质量区间；另核查自动空间归属在怪异作答上的表现。不是要求用户重新认可已审核的 A/B 空间，也不是全库打精确分。

## 两组问题，分开呈现

### 质量判断组

优先同图、同认可空间、参考完整且约束适用的两份作答。第一屏原图叠线，第二屏同尺度 BEV/条件 3D。候选答案用 1/2，不出现 worker、Q、惩罚方案名、优劣提示或“严重例”标题。

用户回答：
1. 1 更好 / 2 更好 / 质量接近 / 无法判断。
2. 若有差距：轻微 / 明显 / 很大 / 无法判断。
3. 每份作答：可接受 / 有明显问题但可用 / 严重问题不可接受 / 需更多上下文。此为待校准的人类语义，不预先映射到 95/85/50。
4. 主要原因可多选：空间范围、位置/边界、墙向规整、顶底/高度、结构遗漏或多画、参考问题、其他。允许自由说明。

“接近”和“无法判断”必须分开，缺失不能自动变成同档。首次提交前不揭示分数；后续可让用户查看公式解释，但修改判断应记录为新版本，保留首轮。

### 空间匹配组

展示固定认可空间 A、B 与待评作答，不显示 Q。用户回答：仅 A 可匹配 / 仅 B 可匹配 / 两者均可匹配 / 两者均不匹配 / 无法判断，并标记是否斜跨不同区域或局部混合。答案是绝对几何兼容判断，不要求猜作答者意图。若另问“相对更近哪个”，须设为单独可选题，不能用相对偏好覆盖双兼容状态。

针对同空间不同细节、轻微定位偏差、同时吻合共有部分、斜跨差异区域、远离全部参考都要有覆盖。真实 B 缺顶界时明确只审底面归属，不能用这种案例校准完整三维质量总分。

## 采样和顺序

先交少量小样检查可读性，之后分批，避免一次性几十页增加疲劳。开发批与验证批按房间隔离；跨房仍是历史研究库存，不宣称完全未见数据。选样规则与随机左右顺序在收答案前冻结。

开发批覆盖：轻微偏差对照、明显/严重规整问题、各候选排序相反、接近候选临界点；避免只按最大改分挑选极端案例。另设正常覆盖样本，注明争议样本不代表总体发生率。

验证批不参与选择参数或分档，先封存名单和图。若为解释用户反馈而改阈值，之前看过的验证例降为开发证据，并明确需要新的验证；不无限增加人工负担。

## 数据保留和比较

每个案例需盲编号、图/房间、作答/GT版本、目标 ID、渲染和几何哈希、入样理由、分组、左右映射、用户判断版本。用户版只暴露必要审图信息；分数与身份映射独立保存。

同一人工判断对比各公式的排序是否一致、是否把严重问题分进高档、是否误伤可接受样本。模糊对的处理规则事先说明，不删除不利判断。少量人工判断提供校准证据，不包装成全人群普适真值。

最终由 dot 汇总：被用户证据支持的改动、未解决的冲突、需要保留连续分而不作硬分档的边界。任何公式更新附参考/样本分母和参数版本，不覆盖历史分。
