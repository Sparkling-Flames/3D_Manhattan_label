# 全部人工确认空间的参考路由：实现、证据与边界

## 结论与本轮推荐

已将局部结构优先的参考选择推广到恢复出的全部 **35 张人工确认图片**，并对这些图片的 **429 份当前研究输入记录**执行路由和逐参考几何复算。保持原有底面协议后，**417 份可路由，12 份不可路由**；缺口逐份保留，不写成零分。结果包含原始上下角点、平均 x 后输入、参考版本和坐标哈希。主方案推荐本目录 `config.json` 的 `local_reference_router_v1`：明确人工指定优先；否则先检查候选区别边界、转折和差异区域覆盖；证据不足时在尚未被局部证据排除的候选中按底面 IoU 兜底，精确并列时才用归一化边界距离。

这轮没有证明局部路由比全局最大底面 IoU 更准确。对 **333 份可计算、多候选作答**，去掉人工指令后的最终候选与全局最大底面 IoU **全部相同**。局部模块在这里的实际价值，是明确显示结构证据、候选族和不确定性；不能把相同选择包装成准确率提升。T29 是反证：几何自动选择 B，而用户明确要求 A，必须由外部人工指令覆盖。没有把最终质量最高的参考反推为标注者选择。

本轮实现支持改变候选而不伪造顶面：65 个已准入、去重后的候选中，35 个保留既有完整参考身份，30 个只有确认底面。417 份主路由中，286 份落到只有底面的参考，131 份可以计算条件完整质量。新底面缺少顶面时，`Hm`、`Hc`、完整 Q、3D IoU 均为 null。

所有这些图片和作答已经用于开发、协议验证或影响分析，不是新的独立人工泛化验证集。详见 `results/summary.json`、`results/routes.json`、`results/all_candidate_metrics.json` 和 `validation/summary.json`。

## 2. 通用方法：局部证据先于全局兜底

`router.py` 不接收人员、图片编号、作答 ID、最终 Q、D 或高度。输入只有作答底面、外部已准入候选底面和配置。因此 T30 的第 5/8 对点号不可能被套用到其他图。人工指定和人工结构族限制由 `run_routing.py` 在外部应用，保留未经覆盖的算法结果供复核。

### 2.1 从每一对参考自动提取差异

对候选多边形 P 与 R，按共同并集面积设尺度 `s=√area(P∪R)`，局部距离尺度为 `τ=0.03s`。提取两类位置与结构：

1. **区别边界**：沿候选真实边界等弧长采样，距离另一参考边界超过 τ 的边界部分。保存其物理位置、总长度和切向，不只比较顶点数量。
2. **区别转折**：转向幅度至少 15° 的结构角点。如果另一候选没有相近位置及相似入/出边方向的角点，就把它作为区别转折。不会把同一墙上的额外共线点当成新转折。角点支持长度按两侧完整连续墙链积分，不取距角点最近的一个短线段。

另外保存 P\R、R\P 的所有具有实质面积的连通区域，以及作答在每个区域中的覆盖率。小于共同并集面积 `10⁻⁴` 的碎片只按数值/细小差异保留弱证据，不升级为独立结构要求。源参考没有被修复、配准、缩放或取凸包。

完整逐图提取结果在 `results/reference_candidates.json` 的 `differentiating_regions_and_structures` 中：差异区域 GeoJSON、区别角点坐标、区别边界长度及尺度都可逐项检查。角点序号只用于指向该图原始几何的审计，不是选择规则。

### 2.2 作答与局部结构是否相符

区别边界的支持同时看最近边界距离与切向差，使用平滑核 `exp[-(distance/τ)²-(angle/20°)²]`。因此画到一个远端点，却用斜边跨过应有的入口转折，不会与沿正确墙链覆盖该区域等价。区别角点支持同时看位置和两个邻接方向，位置尺度为 2τ，方向尺度仍为 20°；角点匹配允许不同点数。

边界支持权重为 0.65，角点支持为 0.35。这些是路由证据的合成系数，不是最终质量分的结构权重。局部单一胜者至少满足：支持≥0.55、比另一候选高≥0.20；具有实质独有区域时，其覆盖率≥0.60，而竞争候选的独有区域覆盖率≤0.40。连续邻接支持和每个角点的相似度另外保留。缺一个角点只能降低对应证据，不能立即判成另一空间。

这套设计区分了**缺失空间的正证据**与**没有看到空间的弱证据**。当一个小空间的关闭边界和局部转折被直接表达时，可以支持小候选；只有“远处没有点”时不会自动批准小候选，必须检查其闭合/边界证据，否则进入兜底。

候选多于两个时，先删除被明确局部证据击败的候选。若仍剩一个候选，就按局部证据选择；若剩下一个结构族，例如 T30 的 C/D，再在族内兜底。互相矛盾的循环证据会恢复全部合法候选并标注冲突，不任意挑一个局部赢家。

### 2.3 兜底及不确定性

主方案在尚未被局部证据排除的候选中取最高底面 IoU；精确并列时按对称平均边界距离/√参考面积打破并列，再用稳定 ID 处理剩余数学同分。它不用高度、方向惩罚或完整质量分。候选 IoU 差小于 0.03 标为 `low_margin`；其余兜底仍为暂定几何选择。0.03 不是经过人工校准的“置信概率”，更不是质量等级边界。

另行导出了面积数值和边界距离单独兜底的结果。面积方案用 `|log(area作答/area参考)|`，保留精确并列；边界方案按归一化对称平均距离选择。这些对照不改主协议。`oracle_diagnostic_separate.json` 额外报告所有合法参考中的最佳底面 Q，以及现有完整参考子集的最佳完整 Q；后者因为缺顶面不是完整允许集合的最大值，不能拿来替代主协议。

### 3.2 必须保留的 T29 反例

R03192 / T29 在大空间 A 下的底面 IoU 为 **0.317285**，在小空间 B 下为 **0.346808**。仅比较面积也选 B。归一化平均边界距离却偏向 A：A 为 **0.169459**，B 为 **0.363206**。用户明确要求按 A 匹配，所以主协议选 A，并保留原大空间中约 67.66% 的漏出面积。这不是一个新的自动路由成功例，而是说明几何兜底不能完全代替明确的人类目标解释。

### 3.3 面积、重叠、边界对照

333 个真实多候选作答中，面积数值单独选择与主自动算法有 **88 条**不一致，归一化边界单独选择有 **9 条**不一致。没有给这些未标注分歧编造正确答案。

一个严格反例排除了“面积数值够用”的设想：两份合法、正交、包含相机的矩形面积同为 10h²，一份沿 x 方向长，一份沿 z 方向长。作答与后者完全相同。面积差都是 0，不能区分；IoU 和局部边界正确识别完全重合参考。这个失败与学习参数无关，是面积丢失位置和形状信息的直接后果。[证据：`validation/synthetic_counterexamples.json` 的 `equal_area_wrong_location_shape`。]

边界方案确实在 T29 这一开发案例中更接近人工指令，但这种归一化也倾向于给较大参考较小的相对距离；另 8 条分歧缺少独立判断，因此本轮没有把单一例子的优势扩大成默认边界兜底。当前保留 IoU 主兜底及显式人工覆盖，边界对照用于少量真正有区分力的复核。

## 4. 反例、不变性与消融

### 4.1 不按点数机械选空间

所有 **65 个已准入参考**作为作答输入时都回到自身候选。对 333 份真实多候选作答，分别在每条边近角 `10⁻³`、`10⁻⁶` 相对边长位置插入共线点，独立改变作答或全部参考，共 **1332 次**实验：最终候选和路由原因都没有变化，局部支持量最大差为 **2.04×10⁻¹⁰**。48 份共同旋转与尺度变换控制也没有候选/原因变化。

这里实际发现并修正了一个实现问题：只取任意最短距离边的切向，会在最近点是角点、相邻边距离相同时受到顶点插入后的边索引影响。最初 1332 次中最终路由未变，但局部支持量最大变动 0.05096。现在在同一最近几何点集合内取最佳对齐的合法相邻切向，并使用尺度相对的数值并列容差；最终完整复验支持量变化降到上述数值水平。这个修正只改变路由描述，不改变 I、Sb、D、高度或原坐标。[证据：`DEVELOPMENT_FIXES.json`、`validation/collinear_invariance.json`。]

对所有适用真实候选逐一删除一个顶点，并仅保留仍有效、包含相机的底面，共 **362 次**控制，339 次仍选原候选、23 次改选。后 23 次不自动当成错误，因为删除结构后可能确实与另一合法参考更相似，甚至相同；完整几何和路由保留供检查。它证明算法没有“点数少一个就必定改空间”的规则，不能证明未知的历史意图总被恢复。

### 4.2 归属和质量必须分开

合成大空间为 4×4 的基本房间加 3×1 的狭长分支，小空间为基本房间，两者都是有效候选。独立生成并实际计算以下控制：

|控制|最终候选|基线底面子评分|说明|
|---|---|---:|---|
|完整大空间|大空间|100.00|正确参考自匹配|
|完整小空间|小空间|100.00|合法小候选可以是好作答|
|大空间漏一个远端角|大空间|51.03|不因漏一个角切成另一空间；斜边仍受罚|
|大空间漏一个入口角|大空间|42.78|局部结构损害仍反映在质量中|
|只画 2×2 未批准小正方形|小空间暂定|2.47|路由成功不批准这个更小空间，也不掩盖严重漏画|
|斜跨延伸区域|大空间暂定|33.58|保留较大方向残差；不是好质量标签|

这些分数使用题设基线的**底面子评分**，不含人为构造高度。合成控制用于反例和响应验证，不是用户确认的质量等级，不能据此贴“严重”人类标签。

### 4.3 不能同时满足的意图要求

如果合法小候选 B 恰好等于合法大候选 A 删除全部分支后的多边形，那么同一份观测几何 B 可以来自两段历史：标注者正确选择 B；或标注者想画 A 却漏掉整个分支。两段历史的上下角点甚至可以完全相同。任何只接收几何的算法都会得到相同输入，不能一边给前者好分，一边必然识别并重罚后者。D=0 也没有帮助。

因此，“路由后仍处罚画小、漏角”能够保证的是：相对选中参考仍存在的小范围或转折错误会继续处罚，不能保证识别与另一合法候选完全相同的潜在漏画。已有人工指令可解决 T29 等指定案例；没有独立意图证据的同形情况必须保留不可识别状态。这个边界不是等待人工后才工作的理由，本轮已经对全部现有输入完成可执行路由。[证据：`validation/intent_nonidentifiability.json`。]

### 4.4 参数和项的实际作用

对 333 份真实多候选作答，把 τ/s 从默认 0.03 改为 0.015、0.020、0.045、0.060，把最小局部支持改为 0.45/0.65、最小差距改为 0.10/0.30，再做仅边界、仅角点和去掉覆盖一致性约束，共 11 变体、3663 次重路由。所有变体最终候选都与默认相同。

纯算法默认有 85 条唯一局部胜者（其中 3 条实际主协议仍按已有人工指令登记）。τ/s 为 0.015 时只有 45 条、0.060 时为 128 条；仅边界为 89 条、仅角点为 67 条、去掉覆盖一致性约束为 94 条。可见最终候选稳定并不意味着“局部明确/不明确”的界线经过校准。变大匹配尺度会增加局部明确标记；本轮选择居中的 0.03，保留较宽的不确定区。覆盖项可阻止一些局部边界相似但区域证据冲突的过早定论；角点项提供独立的邻接/转折诊断。该批数据没有给额外项带来最终准确率增益证据，后续应以能区分候选的少量人工材料检验这些诊断价值。[证据：`validation/sensitivity_and_ablation.csv`。]

## 5. 数值口径及参考/公式四路比较

全 798 个实际候选指标对使用底面球面 2048/方向、均高中心化高度 4096/方向的冻结计算口径。另对全部候选运行球面 1024 对照：Sb 最大差 **0.000118231°**，基线底面子评分最大差 **0.000653543 分**。再选完整参考中 Hc 最大的 8 对与 Sb 最大的 8 对，共 16 对，运行高度 2048/4096/8192/16384 和球面 8192：4096→16384 的 Hc 最大差 **1.45×10⁻⁵**，2048→8192 的 Sb 最大差 **1.66×10⁻⁵°**，合并导致完整基线分最大差 **0.000068605 分**。这些是具体数值风险检查，不是全连续域的精度证明。

与 922 评分共有的 24 份同输入、同参考作答，I、Sb、D、Hm、Hc 全部在 `10⁻⁷` 内复现。原始上下 x 不对齐另外保留并测量：本地 `X_rms_deg` 是整段上下 x 差的 RMS，Pro `Eperp_deg=X_rms_deg/2`。没有把预处理后的零 x 差当成原始输入质量好，也没有在本路由模块擅自增加所有 x 差的统一罚项。[证据：`validation/frozen_metric_consistency.json`、`validation/numerical_spot_check.json`、`results/raw_x_diagnostics.json`。]

必须区分“历史原始 A”和“之前实际固定参考”。wc2-26 之前已经采用人工修订 B，不能把 B 的改善算成这次路由新收益。严格包含两个现成完整参考的共同集仅有该图 6 份记录：R00105、R00629、R00660、R02017、R02052、R02373。新主路由保留 5 份 B，将 R02052 从 B 路由到 A；题设完整基线分从 **9.451148** 变成 **11.479449**，这 **2.028300 分**是参考变化，与新的质量公式无关。它不证明这条作答变好，更不证明某人能力提高。

其余新确认参考没有顶面，不能做伪造的完整四路。它们可做相同底面指标、相同作答资格下的底面四路对照；根目录联合结果另将评分公式变化与路由变化分解。相同资格、相同参考、相同完整可计算集合的 3D IoU 对比才有效，不能让质量方法享用新 floor-only 参考、却让 3D IoU 继续背负旧大空间误差。

## 6. 唯一新增路由复核优先项

推荐只新增 **R03197 / uNb9QFRL6hY-67** 的目标归属复核。它和已有人为指定 A 的 T29 很接近；IoU 对 A/B 为约 0.3143/0.3502，归一化边界对 A/B 为约 0.1709/0.3540。判断它应归大空间 A、合法小空间 B，还是本来无法区分，能够直接区分当前 IoU 与边界兜底策略。T29 已有指令，不重复让用户审查。

## 7. 复现和交付范围

执行命令见 `INTERFACE.md`。已使用包内相对路径 `baseline` 实际重跑全部 429 条输入，15 份非时变结果文件逐字节一致；模块清单可用 `python routing/check_delivery.py` 核验。主要命令从随包 `prepared_input.json` 和冻结引擎直接生成逐图、逐作答结果，不依赖未下载资料或用户电脑。`prepare_inputs.py` 另记录从完整原件抽取本任务输入的步骤。结果目录同时保存 JSON 和 CSV，以及单列的 oracle 诊断、旧 T30 对比、采样精度、raw-x 诊断和人工开发证据核对。

本模块完成的是空间归属协议及其可运行底面/完整几何接口。它没有变更任何 GT、原角点、资格、OOS 或门洞裁决，没有把人工偏好合并为精确分差，也没有把批量几何计算数量当成人工标签量。质量公式、联合搜索和最终推荐参数由根目录任务 B 的独立实验选出；本报告给出的路由只为其提供冻结且可审计的参考协议。
