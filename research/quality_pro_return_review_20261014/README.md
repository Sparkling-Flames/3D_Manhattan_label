## 新组合究竟改变了什么

令 `K = Sb²/32 + 1.5D²/(D²+37.5) + (Hm/.8)² + (Hc/.25)²`。

|口径|公式|
|---|---|
|现有 hill_global08|`100I/(1+K)`|
|Pro 候选 WQ-LS08|`100I/(1+I K)`|

Pro 对 `100/Q` 的分解正确：旧式等于 `1 + O + K + OK`，新式等于 `1 + O + K`，其中 `O=1/I-1`、`I>0`。这是一个明确且可解释的组合选择。

但**倒数尺度上的交互项存在，不等于已经证明重复处罚或计算错误**。例如在负对数尺度，旧式本来就是 `-log(Q/100)=-log(I)+log(1+K)` 的相加。多个分项也可能测量同一局部错误的不同后果；仅凭它们共同变化，不能推出其中某种组合必然错误。选择新式需要质量判断或下游稳健性依据，而不只是代数形式更简洁。

新式在所有有效输入上都不低于旧式。上升是构造性质，不是预测准确率改善。在固定I时，其他损失相对于范围的权衡已改变；只有其余指标均理想的抽象单因素轴上，响应保持一致，不能扩大为真实混合误差样本的处罚强度完全不变。

独立复核的实际高度边际扣分变化如下（完整分相对去高度分的差）：

|用途层|可评分数|扣分增加|扣分减少|基本不变|
|---|---:|---:|---:|---:|
|普通|574|49|519|6|
|严重例外|9|9|0|0|
|门洞条件|125|103|22|0|
|历史旁证|10|0|10|0|

不变以绝对差不超过 `1e-8` 计。这既不自动证明变好，也不自动证明变坏；它表明“参数仍为0.8/0.25”不能替代对最终分数响应的解释。Pro 对 T20 5.323→5.063 的说明正确，但更广的分层影响也应保留。

## 支持接收与尚不能认可的部分

### 有实质价值，可以保留

1. 全部允许配对和控制的重建、输入一致性、同参考3D IoU对照，关闭了前轮只部分重建的执行缺口。
2. 方向轴、自由归族和长度权重的拆解有用。固定参考轴仍自由归族的等边菱形RMS是 `min(theta,90-theta)/sqrt(2)`，与自由轴的二分之一形式不同。没有把之前的L1诊断混成现用RMS。
3. J04恢复单底点的诊断副本没有写回原数据，也没有作为新真人样本参与校准。约97.33%的bottom-y平方偏差集中于一对，支持局部投影放大机制，但不是心理原因解释。
4. 最近边朝向替代量受缩放影响、首交边朝向对多交点覆盖不足等负结果应保留，不再把“新增结构项”当作必然改进。
5. 门洞保留92份暂缓，Q01小房间不借大参考定低质量，Q02/Q03修订不强制总分排序。没有新增完整偏好支持调参时保留普通版是合理决定，不能反过来称其没执行门洞阶段。

### 推荐新式的证据仍有限

35个候选中，32个同时通过“P01方向正确、弱等级派生比较无逆序、严重—轻微比较无逆序”三项检查。此计数不包含全部定性证据，也不说明32个候选等价；它说明这些主要检查的区分力有限。J01由二十多分升至三十多分，不能单独证明量表更贴合人类判断。

J04旧尾项7.254→现版27.078的主要修复已经在前轮完成，本轮仅进一步到33.534。密集底点控制上，现版与新式都是0个上升步，不能把消除旧反转全部记成本轮收益。

更广的真实输入派生轨迹中，330个“I下降且D下降”的窗口，现版完整Q上升108次，新式110次。其他分项可能改善，因此这些不是110次已认证的人类质量反转；但也不支持新式已经普遍修复结构响应。真实提交配对检索的0命中仅限同图同参考、四角和近正交参考等过滤条件，不能推广为整个真实池没有此问题。

9份严重例外的新分数从现版3.31–12.34上升到8.06–20.34，不违反已有“轻微应高于严重”的约束，也不能仅因不再个位数就否决。没有通用严重切点，因此目前只能报告变化与相对约束，不能认证新的绝对等级。

### 方向与结构缺口没有解决

D依旧衡量自身接近一组正交轴的程度，不充分表达墙族关系或遗漏结构。Pro 的正交窄分支遗漏控制仍约92.705；这不能无条件算成已有人评反例，但明确说明高Q不保证局部结构完整。

合法略非正交参考自比仍可能不到100（所查普通参考一例约94.686），是继承的自身规整性项所致。新式没有新造此问题，但也没有修复。不要把Q作为纯GT距离，或不加适用条件地用于OOS、全部融合输出和人员资格。
