## 结论

Pro 的数学机制研究与执行边界有价值，暂不采用它测试的替代总分也有依据。但将“原WQ＋五档读数＋诊断”作为本轮主要采用建议，尚未完成用户关心的几何处罚问题。可以保留这一输出形式作探索性展示，不建议现在冻结五档，更不能把它作为质量模型已经收尾的依据。

用户认为它像对总体数据求平均：代码没有将1145份分数取均值后回填每个作答。它以30份普通开发反馈拟合单一WQ到五档的正斜率累积logit映射；同图作答的拟合权重合计为1。全库均值仅用于描述，人员单元中心化另作敏感性分析。它确实在全体开发反馈之间求一种统计折中，但不改变任何原WQ分数，也不改变逐作答排序。因此它只能解决读数解释，不能修正某种错误被罚过重、方向族归属或细节遗漏的问题。

## 需要纠正的研究重点

1. **把五档降为待核展示，不作为几何模型问题的解决方案。** N18的WQ仍为47.251，冻结映射仍给“一般”，用户原反馈为“较好与一般之间”。这不是要求逐例拟合，而是说明单调映射没有处理原来提出的问题。N18约47分、N24约48分、N08约50分的原反馈次序也不同；一个仅看总分的单调函数无法区分这种错误构成差异。
2. **完整五档的低端支持不足。** 30份、26图、9建筑中，差/一般偏差/一般/一般偏好/好为1/2/12/10/5；15份曾显示分数。训练WQ最低29.321，模型的“较差”切点23.314落在全部观测分数以下。原拟合对两种低档共3份均未同档命中；不能用总体19/30拟合命中掩盖缺少低档证据。Pro已披露这些限制，因此问题在于“冻结”的采用措辞过强，而非隐瞒。
3. **参考相对方向模型仍未完成。** 实现的参考角度进入总分的方式是将角度F1作为BC的硬最小值守门；对应门限失配会使总分归零。该特定构造失败，不等于连续的参考角差、对应覆盖与定位容忍无法有效结合。全局D死区也没有检验逐边定位精度不同的方案。不能把几种初步候选未胜出当成所有合理修订均已穷尽。
4. **普通真实数据的候选比较原来不完整。** 1145份比较只覆盖能由既存分项重算的WQ/T1/T2/T4/MAX/RGP/3D IoU。新BC与角点指标原来限于两图34份和合成控制，7份普通存档也全部来自uNb-09这一张图。缺少普通几何是当时执行限制，不是候选无效的证据。本次在本地补了普通30份，以便公平检查。

## 值得保留的成果

- D在2–3度附近很陡的数学分析，以及N18主导边和ERP定位敏感性证据。
- 明确“假设1像素扰动”不是实测点击误差；N28的偏轴也不能统一归因于小定位噪声。
- 最大损失组合会隐藏非最大分项变化、容忍值改变会显著改变结果的控制。
- 合法非正交参考自比、窄分支遗漏、共线细分与现用棱柱IoU等性质检查。
- 保留条件参考、排除、暂缓、manual/semi和新顶界缺失，没有依最高分自动选择参考。
- 单调读数用于人员均分仍会改变排名的敏感性检查；冻结融合终点不冒称重新融合。
