# 已有质量指标的阅读说明

以下是本轮之前使用的诊断基线。它们供人工判断后比较，不是评分标准，也不是最终推荐权重。所有比较必须说明同一图片、同一作答与同一参考版本；不能把原 GT 与修订 GT 的数值交叉作差。

## 基础分项

| 记号 | 定义或用途 | 解释限制 |
|---|---|---|
| IoU | 作答与指定参考的 BEV 面积交并比 | 只描述底面范围接近程度，不能认证细节与上界 |
| C | BEV 质心距离除以参考面积平方根 | 随范围选择改变，不一定是独立定位错误 |
| T | 对指定参考的条件墙顶有限折线距离 | 有参考、模型和可计算域依赖，不是自身规整性 |
| dir | 作答自身正交方向一致性的残差，单位为度 | 规整不代表选对范围或保留完整内容 |
| flat | 作答自身水平顶模型残差，单位为度 | 假设不适用时应保留限制，不直接判错 |

## 固定基线换算

- 范围损失 L = 1 − IoU
- LC = L + 0.5C
- Jdir = sL × dir / sDir
- Jflat = sL × flat / sFlat
- J = (Jdir + Jflat) / 2
- K = sL × T / sT
- LCG = LC + 0.3J
- LCT = LC + 0.3K

损失越小，表示按该公式更优。已有固定尺度为：sL=0.14707940277528614，sT=0.1303322459424322，sDir=2.7126745183041483，sFlat=0.8990282772073596。缩放和 0.5／0.3 系数都属于继承基线，没有在这 36 份人评上校准。更改归一化或单位会改变权重的数值含义。

既有有界补偿形式为 LCB = LC + εJ/(sL+J)。在 J 非负且有限、ε>0 时，新增项在 [0,ε) 内；这只是代数上界。它不会自动知道多少补偿对应人类的“差不多”，也没有证明 ε=0.1 是合适容忍度。

## 怎样使用诊断

同一对作答在多个分项间可能取舍。某一损失更低、多个分项支配，或一个小分差发生反转，都不能单独替代整体人工判断。对参考、合理范围、结构忠实度和模型适用性有疑问时，保留原因，不通过调权消掉问题。

T、方向与平顶同时出现的普通联合方案仍有实证空间；原有线性冲突或极端参数证书只针对指定特征、尺度与压力条件。它们不代表所有简单总分不可行，也不直接给出可使用的最终权重。
