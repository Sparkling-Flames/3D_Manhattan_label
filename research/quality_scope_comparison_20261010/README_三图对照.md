## 省人工的两种定义

1. 固定允许集合：若采用“完成预先固定且允许的任一目标”协议，直接输出max(Q_G,Q_T)可作为集合匹配分，不需要恢复每个人不可观测的历史意图。集合必须事先固定，不能按每份答案新增裁剪。建议同时保留Q_G、Q_T及覆盖/越界，避免把“匹配某个允许目标”混成“完成整个大G”。本次未把这个协议改为正式默认。
2. 不读取完整Q的空间归属：比较IoU_T与IoU_G；差值超过统一margin才分配，否则“不确定”。这不读取顶界、高度或完整Q，也不是历史意图识别。IoU本身也是Q的一项，因此不能说两种方法在统计上独立。

本批margin=0、0.05、0.10时都为16 T＋2 G，和max全部一致，且得分逐条相同。margin=0.20、0.30时，e9-17的6条变为“不确定”，其余12条同选，无反向分配。阈值仅做敏感性探索，没有通过验证的最终默认阈值。

另一条更可解释的空间规则读取G\T覆盖率：覆盖很少且T覆盖足够，归T；覆盖很多且G覆盖足够，归G；其余不确定。报告保留27组低/高/最低覆盖阈值组合。示例低≤10%、高≥75%、最低目标覆盖≥50%得到相同18条；收紧最低覆盖会显著增加“不确定”。不能挑选“刚好全分完”的阈值就宣布有效。

最近参考法对极小残片也能输出T，这只是匹配对象，不代表作答合格；覆盖门槛规则则会保留“不确定”。本实验把归属、完整几何分与人员资格分开记录。

## 覆盖与越界的含义

comparison_18.csv逐条保留：
- coverage_G=面积(A∩G)/面积(G)，coverage_T=面积(A∩T)/面积(T)
- outside_G_fraction_of_annotation=面积(A\G)/面积(A)，小T同理
- G\T覆盖率，以及存在T\G时对该区的覆盖率
- 全套Q分项：BEV IoU、顶/底球面边界角距、Hstar/Hmean/Hlocal、方向与平整、两种3D IoU、四项扣分

例：e9-09的T覆盖仅62.15%–82.08%，所以即使移除大范围要求，主体仍有明显遗漏。b8-18的R02278虽覆盖T=99.96%，Q_T仅60.53，顶界角距2.80765°、底界1.13724°、Hstar=0.18322；覆盖完整不等于其余几何正确。

在本目录运行：

    python reproduce.py
    python validate_controls.py

本工作区已有依赖时可加PYTHONPATH=/tmp/quality_integration_deps。常规环境需要numpy、scipy、shapely；绘图另需matplotlib。requirements.txt记录本次版本。仅本目录results和figures会被生成或更新，不读取照片、不依赖网络、不写源GT。

- results/complete_components_long.csv、full_score_results.json：完整分项及引擎返回
