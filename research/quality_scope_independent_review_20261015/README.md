## “没有归一化”的感觉对应什么问题

WQ已做了两件事：用常数将不同分项转成无量纲损失；将总分限制在0–100。尚未充分建立的是第三件事：**多大的误差仍可接受，以及这些误差为何应该对应某个分数或粗档。** 有上下界不等于已经具备这种意义。

固定其他分项，只检查方向函数，D为1°、2°、3°、5°时，条件分数依次为96.25、87.37、77.50、62.50；最陡处每增加1°约下降10分。这是函数响应，不声称普通正交GT下存在IoU=1且D>0的真实作答。Pro的实际剪切控制也显示：相邻墙角偏离约5.71°时底面IoU仍为95.12%，WQ已为75.45，去D的同几何探针为94.56。这里D约2.86°，不是墙角偏离本身。

因此，用户认为部分近似作答扣分偏重有可研究的依据，但尚不能由此选定新的扣分值。Pro的粗档反序数主要检验排序，不检验绝对分数刻度；α=0.75和1的微小差异还随样本范围而改变。维持基线是合理的操作决定，不是曲线已经校准的证据。

还有一个应实算的机制：端点定位误差会被短墙和近平视线投影放大成角误差。独立、同方差的小位置噪声下，单边角误差方差约与墙长平方的倒数成正比；当前再乘墙长后仍约与墙长倒数成正比。多标细节是否因此被额外处罚，需要逐边验证，不能先归因为人员画错或直接给短边免责。推导和限制见[数学审查](MATH_REVIEW.md)。

## 可借鉴的方法及迁移边界

|方法|原研究提供的依据|本项目值得检验的用法|限制|
|---|---|---|---|
|[Surface Dice，Nikolov等](https://pmc.ncbi.nlm.nih.gov/articles/PMC8314151/)|按给定距离容忍度计算合格表面比例；容忍度参考专家间差异|把可接受的小偏差与明显错误区分，形成“多少边界处于容忍范围”的读数|医学毫米阈值不能移植；需明确ERP球面或BEV空间及本项目容忍依据，防止容忍带吞掉细节|
|[Boundary IoU，CVPR 2021](https://arxiv.org/html/2103.16562v1)|局部边界带评价，并以两指标最小值结合区域与边界质量|检验相关几何信息能否采用不重复累加的组合，同时保留严重范围约束|不能直接移植到D；最小值组合会忽略较好分项中的次要损失，边界带太窄也会过罚|
|[RoomFormer，CVPR 2023](https://arxiv.org/html/2211.15658v2)|匹配房间后分别评价房间、角点和角度的precision/recall/F1|评价相对参考的对应角度，同时计入遗漏和新增结构|它的IoU匹配用于指定GT集合，不能用来替代本项目先确定合法目标范围；原像素阈值不能照搬|
|[McCullagh有序回归，1980](https://doi.org/10.1111/j.2517-6161.1980.tb01109.x)|利用档位顺序，不要求各档之间等距|建立“较好／较好与一般之间／一般／一般与较差之间／较差”的阈值或概率|当前44份是开发意见，存在曝光和压力选样；不能直接宣称独立人类尺度已验证|

以上是迁移建议，不是已在本库验证有效的新算法。文献资格、检索日志和待核验记录见[literature目录](literature/literature-list.md)。检索采用用户指定3T技能；同模型独立双审、3T-only，没有向量RAG。检索覆盖与剩余队列以该目录记录为准。

## 建议 Pro 下一轮交付什么

目标是形成一个能解释、能复算、可供新一批普通图核验的质量候选，而不只是再写一份“证据不足所以不动”的报告。方法选择保持开放；有希望的方向是参考对应角度、定位容忍和标尺校准，也可验证边界与区域的非累加组合。应说明每个改动解决什么性质、付出什么代价，允许实证否定候选。

需要明确区分：排序错误要改测量或组合；排序基本可用但读数不直观才适合单调标尺校准。不能用全库最小最大值、分位数或Z分数把这一批分数拉得好看，再称绝对质量。单调变换保留逐作答排序，却**不保证人员均分排序不变**：例如两组原分(100,20)与(55,55)，均分60高于55；逐分取平方根后乘10，前者均分72.36反而低于后者74.16。若新标尺用于人员均分或融合统计，仍需同资格比较。

保留WQ及同参考现用3D IoU作基线。可接受细微GT偏差的规则不能误罚合法参考自比；对应覆盖不足不能填零；必要细节遗漏、方向族塌缩、严重范围错误和共线细分不变性应有明确响应。先普通粗调，再门洞交界细调；门洞预期低分不构成优化目标，用户也不要求逐例主观分数完全吻合。
