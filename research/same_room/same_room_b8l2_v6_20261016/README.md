## 一、同房平均质量是否接近

每个图对使用同条件、完全相同人员，各视角相对自身指定参考计分。保留“共同人员均值之差”与“同一人员跨视角绝对差的均值”，二者不互换。主展示33个manual图对均为普通层、`selected_gt`目标；既有可比记录不是新做的跨视角几何配准或视觉认证。

|直接关系组|图对/视角数|B8L2共同均值绝对差，分|3D IoU共同均值绝对差，百分点|
|---|---:|---:|---:|
|G047，S9|7对/5视角|9.225|4.075|
|G057，VFua|2对/3视角|6.813|4.251|
|G090，e9z|3对/3视角|13.747|3.579|

33图对等权时，B8L2平均均值差为6.797分，逐人绝对差均值为12.096分；四组等权的均值差为8.695分。两种权重都不是总体置信区间，21个uNb图对也不是21个独立房间。e9z-15/28同7人的B8L2均值差达20.620分，这个反例没有因不符合相似预期而删除。

因此可以保留“某些同房视角有接近线索”，但不能概括为所有房间具有同样强的完整质量相似性。G090的B8L2差距较大而IoU差距较小，也说明底面/体积接近与包含方向、高度等项的工作指数不是同一观察。

相同单源预算、同条件、同人员、同源图粗类的匹配对照仍只在uNb可用。对照位于所有既有候选关系块之外；关系块仅防泄漏，未记录同房不认证异房。先源任务再7个目标图等权：

## 二、同房平均时间是否接近

合格来源时间有5个确认可比图对、3栋建筑，但部分仅1—2名共同人员；当前目标可比时间只有G057的3个图对，其中2对达到4人。当前没有适合同人数/同类的时间对照覆盖，不能照搬uNb质量对照结论。

|图对|共同人员|平均秒数A/B|均值绝对差|逐人绝对差均值|人员耗时排序相关|
|---|---:|---:|---:|---:|---:|
|VFua-04/07|6|157.667 / 224.000|66.333秒|74.000秒|0.943|
|VFua-07/10|4|220.000 / 219.500|0.500秒|97.000秒|−0.200|

04/07的平均时间不同，同一批人员谁快谁慢却较一致；07/10的平均时间几乎相同，具体人员的时间变化却较大。**平均任务成本、人员时间模式和质量相似性需要分别报告。** 这些仅是少数视角的实际差异，不能单凭它们判断认真程度或房间难度。

时间还保存配对几何均值比及平均绝对对数比，避免秒数长尾或方向抵消。04/07的几何均值比B/A为1.367，07/10为0.854；后者算术均值接近，不等于逐人比例接近。质量和时间的同成员联合表见[joint_quality_time_pairs.csv](joint_quality_time_pairs.csv)，不把不同成员的两组均值拼起来。

- 在**当前33对完全相同输入、人员和参考**下，WQ均值差为7.428分，B8L2为6.797分。变化只说明两个评分尺度的数值响应不同，不证明几何改善或人员更一致。

桥接表保留逐对象和逐图对：旧23[成员/参考ID桥接](historical_23_pair_membership_bridge.csv)、v4的27[图对桥接](v4_27_pair_membership_bridge.csv)、[v4/v6完整评分成员桥接](v4_v6_quality_membership_bridge.csv)、[当前同输入指标对照](same_input_metric_swap_pairs.csv)。改变参考ID本身不证明几何改变，未凭ID改写语义。
