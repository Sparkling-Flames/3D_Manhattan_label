## 门洞为什么没有形成新图对

合格来源中的门洞图接触23条候选直接边，其中涉及15张已获得质量用途评分门洞图的为19条。所有边均逐条件检查来源、完整质量人数、共同人员及两端参考；见[门洞关系覆盖](doorway_relation_coverage.csv)与[门洞作答](doorway_records.csv)。

- 这19条中18条没有直接明确确认的物理同房证据。即使存在共同人员和两端评分，也没有因结果可算而升级为确认同房。
- 唯一物理同房明确的7y-06/13属于`confirmed_other_scope`，不是既有范围可比主层。06端7份质量作答为manual，13端18份为semi；分条件比较时共同质量人数均为0，不能拼接两种任务。
- 因此，新门洞的确认且范围可比质量图对为0；物理确认的其它范围层也没有同条件共同质量人员。这里的零来自实际关系与成员检查，不代表门洞没有同房关系，更不代表门洞标注质量差。
