# 最新既有团队的同房覆盖与类别构成重聚合

输入 main `72a44e80c344975962e1071bd54d894dd86bb4b4`。本分支新融合、评分和标签数均为 0；新增的是逐成员对齐检索和既有当前分类结果的重新组织。

## 1. 哪些问题现成结果已经覆盖

当前结构严格 ABC 在 80 个可比直接同房图对、7 栋楼两端都有结果，另有 8 个范围不同图对。联合 A/B 两端只有 G086 的不同范围视角。完全相同的实际 A/B/C、A/C 或 B/C 在两端都出现的次数均为 0。现有限定面板只同时覆盖 G086 两图，且相同实际团队交集也是 0。因而，正式检验同一人员调整跨视角重复需要补算配对团队；这不是评分缺失或数据损坏。

文件：`existing_exchange_pair_coverage.csv`、`existing_panel_pair_coverage.csv`。前者按已采用直接关系连接，未用建筑替代房间、未用传递闭包扩张。

## 2. 现成同构成、不同成员给出的起点

按人数 n、实际 m、方向、粗细层、完整 A 和 C 类别人数向量匹配图片；同一个目标楼的 LOBO 类别版本保持一致。逐图格内对实际 A-C 去重后求直接 C−A；同类 B−A 的绝对变化单列。两图成员和具体 D 可以不同；此结果描述同构成的成员实现波动，不能命名为相同人员调整的重复。

普通 Manual、可比范围、n20/m4 常规表达→较多转折：77 图对、35 图、7 栋、1,189 个共同格。格内平均后图对内等权、楼内等权图对、建筑等权：

| 指标 | 值 |
|---|---:|
| 直接效应均值跨视角同号（含微小值） | 63.19% |
| 两端均在 ±1 分内 | 8.44% |
| 两端均超过 1 分且同向 | 27.99% |
| 两端均超过 1 分且反向 | 11.78% |
| 仅一端超过 1 分 | 51.79% |
| 两端类别格均值作用绝对差 | 3.07 B8L2 |

将两端各至少 3 个实际 AC 集合的格单列，保留 94 格/48 对/35 图/7 楼；同号率 64.54%，均值作用差 3.52 分，格内成员效应标准差平均 2.93 分。这个子集是估计成员波动的支持诊断，全部格仍保留，不用它替换全体。

结果显示可重复方向占多数，但更多情况下只是其中一个视角发生超过 1 分的效应。类别构成在目标视角是否有改变空间，比忽略近零值后的“同号”更有解释力。1 分为解释阈值，不代表评分精度或统计显著；0/1/2 分结果完整保存。

## 3. 对新配对实验有帮助的房间

- **G078，Z6-02/08**：在两端都有至少 3 个实际 AC 的 n20/m4 上升方向格中，两个视角均无真实转折数量变化，类别平均质量效应为 +2.58 / −4.95；提示应检验定位与自身方向规整性，而非只看节点。
- **G047，S9 多视角**：这些格均无真实转折数量改变，均值作用通常很小；适合呈现结构稳定、不应被记为“真实同向补结构”的条件。
- **G172，uNb-01/40**：同一完整构成 `M1:3|M2:11|M3:6 → M1:3|M2:7|M3:10` 的类别平均作用为 −20.84 / +40.28；真实转折平均变化分别 0 / +1.50。这里成员不同，尚不能将反向归因于视角；新同成员配对可分离两者。
- **G046**：类别格及成员波动均较大，失败真实存在；已经确认的同墙角对应无需再次裁定。

## 4. 交付表和复现

- `adopted_direct_pairs.csv`：采用的全部直接同房关系及原图 ID/组码/范围身份。
- `existing_exchange_shared_class_conditions.csv`：当前各阶段匹配的完整构成条件。
- `existing_structure_composition_cells.csv.gz`：逐图完整构成格、AC/AB成员数、直接作用分布、各分项与失败。
- `existing_structure_crossview_composition_cells.csv.gz`：逐同房图对匹配格；原分母和双方均值/分布保留。
- `existing_structure_composition_replication_summary.csv`：全部、n20/m4正向、反向，主域与不同范围，以及 0/1/2 分阈值和 ≥1/≥3 成员集合支持。
- 同名前缀的 `pairs/groups/buildings.csv` 保留图对、原声明组和建筑汇总。
- `coverage.py` 与 `reaggregate_class_cells.py` 在仓库旁的 `work/reuse/` 执行；只有 pandas/numpy 和标准库依赖。脚本 R 指向相邻 `hohonet` 仓库，移植时修改或设置一致目录。

准确输入路径和 SHA256 在 `INPUT_INDEX.csv`；本轮计算身份在 `ANALYSIS_RECEIPT.json`。结构 `fusion_turn_n` 等沿用已保存判据。两视角转折数量的同向不声称同一物理角点对应；此分支没有新查看原图，也没有新增必要结构人工裁定。
