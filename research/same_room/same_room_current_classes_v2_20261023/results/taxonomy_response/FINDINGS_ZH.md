# 当前结构类别构成与具体成员作用：同房跨视角结果

本分支使用 main `72a44e80c344975962e1071bd54d894dd86bb4b4`、当前楼外 `V3_BEHAVIOR` 结构标签，以及同一批实际团队的 `V3_JOINT_QT` 联合标签对照。原生团队由主实验本轮实算；这里新增配比/成员分解、换成员曲线、源侧预测和内部楼外校准，没有重做分类或评分。

## 1. 最值得保留的判断：多数有明显响应的配比趋势能重复，但幅度与具体成员作用仍随视角变化

普通 Manual 的主预算是共同已知人员的一半，按容量裁剪，使用第一批核心/候选。登记 **309 个面板、118 个直接图对、59 图、11 栋建筑、17 个原声明组**；有11,350个双视角团队链接，11,256个双端质量完整。一个面板没有至少两个双端可评团队，故主 Q 分解为308面板。人数与替换候选数由容量决定，未固定 n20/m4。

对每个固定核心面板，把实际团队 Q 写成“该视角同完整类别配比的均值 + 具体成员残差”。这让两种重复性可以分别观察。

**17 组中13组的配比相关均值为正。** 面板→直接图对→原声明组→建筑等权后，61.16%的面板配比相关为正。这包括较弱响应，不直接称为明显质量收益。用构成曲线两端极差均达到2分辨认“两个视角都有实际响应”的条件后，149面板/88图对/9楼/13组中有105面板正相关、44面板负相关；按既定分层计权，**73.23%正相关，67.21%达到ρ≥0.5**。这是支持“多数有响应条件下配比方向重复”的结果。[表：`results/COMPOSITION_DIRECTION_COUNTS.csv`、`COMPOSITION_DIRECTION_SUMMARY.csv`]

这项双端筛选使用目标结果，只回答已发生的响应。若仅依据源端极差≥2分选入，409个有向面板、260个不同面板、116图对的结果为：

| 目标端结果 | 原始有向行 | 组/楼等权比例 |
|---|---:|---:|
| 目标也活跃、构成曲线正相关 | 210/409 | 40.26% |
| 目标也活跃、构成曲线负相关 | 88/409 | 18.47% |
| 目标构成极差小于2分 | 111/409 | 41.27% |

原始比例和分层比例不同，因为大组包含更多直接图对；两者都保留。源图已经有明显类别效应，并不意味着目标必有同样幅度。**重复“趋势”、重复“明显幅度”和预测“某一实际队的 Q”应是三个结果。**

把响应幅度也计入协方差后，主 Q 的配比 pooled ρ仅0.002，同配比成员残差ρ为0.023。它与多数面板正相关并不矛盾：少数幅度很大的反向作用可以抵消较多弱正作用。主图同时展示每组面板ρ均值与合并方差ρ，不能用一个替换另一个。[图：`../../figures/GROUP_COMPOSITION_MEMBER_REPEATABILITY.png`；小表：`GROUP_PATTERN_PRIMARY.csv`]

## 2. 为什么“配比规律”与“换成员规律”必须分开

### G015：同一配比方向可以重复，具体同类成员却能反向

7y3-11/19 中，当前该折 M2/M3 的 n7 面板固定核心 W110/W113/W118/W119；M2候选 W104/W120/W128，M3候选 W109/W112/W122，完整枚举6选3的20队。M3人数0、1、2、3时，两视角配比均值分别为：

| M3人数 | 7y3-11 B8L2 | 7y3-19 B8L2 |
|---:|---:|---:|
| 0 | 86.419 | 81.970 |
| 1 | 88.350 | 87.349 |
| 2 | 90.015 | 90.938 |
| 3 | 90.928 | 92.678 |

配比相关ρ=0.996，但同配比具体成员残差ρ=−0.785。主预算 n10 中也成立：配比ρ=0.980、成员残差ρ=−0.643。n14仍相似；n11的一端几乎没有质量变化，已保留。n10改用另一批核心/低类候选后，成员残差反而为正0.537，因此不能把这一批人的负相关推广成整类成员的固定性质。

一个精确同类替换尤其直观：固定其它6人，将 **W104换成W120**。两人同为该折结构M2，联合类也同为J3。7y3-11的Q由82.052升至90.066（+8.015），7y3-19却由98.419降至82.228（−16.191）。D10同向支持这个反转。转折数在两个视角分别一直为4和8；底点误差、自身正交方向残差 `dir` 和高度误差随成员改变，说明这里的质量作用来自定位等分项，而不是多保留一个转折。`dir` 不应读成相对GT的墙向误差。

原答质量本身也反转：W104在两图约61.17/99.17，W120约86.35/57.43。W104楼外相对Q还高于W120，因此不能仅用稳定的楼外Q高低解释。这是“类别描述保留了构成趋势，同时具体人的视角适应差异仍很大”的强例。G015的壁炉与简化参考沿既有人工解释及冻结评分保留，没有改GT来制造一致性。[精确表和图：`cases/CASE_G015_*` 与 `../../figures/G015_COMPOSITION_MEMBERS.png`]

### 完整配比不变，换另一批核心和候选

replicate0/1仅连接完整类别向量相同的格，移除实际成员完全相同的队。普通层有83图对、8楼、12组。换成员后，Q配比曲线在**同一视角**的平均相关为0.438，跨视角为0.341；保留另一批成员提供了正的方向证据，但远非同配比即可复制同一质量。按相同配比单元等权的主诊断，成员质量P90−P10在两视角约9.37/6.50分，即平均约8分，具有实际幅度。

作为预测，已知旧成员的同视角配比均值，可把新成员格均值MAE从4.768降至4.505（改善0.263分）；跨视角MAE反而从8.883变为8.979。类别配比对同一视角换成员有小幅实际用途，直接跨视角搬运整条质量幅度曲线仍不划算。[`REPLICATE_SUMMARY.csv`、`REPLICATE_MATCHED_COMPOSITION_CELLS.csv.gz`]

## 3. 当前结构类别更能解释结构差别；速度的可重复部分主要保留在具体成员

在固定人数、核心和候选的有限队内，结构配比解释 **46.64%的转折数团队方差、41.41%的短转折边方差、20.37%的Q方差**。这里是面板内团队差异，不是所有人员质量的总体方差解释率。只看具备同配比成员重复的支持，转折数仍为45.13%，Q为15.08%，因此不是单成员格导致的全部现象。

转折数配比 pooled ρ=0.382，成员残差ρ=0.086；短转折边为0.344/0.046。**类别较能描述融合会保留怎样的结构，而同配比成员的结构细节仍随视角改变。** 这不意味着所有团队都发生了结构调整：309个主面板中215个两端转折数完全不变，39个两端都变，涉及25图对。恒定例单列，不计作积极同向变化。

相同配比换另一批人时，转折曲线同视角相关0.719、跨视角0.321，但可计算相关仅分别42/192和32/192个曲线比较；其余大量情况含一端或两端恒定。因此应同时看结构不变率与活跃曲线，而不能只引用相关。[`REPLICATE_CORRELATION_SUPPORT.csv`]

时间提供另一种稳定性。在完全相同的Q和时间可算团队上，39图对/10楼/12组中，**同配比具体成员残差的劳动时间ρ=0.740，而Q仅0.011**。时间记录覆盖差异不能解释这个对比。

单源响应预测的较严格共同支持为33图对/10楼/11组。队间log劳动时间形状MSE从源均值的0.02501降至源精确队的0.01953（下降21.9%），源侧连续历史响应为0.01870（下降25.2%）。结构配比为0.02659，联合配比为0.02404。绝对log劳动时间MAE仍约0.354—0.359，主要增量在“哪些实际队相对更省时”，没有消除视角公共耗时差，更不是现实排队或交付时间预测。[`TIME_QUALITY_COMMON_SUPPORT_*`、`SOURCE_TRANSFER_SUMMARY.csv`]

## 4. 联合类别没有超过强连续校准的质量预测；不应把分类收缩的好处误称为类别独立增量

所有模型在相同目标支持上比较。普通主预算为113图对、11楼、17组。源视角正式Q与队曲线已知；标签、连续画像与校准参数均排除目标楼。使用同一固定实验银行作内部楼外参数检查，没有另造人员分类，也没有把探索当新外部验证。

| Q预测方法 | B8L2 MAE |
|---|---:|
| 源有限队均值 | 8.7488 |
| 源精确队原值 | 9.7909 |
| 源精确队楼外线性校准 | **8.7464** |
| 源精确队 + 结构配比校准 | 8.7633 |
| 源精确队 + 联合配比校准 | 8.7718 |
| 完整连续信息校准 | 8.7925 |
| 完整连续信息 + 结构配比 | 8.8097 |
| 完整连续信息 + 联合配比 | 8.8179 |

完整连续信息包括源精确队偏差、楼外Q/转折/T/短边/低尾历史，以及仅在源侧选择线性/二次ridge的连续响应。最强已登记连续对照是非常强的源队收缩，跨楼斜率仅0.016—0.050，接近源均值。结构/联合类别都未带来平均预测增量；D10同结论。这里不再继续调类别或模型来寻找正结果，采用源均值或强收缩即可。

在**两套标签共同已知的实际团队支持**上，联合类别能把Q的描述方差占比从结构类21.09%提高至38.60%，同时完整配比格平均由3.95增加至6.30；这与上文结构全部已知支持的20.37%分母不同。更细的分格可自然解释更多本视角差异，不能据此宣称跨视角更好；校准检验给出了相反证据。时间方面联合类有较高描述占比，但仍不及实际成员/连续响应用于队间相对耗时的迁移。

当前结构方法 `V3_BEHAVIOR` 的各折内部允许 TURN/JOINT 等结构特征家族；其中 JOINT 指结构行为轴联合，**不等于**此处独立对照的 `V3_JOINT_QT`。全主层保留当前采用方案，另有 family 分层表，不静默剔除语义不同的折。

## 5. 采用建议与交付边界

保留当前结构类别作为理解结构表达、提出组合候选和解释组内差异的起点。对源图明显响应的配比，目标图“仍有同向活跃响应”的概率质量有条件证据；同时要给近零目标保留足够权重。具体采用哪位同类成员，以及该改变是否改善Q，仍须看目标视角定位与参考结构条件，不能只复制源图的精确Q幅度。

可以保留同房实际人员的相对速度信息，用来比较劳动成本；质量与结构仍分别判断。联合分类不提升为质量预测主模型。结构规律、同房均值、具体成员速度和局部几何机制各自提供不同信息，不揉成一个总分。

本分支保存全部人数、第二批成员、门洞/范围不同条件和失败结果；主报告数字只引用明确主支持。原参考与投票资格不变。所有原生团队、对象、参考和几何均可用 `panel_id`、`team_key_a/b`、`member_set_key` 及主包索引连接。最小复现见 `REPRODUCE.md`；全量93MiB工作输出包含可再生汇总，不应整目录打包，宜交付主小表、压缩精确响应、代码与两张关键图，完整人数表另存可选附件。
