# 同构成成员差异与跨视角重复性：方法和文件接口

本分析复用本轮冻结的双视角有限团队面板及原生融合结果，不重新拟合人员类别。普通 Manual 为主层，其余采用的范围差异/门洞条件单列。关键标签为当前 `V3_BEHAVIOR`，`V3_JOINT_QT` 作为同队、同人数、同实际人员支持上的对照。

## 一、构成和成员各解释什么

对每个双视角面板，固定背景核心，两种当前结构类各选 k 名候选，在 2k 人中完整枚举取 k 人，形成所有有限团队。每个实际团队在两个视角都重放。分类向量计入整队核心与可变成员；联合类使用同一批团队自己的完整联合类向量，不另换人员域。

对一个可计算的指标 y，把每个团队的结果写成该视角的同构成均值加成员残差：

`y(team, view) = mean(y | full_class_vector, view) + member_residual(team, view)`。

有限团队内均匀权重，因此每个配比的权重等于实际包含的团队数。逐视角总方差恰好分为构成间方差与同构成成员方差；双视角协方差也恰好分成构成均值协方差与成员残差协方差。后者让人直接看出：类的整体趋势是否重复，以及同类、同配比中哪些具体人员较好这一排序是否还能重复。

分解是对已登记有限面板的描述，未声称全体随机团队的因果贡献。单团队格没有可估成员波动，保存 `n_singleton_teams`、残差自由度和实际配比数。两边恒定时相关系数保留缺失，同时保存 invariant 状态，不把没有变化计作积极重复。质量缺失不填零；正式失败率另作结果，质量分解使用两端共同可评分团队，并明确其条件分母。

`PANEL_DECOMPOSITION.csv.gz` 保留每面板全部矩。主预算 `mid_n_rep0`：共同已知人员数 N 的一半（向下取整），按有限面板可行区间 `[max(3,k), N-k]` 裁剪，使用第一批核心/候选。`all_n_rep0` 保留其它奇偶人数作为敏感性；`replicate1_mid` 为换具体成员的另一批面板。三个预算分别汇总，不把其它人数或重复成员面板混入主数。

汇总先面板→直接图对→原声明组→建筑等权；同时保存 PAIR/GROUP/BUILDING 表和带人数、replicate 的 PAIR_N/GROUP_N 表。汇总中的 pooled correlation 由按此权重汇总的协方差与方差计算，不是大量团队当独立样本的相关显著性。`pooled_between_fraction` 同样用汇总构成间方差除总方差。逐面板比例平均也保留，二者量义不同。

除了总体相关，`COMPOSITION_DIRECTION_*` 保存构成 Q 曲线的实际活跃范围：两端极差都小于2分、仅一端达到2分、两端达到2分时的正负相关。双端阈值是对已发生响应的描述性子集，不能称为源图可部署成功率；另一张表仅用源端极差≥2选入，随后把目标近零、目标活跃同向和目标活跃反向都计入分母。原始面板/有向行数、图对/声明组/建筑数与分层等权率同时保留。

## 二、相同配比但换具体成员

在固定同房图对、人数和原类别方向后，另一个确定性候选/核心面板提供成员重复检查。只连接两个成员面板中完全相同的整队类别向量；剔除实际团队成员集完全相同的端点后，再比较不同成员集合的均值曲线。核心也可能改变，故它检验“完整配比保持后的另一批实际成员”，不冒充只改一人的固定背景替换。

`REPLICATE_MATCHED_COMPOSITION_CELLS.csv.gz` 保存每格精确 panel、向量、成员集合数、移除的重复团队数、平均实际替换人数、两视角四组结果。`REPLICATE_COMPOSITION_CURVES.csv` 同时比较同视角换成员及跨视角换成员。没有相同向量支持的格不会补造；只有一个共同格时保留格均值但不计算曲线相关。

## 三、类别信息的预测增量与竞争基线

两个分类都在同一批精确团队上评价，联合类多出的配比格不会仅凭更高描述方差占比获得“更好”的判断。单源响应检验把一个视角作为已知历史，以另一视角为目标，两个方向分别保存。

质量预测的信息条件：源视角 GT/正式 Q 已知，并且源有限团队库已融合；这不是无需 GT 的在线质量策略。时间响应只使用源活动耗时与既有楼外画像，不要求该源图 GT；转折数响应使用源融合几何。源队库使用同一批原答复用组合，所需人的标注劳动是源核心与候选人员的记录，不把枚举队数重复计成人工劳动。目标 Q 只用于评价。类别与连续画像均来自目标建筑以外的历史。

比较源图有限队均值、源精确队原值、源结构配比均值、源联合配比均值，以及源侧拟合的连续历史响应。连续输入是楼外 Q、转折、T、短边和低尾；线性/二次响应与固定有限 ridge 候选的选择只使用源侧留一团队误差。这个对照允许连续历史解释同类成员差别，避免把粗分类和过弱基线比较。

所有源拟合和源配比均值先按源端可计算性确定；目标失败不会反过来筛选源团队库。随后在各模型共同的实际可评分目标上比较。原始绝对误差保留视角公共水平差；另报去除各自均值后的响应形状误差。后者中的目标中心仅是评价尺度，不被写入实际预测。

另有 `calibrate_response.py` 的主预算固定设计内部楼外参数检验。验证楼 b 的既有 `heldout_building=b` 标签/画像同时用于训练楼和目标楼全部团队，避免把包含 b 历史的其它楼标签混入响应拟合。比较固定弱 ridge：源精确队连续校准、加五个连续历史、加源端拟合的连续历史响应、以及在这些完整连续信息上再加结构/联合配比源均值。源端响应的线性/二次形式和 ridge 参数仅在源端留一团队中选择；响应跨楼系数使用固定标准化 ridge 0.01。目标楼质量不进入系数。报告固定完整连续基线，也列出已登记连续对照中误差最小者，后者是结果对照而非新训练出的部署选择器。固定实验银行的内部检查不等于新外部数据验证；也不据这些模型改动当前分类。

## 四、主要文件

- `PAIRED_TEAM_RESPONSES.csv.gz`：精确 panel/team 键、成员、完整两类向量、双视角指标和楼外连续特征，可从已保存端点重新生成。
- `PANEL_COMMON_SUPPORT.csv`：同队支持与分类格数。
- `DECOMPOSITION_PAIR/GROUP/BUILDING/SUMMARY.csv`：构成与成员重复性。
- `SOURCE_TRANSFER_PANEL_RESULTS.csv.gz` 与各级汇总：单源、目标未参与选择的响应检验。
- `REPLICATE_*`：换具体成员后的相同完整配比检查。
- `COMPOSITION_DIRECTION_*`：有辨识度的构成响应方向、两端筛选与仅源端筛选的各自分母。
- `CALIBRATED_*`、`FOLD_COEFFICIENTS.csv`、`FOLD_SUPPORT.csv`：固定面板内部楼外响应校准。
- `GROUP_PATTERN_SUMMARY.csv`：逐组的质量、结构、定位、时间与失败响应；`MODEL_COMMON_SUPPORT_COMPARISON.csv` 比较同支持的最强已登记连续基线与类别增量。
- `DECOMPOSITION_MEMBER_SUPPORTED_*`：另列至少6个双端可计算队、同配比成员残差自由度≥3的支持；原主结果仍保留单候选类对比。`SINGLE_MEMBER_CLASS_STRONG_REVERSALS.csv` 保存单候选类对比中协方差最负的3个精确反例，解释平均相关和幅度加权相关为何不同。
- `TIME_QUALITY_COMMON_SUPPORT_*`：在完全相同的可用实际团队上对照 Q 与劳动时间重复性。
- `REPLICATE_CORRELATION_SUPPORT.csv`：相同配比换具体成员的相关可计算分母；结构两端恒定不会计作积极同向变化。
- `cases/CASE_G015_COMPOSITION_MEMBERS.csv`：G015 的100条精确双视角团队结果，包括组均值、成员残差、源侧配比预测、对象/参考/团队键。

G015 展示配比均值可重复与成员作用反向同时成立；保留 n11 近零例及 n10 更换背景后成员残差转正，未只挑原方向一致人数。所有脚本只读已保存标量与设计，不新增融合/评分。图像机制与必要原图由主包案例接口连接。
