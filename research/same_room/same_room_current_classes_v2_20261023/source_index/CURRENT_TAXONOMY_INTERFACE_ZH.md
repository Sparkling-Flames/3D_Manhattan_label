## 3. 历史特征含义

结构历史先按同图×条件×参考×层中心化，再按个人建筑均值、建筑等权。`turn_history` 是点对数减近共线节点数的表达残差；它不是已确认必要墙角的计数。`short_history` 使用周长4%且两端角≥15°的短边；`redundancy_history` 为≤5°近共线节点；面积/高度为相机高度归一代理。复杂机会使用同图转折中位数≥6，不等于人工难度 D。

联合 `q_history` 是本条件合格 B8L2 减同图人员均值再建筑等权；`q_downside` 保留该轮自己的低尾定义。`t_history` 是同图×origin×time_source_kind 中心化对数时间，不能当作秒数。真实目标团队记录时间仍应从每个成员在目标图的原记录相加，保留语义一致与缺失。

基本支持至少12图4楼；CONTEXT 另需简单、复杂各3图2楼；QT 另需本条件Q至少8图（Manual）、3楼及T至少6图3楼。类别已知不增加正式投票或正式评分资格。

## 6. 最值得继续的研究组织

1. **同一实际块跨视角**：先保留原事件，用当前LOBO完整配比重述；新团队据共同池补齐真正同类/跨类块。按质量、结构表达、定位分别建立“双方无实际变化／双方同向有变化／仅一边变化／双方反向”的转移表，不把双方没变化算作积极迁移。
2. **同配比成员变化**：在共同池固定候选成员域和背景，完整枚举或平衡抽取同一构成的不同成员。报告构成中心在不同视角的方向、构成内成员离散度，以及同一实际成员效应相对于换成员效应的相关性。已有图独立抽出的924队面板可以描述单图构成内变动；要作严格同成员跨视角，需实际团队键交集或补齐另一端。
3. **结构与质量分开解释**：采用当前结构类对复杂表达的已成立用途，直接检验其跨视角成套补角支持；当转折变化相似但B8L2反向，用位置、连接、范围/参考差异定位机制。联合分类适合检验记录时间方向能否更稳定重复，Q/T参与分类的效果和纯结构角色分开解释。

已有总体结构与联合用途是本轮先验出发点：复杂机会中表达差异更清楚；定向换类比任意改配比更有解释力；同配比仍有大量成员差异。这里不把这些已有结论写成新同房结果，也不因一个反例否定方向。新同房结果应按真实多数条件和机制判断。
