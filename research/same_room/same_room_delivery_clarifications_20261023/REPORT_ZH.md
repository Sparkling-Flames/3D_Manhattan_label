### 4.4 P10、标准差与失败的准确分母

对每图、每个 k，先在可评分路径 Q 上计算均值/P10/SD，再汇总图片；不把所有图的路径混成一个分布。P10 用 pandas 默认 linear 插值。自然曲线 SD 使用 ddof=1；策略各臂 SD 使用 ddof=0，保留来源差异。

不可评分 Q 不补 0；均值、P10、SD 跳过它们，失败率的分母则是全部尝试路径。一条可评分路径的自然 SD 缺失，P10 等于该值；零条可评分路径时三个统计量都缺失。k=2 的合同暂不评分与融合失败分开。几何、质量、时间可用性分别记录。

自然曲线区间的均值/P10/SD 差使用两端各自可评的分布；精确路径两端均可评的差另存为 `paired_Q_delta`。策略均 Q 差采用两臂皆可评的路径对，P10/SD 差仍来自各臂各自可评分分布。**不能把所有这些量统称为“完全相同可评分路径上的变化”。** Q80/Q90 的达标率把不可评分算作未达标，但不把 Q 补成 0；首次达到人数的条件中位数须与达到率并列。
