# 已取得文件中的类别方向与成员解释

## 1. 本补件恢复了什么

本补件读取 main 提交 `e92abe8631d7f01dc192ee796b46f295ece37a6d` 中的 `research/same_room/same_room_current_classes_v2_20261023/`。它整理现有标签、面板和 G015 已保存团队，不进行分类、融合或重新评分。所有衍生表明确标记 `stage=main_existing_small_block`。

这不是遗失的较大块严格 ABC 结果：本次环境与该 main 中均未取得 `same_room_large_block_matched_20261023/` 的原文件。旧有限面板的 `k_selected≤4`、G015 的 m=3 示例，以及 main 中的旧四份标量，不能冒充后来 111,054 个端点或严格大块事件。本文不能判定遗失大块总体由哪几个方向贡献最多。

当前可核验内容包括：22 个楼外折、72 条 Manual 结构粗类、110 条 Manual 联合 Q/T 粗类、1,954 个旧有限面板的实际人员设计；G015 保留了 5 个面板的 100 条团队双视角记录。本补件只重组其中的已存值，新增融合端点为 0。

## 2. 哪类换哪类：类编号必须连同楼外折解释

分类键是 `method + condition + heldout_building + class_id`。源表的研究版本为 v3，数据仍为真实 v2。标签阶段为 `outer_building_excluded_inner_selected`；本补件未利用目标图评分调类。

`LOBO_CLASS_MEANINGS_AND_MEMBERS.csv` 保留每折完整名单、历史中心、支持量和中文释义。结构家族 TURN 的三类折，可按历史中心解释为：

| 角色含义 | 典型历史表现 | 不能直接推断的事 |
|---|---|---|
| 复杂结构明显简化 | 复杂任务的转折残差明显为负；短细节残差也偏低 | 不能推断每张图都少角或每次融合都简化 |
| 常规转折表达 | 转折表达居中，短细节接近同任务基线 | 不能推断同类具体成员可无损互换 |
| 较多转折与短细节表达 | 转折及短细节残差偏高 | 不等于每个额外点都必要，也不保证融合后的节点更多 |

TURN 有 17 个折，其中 VFuaQ6m2Qom 只有两类。该折的 M1 是“较少转折的广类”，不能当作其余三类折的“复杂结构明显简化专类”。结构 JOINT 有 4 个折，CONTEXT 有 1 个折：本补件直接给出每类转折、复杂转折、短细节和近共线冗余中心，不自行建立新的跨折等价类。结构家族 `JOINT` 表示结构多轴，不是方法 `V3_JOINT_QT`；后者另外提供了历史 Q 和对数时间残差。相同 M2 或 J3 编号在不同折不自动等价。

表中 `role_alignment_key` 只用于 TURN 两类/三类语义的阅读索引，不能替代完整类别键；未对 JOINT、CONTEXT 或 Q/T 多轴类强行给出跨折等价键。所有成员名单和历史中心均来自现有表，中文说明仅翻译历史中心，没有重新分型。

`PRIOR_PANEL_DIRECTION_ROSTER.csv` 为每个实际旧面板列出源/目标类中文含义、`lo_candidates`/`hi_candidates`、共同背景 `core`、背景各类人数、n、m=`k_selected`、m/n、图对/建筑/声明组以及原参考键。该 m 是纯端点 AC 的实际块大小；原面板其他有限团队还包含更小实际调整，不能把一行面板当成一行严格 ABC 事件。

## 3. 一个已能完整读懂的现有方向：G015

以下仅展示 main 中已经保存的旧阶段结果。G015 为 7y3sRwLe3Va-11 与 -19，当前 7y3 楼外结构分类选中 TURN。其 M2 是常规转折表达，M3 是较多转折与短细节表达。

### 3.1 具体三人块 M2 → M3

| 项目 | 实际设计 |
|---|---|
| 分类/楼外折 | Manual V3_BEHAVIOR / 7y3sRwLe3Va / TURN |
| 源类及替出块 X | M2 常规转折表达；W104、W120、W128 |
| 目标类及替入块 Z | M3 较多转折与短细节表达；W109、W112、W122 |
| 共同背景 D | W110、W113、W118、W119，均为本折 M2 |
| n/m/m:n | n=7、m=3、m/n=3/7；有共同背景的混合团队 |
| 原队/目标队类别构成 | M2×7 → M2×4 + M3×3 |
| 范围 | 同一物理图对、两个视角、同一替换块；非严格 ABC 大块总体 |

| 指标 | -11：原队 → 换后 | -19：原队 → 换后 |
|---|---:|---:|
| B8L2 | 86.419 → 90.928（+4.509） | 81.970 → 92.678（+10.709） |
| D10 | 87.369 → 90.969（+3.600） | 85.622 → 93.728（+8.106） |
| 实际转折数 | 4 → 4 | 8 → 8 |
| 短转折边数 | 0 → 0 | 2 → 2 |
| 底点角误差 S_bottom_deg | 1.271 → 0.680 | 0.968 → 0.513 |
| 已记录劳动时间（秒） | 949.820 → 1308.678（+358.858） | 707.601 → 973.973（+266.372） |
| 这两个端点的失败状态 | 0 → 0 | 0 → 0 |

这次方向的两个视角均升质并增加记录劳动时间，提升主要伴随已有几何的定位改善，转折数和短转折数都未改变。因此“换入历史较多转折成员”不能直接解释为“这次靠补出更多转折升质”。时间是原表的同语义记录劳动时间，不能解释成排队或交付时间。失败行只报告这次两端点状态；它不是一个有普遍无失败含义的团队总体统计。

G015 n=7 面板中 6 选 3 的 20 个团队均有 B8L2 和失败状态。目标 M3 人数 0、1、2、3 的团队数依次为 1、9、9、1；-11 均 Q 为 86.419、88.350、90.015、90.928，-19 为 81.970、87.349、90.938、92.678。`G015_SAVED_COMPOSITION_CURVE.csv` 保留这些格内均值、P10、成员池、可评分数和失败数。它说明该面板中的配比方向，不是增加了 20 个独立房间证据。

### 3.2 同类具体换人仍可出现视角相反

在同一 n=7 面板中，固定 W110、W113、W118、W119、W122、W128，把 W104 换成 W120。二人同为该折结构 M2，现有联合标签也同为 J3。

| 指标 | -11 | -19 |
|---|---:|---:|
| B8L2 变化 | +8.015 | −16.191 |
| 转折数变化 | 0（仍为 4） | 0（仍为 8） |
| 底点角误差变化 | 1.640 → 0.911 | 0.132 → 0.974 |
| 记录劳动时间变化（秒） | −35.836 | −3.366 |

两个视角的类别构成都不变，转折数也不变；相反的质量响应同时对应相反的定位响应。这个已保存实例支持保留“类别可组织整体方向，具体成员与视角的交互仍不可忽略”的判断。它与前面的方向例可以并存，不能互相替代。

`G015_SAVED_DIRECTION_AND_MEMBER_CHANGES.csv` 给出上述 4 条逐视角事件的实际成员、D、n/m、源目标语义、精确团队键、object_id、参考键、各质量/结构/位置/时间分量及失败状态。原有壁炉与简化 GT 的解释和评分资格沿用，不在此重判。

## 4. 关键成员与 G236 的措辞

`KEY_MEMBER_ROLES_BY_FOLD.csv` 仅整理 W112、W115、W032、W109、W122、W028 及 W008、W029、W034、W035、W127 的现有 22 折结构标签和历史特征，共 242 行。它不能补出遗失的大块“含该成员/不含该成员”匹配前后效应、保留图对或建筑数。应等实际匹配表恢复后再与本表按折连接，不能拿 ALL 名单代替楼外角色。

对关键成员的现有文字，应采用有限范围表述：“在六位成员具有合法缺席对照的匹配子域中，较宽匹配下的平均方向仍为正。”较宽与精确 D 匹配的保留比例、两人转负及五人容量受限，来自前轮报告和用户反馈；本补件没有取得其逐事件表，不能宣称已经独立复算，也不能扩写为整体不依赖任何关键成员。

G236 应放在“历史类别倾向与具体任务响应不同”的机制部分。历史上较多转折的人，在一张具体图上也可能导致融合简化；结构变化与位置变化可能方向不同。三条锚点若共享同一目标块，不构成独立人员重复。失落的 G236 历史 Q 接近 42 事件表本次未取得，不能据聊天数值生成新的事件表；该条件机制也不否定此前广图中的结构表达差异。
