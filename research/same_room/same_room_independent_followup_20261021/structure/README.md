# 同房结构迁移：个人额外信息的独立复核

日期：2026-10-20 UTC。输入固定为 main `3391bc6ba241172e06fa114728b4c58d40558b3f` 中已有结构迁移预测。这里新增的是配对建筑稳健性分析，不把旧预测当作新 Pro 包的独立复现。新 Pro 回复的 47.1 MiB 包未取得可核验字节，本分析不验证它的代码、33,953 次运行或新结果。

## 结果与解释

同一个人的其他视角可以比楼外历史更准确，但这还不能把全部改善归于个人标法：同一房间给所有人的共同结构信息也会改善预测。因此比较本人源视角与完全相同源图上其他人的均值；本人不进入其他人均值。

- 参考角点数差：本人 MAE 0.6173 个，源图他人 0.7133 个，额外改善 0.0961 个。删去任意一栋楼，改善仍为 0.0202–0.1149 个。不过七栋中仅三栋严格改善，两栋相同，两栋略差，收益明显不均匀。
- 9°未匹配参考角点比例：本人 6.2174%，他人 7.3162%，改善 1.0988 个百分点；删去任意一楼仍改善 0.6834–1.2859 个百分点。12°对应改善 1.0353 个百分点，留一楼仍为 0.6294–1.2098 个百分点。这支持个人在参考角点匹配表现上的额外信息；未匹配可能来自省略或定位偏离，不能直接当作人工确认的语义漏角率。
- 不依赖参考的相对同行点数差：本人 0.6393 个，他人 0.6458 个，仅改善 0.0066 个；留一楼范围 −0.0404–+0.0518 个。现在不能把它作为稳健、跨楼通用的个人风格迁移效果。
- 带符号底点 y 偏移：本人误差比他人大 0.4072 像素，七栋全部更差。面积比对数误差同样七栋更差（平均大 0.01482）。原作答的定位偏移不适合直接从另一视角平移预测。
- 参考范围遗漏和超出：本人源历史也没有超过源图他人均值。这里比较的是参考几何误差，不是人员主观 scope 准确率。

这些结果适合形成“房间共同结构 + 人员细节保留倾向 + 视角相关定位”的分解。它们支持继续解释局部机会，不支持仅凭总点数或一个人员类别就推断新视角的准确位置。参考相关指标仍依赖参考质量与适用性，不构成无 GT 部署能力。

## 方法、分母与不确定性

- 原预测共 11,153 行；metric × 建筑 × 图 × 人唯一，无重复目标证据。
- 每个参考相关指标 1,385 个图×人记录、44 图、7 楼、55 人；GT-free 指标 1,458 个。9 个声明组允许重叠，不能当作 9 个独立房间。
- 逐人绝对误差先在目标图内平均，再图内聚合到建筑，最后建筑等权。所有方法使用同一目标记录。
- 此表使用原程序的全部可用其他视角，实际本人历史 1–9 张（GT-free 最高 10 张）。并未重新枚举历史图片严格超过 50% 的每种信息预算，不能拿本表直接替代新 Pro 的严格多数比较。
- summary.csv 中 bootstrap 区间使用 20,000 次建筑重抽样，固定种子；只有 7 栋、同一资料已反复探索，这些区间仅描述当前样本不确定性，不是新的预注册确认或等效性检验。留一楼范围用于显示单楼影响。
- 没有进行目标结果训练、重写评分、改变参考、修改人员类别或调用新融合。与未访问的新包不合并分母。

## 针对新 Pro 文字的待验事项

1. 80.3% 替换方向一致率限定源、目标两端效果绝对值均至少 2。目标端筛选使用了将来才知道的结果。应另报全体共同支持事件、仅凭源端阈值筛选的覆盖与一致率，以及类别固定方向基线。
2. 新回复中细类收缩的 0.303 MAE 改善是相对非分类收缩，并不等于超过最强的“源图公共 Q + 本人楼外相对 Q”。两者需要同样信息预算和共同支持比较。
3. 新回复的细节保留、角点与短墙迁移，应保留这里的同源他人对照。否则会把房间几何本身的一致性算成人员分类的成功。
4. “源视角 Q 预测更准”和“用源视角选人后融合更好”是不同目标。新回复已经给出扩展团队中后者失败的结果，应并列保留。
