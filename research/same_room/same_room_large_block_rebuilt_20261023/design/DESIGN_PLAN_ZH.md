# 同房大块严格 ABC：本轮新实验设计

版本：`same_room_strict_abc_rebuilt_20261023_v1`。固定输入 main `e92abe8631d7f01dc192ee796b46f295ece37a6d`；既有直接同房采用版本 `same_room_user_working_classification_20261016_v2`。

**身份：本轮重新开展的实验。** 上轮新大块的精确设计原件未找回；这里不声称恢复原设计，不以旧报告的事件数、端点数或数值为目标。人员分类、直接同房关系、正式资格及冻结融合输入沿用仓库。

## 设计回答的问题

每个直接图对、楼外分类方案、源类→目标类方向，构造互不重叠的 D/X/Y/Z，X/Y 来自同一源类，Z 来自另一目标类，三个替换块人数均为 m。A=D∪X、B=D∪Y、C=D∪Z；两个视角使用完全相同的人员集合。m>4；m 的真实容量为 min(floor(源类人数/2),目标类人数)，所有 m≤n≤N−2m 的整数配置均进入设计。

N 为两图冻结正式人员池的实际交集。缺楼外类别的共同人员可进入 D，但不能进入 X/Y/Z；未知仍单列。D=∅的纯块和 D≠∅的有背景团队都保留，不把二者合并解释为同一种应用。普通且范围相容 Manual 结构分类为主层；其它 Manual 范围/门洞层、联合 Q/T 分类分开分析。Semi 在全部既有直接关系中只有一个两图均有冻结池的关系，其共同人员仅 4 人，不能形成 m>4 的严格 ABC；保留容量表，不补造团队。

## 配置内成员覆盖

小配置空间（去掉 X/Y 互换镜像后不超过 512 个 ABC）全枚举。其余配置采用 12 个确定性的循环成员锚点、2 条背景顺序：固定 A 兼容顺序与按类别轮转顺序。锚点和顺序仅依赖建筑、分类、源目标类别、成员编号和固定种子；不读取目标 Q、耗时、几何或融合结果来选队。所有 n 的背景前缀进入设计；实际重复事件去重。多个路径引用同一事件不增加独立样本量。

固定 XYZ 增 D 的路径用于研究背景及替换比例。另保存真正固定 A、固定 n 的跨 m 路径：较小 m 时，把 Xmax 中未替换的成员留在 D，Y/Z 用各自嵌套前缀。A 始终等于 Xmax 加同一背景前缀。只有至少两个 m、且 A 与 n 逐行相同的路径才写入 `FIXED_A_SCALE_PATHS.csv.gz`。

## 方向与类别含义

`CLASS_ROLES_AND_MEMBERS.csv` 保留各建筑外训练折的原类别编号、全体历史成员、原始中心、中文角色及角色对齐键。TURN 按转折中心顺序描述为较少／常规／较多转折，二类与三类分别保留；JOINT 附近共线分段特征；CONTEXT 单独保留情境表达；联合 Q/T 描述历史相对 Q 与调整后 log 时间及转折中心。不直接把不同折的同编号拼成一类，不重新训练分类。

块历史 q_X/q_Y/q_Z 是任务调整后的相对 Q；t_X/t_Y/t_Z 是调整后的 log 时间，均来自排除目标建筑的历史。每块保存 known_n/full_known；缺失均值可供描述，但三块历史 Q 接近的主要子域必须要求三块全部 known，不能把剩余成员均值当作完整块。

## 精确关联与计权

`STRICT_ABC_EVENTS.csv.gz` 是去重事件，每行包含 D/X/Y/Z、A/B/C、六个图队端点键、目标/参考键及支持条件。`ENDPOINT_REQUESTS.csv.gz` 是去重后的冻结计算请求，成员→object_id 绑定逐队验证。team_key 使用原冻结规范。

事件把 X/Y 按字典顺序规范化，以去掉同类两队交换的镜像重复。因此无符号同类幅度与对称跨类幅度可直接用规范化 A/B；有方向的原队路径必须使用路径表的 `nominal_A_role`。当该值为 B 时，路径中的原队是事件表 B，原队到同类/跨类的差值须相应交换，不能把 canonical A 当作原路径锚点。

配置内事件只是覆盖量。比较先在相同图对、方向、n/m、背景条件下汇总，再按图对/声明组/建筑报告；不得让枚举更密的配置自动取得更高研究权重。`CONFIGURATION_COVERAGE.csv` 保存精确有限空间与实际覆盖，`MEMBER_COVERAGE.csv.gz` 保存实际成员块参与次数。
