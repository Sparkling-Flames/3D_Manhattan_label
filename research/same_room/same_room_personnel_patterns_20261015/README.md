## 计划检查与实际修正

用户调用are-you-sure检查计划，审查决定为**修改（Modify）**，之后进入单独实施阶段。

1. 共享人员基线扣除可能人为增加相关：纯内存反例的原相关为0，减同一个楼外估计向量后Pearson约0.95。因此残差相关只作诊断，主要结果看原始人员模式及同预算迁移误差。去图片均值不改变人员排序，减同一人员基线不改变两视角间差值，都不当作独立支持。
2. 类间比较须每侧至少2人，但研究某一类只需该类自身至少2人；不因另一侧不足而删去该类。2人子群只提供k=1、2两个点，不作一般增人规律。
3. 不把23个图对、46个方向或大量成员子集当独立房间；资料只有两组，匹配对照只有一栋建筑。连续效应保留，正负候选粗类不升级为稳定类型。
4. 完成覆盖后补充类型之间的公平人数比较：固定两类都可算的同一组任务，以及共同区间 `k=1…min(N正,N负)`。全区间与共同区间都保留，不按结果好坏择优。

这些修正见计划中的审查记录与字段合同。审查阶段只读；实施阶段仅新增本模块目录、专属工具和测试。

## 一、同房视角是否保留“谁标得好”的模式

对每个图对取完全相同人员及manual条件，各图相对自身固定参考评分。原始排序相关直接回答谁相对较好；另以各视角减去自身共同人员均值后的向量计算RMSE，允许整体质量水平不同。目标均值来自目标结果，所以该比较是**相对人员模式的回顾性分析**，不是未知目标绝对质量的部署预测。

23对等权的WQ人员排序Spearman平均为0.193，3D IoU为0.363。分组看：G057两对的WQ/IoU平均相关为0.100/0.671，G178的21对为0.202/0.334。两个指标不宜混成一个“人员模式稳定度”，也不能用大量uNb图对掩盖两组覆盖差异。

在唯一可做匹配控制的uNb建筑，先对源任务、再对7个目标视角等权：

|相对人员模式|一张同房源|一张同建筑同源图粗类对照|楼外一般人员画像|
|---|---:|---:|---:|
|WQ模式RMSE，分|14.686|16.084|**12.269**|
|3D IoU模式RMSE，百分点|6.637|8.412|**5.789**|
|WQ人员排序相关|0.204|0.123|不在这一列直接比较|
|3D IoU人员排序相关|0.379|0.083|不在这一列直接比较|

同房源比一张同建筑对照稍接近，但一般人员画像更好。因此现有证据还不足以说明“同房结构在一般人员强弱之外，带来一个稳定的WQ人员响应模式”。这不是说同房完全没有信息；上一轮平均质量的迁移与本轮具体人员模式是不同问题。

扣除楼外一般人员效应后，uNb的WQ残差相关为同房0.069、对照0.133；3D IoU为0.295、0.167。结果没有在指标间一致，且共享基线会影响该相关，**不据残差结果单独宣布识别房间交互**。底面边界角度分项甚至出现同房模式RMSE 1.396大于对照1.274的反例，所有分项保留在[逐建筑表](pattern_by_building.csv)。

37个其它同房支持图对另列[人员模式表](person_patterns.csv)，WQ平均原排序相关0.227、3D IoU为0.186；它们的范围/可比性状态不同，不与23对主面板合并成统一规律。

## 二、Q/T类别的相对差距是否跨视角保持

固定同一批人员及楼外类别，在每个视角计算：

- Q差距：Q较高类平均质量减Q较低类平均质量。
- T差距：T较慢类平均质量减T较快类平均质量。

相同图对两方向共用类别和人员，因此40方向不是40个独立分类试验。Q差距的正负在26/40个WQ方向一致，在32/40个3D IoU方向一致；T分别为12/32、20/32。方向一致也不保证差距幅度相同，更不是分类准确率。

同建筑匹配控制、目标图等权结果如下：

|类型与质量量：跨视角类别差距的绝对误差|同房源|单张同建筑同类对照|
|---|---:|---:|
|Q类别，WQ分|11.076|**8.944**|
|T类别，WQ分|10.729|**10.082**|
|Q类别，3D IoU百分点|**5.074**|5.658|
|T类别，3D IoU百分点|**5.159**|7.635|

3D IoU有一定差距迁移线索，WQ没有一致优势。不能因某个视角中Q较高类的分数反而低，就临时调换类别；也不能因慢类某些底面曲线接近就宣布慢人质量更高。一般人员效应所预示的类别差距同样保存，扣除该差距后的数值只作条件解释，不重复计算成新证据。

## 三、同类人员的人数曲线是否相似

沿用固定Lee MV50底面法，每个子群在两视角和对照中使用完全相同人员，对每个实际k精确枚举。没有输入GT来选融合，也没有利用目标分数选择类别；GT只在融合后评价。每个类型方向的原始水平与减去自身k=1后的形状分别比较。

下表使用**相同图对、两类共同人数窗口、单张源图预算、uNb目标图等权**。较小表示更可迁移，数值均为底面IoU的平均绝对差。

|候选类别|水平：同房|水平：对照|增益形状：同房|增益形状：对照|
|---|---:|---:|---:|---:|
|Q较高|**0.03322**|0.05048|**0.01842**|0.02510|
|Q较低|0.05184|0.05364|0.02237|0.02242|
|T较慢|**0.03646**|0.05372|0.02245|**0.02101**|
|T较快|0.06393|0.06726|**0.01040**|0.02315|

这更接近用户提出的分层问题：**不同候选类型可能保留不同部分的规律。** Q较高类在水平与短期增益上有较一致线索；T较慢类主要表现为水平相近，T较快类则在短期变化上更接近。但多数共同窗口只到2—3人，不能将它们写成高人数收敛规律。Q/T类别还对应不同具体成员，当前比较没有识别类别的因果作用。

各类自身完整人数区间、原始GT敏感性及相同窗口结果全部保留。T较慢类在自身完整区间下的增益误差也是同房0.02365、对照0.02264，仍无改善；没有只挑较好看的共同区间。原始GT共同窗口的结果见[同人数汇总](type_curve_balanced_by_building.csv)，不按最高IoU选择参考版本。人工修订GT没有足够的两端共同覆盖，因此未声称完成这一路同集合敏感性。

本轮人数曲线仍是底面区域法，不是完整墙线/WQ融合轨迹。**完整WQ人员差距未稳定迁移，与底面子群曲线出现线索可以同时成立**，原因仍可能涉及上下定位、方向、具体成员与参考目标等；本轮没有据统计新裁决其视觉原因。

## 当前能说什么、下一步做什么
