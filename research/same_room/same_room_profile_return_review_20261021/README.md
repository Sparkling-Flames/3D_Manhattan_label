## 采用判断

**建议采用这轮同房结果的核心发现和可追溯实验库，同时明确它不是最新人员分类总目标的完成证明。** 五个原包实际取得，CRC 和包内 206 个文件哈希一致。旧 47.1 MiB 原件仍未找回；本轮为重建及新增，不能将新团队库冒称旧库原样恢复。

1. **平均质量相似性是值得保留的主发现。** 123 个直接图对、64 图、12 栋建筑覆盖两视角组。全 64 图单源均值预测 MAE 5.081，楼外图片均值 9.303。使用共同人员与实际人员池得到的均值差分别约 7.238 和 6.810，含义不同；人员构成可以放大、也可以掩盖视角差异。建筑仅用于留出/计权，未替代用户原房间组。
2. **公共任务水平和稳定个人差异应分开。** 排除本人后的源图公共水平 P 加楼外个人相对水平 θ，是强个人预测基线；最大历史 MAE 11.145。加半份本人剩余项没有总体 MAE 优势，却有排序及部分组条件收益，不能将其描述成强而普遍的个人房间专长。0.405→0.239→0.031 是描述性残差关联，不是因果方差贡献率。
3. **类别不是无效，而是用途不能混淆。** Q 匹配后未保留原跨类平均收益，以及类别未超过历史 Q 的预测增量，不足以否定类别构成的总效用。最新主线要求先评价总作用，再解释附加信息。原报告保留容量随机结果是正确做法；它尚未穷举所有类别人数配置、具体成员集合或大团队类别块。
4. **选队和成本结果值得条件采用。** 楼外 Q 是强选队基线；楼外 Q/T 的劳动比约 0.787，同时存在损失超过 5 分的坏尾 8.57%。这里劳动比是逐对对数后分层平均再指数还原，不能直接称所有作答总劳动减少 21.3%，也不是交付时长或货币成本。原报告脚注已正确区分。
5. **已有历史与从零建立历史不同。** 源曲线规则用于已有同房评估历史时有价值。四个可计时组从零获取多数源完整历史，相对所有视角固定 7 人的劳动比约 2.395。几何稳定或全票不能替代定位准确性；G046/G205/G172 的机制解释应保留。

## 本次新增分析：跨视角重复的到底是什么

代码 `audit/extend_mechanism_transfer.py` 基于原包的精确替换事件新增分析，不新造团队、不修改融合。每个完全相同的成员替换/人数作为一个无向图对事件；先图对内平均，再建筑等权。与 Pro 的源→目标/目标图计权不同，数值不强行对齐。

普通 Manual、可比范围、容量随机粗类 M0→M1、5 人换 1 人：118 个精确图对事件、11 栋，116 个两端均可评分。

- 两视角节点数变化方向一致的建筑等权比例为 **82.60%**。
- 其中 **76.79 个百分点**其实是两视角节点数都没有变化；两端同向且非零只有 **5.82 个百分点**。
- 质量作用反向为 **33.15%**；其中 **25.70 个百分点**发生在两端节点数都不变时。
- 相同替换的 B8L2 增量跨视角绝对差平均约 **8.05 分**。

反向 M1→M0 也有约 32.72% 的质量作用反向。完整条件、失败分母及其它 n/m/粗细类结果均保存，没有只发布上述一格。

这增加的认识不是“类别没用”，而是：**将构成作用传递到另一视角时，要分清没有节点数变化、真实结构表达变化，以及位置/规整性和参考质量变化。** 节点数同向率会被零变化显著抬高；同点数不能证明同一细节保留。`dir` 在本轮仅指自身正交规整性，不冒称相对 GT 的墙向距离。该补充是已探索库存上的描述性分析，不是新的外部验证或部署选队规则。
