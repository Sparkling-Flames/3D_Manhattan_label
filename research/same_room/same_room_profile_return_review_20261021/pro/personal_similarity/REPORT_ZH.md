# 同房不同视角中的个人质量：什么重复，什么只是公共难度与稳定人员水平

输入 commit：`561584c8f64d5349d497ec1c6e91f1aeb4bbd7c9`。采用关系版本：`same_room_user_working_classification_20261016_v2`。人员标签：当前已校正 `labels/lobo_labels.csv`，版本 `personnel_taxonomy_20261021_v1`。本目录是本轮新增分析，复用原多历史划分；没有找回旧 47.1 MiB 包的个人预测原件，也没有将旧回复数字补写为原始结果。

## 1. 最值得保留的判断

**同一人的同房 Q 确有重复关系，但主要由两种可分开的信息组成：房间/源视角的公共质量水平，以及该人在楼外的稳定相对水平。扣除两者后，普遍的“个人特别适合这一个房间”效应很弱。** 这并不意味着同房线索没有价值：将公共源水平与楼外个人水平结合，反而比直接照搬本人源 Q 更准。

在原 44 图、1385 份目标作答、7 栋建筑的最高历史条件下，本人源 Q 均值的 B8L2 MAE 为 **12.364**；公共源水平加楼外个人相对 Q 为 **11.145**；只有楼外个人绝对 Q 为 **15.402**。同房信息值得保留，其主要作用是给人员画像提供一个当前任务的水平基准。这里独立复算得到的 **11.144709** 与 Dot 的匹配源历史结果一致；不把其额外使用本人未作答源图的 11.125810 当作同预算结果。Dot 对照引用固定 PR 头 `e83286b7814afc614253aa392050e9a3851ae058` 的 `same_room_independent_followup_20261021/calibration/README.md`；扩展源图数字是引用，未在本目录重复计算。

**本人源信息仍有另一种实用价值：排序和局部条件适应。** 在上述强基线上加半个本人同房剩余项，整体 MAE 几乎不变（11.145→11.166），但每次实际历史内的目标人员排序相关从 **0.398→0.432**，大幅高估超过 20 分的比例从 **9.98%→8.79%**。G178 与 G057 的绝对 Q 预测也有清楚改善，G046、G205 则是反例。不能把“平均绝对误差不改善”直接写成“本人同房信息没有用途”。

**类别对质量预测的增量很小，不宜成为主预测器的必要成分。** 固定半份同类剩余项将 MAE 从 11.145 降至 11.078，只有 **0.067 分**，7 栋中 4 栋改善；两视角直接单源面板反而略差。风险预测在强简单基线上直接加入类别也没有改善。类别仍可用于结构和组合机制解释，本结果不取消其几何用途。

## 2. 同一个人的相似性，不能与房间平均相近混为一谈

主描述包含全部范围可比、正式质量有支持的普通 Manual 直接关系：**123 图对、64 图、12 栋建筑、57 人、2581 个人图对**。两视角房间在内，原声明允许重叠，不形成传递闭包。旧报告的逐人绝对差 **16.384** 和共同人员排序相关中位数 **0.261** 得以重现；它们是图对层面的汇总，不能当作 2581 个独立实验。

本轮进一步分离公共与个人成分。每个源/目标任务均从同行均值中排除本人，楼外个人水平也不含目标建筑。

|观察量|结果与含义|
|---|---|
|对称、建筑→图对→共同人员等权的绝对 Q 相关|0.405；包含房间公共水平和稳定人员差异|
|减去该图其他人员均 Q 后的相关|0.239；公共质量水平解释了部分相似性|
|再减去楼外稳定个人相对 Q 后的相关|0.031；普遍额外的个人同房剩余关系很弱|
|每图对内人员 Q Pearson，再对建筑等权|0.273；扣楼外个人水平后为0.062。这是另一种汇总，不与上一序列混用|
|两端相对同行好/差同号|59.06%；按两图边际正负比例得到的独立参照为50.35%|
|扣楼外个人水平后剩余项同号|51.04%|

2581 个个人图对中，W022 的 S9h-06/-10 一对缺合法楼外历史，剩余项保持缺失；其他 2580 对有支持。相关与同号率是描述，不是因果方差比例，也不据大量重复图对给显著性结论。见 `information_decomposition_summary.csv`、`personal_similarity_by_building.csv` 和逐人原表。

## 4. 留出用途：什么信息真正增加预测能力

### 复杂连续模型与类别必须面对强基线

本轮固定比较了17个 B8L2 Q预测器：6个固定规则、7个 Ridge 信息组合、4个浅树绝对误差模型。D10保留固定与线性13个模型。所有拟合按整栋建筑留出，训练行的个人历史同时排除外层建筑与该训练行建筑；标签取对应外层建筑排除的既定版本。没有重分型或据测试结果调参数。

最高历史中，拟合 P/θ 两系数的 Ridge 为11.382；丰富连续画像＋本人信息的浅树为11.646；丰富连续 Ridge 为12.202、加类别为12.138。后一差额不能宣称类别已胜出，因为两者仍差于11.145的强基线。固定类别剩余收缩直接加在强基线上，确实有0.067分小改善，但没有足够实用幅度取代主规则，且真实低Q尾部由25.72恶化至25.96。原旧回复中的“0.303分类优势”不作为本轮已复核结论保留。

## 5. 低尾判断：有风险关联，但剩余的个人信息很少

全量直接图对中，源Q<50时目标Q<50的建筑/图对加权率为30.93%；源Q≥90时为5.75%。本人源表现是风险信号，却不是失败命运：源低于50后，大多数目标视角仍不低于50。

最高历史中，实际目标Q<50的事后诊断：P＋θ预测MAE25.72、平均高估25.64；加半份本人剩余项降为24.37；本人均值23.44；楼外绝对Q21.74。后两者在整个目标面板更差，不能依据目标已知低Q来选规则。这显示均值最优规则仍会漏掉具体视角失误。

为检验风险信息增量，另设Q<50概率模型。首先固定比较丰富连续与类别模型，随后明确补上强简单基线及其直接类别增量；该扩展时序保存在 `LOWTAIL_EXTENSION.json`，没有伪称预注册或外部验证。

|概率模型，Brier越低越好|同目标单源|最高历史|全部直接单源|
|---|---:|---:|---:|
|简单 P、θ|0.10104|0.09906|0.11772|
|再加本人剩余项|0.10153|0.09882|0.11775|
|再加类别源残差/标签|0.10242|0.09959|0.12361|
|同时加本人和类别|0.10272|0.09952|0.12359|

本人最高历史额外改善只有0.00024，实际用途有限；单源未改善。类别没有超过强简单风险基线。丰富模型“加类别后Brier由0.12769降至0.11271”是实算结果，但仍弱于0.09906，不能作为采用类别的依据。低尾概率主方案宜保留 P、θ；本轮不再扩展此模型搜索。

## 6. 采用建议及证据边界

1. **保留同房质量迁移线，主叙述改为公共任务水平与人员稳定差异的组合。** 人员质量不是只能由个人解释；同一个人所面对的视角公共水平对结果有很大影响。
2. **绝对 Q 预测以 P＋θ 为主。** 它在原多数历史和扩大的直接单源面板都胜过本人源Q与仅楼外个人Q，也胜过本轮更复杂的拟合器。
3. **排序需要时保留固定半份本人剩余项作为独立规则。** 它提高同支持排序，G178/G057也有绝对Q收益；整体MAE与尾部概率不证明它应全面替代主规则。它不是本轮已经验证的最优团队策略，选队仍应由实际融合检验。
4. **类别用于标法/局部结构与组合解释，不强制加入个人 Q 或低尾模型。** 不因本轮Q增量小而取消此前结构、人员替换和融合票账发现。
5. **保留具体视角反例。** G130的类内反向变化、G202的公共视角变化、G046/G205的本人剩余项负收益，都直接改变解释，而不是附带“不能普遍保证”的泛泛提醒。

普通 Manual 是本轮可完成的主分析。正式非OOS证据中，Semi仅有1个物理同房但范围不相容的两图/4人对；门洞保留6个范围不相容图对，未混入主预测。不能据此建立已验证的Semi/门洞统一模型。逐份未知、暂停与不可评分的资格来自冻结证据，未恢复其Q或投票资格。

源Q与公共同行源Q都要求有参考评估过的历史；这不是完全无GT部署。建立历史所需人员劳动和参考成本不在本模型MAE中被当作免费交付成本。最高历史、单源和跨楼拟合均是当前库存的内部留出检查，不能称为新外部验证。
