## 同房各图片的平均质量

先在每个图对内固定共同人员及manual条件，再计算各视角相对自身指定参考的平均质量；没有跨机位叠加BEV。下表每个图对等权，两个组的图对数不同。

|直接关系组|图对数|平均WQ绝对差，0—100分|平均3D IoU绝对差，百分点|平均底面IoU绝对差|
|---|---:|---:|---:|---:|
|G057|2|6.805|4.251|0.00220|
|G178|21|4.704|4.893|0.04319|

两组等权的WQ差为5.754分，但两个组不足以估计一般房间规律。37个其它支持关系图对的WQ平均差为13.606分，仅说明范围/审核条件未齐的同房资料中仍有较大差异，不用它反向证明物理房间不同，也不把它解释为范围的独立因果作用。

**底面相近与完整质量相近需要分开。** VFua-07/10的4名共同人员，WQ均值为60.843与48.083，相差12.761分；整个G057的底面均值差仍很小。WQ另含高度、方向等项，目前未对该例做新的逐作答视觉原因裁决。uNb-07/14的5名共同人员，WQ均值70.471与57.971，相差12.500分；同房身份不能消除视角、目标和人员表现的差异。

[逐图均值](image_mean_quality.csv)保留每张图自身人员池，不能拿不同池均值假装控制了人员组成；[逐对表](quality_pairs.csv)才使用共同人员。[组内共同人员逐视角表](group_common_worker_views.csv)还提供整组固定人员视图：G057可用3/6个视角、G178可用7/7个视角，两组各自所有可用视角的共同人员都仅2人。这说明21个图对的4—9人池并不等于有一个七视角共同9人面板；不能将它们合成一条统一房间曲线。

## 人数曲线相似性

本轮补算保持每个图对及其对照完全相同的人员集合，在每个k枚举所有真实成员子集，两视角使用同一批集合。对每张图分别计算相对其既定GT的底面IoU，再比较逐k的**子集平均曲线**。没有测量单条加人路径的逐步配对差，也不把不同视角的坐标硬配准。

- 水平差：共同k上的 `mean(abs(Qa(k)-Qb(k)))`。
- 增益形状差：各曲线分别减去自身k=1，再对差取平均绝对值。保留原有尺度，不做最小最大归一化或人数轴拉伸。
- Spearman另存，平坦曲线无定义时为空，不以高相关代替分数接近。
- 保留枚举数、可评价数和非空输出比例。当前154个共同池的所有子集均可评价、全部输出非空；这是已经完整可评价的主面板上的Lee结果，不代表原1145条或全库没有失败。

|关系组|水平差，IoU|增益形状差，IoU|
|---|---:|---:|
|G057，两对等权|0.01097|0.00909|
|G178，21对等权|0.03669|0.01952|

例如uNb-07/79的8人共同池，水平差0.08628、增益形状差0.03465；uNb-72/79的曲线Spearman达0.929，水平仍相差0.07033。相似变化顺序不保证质量水平相近。奇偶MV50的平票保留会使曲线起伏，本轮不平滑或删偶数点。

[全部23对曲线图](all_same_room_lee_curves.png)逐对展示4—9人的实际区间，纵轴统一0—1。绿色是所示源→目标方向的多张同建筑对照均值，仅作辅助；主对照预算见下表。两个方向可能因源图粗类不同而有不同可用对照，空线不是补零。

## 源视角到留出视角的简单迁移

每对的两个方向都作为固定任务，不按效果选源。用一张同房源图的共同人员质量均值/平均人数曲线直接预测目标；没有拟合模型或读取目标分数调参。对照必须覆盖完全相同人员、与**源图**粗类相同，位于同房候选连通块外。目标人员支持、既有目标适用性和粗类都来自回顾资料，因此是条件迁移诊断，尚不是面向未来未知标注的独立部署验证。

46个定向任务中36个具有同建筑匹配对照，均来自uNb的7个目标视角；VFua无此类对照，缺失保留。同建筑未记录关系不等于已确认异房。每次一张对照图的误差先对对照图等权平均，再按源任务、目标图、建筑分层汇总；主要表为**目标图等权**，有36方向等权结果作对账。

|预测量，误差越小越好|一张同房源图|一张同建筑同源图粗类对照的平均误差|误差减少|
|---|---:|---:|---:|
|共同人员平均WQ，分|4.954|9.442|4.488|
|共同人员平均3D IoU，百分点|5.213|5.868|0.655|
|Lee底面IoU平均曲线：水平|0.03865|0.04997|0.01132|
|Lee底面IoU平均曲线：增益形状|0.02017|0.02336|0.00320|

WQ的单源误差在7个目标图均较小；Lee水平为5/7图较小，增益形状为6/7图较小。它们共享一个关系组、一栋建筑和部分人员，不能当作7次独立房间验证，差值没有总体置信区间或显著性结论。

**信息预算会改变比较。** 如果把多张对照源图先取均值，目标图等权的WQ误差降为3.797，反而小于单张同房源的4.954。对应Lee曲线也保存多源均值结果，但与单源预算分列，不能混合后挑有利结论。这意味着当前资料支持“同房单源有信息”，尚不支持“只要同房就优于更多历史资料”。

建筑外同源图粗类历史资料另列：42个uNb方向可比较，单张外建筑源的WQ期望误差16.418，同房为4.704；3D IoU分别9.505和4.893百分点。建筑外可用图片/人员分布不同，这个差距不识别房间标签的独立作用；VFua没有相同条件的外建筑控制，未强行放宽筛选。

所有预测参考都是各图自身指定版本。原始GT敏感性下，目标图等权的Lee水平误差为同房0.03865、对照0.04866，增益误差为0.02017、0.02261，方向相同。人工修订GT只有部分图片可用，没有两端共同修订的主同房图对，未冒称完成同集合修订敏感性。
