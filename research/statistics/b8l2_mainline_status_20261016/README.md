## 建议推进顺序

### 第一批可以并行

1. **统计与数据线提供共同接入材料。** 使用本轮已核验的B8L2明细、当前GT/目标绑定、来源池和缺失清单。优先查清准备进入人员/融合/同房分析的图片的参考缺口，不必等全部库存都能评分才研究现有合格集。
2. **图片难度线使用v4并保存分类依据。** 22处分歧已经按用户意见采用，当前研究无需等待重新裁定。分类表述为固定目标后结合几何特征、视觉线索与人工复核的粗分类；若需要检验规则的可复用性，再做独立复核。保留v3用于敏感性比较，不用质量均值的顺序证明v4正确。
3. **人员线重建Q/T。** 以当前合格作答、固定参考与B8L2形成新画像；保留目标建筑外信息隔离，汇报覆盖与边界人员，不预设天然人员类型。原来的四变量问题仍保留，S/B后续在语义和指标对应清楚后接续。
4. **融合线先迁移评价，不同时改融合算法。** 对已有实际成员、几何和人数轨迹应用B8L2及同参考IoU。特殊层先从已有6图核对目标与表示适用性；不能因为普通主表无分，就把已有特殊研究删除或替换成0。
5. **Pro独立推进整体新质量模型。** 不要求保留B8L2的方向、组合或参数；现有主线不因此停工。

### 第二批按依赖接续

- **人员组合**：在新Q画像与同一冻结融合终点质量都可用后，重做同一团队的一人替换分析。先报告同集合变化，再单列新资格面板，避免将换样本误认为新算法收益。
- **同房**：基础B8L2描述可以先做；人员类型迁移等新版Q/T，完整墙线过程等融合评价接入。Lee底面历史轨迹可保留对照，但不能称为完整B8L2墙线轨迹。
- **统筹**：汇总不同图片条件下的质量、时间、人员组成、融合稳定性和参考位置；允许“更稳定但不更接近GT”。暂不锁定论文大纲或以预期结论裁定方法。

### 本轮现有数据收尾后

统一记录各模块使用的输入、参考、难度、评分版本及人员集合，保存完整结果和待处理原因，再加入新人员/图片。未来用新质量算法重评分时保留相同输入，说明哪些结论稳定、哪些敏感；不覆盖旧快照。

每个模块的接入完成应包含：实际成员与参考清单、B8L2和对照指标、有效/失败/缺失分母、相对旧结果的同集合比较及剩余问题。仅在报告中把WQ改名为B8L2不算完成。

本轮只读核对原线程，没有发出新的跨线程执行任务。上述顺序是计划，不表示模块已完成迁移。
