## 保留的不确定性

房间分类已经完整存在：原始260组全部人工看过。当前直接按版本化G工作分组及明确拆分/合并统计，不把未单独点击确认或没有全库唯一物理ID当作缺人工分类。不同房、范围不同、具体争议、重叠成员及未关联图片分别登记，不作传递闭包；组均值和人员均值不等于独立样本或能力排名。见[当前房间分类采用口径](details_room_adopted_v3/ROOM_SEMANTICS.md)。

e9-16的人工简单标签已采用，但旧表示待核门仍被继承；24份semi质量保留单列，不冒称用户确认特殊。见[e9-16追溯](details/E9Z16_ELIGIBILITY_AUDIT.md)。41份确认新空间中29份完整参考仍待补，旧空间归属和明确hold不由本统计模块强行解决。43图点位人工确认没有自动补齐顶边或改变冻结评分参考。

缺失不是0，未运行不是失败；未标记特殊不是确认普通。人工难度部分参考过作答，分组差异不能作为独立难度规则验证。IoU仍为既定底面/均高棱柱口径，不是任意实体精确IoU。新人员/图片/算法应另起版本，旧3152/1145/931/836及后续891/1622历史集合保持可追溯。
