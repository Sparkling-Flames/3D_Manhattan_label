## 来源与边界

- 输入：`research/fusion/worker_composition_fusion_20261018/input_snapshot.json`，修订号`processed_input_fine_composition_20261018`，沿用已处理点对和声明环序。八图191份真实作答，96份人工确认环序、95份默认环序未审。没有接入35份/图的新增或模拟数据，没有读取原始导出。
- 距离：复用`worker_annotation_similarity_20261018.analyze_images`。上下端点球面角距离取最大，整环最大，再取所有循环起点中的最小；不反向、不自由匹配、不移动坐标。不同点对数不可比较且必分开。
- 完整链接与全局亲近度共用同一距离矩阵、同一6/9/12度阈值。后者在同簇两两距离不超过阈值的约束下最大化Σmax(0,1−d/τ)²，以成对二元变量和三角传递约束实现。每个点数层独立求解，60秒上限；可行但未证最优的状态必须显示。本轮全部取得目标最优证明，不证明分区唯一或语义最优。
- 这是9月目标与当前绑定循环距离的新组合，不是9月25.6像素版本复现，也不是10月1日允许未匹配点和反向环序的部分对应。
- 不使用GT、Q/T、Semi、scope或融合结果定簇。研究合同、资格、评分、票权与原始输入未修改。人员分类只是当前执行暂停，研究目标保留。

## 字段与复现

`review.json`及页面`cluster-review-data.js`为同一负载。顶层schema、source、revision、distance、cuts、images；image内records为输入字段投影，pairs以零基记录位置a/b索引，d为度或null（点数不同），shift为当前成对循环偏移，margin为次佳减最佳距离。states以cut定位，groups按方法保存成员索引数组，objective为亲近度目标值，solver逐点数层保存最优状态和gap。簇编号由固定人员排序后的成员列表确定，不可跨方法或阈值对号比较。人工导出以图片、阈值、两个object ID和record ID绑定，并保存当时组号与输入修订。
