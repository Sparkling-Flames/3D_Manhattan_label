## 1. 自然人数曲线：你的预期得到了哪些支持

## 2. 类别进入顺序：过程确实会不同

四种顺序分别优先当前楼外标签中的高历史Q角色、较多转折角色、人数最多结构类、快角色；基于同一条自然顺序稳定调整，最终成员不变。这回答“先由哪些人形成共识”，不等同于最终配比改变。

四策略共同支持、N≥20普通图，比较 k=3 至 floor(N/2)，每图配对8条自然路径，再人数和图片等权：

|顺序|Manual平均ΔQ（157图/22楼）|提高图片|Semi平均ΔQ（21图/11楼）|
|---|---:|---:|---:|
|高历史Q角色优先|+7.71|152/157|−0.87|
|较多转折优先|+6.15|137/157|−0.73|
|历史人数最多结构类优先|−1.84|40/157|+0.11|
|快角色优先|−1.65|53/157|−0.09|

这已经说明类别/角色能解释人数过程中的实际差异。Manual的多数规律很清楚；Semi呈现不同结果同样值得保留。满员时各策略使用完全相同的团队，差值为零，不能把前段收益说成全员收益。

质量与时间必须使用同一支持。完整历史时间共同域Manual88图/20楼：高Q优先为Q+7.62、记录时间+1.50%；多转折优先为Q+7.18、时间+6.19%；快角色为Q−0.54、时间−21.80%。Semi完整时间域只有3图，单列。Q90到达人数是事后可评价的过程指标，不是已实现的无GT在线停止规则。

表见 [策略汇总](population/POLICY_RECOMPUTED.csv)、[逐图结果](population/POLICY_PER_IMAGE_RECOMPUTED.csv)。`common`行的`q`是上述质量共同域；`qt_q/time_pct`只对有时间的局部支持计算，正式质量—时间联合叙述使用`complete_time`行，避免拼接分母。

## 3. 同房重复性：类别用途与成员不确定性同时成立

沿用用户既有直接同房关系。当前结构类别为主，楼外标签按目标建筑留出；没有把同建筑改称同房，也没有本地重拟合新类别。

- 17个声明组中13组的配比相关均值为正；主面板按图对→组→楼等权后的正趋势比例61.16%；两端配比质量极差均≥2时为73.23%。这些是有实际用途的多数/条件规律。
- 合并配比相关约0.0018，同配比成员剩余相关约0.0228。它们衡量幅度关联，不能消除上述出现频度规律；也提示不能照搬另一个视角的具体Q增益。
- 在相同时间/Q支持下，纯类与同配比一人替换的时间方向一致率为78.19%/81.63%，Q方向为49.77%/40.51%。时间是已保存的个人记录劳动量，不是日历交付时间。

**人员类别用于描述混合人群、组织配比和解释差异；同类人员仍有不确定性，本身就是结论。** 详细口径及直接输出见 [同房独立记录](same_room/SRCC_INDEPENDENT_REVIEW.md)。

### 三处小修已记录

1. 源端极差用了双端共同可评分团队，应称“共同支持上的回顾性源端阈值分析”。改为仅要求源端可评分时，一处方向跨过2分门槛；不推翻双端有响应的73.23%。
2. 增人劳动比2.006是分层算术平均；报告写成log平均还原不符。采用2.006并修正文义，后者另算为1.940。
3. 一格零阈值Q同向数当前端点为49/120，原保存为50/120；本地输出采用49。总体仍四舍五入为40.51%，不需要因这一个计数悬置研究。

## 4. m≤4的真正原因，以及本地已经补完的大块比较

同房设计有 `k=min(4, class_a_n, class_b_n, N-3)`，因此四人包含人为上限。普通主预算309面板中，209已覆盖较小类别的共同容量；100面板、86图对、9楼仍可设计纯类m5–10。原结论中“完全受真实容量限制”的解释应修正。

本次直接复用已有冻结团队，**新增融合和评分均为0**，完成两类较大块诊断：

|比较|事件|图对/楼|替换人数|每视角绝对Q变化均值|
|---|---:|---:|---:|---:|
|纯类别换块|134|18/3|5—6|3.90分|
|同配比换具体成员|193,704|99/10|5—12|7.22分|

纯类按历史转折中心由低到高定向，平均Q变化+1.06，但93.54%两视角转折数都不变；在2分变化阈值下两端非小同向13.76%、反向28.58%。大块替换已有实质质量变化，机制不能只看转折数量，定位及背景仍需解释。具体成员造成的配比内波动也保留下来。

两行图片、人数和背景支持不同，**3.90与7.22不能直接用来判定类内/跨类谁更强**。现成纯类大块未找到同D、同m且X/Y/Z互不重叠的第三队B；已完成的是AC变化和配比内扰动。只有以后专门回答“匹配背景下跨类净影响是否更大”，才需要定向补这类B端点，不妨碍当前主线收束。

新诊断不是Pro原结果。去重、方向、层级平均、阈值、失败和支持均见同房记录第四节及 [逐图对×n×m表](same_room/INDEPENDENT_EXISTING_LARGE_BLOCK_EFFECTS_BY_PAIR_N_M.csv)。
