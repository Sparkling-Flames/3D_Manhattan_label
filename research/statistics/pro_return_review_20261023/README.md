## 3. 同房重复性：类别用途与成员不确定性同时成立

沿用用户既有直接同房关系。当前结构类别为主，楼外标签按目标建筑留出；没有把同建筑改称同房，也没有本地重拟合新类别。

- 17个声明组中13组的配比相关均值为正；主面板按图对→组→楼等权后的正趋势比例61.16%；两端配比质量极差均≥2时为73.23%。这些是有实际用途的多数/条件规律。
- 合并配比相关约0.0018，同配比成员剩余相关约0.0228。它们衡量幅度关联，不能消除上述出现频度规律；也提示不能照搬另一个视角的具体Q增益。
- 在相同时间/Q支持下，纯类与同配比一人替换的时间方向一致率为78.19%/81.63%，Q方向为49.77%/40.51%。时间是已保存的个人记录劳动量，不是日历交付时间。

**人员类别用于描述混合人群、组织配比和解释差异；同类人员仍有不确定性，本身就是结论。** 详细口径及直接输出见 [同房独立记录](same_room/SRCC_INDEPENDENT_REVIEW.md)。

### 三处小修已记录

1. 源端极差用了双端共同可评分团队，应称“共同支持上的回顾性源端阈值分析”。改为仅要求源端可评分时，一处方向跨过2分门槛；不推翻双端有响应的73.23%。

## 4. m≤4的真正原因，以及本地已经补完的大块比较

本次直接复用已有冻结团队，**新增融合和评分均为0**，完成两类较大块诊断：

|比较|事件|图对/楼|替换人数|每视角绝对Q变化均值|
|---|---:|---:|---:|---:|
|纯类别换块|134|18/3|5—6|3.90分|
|同配比换具体成员|193,704|99/10|5—12|7.22分|

纯类按历史转折中心由低到高定向，平均Q变化+1.06，但93.54%两视角转折数都不变；在2分变化阈值下两端非小同向13.76%、反向28.58%。大块替换已有实质质量变化，机制不能只看转折数量，定位及背景仍需解释。具体成员造成的配比内波动也保留下来。
