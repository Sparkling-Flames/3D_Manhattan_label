本目录由独立审查生成。复核程序不调用交付方的统计聚合函数，不重新融合或评分。

## 复现

`--input-root` 指向 S10/S11 解压后包含 `analysis_precision26` 的目录；`--repo` 指向已有 HOHONET 仓库，`--downloads` 指向含 S01 和 14 个 DATA ZIP 的下载目录。

```powershell
python reaggregate.py --input-root <解压根目录> --output <复核结果目录>
python recompute_selected_prefixes.py --input-root <解压根目录> --repo <仓库根目录> --downloads <下载目录> --output <复核结果目录>
```

- 41,252 行逐图逐人数的均值标准误、实际共识失败率、已生成但不可评分率及旧不可评分率。

## 对论文结论的影响

1. 主展示可采用 256 条与既有精确边际，旧 24/48 条转为历史来源和独立追加对照。256 包含旧48，删除这些来源会破坏复算链。
2. 普通 Manual 固定 157 图的总体平均曲线变化很小；单图精度提升显著。3 人时，均值 MCSE>1 分的图片数从 122 降至 20；P10 经验区间半宽>2 分的从 137 降至 76。
3. 困难 27 图的 20→30 人：均Q −0.174941，P10 +4.245765（24图提高），Q标准差 −4.675889（25图下降）。追加使“后段低尾和稳定性改善”的认识更明确，没有给持续升质提供依据。
4. 困难 27 图的 3→6 人：均Q +6.107330（26图提高），实际共识失败率 +4.3258 个百分点（17图增加）。质量均值与形成共识的概率应并列呈现。
5. 门洞 17 图的 6→10 人均Q −1.006448（12图下降），实际共识失败率 −13.5340 个百分点（17图均下降）。应修正旧48的微升说法。
6. 门洞 20→30 人：均Q −1.729335 的质量分母为15图；失败率 +9.1309 个百分点的分母为16图，其中6图增加、5图减少、5图不变。不能把均Q平均下降改写成多数图片下降，此处实际为8图上升、7图下降。
7. 本轮未改人员分类与严格ABC的成员、端点及配比实验。依赖旧随机人数基线的单图尾部说明需要更新，类别与换人换类结果无须据此整体重算。

本复核未重跑原生融合、完整几何距离或全套 bootstrap；经验区间与路径/建筑重抽区间的数值不是本目录重新估计所得。
