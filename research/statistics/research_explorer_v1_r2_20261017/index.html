质量指标

评分公式 · 与冻结实现一致

打开质量算法流程图 · 打开与3D IoU的真实对照

设 I 为底面IoU，S 为球面底边误差（°），d 为方向残差（°），Hₘ 为整体高度误差，H꜀ 为局部中心化高度误差。

b = S² / 32
uₐ = 1.5 d² / (d² + a²)
g = (Hₘ / 0.8)²       h = (H꜀ / 0.25)²
Lₐ = √[(1 − I + I b)² + (I uₐ)²]
Qₐ = 100 I / [I + Lₐ + I(g + h)]
B8L2 = Q₈             D10 = Q₁₀
I = 0 时 Qₐ = 0
I = 面积(A ∩ G) / 面积(A ∪ G)

A为作答声明底面，G为绑定参考底面。L2只组合范围／底边与方向损失，高度项另外相加；不是五类分项各自平方后相加。Hₘ、H꜀沿用冻结引擎测量，不能以顶点高度方差代替。

同图同条件同参考的保存团队，可报告 ΔQ = Q(团队B) − Q(团队A)；这是相对参考评分变化，不代表所有局部结构都变好。

B8L2 · 主指标
0–100分，是参考接近程度与作答内部几何一致性的联合工作指数，不是正确概率。范围／底边与方向块以L2组合，整体及局部高度损失另外相加。方向尺度取 8°；它不是容差区间，也不代表正确概率。
D10 · 敏感性指标
与B8L2使用同一输入、参考和质量资格，仅将方向尺度由8°改为10°。涨分不代表标注变好；部分作答的排序也会变。
底面IoU
声明底面与参考底面的交集面积／并集面积，取值0–1。只衡量底面范围；顶界、高度和局部结构要另外看。
均高棱柱IoU ×100
当前冻结引擎使用角点均值高度的棱柱代理，并非一般连续三维实体IoU。与B8L2并非同一种质量度量。
比较前提
先核对图片、采集条件、参考与评分版本。诊断分不自动进入主质量统计；GT／参考有问题时，分数不能当作正确性结论。

r_wc = q_wc − [Σ(v∈Wc, v≠w) q_vc] / (|Wc| − 1)
Q_peer(w) = mean_c(r_wc)
u_wc = ln(t_wc) − mean_(v≠w) ln(t_vc)
relative_time(w) = exp(mean_c(u_wc)), t_wc > 0

Q背景c为图片、条件、目标参考和参考版本，同行不按新旧来源切开。时间另按origin与time_source_kind分背景，使用ln(T)，不是旧任务效应的log1p(T)。relative_time<1表示在相容同行背景中较快，不作跨来源统一耗时倍率。只有一人或缺少相容时间时保留缺失。画像均值、偏低的部分（P10）和难图表现，各自只用有记录的那部分作答；它们不是正式类别。

历史任务效应画像 · Q_effect／T_effect

绝对均分 Q̄w = (1/nw) Σc qwc
相对效应 β̂ = argmin Σc Σw∈Wc [(ywc − ȳc) − (βw − β̄c)]²
约束：Σw βw = 0
质量轴：ywc = 对应版本B8L2（或独立拟合D10）
时间轴：ywc = ln(1 + twc)，twc以秒计

w是人员，c是任务背景，Wc是该背景中的可比人员，ȳc是背景内观测均值，β̄c是这些人员效应的均值。背景按图片、条件及等价参考几何绑定；不是所有同图作答都能混合。相对Q为质量轴β̂w；T为时间轴β̂w，负值倾向较快，正值倾向较慢。它们都不是百分比。

楼外画像剔除目标建筑后拟合；旧版这套画像要求比较图连通，且至少6个背景、3栋建筑才标记支持。该公式解释已有任务调整画像，不用于替代Rnew2／F01等其它研究标签的各自规则。

绝对Q
依据有质量资格作答的参考评分描述表现；均值、P10 等是不同统计量。人员任务不同，直接比较均分会受难度、条件和参考分布影响。
相对Q
已有任务调整画像中的相对效应（Q_effect），用于比较任务背景调整后的表现；不是逐图排名，也不是正确率。具体估计与支持范围以对应表的来源口径为准。
T · 时间
区分来源活动时间与同目标时间。来源时间不自动等于当前参考目标耗时；缺失不能用lead_time或0替代。现有T效应分组与固定分钟阈值分类不是同一规则。
难度
使用已有图片难度标签，可观察同一人员在不同难度上的表现。样本少时不能据少数高分确认“擅长难图”。
Semi · 半自动
记录是否修改预标注及错误预标注的处理。“盲信”要有可确认的错误预标注记录和最终作答证据；没改动不代表盲信，改动过也不代表改对了。
Scope · 范围判断
区分范围选择倾向、有记录的判断条数和这些记录上的判断结局。图片的 OOS 标签不能当作每次作答的标准答案；有记录的比例也不是准确率。
类别标签
Q、T、难度表现、Semi和Scope是可讨论的细分变量；当前页面中的候选标签依各来源保留，不代表已确定的通用人员等级。高Q组合也不保证融合更好。

数据范围与缺失值

版本
顶部选择v1／v2。历史实验按自己的快照解释，切换主版本不会把历史实验重新计算成最新结果。
研究清单
以全部非OOS图片为起点，门洞交界单列。GT有问题的图片仍可研究标法；涉及正确性和评分时另行限制。
质量资格
全部记录数、可计算数、主质量可用数，以及人员／图片／团队数使用不同分母。能算出几何，不代表有主质量资格。
缺失
未知、不可用和不适用分别保留，不按 0 填写。没有同房记录时按未知处理；同一建筑不表示同一房间。
来源追溯
“数据与方法”模块保留统计表与支持范围。原处理点位、参考及保存的融合状态保持可追溯；报告文件不作为这里的指标定义或正式结论。

如何查看原标注与融合

  1. 进入“类别原答与融合”，选择图片、条件与类别口径，比较同图原标注叠加。
  2. 勾选成员或高亮人员，分辨细节保留、简化、范围差异与bottom-y相关变化。
  3. ERP视图用滚轮／加减按钮放大，拖动查看局部，重置恢复全图；切换BEV和3D辅助判断平面接近但高度不同的情况。
  4. 选择已保存团队，核对成员、融合几何与已有质量分。原答差异、融合结果和参考评分需分别观察；页面不会即时重算融合。
  5. 进入“同房多视角叠加”，沿同一人员或同一团队查看各视角，核对范围和参考条件。不同视角的分数差不能直接当作人员能力的变化。

没有保存的融合或评分时会明确显示缺失。局部差异值得关注时，再结合同图叠加和局部放大进行人工复核。
