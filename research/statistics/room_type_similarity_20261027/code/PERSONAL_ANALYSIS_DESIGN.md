# 个人用途可重复性：预计算设计

在看到本轮拟合结果之前记录。研究对象为正式可评普通 Manual 原答；Semi、门洞另表，不并入主模型。最终字段/支持以 inputs 底表为准。

## 评价量

每张图上本人 Q 减其他正式可评人员的 Q 均值。同行基准明确排除本人。D10 在共同记录上作为评分敏感性。若有原答结构字段，使用同样的同行调整量衡量结构表达。

## 分割与可知信息

外层整栋楼留出。任何目标作答、目标质量以及目标楼内其他视角均不参与拟合、个人历史或参数选择。因此同一个物理房间另一视角不能成为本轮独立历史。目标可知：身份、已有用途标签、冻结难度；扩展诊断另允许已知参考几何，而不把其描述为无参考部署。预测允许按目标人员名单中心化，不能用目标 Q。

## 候选方法与超参数

1. 零相对差异；
2. 简单楼外个人历史相对均值；
3. 人员主效应岭回归；
4. 人员主效应 + 人员×难度/参考几何；
5. 人员主效应 + 人员×用途；
6. 人员主效应 + 人员×难度/参考几何 + 人员×用途。

各岭模型只在外层训练楼内，按 5 个建筑组折选择 alpha ∈ {0.1,1,10,100,1000}，选择依据图片等权均方误差，不基于目标楼表现。训练作答权重使每图总权重相同。类别保留原标签，不重分类。所有方法在同一目标记录支持比较。

## 汇总

每图先汇总 MAE/MSE；均值按图等权及建筑等权分别给出。模型差异保存逐图、逐楼、逐人、逐用途及 OOF 原始预测。建筑重抽用于描述本数据的建筑层不确定性；不把作答或重叠图对数当独立样本。主判断看实际幅度和改善图/楼/人比例。

## 解释支持

逐个 worker×用途保留历史图、楼、记录数，报告一般历史和用途增量；已知一般水平后尚无增益可以作为结论。少楼用途不合并凑支持，不以总体分数宣称每个人都有用途专长。
