# 同用途房间研究：独立审查与论文采用建议

2026-10-27。审查对象为 Pro 的 room_type 01—04 四包。Dot 本次提供的是包名和交付范围，未提供本轮统计复算结论；下列判断来自本地独立核对。

**主要数值成立。这轮适合归档为图片条件的补充研究，暂不新增论文主章节，也不据此提出“擅长浴室／卧室”的人员分类。** 房间用途对图片平均质量有可重复的小幅预测帮助；具体人员的表现主要仍由其一般历史解释。这两个问题得到了不同答案。

## 1. 最值得保留的结果

### 用途能补充图片条件，但单靠用途名称预测得不好

普通 Manual 共 5,719 份作答、177 张图、60 人、22 栋建筑。预测的主比较限于已有用途标签、且该用途出现在多个建筑的 161 张图，涉及 5,236 份作答、21 栋建筑。预测时整栋目标建筑留出。

MAE 是预测值与真实值的绝对差取平均，越小越好。这里预测的是图片上人员作答的平均质量，**不是融合团队质量**。

| 预测输入或比较 | 图片平均 Q 的 MAE | 得到的认识 |
|---|---:|---|
| 只用训练图片总体均值 | 12.019 | 没有区分图片条件的基线 |
| 只用房间用途 | 11.918 | 用途名称本身的信息很有限 |
| 难度 | 6.556 | 难度标签解释了明显更多的差异 |
| 难度与参考几何，同一候选模型库 | 4.567 | 更强的比较基线 |
| 在上一行加入用途 | 4.188 | MAE 再减少 0.379，约 8.3% |

加入用途后，97/161 张图、19/21 栋建筑的平均预测误差下降。按建筑重抽的图片等权 MAE 改善区间为 [0.152, 0.667]。D10 的改善较小：4.387→4.218，减少 0.168；89/161 图改善，区间为 [−0.026, 0.362]。

0.379 分是**预测误差减少**，不是把标注质量提高了 0.379 分。相对强基线的 8.3% 改善值得记录；它还不足以把房间用途提升为人员研究的主要解释。模型使用既有难度标签和参考布局的几何特征，实际用途是已知这些图片条件后的质量估计。方法比较与选择发生在当前 v2 内部，按楼留出阻止目标楼记录进入训练；它与另收集一批独立图片的验证是不同步骤。

### 同用途的均值略接近，人员相对表现没有一起变得更接近

三图匹配选择目标图 T、另一栋楼内的同用途图 S，以及与 S 同楼、同难度的异用途图 C。C 从合格候选中按参考几何接近程度选择，匹配不读取 Q。各项比较使用 T/S/C 都有作答的共同人员。

在三图难度也相同的 1,638 个匹配事件中，先按来源建筑、再按目标图片汇总，得到 150 张图、21 栋楼：

| 比较 | 同用途 | 异用途 | 解释 |
|---|---:|---:|---|
| 图片平均 Q 的绝对差 | 9.042 | 9.537 | 同用途小 0.494；89/150 图更接近 |
| 个人相对 Q 的平均绝对差 | 16.609 | 16.446 | 同用途没有平均优势 |
| 图片平均有效转折数的绝对差 | 0.726 | 0.716 | 结构数量也未出现统一的同用途优势 |

卧室的均 Q 差距减少 1.312 分，32/41 图更接近；卫浴减少 1.289 分，22/35 图更接近。厨房与用餐的平均差距反而增加约 2.048 分。这里可以保留卧室、卫浴的多数规律；总体上不能只用“同用途”替代具体难度与几何条件。

### 个人的同用途历史没有胜过一般历史

个人模型预测的是一个人在该图上相对其他人员的 Q 偏差。全部历史来自目标建筑之外；比较使用同一批 161 张图。

| 方法 | 个人相对 Q 的 MAE |
|---|---:|
| 不区分人员，预测相对偏差为零 | 12.872 |
| 一般个人历史 | 11.449 |
| 仅使用同用途个人历史 | 12.107 |
| 固定一般历史，再增加用途专属修正 | 11.450 |

最后一个实验专门避免“增加用途时把原有一般能力估计改坏”的问题：一般历史保持不变，只拟合用途修正的收缩强度。22 个留楼折中，21 折选择不增加修正，另一折也采用很强的收缩。D10 得到相同判断。

因此，当前没有必要把人员再分成“浴室型”“卧室型”或重新安排用途专属选人实验。它没有改变 DSTRUCT、RFUSE 和严格 ABC 已有结论；本轮根本没有重新建人员类别或融合团队。

## 2. 怎样放入现有研究

建议保留全部资料，但采用时分轻重：

- **论文图片条件部分可选一段或一张补表：** 原始卧室均 Q 为 76.16、卫浴为 68.07；将六大用途统一到相同的简单／中等／困难比例后，分别为 71.18、74.59。排序反转说明原始用途均值包含了难度构成的差异。六大用途共 155 图，统一权重为简单 65.81%、中等 14.19%、困难 20%。这是一项描述性的条件比较。
- **预测增量放补充材料更合适：** 交代用途在较强图片模型上减少约 8.3% 的 Q 平均预测误差，同时给出 D10 对照。它回答了用户的问题，但对论文主线的新增解释较小。
- **人员用途专长不列为主发现：** 若需要解释为什么没有采用用途建类，可以用一两句话说明一般历史更有用。无需为得到积极结果继续调标签、换模型或增加一批实验。
- **三个机制案例作为已有难度案例的补充：** 104 份正式原答的统计已核对；三图六份代表原答的综合图已查看。局部结构与定位能解释具体差异，不应把案例直接归为用途的作用。

研究台可以在“图片条件／扩展研究”中保留专题入口。是否写入论文，由其对正文的解释价值决定；本次没有自动应用作者提供的接入补丁，也没有改动论文提纲。

这轮不研究同一个物理房间的跨视角迁移。它研究的是不同物理房间具有相同用途时，表现是否相近；两者结论分别保留。

## 4. 两项交付与复现细节

1. `results/personal/OOF_Q.csv.gz.writing.2` 与 `OOF_D10.csv.gz.writing.2` 是损坏的临时导出，读取到结尾会报 EOFError。正式 `.csv.gz` 文件正常，当前代码也不会把这两个残件读作输入。作者“无效导出未收入包”的说明需修正。残件只保留来源身份，不纳入有效结果；无需补下载或重跑。
2. 作者和本地 NumPy／scikit-learn 版本不同，内层 GroupKFold 遇到同样大小的建筑组时可能采用不同的并列排序。个人实验保存了具体分组，按该分组可以完整复现；图片实验只保存所选参数和损失，未另存全部内层建筑名单。本地 8 组搜索均选出相同参数，但损失数值存在分组差异，不能称全部图片内层搜索逐位复现。以后复现该部分宜使用作者锁定环境，或导出内层建筑名单；这不影响本次 88 个最终预测模型的重拟合结果。
