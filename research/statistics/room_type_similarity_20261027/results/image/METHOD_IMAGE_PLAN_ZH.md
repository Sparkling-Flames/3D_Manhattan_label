# 图片用途相似性：执行前比较设计

本文件在读取本轮用途效应结果前保存。沿用已有用途、难度、质量资格和参考；跨建筑图对确保物理房间不同。建筑内关系未知的图对不进入本轮主比较。

## 相似性的估计对象

1. 对每张目标图，比较其与其他建筑同用途图、异用途图的差异。先保留实际作答池，再对每个图对使用共同人员重算均值和人员差异。图对本身不是独立样本；先对每张目标图汇总，再报告图片等权和建筑等权结果。
2. 把同难度、同有效转折数的比较另列，用途总差异不等于用途独立效应。
3. 构造更严格的三图对照：目标图 T 固定，外楼同用途图 S 与异用途图 C 来自同一栋外楼，S/C 难度相同；在可选 C 中按冻结参考几何距离选择，选择不使用质量。T/S/C 用完全相同的共同人员计算质量及表达差异。每个目标图先对每栋源建筑等权，再对目标图等权。保存完整 T/S/C 键、候选数、几何距离、共同成员及支持损失。
4. 结构表达指标以有效转折、近共线点、相对参考简化及已保存定位诊断为准，不能把几何计数差直接解释为语义漏标。

## 留出用途

- 外层留一整栋建筑。任何目标质量、目标作答几何、目标个人残差都不进入预测输入。
- 最弱基线为外楼训练图片均值；再分别考虑用途、人工难度、冻结参考几何、已知分配人员的外楼历史水平，最后加用途。
- 参考几何是研究者已审核结构信息条件，不宣传为完全没有参考的新图预测。完全不依赖参考的用途/难度分支单列。
- 用少量嵌套建筑交叉验证选择岭回归收缩量，并与小型非线性模型对照；所有增量在相同目标图上计算。
- 训练图的历史人员池特征也排除该训练图所在建筑，避免在训练特征中使用同图质量。
- B8L2 为主，D10在相同记录上重算敏感性；原答质量标准差等对象单独报告。

## 结果呈现

报告逐用途、逐图、逐建筑的均值差、绝对差及方向比例，保存所有可复算表与模型输出。建筑重抽仅度量当前建筑集合的敏感性；不把大量共享图对当作大量独立房间。少数用途仅有少量建筑时保留描述，不合并成新类别。
