# 给 Pro：同类房间的质量与个人表现能否重复

请在 HOHONET 当前真人 v2 数据上开展一项实际研究，并把本轮结果与既有相关研究整理在一起。方法由你根据数据选择，不预设某种模型最好，也不要求得到正相关或质量提高。

## 我想研究的问题

我以前已经给图片分过房间用途，例如卧室、卫浴、通行与连接（包括走廊等）。现在想知道：**不同物理房间，只要用途相同，平均标注质量是否有相似性？同一个人的相对表现、结构表达，在同用途的其他房间中是否会重复？**

这类似之前“同房预测”的思路，但这次是同一用途的不同房间，不是同一个物理房间的不同视角。研究的目的，是进一步理解图片条件与人的不确定性。不要把场景类别重新变成人员永久类型，也不要把问题只改写成挑选高 Q 人员。

请分别回答：

1. 同类房间的图片平均 Q、人与人之间的差异、实际结构表达是否更相似？和不同用途图片相比有多少差别？
2. 同一个人在某类房间的相对表现，能否在该类其他房间重复？这种相似性有多少只是因为这个人一般就标得更好？
3. 已经知道人员历史表现、图片难度与几何结构后，房间用途还有多少额外信息？能否帮助估计目标图的平均水平或某个人的相对表现？

质量、差异幅度、结构简化、定位和记录时间都可以有意义；结果可以为正、为负或只在部分条件成立。用平均幅度及支持图片/建筑/人员的比例解释，个别反例不应否定总体规律。

## 研究要求

沿用已有用途标签、质量资格和参考。Manual 优先；Semi、门洞、OOS 分开。用途缺失、明确“无法判断”以及多功能空间分别保留，不根据 Q 补标签。需要人工判断时列出具体图片和疑点，不让全研究等待无关的小样本补标。

请先独立判断哪些比较真正能回答问题，再选方法。原答质量与标法是主对象；不要一开始就用大量融合重算替代它们。可以使用共同人员、一般历史能力、难度、结构特征、建筑等信息，但要讲清比较对象和目标图可用信息。对于预测，评估时不要让目标作答或目标质量进入预测输入；同一物理房间的另一视角也不能悄悄被当成独立新房间。

同用途图对会大量共享图片与人员，几千个图对不能按几千个独立样本解释。请选适合的估计与验证方式，报告图、楼、人员的实际数量。对小类可作描述，不为得到整齐类别而强行合并。优先寻找有效、可解释的结果，不必把每一个阈值都扩成一轮实验。

分别比较未经调整的用途差异、结合难度/几何后的差异、去除个人一般表现后的用途差异。这里要求的是问题区分，不限定必须使用某种回归、相关系数或聚类。B8L2 与 D10 可在相同记录上检查主要判断；时间只使用合法且同来源的支持。

若发现清楚的用途规律，再适度连接既有团队构成和人数曲线。当前普通 Manual 自然顺序已从48扩至256，见 `research/workers/personnel_population_curves_v2_20261023/sampling_extension_20261026/` 及其归档说明；Semi没有扩量，历史进入策略是32条配对路径，不能称新DSTRUCT/RFUSE验证。类别与严格ABC结果也不由自然曲线替代。优先复用保存端点，只有必要时才新增计算并解释理由。
