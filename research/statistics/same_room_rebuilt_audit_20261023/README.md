## 2. 关键发现：回答“换人、换类会有什么差别”

### 2.1 混合队和换少于半队都出现了多数方向

固定保留成员D，A=D∪X、B=D∪Y、C=D∪Z。X/Y来自相同源类，Z来自另一目标类，四块互斥；两个视角使用相同实际人员。用同类幅度 `|B−A|` 和对称跨类幅度 `(|C−A|+|C−B|)/2` 比较，二者相减称“额外幅度”。正值表示跨类改变通常更大，包括升质和降质。

普通Manual结构类主域，先平均两视角，再平均配置内成员、最后图对等权：

|条件|可评/尝试ABC|图对/建筑|同类Q幅度|跨类Q幅度|额外幅度|正向图对|
|---|---:|---:|---:|---:|---:|---:|
|全部，含纯块|27,112/29,543|78/9|7.208|9.322|+2.114|61/78|
|混合队，D非空|25,472/27,773|78/9|6.869|8.829|+1.960|61/78|
|混合队，换少于半队|8,707/9,554|73/9|5.836|7.087|+1.251|50/73|

这支持当前结构类对变化幅度的解释用途，也保留了相当大的类内成员波动。建筑等权额外幅度分别为4.233、4.020、2.804分，权重影响量级。联合Q/T混合域也有+2.055分、22/31图对为正，但支持为31图对8楼，不能据两个均值直接排名分类。详见[独立主结果](results/INDEPENDENT_MAIN_RESULTS.csv)。

实际替换为m5—8、团队n5—24；m8只有2图对1楼，不能把主域整体覆盖写成每个规模都有同样覆盖。所有2,825个合法n/m配置已核对，26个小配置完整枚举；大配置采用均衡成员锚点，**配置覆盖不等于全部具体成员组合穷尽**。现有合格同房共同池中，Semi没有m>4严格ABC容量；此前Semi配比、直接AC和人数过程结果仍独立保留。

### 2.2 质量变化、几何移动和跨视角方向不必一致

在同一14,880个混合事件的Q与唯一几何共同支持上，Q额外幅度为+0.894分，底面平均对应距离的额外幅度却为−0.01204h。h是归一相机高度单位。质量对参照的改变与团队间几何位移是不同指标；异角点数、对应歧义和无完整底面没有填零。见[几何共同支持与汇总](results/label_geometry/审查说明.md)。

混合队C−A按严格超过2分定义响应：双端同向41.92%、单端响应35.03%、双端反向14.31%、双端近零8.74%。仅在双端都响应时，同向率为73.01%；六端点共同可评后按源端响应分组则为53.83%。这两个分母回答不同问题。见[独立响应状态](results/INDEPENDENT_RESPONSE_STATES.csv)。

两个已核原图/原答案例解释这种差异：G130三队都保持四个有效转折，换入块仍通过位置中位数改变质量；G172两个视角都增加一个有效转折，却分别Q约+12.97和−3.86。结构变化不能直接等同于补对了必要结构。两例六队均已从原答重融、重评，未修改冻结参考。

### 2.3 规模、背景和历史质量各有信息

- TURN3“常规转折→较多转折”方向，固定原队与n，m5→6的C−B净优势增加0.776分，31/41图对为正；m5→7增加1.540分，16/21为正。
- 固定XYZ，从纯块加背景至最大D，65图对5楼的C平均−3.482、B+1.259，净优势减少4.741分。扩大替换与增加背景是不同操作。
- 去掉占50/78图对的uNb后，混合额外幅度+2.460，26/28图对为正；少于半队为+1.604，20/24为正。逐楼删除均保留正向均值。
- 28名关键人员中23人存在合法缺席对照，两种匹配均有19/23人的缺席子域额外幅度为正，负向和容量不足者保留。
- 三块楼外历史Q极差≤2分时，均值仍为+1.312，但仅8/20图对为正、涉及4楼。因此已有广域差异成立，尚不能把它全部归因于独立于历史质量的结构风格。

详见[敏感性及路径实核](results/sensitivity/审查说明.md)。成员敏感性按“匹配层→图对”平均，与主域“配置→图对”权重略有不同；另算配置等权后19/23判断不变，零附近个别成员符号变化不用于评价个人优劣。

楼外结构方法族 `V3_BEHAVIOR` 中TURN2/3及结构JOINT4/5保留各自分区与特征含义；结构JOINT不等于 `V3_JOINT_QT`。182个历史角色排名已重建，跨楼按历史特征角色解释，不能直接拼接同号类别。

## 3. 人数与进入策略：保留用途，也接回难度

210个N≥20池的自然均值、P10、样本SD，以及3→6、6→10、10→20、3→20四区间的2,000次完整路径/建筑重抽已独立复现。困难Manual29图3→6平均Q增加约7.97，29/29提高；10→20平均Q约−0.216，主要变化转向低尾与波动：P10+3.122、SD−2.714。

困难图图等权的建筑重抽95%区间：Q为[−3.007,2.533]，P10为[0.291,6.161]，SD为[−5.628,−0.399]；改为建筑等权后P10/SD区间跨零。它支持当前图片中后段稳定性改善，不证明平均质量严格不变。门洞17图10→20平均Q约−3.066，路径与建筑重抽均保留负向；“仅靠增加人数不能普遍解决门洞交界”可以作为发现采用。

四策略共同图片池内，Manual高历史Q优先+7.710分、152/157图提高，多转折优先+6.146分、137/157提高；Semi21图对应约−0.875/−0.727，未复制同一优势。这里是共同图片池，每个策略的可评配对前缀仍可不同；满员成员完全相同，差值为零。这是前半程组成/顺序的作用，不是最终全员收益或无GT停标规则。精确支持与各策略正向图数见[共同池汇总](results/population/POLICY_COMMON_POOL_SUMMARY.csv)。
