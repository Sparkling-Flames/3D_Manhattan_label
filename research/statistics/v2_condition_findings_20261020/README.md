# v2条件差异：人员标法、细节与融合的发现摘要

2026-10-20。入口：[一页发现摘要](SUMMARY.md)。本主题复用当前人员标法、质量解释与同房研究，只新增一个问题的计算：**同图同参考内，少于／多于参考点数的作答，是否都比点数相同的作答质量更高？** 结果并不支持这种单向概括；它不建立新评分或人员类别。

## 本次补充及字段解释

逐份质量和参考回读指定入口 `research/statistics/v2_evidence_audit_20261019/records.json.gz`，以唯一object_id连接现有标法表；核对非OOS库存精确一致。库存9217份、233图、门洞17图；GT问题不从标法库存删除。

本次评分比较仅取普通Manual、`quality_use=ordinary_primary`、正式质量可用且已有个人几何比较资格的记录：5715份/177图/60人。相对既有5719份普通Manual质量面板，4份有坐标修复证据，不进入人员表达比较；66份特殊条件用途未混入。门洞和GT暂停图不参加这项普通质量对照，仍保留在原标法主题中。

按图片×绑定参考，将处理后上下点对数与当前参考点对数比较，分为少于、等于、多于；比较组及同数组均至少两名独立人员。同一图片不同参考不互相凑分母。先得到目标面板内人员均值差，再同图等权、建筑等权。没有按质量结果筛选图片；无p值或独立人员因果推断。参考点数相同不保证位置或结构正确。

- `detail_quality_panels.csv`：74个对照行（50少画、24多画，图片可能重叠），image_id/reference_id/condition隐含普通Manual；n_selected/n_equal为该面板组内人数，selected_workers/equal_workers保留W身份。`B8L2_delta`/`D10_delta`均为少画或多画组减点数相同组，单位分；不表示同一个人实际改点后的变化。
- `detail_quality_buildings.csv`：各方向每栋的图片等权均值差；图中每个点一栋，黑线是建筑等权平均，非置信区间。
- `FINDINGS.json`：分母与汇总；`*_record_occurrences`是组内记录出现数，不跨方向累加为独立记录数。每方向59人为两侧参与人员并集，不是59名少画者或多画者。
- `detail_quality.png`：新增对照结果。少画组3/50面板仍为正，多画组2/24为正，保留这些反例，不把平均规律变成资格规则。
- `condition_transfer.png`：复用两份现有数表重绘，左为同图固定人员的类别均值差，右为同房预测MAE；量纲和面板不同，不横向比柱高。

“多于参考”不是“真实细节更多”。该组可能包含参考遗漏、额外范围、共线分段或错误凹凸；本轮没有逐项语义裁决。人员能力和具体成员构成没有随机控制，评分又以该参考为目标，因而不能把相关差异称为“多画导致扣分”，也不能据此否定GT未表达的真实细节。少画与多画两项图片支持不同，不能以−23.54比−18.71更低就宣称多画比少画更差。
