## 数据入口与字段

`CONSUMER_INTERFACE.json`列各表、粒度、行数及来源；`FIELD_CONTRACT.json`列单位、类型和缺失语义；`CHECKS.json`保存实际分母。接口中的CSV和`tables.json`路径描述本地派生文件，外部直接读取同内容的`tables.json.gz`即可，不应误判为统计缺失。

`REQUIREMENTS.md`保留用户15类要求，`COVERAGE.json`逐项记录166项：110项computed、28项historical_only、12项source_missing、16项not_run。复合需求同时列出已完成子项和剩余子项，不能把有基础表等同于实验已经完成。

`REPRO_CONTEXT.json.gz`保存本次统计所需最小源列，原账户字段及本机绝对路径已使用证据包的公共清洗函数处理。它是可重放统计的源列快照，不替代正式v2输入真源，也不证明已重新采集或回放原始日志。`SOURCE_INPUTS.json`仍记录直接关系、历史对照及人员候选表等其它依赖；缺少被忽略的依赖时使用已有匿名统计结果，不能宣称全链独立复现。
