## 研究问题与最新决定

原邻接与连续局部路径，能否比单点／上下点对距离提供更好的身份对应依据，并帮助构造有观察支持的布局候选？必须允许结果否定这个方向。

用户最初希望汇集全体人员的角点／局部结构，按对应和支持融合；也希望比较一人画两对、另一人画三对的局部结构，并从丰富候选中有依据地删改。不是先选最大人员簇，也不是强制拟合矩形。

最新决定：**暂不强制最低8角点。** A线保留原始MV，包括不足4对的真实输出；B线独立研究结构约束候选。B线不冒充原始MV，不以补点、拆点、强制四对或GT选点制造成功。满足四对与几何规整均不是正确性证明。

## 任务

1. 先复算包内108个四路基线状态。明确结构信息分别用于对应、定位、连接还是候选选择，避免把这几层混成一个总分。无需重新审计全部历史项目。
2. 提出一个最小可运行的局部连续路径方案，真正比较两对／三对、不同分段和真实细节。说明端点锚定怎么来；允许跳过或保留哪些内部节点；内部细节的差异如何记账。若需扩展候选门限以恢复旧簇外对应，作为单独消融，不把它算作结构信息的收益。
3. 硬条件限于模型下确实必要的条件；原邻接相似、Manhattan方向、同高顶、较小残差通常只能作为有适用条件的证据。不要假设所有源环正确、相机处于所有声明范围内、所有顶部同目标，或强制全局单值表示。允许多个候选和未决；也要给出真正生成的局部／完整结果，不仅列限制条件。
4. 固定完整人员池、票权和候选中心估计，先比较距离基线、分段不变的路径证据、结构辅助对应；若改中心估计或连接，另列增量。不先挑最大整答簇，不把局部边票数相加成完整布局支持。记录旧组如何变化、被移走的其他成员、未达票观察、新跨接及其原路径来源。
5. 在9图面板报告全部结果。五张12°仍缺点图是定向选出的困难面板，不是随机全库样本；e9z/rpc/unb/2t7已有人审曝光；7y3s是普通副作用观察例，没有新人工gold。可以先深入2—3图，随后报告其他图的可运行结果及未执行项，不能只挑改进案例。
6. 做少量决定性控制：纯共线分段不应改变连续几何证据；真实短凸起不应被当冗余分段抹掉；不同上端目标不能因下端一致被平均；接缝两侧近点不自动同身份。含必要反例即可，不堆测试数量。
7. 评价至少分开：已审关系的漏配／混入、未审成员变化、细节保留／新添结构、范围变化、未决与覆盖、上下偏差及原邻接支持。不能只看角点数、几何残差或IoU。候选和政策先保存，再用evaluation中的固定参考作离线比较；这些图已有历史GT曝光，不宣称盲测。不要为个别图按GT挑阈值或权重。
8. 允许查阅相关研究，用原论文／官方实现说明借用了什么、哪些适用条件不同。文献服务于可实施方案，不以综述代替实验。对无法凭现有证据判断的身份关系，提供具体图片、记录、索引和对照，列成最小人工问题，不猜语义，也不要等全部标完才推进独立计算。

```python
import json
from pathlib import Path
from tools.thesis_main.analysis.point_route_panel_20261005 import build_routes
folder = Path('research/structure_constraints_20261006')
inputs = json.loads((folder/'inputs.json').read_text(encoding='utf-8'))
expected = json.loads((folder/'baselines.json').read_text(encoding='utf-8'))
actual = []
for image in inputs['images']:
    for threshold in [5, 9, 12]:
        for route, result in build_routes(image['records'], threshold).items():
            actual.append(dict(image=image['image'], threshold_deg=threshold,
                               route=route, result=result))
assert actual == expected['states']
print('108 baseline states reproduced')
```
