# 按转折事件与弧长定义锚点域：一次有限正向探索

## 结论先行

这次把原报告的一个“值得下一轮检验”建议变成了可复算实验：**外锚点按几何转折事件提出、按累计弧长限域，而不再按一/两条原边限域。** 原平方形反例逐字段重现：旧搜索 `not_witnessed`，新搜索在同一5°门、同一120°弧长上限下得到 `witnessed`。

在预先写入政策的1个合成窗口和7个报告指定真实焦点窗口中，2/4/8倍纯共线细分后的432项对照，候选端点、各侧路径通过状态和双侧见证组合都与未细分版本一致。14项测试通过；另一次独立执行的235个输出文件逐字节相同。

**这是搜索表示对纯分段变化的有限正向结果，不是身份正确率、全池融合成功或上下内部点对已解决。** 配对模式的rpc A↔C、B↔C在5°仍无双侧见证；不能说这次修好了rpc。

## 2. 新搜索域

对每个固定焦点和两个环方向：

1. 读取原顺序上的完整源路径，不改坐标、不跳过内部观察
2. 顶部模式只看顶部转折；底部只看底部转折；pair模式取原配对位置上两侧转折事件的并集
3. 提出弧长上限内的所有转折事件为外端点，不再限制源边条数
4. 任一被比较侧从焦点到端点的累计球面弧长超过120°即越出本域
5. 焦点门、外端点门、连续Fréchet门仍使用同一5/9/12°；近似步长仍为5/2/0.5°
6. 比较两种方向假设，要求焦点前后均有接受路径；两侧路径合起来覆盖完整源环的组合仍排除

焦点本身即使共线也保留。非转折位置仅不作为本政策的搜索端点，仍完整保留为原观察和路径内部点；这不删除该点，不证明它不是真实角点，不改变任何票。

此政策也不是旧域的保证超集：旧域内某个共线端点可能不再是候选。它解决的是一个明确定义的表示不变量，不是保证所有旧锚点假设保留或所有结果变好。

### 2.1 数值与退化处理

单侧相邻两条有向大圆弧的法向夹角用于数值转折判定。固定共线容差1e-7°；处在0.1至10倍容差附近时，整个对应搜索域保留为未决。小于等于1e-8°的零/近零边，以及距离对跖180°不足1e-7°的边，同样返回 `domain_unresolved`，不自动塌缩或猜测弧。

反向折返的法向夹角接近180°，必须是事件；不能与同向共线延续混淆。小而明确的真实凸起、仅顶部出现的转折，以及共线焦点均有独立测试。当前实现偏保守：整圈任一位置出现退化边或近容差转折，会让该记录的相应局部搜索域全部未决，即使问题位置在120°窗口外；本轮没有改成按窗口局部降级。

该容差是浮点表示规则，不是语义细节删除尺度。低于分辨能力的真转折不能获得“纯细分”认证；加噪插点也不在本次精确细分不变量内。

## 3. 为什么理想规则对纯细分不变

在固定焦点、固定方向、每条源弧唯一且插入点确实位于同一有序弧内部的条件下：

- 真转折的几何位置和环上顺序不变；新插入点的两侧切向相同，不增添转折事件
- 到每个转折事件的累计弧长不变，所以120°域内的端点集合不变
- 焦点、外端点的距离不变，完整环排除条件也不变
- 给定相同几何路径，理想连续Fréchet距离不受细分影响

因此理想候选集及其见证关系保持不变。**程序不是区间算术形式证明。** 源路径仍完整传给原数值核，细分可改变数值近似网格；理论条件与浮点边界未决必须区分。本次432项是有限实现检查，不把它升级为普遍数值保证。

## 4. 实算结果

### 4.1 原反例

`results/original_counterexample_reproduced.json`保留了原记录、旧结果、新结果和新路径账本。

- 原发布的旧搜索结果逐字段完全重现
- 未细分平方形与每边插入三个纯共线点的平方形，旧一/两边搜索无见证
- 新域在同一5°门内恢复见证；稠密一侧需要走4条源边才能到原外锚点
- 新域不是把跳数改成4，而是移除跳数上限，以相同转折位置和相同弧长定义域。8倍细分时同一几何路径走8条源边，仍对应相同候选

### 4.2 432项细分对照

每个比较都把新端点映射回未细分源位置，再比较候选域、全部尝试路径的状态及双侧见证组合，不只比较最终yes/no。

- 432/432签名相同，360项维持有见证，72项维持无见证
- 本矩阵没有数值未决的事件域
- 插入点的逐边球面弧长可加性最大误差约2.14e-14°
- 所有原观察坐标在副本中逐数值保留；磁盘源文件哈希前后一致

作为对照，相同432项中旧固定跳数的最终状态有95项从有见证变成无见证，26项反向从无见证变成有见证。纯加点既可能把旧外锚点推远，也可能创造新的近邻端点假设；这不是单向漏检问题。上述计数不是独立样本发生率。

### 4.3 真实窗口有什么新结果

在63个真实基准设置中：原本有见证的38个仍有；原本无见证的25个中，13个变为有，12个仍无。这只是同门、同焦点搜索可达性变化。

## 5. 未解决什么

1. **上下内部关系**：转折并集只让任一侧的重要路径位置进入候选。上下连续距离仍分开求；不推出一个共同内部重参数化，不创建新的上下点对身份
2. **真实锚点身份**：几何近、路径通过仍可能发生于不同角点或相似重复结构。原报告接缝反例仍有效
3. **长直弧**：如果120°内没有转折，域可能无端点；这仍是未知，不是结构不同。暂未追加等弧长采样作为补救
4. **细噪与退化**：纯细分和带噪密采样不同。短边法向不稳定、真小转折与舍入误差难分、对跖弧不唯一，都不能作普遍鲁棒性承诺
5. **身份聚类与票数**：没有据此重聚类、删除成员、补足四点、改变全池ceil(N/2)、移动中心或生成新共识环
6. **中心后失配**：本轮没有移动中心，因此原报告的中心化后路径漂移问题没有消失，也没有被本实验重新“修好”
7. **语义**：unb顶端目标及未审内部结构仍未知；未从底部见证复制顶部票数
