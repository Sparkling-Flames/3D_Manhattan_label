### 2. 有明确的“更稳定却更远”例子

e9z-19在8→16人时，12对独立团队的平均底面差异（1−IoU）从**0.175357降至0.072563**，两个人数下均12/12对可评价。与此同时，对修订参考的平均D从**0.219675升至0.246548**；对原GT也从**0.549741升至0.565108**。这是平均意义的结果，不表示每条路径都变差（修订参考下12条改善、12条变差，幅度不同）。

rPc-06的同人数团队差异则从0.114543升至0.148865；yq-32从0.051745升至0.054460，后者8人时只有11/12对可评价。这些有限抽样尚不足以断言总体非单调，但已不支持把增人必然更稳定写成规则。全员唯一组合的差为零只由抽样设计决定。

### 3. 本轮只有Uw出现不足4对，但连接与几何问题不止这一张

- Uw在k=3…23的504个路径状态中有226个不足4对，24条路径均至少出现一次。8人时0/24不足4对、但只有17/24形成≥4节点可评价底面；16人时12/24不足4对、可评价11/24；全员固定为3节点。8→16同时有效的只有8条路径，不能把上表中的条件均值下降解释为整体过程成功。
- 其余11图在本次k≥3抽样中均没有不足4对。**这没有证明其他图片不会出现**，只说明本有限面板没有观察到。
- 除k=2政策暂缓，内部人数过程无来源完整环的状态分别为Uw 25、q9-32 4、rPc-06 4、yq-25 4、yq-32 7；各图分母见[findings.json](findings.json)。不能把这些都归为节点不足。
- uNb-36的k=3…5共72个状态中，有28个常规几何检查报`wrong_hemisphere`，底面仍可算；节点始终4个。故底面可评价不等于完整上下几何可用。当前新输入的全员自动几何可算，也不能由此推翻原有人审对不同停止点的判断。

### 4. 哪些变化已能解释，哪些还不能

排除从1、2人出发的政策特殊步，5,592次加人变化中，**349次改变了旧观察的同组关系**。这是实际的对应重分，不表示349次语义错误。

另有**387个节点退出**发生在旧观察分组未变的身份上，全部位于偶数→奇数的门槛提高步；这些退出可以用存在票说明。它们与“发生过对应重分”的步骤可能重叠，不能将两个数字相加当成互斥原因比例。

具体例子见[Uw固定路径0](uw_path0_example.json)：12→13人，旧观察对应不变，两个6票节点因门槛从6升7退出，节点5→3。8人时有6节点却无覆盖全部节点的来源环；9人时剩5节点并恢复来源环。这些变化不需要假设人员随人数改变了自己的标法，也不证明算法对应已正确。

误合／拆散的语义真假、上端目标差异和细节是否恢复仍不能由这些统计裁决；本轮不扩大人工审核。已知yq-25自动终点5节点、同输入人工辅助终点6节点，继续分别保留。uNb-36输入已更新，旧6节点人工终点不可直接作为本轮自动轨迹的终点或优劣对照。

## 面板与设计

采用已有共同24人×10图，避免按本轮结果挑图。另列yq-25（23人，遮挡同角）和uNb-36（6人，前后停止点／几何）两个既有诊断例，不混入十图汇总。共12图、269份不同人图作答；不是269名不同人员。

每图24次独立随机无放回排列，记录每一步k=1…N。共同十图采用相同人员排列。参数固定7.5、MV50、全来源中位数、既有来源环政策。每个子集重新计算对应，不输入未来人员、人审分区或全员顺序。同一成员集合只计算一次，复用不改变抽样权重。

同人数换组比较采用相邻两条独立路径配成12对，允许人员重叠。全员只有一个集合，所以终点差必为零；它不是人员一致、正确或最优人数的证明。24条路径只支持有限池描述，尚不足以精确估计小概率异常。

输入来自当前`load_current_bundle()`，按原资格与预处理入口投影，冻结在`input_snapshot.json`。共同十图及yq-25与10月8日输入一致；uNb-36的R01570、R02473已被授权更新。本轮使用新输入，旧人工辅助终点不与它连接成同一轨迹。

粗难度只复制10月11日`scope_preferred_difficulty_20261011_v2`：共同十图当前6简单／1中等／3困难，旧5／2／3不覆盖新版。它是所选范围条件下的判读，部分由Codex按准则审查，不称独立盲标。该小面板没有覆盖OOS或已标门洞特殊层，不能外推那些情形；中等仅1图，也不能据此比较稳定组效应。

## 量的含义

1. **完整性**：节点数、不足4对、无来源完整环、位置未定、几何状态分别保存。k=2按现行政策暂停排序，不算成算法不收敛。
2. **同人数成员敏感性**：两组底面`1−IoU`及原始对称差面积；主汇总仅比较双方≥4对且底面可算的配对，并给出实际分母。这个归一化不是旧Lee表中以全员并集为分母的V，数值不能直接横比。
3. **增人时分组与投票变化**：比较前后共同观察的同组关系；只有旧观察组没有重分时，才将节点入／退出明确计作存在票变化。该统计是算法过程分解，不裁决实体真假，也不是人员／图片噪声因果分解。
4. **参考范围诊断**：原GT、人工修订GT分别保留；另列与粗难度绑定的所选底面。记录IoU、遗漏/参考面积、外扩/参考面积及D=二者之和。不合成Q；所选范围没有可信顶面时不嫁接顶面。
5. **实际分母**：逐次表保留不完整但可算的诊断分值；主参考曲线限制为≥4对且有效底面，必须与完整率一起读。不可算为NA，不置零、不删除路径。人审终点与自动终点分别输出。

这些量不测原作答两两一致性R，也不把输出稳定性当成人员原作答更一致。原始面积单位h²采用共同相机高度单位，不是实测平方米。k=1同样是24次随机路径的首人样本均值，不是枚举全体人员的精确均值。
