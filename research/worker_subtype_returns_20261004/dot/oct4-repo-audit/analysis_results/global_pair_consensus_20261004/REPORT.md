# 全员点对融合：137图基础对照与Pro返回审查

日期：2026-10-04。本轮目标是**同一张图的全部当前人员形成一个图级共识**。整份作答分簇仅解释不同标法；点身份分组用于寻找对应，两者不是同一件事。

已实现一个跨不同点数的全员点融合探索基线，并接入[全景／3D工作台](../consensus_result_studio_20261004/index.html)。它能产生包含 top_y、bottom_y 和连接的单份候选，也会明确失败。**尚未确定最佳完整layout算法：默认点方法的失败和底面误差都不能忽略。** Lee仍是已有BEV人数研究的区域基线，ERP轮廓与点方法继续并行。

## 1. 输入与计算范围

沿用[既有固定输入](../lee_expanded_20261003/source_input.json)，选取 `independent && consensus_eligible && condition == manual && main_consensus_gate.status == main_candidate`。这与原扩图研究完全相同，未根据本轮结果筛人。136张旧Lee可计算图的人员ID逐图与 `rosters.json` 核对；旧Lee整池失败图 `rPc6DW4iMge-22` 的24份也保留，共**137图、1,520份独立标注**。重复坐标仍按独立人员计票。

本轮每图均使用完整既有人池；2.5°、5°、10°三个预先声明的探索阈值，各计算≥50%和>50%，共822种设置。不是新增人数曲线、随机抽样或稳定速度实验。原136图1—N曲线与质量资格不改写。GT只在输出生成后评价；不参与点对应、投票、中心或环序选择。

## 2. 三条方法各自输出什么

|方法|本轮作用和输出|未解决的部分|
|---|---|---|
|Lee tile等权BEV投票|复用原全员区域结果；可回投全景底边，保留全部分量和孔洞|没有融合top_y，不能称完整layout|
|直接ERP墙带区域投票|全员上、下稠密轮廓；137图中113图适用，24图整池不适用|需满足单列共享地平线墙带条件；512采样列是显示近似，尚未恢复稀疏真实墙角|
|新全员点对基线|全部上下点对共同建立身份分区，以人员为票，选多数点对，求中心并生成一个未确认的新环|阈值未校准；对应可能有歧义；多数点不保证多数边或物理正确；默认x新环待研究|

点方法的具体规则：两点对距离取上、下端点球面角的最大值；以完整链接形成身份分区，同一人的两个点对不能进入同一身份。一个身份至多获得该人员一票。保留达到全员门槛的身份，用周期共享x中位数及分开的上下y中位数形成中心。默认5°仍是探索值，不是已经验证的分类标准。

**新融合环按中心x排序**，与用户指定的来源默认排序相容，但不继承来源人工确认，也不修改任何来源环。另统计原始直接邻接、删去未选点后的路径支持、来源环冲突及整环结构支持。直接边和经过删点得到的路径不能混算。确定性分区不等于唯一真实对应；加入新人员仍可能重组身份。

不足3个多数点对、周期中心或同x排序歧义、不可用几何会保留明确失败。可显示但有对应竞争、连接票不足等情况记为 `geometry_review`。`ok` 仅表示当前计算检查通过，不表示视觉正确、全局对应唯一或真实闭合三维体已验证。

每行尝试分母始终为137。差值仅在相同图、相同人员池、相同投票规则、原参考和两方法均可计算的**完整候选**上配对，是条件性描述，不是计入失败惩罚的总体优劣。不同阈值的可配对图片不同，不能据此把10°选为最佳阈值，也不能用底面指标证明完整layout质量优劣。

默认5°、≥50%有119个完整候选，18个不可用中17个是多数点不足，1个是顶部几何不适用。后者 `uNb9QFRL6hY-36` 的底面仍可算IoU，因此保存了120份底面分数，**不能把120写成完整输出成功数**。严格多数有113个完整候选，24个不可用中23个为多数点不足，1个为底面几何不适用。

5°下，≥50%有40个输出至少一条边没有任何原始直接邻接支持，63个有边未达同一多数门槛；严格多数分别为39、63。零直接边可能仍有删点后的路径支持，不能描述为完全没有来源证据。默认≥50%有27图出现某个端点对在另一人员处有多个阈值内可对应点。以上诊断揭示后续连接和对应研究的具体对象，不因能绘制3D就忽略它们。

本轮支持的结论是：**点融合已经可实测，但“按阈值匹配点＋多数保留＋默认x连线”仍有明显局限。** Lee底面结果暂时更稳健；它缺少顶部的问题依旧存在，不能因此停止点和ERP研究。

## 5. Pro返回：吸收成立的发现，不照单全收

[独立审查与精简归档](../../research/full_layout_pro_review_20261004/REVIEW.md)保留原报告、源码、关键输入和复算证据。主要判断：

- 两两匹配各自唯一并不保证多人共同对应一致；多数直接边也不保证自然形成合法单环。这些反例独立复现，适合作为算法诊断。
- 局部多数可能生成从未有人完整画过的结构。这不自动构成错误：融合允许产生新组合；整环见证数应报告，但不应要求输出必须复制某个人。
- Pro的真实面板只有一图三人，三份作答及GT摘录与本地逐值一致。它的结论不是137图验证，也没有视觉GT裁决。
- Pro原型实际生成候选时采用最小误差和对应，认证却检查最小最大误差对应；本地构造了有效的两人三点反例，证实认证与实际融合对象可不同。原包25项测试没有覆盖该问题。因此其“单候选认证”不能直接接入。
- 新全员点方法已经给所有观测建立共同身份，不会同时把互相冲突的两两最优对应当作定义。但完整链接仍只是一个分区政策，不能藉此宣称语义唯一。

## 7. 随后的研究顺序

先围绕已定位的真实例检查对应歧义、少数角点丢失和连接票不足；将用户对工作台的视觉判断记为独立审核，不用GT自动选环。针对性比较默认x环与有来源依据的连接规则，保留失败及人工介入标记。上轮历史改序案例还需逐点迁移，不能把本轮来源索引验证称为完成该工作。

随后在相同人员集合上补人数与成员变化，分别研究参考接近和自身稳定；点身份在每个当前子集重建，不借全员未来成员决定早期点。阈值敏感性和缺失输出同时报告。人员子类Q/T/S/B、连续画像及真实组合继续保留，尚未因Pro反例被否定；完整人数×构成与Lee稳定性仍是后续任务。
