# 人员分型最新报告：独立统计解释与嵌套收益集中度审查

审查对象：`worker_subtype_research_20261004`。本审查只读取所给冻结材料，在独立目录运行小型数值诊断；没有改原图、GT、人员资格、远程仓库或源研究包。

## 结论先行

**这版研究值得继续。真正站得住的增量是把“分组名单→真实成员集合→共识输出”连起来计算，并明确区分参考一致性、原始离散度和融合稳定性。新增嵌套预测也比直接挑最好的外层模型严谨。但其约11%的总误差收益，不能代表多数人员已经有可迁移、有效的画像。**

本次针对新增嵌套结果的独立诊断发现：

- 原参考/修订参考政策下，P017单人分别占全部**有符号净SSE收益**的114.58%/87.55%。大于100%是因为其他人员的负收益相抵，并不是因果贡献率
- 24人中，按每人10图总SSE衡量，只有7人/9人优于“不区分人员”的零相对分数预测
- 保留原模型和24人居中目标，仅把评价拆到P002/P017以外的22人，改善率为−2.99%/+0.27%；这不是删人重训，不能据此剔除谁或改资格
- 改成建筑等权，完整24人的总体改善仍有13.21%/12.37%。因此不能把总收益简单归咎于表格权重；主要需要收窄的是它覆盖哪些人、哪些建筑

我的研究判断是：**现有结果更支持少量高信号尾部人员的条件性可识别性，加上多数人员仍需收缩、不确定标签或连续描述；尚不支持把所有人都强行固化成永久类型。** 这并不要求类别天然、人数均等，也不取消小类和未知层的研究价值。

## 1. 针对检验：范围、方法和停止条件

选择的问题只有一个：新增嵌套总收益是否广泛分布于人员，且是否依赖图/建筑权重？不另开模型搜索，不重复35项测试或大规模几何复跑。

从两种政策共480个已冻结外层预测格，独立重新计算：

- 目标 `r_iw = y_iw − mean_w(y_iw)`，每图保留全部24人
- 基线平方误差 `e0_iw = r_iw²`
- 模型平方误差 `e1_iw = (r_iw − prediction_iw)²`
- 有符号收益 `g_iw = e0_iw − e1_iw`

然后按人、建筑以及人×建筑分别求和。总体相对改善是 `sum(g)/sum(e0)`；建筑等权版本先把各建筑的每张图权重除以该建筑图数，再取对应比值。每个评分分区都沿用原预测和原24人目标中心，绝无再拟合、再居中。

核验完成即停止：480格唯一且完整；独立居中目标与保存目标最大差9.89×10⁻¹⁷；各外层基线SSE最大差2.78×10⁻¹⁶，模型SSE最大差2.22×10⁻¹⁶；两种总体汇总均复现到浮点容差。所有检查通过。

## 2. 数学正确性、目标有效性、泛化边界分开判

### 2.1 嵌套LOBO：隔离正确，但三个权重并不相同

代码外层整栋隔离、内层只使用其余建筑选择方法；未发现用目标图IoU选择人员、类数或方法的路径。`no_worker`确实在候选菜单中，预测恒为0，是一个明确的不分型相对分数基线。

三层统计对象需写清：

1. 画像拟合：训练图片等权平均。拥有两张图片的建筑在人员画像中影响更大
2. 内层选择：每栋建筑的MSE等权
3. 正文主结果：汇总外层SSE，各人×图等权；结果文件另提供建筑等权比值

这不是算术错误，原报告也披露了这些做法。但如果下一阶段目标是“平均新建筑”，应先决定是否连训练画像也采用建筑等权，而非只改最后表格。不能事后在两种权重中挑更好者。

此外，“建筑等权MSE的相对下降”也不是“每栋相对百分比下降的平均”。比值聚合仍受各建筑基线残差能量影响。这里低人员差异的图绝对误差变化较小，但模型相对零基线可能差很多；只报一个百分比会掩盖此结构。保持总误差、逐楼方向及人员集中度并列即可，不需要额外挑一个极端归一化指标制造结论反转。

### 2.2 居中：不是直接训练泄漏，也不是可部署绝对质量预测

目标图24人均值用于定义离线相对目标，并未进入训练预测器，所以把这一步一概叫“目标泄漏”不准确。相对分数的含义是“该人比这张图的这24人平均高/低多少”。

它回答的是同一批已知人员的参考相对表现迁移。在实际尚未收齐目标图作答、尚无参考时，这个目标中心本身不可观察；因此不能把结果当作提前输出绝对IoU的能力，也不能把10.7%误差减少变成共识IoU提高10.7个百分点。工人群体换了，居中参照也会换。要面向新人员，另需特征或独立校准；现有ID画像没有给出该能力。

当前loss也更重视大幅相对偏差。因此发现少量尾部人员能够带来整体下降是实质信号，却不足以证明多数人的精细排序、类别或专长可用。本次影响分解正是对这条新嵌套结论的具体收窄。

### 2.3 小类Ward：应保留，却别把粗量化误认成独立类型

Ward在这里处理一维校准Q，输出同簇均值，本质上是对连续画像做数据驱动的阶梯近似。固定二分得到2人高组是合法结果，不需要补到12人。修订政策八折都是P002/P017也是真实重放现象。

但是这八个训练集高度重叠；完全不重叠4+4校准的较高组Jaccard中位数1/3已由原报告给出。该小类是否值得使用，取决于其未来任务用途，不必先证明“天然类别”。当前可保留为带来源和支持量的条件性小类；最多只能做这两名不同真人实际支持的1→2人数过程，不能复制人或扩大定义来填曲线。

更重要的是，小类稳定与预测增益不是同一结果。P002在原政策的净预测收益约−0.00027，P017贡献却超过整体净收益，提示“同属高Q小类”并不意味着两个人的迁移误差结构相同。

## 3. 六人构成解释方差：公式正确，份额依赖实验设计

`Var(Y)=Var_c(E[Y|c])+E_c(Var[Y|c])`在已枚举134,596个六人集合且按其自然频率加权时是严格恒等式。代码采用总体方差 `ddof=0`，与有限均匀分布吻合；不是把大量重叠集合当独立样本做显著性检验。

需要保留的依赖包括：目标图、固定24人池、参考版本、投票规则、k=6、分型方法、校准名单，以及六人集合的抽样分布。尤其是：

- 中位数12+12下，全高/全低各只有924个集合，各占全部六人集合的0.6865%；3高3低有48,400个，占35.96%
- 所以“全高均值比全低好”与“构成只解释很小总方差”完全可以同时成立。两端差异不是普通随机六人队最常遇到的变化
- Ward二分的小类改成2人或3人后，构成的取值范围、事件频率与人员身份含义均改变。33.60%不能直接与中位数的6.50%比较后宣布Ward获得更普遍的因果解释力
- 如果用户要固定比例配人，所需评价应条件于该比例，再看真实成员间的分散；如果用户要随机抽六人，才应沿用全池自然频率。两个问题都合理，不能混为同一个“构成贡献率”

因此，原报告把这些份额称为固定池描述而非因果贡献率或泛化R²是正确的。最值得继续的是同时呈现构成均值曲线与构成内分布，而不是追求单个更大的解释份额。

## 4. 名单传播约11%：精确的是指定两层随机过程

令L为从目标之外7栋中均匀抽4栋的校准集合，`q_L(t)`为在由L确定的高Q名单中随机取六人后，tile t进入融合的概率；U是固定全池并集面积。两次独立重跑整个过程的平均形状差为：

`D_total = 2∫ bar(q)(1−bar(q)) / U`

先固定同一名单、独立抽两组人员的平均形状差为：

`D_within = E_L[2∫ q_L(1−q_L) / U]`

两者之差为：

`D_between = 2∫ Var_L(q_L) / U`

所以 `D_total=D_within+D_between`，不需要假定不同tile相互独立，也不需要假定真实工人的行为独立同分布。代码的逐tile积分与恒等式相符。

原参考MV50下，7y3s/rPc的名单间项占总量11.10%/9.99%；修订政策为11.56%/12.61%。应明确它是：

- 两个独立“校准→名单→六人抽组”流水过程，相对两个共享同一名单的抽组过程增加的期望形状差
- 以35个校准建筑组合等权，而非不同人员名单等权；同一名单出现多次会得到更大质量
- 固定4栋、固定中位数二分、固定k=6、固定几何/参考政策下的描述，不包含T/S/B缺失、候选方法选择或未来人员总体的不确定性

它不是“换一次名单必然造成11%面积变化”，不是名单不确定性的置信区间，也不是总变化中可唯一归因于某因子的因果比例。该分解反而给出很有价值的中间认识：名单ARI不高时，共识分布也可能变化有限，必须计算输出而不是仅凭名单指标否定分型。

## 5. 我的研究建议及明确取舍

**继续当前路线，但把主张从“已有效刻画所有人员”改为“条件性分层能保留部分跨图信号，且能精确传播到固定池共识过程”。**

1. **保留Q/T/S/B与连续画像并行。** 不把一维Q拆成所有人员的终身标签。T/S/B按原意绑定有效时间、scope判断、真实初始化与编辑记录后分别验证；未知保留未知，Manual不当B=0，特殊图分层保留
2. **下一轮方法比较应加入收缩连续画像，但本轮不追加新模型。** 当前菜单有裸连续均值、Ward阶梯与零基线，缺少介于裸画像和零之间的连续收缩。这使Ward可能兼有压低噪声的作用。只有预先固定的收缩连续对照仍输于子类，才能更清楚说离散分层本身提供了额外用途。不能用目标图回调收缩强度
3. **保留小类和“不确定/未分型”层，不强迫人人获得有意义标签。** 本次多数人净预测不改善，是给这些表达留位置的具体理由，不是删除人员的理由
4. **把真实组合和名单传播作为主交付。** 它们直接回答用户关心的具体成员、配比、人数过程及稳定性，不要求先发现自然类别。扩到固定面板时同时保留失败覆盖和参考适用边界，原图/GT问题不以更精确的统计替代
5. **更新报告的最小动作。** 在约11%的嵌套总收益后加一句人员收益集中度；并列建筑等权结果；在全24逐人表保留改善/变差方向。其余数学核心无需因为本次发现而推倒重做

没有新增自然类别验收要求，没有把历史24×10高低LOBO脆弱性包装为新发现；也没有宣称可用当前两个BEV案例推断全场景或完整3D布局质量。
