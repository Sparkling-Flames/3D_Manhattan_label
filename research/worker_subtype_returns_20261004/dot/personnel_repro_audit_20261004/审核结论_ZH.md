# 人员子类最新包：云端独立数值审核

## 结论

作者包的数值链可复现，目前没有未解释的作者数值错误。35项测试全部通过；11个数值阶段一次连续跑完；41个运行产物精确匹配（37个文件逐字节相同、4个NPZ全部数组逐元素相同）。同时保留一例独立几何核验器的GEOS数值路径失败，不能把它误记为作者公式错误。

本审核只支持包内有限人员池、既定参考、BEV地面多边形的计算正确性。不是新人员泛化、视觉GT裁决、四轴Q/T/S/B有效性或44张高人数图全量几何验证。

## 唯一几何核验异常及定位

为了绕开全池tile，在每图每规则抽取19组，直接对全部三人或四人交集求并。rPc第一组六人P001–P006（R01784、R00020、R02452、R01886、R02165、R02468），阈值3、参考R02670，在Shapely2.1.2/GEOS3.13.1的一条unary_union运算路径下漏掉面积0.002619939822869757，使IoU从tile的0.5018406295769197变成0.501497083352437。

定位证据：

1. 六原多边形均valid，无计算警告；漏区代表点距最近原边界约0.00735，covers与contains一致，70位Decimal射线计票恰为3
2. 某输入三人交集包含代表点，unary_union结果却不包含；不是票阈值或参考变化
3. 只用该六人重新分tile与全24人tile的输出对称差面积为0
4. 改变交集顺序的三条路径、逐个binary union的正反两条路径均与作者输出同区
5. 旧Shapely2.0.4/GEOS3.11.3仅重跑此fixture，所有顺序正常，与作者输出同区
6. 1e-12至1e-8 precision grid只是额外诊断，也趋近作者值；未对原始数据或生产算法应用修复

判定：独立核验器暴露了GEOS特定overlay路径风险，不是已观察到的作者finite_pool错误。保留JSON、GeoJSON、原始FAIL机器结果和双版本证据。没有扩大到全库GEOS保证。
