# 十图固定人员子类补充核查

日期：2026-10-03 UTC。独立核查，探索性有限池描述。

## 结论

人员新报告的两个案例确实证明“高Q不必更一致／稳定”，但它们不能代表十图面板的多数方向。补齐同一冻结24人×10图后：

- 原始作答平均两两1−IoU：高Q组更分散3/10图，更一致7/10图
- 独立同k重抽融合对称差：MV50、严格多数，在k=4和k=6下，四个设置均为高Q更不稳定5/10、较稳定5/10；具体是哪5张随k和规则变化
- 强制两组成员完全不重叠时，MV50 k=6为高Q更不稳定6/10，其余三个设置仍为5/10
- 因此，不能反向提出“低Q普遍更稳”，也不能用原始作答一致性代替融合稳定性

## 固定设计和来源

输入为已冻结共同面板 inputs，Git blob：5a174746730bb70e405680a3748663caf56dd51f；与本轮新包所声明的源blob相同。保留原始footprint和原环，不修复、不补点、不按坐标去重。名单严格为新包原Q政策、整栋留出校准、中位数二分的12/12人名单；已从完整原Q矩阵独立重算，并逐人核对新包标签。10图各有26条保存记录，合计20条历史额外记录（每图P013/P016）保持排除，使用240份正式作答。

这是既有十图共同块的针对性补算，不是新增人员、全44张Manual或17张Semi验证，不包含T/S/B、参考真值裁决、新模型、全布局、IoU最优选人或六人参考IoU完整枚举。k=4已有历史十图面积研究，此处作为复核锚点，不能把全部k=4结果称为首次发现。

按12人固定类不放回取k=4/6，以超几何分布精确计算每块tile的入选概率q；独立重抽的期望对称差为面积加权2q(1−q)。组间可重叠。另行计算完全不重叠二组的联合超几何概率。分母始终为同图全24人原多边形并集面积U。参考不参与几何稳定性计算。
