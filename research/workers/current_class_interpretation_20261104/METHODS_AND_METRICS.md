# 本轮原答画像与既有团队证据的统计口径

版本：`current_class_interpretation_20261104`。来源冻结于 GitHub `Sparkling-Flames/3D_Manhattan_label`，commit `48a2fc6aedd51cd701b1bce06c02bd3ef92ec75b`（2026-11-04）。本轮任务是补齐当前类别的行为解释，计算现有数据缺少的同图画像与共同支持汇总。

## 1. 预处理、参考与分类的接续

1. 原始采集与既有预处理后的有效作答，沿用 `v2.1/analysis_input` 当前数据束。其 manifest 明确原始标注库存复用 v2，而参考、质量和当前难度通过 v2.1 的评分上下文获取。不能因数据束复用 v2 就退回 v2 的参考或标签。
2. 原答以 `object_id` 固定身份。使用已整理的 1024×512 ERP 上下交替点对，不重新按 x 排序，也不改变清洗、顺序修正或绑定决定。示例从这套有效坐标绘制；原图 2048×1024 只用于显示，缩放不改变研究坐标。
3. 原答特征来自难度接续后的 `RAW_TARGET_RESPONSE_RECORDS.csv.gz`；普通 Manual 与普通 Semi、主目标与其他合法目标分开。特殊范围与门洞不因当前画像被新增纳入。
4. 正式 Q 及五项分量按 `object_id + reference_id + reference_version` 连接。主目标使用 `quality_records.csv`，其他合法目标使用 `image_difficulty_20261030/ANALYSIS_RECORDS.json`，后者不从主参考表借用分量。
5. 既有当前分类读取冻结标签，不拟合新分类。DSTRUCT 与 RFUSE 读取 2026-10-30 的接续版本；OPPJOINT 使用其实际未变化的 2026-10-29 标签，相关历史域逐值一致性已核验。
6. 本轮楼外原答的类别使用 `worker_id + building → heldout_building`。`ALL` 只用于完整名单和训练画像说明，不替代每个目标楼的留出标签。
7. 既有团队结果按实际标签版本、Manual/Semi、目标范围、人数、替换人数、共同支持和辅助连接身份接续。历史设计不自动更名成当前 DSTRUCT。人工连接的新增可评事件与原共同支持继续按已交付验收规则区分。

57 组人工排序属于定向融合辅助病例，改动发生在团队融合连接层。当前个人原答、Q、记录劳动以及本轮使用的人员历史输入没有因此被重新定义。F2/F9 的坐标候选仍是独立案例，不进入当前画像输入。

## 2. 三种分类分别回答什么

| 系统 | 当前角色 | 直接建类输入 | Q/T 关系 | C 编号含义 |
|---|---|---|---|---|
| TARGET_DSTRUCT K3；K2 粗分 | 前向人员行为分类 | 原答结构水平、困难及困难减简单响应 | 不直接输入 Q/T；参考未匹配特征使用参考几何 | 各训练折困难结构中心由低到高 |
| RFUSE_GEOM K2 | 反向解释融合响应 | 实际自然团队的结构和边界/尺度响应系数 | GEOM 不直接输入 Q/T；训练完整输出门槛间接涉及 Q 可用性 | 各训练折困难融合转折响应中心由低到高 |
| OPPJOINT K3/K4 | 结构、位置、Q/T 的联合画像 | 几何机会响应、原答质量与同源 logT 历史 | Q/T 是分类依据的一部分 | 各训练折训练 Q 残差中心顺序；不是永久固定角色名 |

三者作用互补。本轮保持当前方法及角色，不把全部候选重新排序，也不根据新画像选择新的 K。训练特征中的差异用来解释类别含义；楼外新观察说明这些含义如何在实际原答和团队中表现。JOINT 的历史 Q/T 差异不能当作独立的新发现，楼外同图、同源表现才是本轮补充的关键。

## 3. 单位与权重

设同一图片 i、合法参考 r 中，类别 c 的有效人员为 W。对每一指标分别计算图内目标的类别均值：

\[
\bar{x}_{irc}=\frac{1}{|W_{irc}|}\sum_{w\in W_{irc}}x_{irw}.
\]

比较 a、b 两类时，只使用两类都有该指标有效值的同一目标：

\[
\Delta_i^{b-a}=\frac{1}{|R_i^{ab}|}\sum_{r\in R_i^{ab}}
       (\bar{x}_{irb}-\bar{x}_{ira}).
\]

主结果对图片等权。另输出先楼内图片等权、再建筑等权的结果。其他合法目标在图内先等权，避免同一图片因目标多而获得更多总权重。当前普通原答库存中，同一 worker×pool 没有重复对象；仍保持对象、人员目标、图片、建筑层级的明确定义。

全类共同支持表要求同一目标中所有类别都有有效值。两类比较表可以使用更大的两类共同支持，因此三类水平表的 201 图与 C3−C2 的 205 图并不矛盾。每项指标保留自己的图数、建筑数和实际人员数。

同时保留每张图内各类个人值的分位数、所有逐对象数据，以及图间类差的分位区间和正负方向数量。类别均值不替代类内分布。DSTRUCT 表中的“图内分位数的图均值”与 RFUSE/JOINT 另外提供的层级加权个人总体分位数，名称与定义分别保留，不混成同一个分布指标。

## 4. Q 与分项

正式 Q 为冻结 `WQ-B8L2-20261015`，范围 0–100。五个完整分项为：

| 字段 | 意义与单位 | 趋势 |
|---|---|---|
| `iou_2d` | 底面 IoU，0–1 | 越大越好 |
| `S_bottom_deg` | 底边位置误差，度 | 越小越好 |
| `dir` | 内在方向误差，度 | 越小越好 |
| `Hmean` | 全局高度相对误差 | 越小越好 |
| `Hcenter` | 局部高度相对误差 | 越小越好 |

对 I>0，冻结代码等价于：

\[
Q=\frac{100}{1+\sqrt{(I^{-1}-1+S_b^2/32)^2+
 [1.5D^2/(D^2+8^2)]^2}+(H_m/0.8)^2+(H_c/0.25)^2}.
\]

完整 I=0 输入的连续极限为 0；缺分项、缺参考或不可评结果不是 0。D10 只把方向尺度 8° 改为 10°，保留为既有敏感性指标。`IoU3D100` 是独立的三维 IoU 诊断，不能替代 Q。

本轮读取逐人已算好的 Q 后聚合，读取同一参考下的分项说明误差来源。因为 Q 非线性，不能先平均分项再代入公式当成平均 Q，也不能把分项变化解释成固定百分比贡献。

官方实现：`research/quality/quality_ab_feedback_handoff_20261015/prior_AB/src/working_models.py`；接续实现：`tools/thesis_main/analysis/quality_b8l2_d10_20261017.py` 与 `scope_quality_scoring_20261016.py`。

## 5. 原答结构与位置特征

| 字段 | 当前原答定义 |
|---|---|
| `turn_n` | 有效底面上转角严格大于 5° 的节点数 |
| `short_turn_edges` | 边长/周长小于 0.04，且两端转角均至少 15° 的边数 |
| `near_straight_nodes_5deg` | 转角不大于 5° 的节点数 |
| `unmatched_ref_9` | 原答与参考底点单位球面方向做一对一最小成本匹配，保留不超过 9° 的匹配后，参考未匹配比例 |
| `matched_pair_fraction` | 按水平角的一对一匹配并施加 9° 门槛后，匹配参考点对比例 |
| `matched_boundary_abs_deg` | 上述匹配中，上下边界绝对角偏差平均 |
| `matched_top/bottom/horizontal_bias_deg` | 对应匹配的有符号偏差；不能把均值接近零当作绝对误差小 |
| `omission` | 1 − 原答与参考底面交面积/参考面积 |
| `extension` | 原答超出参考的底面面积/原答面积 |
| `log_area_ratio` | log(原答底面面积/参考底面面积) |
| `log_height` | 相机高度标准化条件下，原答重建平均高度的 log；不是高度误差 |

球面底点匹配与水平角匹配是两种诊断。面积漏出与延伸描述几何差别，不自动等同于语义漏标或错误目标选择。原答短墙段定义也不等于 RFUSE 团队输出中的 `floor_short_edge_03_n`；不同层的字段保留原定义和来源。

实现见 `research/workers/personnel_v21_reselection_20261029/classification/code/build_target_aware_candidates.py`。本轮只复核展示对象的特征与有效坐标对应，不重新定义全库特征。

## 6. 时间与共同 Q/T

记录劳动 T 使用有限且为正的 `source_active_time_seconds`。没有合法时间的记录保留缺失，不以零替代。new 的 `user_processed_reported_not_raw_log_replayed` 与 v1 的 `inherited_v1_audited_source` 分开，时间不是本轮重新回放浏览器原始日志获得的“净专注时长”。

主时间比较在同图、同参考、同 origin、同 time_source 内计算。几何时间比为 `exp(mean(logT_B) − mean(logT_A))`；算术秒数和类内分位分布同时保留。几何时间比不等于总秒数比。

当一句话同时比较 Q 与 T 时，使用 `rfuse_joint/Q_T_COMMON_RECORDS_PAIR_SUMMARY.csv`：同一批正时间且 Q 可用的原答、同一目标与来源、同一类对。不能将全源 Q 均值和 new-only 时间比拼接成所谓共同效率结论。

其他合法目标的时间是其原任务记录，并非该空间独立耗时。团队记录劳动是既有各成员记录时间的相应汇总；人工排序或候选坐标修正没有完整计时，不能据本轮宣称已计算其净收益。

## 7. 难度、支持与现有团队实验

当前官方图片难度保持冻结。难度层先比较同图类差，进一步汇总同时有简单/困难图的同一建筑，避免只因两种难度来自不同建筑便解释成响应变化。这个描述仍是不同图片之间的观察比较，不是随机增加难度的实验。

原答主画像使用当前正式可评的普通原答；它不是所有采集对象的失败率估计。更大原答库存中因参考待修正、范围待核或质量用途限制而没有正式 Q 的对象，不被归因为某类人员能力失败。类别历史不足、几何不可评、参考限制和未做人工连接也分别保留其状态。

团队证据继续区分三种问题：严格 ABC 比较同类与跨类变化幅度；直接 AC 描述一次具体替换的方向；完整联盟描述实际组合的输出。配比方差使用固定图、固定目标、固定人数的既有团队面板。跨方法比较另外取相同团队覆盖的共同面板，保留各指标可评支持。

配比间方差份额是这些有限面板的描述性分解，不是预测准确率或因果解释率。K4 比 K3 更细也会改变分解份额，不能仅据份额大而重新选择分类。平均有符号变化接近零时，同时报告平均绝对变化与正负图数，观察是否存在方向抵消。

## 8. 本轮复现边界

本轮新增内容是已存在原答的画像、同源共同 Q/T、当前标签和容量说明、既有团队的共同支持汇总、原图展示及文档。没有开展新 Q/T 选队、扩大大池策略、增加新的同房团队或重新选择分类。

每个分析目录提供脚本、输入清单和输出检查；完整引用见顶层 `SOURCE_INDEX.csv`。数值沿用未四舍五入的 CSV，文档与图只在显示时四舍五入。
