# VFuaQ6m2Qom-04：接近满员仍存在多种输出，精确边际比追加顺序更有效

本例来自冻结普通 Manual 困难图，人员池 N=35，参考 `gt_original`。它按旧24路径的高波动进入本轮重点精度检查，不是按新增结果挑出有利方案。本例所有35个 N−1 团队均来自本轮预先登记的精确边际；案例程序只读取结果，新增融合0次。

## 精确35队的分布

34人团队恰好对应35种“缺席一人”，每队在自然均匀抽样下概率均为1/35。已有缓存复用21队，本轮补齐14个此前没有的34人端点；35人满员队直接复用旧结果。

|结果|团队数/35|Q范围/均值|缺席者|
|---|---:|---|---|
|4节点、右后位置得到保留|15|79.758—80.457|精确成员见逐队表|
|4节点、改为左后相邻点并改变连接|14|26.119—26.504|精确成员见逐队表|
|5节点|3|60.720—61.159|W114、W124、W131|
|3节点、不完整且不可评分|3|Q缺失|W104、W106、W134|

32个可评团队的精确条件均Q为54.679，线性P10为26.205，有限总体标准差为25.625；失败率为3/35=8.571%。满员35人的唯一团队只留下3个节点，Q保持缺失。

这张图在34人时的成员波动不是偶然遇到一个离群低分。两种四节点输出各占了相当份额，且对应很不一样的底面形状。单看“节点数均为4”会错过主要差别。

## 票数、对应与连接的实际机制

同为34人，冻结支持门槛均为17票。保存的完整状态提供了以下对照；表中的身份组编号只用于这三支精确队，不作为跨全库的语义编号。

|缺席者|右后位置组 `node_002`|左后相邻组 `node_015`|最终节点/Q|
|---|---|---|---|
|W103|17票、入选|16票、落选|4节点，79.845|
|W113|16票、落选|17票、入选|4节点，26.176|
|W134|16票、落选|16票、落选|3节点，失败|

右后组的底点横坐标约635像素，左后相邻组约396像素；两组确实来自不同空间位置。缺W103的输出近似保留房间主矩形，缺W113则漏去右后位置，冻结连接环变为 `node_000 → node_003 → node_001 → node_015`，出现跨过大块房间底面的斜连接。BEV同时显示固定参考、被移除成员原答与实际融合，读者可以直接看到这一差别。

两支四节点队的Q从79.845降至26.176，底面IoU从84.496降至47.994；边界/方向损失明显增加。平均高度只从1.7046变为1.6950个相机高度，说明主要变化来自保留了哪个位置以及怎样连接，高度改变很小。

缺W134还有一项具体的对应变化：共同保留成员W104的同一份原答，其第二个点对在缺W103、缺W113的队中属于 `node_015`，在缺W134的队中转入 `node_004`。因此不能仅按“从固定身份组中减去缺席者一票”推算全部响应。人员集合变化经过冻结对应算法后，会改变其它人的身份组归属，随后才进入门槛和连接。精确关联保存在 `VFUA_W104_ASSIGNMENT_CHANGE.csv`、全部对应表和代表完整state中。

35人门槛为18，实际满员输出只保留3节点。这与34人处多个组位于一票边界的现象一起，说明近满员结果可能有离散跳变。本包的35人队继承旧标量/几何，没有其完整身份组票账；因此没有把34人票账直接冒充35人的逐组票数。机制解释主要依据上述同为34人的实际状态对照。

## 24、48、96条路径对精确分布的估计

|样本|实际不同34人队|可评路径/全部路径|估计均Q|相对精确均值误差|均Q的MCSE|
|---|---:|---:|---:|---:|---:|
|原24|17|22/24|54.516|−0.163|5.345|
|新增独立24|15|21/24|58.548|+3.869|5.731|
|合并48|24|43/48|56.485|+1.806|3.878|
|合并96|32|88/96|53.167|−1.512|2.709|
|精确35队|35|32/35|54.679|0|0|

原24恰好非常接近精确均值，但从方差来看，它并不能稳定保证误差只有0.163分。合并更多独立路径降低了抽样标准误，点估计却没有单调靠近精确值。这是正常抽样行为，不能据某一次点估计变远就删除新路径或换种子。

本例96条随机路径仍只访问32支不同队；补齐35种单人缺席只需计算14个旧缓存没有的端点，即获得该人数处的完整分布。**接近满员时优先枚举有限的缺席组合，比继续增加大量重复顺序更合算。** 随机路径仍用于低/中人数及进入过程的配对变化，两种办法回答不同层面的精度问题。

几何结论与此相容，但精度表现不必与Q均值相同。34人有效底面之间的精确 V 为0.27008：尽管只差一人，成员变动仍可能改变很大一块底面。原24、新24、合48、合96的V估计分别为0.27752、0.27236、0.26962、0.27431；对应MCSE为0.01889、0.02974、0.01583、0.00405。全35队的精确V通过32个有效底面的全部独立双抽样配对计算，分母32²并包含同队自配的零距离；不是把32×31个不同队对当成独立样本。
