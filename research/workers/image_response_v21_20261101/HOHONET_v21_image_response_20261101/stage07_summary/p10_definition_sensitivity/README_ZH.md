# P10 分位定义的定向敏感性补算

本补算针对明确发现的风险：双峰质量分布的 10% 累积位置附近，线性插值 P10 可以落在两个质量模式之间，即使该位置没有实际团队。主分析仍采用原保存路径的 linear P10，本目录用**同一份路径加权样本**的 inverse-CDF P10 并列核查；没有替换人员、团队、路径、端点或评分。

## 已计算结论

- 普通主目标 206 图，linear 和 inverse-CDF 都有 127 图满足原 P10 全尾小变规则；起点中位数 19→20。
- 206 图的“有起点/无起点”判断全部相同；201 图的起点值或同为无起点完全一致，5 图只有起点人数发生变化。
- 固定 N≥30 的共同 171 图、22 楼，20→30 P10 平均改善由 +2.84838 变为 +2.87153；两口径均为 166 图改善、5 图下降，逐图方向全部一致。改善超过 2 分的图数 65→66。
- 这些结果支持多数图片的低尾改善，不需要因为一个分位位置敏感案例而撤回多数规律。

该图采用两种定义都**没有**满足足够后续观察长度的 P10 起点。无后续长度限制时，两者都只到 k28 才出现小范围，因为满员 Q=98.032082，末端变化仍然存在。分位定义能够解释 k27 的部分曲线形态，不能把全部末端变化改称统计假象。

与完整 28 支留一团队的精确有限总体比较属于另一种敏感性：它改变路径 Monte Carlo 权重为全部团队等概率，不能与这里“同一256路径样本、只改变分位定义”混在一起。对应资料保留在有限尾部比较和案例目录。

## 方法与文件

全尾范围、容差 1/2/3/5、有效路径 32/64/128 和后续长度规则全部复用主方法。主规则为 2 分、64 路径、至少 `max(5,ceil(.15N))` 个后续人数。inverse-CDF 使用排序后 `ceil(.1*n)` 位置的实际观测值，仍保留重复团队的路径频率。

**没有**为 inverse-CDF 生成或套用旧 linear P10 的 bootstrap 区间；本目录的精度陈述仅限定义敏感性。

- `FACTS.json`：机器可用结论与变化名单。
- `P10_DEFINITION_ONSET_COMPARISON.csv`：206 图两定义起点逐一对照。
- `INVERSE_CDF_ONSET_SENSITIVITY.csv.gz`：容差及支持敏感性。
- `P10_DEFINITION_PER_K_COMPARISON.csv.gz`：全部逐图逐人数值。
- `FIXED171_20_30_IMAGE_COMPARISON.csv`、`FIXED171_20_30_SUMMARY.csv`：共同面板逐图及汇总。
- `WC2_46_PATH_P10_DEFINITIONS.csv`：具体风险案例的全曲线。
- 复现：`python scripts/p10_definition_sensitivity.py`。
