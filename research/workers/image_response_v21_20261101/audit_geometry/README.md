# 门洞几何波动与五个机制案例：独立核查

日期：2026-11-01。对象为同级 `HOHONET_v21_image_response_20261101` 原始交付。此处只核查几何与案例；整体质量曲线、逐图平台和抽样身份由主审查另行处理。

## 判断

本项没有发现影响主要结论的数值或成员关系错误。门洞几何波动、五个机制案例可以接入 v2.1。它们分别说明：继续加人可减少几何波动，某一个人也可触发结构变化；节点不变时位置仍会变化；满员和稳定输出均不保证接近当前参考。

这些是从已交付几何、逐票记录、成员与指标作的独立核查。本次没有重跑原生融合，没有重新评分，也没有替用户修改空间或裁定参考。

## 几何核查

- 重新核查全部 **1,314 个池×人数单元** 的路径频次，每格保持 256 次路径出现；重复团队保留真实频次。
- 从几何坐标和资格重新判断有效底面，保存的几何有效标记全部一致。逐指标重建有效路径数和 `n(n−1)/2` 配对分母。它们没有把缺失几何填作零，也没有用 Q 是否存在替代几何资格。
- 对 **67 个单元、1,860,477 对路径输出**，直接展开重复路径，用 Shapely 从底面多边形重新计算 `1−IoU`。单元均值最大绝对差 **3.63×10⁻⁷**，未见影响报告精度的差异。这一项覆盖 17 张门洞图的筛前/筛后 k=14，以及筛后的 k=3 和实际满员；相同人数重合的单元只算一次。
- 对中心距离、均高差、节点数差、有效转折数差，全部 **5,256 行**从坐标或几何字段重算；各指标各有 33,882,677 个有效路径对。最大绝对差依次为 1.33×10⁻¹⁵、1.39×10⁻¹⁶、6.66×10⁻¹⁶、6.66×10⁻¹⁶。
- 固定 17 张图、14 人，筛后相对筛前的平均底面波动变化为 **−0.096507**；12 图下降，2 图上升，3 图不变。
- 主几何图 `06_Doorway_Geometry_Response` 的 46 个绘图数据点重新聚合一致，最大差 1.11×10⁻¹⁶。

正式 U 使用全部已保存路径索引对：不同状态的权重为 `m_i m_j`，同一状态的零距离权重为 `m_i(m_i−1)/2`。这正好回答“当前 256 条路径代表的团队分布有多大几何波动”。这里的“精确”是对已保存路径配对，不是对全部人员组合穷举。配对距离的 SD 是距离分布宽度，不能当作均值标准误；本包也没有这样使用。

## 五个案例

| 案例 | 独立核查所得 | 对研究的解释 |
|---|---|---|
| jh4-09，筛后 23→24 | 低高团队严格嵌套、只加 1 人；24 个缺一人团队齐全；17 个补齐后 Q 上升，12 个增加节点，平均 Q 变化 +5.481 | 某些图片在接近满员时仍会发生结构响应，不只是均值曲线的平滑变化 |
| uNb-47，筛后 31→32 | 32 个缺一人团队齐全；21 个补齐后 Q 上升，19 个增加节点，平均 +17.376；精选轨迹为 7→8 节点、Q 52.963→81.878 | 末段加入一人仍可使局部表达进入输出；该精选轨迹不是对所有缺一人团队的平均描述 |
| VFua-04，满员 35 | 从各组实际成员独立重计支持：两个候选各有 17 人，门槛 18；仅 3 节点入选；正式状态 `below_four`，三种质量分数均缺失 | 现有人全部加入仍可能无法形成合格布局；缺 Q 不写成零分 |
| e9z-17，11→12→13 | 三队逐个加人；始终 4 节点，所有所选节点均获全体支持，无未选组；Q 74.403→84.358→76.259；底面面积 +7.289% 后 −5.573%，中心移动 0.0714/0.0778 相机高度单位 | 这次变化由位置/尺寸变化体现，不能归因于节点没有达票 |
| pa4-11 | 35 人原答各有 8 对点；所查输出均 8 节点、节点全票；现行参考为 4 节点；满员 Q=22.367 | 这里存在相对于当前目标参考的共同表达偏离。不能仅凭这个分数断言每人都画错，也不据此改参考 |

两个门洞案例另外逐行检查了 **62 个身份组、727 条原答点票**：独立人员支持数、人员集合、MV50 是否入选均吻合；票来源属于相应团队。检查基于交付的完整 trace，而非只读取作者的 parity 回执。

机制表达应保留一个区别：加人还可能改变对应分组、位置和连接，案例不是“固定所有其他计算环节，只拨动一个票数”的人为干预。可以说观察到节点支持与结构输出的变化，不能把全部 Q 差额都算成一票单独的效应。
