# 混合人群规律与 C1↔C3 半队替换：本轮分析合同

日期：2026-11-04。输入接续 GitHub `main` 已核实的冻结提交 `48a2fc6aedd51cd701b1bce06c02bd3ef92ec75b`，以及第 08–10 批已经完成的当前类别解释结果。此文件在本轮结果汇总前制定；容量调查可以决定可实现的实验人数，不按效果大小决定选图、选员或人数。

## 研究问题

把既有单类、联盟、固定人数配比、固定配比成员、固定替换块背景和逐前缀结果串联，回答哪些类别组合在什么条件下改变质量、结构、位置、劳动和输出状态，以及是否更早接近当前采用参考。额外完成用户指定的当前 DSTRUCT K3 C1↔C3 50% 严格 ABC 缺口。

## 数据与方法身份

- 普通 Manual 主目标为主；Semi、其他准入目标和门洞保留各自范围。门洞与多参考不重新定义。
- 图片使用所在建筑的当前 LOBO 标签。DSTRUCT K3 为主解释，RFUSE GEOM K2 为融合响应解释，OPPJOINT K3/K4 为联合画像。现有分类和有效预处理保持。
- 完整联盟包含实际人数变化；固定人数配比比较另列。全体已分类人员的合并队与含未知标签人员的真正全员队分别命名。
- 历史进入策略保留实际 V3/OPP 等身份。当前标签重标已有随机前缀，只说明这些既有序列中的构成联系，不自动变成一项新选人政策试验。
- 当前 57 组已批准人工顺序只复用于同一输入、同一成员与原融合节点的精确匹配端点。自动、已批准人工辅助和不可评状态保持可区分。没有新依据时，不替新失败端点猜人工环序。

## 规律挖掘

1. 完整联盟：单类→两类、两类→三类，以及已存在 K4 联盟；列出各端人数、同图效应、正/负/近零比例与可评支持。
2. 固定人数：使用既有有限面板，在相同图片、目标、人数及共同背景内分析配比差异；同时保留同配比的成员波动与失败率。
3. 背景：对固定替换块比较共同背景变化，明确有符号阶差与绝对变化幅度的区别。
4. 分层：先使用既有官方难度、用户已登记房间用途、参考结构/遮挡等现成条件；不从 Q 效果倒推场景名称。查看完效果后发现的子集明确为探索性解释，同时交代其在全部图片中的覆盖。
5. 重复支持：报告图等权、建筑等权、图间中位数与方向分布；适用时补建筑聚类区间或留一建筑稳定性。有限组合/重复抽样事件不能充当独立图片数。少数反向图片不会自动否定多数图上的规律。

## 接近参考的速度

输出趋于稳定、质量接近采用参考、用更少人数达到既有质量目标、用更少合法记录劳动达到目标分别回答。优先沿用原研究阈值和路径；完整报告未达标、暂时越线后回落及不可评前缀。没有 Q 的前缀不计作 0 分或达标。使用同图同条件共同支持，避免因每个 n 的图片集合改变产生虚假的上升曲线。累计劳动是人员记录时间之和，不是墙钟等待时间，也不包含未登记人工排序劳动。

## C1↔C3 的新增严格 ABC

每个方向必须分别满足 A=D∪X、B=D∪Y、C=D∪Z；D 固定，X/Y 为同一来源类，Z 为另一类，D/X/Y/Z 两两不交，|X|=|Y|=|Z|=m，|D|=m，n=2m。真实候选容量决定能实现的 m；不为维持某个期望人数重复使用人员。两方向不通过简单翻号替代实际严格 ABC。

冻结随机种子与选样规则，覆盖全部合法图片，不看 Q/T 选择事件。尽量复用原端点，仅新增缺失的融合与评分。主指标为同类幅度 W=|Q_B−Q_A|、同起点额外幅度 GA=|Q_C−Q_A|−W、对称额外幅度 GS=(|Q_C−Q_A|+|Q_C−Q_B|)/2−W，另报 CA/CB 的实际升降、质量分项、结构/位置/尺度、同源劳动与输出状态。所有指标保留自己的端点共同支持。
