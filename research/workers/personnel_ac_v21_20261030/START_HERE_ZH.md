# HOHONET v2.1 直接 AC、较大团队与整类人群模拟

## 研究结论入口

先读 `stage08_report/HOHONET_v21_AC_population_report_ZH.pdf` 或同名自包含 HTML；可编辑 DOCX 和 Markdown 同时提供。完整报告为28页、36张表、5张图，包含全部重点方向、质量分项、几何、记录劳动、输出状态、成员与背景敏感性、原答机制和既有严格ABC的边界。

采用方案保留 TARGET_DSTRUCT K3 为普通 Manual 主解释、K2 为粗层，OPPJOINT 为质量/劳动/标法联合画像，RAW3 为原答定义及较大块敏感性，RFUSE 为融合响应反向互补。本轮新增的主要模拟条件是 TARGET K3 中→高、固定20人且整目标类等量换入；固定20/7与原严格ABC形成证据链。十人、十二人和较大团队按实际逐图容量与角色方向使用，不能把覆盖率或最大Q差当成分类优劣。

## 完成数量

- 478,012支唯一团队，471,758条方法事件，412,839个不同无向物理AC端点对；550,794条设计链接不是额外独立样本。

- 原生完整端点与逐事件指标各覆盖同一258池，分别按四包和两包提供。正式指标为431列，缺Q保持缺失。

## 正式统计入口

主结果使用 `stage05_main/CONDITION_METRIC_SUMMARY.csv.gz`；正文主要直接AC及等量整类结果采用预登记 `neutral_members_0` 背景。图片内先汇总事件，再按图等权；所有合法范围也另报。均值、平均绝对变化、多数方向、低尾、建筑支持及不同有效分母同时保留。

敏感性最终入口依次为 `member_variability_v2/`、`results_v1/SENSITIVITY_IMAGE_BALANCED_SUMMARY_V2.csv.gz`、`report_tables/`、`three_leg_common_support_v2/`、`exact_outside_background_v1/`、`core_members_v2/`。成员跨度/SD/翻转至少要求同指标两个有效值；单一可评值不会当成零波动。逐事件绝对幅度与图均值的绝对值明确分开。
