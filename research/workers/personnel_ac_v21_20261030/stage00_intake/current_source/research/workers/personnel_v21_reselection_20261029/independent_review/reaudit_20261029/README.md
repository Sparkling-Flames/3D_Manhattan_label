## 2. 分类是否按声明的方法得到

本地从合格原答重新构造楼外历史：先去掉目标建筑，再按目标、图片、建筑逐层平均；同图同目标的同伴中位数用于扣除共同图像水平。414项历史特征及支持量核对一致，四个同伴差值特征也一致。

另用独立代码重新缩放、PCA和Ward聚类，复算 TARGET、RAW3、FULL 三家族，各K2/K3/K4、ALL与22个楼外折，共207个分区。合格人员集合一致；考虑类别编号任意重排后，所有分区均一致。这里的ARI=1是“复算与交付一致”，不是人员类型的正确率。

TARGET沿用的设计规则包括：总体12图/3楼，简单5图/2楼，困难4图/2楼；中位数中心化、p85−p15缩放及±3截断；总体与困难响应两域等权，域内最多两维PCA，再切层次聚类树。数值、历史和标签已按v2.1重算。

四条输入是有效转折、短转折边、近共线节点和 `unmatched_ref_9`。最后一项同时受缺结构和位置偏移影响。**它没有直接输入Q或时间，但也不是完全不使用参考的“纯风格”分类。** 较多转折类的历史Q较高，因此团队差异应解释为这些结构角色的实际作用，不能全部归为与能力无关的风格作用。

全历史展示名单为10、37、12人：第一类在困难图上更偏简化，第二类常规或略简化，第三类保留较多转折和短细节。实验使用的是对应目标建筑的楼外名单，不把这张全历史名单硬套到每张图。

五种新变体分别改变PCA、直接参考匹配特征、困难响应域、困难定义、困难域权重；各切三种K，共15个新配置。60是旧45加新15个配置，不是60种互不相干的方法。方法、方向与人数规模经过本批数据比较后采用，应作为内部探索选型如实说明。

## 3. 为什么选 TARGET，而不是只挑跨类比例最高的方法

从保存的逐图原答距离独立重聚合，相同角点数的原答中，TARGET类间角距比类内平均大0.684°，162/206图为正；RAW3为0.428°、155/206图；OPPJOINT K3为0.501°、155/204图。它们覆盖普通合法目标，不等于下面严格ABC的原主目标支持。[结果表](RAW_GEOMETRY_REAGGREGATED.csv)

这个比较回答“同样画这么多个点，人员画的位置是否还有类别差异”。与多数图片上的实际替换结果结合，TARGET能够把实际标法和共识输出连起来。各方法的有效人对和图片支持仍略有差别，这张表不构成所有方法在完全相同团队上的性能排名。

|方法|建议用途|独立判断|
|---|---|---|
|TARGET_DSTRUCT K3|普通Manual主工作分类|结构和困难响应解释直观；原答区分与七人替换证据较均衡|
|TARGET K2|主分界的粗层|呈现较多转折角色与其它人员的主要区别|
|TARGET K4|父类内部的细节|当前小类和条件差异较多，不默认用四类替代三类|
|OPPJOINT K3/K4|质量、劳动和标法的联合画像；配比与定向选人|直接使用历史Q/T；保留实际用途，不把升Q差额自动归因于结构特征|
|RAW3 K3|删去直接参考匹配特征的敏感性；八人块补充|八人覆盖更广，但20/7的平均Q区分没有保持正向|
|RFUSE_GEOM K2|从融合响应反看人员角色|继续与原答建类互补；小目标类适合其实际可行规模|
|OPPSTRUCT等|具体结构条件、位置尺度、跨条件行为的补充|有局部强结果；不能单凭小支持内更高比例替代总主方法|

例如OPPSTRUCT的14/7同起点比较为33/38图正向，高于TARGET的61/83比例；但换成旧研究使用的对称跨类定义，则为28/38，对应TARGET62/83。只挑其中一个百分比，会改变方法排名的印象。TARGET也并非每个几何指标都最强。

## 4. 换类效果：把比较对象和分母写清楚

严格ABC为 A=D∪X，B=D∪Y，C=D∪Z；X、Y同来源类，Z目标类。

- 同类幅度 W=|Q_B−Q_A|。
- 同起点跨类幅度 C_A=|Q_C−Q_A|，G_A=C_A−W。本轮报告主要采用它。
- 对称跨类幅度 C_S=(|Q_C−Q_A|+|Q_C−Q_B|)/2，G_S=C_S−W。旧研究常采用它。

G>0表示跨类变化比同类大，不表示Q提高。方向性升降另看C−A、C−B。本地两种定义均重算，避免新旧数值串用。

普通Manual原主目标，按困难图转折历史排序的中间角色→较多转折角色：

|---|---:|---:|---:|---:|---:|---:|---:|
|TARGET K3，14人换7人|83（登记85）|4.577|8.089|+3.512|61/83|+3.397|62/83|
|TARGET K3，20人换7人|70（登记72）|3.533|4.998|+1.465|54/70|+1.347|47/70|
|RAW3 K3，14人换7人|76（登记77）|4.970|6.153|+1.183|51/76|+1.641|51/76|
|RAW3 K3，20人换7人|66|3.775|3.066|−0.710|38/66|+0.068|43/66|

表中按固定块内背景→块→人员池→图片等权，不把大量事件当作独立图片。前四行为旧新综合事件；RAW3 16/8为本轮新增，综合表与新增表在此条件一致。全部方向见[重聚合表](ALL_DIRECTION_RECOMPUTED.csv)。TARGET 12/8的综合表与Pro重点展示的new_only子集不同，不应直接抄成同一结果。

这已经实现了用户要求的“多数图片中跨类比同类更不同”，以14/7半队替换最适合主展示。20/7保留为较大背景对照。反方向也保留：TARGET中间角色→较少转折角色在14/7为25/46图G_A>0、对称定义23/46；20/7两种定义均15/30。当前三类并非任意两类都具有同样强的区分。

这些人数还受严格对照的容量限制：同时保留互不重复的D/X/Y/Z，至少需要n+2m个不同的人。14/7需要28人，20/7需要34人，16/8需要32人；来源类还要至少2m人、目标类至少m人。所以“每图30多人”不自动保证每个分类都能做20/7或八人替换。应区分实际实验覆盖和类别容量，不能拿某一K只做过的图片数当作其全部可行图片数。

## 5. 例外能解释到什么程度

### 难度和替换比例确实有关，但不是一条万能解释

TARGET上行方向、原主目标，以下均为G_A：

|条件|简单|中等|困难|
|---|---|---|---|
|14/7 正差图片|41/59|12/15|8/9|
|14/7 平均额外幅度|+1.813|+6.662|+9.400|
|20/7 正差图片|43/53|9/13|2/4|
|20/7 平均额外幅度|+2.248|+0.782|−6.693|

14/7困难图的同类变化本来就大，跨类还更大。20/7这4张困难图则有几张同类变化非常大，超过了跨类。这两行支持不同，不能只把差额归因于替换比例。[逐图数据](TARGET_MAIN_IMAGES.csv)、[难度汇总](TARGET_DIFFICULTY.csv)

### 已能区分三种具体情形

1. **接近满分，两种换法都变化小。** jtc-30在14/7平均Q约98.99，同类0.927、跨类0.537。这样的负差主要发生在很小的变化范围内。14/7的22张非正差图片中，有11张G_A处于−1到0分。
2. **分数集中，但并非高分。** X7-19在14/7平均Q约72.49，同类2.359、跨类1.385。高分饱和不能解释它。保存端点说明几组结果接近；具体是否共同漏结构或共同定位偏差，还应看原图及对应几何。
3. **同类具体成员也能引起结构或位置的大变化。** jh4-04在14/7同类变化30.460、跨类17.538。困难图的差异很大这一点成立，但差异未必沿当前类别边界排列。

高分并不是负差的普遍原因：14/7简单图中，负差图片平均Q约89.45，正差图片约93.59。不能看见反例就统称“太简单”。

### 一个已经查到分项和结构的例子

7y-21，20/7，同一个ABC事件：

|团队|Q|输出节点数|参考节点召回（9°）|底面IoU|方向损失|
|---|---:|---:|---:|---:|---:|
|A|80.812|8|0.8|0.916|0.313|
|B（同类换人）|49.846|7|0.7|0.786|1.121|
|C（跨类换人）|79.268|9|0.9|0.945|0.386|

同类B的方向损失明显增加；跨类C保留更多结构，底面IoU也提高，但总Q与A接近。**这里“跨类Q变化小”并不是“跨类没有改变结构”。** B6-47的两个事件也出现C比B保留更多参考节点、底面更接近参考，同时方向项改变总Q的情况。见[端点与分项](EXCEPTION_ENDPOINT_COMPONENTS.csv)。

这些事件已有部分节点支持接近10票门槛。仅凭被选节点的票数，尚不能把每次结构变化都归因于某条未过50%的墙线；认定这一点需要对应被淘汰身份组、位置估计及连接账。当前不为每张反例编一个因果故事。
