# 整类不等人数三段分解的共同有效支持

最终正文使用本目录v2；旧 `three_leg_common_support/` 未区分父背景人数，仅作中间汇总保留。

输入63,491条已登记路径、12,922个父对照。每指标仅保留总比较、等人数换类、追加目标类剩余成员三段均有效的同一路径；中间队路径先在父对照内平均，再在池内平均，再按图和楼汇总。因此有符号可加标量的总体均值也使用相同分母闭合，不将不同可评集合的三段均值硬相加。

- `COMMON_VALID_THREE_LEG_IMAGE_SUMMARY.csv.gz`：逐方法、方向、scope、Manual/Semi、父背景类型和背景身份策略汇总；三段各自的方向、绝对幅度、低尾及图/楼支持。
- `COMMON_VALID_THREE_LEG_POOL_SUMMARY.csv.gz`：可回连逐图逐目标池的共同有效支持汇总。
- `COMMON_VALID_DECOMPOSITION_RECEIPT.json`：输入路径和容量哈希、完整可读性回执。

父背景类型明确分为无D、部分两交换类之外成员、全部两交换类之外成员。若存在unknown标签人员，它们只在D中；这里的“全部外部D”因此不一定仅是第三个已知类别。父D与追加腿的实际公共成员不同，后者还包含已换入的目标子集。

`*_image_balanced_path_abs_mean` 在每条中间队路径上先取绝对值，再按父对照、池、图片平衡，避免正负路径抵消。`*_image_mean_abs_of_mean` 是对每图的有符号均值取绝对值，含义不同。

Q、角度、转折数量、绝对坐标和合法记录秒数等可加差可检查闭合；面积或高度百分比以及几何1−IoU距离不满足加法，表中仅并列三段描述量，不赋予加法分解。追加腿是“加入这些剩余目标类成员”的路径结果，不能解释成与人选无关的纯人数效应。不同背景层的容量和可评图集合不同，不能直接相减称为控制背景的因果效应。
