# 人员分类用途与同图大块结果：当前展示口径

2026-10-25。本文负责研究台接入、分类定位和显示合同；人员研究的统一论述仍在[人员主报告](../../../docs/thesis_main/人员分类与构成不确定性_研究组织与比较清单_20261022.md)。来源为已独立审查的13个研究包，底层是真人v2。本次整理不新增拟合、融合、评分或标签。

## 采用结构

**主要解释方法采用DSTRUCT_K3；两套融合响应类是核心效果对照；跨条件联合、边界和Q/T类按各自问题保留。** 这是研究内容的组织选择，不声称某一方法在全部条件胜出，也不要求唯一永久的人员类型。

|方法|主要回答什么|输入和解释重点|采用边界|
|---|---|---|---|
|DSTRUCT_K3|人在困难图怎样表达结构；这种差别如何影响构成与换类|Manual总体、困难及困难−简单的转折、短边、近共线节点和参考对应缺失；不输入Q/T|转折较多不是正确率；已采用具体方向/规模，不把全部方向推广为有效|
|RFUSE_GEOM_K2|哪些人员块更容易改变当前融合输出|自然随机团队的结构、边界和尺度响应；ALL为55/4人|融合响应角色依赖当前算法，不等于纯个人能力|
|RFUSE_GEOMQ_K3|哪些人员块同时影响形状和参考质量|几何响应再加质量响应域；ALL为20/32/7人|含质量域，不作为独立于Q的纯风格证据；响应核心的容量影响可替换性|
|MSDGEOM_SCOPE_K4|两种采集条件和范围判断是否提供互补画像|Manual与Semi的终稿结构/边界，再加入scope倾向；Q/T用于事后角色解释|本轮效果仅普通Manual；scope倾向不是准确率，未使用确认初始化错误的纠错特征|
|DBOUNDARY|总分相近时，边界、位置或尺度是否仍有区别|顶底界相对位置、面积/高度与难度响应|K3 n18/m7：Q幅度4.058/4.000，顶界角距离0.440°/0.550°，41/61图跨类更大；几何用途成立不要求总Q同时分开|
|DJOINT与旧结构＋Q/T|如何描述质量、劳动与结构的取舍|表达、历史Q和记录时间，不是单一质量排序|历史快角色不必在目标图实际更快；质量/时间共同支持单列|
|MSDGEOM|Manual和Semi终稿几何提供什么互补信息|两条件的结构、位置与尺度|保留无scope对照；当前不同支持的结果不足以单独估计scope增量|
|Q_MEDIAN2|复杂分类之外，历史能力本身能解释多少|楼外历史Q二分|能力基线有区分价值，但不回答具体标法为何不同|
|旧A2、QTD、F01、Semi结构/尺度|几何相似、效率与次要采集条件的不同问题|各自原特征、原标签和已完成实验|保留正负结果，不统一改写为新DSTRUCT的证据|

反推类别并非“难解释所以降级”。例如B6-47中，背景给某身份组2票，换入4名响应核心后达到6票门槛，输出结构改变。它从团队结果反推可观察响应，正好补充从原答特征出发的DSTRUCT。两者分别回答“怎样标”和“怎样影响共识”。

## 四个重点条件怎样读

A=D+X、B=D+Y、C=D+Z。D相同，X/Y同类，Z为目标类；所有成员块互斥。同类幅度为`|B−A|`，跨类幅度为`(|C−A|+|C−B|)/2`；方向另看C−A、C−B。以下为选型保留建筑内检查、图片等权汇总，建筑支持另数。

|分类|n/m|同类Q幅度|跨类Q幅度|幅度差|跨类更大图片/建筑|C−B平均Q|
|---|---:|---:|---:|---:|---|---:|
|DSTRUCT_K3|18/7|3.438|6.386|2.948|31/40；10/10|+4.319|
|RFUSE_GEOM_K2|12/4|3.642|6.492|2.850|23/29；9/10|+5.662|
|RFUSE_GEOMQ_K3|20/6|1.828|5.642|3.814|16/21；8/9|+3.971|
|MSDGEOM_SCOPE_K4|20/6|4.611|7.246|2.635|40/49；9/10|+5.293|

“变化更大”“类内更稳定”“两者差距更清楚”是不同用途。scope联合类跨类幅度较大，但类内也较大；不能只拿7.246分称其最佳。GEOMQ的3.09倍也受一张较大响应图影响：与K2共同可评20图为1.904/3.928，约2.06倍。全部结果及原分母在[71条件表](sources/FINAL_CONDITIONS_COMPACT.csv)，包括未选为重点的规模、方向与其它方法；[31方法/层级表](sources/METHOD_ADOPTION_DECISIONS.csv)保留探索身份及采用理由。

四条件C−B记录时间依次+5.941%、+10.862%、+2.665%、+4.389%，时间支持分别30、29、20、31图，不能与上表质量支持拼成“普遍又快又好”。失败分别3/343、0/60、0/56、1/589个C事件臂；这些不是独立图片数。不可评不填0。

四条件逐图幅度差中位数分别0.874、0.920、0.707、1.359分；少数大响应与多数同向并存。去掉任一楼后固定结果的平均幅度差仍为正，该检查没有删楼后重新拟合。条件经比较后挑选，报告为当前v2内有支持的发现，不宣称全新外部盲测。

## 人数、类别数和人员池

K是类别数，n是每队人数，m是换人数，N是当图可用人员池。普通Manual177池中157池至少30人，92池35人；并不意味着每一类都能提供足够成员。

- 严格ABC需要`(n−m)+3m=n+2m`名不同人员，并要求源类≥2m、目标类≥m。N=35、m=7时n最多21；n18/m7是比较后选择的具体条件，不是数学上唯一可行值。
- 没有同类B队的直接AC只需`n+m`人，因此可到n28/m7。它回答原队与换类队的差别，不能代替类内/跨类幅度对照。
- 自然人数曲线已到30、35及实际满员，保留低人数变化。这是增加人数的问题；满员N人只有同一个完整成员集合，不能再换出另一支不同的N人队。

固定XYZ的严格路径已到10—21人；固定35人容量范围，DSTRUCT在21人时同/跨幅度2.846/5.987，44/57图跨类更大。直接AC在28人时C−A为+2.868分，51/57图升质。路径表合并探索和检查阶段，与四重点的选型保留建筑分母不同；不混合计算。

## 标签、名单和历史结果衔接

DSTRUCT ALL三类为8/39/12人，未知3人；未知是历史支持不足，不是低能力。新C3十二人全部来自旧Manual结构M3十九人，但新C1/C2也重新组合，整套分区不是旧分类的纯细分。完整关系见[新旧名单](sources/DSTRUCT_K3_AND_REVERSE_MEMBERS_ZH.md)。

研究台可切换7种方法和ALL/22个目标楼外范围，共9,982条人员×方法×范围标签。ALL用于总体描述，实验读取排除目标建筑的LOBO标签；相同C编号不能跨楼直接套同一个中文角色。楼外名单服务分类及换类实验，并非同房预测专用。

此前的四套方案是Manual/Semi各自的结构类和结构＋Q/T类；本轮四个重点则全部评价普通Manual，其中一套允许使用Manual＋Semi＋scope历史建类。**旧完整配比、进入策略、同房结果继续按原标签解释，不将旧数据换名算作DSTRUCT验证。** 本次没有补做新标签下的完整混合配比；这是可复用已保存团队作分类衔接的后续事项，不要求重跑融合，也不阻塞已核大块结果的采用。
