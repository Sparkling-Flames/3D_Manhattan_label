额外背景的原留出图片中，G五栋的主稳定率差均为正；R六栋为五正、一并列。严格／宽口径也保留两方向的类内优势，但强度不同：R宽口径约90.16%／82.65%，远小于主口径的差距。不能只选最漂亮的阈值。连续距离、质量方向及事件低尾保留在明细。

进一步拆分判据，去掉Q限制、只保留完整性／底面／节点数／绑定角差时，原留出图片额外背景的G同类／跨类为78.97%／56.23%，R为95.40%／82.96%。因此并非全由评分差驱动；但部分展示例确实主要因Q差被拒，仍需人工判断。见CRITERION_COMPONENTS.csv；这个几何判据并不等于完整三维实体距离检验。

C−B负值说明这里的跨类替换平均降低质量，并不表示“换类应该提高质量”。目标中的可区分性与选人收益分开解释。这两个方向是从既有大搜索事后挑出的；额外背景清单先于本轮融合登记，但仍使用已探索v2图片。不是新图片、外部盲测或独立的新样本，不声称全部团队在先前58万搜索中未出现。每条事件的核心背景相对于该方向在该池的原选中事件不同；不同方向可共享图片。
