## 当前研究意图

类别来自Q、T、难度、Semi/盲信、scope及历史结构等变量的正向分类，或从标法簇/融合行为反向发现后再解释。ABCDE只是类别组合示意，不限定类数。下一轮重点比较类别组合、比例、总人数及整类替换，同时用同构成不同具体人员的波动作对照；不局限单席替换或既有8/12/16/24人数。

允许广泛探索和寻找清晰、有解释力、适合展示的结果；搜索与验证分开，保留尝试范围、反例和失败。当前包不替Pro选定方法、类别数、人数、配比或最大换人数。

## 已知缺口，不作为禁止探索的理由

- FULL画像的Q与结构变量60人均有值；T为35名新增＋22名旧人员有值。难度差有不同支持量。
- Semi旧确认错误和新报告错误是不同证据层；非编辑不等于所有情境下的盲信。旧错误非编辑效应24/25旧人员有值，新来源对应35/35新增人员有值，另一来源字段自然缺失。新批缺逐份初始几何，不能编造净改善。
- 当前scope_out_effect新增35人有值、旧25人全缺；这是该效应的支持问题，不代表旧人员完全没有scope回答。倾向、裁定正确率及未知分开，OOS图片标签不等于个人答案金标。
- 图片索引259图列于已有Release，另2图有仓库预览但不在该Release清单；缺原图不阻止数值研究，不声称完成不存在的原图目视审查。
- 229池是现用质量合格池，未包含不合格作答不等于这些作答被删：完整10439份匿名证据仍可研究行为与排除，但不能直接恢复为主融合投票。
- 原A主选的类有规模不平衡、来源关联与小类问题。允许重新分型，不能把任何一种当前主选当作类别数的硬上限；也不能依靠当前测试图GT反调成员。
