## 归档与证据边界

五个源 ZIP 的解压目录在归档前逐文件与 ZIP 比对，文件数、相对路径、字节数及 SHA-256 均一致。归档共 158 个文件；Semi 案例包里与仓库已跟踪原图完全相同的 PNG 未重复复制，其来源为 [`data/mp3d_layout/test/img/q9vSo1VnCiC_a412536ff52747d3b078f66e764cf103.png`](../../../data/mp3d_layout/test/img/q9vSo1VnCiC_a412536ff52747d3b078f66e764cf103.png)。源包原始 `MANIFEST.csv` 保留为交付时清单；上述单项省略属于本仓库归档整理，不改写源包身份。

这些是基于现有真实标注与冻结终点的构成分析，不是模拟人员生成数据，也不表示 269,814 个事件都已被独立重跑。已复核范围、未复核项与采用边界以[人员总体进度](../../../docs/thesis_main/人员标法分类与换类研究_总体进度_20261020.md)为准。该包尚未接入研究台。
