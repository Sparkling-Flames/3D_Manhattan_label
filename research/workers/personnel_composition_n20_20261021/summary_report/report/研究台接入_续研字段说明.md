# 研究台接入：续研字段说明

本说明连接既有人员标签、修复事件、新 n20 分片与配置模型，不新增标签或改变资格。字段依据：[旧接口 schema](../../integration/FIELD_SCHEMA.json)、[旧 719 字段字典](../event_repair/EVENT_FIELD_DICTIONARY.csv)、[新 697 字段字典](../n20_abc/N20_MATCHED_EVENT_FIELD_DICTIONARY.csv)及各条件 `n20_analysis/*/N20_ANALYSIS_CONTRACT.json`。

## 1．标签绑定

`integration/PERSONNEL_LABELS_LONG.csv` 的 620 行以 `method_id, condition, label_snapshot_id, worker_id` 为键；宽表用 `coarse_class/fine_class`，勿虚构扁平方法的细层。`heldout_building=ALL` 是全数据展示标签，不能用于目标验证。验证先按 `VALIDATION_LABEL_INDEX.csv` 的方法、条件、目标楼、快照查 `source_path/source_sha256/source_filter`；实际实验按 `composition/FROZEN_LABELS.csv` 的 `method_id, condition, tier, heldout_building, worker_id` 取 `class_id/parent_class`。不同方法同名类无共同含义；未知按 `known/missing_reason` 保留。

## 2．事件、端点与去重

旧正式结果为 `event_repair/ABC_EVENT_RESULTS_COMPLETE.csv.gz`，**12,953×719**；新 Manual 为 `n20_abc/checkpointed_manual/shards/part_*_EVENTS.csv.gz`，合计 **269,814×697**，按 `CHECKPOINT_PLAN.csv` 及批清单读取；Semi 为 `results_semi/N20_ABC_ALL_COMPONENT_EVENTS.csv.gz`，**1,517×697**。只读完整文件，不读 `.pending`。

保留方法、条件、`tier`、标签绑定及 `pool_id/event_id`。`event_id` 是登记标识，不是跨方法独立样本。`team_A/B/C` 对应端点 `team_key`；按冻结池内的 `member_workers/member_object_ids` 实际集合去重，并核对 `reference_id/reference_version`。新表另有 `physical_triple_id/oriented_triple_id`，用于跨登记识别同一三队关系，勿简单累加事件当独立试验。

新匹配保持共同背景且 `m_AB=m_AC`；`m_BC` 是 B→C 净换人数，不能沿用前两者。`n` 是人数；K 是类别数；每格 r 来自 `sampled_member_sets/registered_member_sets`；ABC 是三支团队，三者均不限制 K。

## 3．配置模型连接

`next_stage/candidate_n20/CONFIG_MEMBERSHIP.csv.gz` 以 `pool_id, method_id, tier, cell_id` 标识登记格，用 `team_key` 接端点；保留 `composition, class_capacities, possible_member_sets`。全配置覆盖不等于成员全集或加入顺序穷尽。

模型池表 `N20_PREDICTION_POOL_RESULTS.csv.gz` 按 `condition, method_id, support_scope, design_anchor, family, heldout_building, weighting, outcome, model, n, pool_id` 区分行；汇总另保留 `target_panel`。`N20_FOLD_MAPS.csv.gz` 记录共同端点哈希与折映射，不能只按图片串接不同支持域。`configuration_uniform` 对原采样锚细格等权；`member_universe_estimate` 是按精确格容量加权的抽样估计。汇总 `R2_relative_to_pool_mean` 解释同图同人数的相对变化，不是绝对新图质量预测。

## 4．未知、评分与时间

端点使用 `complete_evaluable, score_status, geometry_status`，事件中带 `endpoint_A__/B__/C__` 前缀。Q 缺失不补零；原生失败保留失败分母；单成员格的成员波动不可估，不记稳定。B8L2 为主、D10 为敏感性，IoU3D100 等几何代理沿用原定义；同分不等形状，参考外结构不自动判错。

时间优先读取统一端点字段 `source_time_total_seconds, source_time_known_n, time_source_kinds, time_source_table`；未知不补零。完整且同来源时才用于本轮时间模型，结局 `log_source_time_total` 是总人员秒数之和的自然对数，非最大等待时间。新报告加工时间与旧审计来源保持区分；标签和行为库存不恢复筛除作答、GT 暂停或特殊范围的正式资格。
