# 发现阶段类别块替换请求的独立身份与覆盖审查

审查对象是 `DISCOVERY_BLOCK_REQUESTS.json.gz`，SHA256 为 `af2a6fa99bc45dba4d4241d669438b67cc2b01d5ba50e96032a24058d0d656b1`。对全部事件及请求进行核验；没有读取这些事件的融合结果，也没有读取本轮验证集新结果。审查不导入生成器，使用冻结池、独立读取的历史类别标签及独立动态规划重算构成支持。

## 审查结论

全部 **25,744 个事件、77,232 个请求**通过身份与构成不变量。共涉及 **76,973 个唯一团队、51 张图片、6 座建筑、55 位已获得类别的实际人员**。事件数和团队数不能替代图片、建筑或人员支持量。

每个事件均满足：A=core+outgoing，B=core+同构成新人员，C=core+异构成新人员；A、B、C 总人数相同；A 与 B 的类别数量向量完全相同，A 与 C 不同；A∩B=A∩C=core；A→B 和 A→C 的实际换出人数与换入人数都恰为 m。所有成员属于同一冻结池，各请求的精确成员、team key、构成字符串及事件关联全部一致。

**13,714 个来源匹配事件**中，三个换人块均来自声明的同一批次，且 A、B、C 全队新批人数完全相同。共同背景本身允许新旧混合，但它在三臂中相同。该设计控制批次数量，不能据此称所有历史机会、时间或 Q 也已匹配；后者应另外分析。

共有 836 个方法×域×池×人数格，另有 20 格因已知类别人员不足 k+2 而跳过。截断后的计数模式候选帧共有 513,618 项，实际尝试 26,854 项，接受 25,744 项；942 项因换入计数超出排除换出成员后的容量失败，168 项因单次成员抽样后的 core 容量不足失败。770 格填满 32 事件配额，66 格把该格截断后的候选帧全部尝试，所有格均有接受事件。以上台账计数和所有可进入格均独立重数一致。

这一阶段是有记录的系统抽样，**不是遍历所有类别计数变化，也不是遍历所有具体团队**。多类换出／换入向量各侧最多考虑 16 个系统分散的向量；核心构成最多考虑 64 个。每个被选择模式只抽一次真实成员，并采用一个核心构成。穷尽标志只针对已经截断的候选帧；不能扩大解释为该人数的所有可行模式均已遍历。

## 分析中需要保留的限定

分层键实际为匹配方式、指定来源、单类／多类块、m；层内随机打乱候选，再按层轮换取到配额。具体有向类别对或计数变化没有独立配额，因此不能把各类别方向视为同样覆盖，也不能把所有事件直接当作人群中自然发生的频率。逐方法、人数、m、来源和块类型的真实支持已保存在 `BLOCK_SUPPORT_RECOUNT.csv`。

`m` 是实际人员替换规模，而 `changed_category_slots` 是两个构成向量 L1 差的一半，可小于 m。例如更换 4 个具体人，其中仅 1 个类别槽改变，仍是 4 人替换、1 槽类别变化。比较两类波动时应同时保留这两个规模。

B 和 C 的换入成员可以部分重叠，这不破坏 A→B／A→C 的相同 m 与共同 core。它也意味着 B、C 不是两次独立成员抽样结果；应按共同事件作配对分析，并在图片／建筑层汇总不确定性。

有 9,390 个事件把 A 中某类的全部原成员换出，但只有 6,596 个事件使某个原先存在的类别在 C 中完全消失。`replaced_entire_categories` 表示前者，不应标成“类别被彻底删去”。

77,232 个请求中有 259 行超出唯一团队计数；25,744 个事件中有 1 个超出唯一有序 A/B/C 三元组计数。共有 25,654 组不同图片内 core。大量不同 core 和团队依然来自相同的 51 张图片，不会生成新的独立图片支持。困难条件专门类别仅覆盖 10 图／4 楼／37 人。

不限制来源的 12,030 个事件中，A→B 有 3,488 个事件的新批人数改变，A→C 有 3,899 个改变。它们可以回答整体类别组合效用，但来源匹配分支及后续控制分析应单列，不能把批次人数变化悄悄归于类别。

## 复现与证据

`BLOCK_DESIGN_AUDIT.json` 保存所有输入、标签、生成器的 SHA256、全事件断言结果、方法支持、实际 m／类别槽变化、来源变化、重复和台账摘要；`BLOCK_SUPPORT_RECOUNT.csv` 保存分层支持小表。运行：

```bash
runtime_env/bin/python analysis/independent/audit_block_design.py \
  --expected-manifest-sha256 af2a6fa99bc45dba4d4241d669438b67cc2b01d5ba50e96032a24058d0d656b1
```

此审查证明请求的成员和比较结构与声明一致，不预先证明任何类别效用规律。规律仍需实际融合、方向与失败、不同具体成员和后续冻结规则复查支持。
