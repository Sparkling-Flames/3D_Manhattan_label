# 固定参考墙段覆盖与转角保留：定义、接口及边界

本模块用于补充解释最终融合 footprint 的结构差别。它不调用或改变冻结融合、不进入 B8L2／D10，也不是 N1，不是已经人工验证的“必要结构正确率”。所有参数于本模块编写时固定，未根据本轮新验证结果调参。

## 调用与主要返回值

```python
from geometry_diagnostics import diagnose

metrics = diagnose(
    row['geometry'].get('footprint') if row.get('geometry') else None,
    pool['reference']['floor_xz_h'],
)
```

两个输入均为同一冻结底面坐标系的 N×2 环序数组；不做对齐、重新缩放或参考更换。模式名称为 `fixed_reference_geometry_diagnostics_v1`。

| 字段 | 含义 |
|---|---|
| `diag_status` | `ok`，或 `missing_candidate`／`invalid_candidate`／`missing_reference`／`invalid_reference` |
| `diag_wall_coverage_03` | 距离容差 0.03×√参考面积的参考墙段覆盖 |
| `diag_wall_coverage_05` | 距离容差 0.05×√参考面积的参考墙段覆盖 |
| `diag_corner_recall_05` | 距离容差 0.05×√参考面积、参考转角大于 10° 的位置匹配率 |
| `diag_reference_area`／`diag_reference_perimeter`／`diag_reference_scale` | 固定参考面积、周长、√面积 |
| `diag_reference_corner_n`／`diag_candidate_corner_n`／`diag_matched_corner_n` | 过转角阈值的两侧角点及实际匹配数 |
| `diag_wall_details_03`／`diag_wall_details_05` | 每条参考墙的长度、覆盖长度／比例、投影并集区间、原始端点索引 |
| `diag_corner_matches` | 精确候选／参考角点索引、距离、两侧转角 |

批量小表可以仅保存状态、三个主标量、尺度和计数；代表案例保留完整明细，即可沿参考边把覆盖区间和未覆盖区间精确画出来。原始环的最后一个重复闭合点、相邻完全相同的点会被移除并报告数量；不修复自交，不移动点，不合并近似点。

## 墙段覆盖

对每条参考墙，使用方向的无向夹角：正向或反向同一条直线均为 0°。只接受与参考墙方向相差不超过 10° 的候选线段。

随后把候选线段逐点裁剪到参考墙支撑直线的 ±距离容差带内；将剩余线段投影到参考墙轴上，与参考墙自身的有限区间相交，并对所有候选贡献取区间并集。各墙被覆盖长度相加，再除以参考周长。

采用逐点距离带裁剪，原因是“只要候选两个端点都近才计入”的方法会受共线分点影响。当前方法对同一物理线段的精确共线细分不敏感，也不会因为多个候选贡献重叠而把覆盖数算到 1 以上。方向与距离条件同时满足，单纯穿过墙的垂直线段不计覆盖。

## 转角保留

转角定义为沿环走到该顶点时，入边方向转向出边方向的变化角；直线为 0°，矩形角为 90°。参考和候选仅保留该角严格大于 10° 的顶点。直墙新增的共线顶点不会增加角点分母或候选角点数量。

一对参考和候选角点只有欧氏距离不超过 0.05×√参考面积时才允许匹配。匹配采用严格的两级目标：先最大化一对一匹配数量，再在相同最大匹配数量内最小化总距离。实现用足够大的未匹配惩罚与虚拟列保证该优先关系，避免“先最小总距离、再阈值删点”降低本可匹配数量的问题。

当参考没有超过 10° 的角点时，转角匹配率返回缺失，另标 `diag_corner_status=no_reference_turn_above_threshold`；有效参考有角而有效候选没有角时，匹配率为真实的 0。无效／缺失几何的三个指标均为缺失，不能与后一种真实 0 混合。

## 确定性几何核验

`audit_geometry_diagnostics.py` 核验 12 个几何输入情形和 1 个独立匹配反例，结果均通过，完整输入与实际明细保存在 `GEOMETRY_DIAGNOSTIC_PROBES.json`。

| 几何情形 | 墙覆盖 0.03／0.05 | 转角匹配率 | 核验目的 |
|---|---|---|---|
| 完全相同正方形 | 1／1 | 1 | 基准 |
| 候选直墙加共线点 | 1／1 | 1 | 候选细分不变性 |
| 参考直墙加共线点 | 1／1 | 1 | 参考细分不变性 |
| 逆向、环起点变化、重复闭合点 | 1／1 | 1 | 表示变化不应改变几何诊断 |
| 参考凸出结构被省略 | 14/18／14/18 | 4/8 | 可定位被省略的凸起 |
| 参考凹入结构被填平 | 14/18／14/18 | 4/8 | 可定位被抹去的凹入 |
| 整体转动 5° 的正方形 | 0.685803／0.954519 | 0 | 容差影响及墙／角指标的不同含义 |
| 上述转动形状共线细分 | 与上行相同 | 与上行相同 | 倾斜但近似平行线段的细分不变性 |
| 上述候选和参考统一缩放平移 | 与上行相同 | 与上行相同 | 共同尺度及坐标原点变化的不变性 |
| 候选自交／候选缺失／参考自交 | 均缺失 | 缺失 | 失败不能补零 |

另一个点匹配例中，最小总距离分配后再阈值化仅保留 2 个配对；当前先最大匹配数量的实现正确保留 3 个阈值内配对，总距离为 8。此例检查算法目标，并不代表研究图片上的发生频率。

## 使用边界

墙覆盖只看参考墙有多少被近似覆盖，没有对额外墙或错误连接施加对称惩罚。转角匹配只使用位置，没有要求凸角与凹角类型一致、入出边方向一致或全环拓扑一致。因此墙覆盖高、转角匹配高仍不保证整个房间结构正确，应同时看冻结质量、omission／extension、失败、节点／连接及图像案例。

√参考面积提供共同尺度归一化，同样比例在更大房间对应更大的绝对距离；长窄房间、相邻墙很近、细小凹凸和非常复杂多边形尤其应检查局部容差。10° 转角门槛对近似弧形或多段微转折的表示仍敏感，目标数据的曼哈顿角形状更适合解释该指标。旋转 5° 的例子已显示，较宽距离带可给出高墙覆盖，同时所有角仍在角点容差以外；二者回答的是不同几何问题，不宜合并成一个总分。

指标只比较给定固定参考，没有判断某墙是否可观测、被遮挡、属门洞范围、处于 OOS 或是否应该由这份任务标注。也不检查高度和三维墙面的垂直变化。原图、任务资格、既有参考说明和人工案例确认仍决定这些几何差异的实际含义。

本模块无需重跑融合，可对已有最终候选几何后处理。它的参数与主评分必须在报告中分开列示，并保留无效／缺失率。
