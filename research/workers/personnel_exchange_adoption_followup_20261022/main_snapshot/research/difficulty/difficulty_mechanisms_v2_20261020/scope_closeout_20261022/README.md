## 1. 主观与客观分别承担什么解释

研究单位是“图片＋已固定目标范围／参考版本＋作答条件”，而不是脱离任务范围的图片固有难度。

|层次|可采用内容|不据此推断|
|---|---|---|
|客观结构条件|参考有效转折数、短边、几何自遮挡H、张角及归一距离可复算，解释本任务的结构和位置机会|它们不是RGB遮挡识别，也不直接等于人类推断难度|
|人工辅助粗难度|沿用已采用的简单／中等／困难裁定，以结构表达和定位推断负担组织样本|不是纯公式自动分类，也不要求所有图符合所有人的感受|
|人员条件响应|同人跨条件的变化、同图同参考下结构保留或位置分散，解释对谁难及发生什么标法变化|不由当图低Q、少点或融合失败反向定义难度或永久能力|
|质量及融合结果|在目标和资格相容时检验既定分类及结构条件与结果的关系，用原答和票账解释局部变化|不将后验效果作为贴标签的依据，也不把Q损失直接当作图片难度分|

6对点在无／较少妨碍定位的遮挡、结构线索较清楚时可属简单；不能用“超过4对点”自动判中等，也不能用“H>0”自动判困难。少量隐藏角是否明显增加推断负担、人工采用的边界判断允许有差异。现有等级是工作粗分，结构特征补充解释其组内机制，不宣称独立因果分解出图片和人员不确定性。

OOS、非正交、门洞和粗难度分开。非正交本身不等于不可标；实际用途继续服从已有OOS裁定及资格，不按名称补判。门洞交界描述目标和范围选择条件，不因照片里有门就自动认作门洞交界，也不自动认作困难。

## 3. 先固定范围，再解释难度和正确性

用户确认的裁切是**整个空间体的竖直边界裁切**，不是只裁BEV地面。范围采用、顶界是否能由既有证据确定、完整参考可用和某份作答的目标绑定是不同状态。新范围改变需要表达的转折或自遮挡条件时，旧范围分数不能直接证明新范围更容易。

从当前v2逐对象证据回读：

- 库存10439份／261图，非OOS研究库存9217份／233图；OOS记录不混入普通难度效果。
- 正式质量7302份均与证据中该图当前难度目标身份一致，且两层完整参考标志均为true；保留原用途，其中普通主Q6620、门洞571、其它特殊条件111。
- 另有242份绑定参考不同于当前难度目标，8份缺少参考或目标身份；均未纳入正式质量。这些可按既定资格研究表达，不能拿另一范围的参考分数解释当前范围难度，也不据此把另一标法判为人员错误。
- 对41张沿用“顶界待定”历史标记的新范围图，当前目标实际为12张完整参考可用、29张完整参考不可用。12张中已有采用既有完整几何的确定性参考；历史标记仍在，不是当前资格开关。**不把41张全部称仍待确认，也不宣布29张已补全。**
- 参考完整也不自动代表作答可用：非OOS中977份完整参考记录仍未获正式质量资格；个人排除、用途限制和目标绑定等既有条件继续保留。相同目标身份是可比的必要依据，不是额外几何语义正确性认证。

[逐份范围支持](record_scope_support.csv.gz)保留实际参考和当前目标；[分层支持表](scope_compatibility.csv)按条件、OOS／门洞、目标关系及原质量用途分开；[261图目标支持](image_scope_support.csv)显示参考多样性及实际目标完整性。表中图片可跨记录层出现，不将各层图片数相加成新总数。

门洞的面积分散仍只作为范围／尺度线索，不是选错率或scope问卷正确率。Manual和Semi效果分别评价；分类发现本身可按当前主模型采用单条件或联合历史，这不是本专题限制的对象。Semi高Q组合与门洞细机制支持较少，保留未知，不从Manual推广。

## 5. 可直接采用的结果解释

我们采用固定目标空间下的人工辅助粗粒度难度分层，同时保留可复算的转折、短边和几何自遮挡条件。固定6个参考转折时，三种结构条件的简化比例依次增加，同人跨条件比较也以简化增加为主；这支持结构条件对标法差异的解释，但不把几何自遮挡等同照片遮挡，亦不要求每个人或每张图方向相同。

相同难度或结构条件中的人员差异，可以经由局部结构支持或位置聚合产生不同的融合结果。Uw-22说明同一局部支持从3票降到2票可使结构失选；B6-48说明存在票和点数不变时，远端短墙仍对端点定位敏感。相同比例团队亦有正反结果，因此总体Q、困难图表现、局部表达与团队贡献分别采用，不以当图Q重定义难度。

上述结论仅在各自目标、条件和参考资格相容的面板内成立。门洞的范围选择、OOS用途、参考不完整与个人排除分别处理；可研究标法不等于可用于正确性评分。现有描述性结果及代表案例足以采用，全量RGB语义复核不是前置要求。
