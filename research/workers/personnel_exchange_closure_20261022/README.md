## 推荐采用

- Manual联合：n20/m4、较高历史Q且相对更快目标类，兼顾质量与记录时间；最高历史Q且较慢方向作为以时间换质量的另一用途。

类别按目标楼外历史形成，不按不同折编号硬拼。已有M/SP/A2/QTD/Rnew2/F01与跨条件方案保留各自用途；本轮不重新无限搜索类别。连续Q/T仍用于类内人员选择。
