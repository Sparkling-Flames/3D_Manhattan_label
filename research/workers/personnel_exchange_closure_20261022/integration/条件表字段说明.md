# 有效换类条件表：字段与比较口径

本表整合43个已完成条件：Manual联合20行、Manual结构14行、Semi联合9行。条件可以互相包含，不能把各行事件数相加作为独立证据量。每行保留原始表名及行键，完整逐事件表保留全部尝试和失败。

## 一、怎样读一行

`classification / input_condition / evaluation_condition`区分分类方法、形成类别的历史条件与实际评价条件。本轮三主线使用各自条件历史，Manual结构＋Q/T不等于Manual＋Semi联合历史。`class_level`保留逐折类数；类别编号不跨折直接对齐。

`n / m / replacement_fraction`分别为团队总人数、每次实际替换人数及m/n；`class_seat_change`为类别人数改变，`background_rule`说明共同D。严格ABC均为A=D+X、B=D+Y、C=D+Z，X/Y同类、Z目标类，三块人数m、相互及与D不重叠。

`source_semantics / target_semantics`解释楼外历史角色；具体成员以`class_members_reference`和`exact_events_file`为准。原类中心的角色与目标图片实际可用成员子集的均值可能不同，Semi保留了这种差异的检查字段，没有据目标结果重新分人。

## 二、质量、变化幅度与分母

| 字段 | 含义 |
|---|---|
| `Q_B_minus_A` | 同类换人后的Q变化 |
| `Q_C_minus_A` | 跨类相对原队的Q变化 |
| `Q_C_minus_B` | 跨类相对同类替换的净Q变化 |
| `Q_C_minus_mean_A_B` | C−(A+B)/2，减少源两块命名顺序对方向均值的影响 |
| `common_ABC_rows` | 三队Q同时可评的事件行数；Semi含互换A/B的两行 |
| `pairwise_Q_*` | 各对使用自身全部可评事件的均值，分母可能不同 |
| `D10_*` | 同样三个比较的D10敏感性结果 |
| `same_abs_Q / cross_abs_Q` | 变化幅度；具体跨类定义见`abs_cross_definition` |
| `Q_net_positive_images / ...known_images` | 图片层面C−B平均正向的分子／分母 |
| `Q_sym_positive_images / ...known_images` | 图片层面C−(A+B)/2平均正向的分子／分母 |
| `...positive_buildings / ...known_buildings` | 相应建筑层面分子／分母 |

三个有符号Q主字段使用同一共同ABC分母及同一层级权重，因此严格满足`C−A − (B−A) = C−B`。不应将逐对各自可用均值直接拼成这一恒等式。Semi保留A/B双方向，所以同类有符号均值约0是设计对称性；是否稳定仍看绝对变化，不能把0解释为换人没有影响。

Manual联合的跨类幅度为`(|C−A|+|C−B|)/2`；结构主线原表使用`|C−A|`；Semi双向平均等价于两源对称比较。各线的源人群与背景权重也不同，不能横向排名成同一个人员池上的算法胜负。

## 三、质量分项与几何

`components_contrast`明确该行分项是C−B还是C−(A+B)/2。`component_*`保存可直接读取的主要分项；原主题表保留每个分项的真实分母和其余几何指标。

- `IoU3D100`：相机高度归一的棱柱三维代理IoU×100，升高较好。
- `iou_2d`：底面IoU，升高较好。
- `S_bottom_deg`：底点角度误差，单位度，降低较好。
- `dir`：候选自身最佳正交轴残差，单位度；不是相对GT的整屋旋转误差。
- `Hmean / Hcenter`：冻结高度误差项，降低较好；不是平均高度本身。
- `omission / extension`：冻结遗漏／外扩项，降低较好。
- `nodes / fusion_turn_n / fusion_short_turn_edges / fusion_redundancy_n`：节点、有效转折、短转折边、近共线冗余数量，增减本身不判好坏。
- `ref_node_recall_5/9 / ref_edge_recall_5/9`：指定角度容差的参考几何召回，只是结构诊断，不替代原图语义检查；5°与9°分列。
- `height_mean_h / geometry_area_h2`：相机高度单位下的有符号高度／底面积变化，不等于误差改善。
- `top_y_mean_px / bottom_y_mean_px`：ERP上下界平均像素位置变化，受输出节点集合影响。

没有将原答整份9°/12°分簇与冻结融合内部的墙角对应参数混为一谈。

## 四、时间与失败

`time_source`均指已有库存记录秒数，按成员求和。不同来源混合、缺值或时间资格不符的比较不用于相应时间主结论。`time_contrast`保留各线真实聚合口径：

- Manual联合：C相对A/B记录时间算术均值的比值，再在既定层级取对数均值并转百分比；`time_C_minus_B_common_pct`另给共同ABC内C/B。
- 结构：同来源时间有效子集内C/B−1的层级平均；`time_images / time_buildings / all_time_rows`给真实支持。
- Semi：C/B对数比值的层级平均再转百分比，保留A/B双方向。

这些百分比是记录时间的组队比较，不是本轮实测生产工时，也不是预测误差改善比例。

`*_failed_unique_endpoints`统计实际不同融合团队；`*_failure_weighted`是事件按既定层级平衡后的失败比例，两者不能互相当分母。失败不赋0分进入Q均值。`loss_gt5/10_weighted`为可评分事件的明显损失，`loss_contrast`指明相对谁；Semi同时给原始不同B/C对的计数。缺少某字段保留空值，不能读成0。

## 五、覆盖与复现

`registered_event_rows`是登记表行数；`physical_ABC`在所列条件内按A/B交换等价计数；真正跨条件去重总量见`coverage/NEW_SCOPE_COVERAGE.csv`。Semi两行只代表一个物理ABC，结构人数/规模路径也可能复用原端点。

`observed_background_class_vectors / feasible_background_class_vectors`比较人数向量，不是具体成员穷举。`theoretical_unordered_XY_ABC_in_selected_cells`等大整数按文本保留，避免浮点精度损失。`finite_reservoir_member_enumeration_complete`仅表示冻结有限储备内部完整；`whole_personnel_space_exhaustive=False`明确没有将全人员池排列组合穷尽。

每行的`source_table / source_row_key / exact_events_file / capacity_reference`可定位原始统计、精确成员及未覆盖容量。条件表由`build_effective_conditions.py`生成，不新增融合或评分。端点全集按真实团队键去重，含全部失败；复现入口见`reproduce/REPRODUCE_ZH.md`。
