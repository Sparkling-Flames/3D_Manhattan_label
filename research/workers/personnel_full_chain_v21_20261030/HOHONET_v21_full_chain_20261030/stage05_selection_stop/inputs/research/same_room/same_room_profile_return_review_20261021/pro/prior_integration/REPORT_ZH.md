# 同房人数与停止研究：重建、增量实验及采用判断

## 最值得保留的结论

**同房源曲线可以帮助选择目标视角的人数，尤其值得保留“相同实际人员顺序”的历史；这一用途不能由个人质量预测的强弱替代。** 以源图整条曲线选人数，再在目标仅因几何不完整而补收，本轮从冻结的真实节点重新得到平均 **7.357 人、B8L2 87.764**；固定7人后按同一几何规则补收为 **7.029 人、86.958**。前者相对全共同池损失超过5分的比例为 **15.71%**，后者为 **18.04%**。这是6个全组共同人员池、24张普通Manual图、6栋建筑上，最大历史量 `m=N−1`、全部路径尝试的结果，不是7人必然足够的建议。[表：stopping_summary.csv；stopping_group_actual_m.csv]

**最需要补充的实际条件是：源历史已经存在，与为了少数目标新建历史，成本判断会反转。** 在同语义耗时完整的4个全新人员池、14图、4楼中，源曲线距峰2分规则的目标劳动仅为全共同池的47.55%；把获得全部源曲线的源图劳动计入，整组劳动却为全共同池的84.34%，为所有视角固定7人加几何补收的 **2.395倍**。它适合复用既有源经验；这批数据不支持专门为剩下少数视角先收齐大量源图人员、以节省整组劳动的主张。[表：source_acquisition_summary.csv；source_acquisition_project_cost.csv.gz]

**目标几何连续稳定也确有实用信息，但它可能稳定在错误的墙向上。** 本轮另取每支持池3条由固定哈希选出的已有顺序，原生重建全部几何。预先固定“最近四次输出完整同角点数、三次相邻环对应角距均≤2°”规则，未调阈值。全组24图的72条目标路径上，平均7.034人、Q85.573；同支持固定7人加补收为7.019人、Q85.988。两者相对全共同池损失>5分分别为16.67%、21.30%，平均Q与坏尾并未一致排序。G046-21在6人时已满足规则，Q70.07；全30人仍然只有6个节点，却提高到96.02。该负例直接指出了需要补充的判断：小幅连续变化与角点数稳定，并不能检查墙向是否已经正确。[图：online_geometry_stable_wrong_G046_21.png；表：online_geometry_decisions.csv]

## 5. 无目标GT的在线几何规则：新增实际实验

主重放表的全量几何指针指向未公开的运行缓存，只有点数、支持率和原答间差异，不能把原答R当作融合坐标位移。因此本轮对固定哈希所选路径重新执行原生融合，保存候选坐标，用真正的相邻融合几何计算绑定环角距。采用与冻结结构距离函数一致的做法：角点数相同才比较，环对应下逐角取顶/底角距的较大值，再求对应角平均；不以目标参考决定环对应。

这一机制比一句“在线停止不保证好”更具体：当前稳定规则检查的是**变化幅度**；它没有检查结果自身的方向结构是否合理。下一步更有价值的在线补充是冻结可观测的墙向/近共线残差或稳定的局部身份支持，并在新划分上比较，而不是在这条路径上反复改2°阈值。本轮没有按这一反例另行调出新最优策略。
