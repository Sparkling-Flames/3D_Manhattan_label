## 核心判断

现有证据支持保留连续 Q、分难度的部分池化效应、T 的成本含义和明确的支持度；尚不能把细分类解释为已经验证的可互换人员类型。质量选人优先研究连续 Q 与低尾风险；T 单独用于成本约束；风格/共同历史只作为有条件的换人兼容模式。不要直接把多个维度交叉成大量稀疏类别。未知、缺失和样本不足必须保持未知。

- 22 折独立矩阵求解复现 FE/joint20，系数误差 ≤2.29e-12。B8L2 总体相对误差改善 1.2643%，建筑重采样区间 [0.4393%, 2.0985%]；困难层 2.4561%，区间 [0.0995%, 4.5510%]。这是同任务同伴相对预测，不是绝对质量前瞻预测。
- 细类型相对 Q3×T3 未显示总体增益。可选 ridge5 与 ridge5_joint20 的全局收缩强度不同；独立 ridge15 对照纠正了这一点。主 FE/joint20 比较不受该问题影响。
- 原交付的逐 k 换人背景通常没有跨 k 嵌套，不能单凭这些比较推断整条人数曲线保持不变。
- 本次新实验明确固定跨 k 背景和替换三人组，k={8,12,16,24}；预选 52 池，其中 1 池在结果产生前无可行三人组，实际执行 51 池、22 栋建筑、261 组三元比较、3,132 请求。实际新鲜融合 2,300 个唯一团队，832 个重复请求复用；3,117 请求可评分，15 个因几何状态不可评分，执行异常为 0。失败计入稳定性分母；连续分数只在两臂整链均可比较的成对样本上计算。
- “整链稳定”要求四个 k 的两侧输出均完整，且每个 k 同时满足 |ΔB8L2|≤2 分、底面 Jaccard 差（1−IoU）≤0.05、节点数相同、绑定顺序循环匹配结构角差≤3°。因此下列百分比是同时跨过所有条件的整链比例，不是平均分相近比例。
- 整链主阈值稳定率：QT 同类 47.73%、跨类 42.80%，跨−同 −4.92 个百分点，95% 建筑重采样区间 [−13.64, 3.41]；QTD 同类 46.59%、跨类 40.91%，差 −5.68 个百分点，区间 [−14.39, 2.27]；共同历史相近 54.37%、较远 40.87%，差 −13.49 个百分点，区间 [−31.75, 3.17]。全部区间跨零，不能宣称已验证的类别效用。
- 共同历史是成对关系而非全局类别；不同方法选择的三人组不同，不能直接以这些数值给方法排名。建筑 bootstrap 固定训练画像与实验选择，不包含重新拟合、模型选择或未来人群不确定性。

## 建议采用的两层工作方式

第一层处理质量和成本：连续 Q、困难层部分池化估计及低尾风险用于质量判断，T 用于时间成本；保留来源、任务/建筑支持数与未知状态。第二层处理具体任务下的替换兼容性：结合共同历史、风格关系、当前背景与投票边界，评估换人后整条曲线的变化。第二层目前是待验证的条件关系，不能替代第一层，也不构成固定人员类型。

## 事后投票边界诊断

`curves/VOTE_GATE_SUMMARY.csv` 和逐曲线明细记录事后划分：四个 k 均远离一票阈值，或至少一个 k 接近一票阈值。QTD 在远离阈值组的同类稳定率为 65.91%、跨类 45.45%，差 −20.45 个百分点，条件区间 [−32.95, −9.09]；近阈值组方向反转且区间跨零。这是观察到结果之后形成的诊断性分层，使用当前任务的投票结构，未作选择/多重比较校正，不能解释为已验证的因果机制、预先可用的选人门槛或新的确认性类别效用。应在独立数据中先冻结规则再验证。

## 实际通过的检查

1. 四原始 ZIP 的大小、SHA-256、全成员 CRC、路径安全检查，以及 2,567 个清单文件的大小与 SHA-256。
2. Git 对象哈希与树重建、731 个冻结源文件核对，四个官方子树核对。证据字段另行重计，保留来源级别、支持度及未知。
3. 独立 Q/难度矩阵和 T 拟合；实际重跑核心画像、细类型、231 组双建筑排除特征与相应审计/信息量对照。关键 10 表容差 1e-9 内一致。核心运行跳过旧版本 LOBO 预测序列，部分其他展示/效率/房间加权脚本未运行。
4. 全 10,439 条冻结几何记录：9,363 完整、941 仅底面、135 不可计算；519 初始分数重放。B8L2 最大误差 1.71e-13，D10 1.85e-13。使用原评分实现，不是独立评分算法，也不重建采集及先前人工审核。
5. 167,581 旧请求、1,161,631 比较行的账本关系；50,291 前向/构成定义重生；独立条件回归；63 个旧团队新鲜融合/评分。三个紧凑状态仅有 1.78e-15 量级诊断角舍入差，其余几何/成员/拓扑未见差异。
6. 原展示载荷的 DOM/native-canvas 检查通过（详见 presentation/VIEWER_QA.json）。真实浏览器布局检查受连接/URL 策略阻塞，未通过也未绕过；不声称移动端布局或完整无障碍测试完成。
