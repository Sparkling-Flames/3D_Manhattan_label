# Analysis notes recorded while the frozen requests are running

1. Registration and DESIGN were saved before any new fusion. No pool, identity, request, or threshold is changed based on outcomes.
2. The generator selects one pool per eligible building×difficulty stratum by a fixed SHA256 order. Two backgrounds are sampled before methods select triples; thus all methods in a context use the exact same nested background, although their outgoing/incoming identities can differ. Methods are not directly paired on identical swapped identities.
3. a is shared as outgoing person in the near/same and far/cross contrast. b/c have equal input point counts and building-held-out predicted Q within 3 points. a need not have the same point count, but both contrasts consequently have identical changes in point-count histogram.
4. Source input point count and observed availability are target-task information. Therefore the experiment evaluates personnel compatibility conditional on an observed, same-point-count replacement opportunity; it is not a pure precollection assignment policy.
5. History compatibility is a pair relation, not a global hard worker class. QT/QTD are genuine training-derived labels. A positive pair result alone cannot validate a global class system.
6. Before reading any numerical study output, analysis code was clarified so continuous quality comparisons use experiments where both same/near and cross/far four-k chains have all scores. Failures remain in all unconditional stability analyses; no missing score is assigned zero. The running process initially loaded the earlier summary function; the final summarize stage will be rerun using the clarified version.
7. Main geometrical tolerances and stricter/wider sensitivities are inherited exactly from compare_fusions.ComparisonPool.pair: strict=(1 B8,.02 Jaccard,2 degrees), main=(2,.05,3), wide=(5,.10,5), all requiring equal nodes and complete outputs. This supersedes the broad earlier provisional protocol's tentative sensitivity grid.
8. Building bootstrap conditions on fixed trained profiles and fixed selected experiments. It does not resample/refit training or establish performance on genuinely unseen future data. Difficulty-stratified outputs are descriptive and may be thin, especially history/hard (8 experiments).
