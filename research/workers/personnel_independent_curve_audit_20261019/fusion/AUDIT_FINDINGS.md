# Independent personnel-v2 fusion audit

## Verified outcomes

- All 167,581 registered requests match actual result membership. There are 144,253 distinct team IDs, 162,825 score-available requests, 1,624 N2 policy-deferred requests and 3,132 other unscored requests. The latter are 2,042 no-connection, 1,044 below-four-node and 46 invalid-floor cases. Unique-team complete geometry count is 139,730; this is not human ring approval.
- All 1,161,631 saved comparison rows agree with request-result team pointers, score availability/deltas, member overlap and declared joint-stability threshold. Maximum difference from recomputing score subtraction is 2.94e-14. All 370,490 replacements have the same exact k-1 background and two different single entrants. All 50,460 prefix transitions are nested additions.
- Cross-k replacement backgrounds are not nested designs. Among 2,484 same-pool/same-draw larger-k background comparisons, only 34 are accidentally nested. These panels cannot establish that replacing a given person preserves the entire cumulative curve.
- All 50,291 forward/composition request definitions regenerated exactly from the heldout-building profile table. All 270,370 distinct ordinary swap event labels (Q2/QT/difficulty/fine, B8 and D10, both entrants) match the appropriate target-building-excluded profile rows. All entrant equal-point-count flags agree with frozen pool inputs. Upstream profile fitting is not independently refit by this worker.
- The k16 fixed-composition headline numbers reproduce from raw comparisons with image-then-building equal weighting: Q2/QT/QTD mean absolute score change 3.34865/3.04849/2.50323; joint stability .64962/.64759/.69624. Shared-member proportions simultaneously increase .72129/.75577/.79875. Smaller class-conditioned variation cannot by itself identify interchangeable people.
- Independent weighted within-stratum regression refits reproduce all 18 all-k conditional-difficulty coefficients within 1.2e-15. Strata fix pool/reference, k, background, entrant point count and concrete QT parent. For merged-fine labels the cross-vs-same absolute score-change association is .22296 unadjusted, .11705 after continuous Q, .14331 after Q and T. For raw difficulty type it is .06678, -.02635, -.01614. These are observational diagnostic associations, not causal category effects or evidence of whole-curve equivalence.
- Direct fresh fusion and scoring on 63 selected saved teams cover every ordinary building plus layer/status cases. Score availability agrees for all; score error at most 2.85e-14. Sixty compact states are exactly equal; the other three each differ only in one diagnostic maximum_bottom_angle by 1.78e-15. No candidate geometry, membership, connection or topology difference was found.

## Reusable strict-nested experiment components

Frozen INPUT_SNAPSHOT.json.gz supplies real worker IDs, processed point pairs and ring order, pool/reference identity and original costs. fold_profiles.csv supplies target-building-excluded Q/T/difficulty labels and continuous traits. fusion_engine.fuse and compact provide unchanged actual subset fusion; compute_score applies frozen scoring; compare_fusions.ComparisonPool provides geometry, structure, shared-identity and failure outcomes. These functions can be imported, but redirect all output-module OUT variables into a new directory before invoking mutating runners. Do not use archived caches as fresh recomputation evidence.

For a strict curve test, freeze an ordered background chain excluding all compared entrants, evaluate exactly B_(k-1)+a versus B_(k-1)+b at every declared k, and retain the identical chain across swap alternatives and k. Choose entrants/labels using training-only data, match or adjust continuous Q/T and point counts, report failure-inclusive joint curve stability as well as continuous score/geometry differences, and aggregate at image/building level. Per-k independent background results and fixed-composition multi-person comparisons remain separate supporting evidence.

## Reproduction and boundaries

Run audit_ledgers.py, replay_registration.py, audit_label_adjustment.py, replay_saved_teams.py, explain_state_roundoff.py and replay_pair_metrics.py in this directory. For geometry scripts prepend the audit runtime_deps directory to PYTHONPATH and set OPENBLAS_NUM_THREADS=1. Scripts read frozen extracted files; all written artifacts remain here. Registration replay writes to registration_replay only. Inputs and repository files were not changed.

Detailed JSON outputs preserve exact sample identifiers, denominators, tolerances and mismatches. The sampled fusion replay is not a replay of all 144,253 teams, an independent recreation of original data collection, or semantic certification of annotation rings.
