# 发现阶段 F／R 配对判据独立审查

## 审查范围与真实支持

只读取 `discovery/forward_metrics` 和 `discovery/reverse_metrics`，没有读取其他 assessment 输出，没有改变分类、参考、资格、融合或评分。输入共 62,610 个正向事件和 33,468 个反向事件。每个同图、同参考、无向实际团队对只计一次；不同方法或不同方向再次引用同一对不会增加独立支持。

正式 n≥3 部分有 185,474 个不同 A/B 或 A/C 几何对，来自 **55 张图、62 个池、6 栋楼**，其中 183,466 对双方可评分。把实际 B/C 对也计入方向检查后，共 277,882 对，274,804 对双质量可用。另保留 n=2 的 4,941 个几何对、7,325 个质量对，均不混入正式通过率。图与池不同，是因为同一图片的条件池需要分开。

跨方法、方向和路线重复的配对指标全部一致，最大浮点差 `2.84e-14`。另外选取 16 个展示对，从保存的原生最终几何重新调用冻结 pair API，指标全部一致；这里没有再次融合或重新评分。完整收据为 `PAIR_METRIC_AUDIT.json`，源文件 SHA 与边界为 `METRIC_AUDIT_SPEC.json`。

## 三种口径的分歧

下表是去重后的实际对数，不能当作独立图片数。它是判据敏感性审查，不是类别优劣排名。

| 情况 | 不同团队对 | 覆盖图／楼 |
|---|---:|---:|
| 旧主判据通过 | 117,692 | 55／6 |
| 去 Q 的旧几何判据通过 | 147,419 | 55／6 |
| 新 shape 并列判据通过 | 143,084 | 54／6 |
| 旧主不通过、去 Q 通过 | 29,727 | 52／6 |
| 去 Q 不通过、新 shape 通过 | 2,163 | 35／5 |
| 去 Q 通过、新 shape 不通过 | 6,498 | 55／6 |
| 原始节点数不同、新 shape 通过 | 405 | 13／4 |

旧主判据通过一定蕴含旧 noQ 通过，此逻辑在全部配对成立。新 shape 既接受一些旧口径排除的几何，也排除一些旧口径接受的几何，因此不能称为统一放宽阈值。

一个明确的节点冗余例是正向事件 `I20_06baf814f0f5e559c999f2`，`e9zR4mvMWw7-39`，n=8、m=1。实际两队原节点数差 1，但 floor 的 `1−IoU=0.000609`、真实转角 F1=1、双向墙段覆盖接近 1、B8 分差仅 0.0136。旧 main 和 noQ 因节点数条件不通过，新 shape 通过。反向同构成例 `I20_8523e3ff6b5ff480f69095`（`jtcxE69GiFV-26`，n=26、m=1）也有节点差 1、真实转角 F1=1、floor 差 0.00332。它们只用于说明诊断定义，不能据此把单人替换恢复为研究主单位。

新 shape 不通过而旧 noQ 通过的对中，有 6,103 对真实转角 F1 小于 .95、2,101 对墙段覆盖小于 .95；两种原因会重叠。各原因和完整混淆表见 `GEOMETRY_FLAGS.csv`、`METRIC_CONFUSION.csv`。

## bottom-y 和三维可观测性

有 **2,062 对／53 图／6 楼**通过新 shape，但平均高度棱柱 proxy IoU 小于 .95；没有一对低于 .90。全部 185,474 个正式几何对都不满足已识别的平顶棱柱条件，因此精确平顶棱柱 IoU 全部是缺失。不能将 proxy 改称完整房间三维 IoU，也不能把这些缺失记为零。

例如反向 `I20_a5a4075419c797a8a55106`（`e9zR4mvMWw7-02`，n=3、m=1），新 shape 通过、bottom-y p95 为 0.753°、top-y p95 为 2.777°，但 prism proxy 为 0.9197。它展示角度容差与深度／高度变化的不同含义。

shape 使用 p95 不是最大误差：6,308 对通过 shape 而 bottom-y 最大差超过 3°，7,092 对 top-y 最大差超过 3°。另有 5 对／5 图／3 楼在通过 shape 时，边界总高度比的 p95 变化超过 10%。这些是局部或三维诊断提示，不是新的自动失败标准。原始 max、p95 和高度比应随代表案例一起看。

## D10 与 B8 的方向

在 274,804 个双质量可用的不同实际对中，**11 对、5 图、3 楼**存在实质反向：B8 改善至少 2 分而 D10 下降至少 2 分，或者相反。精确记录全部保留在 `D10_MATERIAL_DIRECTION_REVERSALS.csv`。另有 11,322 对是一种口径越过 ±2，另一种仍在 ±2 以内；整体方向通常相近，具体阈值分类不完全相同。

最大展示例是正向 `I20_3524c885bd612776a70253`，`yqstnuAEVhm-01`，n=7、m=3 的 B/C 对：按文件中明确的 canonical team 顺序，B8 为 +2.2019，D10 为 −4.0022。canonical 顺序只是为了对称去重；解释“换入类别变好还是变坏”时，应按原事件 B→C 顺序恢复符号。

## 如何使用审查结果

保留原主判据作为跨方法主比较，noQ 与 shape 并列说明它为何通过或失败。一个分类可能主要维持 Q，也可能维持几何，二者需要分别陈述。原节点数不同不等于几何必然不同；同节点数、近 Q、甚至 shape 通过也不等于三维和局部结构全部相同。`EXAMPLE_PAIRS.json` 包含精确人员、团队 key、原生文件路径和独立重算值，可直接定位人工看图案例。
