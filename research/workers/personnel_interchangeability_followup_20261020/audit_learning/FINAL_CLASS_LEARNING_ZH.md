# 人员分类代码审计与有限追加实验结论

## 结论

原始 Rnew2 的35人、21/14二类已从原始输入及新重建的历史融合结果独立复算，完整标签与10次留一建筑标签全部一致，平均 ARI=0.95496594。这个 ARI 说明划分对删除历史建筑较稳定，不等于所有同类人员均可互换。

新增的连续角点距离 m1 学习，及专门使用真实多人块结果的 m2 学习，都没有建立优于现有有效基线的实用通用分类。冻结的 legacy meanK3 在共享 m2 测试上未优于 Rnew2；新的直接 m2 K2/K3 在历史留建筑验证中也同时输给 Q 与 Rnew2，而且完整有效距离覆盖与角点数量变化风险更差。因此不采用新模型来宣称研究目标已完成，也不继续搜索直到出现好看结果。

## 已测条件与未证明事项

Rnew2 的训练域为普通 Manual、替换人员均为新来源，替换前后固定图像、参考和背景。类内仍存在明显风险，原始历史内层验证的宽阈值坏结果约21.4%；Q 与分类显著相关，不能把“学习时未直接输入 Q”说成“排除了 Q”。F01 的主要冻结方向为普通 Manual、n=13、m=2、C02→C01；几何分离较弱，不能把效率收益变成结构等价证明。

历史/发现/评估建筑分组代码未发现直接目标泄漏，但发现用于选方案、既有评估已反复用于研究，均不能重新称为独立盲测。481,998 是共享端点和建筑的历史成对观测数，不是独立样本量；1,808 是尝试的反向定义数，不是全部成功且独立的分类。

Scope 只能支持响应倾向描述，不能推断域外识别准确率。Semi 旧来源确认错误和新来源报告错误的证据级别不同；编辑不等于修正、不编辑不等于盲信。条件数据不足时保持 unknown，不推断人的能力或态度。

新直接 m2 模型的平均留双建筑 ARI 仅约0.036（K2）、0.141（K3），成员不稳定。研究工作标签因此保留原始 Rnew2 与 F01 两个独立、带条件的参照列；新模型所有成员、失败、负结果和控制均保留在实验目录，可复查但不推荐采用。
