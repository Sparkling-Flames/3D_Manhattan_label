## 2. 分类具体怎样形成

### 2.1 把“人的倾向”与“本来就不同的图片”尽量分开

1. 结构特征先减去**同图、同条件、同参考、同层**人员的中位数，得到每份原答的相对表达。
2. 先按个人在每栋建筑内求均值，再建筑等权形成个人历史，避免某栋图片多就主导类别。
3. 转折代理是上下点对数减去底面转角≤5°的节点数；短转折边沿用周长占比<4%、两端转角均≥15°的几何定义。
4. 结构条件C按同图转折中位数划分：<6为简单结构机会、≥6为复杂结构机会。**C不是主线人工图片难度D**。之后的难度结果仍要接回既有难度版本。
5. 联合类的Q来自本条件合格质量记录，相对同图人员均值；低尾差为个人历史均值与低端表现的距离。T为本条件记录秒数取自然对数，再在同图、同来源、同时间口径内中心化。

几何建类使用可比较的普通原答历史。带GT问题的记录可在原资格允许时提供结构行为信息，但无正式质量分；行为可观察、可评分、可投票是不同资格。标签本身不恢复任何被排除作答的投票资格。

### 2.2 用什么算法、为什么是这些类数

算法是**稳健标准化后的Ward层次聚类**：各字段减人员中位数、除四分位距；四分位距退化时用标准差，再退化用1；标准化值截断到±3。每个特征域等权，域内多个字段分摊该域权重。Ward逐步合并相近人员，形成一棵树，再比较切成不同类数的结果。

候选不限三类。数学搜索范围由库存62人、每类至少3人给出K2—K20，本轮实际可支持的切割最高到K11。至少覆盖90%基础支持人员，且至少80%内侧楼折、最低5折具有足够类别容量。可用候选中按**内侧留楼重构误差最低**选择输入族与细类数；同一棵树上，选择与最佳细类误差差距落在配对一个标准误内的最小粗切割。因此Semi结构留下3粗4细，其余没有新增细层。

两类选型目标需准确区分：

- **结构类**：重构留出建筑的原答转折、短边、近共线节点、面积和高度残差。损失权重依次1/6、1/6、1/3、1/6、1/6。它没有使用Q/T作为聚类输入或选型结果。
- **结构＋Q/T联合类**：重构原答转折、短边、面积、高度、Q和T。前四项各1/8，Q和T各1/4；目标项缺测时按可用项重新归一。这确实包含质量与时间用途，但**没有用本轮新团队融合的升质幅度来形成类别**。

全数据切割与选择账已重新核对，见 `CLASSIFICATION_K_SELECTION.csv`。本次提取核对了保存的选择账与标签，不声称重新执行了上游全部嵌套拟合。类数的实用性来自后续原答、配比、替换及人数比较，不由“Ward能切出几类”单独证明。

### 2.3 图上中心数值怎么读

`CLASSIFICATION_CENTERS.csv`保留原中心字段与原量纲，是**个人建筑等权历史的成员均值**，不是重新标准化的雷达图分数。

- Manual结构M1/M2/M3的复杂机会转折残差约为−2.372／−0.550／+0.791个，而简单机会约+0.042／+0.068／+0.319个：差别主要在复杂结构机会。
- Manual联合J1/J2/J3的历史相对Q约−3.74／−3.70／−3.22分，但时间残差约−0.650／−0.076／+0.099，复杂转折残差约+0.280／−0.650／−2.372。因此它们不是把质量排序切成五档。
- Semi结构S1.1/S1.2/S2.1/S3.1的转折残差约−0.350／+0.087／+0.042／+0.444；S2.1的近共线残差约+0.162个，其他三类约+0.006／+0.001／+0.014个。重点是表达种类的差别。
- T中心是对数残差，负数表示相对同来源常规记录更短。`exp(中心)`仅为相对几何时间尺度的解释，不直接等于某张图、某支团队节省的秒数或百分比；实际团队时间效果另读共同时间域结果。

`is_training_input=true`只标记所选族实际聚类输入。其他字段是辅助解释；未知组即使有少量残存观测均值也不画成正式类别中心。不将结构数量、Q分数、对数时间塞进一条没有解释的统一数轴。

## 3. ALL与楼外名单：两种视图都需要

**ALL描述名单回答“这些人目前总体分在哪类”。** 它用全部可用历史形成，便于逐类看人、看中心与名单。不能把ALL名单用于目标建筑后再称楼外验证。

**LOBO回答“排除目标楼后，类别还能解释该楼上的变化吗”。** 例如评价建筑A，A上的历史记录不用于人员特征、标准化、聚类及内侧选型；只使用这些人在其他建筑的历史。A的配比和替换实验固定A专用标签。LOBO不是同房预测专用名单，也不是对陌生人员的预测。

不同楼折可以选择不同家族、类数和成员集合。M3、J5、S1.2等编号不保证跨折含义相同；须按训练中心的语义角色对齐。当前同房大块的V3_BEHAVIOR可能为TURN2、TURN3、结构JOINT4/5；这里的结构JOINT不等于V3_JOINT_QT。

研究台默认展示ALL中文类名＋编号＋人数；一旦进入具体实验，应切换到“目标建筑专用楼外名单”，显示heldout_building、家族、类数、实际角色和成员。不要将ALL类别中心随手贴给任意楼外实验类号。

## 5. 跨条件及其他历史方案放在哪里

Manual与Semi结果分别评价，不妨碍用两条件历史共同形成类别。既有XCOND_GEOM、XCOND_GEOM_QT、XCOND_PAIRED已作为独立跨条件候选保存；目标楼应在两条件历史中都排除。本F1四套中，两套联合类均为**自身条件的结构＋Q/T**，不是跨条件建类。

Q、T、人工难度适应D、scope倾向／裁定正确率和Semi初始化编辑仍有用途：一部分在旧多域分类中是真实输入；在当前四套中，D、scope、初始化行为主要作为有支持时的辅助解释。不同支持量与资格继续保留，不把“没有足够初始化记录”解释成不编辑，也不把scope倾向直接解释为答对率。

旧M、SP尺度、A2关系、QTD、F01和跨条件方案维持各自独立实验身份。当前四套服务主文叙事，其余通过方法覆盖表说明用途和正负发现，不因未放主图而删除。
