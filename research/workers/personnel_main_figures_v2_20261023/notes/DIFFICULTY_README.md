# F4：图片难度怎样改变人员类别的表达和构成作用

## 主线讲述顺序

**先固定人员类别，再沿用已有人工图片难度，观察类别差异何时进入原答、构成分布与融合结果。** 这三个观察层对应 F4a、F4b、F4c；不把低 Q 重新命名为困难。

1. **怎样标：** Manual 的高历史转折角色与低角色，在简单图实际转折差很小，困难图明显分离；它说明结构分类有可解释的条件表达。
2. **怎样波动：** 固定 n=20，困难图既有更大的配比格间差，也有更大的同配比成员波动。类别与具体人都重要。
3. **往哪类换：** 同一历史角色方向可随难度反转。升质、省时并非唯一有用结果；降质、费时和几何来源不同也是主发现。

本图复用已核真人 v2 保存结果。没有新增融合、评分或拟合。Manual 和 Semi 分面呈现；门洞、OOS 不纳入这三幅普通图比较。门洞人数过程由人数曲线图单列。

## F4b：配比格间差与同格成员波动一起看

数据：`data/DIFFICULTY_MIXTURE_SPREAD.csv`、`DIFFICULTY_MIXTURE_IMAGES.csv`；失败：`DIFFICULTY_MIXTURE_FAILURE.csv`。

**主图推荐：** `condition=manual, method=V3_BEHAVIOR, tier=coarse, n=20, metric=B8L2`；并列两组点/柱：

- `measure=cell_mean_span`：一个面板内不同可评配比格的 Q 均值最大值−最小值，回答改配比的分布跨度。
- `measure=median_within_cell_iqr`：每个有≥2个可评团队的配比格先求 Q 的 P75−P25，再对面板内这些格取中位数，回答固定配比后换具体人仍有多少波动。

|Manual n20结构粗类|简单|中等|困难|
|---|---:|---:|---:|
|格均值Q跨度|1.771584|2.874204|11.241224|
|典型格内Q IQR|1.595061|5.082039|9.985468|
|支持图／楼／面板|21／21／39|3／3／6|14／14／28|
|全部尝试失败率，楼等权|0.7859%|0%|1.5074%|

细类完整结果作为附图/切换项保留：对应 Q 格间跨度为1.711140／2.874204／11.984327，格内 IQR 为1.583012／5.082039／9.967484。**主图用粗类即可讲清两层不确定性；细类结果不冒称细分增益。** 人工中等组仅3图，显示支持即可，不抹去该层。

每面板固定其实际背景和12人候选集，12选6的924支团队完整枚举。全队20人并不意味着所有20人任意组合已穷尽。先算面板尺度，再面板→图→楼等权；不同指标只在有值单元参与。`*_valid_*` 已核，导出统一为每个 measure 独立的 `images/buildings/panels`。`cell_mean_span_ge10` 仅保留每格≥10个可评团队作支持检查，避免极小格影响跨度。

这些量不是同一统计定义，**不能用两个柱高之比称为“类别解释了多少方差”**，也不是某个定向换法可以提升11分。另有总体方差分解时继续按其原身份解读。

Semi n20结构粗类简单支持9图7楼；中等仅1图，只有一个可用粗配比格，格间跨度是 NA（无法估计），格内 IQR 仍可计算。细类中等可描述格间差，但只有该一图。Semi 困难没有当前面板支持。不要把粗类 NA 画为0，或由 Manual 推出 Semi 困难趋势。

失败表从相同面板全部团队另算，未把不可评分团队填 Q=0。`team_appearances/failed_team_appearances` 是跨面板团队出现次数，同一团队可重复，不能当独立样本。主图小注用 `building_equal_mean ×100`；`pooled_failure_rate` 只供追溯，不能与楼等权率混用。
