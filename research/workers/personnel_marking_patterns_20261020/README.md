# 人员具体怎样标：v2 标法解释与实例

2026-10-20。当前入口：[离线叠图页](index.html)、[逐例解释](CASE_NOTES.md)、[关键图表](figures/pattern_summary.png)。

本轮负责解释实际作答，与 Pro 的分型搜索互补。沿用 R5/H2、Rnew2 冻结标签，不重新搜索类别。研究对象从全部非 OOS 图片开始，门洞交界单列；参考有问题的图片继续观察标法。所有人员标签只是已有候选，本文描述性结果不是新留出验证，也不建立新的质量或排除规则。

## 先看五条发现

### 1. R5 的区别主要体现为保留短墙转折，不是普遍增加共线节点

普通 Manual、同图同参考且双方至少两人的 192 图、22 栋建筑中，R5 六人相对其余人员：

- 每图平均多 **0.562 个上下点对**；
- 多 **0.329 条短转折边**；
- 少 **0.024 个近共线节点**。

这里的短转折边要求长度小于底面周长的 4%，且两端方向变化均至少 15°；近共线节点用 5°，另保留 3°、10°结果。它们描述几何，不自动判定真实、必要或正确。一个真实局部结构也可能没通过这个长度阈值，例如 M01 的部分六点对作答。

跨图重复并非只由某一人带来。R5 六人普通 Manual 的平均点对数都高于同图、同条件、同参考的人员中位数；按建筑求均值，增加方向分别覆盖 11、15、16、16、15、17 栋建筑，减少方向仅 W126 有 1 栋，其余为零，余下建筑平均持平。这支持“在所做图片上重复出现的表达倾向”，尚不等于每个真实细节都会保留。

### 2. “保留结构”有正例，也有明确的类内反例

**M02：yq-01 的左右墙面转折。** 原图可见左侧壁炉旁墙面变化及全景最右侧不显眼的变化，已有图级审核也明确指出这些结构。六名 R5 在 Manual 均表达为八个点对；其余人员中既有保留者，也有四点对简化者。M02 单人图直接对照 W130 与 W100，避免仅凭线条密度作判断。

**M01：pRb-12 的真实凸起、参考省略。** 左侧白色竖向凸起可在原图、局部放大中定位；用户确认GT没标这个墙角，蓝色展示另一种标法类型。本图被用户排除的GT错误是把木质装饰误作天花板，原因不是墙角漏标。R5 只有 W115、W122 两人把该处展开为多个局部点对，其余四人仍采用四点对表达。这 35 份都不进入正式质量评价，但完整纳入标法研究。不能把它写成“R5 都能发现 GT 遗漏”。

**M03：Uw-22 的近处墙体转折。** W122、W115、W112、W130保留，W126 简化；W109 没有本图作答，不算遗漏。W115、W122 在 M01/M02/M03 三张不同建筑图片都表达相应转折，W126 则在 M02 保留、M01/M03 简化。因此目前更适合用“个人倾向 × 结构条件”解释，而不是给整类一个无例外名称。

### 3. 候选类别外还存在“墙面内分段点”和“较低顶界”两种值得跟进的表达

**W037：墙面内分段点。** 普通 Manual 的 95 份未见坐标修复、单人不重复的可计算观察中，19 图、10 栋建筑出现至少一个 ≤5°近共线节点。进一步只看既有独立作答资格，仍有 12/72 图、7 栋建筑。M08 的两个额外节点位于玻璃面板附近，底面几乎沿同一直线；与 W130 的四点对表达相比，它们没有产生新的底面转折。按“布局折线表示”可称几何冗余，但不能因此将整份作答判作误标，也不能把真实可见的材料分界当成不存在。原始导出点可在离线页打开核对。

**W030：较低顶界的重复倾向。** 普通 Manual 96 图中，80 图的推导总高度低于同图同行中位数，15 栋建筑的平均方向均为负，平均 log 高度差约 −0.030。M09 为更清楚的实例：四点对数量相同，W030 的顶点平均图像 y 比 W122 大约 34.33 像素（更低），底点平均 y 只差约 4.14 像素。原图中蓝线更靠近玻璃隔断上缘，而参考和 W122 更高。该例支持“边界选择差异”的解释；全库较低高度还可能受底界定位与投影距离影响，不能把 80 图全部命名为同一种顶界错误。

### 4. 范围选择和局部定位应分开；门洞会放大范围差异

M04（7y-13）中，W008 将走廊一端停在较近位置，W001 延伸到远端；两人都是四点对，所以点数无法表示这个差异。已有评论明确将 W008 记录为停止范围不同。M05（jtc-12）中，W108/W036 主要表达左侧入口区域，W115/W122 延伸到卧室区域；这是门洞交界下目标范围选择，不能直接按更大面积判优。

R5 相对其余人的底面 log 面积差，建筑等权在普通 Manual 为 **+0.024**，在门洞交界为 **+0.349**（13 图、9 栋建筑）。Rnew2 C01−C02 在门洞为 **+0.408**（17 图、9 栋建筑）。面积本身只能作定位线索，可能混合范围、底界位移、近地平线效应；本轮只在有原图/评论支持的实例上解释为范围差异。

### 5. Manual 的结构倾向没有直接迁移到 Semi；“改了”也有不同方向

跨条件配对得到 496 个同人、同图、同参考的作答对，涉及 37 人、25 图。进一步要求同一图片中 R5 和其余人员各至少两人，保留 23 个目标面板，并在两条件中固定同一组人员：

|同一组人、同图、同参考：R5−其余|Manual|Semi|
|---|---:|---:|
|平均点对数差|+0.418|−0.099|
|平均短转折边数差|+0.247|−0.079|

这比直接比较不同图片集合更能说明条件依赖，但仍不是随机实验；任务先后、模型初始化与来源批次没有被随机控制，不能据此声称模型导致人格或能力变化。

M07（yq-01）有逐份初始化支持：W034 将八点对改为四点对，移除了左右局部结构；W028 修改坐标但保留八点对。两人都“编辑过”，行为却不同。另有同一新批人员在本图 Manual 为四点对、Semi 为八点对（例如 W100、W103、W125、W128）；新批缺逐份初始化，不能进一步断言是主动补结构或直接保留模型。此处不把编辑、净点数变化或分数变化称为错误纠正。

## 与已有融合结果如何连接

本轮复用现有实例，不重跑融合、不累加样本。

- **M03 对应 S07**：同为 13 人，既有 A/B 两队融合均为四节点、B8L2 分别 64.386/61.906；把 B 中五名 C02 换为 C01 后，C 为六节点、90.791。原答叠图把差异定位到近处墙体转折，可支持“成员表达支持改变→融合恢复转折”的解释。类别并非逐人保证，须保留 W126 等反例。[原案例](../personnel_interchangeability_20261020/interchangeability_20261020/cases/S07_reverse_new2.json)
- **M02 对应 S05**：已有三支 19 人团队为 6/5/6 节点，B8L2 为 83.456/82.122/81.384。文件名中的 redundant 不能作为语义裁决；本图有真实的细微转折，本轮也发现共线节点与部分结构省略，后续应对准具体节点判断，不按节点总数给整队优劣命名。[原案例](../personnel_interchangeability_20261020/interchangeability_20261020/cases/S05_redundant_nodes.json)
- **M06 对应 S04**：既有研究已定位到增人后支持门槛提高、丢失一个已支持节点，B8L2 87.322→51.651。它说明“保留结构的人更多/少一点”和“最后结构进入融合”之间还隔着支持门槛，不是简单平均的连续过程。本轮补原答展示，不把既有机制写成新实验。[原案例](../personnel_interchangeability_20261020/interchangeability_20261020/cases/S04_threshold_worsens.json)

## 下一步判断

1. **优先把结构机会表扩到少量不同建筑的明确实例。** 以可见结构为单位，分别记录“真实且必要”“真实但参考省略”“允许简化”“底面共线/材料分界”“范围选择”“仍不确定”。本包 `local_feature_observations.csv` 已把局部窗口、对象及点对索引落盘；它是可复用的定位层，不是假装完成的语义金标准。
2. **用现有融合队验证这些具体结构的支持变化。** 优先 M03 已有成功变化与 M06 门槛反例，将“哪几个人表达了该转折”接到现有节点支持；不先扩大候选分类数量。
3. **把顶界与共线分段保留为新增解释轴。** 它们在 R5/H2/Rnew2 之外已有例图和重复迹象，值得检查跨建筑复现与融合影响；暂不把 W030/W037 单人行为扩成新人员类别。
4. **Semi 按保留结构、删结构、重定位及改范围分别记录。** 旧批可对照初始化，新批先只研究实际终稿及报告行为；缺初始化的记录不补造操作过程。

本轮没有需要用户逐份裁决的批量清单。最值得后续集中讨论的两个语义边界是：M01 左侧凸起应保留到什么细度；M09 玻璃隔断上缘与更高顶界在该任务中各自的解释。当前可继续做行为解释，不以得到这些人工结论为前置，也不据此改参考。
