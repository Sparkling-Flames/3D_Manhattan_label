## 2. 先读懂“构成之间”和“构成内部”

固定图、人员池、标签和n，先把团队按类别人数向量分组。每种向量的均值不同，形成构成间方差；同一向量下换具体成员仍有变化，形成构成内方差。两者相加为本有限面板的总方差。先在面板计算，再图内平均、楼内平均、建筑等权；最终占比为聚合方差之比，不能直接平均各面板百分比。

这些是有限人员域的描述。构成间占比12.96%不是Q增加12.96%，也不是分类解释了总体人员不确定性的12.96%。成员只有一队的构成，经验分解中组内项为零，但没有可替换成员来估计波动；表中保留单队格数。增加类别会机械减小组内方差，细分有用与否还需看楼外结果、人员支持及实际解释。

楼外response R²预测的是**相对本图片面板均值的变化**，不是陌生图片绝对Q，也不是从图像估计难度。以下 coarse/fine 为历史楼外折标签，不能直接视作当前ALL展示名单的固定层级；例如Manual ALL为三类，但历史楼外折可能选不同特征或层级。
