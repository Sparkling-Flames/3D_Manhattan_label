# 历史 Q 较低、较快方向：困难条件与一个典型正向事件

这是本轮全面换类比较后发现的**有范围的方向性用途**。条件固定为 `ca2a651478a2ab2966a4`：Manual 自身联合类、`manual_joint_A / all_registered_directions / q_down__faster`、新来源有楼外标签人员、严格三队 `n=20,m=3`。类别角色由目标建筑外的历史类中心定义；不同楼的 J 编号不能直接拼接。

本目录复用 2,810 个已存事件、端点和冻结分项，没有新增融合或评分。全部 22 图／16 楼、29 个实际背景均保留；没有只保存正向事件。关键分母在 `DIFFICULTY_SUPPORT_AND_RISK.csv`，精确逐图和背景计数在 `EXACT_IMAGE_COUNTS.csv`、`EXACT_BACKGROUND_COUNTS.csv`。

**采用判断：**这是一项值得保留的困难条件换类方向，而不是应从比较中删除的“低历史 Q”负向候选。它主要支持“整体几何与背景匹配改变融合”这一用途。简单图上该方向稳定出现小幅质量代价，应作为省时与质量取舍报告，不推荐用作简单图升质方法。中等仅 2 图，作为补充。

## 2. 失败与较大损失的真实分母

| 难度 | 已存严格事件 | C 失败事件 | 不同 C 端点／失败端点 | 净 Q 可评价事件 | 净 Q 下降 >5 / >10 |
|---|---:|---:|---:|---:|---:|
| 简单 | 1,410 | 30 | 141 / 3 | 1,380 | 19 / 0 |
| 中等 | 200 | 0 | 20 / 0 | 200 | 0 / 0 |
| 困难 | 1,200 | 100 | 120 / 10 | 1,100 | 39 / 16 |

困难 100 个 C 失败事件对应 `S9-12` 的一个背景中的 10 个不同 C 端点，每个 C 与 10 个来源分块配对。这不是 100 次独立融合失败；另一个背景有可评分 C。原始事件 C 失败率为 8.33%，图／楼等权为 5.56%。困难净损失 >5 为 39/1,100（3.55%），>10 为 16/1,100（1.45%）；对应楼等权率 3.44%、1.11%。两个权重口径都保留，不能混写。

简单的 30 个失败事件来自 `x8-08` 的 3 个不同 C 端点。所有失败和无净 Q 的行均保留在母表，没有填成零分或删除出事件分母。A、B 失败计数及其它方向损失在计数表。

## 3. 改善不等于补更多结构

困难层 C−B 平均节点 −0.300、实际转折 −0.367、短转折边 −0.181、近共线冗余 +0.067；净 Q 同时增加 +8.590。主要分项关联为融合自身正交方向误差 `dir` 下降 2.994°、底面 IoU +0.0107，三维棱柱代理分 +0.905。它不能被描述成“低 Q 人补上更多必要转折”，也不能仅凭转折减少就认定删的是冗余点。

下面的典型正向例直接显示：**节点相同，局部位置和自身形状改变，Q 增加，但部分三维／高度指标变差。**
