# 较大纯类别块的直接 A/C 构成变化

本目录接回原来已经实际计算、但在最新 main 中没有完整逐事件表的纯块直接 A/C 结果。它补充严格 ABC 的容量边界：缺少额外同类块 Y 时，仍能研究完整类别块 X→Z 的变化。**此处没有 B，不提供同类／跨类幅度的匹配证据。**

读取 main：`ef148c82df18582228b2d23837faa2659e79eba7`；真人底层 v2。复用原 `pure_001/002` 的真实端点，新增融合 **0**，新增分类 **0**。本轮新工作是全方向关联、实际换人数／席位核对和同一口径下的图／楼／难度结果，而非重新生成这些原答或融合。

## 范围与计量

- 2,056 登记 A/C 事件，58 图／22 楼，3,863 个去重端点；12 个方法×评价条件身份，461 个方法／条件／层级／来源／方向角色／n／实际 m／父内状态条件。
- 完整保留新 Manual/Semi 结构与联合分类、旧 M、SP、A2、QTD／QTscopeSemi、Rnew2、F01。n=10–22，实际 m=4–20；具体容量、两背景的有限登记及未登记全池容量沿原设计保留。
- X、Z 互斥，D 为 A/C 的实际共同成员；以集合重新计算 m 和类别席位净转移 r。`replacement_fraction_team=m/n`；`source_replaced_fraction=m/A队源类人数`；`source_pool_fraction=m/域内源类容量`，三者不混同。
- 新四方法的方向按该折楼外历史中心对齐（`turn_more/less`，`q_up/down × faster/slower`），每事件保留源／目标类 ID 及特征中心。旧方法没有强行语义对齐；`fold_specific_unaligned` 的有符号合计不能当作统一源→目标方向，逐图和精确事件保留原方向。
- Q/D10 使用原完整可评分资格，失败另列；其它分项保留各自非缺失分母。结构来自缓存底面：≤5°转向为近共线；短边占周长<4%且两端转向≥15°。这不是必要结构的语义裁定。
- 质量平均先图内、再图等权或楼内后楼等权，两种均保存。时间仅纳入所有成员记录齐全且两队来源一致、各自不混来源的秒数；这里的百分比为事件 `(TC/TA−1)×100` 后按图／楼平均，与严格 ABC 的平均对数比指数另列，不能无说明排名。

## 本轮比较得到的用途判断

1. **较大块减去转折成员，可以稳定地产生结构和质量下降。** Manual 结构粗类 `turn_less` 的 204 事件／32 图／22 楼，m=4–13；楼等权 Q −7.318，30/32 图平均下降；融合实际转折 −0.796。这个方向可以用来研究结构稀释与质量风险，不应因其是负效应而不报告。
2. **不能把严格 n20/m4–7 的有益方向直接推广为整类换入。** 此有限直接 A/C 库存中，常规→较多转折的 31 事件／8 图／8 楼，m=7–14，3/8 图改善，楼等权 Q −1.606。它与较广的严格 ABC 来自不同容量、成员、背景和图片，保留原有多数改善结论；这里明确了另一种大比例条件的风险。逐事件有强正向和强负向，不能只用总均值替代案例。
3. **Manual 联合类的大块效率取舍更清楚。** `q_down__faster` 159 事件／28 图／17 楼，m=4–8：楼等权 Q −5.560，23/28 图下降；在有可靠时间的子集，记录时间平均 −12.228%。这是“用质量换时间”的用途描述，不推荐作无代价替换。`q_down__slower` 40 事件／8 图／5 楼全部图平均降质，楼均 Q −6.261，时间 +12.351%，不作为效率或升质优选。
4. **Semi 的父内联合细类仍可有条件用途。** 父内 `q_up__faster` 的 16 直接事件／4 图／3 楼、m=4–11，4/4 图 Q 改善，楼均 +2.355；时间来源没有足够支持，不给省时结论。其作用是父类构成固定时的定向补充证据，不替代严格同类对照，也不由 4 图外推为 Semi 普遍规律。

这些是有范围的内部探索比较。全方向、降质、无明显变化和失败均在表中，主报告择其有解释价值的部分采用；没有重新以目标图表现拟合标签。
