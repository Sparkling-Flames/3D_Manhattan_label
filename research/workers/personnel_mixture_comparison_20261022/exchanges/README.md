## 怎样读结果

先用 `ALL_CONDITIONS.csv` 看全范围，再用 `ALL_CONDITIONS_SELECTION_REASONS.csv` 看每个条件为何进入主要用途、风险对照或补充。选择理由是本轮内部探索性解释，不删除任何配置。各方法来源域、图片和容量不同，不能把这些均值直接当共同域排行榜；已完成的共同域分类/连续 Q/T 对照继续引用原成果。

`same = B−A`、`cross = C−A`、`net = C−B`、`symmetric = C−(A+B)/2`。严格 ABC 三块不重叠，因此实际 m_AB/m_AC/m_BC 相同。旧 n20 的 m_BC 可以更小，另存另一阶段。有限面板端点对是不同设计，比较的是在相同背景与实际 m 下，两类配对集合的结果变化幅度，不能写成同一 A 的三队实验。

类别席位 r 是完整类别人数向量 L1 距离的一半。m 是成员差集人数，m/n 是团队替换比例，m/A中源类人数是原队内该类被替换比例。这些字段分开保存，尤其旧混合块 r 常小于 m。

类编号只在本折比较。Manual 联合按历史 Q/时间箭头对齐；结构按“常规表达↔较多转折”；Semi 联合按训练侧转折差≥0.25分为更偏转折与常规表达的历史 Q 上升/更快方向。全数据 ALL 描述标签不用于效果检验。

## 核心选择依据

1. **保留 Manual 联合 n20/m4 的较高 Q、较快方向**。共同 Q/T 分母下净 Q +3.142，记录总时间 −1.565%；6/7 图、5/5 楼质量正向。完整方向比较显示，这个判断来自具体方向和支持，不能简化成历史 Q 越高总有益。
2. **愿意用时间换质量时，采用明确的最高历史 Q 目标角色**。另存 Stage B n20/m4 共同 Q/T 分母净 Q +4.707、时间 +7.165%；16/20 图、10/14 楼正向。Stage A 的一般 q_up/slower n20/m3 净 Q −1.097、m4仅+0.617，记录时间约+14.6%，所以目标角色细化有实际组织意义。Stage B 是选型后的新背景内部检查。
3. **保留 Manual 结构方向及其反向作构成不确定性主线**。n20主实验，常规→较多转折 m4 净 Q +1.789、96/120 图与15/16楼正向；m7 +3.153、63/77图与15/16楼正向。反向 m4 −1.363、m5 −1.369，分别只有26/72图和7/20图正向；反向 m6在另一支持上+1.137，必须按规模、图片和背景解释，不能把反向效果机械取负号。
4. **Semi 联合保留效率和条件性质量用途**。完整有限面板比较会独立说明相同构成与改变构成的时间波动；某些条件下源类内部 Q 变化更大，并不取消该分类的效率用途。
5. **保留不利与均值/多数不一致方向**。Manual n20/m3 q_down/faster 建筑均值净 Q +2.450，但仅8/22图、7/16楼正向；其价值是效率与质量风险，不能称多数图片升质。q_down/slower 净 Q −1.460、时间+15.877%，是有用的反向构成对照。

这些均为建筑等权效果。上述时间除明确标“共同 Q/T”外使用全部同源、全员时间已知事件；库存记录秒数不是新测生产耗时。主要采用数字优先读 `COMMON_QT_CONDITIONS.csv`，各指标完整分母在 `ALL_CONDITION_METRICS.csv.gz`。

## 同类波动与失败的解释

Semi 注册了每组 X/Y 的镜像，所以同类**有符号平均**可能恰为 0；它不表示逐次换人没有变化。绝对 Q 变化与源队标准差常明显非零，须与有符号均值分开读。

Manual 较高 Q/较快 n20/m6 在固定背景下通常只有一个目标 C，目标类成员波动不可估计；不将单例的零离散当分类有效性。大多数 Semi 严格 ABC 背景也只登记一个 C；有限面板实验补的是这些目标内可替代成员和混合配比的观察机会。

失败按唯一端点及登记引用分别计数。较少失败不等于正确，跨构成变幅更大不等于升质。质量、时间、结构/几何与失败为不同用途；各自的成立范围都保留。

## 代码与复现

1. `compare_saved_exchanges.py`：从 frozen requests 与101,092既有标量端点重建事件及分层汇总，分阶段保存。
2. `complete_comparison_products.py`：补共同 Q/T 分母、成员波动、容量与全条件采用理由。
3. `compare_finite_panel_pairs.py --condition manual` 或 `semi`：复用相邻 `configurations/` 的面板/人数向量/端点，完整枚举每面板924选2的端点对；父内细类比较固定完整父类向量。
4. `compare_legacy_n20.py --source <恢复后的n20目录>`：原全事件窄列恢复、精确实际m/r与父内规模响应。

`STAGE_RECEIPT.json`、`METRIC_CONTRACT.json`、各阶段回执记录实际输入/完成范围。每个子目录实际 `.gz` 都保存数据，不是下载索引代替实体。完整几何和原图不在此重复打包；机制案例沿主报告已有来源定位。
