## 关键字段与比较口径

- `same_* = B−A`；`cross_* = C−A`；`net_* = C−B`；`symmetric_* = C−(A+B)/2`。
- `within_abs_* = |B−A|`；`cross_abs_* = |C−A|`；`symmetric_cross_abs_* = (|C−A|+|C−B|)/2`。`abs_advantage_*` 是后者减类内变化；大于零表示跨类更易改变结果，不表示改变更好。
- `actual_m_AB/AC/BC` 来自精确成员差集。`seat_change_r_*` 是完整类别人数向量的 L1 距离的一半；两者不同概念。本阶段纯类块事件中 r=m。
- `replace_fraction_team = m/n`；`replace_fraction_source_in_A = m/A中源类人数`，后者不是 m/全池该类人数。
- `source_class/target_class` 仅在目标建筑之外形成的本折内使用；跨折按 `direction_role`（历史 Q 上/下、时间快/慢）合并，不直接按 J 编号拼接。
- 主估计按“去重有向 ABC → 精确共同背景 D → 本图本折类别对 → 图片 → 建筑”等权聚合。所有失败尝试保留；质量差使用三个 Q 都可用且该分项都有值的共同分母。
- 时间为已有标注库存记录秒数之和。三队 n 个人时间均已知且来源相同、单一，才计算比值；先对 log 比值分层求均值，再转百分比。表中时间以全部合格时间事件为分母，与只取三队 Q 都可评分的旧表时间可能略有差异。不是新测生产工时。
- `unique_oriented_ABC`、`physical_ABC`、各臂唯一端点数和背景数均保留；重复使用同一队不增加独立图/楼支持。

## 本轮比较得到的选择依据

下表均为同一条件中相对 B 的建筑等权净效应；支持比例按图、楼平均后的符号计算。

| 方向与规模 | 净 Q C−B | 时间 | Q正向图/楼 | 判断 |
|---|---:|---:|---|---|
| 历史 Q 较高且更快，n20/m4 | +3.142 | −1.555% | 6/7 图、5/5 楼 | 保留为定向升质兼效率条件。仍有 5/252 个唯一目标队失败，需说明成员背景范围。 |
| 历史 Q 较低且更快，n20/m3 | +2.450 | −5.704% | 8/22 图、7/16 楼 | 均值提高由少数大改善支撑，**不能称多数图片升质**；保留为效率与质量风险条件。 |
| 历史 Q 较低且更慢，n20/m3 | −1.460 | +15.877% | 3/17 图、3/12 楼 | 有方向性的降质/费时对照，不作为收益推荐；说明分类确实能组织负向构成变化。 |
| 历史 Q 较高且更慢，n20/m3 | −1.097 | +14.613% | 17/27 图、10/19 楼 | 多图小改善与少数大损失并存；仅“较高 Q”不足以给出稳定收益推荐。 |
| 历史 Q 较高且更慢，n20/m4 | +0.617 | +14.572% | 16/22 图、10/15 楼 | 有条件的质量/时间取舍；另存 Stage B 的“目标为该折最高历史 Q 类”是更具体的后选方向。 |

这些条件的图片/建筑支持不同，不能把均值直接当作共同支持排行榜。n19/20/21、m2–6 的其余条件全部留在条件表。后续阶段将加入结构双向、Semi 与同规模的有限面板比较。
