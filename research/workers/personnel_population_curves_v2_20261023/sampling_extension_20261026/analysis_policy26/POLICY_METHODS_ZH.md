# 历史进入策略：16→32对独立路径的精度分析

本轮继续原四种历史优先进入策略：联合高Q、结构较多转折、联合快速、结构主流表达。它们来自既有 V3_BEHAVIOR / V3_JOINT_QT 历史角色，不是 DSTRUCT 或 RFUSE 的新策略试验。共同支持沿当前 main 的157个原策略池；这一集合按策略资格定义，不凭同样的157图数替换为自然路径 N≥30 的集合。

在每个池把新自然排列0–15作基准，以冻结目标成员作稳定二分（目标先、其余后，各块内自然顺序不变），得到四策略各16条新路径。自然与策略共享 base_path_id、全部人数点以及bootstrap抽样索引。分别比较历史16、新16、合并32。历史16由更早8和前轮新8组成，重新汇总不改变其端点或顺序。

## 固定共同支持

采用最新 main `local_audit/policy/FIXED_K_SUPPORT.csv.gz` 中 old8、new8 与 combined16 的共同人数点。新增比较如使某个既定点不可估，再取 old16/new16/pooled32 的交集，逐图／阶段／指标写明原人数点、新保留人数点及损失；不因缺值悄悄改用剩余人数均值。阶段为3至半池、3至6、20至N−1、满员。保留逐k原始点，阶段不能替代整条曲线。

Q差只用同一基准路径的自然与策略两端都可评；P10和SD亦在该配对支持上分开求两边的分布量。广义不可评率沿旧字段保留，另单列共识形成失败、输出已生成但不可评分、缺参考及其他未评分。k=2的固定延期不计为失败。劳动比只纳入两边完整、正值且同一种语义的时间来源；Q/T联合结论再次限制两边Q可评。比例是逐路径比值先求均值，不自动代表总劳动量比或交付时间比。

## 两类不确定性

2000次bootstrap重抽完整配对路径，并保持历史8、前轮8、新16层的数目。对固定人数点只要某次bootstrap出现不可估，就把这一图阶段保留为缺失；对固定图片汇总同样不删图重新赋权。因此某些区间只是在可估重抽中的范围，表中明确给有效/无效次数与条件区间状态。

图等权和建筑等权并列。路径范围描述当前图片里成员抽样精度；建筑范围来自整栋重抽的固定图片点估计，描述建筑间差异，不能互相替代。独立新16对旧16的方向、大小和低尾提供实际新抽样检查；增加bootstrap次数本身不构成新路径。

## 实现

`adopted_policy_functions_20261025.py` 是当前 main 审查代码的实际副本。`analyze_policy32.py` 复用其统计定义，新增真实独立批次、固定旧支持交集、详细失败分类和分层配对重抽。其保存结果不改动既有报告和原端点。逐池输出先保存，再统一汇总，可中断续算。
