# 新增端点数据分包 HOHONET_20261026_DATA_S1_06

本包包含阶段1中24个已完整保存图片池的102,333个新增独特端点。标量与最终紧凑几何逐片一一关联，内部票账仅按预定案例／哈希规则保存。本包不包括旧main中复用端点。

精确顺序、成员、object_id、请求及旧缓存来源见S01设计包；同一团队出现多次的路径权重由前缀表保留。状态字段分开保留真实共识失败、已生成但不可评分、参考缺失及k2延期。不把缺Q填零。

逐池请求数、资格池哈希和本包支持见PACKAGE_POOLS.csv。分包顺序只为及时保存，不能把早完成的图片汇总成全库研究结论。完整研究结果以最后综合报告和全部数据包索引为准。
