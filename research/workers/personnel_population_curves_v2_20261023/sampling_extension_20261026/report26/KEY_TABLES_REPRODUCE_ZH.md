# 综合报告主表：整理脚本与前置条件

`assemble_key_tables.py`只整理已经完成的正式统计表，不启动融合、不重抽路径、不训练模型。字段来自本轮实际分析代码：`summarize_natural.py`、`analyze_natural.py`、`analyze_policy32.py`及`report_policy_precision.py`。报告骨架仍保留，主表整理不替换它。

## 何时运行

默认同时生成自然与历史策略主表，必须具备：

1. `analysis_precision26/results_stage2/NATURAL_FINALIZATION_COMPLETE.json`：`complete=true`、`pools=194`。
2. 同目录`ANALYSIS_RECEIPT.json`和`SUMMARY_RECEIPT.json`：stage2、194池、`complete_requested_pool_support=true`，来源提交为`b9bcec809fbaec8ab055931a1abb7baa5db44dac`。
3. `analysis_policy26/results/RECEIPT.json`：157策略池、旧16／新16／合32完成。
4. `analysis_policy26/presentation/RECEIPT.json`：全部157池的已存策略展示汇总完成。

在这些前置条件满足前，脚本报出缺失项并退出，**不建立主表输出目录，也不退回stage1、36池技术结果或旧48报告数字**。`--natural-only`是显式只导出自然主表的选项，仍要求自然全部194池完成，并在回执中标明策略未包含。

```bash
python report26/assemble_key_tables.py --base /path/to/sampling_extension_20261026 --check-only
python report26/assemble_key_tables.py --base /path/to/sampling_extension_20261026
```

默认输出为`report26/key_tables/`。`--describe-inputs`仅打印静态输入文件及必需字段，不读取结果；`--out`可以指定另一个报告目录。64位seed字段按字符串读写，不再通过float推断。

## 口径说明

T01A普通N≥30／N≥35首先固定157／92个容量候选池，然后按指标固定全程有效支持。门洞全17池只能共同画到27人；其N≥30与N≥35子集另列。主表直接保留`capacity_images`、`images`和排除图片，不能把容量数当可评分数。

T03A新增的是分母和关联整理，不重算效应或区间。它用`COMMON_SUPPORT_KEYS`定位每项指标真正共同的图片，再连接`NATURAL_INTERVALS`的路径计数。相同区间的Q、失败与几何支持可能不同，不能将其中一个量的分母复制给另一个量。

T04原表对所有指标按0计算`positive_images`；对劳动比，0并不是节时判断界限。脚本保留原字段但明确标注，并在T04C用已存逐图劳动比与1比较。劳动比仍是合法配对路径比值的算术均值，不是总劳动之比。

策略157图是冻结的策略资格集合，不能因为数量相同就当作自然N≥30的同一157图。脚本分别读取自然元数据和策略自身已存支持，不按图数强行合并两份名单。

T05的“新发现失败”表示旧样本未观察到、独立新样本或合并样本观察到，并非同一团队的冻结算法改变。摘要同时给旧零事件机会数；图×k相互关联，不给它们伪造独立二项区间。跨图全曲线最大差的分位数只是已有单图估计变化的描述，不是新置信区间。

输出后实际读回每个CSV/gzip至EOF，检查行宽和行数，保存源表与输出SHA到`KEY_TABLES_MANIFEST.json`。该脚本不读取原图或完整端点，因此不能替代最终包的端点—几何及精确前缀关联验证。
