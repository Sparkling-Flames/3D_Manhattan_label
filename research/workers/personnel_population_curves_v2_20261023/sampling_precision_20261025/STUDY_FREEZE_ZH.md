# 人数曲线随机顺序抽样精度：本轮冻结设计

本轮输入是 GitHub main `40d0fe62dc62f6f6c12723af10195b7abb7bc9fe`，真人数据v2。冻结日期2026-10-25。设计在查看任何本轮新增自然/策略结果之前确定，选择依据为既有24条路径的噪声、原难度和实际容量。原24条原样保留。

## 估计对象

对每个固定图片、条件、参考和合法人员池，从所有人员排列中均匀独立抽取一条；每个k的前缀因而是均匀k人子集。团队从原答独立融合，同成员集合仅执行一次，出现频率保留。Q是可评分团队的条件均值/分布；实际失败按全部非延期尝试计。满员是唯一成员集合，不存在顺序Monte Carlo误差。图片和建筑的差异不是抽样路径误差。

## 有限追加预算

1. 177个普通Manual和17个门洞Manual池，全部增加24条完整自然顺序：原24、新24及合并48在相同图片比较。
2. 普通Manual中N>10，按既有24条在k=3…min(20,N−1)的Q均值MCSE的RMS，在简单/中等/困难内各选最高12池；加全部17门洞，共53池再追加48条（最终96）。名单在FOCUS_PRESELECTION_OLD24_RMS.csv。焦点额外样本单列；全体主表仍用平衡48条，不把不同样本量直接池化。
3. 原四策略均有支持、N≥20的普通Manual共同157池，各取新增自然顺序的前8条base，按原楼外角色稳定二分形成4个配对策略。原8、新8、合并16作同范围比较。该157池名单不等同于自然N≥30的157图。
4. 每个Manual池补齐k=1与k=N−1的全部成员子集；6个N≤10池进一步计算全部合法非空成员子集（k=2保留原政策延期），以低成本给出精确有限总体边际真值。它们不替代完整路径配对。
5. Semi本轮沿用既有32普通池结果作精度次要分析，不追加；OOS不进入普通质量统计。

主随机种子2026102501；命名空间population_precision_20261025；每池/编号用规范SHA256派生完整整数种子，NumPy Generator.permutation。精确实际顺序另表保存，不因Q或失败删种子。

## 精度量尺及停止

报告单图均值MCSE≤1分、固定图片层汇总MCSE≤0.5分、单图P10经验95%重抽半宽≤2分的达到比例，同时保留更保守的二项秩区间。MCSE为一个标准误，不是95%半宽。量尺描述实际可用精度，不是显著性门槛。原24下困难图若要求单图均值95%半宽约1分，常需数百条；本轮不以达到这个要求为强制目标。

完成上述固定追加预算及有限总体枚举后停止新增融合，比较独立新增批次与累积估计。未达到的精度明确标出，不追加到曲线平滑、方向符合预期或统计显著。原24诊断1000次完整路径重抽只用于估计已有不确定性；不作为新增抽样次数。路径重抽保持完整k与策略配对；建筑整块重抽另列，均不声称外部验证。

## 输入/冻结方法

沿用既有资格、参考、处理、投票/对应/定位/连接、评分B8L2与D10，原类标签不重新拟合。k2为设计延期，不当真实失败。参考缺失、未计算、失败、有效分别保留。原答/几何与时间语义按既有字段合同；不把缺失Q或时间填零。

新增路径、请求、去重端点、缓存命中及完整state分片分别保存；用于正式分析的集合由精确团队键连接。新端点在计算时分片落盘，保存阶段设计和最终结果；ZIP及内部压缩表将回取读到结尾核对。
