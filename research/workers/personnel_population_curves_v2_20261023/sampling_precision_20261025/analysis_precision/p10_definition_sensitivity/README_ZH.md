# 精确边际 P10 的定义敏感性：有限收尾诊断

本项仅复用已完成的 `EXACT_MARGINAL_VALUES.csv.gz` 和完整的 `EXACT_ANCHOR_BATCH_ACCURACY.csv.gz`，没有新增端点、随机路径或 bootstrap。固定仓库提交为 `40d0fe62dc62f6f6c12723af10195b7abb7bc9fe`。本项不会覆盖原结果；原样本 P10 估计值全部保留。

## 结论及采用

**P10 的主要采用判断保留，但要区分两种精确参考。** 普通 Manual 的单人低尾用 24 路径估计仍偏粗，48 路径有所改善；接近满员时多数图片的 P10 已很接近精确边际，少数稀有低尾仍会被漏估。把完整目录的线性插值 P10 换成均匀有限分布的逆 CDF P10，没有改变这两点。满员端点是一个确定团队，两参考完全相同。

需要收紧的是“96 路径继续改善单人 P10”一类统一表述。36 个普通焦点池在同一支持上，48→96 的 MAE 对线性目录参考为 **2.016→2.559**，对逆 CDF 参考为 **2.324→2.318**。前者变差，后者基本持平；不能把这项变化单纯称为抽样精度提升，也不能把两种参考间的差异算成纯 MC 误差。单人团队已经全量计算，正式单人分布可直接用精确目录。

### 两种参考及可比范围

对某一 `pool_id,k`，先保留可评分 B8L2 的全部不同团队。设数量为 M，按 Q 排序为 q₁…qM：

- `linear`：沿用 NumPy `quantile(..., method='linear')`，对完整目录在零基位置 `(M−1)×0.1` 插值。这是原研究采用的目录统计量。
- `inverted_cdf`：均匀有限分布的 `inf{x:F(x)≥0.1}`，即 q_ceiling(0.1M)。这是以每个不同团队等概率为总体时的分布分位数。

两者都是明确的计算目标，但不必相同。目录中无可评分团队时保持缺失；失败和 n=2 暂缓不补零。这里的 P10 是**可评分 Q 的条件分位数**，实际失败另有既有分析。样本估计仍用原表的 linear P10；本项只改变比较参考，不偷换样本估计器、不重新计算区间。原表所附区间原样保留，不能把分布分位数区间的覆盖与线性目录统计量覆盖混为一谈。

## 主结果

下表为相同可评图支持上的旧 24→固定 48 比较。`≤2` 指绝对误差不超过 2 分。普通大池单人及 N−1 均为 171 图、22 栋建筑；六个小池的所有子集另列，不混入此行。

| 条件 | 精确参考 | 旧24 MAE → 48 MAE | 48 绝对误差P90 | 旧24 ≤2 → 48 ≤2 |
|---|---|---:|---:|---:|
| 普通 Manual，k=1 | linear | 4.208 → 3.105 | 8.057 | 44.4% → 54.4% |
| 普通 Manual，k=1 | inverted_cdf | 4.495 → 3.170 | 8.819 | 40.9% → 56.1% |
| 普通 Manual，k=N−1 | linear | 0.445 → 0.343 | 0.118 | 97.7% → 98.8% |
| 普通 Manual，k=N−1 | inverted_cdf | 0.452 → 0.347 | 0.122 | 97.7% → 98.8% |

N−1 两参考差异很小：普通 171 图的平均绝对定义差 **0.0186** 分，最大 **0.5326**；门洞可评 16 图平均 **0.0376**，最大 **0.4341**。k=1 的定义差大一些：普通大池 171 图平均 **1.0069**，26 图超过 2 分；门洞 17 图平均 **0.8484**，1 图超过 2 分。六个小池共有 49 个 pool/k 目录，43 个可评；其中部分单人目录仅有 6—9 个成员，线性插值与阶梯分布分位数更容易不同。43 个目录的平均绝对定义差 1.4383 分，最大 22.9143 分；这些是六图的多个边际，不是 43 个独立图片。

门洞的小幅阈值例外应明确保留：`q9vSo1VnCiC-13`、k=32 的目录 linear P10=24.5193，CDF P10=24.0852；48 路径估计为26.2619，误差由1.7426变为2.1767。于是门洞 N−1 在48路径的“误差≤2”比例从16/16变为15/16。该变化来自2分判别边界附近的参考定义，不代表一次新的融合失败。旧24只有14个门洞 N−1 可评，与48比较的共同支持仍为14图；完整逐版本表另保留16图支持，不直接相减。

## wc2-46：定义差不能解释主要低尾遗漏

`wc2JMjhGNzB-46`，N=28、k=27 的完整28队目录：linear P10=**52.406207**，逆CDF P10=**51.950681**，相差 **0.455526**。48路径的估计为 **97.408031**，对两种参考的误差分别为 **45.001824**、**45.457350**；96路径为97.387235，误差仍为44.981028、45.436554。

因此原先关于这个案例低尾估计偏高的判断保留。96路径已访问全部28个不同团队，但重复抽中的频数并不自动等于有限总体的均匀权重；“不同团队都见过”不等于样本频率恰好正确。若目标就是 k=N−1 的有限总体分布，可直接采用本轮已经计算的精确目录。不能以增加 bootstrap 重复次数修复这种尾部分布抽样问题。
