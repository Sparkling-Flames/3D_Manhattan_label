## 方法解释

V是固定图片和人数下两支独立随机团队的有效完整底面之间平均1−IoU。随机路径采用不同路径对的U统计，保留两路径偶然相同成员时的零距离及原抽样频数；不能先去重再当自然随机样本。完整有限目录则包含同队自配零距离，按有效团队数M²计算，正好对应有放回独立双抽样。两种分母不同有明确理由，不是统计错误。

几何精度代码使用删除一整条路径的jackknife，人数差的删除值按path_id匹配；不把成千上万两两距离当独立样本。固定图集的MCSE只描述顺序抽样误差，另列的建筑均值差描述跨楼方向；这里没有重新跑全部建筑bootstrap或计算全量两两几何。
