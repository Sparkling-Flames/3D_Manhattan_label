## 组合结果独立于画像

原包报告88048个不同精确团队键，覆盖196图；本次不重新运行它们，也不把“已归档”写成“全部重新验证”。统筹已从主要成对底表复聚合80行5人快慢、3项H/L效果及7302条相对Q，并实际复放4例12队通过；这是继承的有限核查，不冒称本线程执行。

- 普通Manual/all_supported、170图/22栋，1H6L与3H4L对7L分别+1.866/+4.450；6H1L对7H为−1.035。说明固定人数的构成作用，不表示指导、学习或带动能力。
- 普通Manual新批、历史Q配平的allQ域，4快1慢对5慢：142图/22栋，Q变化+0.260、总源劳动比0.536；但超过5分损失率22.76%，联合节时≥20%且损失≤2分仅60.08%。高Q域77图/19栋，Q变化−2.571、劳动比0.496；面板不同，不能把两者差值归因于高Q本身。
- Manual与Semi分别选人、组队、报告；门洞和special单列。特殊用途111份（Manual66、Semi45）没有并入普通主Q。

均值接近不等于质量等价；劳动比按成对比值先log、再图/楼等权后exp。质量线new-only劳动补表采用另一算术汇总，不混用。max活动时间仅是在同时开工假设下的代理，不是真实交付时长。历史选择是楼外回顾分析，不是严格时间顺序或全流程外部盲测。
