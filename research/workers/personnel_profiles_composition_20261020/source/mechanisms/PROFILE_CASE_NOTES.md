# 人员画像的同图实例：W109 与 W112

本轮新增的是逐人画像之后的六份作答同图对照与可复算图，并未重算六份作答的正式质量、改标注或运行新融合。正式分数和参考均引用当前逐份证据。

## 图像证据支持什么

- **b8cTxDM8gDG-07（普通 Manual、简单）**：两人均表达6对墙角，局部可见转折和底面都接近同一参考。W109 为98.42分、报告耗时24.943秒；W112 为97.00分、207.717秒。该图显示时间差并不必然换来额外结构。此图以前已有“可见转折较清楚”的机制记录，本轮不新增人工正确性裁决。
- **yqstnuAEVhm-29（普通 Manual、困难）**：W109为11对，W112与参考均为14对。左侧局部转折被W109简化，底面出现长斜连；W112保留了参考中的局部路径。B8L2为41.06/91.46，底面IoU为0.7135/0.9647，底角射线误差为2.5846°/0.1237°，方向残差为19.110°/1.961°。因此收益包含范围、局部路径和定位，不能全部归因于“多画3个点”。两人的报告耗时为172.356/1825.214秒，慢者多用27.5分钟。
- **jh4fc5c5qoQ-04（普通 Manual、困难）**：两人都12对，W112在部分窄墙片附近存在位置偏移，底面产生斜边；B8L2为97.27/47.04。方向残差0.945°/12.330°、底面IoU0.9825/0.8681解释了同点数下的明显分差。慢者多用9.6分钟，但该图的分数更低。这是“慢者更细致、更适合困难图”的重要条件反例，不应从均值中删除。

上述三例是画像解释中的事后代表选择，不能作为总体发生频率。跨图平均作用采用主画像分析及两人15张共同困难图的完整配对统计。视觉图使用当前研究处理点，原环顺序不变；“原标注”不冒称未处理导出。

## 时间语义

六份作答都来自W100–W134新批次。同一字段 `source_active_time_seconds` 为 `user_processed_reported_not_raw_log_replayed`，绑定于用户处理对象ID；本轮未重放原始日志。`target_matched_time_seconds`为空，未用其它字段补齐。上述时间只能称报告的任务活动耗时，不能解读为实际排队、交付时间或花费金额。

## 精确引用与复现

- 输入：`research/statistics/v2_evidence_audit_20261019/records.json.gz`。
- b8c-07：`v2:new:102020`（W109）、`v2:new:102023`（W112），`gt_original`。
- yq-29：`v2:new:106435`、`v2:new:106438`，`gt_manual_revision`。
- jh4-04：`v2:new:102546`、`v2:new:102548`，`gt_original`。
- 六份的完整参考ID、当前点位、时间来源与已有分项保存在 `profile_examples.json`。
- 原图均从用户指定 Release `quality-original-images-20261015`取得；b8c/jh4在03分包，yq在02分包。
- 运行 `render_profile_examples.py --records profile_examples.json --repo <当前仓库> --image-dir <所需原图目录> --font <完整或本轮子集Noto字体> --out <图路径>`。依赖与同目录 `render_cases.py`、仓库既有 `case_visuals.py` 一起使用。
