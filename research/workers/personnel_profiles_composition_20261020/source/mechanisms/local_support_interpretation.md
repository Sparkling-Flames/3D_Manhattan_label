# 组合效益的局部支持解释（本轮推导，不是新增实验统计）

现用点组保留规则为 `s >= ceil(n/2)`，等价于 `2s >= n`。下列推导仅在“同一实体对应组保持不变”时成立；如果整队重分组改变旧观察归属，必须另查对应账本，不能只套人数公式。

## 少量高 Q 核心为什么有时有效、有时无效

原低 Q 团队人数为 l，其中 s_L 人已支持某个局部节点；新增 h 人均支持此节点，则节点进入融合的条件为：

`2(s_L+h) >= l+h`，即 `h >= l-2s_L`。

因此，少量高 Q 人员可以为一个“已接近门槛但未达票”的正确局部转折补足关键支持；如果原团队所有人都省略该节点，就需要 h 至少等于 l。此时不能期待一两位高 Q 人员凭身份改变多数结构。同一批少量高 Q 人员仍可能通过中位数改善位置，而输出节点数不变。

这里“高 Q”只说明历史选人方式。是否提供具体节点必须查本图实际观察，不能从全局 Q 自动推断。

## 为什么给高 Q 核心加低 Q 人员会稀释细节

高 Q 核心 H 人，其中 s_H 人支持某节点；新增 L 人，其中 s_A 人支持，则最终节点保留条件是：

`2(s_H+s_A) >= H+L`。

若核心全部支持而新增者全部不支持，节点在 `L <= H` 时保留，在 `L=H+1` 时失去。这是当前允许偶数半票保留规则下的局部门槛，不是一般意义上“混合比例1:1必然最好”。高 Q 核心内部也可能不一致，实际转折点应以本图逐节点支持数为准。

## 奇偶变化的严格条件

从偶数 n 到奇数 n+1，门槛由 n/2 上升到 n/2+1。一个恰好 n/2 票的组，如果新增者没有提供支持且对应不变，将失选。从奇数 n 到偶数 n+1，门槛不增加，新增支持可能让节点重新过票。

但“失去节点”本身不等于质量下降：移除不相容的新增凹槽可能提高固定参考分；移除必要转折可能明显损害布局。缺点后的投影来源环会产生跨越连接，它所获的投影邻接票也不等于工人原本直接画过该条边。

## 新案例应记录的最小因果链

1. 实际成员与留建筑历史 Q / T 分组；是否同人数、同背景、同实际替换规模。
2. 对比前后组通过共同原观察连接的一对一 / 拆分 / 合并关系。
3. 支持来自哪些 H / L 或 F / S 成员，票数和门槛如何变。
4. 中位数位置、最终保留节点及投影连接如何变。
5. B8L2、D10、范围和结构诊断如何变；语义结论只沿有效参考或既有人审。

若旧多数观察被对应算法拆散，例如既有 q9-30 的13份观察分散后失选，人员输入的信息量与算法提取的信息量不同；此时只能把观察到的融合收益 / 失败归于“这组人加现用算法”的整体结果，不能直接升级成人员互补性或不适合组队的证据。
