# 本轮 scope / 门洞边界说明

本说明依据用户本轮明确研究边界与上传附件《曼哈顿scope讨论.md》，不是新增人工判图。

- 研究库存保留全部非 OOS 图；门洞单列；未知 / 待定保留。
- 表示能力、opening 标注政策、可观测性是不同变量。Manhattan 表示成立，不保证单图可以唯一恢复隐藏完整拓扑。
- 门洞前停止与纳入可见延伸可能表达不同的合法目标。没有相容人工裁定时，不根据分歧率或单一参考分数直接认定 scope 判断错误。
- GT 暂停、参考可疑图可提供原标注结构、范围、耗时、筛除等行为证据，但本轮不能擅自恢复质量 / 融合投票资格。
- 团队机制中“节点新增 / 凹槽保留”不等于必要结构；“节点失去”不必然是失败。必要性结论须沿用有效参考并明确限定，歧义处留人工判断。
- 上传附件中先前模型的 tool 引用 ID 不是本轮可引用来源；其中具体图片的暂定裁定不能扩展成全库标签。
