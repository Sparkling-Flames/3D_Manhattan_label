# Pro Part A接入与B线首轮验收（2026-10-19）

本记录区分Pro交付、Dot历史审查和本次Codex实算。结论是：正反向人员类别已经实际产生；主反向几何类在B线一个有限共同支持子集上呈现直接的类内稳定优势，值得继续验证，但目前不足以采用为全体人员的可靠互换类别。正向六域、难度细分和纯替换分区没有在本面板给出同样明确的整体优势。没有重选类别或更改评分、阈值、参考与准入。

## 对研究目标的独立判断

Pro这次确实尝试了用户的两个方向：正向六域28候选，反向关系64候选，并形成实际人员分区。Semi中的未改错误机会和scope倾向进入了候选，而非仅停留在报告建议。缺初始化和有限scope金标仍限制这些变量的含义。

主选择与用户目标存在距离：源码`reverse/selection_common.py`及正向等价实现分别校准类内、类间稳定概率，没有要求类内更稳定。一个分区若准确预测“同类反而容易坏”，也可以改善Brier。Pro另有直接类内/类间检验，不能说它完全没有检验互换目标；但主选的优化目标不是互换效用。所有候选进入one-SE范围后按简约规则选最低K，也不能证明4类天然最好或其他候选等效。

全量主正向15/38/3/3和主反向1/39/18/1是描述性人数，后一方案只有两个多人类；纯替换反向30/6/17/6是另一真实候选。类内单例没有互换机会，未当成功。固定算法名与K也不保证成员在逐楼折中稳定。这些问题限制类别用途，不能直接否定多变量或反向路线。

## B线新增直接证据

固定人员对和背景，先平均12个已算人数节点的主判据通过比例，再在同图同背景配对类内/跨类，最终图内平均、建筑等权。这是通过比例，不是12节点全部通过，也不是跨图人员对的总体成功率。

| 冻结方案 | 有两种替换机会的图/建筑 | 类内通过比例 | 跨类通过比例 | 跨减同，百分点（探索区间） |
| --- | ---: | ---: | ---: | --- |
| 正向主选 | 27/15 | 64.40% | 63.15% | −1.25 [−12.04,8.50] |
| 正向六域 | 34/19 | 70.14% | 67.89% | −2.25 [−8.08,3.82] |
| 主反向几何 | 12/10 | 78.33% | 56.98% | −21.35 [−41.98,−2.81] |
| 纯替换反向 | 27/18 | 65.39% | 70.68% | +5.29 [−2.55,13.02] |

**主反向几何在这个子集上有直接积极信号，不能一概写成“类别没有作用”。** 12图中7图方向有利于类内、2图相同、3图反向。k16单独看为85.00%与56.25%，但只有5图类内较好、5图相同、2图反向。差异并非多数图片都很大，rPc6DW4iMge与x8F5xyUWy9e两栋贡献尤其大。表内各方法可配对图不同，不能按四行数值作方法排名。

看到该结果后追加了统一支持诊断，明确属于事后敏感性，而非重新登记的主检验：

- 九方法都已知的事件：主反向只剩8图/6栋，类内72.92%、跨类56.42%；差−16.49个百分点，区间[−40.63,4.34]。
- 两名替换者同来源：只剩4图/4栋，方向仍有利，但不足以认定排除了批次因素。
- B既有历史Q差≤3：只剩1图/1栋，无法估计跨建筑不确定性，区间留空。不能据这一小子集证明有独立于Q的效果，也不能因支持少就宣布效果不存在。

因此当前采用判断是“保留主反向几何类为有直接证据的条件候选，尚未升级为可靠类型”。纯替换反向有四个多人组，但本次平均方向不利于类内；难度细分与六域方案也没有稳定地改善全部人数。所有12节点、严格/主/宽松阈值、失败及分差均保留，没有只展示获胜k。九方法、多人数、多指标的区间未作多重选择调整，不能将一条正区间解释为最终确证。
