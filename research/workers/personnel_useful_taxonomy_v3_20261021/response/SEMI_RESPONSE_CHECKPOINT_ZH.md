# Semi：完整成员面板中的粗类、细类与连续特征

这是已完成的阶段结果，Manual 另行保存。输入是本轮已冻结的 Semi 多人数面板；每个面板在固定背景下完整计算 12 选 6 的 924 个实际成员集合。此处不重新融合、不改变资格与评分。目标建筑全部排除于类别形成与响应模型训练，不能将反复研究的原数据称为外部盲测。

## 两个不同问题

1. **已有有限面板内，类别人数向量能区分多少波动？** 按每个构成的所有实际成员集合分解组内和组间方差。这是描述量；细分会机械增加组间方差，因此不能单凭它推荐细类。
2. **这些作用能否迁移到其他建筑？** 用其他建筑拟合固定 Ridge=0.1 的响应模型，预测目标建筑面板内部的端点差异。`response_r2` 相对该面板的常数均值；负值表示该迁移模型不如常数基线，不表示人员没有标法差异。

所有结果逐面板、逐建筑保存。多面板先在图片内等权，再在建筑内等权。时间只用来源完整且单位兼容的面板；评分只用本来可评分的成功端点，失败率另计。所有原生失败端点仍在主交付表内。

## 完成范围和主要读数

|比较域|B8L2 支持|时间支持|核心结果|
|---|---:|---:|---|
|结构共同支持|61 面板、13 图、10 楼|28 面板、12 图、9 楼|新结构粗/细类的 B8L2 组间方差占比 3.36% / 8.51%；细类的跨楼 B8L2 响应 R² 为 −0.00179|
|Q/T 共同支持|42 面板、12 图、9 楼|28 面板、12 图、9 楼|联合粗/细类的 B8L2 组间占比 13.49% / 23.07%；跨楼 R² 0.00226 / 0.00148|
|Q/T 共同支持的时间|同上|28 面板、12 图、9 楼|联合粗/细类的时间组间占比 24.49% / 85.28%；跨楼时间 R² 0.192 / 0.341，连续 Q/T 为 0.370|

细构成在当前完整面板内确实区分了很多时间差异；其楼外可迁移信息仍被连续 Q/T 至少同等好地表达。它适合用于可读的人员构成说明，不宜仅凭 85.28% 的描述性占比，宣称比连续特征更适合选队。这里没有把预测误差改善解释为实际节省工时；实际选队的时间、质量与失败结果位于 `utility/`。

结构类的总体质量响应很弱，与原答标法差异、局部替换成功案例可以同时成立。总体均方误差受少数局部中位数、门槛和连接变化影响，类别人数不能完整指定这些成员层面的机会。适用的局部证据由严格匹配事件及真实叠图另报。

## 输出

两个子目录 `semi/geometry_common/` 与 `semi/qt_common/` 分别保存：

- `PANEL_PREDICTION.csv.gz`：每面板、每模型、每分项的楼外预测结果。
- `PREDICTION_BUILDINGS.csv`、`PREDICTION_SUMMARY.csv`：逐建筑及总体、人数/难度/来源等条件汇总，含建筑 bootstrap 区间。
- `PANEL_CONFIGURATION_DECOMPOSITION.csv.gz`、`DECOMPOSITION_SUMMARY.csv`：完整配置的组内/组间波动；单成员构成单列，不作为可互换证据。
- `FITTED_MODELS.csv.gz`：训练建筑、系数、输入中心和尺度。
- `SUPPORT.csv`、`COMPLETION.json`：实际共同支持及完成状态。

模型包含来源基线、旧 M/SP、新结构粗/细类、连续结构、连续 Q/T、联合粗/细类、分类所用完全相同连续字段，以及预先记录的二阶构成交互。`MODEL_REPRESENTATION_AMENDMENT.json` 记录加入交互的时间与理由；所有模型均保留，没有只报告最好者。复现：先运行 `analyze_responses.py derive`，随后按 `DESIGN_FROZEN_ZH.md` 运行两个域。
