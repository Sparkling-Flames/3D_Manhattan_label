## 2. 量的定义与角色对齐

A=D∪X、B=D∪Y、C=D∪Z；三个块与D互斥，X/Y同类，Z目标类，实际m由集合算。保存BA、CA、CB。类内幅度|B−A|，对称跨类幅度(|C−A|+|C−B|)/2，幅度差为后者减前者；幅度使用同一指标的三队可评支持，CA/CB另外保留各自真实分母。

跨折按训练历史角色（挑战转折、历史Q、尺度或反推类容量）及K对齐，不直接汇总C1/C2编号。ALL名单用于看人，实际每一事件使用目标建筑外名单。汇总先同目标，目标在图内等权，再图片等权；建筑均值及分母独立列出。

时间是库存劳动记录的和，非新生产耗时。提供单来源与来源人数签名匹配两种口径；混来源时只有来源人数向量相同且每份时间已知才进入匹配比较。图片难度仅使用正式目标标签；新增空间另给可计算结构条件。
