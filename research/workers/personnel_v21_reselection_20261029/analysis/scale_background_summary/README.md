# 替换块、团队人数与背景：固定条件后的实际作用

**本节完成纯汇总收尾。没有新团队、新融合、新评分、新几何计算或新分类。** 固定仓库提交 `a476461d7ede8db95da43de4139e612c05e618bc`，底层 v2.1。合并原两方向与 focus 后 OPPJOINT K4 的固定 A 规模结果，共 **1,947 条路径、10,184 对 m 增量关联**；每路径最小登记 m→实际最大 m 恰好 1,947 对。另引用既存 3,252 个同 XYZ 背景对照，以及广筛中已经保存的固定 XYZ／嵌套 D 人数路径。

主要判断是：**扩大替换块在多数有支持图片上继续改善 C 队，但“C 改善多少”“相对同类 B 多改善多少”“同跨类幅度差扩大多少”有不同答案。** OPPJOINT K4 在 n12 的块增大效果最清楚；在 n20，同类 B 也可能明显改善，因此净优势增量远小于 C 本身的增量。TARGET DSTRUCT 的结构方向在三个已算人数下都有多数图片支持的 C 改善。改变背景或增加总人数则可能压缩这些优势，不能套用一条“越多越好”的结论。

本节三个固定 A 方向分别为：OPPJOINT K4 的楼外历史 Q 秩 1→4，TARGET DSTRUCT K3 的困难转折表达秩 2→3，OPPGEOM K3 的面积秩 2→3。秩对应各折实际类别，人员及历史中心继续沿用已冻结分类文件。

## 1. 三种实验必须分开

|实验|真正固定的对象|改变什么|回答什么|
|---|---|---|---|
|固定 A 的 m 路径|原 A、总人数 n、最大 X/Y/Z 及各自一次预抽顺序、D0|更长的 X/Y/Z 前缀；D_m=D0∪(Xmax\X_m)|同一原队被替换更多成员后，C、B 与 C−B 各自怎样变|
|同 XYZ 的背景对照|同图同目标、n、m、完整 X/Y/Z|D 中目标类人数及实际 D 成员|既有类别背景怎样调节同一个换人块；A/B/C 都会随 D 改变|
|固定 XYZ 的 n 路径|同图同目标、m、X/Y/Z；较小 D 被较大 D 完整包含|增加共同背景成员、总人数 n 及相应人数门槛|更多人加入后，结果与换类效应如何变化；不能只归因于门槛|

固定 A 路径的每一步仍是严格 ABC。跨 m 时 D_m 并非不变，但 **A 始终是同一实际成员集合**；总人数造成的最低票数项保持固定。背景对照则 A 也改变，不能当作固定 A 的 m 作用。n 路径同时增加真实成员与门槛，只有结合已有投票案例才能作更具体的机制解释。

## 2. 增大 m：把 C 与 B 的变化拆开

主增量定义为 ΔC=C_large−C_small、ΔB=B_large−B_small、Δnet=ΔC−ΔB。下面三列统一限制在**同四个 B/C 端点可评价**的支持上。逐池、图片等权及建筑等权的 ΔC−ΔB=Δnet 都成立；最大数值误差为 6.7×10⁻¹⁵。各自更宽的成对分母仍在完整表中，不用于这组三列分解。

时间基线是**较小 m 的相应 C/B 队**，单位来自已有标注记录。主秒数分解以及表内 C 百分比要求四个 B/C 端点所有时间已知、时间来源人数向量相同；因此时间与 Q 的支持量不同。这不是新增测量的生产耗时。OPPJOINT 的更大块在可比子集中增加记录时间；TARGET DSTRUCT 的 n12 子集略节时、n20/26 略增时，说明较多转折角色并非统一更慢。

失败不会填成 Q=0。“新失效”以小 m 的 C 可评为条件；“降逾10分”以两个 C 都可评为条件，均先在池/图内平均再对图片等权。原始失败、恢复和失效或大损失的分母全部在长表，不能将这些百分比直接除以质量四端点的有效图数。

- OPPJOINT n12/m6 中有 26 张图可改变目标类背景，其中 25 图可作四端点质量比较。D 的目标类席位从 0 增至 1 或 2，C 平均只 +0.085，B 却 +1.100，净差 −1.015；只有 5/25 图净差增大。这个条件的背景更多是在帮助同类替换基线，**净优势下降并不是 C 变差**。目标类已经在背景中提供贡献时，额外换入它的净边际作用可能缩小。
- TARGET DSTRUCT 的 m7 背景对照仍只有 11 张真正共同图片具有可切换背景，不能扩写成全部 m7 图片的普遍调节。n10/m7 中 C 和净差都较明显改善；n20/m6、n24/m4 则 B 的改善更大，净差平均下降。类别方向仍有价值，背景作用应按 n/m 条件说明。
- OPPJOINT n26/m3 的背景净差图片等权均值为正，但仅 39/90 可比图为正；它不是“背景目标类越多越好”的多数规律。所有有利、负向及接近零的背景配置都保留。

这些是**同图、同块的背景变化**，不是把不同图片上某种背景多或少的组均值直接相减。建筑等权结果、完整背景对照和逐图表也已保存。

## 5. 固定 XYZ 后增加 n：共同背景和门槛一起改变

既有 n 路径保持完整 X/Y/Z 不变，实际 D 严格嵌套。这里仅重新引用其对应方向的小表 [FIXED_XYZ_N_PATH_CONTEXT.csv](FIXED_XYZ_N_PATH_CONTEXT.csv)，没有新增融合；全部 45 法人数路径仍见原 `analysis/global_size_paths`。

- **OPPJOINT K4，m6，n12→20：** 17 张共同四端点可比图中，C 平均 −3.396，B −0.829，净差 −2.567；仅 5/17 图净差增大。最低支持票数增加 4，部分图片转折数减少。这与固定 n12 增大 m 时的正向结果并不冲突：前者把同一六人块放进更大的混合背景，后者在同一个原 A 中替换更大比例。
- **TARGET DSTRUCT K3，m7，n10→18：** 18 张共同可比图中，C −0.536，B +0.537，净差 −1.073；5/18 图净差增大。该路径的“类间减类内”幅度差也平均收缩。
