## 1. 分类的增量价值尚未隔离

从完整标签重新计算，45个候选配置共有64,170行（45×23折×62人），键无重复。其中13个新目标前向、4个目标等权RFUSE是新形成；20个既有前向、4个V3和4个原主目标RFUSE复用新版结果。45不是45种独立思想，也不等于45套全部从原答重新训练。把全部23折一起比较，有44种不同分区轨迹；RFUSE_GEOM_K2与TARGET_RFUSE_GEOM_K2在全部折相同。

OPPJOINT高Q类与同资格域、同容量的历史Q前N人高度重合：ALL为7/8；22个楼外折的重合率中位87.5%，范围85.7%—100%，21折只差1人。现有Q_MEDIAN2按Q中位数分成两个大组，类别容量、具体成员和背景不同。共同56池中，OPPJOINT的172个事件与Q二分的224个事件**没有一池出现完全相同的背景D集合**。因此+8.051与+3.929的差额只能描述两套选择设计的结果，不能单独归因于结构/几何/时间变量的额外价值。

最有用的下一项比较是同资格、同目标、同容量Q-top-N或Q-only分类：固定共同D及可行原队/同类对照，再比较两种选人规则；先复用已有精确端点，仅补确实缺少的团队。已有结果足以支持工作分类的描述和换类用途，不需要先启动新人或外部房间研究。若不补这一比较，应删除“联合分类额外优于简单Q选人”的主张，而不是删掉已有换类效应。

历史输入也没有完全对齐：Q_MEDIAN2的1,426行标签和轴分值仍与仓库原主目标版一致。原历史资格集合7,583条、新目标历史7,703条，交集7,472，旧独有111条（Manual66、Semi45）、新独有231条；这些是两套方法的跨条件历史资格集合，OPPJOINT实际使用其中Manual域。共同55池的再过滤只约束X/Y/Z具有联合历史，没有固定背景或统一历史域。补充对照应同时统一历史和资格，不能只调整类别人数。

代码检查显示新候选先排除目标建筑的所有空间，再形成历史、资格、缩放、嵌入与分组，未见直接把目标楼结果用于建类。独立从8,385条目标记录重聚合22折的Q/时间历史，44项最大差7.1×10⁻¹⁵；从保存特征重新PCA/Ward得到44个K3/K4分区，与交付ARI均为1。结构/几何原答特征没有在本轮全部从原始多边形重新生成。楼外建类也不消除看过团队结果后选择方法、方向及n/m的探索性身份。

证据：[分类检查](CLASSIFICATION_AUDIT.json)、[复算脚本](audit_classification.py)。包内源为 `classification/MAIN45_LABELS_ALL_LOBO.csv.gz`、`classification/code/build_target_aware_candidates.py` 及07B的精确事件表；具体读取路径以脚本为准。

## 4. 对象ID导出错误及影响范围

|文件|错误行数|影响|
|---|---:|---|
|07B `experiment/focused_endpoints/ENDPOINT_SCALARS.csv.gz`|1,172|487个重点事件至少一臂涉及错误字段|
|07C `experiment/fixed_A_m_endpoints/ENDPOINT_SCALARS.csv.gz`|8|与上述1,172个端点重叠|
|主OPPJOINT 12/6|0|172事件均未涉及错误字段|

根因在 [run_endpoints.py](../../personnel_global_composition_20261021/composition/run_endpoints.py) 第95行：对 `member_object_ids` 无条件执行 `'|'.join(...)`。历史缓存有列表也有已序列化字符串；字符串再join会把对象ID拆成单字符。07A `experiment/run_registered.py` 第91行经新版引擎调用了这个旧导出函数。正确类型分支可参考现有 [native_team_runner.py](../../../same_room/same_room_large_block_rebuilt_20261023/engine/native_team_runner.py) 第189—191行。

4,022个旧缓存端点的原对象身份均与本地池内worker→object映射一致；其中2,850行为列表、1,172行为正确字符串。出错的是后续标量导出。对1,172个异常字段作单层逆转，再与本地池逐对象比较，全部可恢复。记录在[修复映射](member_object_id_repair_map.csv)，包含原值和正确值，本轮没有覆盖源ZIP。

导出函数直接复制B8L2等数值字段，所以这一序列化错误本身不改变已保存Q；本轮主条件又独立核对为零受影响。它仍会破坏按对象ID直接连接原答的消费者，必须修复后再接入。修复应只对列表join、对字符串保留，并用列表/字符串两种输入验证；不应简单删除所有分隔符，也无需为此重跑融合。
