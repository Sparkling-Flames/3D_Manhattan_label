## 计算定义与可讨论参数

Q同时保留绝对均值、P10、D10均值、同上下文相对百分位及相对同伴分差。同图/同条件/同参考/同版本内，百分位=(升序平均秩−1)/(独立人数−1)，单人上下文缺失；再按人员作答平均。并列用平均秩。它控制了图内比较，但人员面对的同伴和难度分布仍不完全一致，不宣称是潜在能力估计。

当前候选高/中/低以相对Q的2/3、1/3切分，至少6份且3建筑才授予标签。绝对Q展示而未另定“好/坏”的主观阈值。T采用源耗时中位数，至少6个正有效值；暂以<60、60至<180、≥180秒分快/中/慢，同时列90/240秒敏感性。这些是待讨论的分析设置，不是用户批准的永久阈值。源时间不一定目标匹配；新老批的时间来源不同，不能把批次差当能力差。

难度候选沿用已有`preferences`逻辑：难图与非难图分别至少6份/3建筑，观察相对Q差及删去单个建筑后的范围。普通Manual中：5人难图优势候选、7人两类均较高、5人难图相对提升、6人相对下降、1人非难图优势、35人无明确偏好、1人证据不足。删除建筑是描述稳定性分析，不是独立验证。

普通Manual全部难度层有9个高Q候选，其中快1、中6、慢2。改为90/240秒有16人的T类变化；B8L2换D10没有改变这一层的Q标签。不能据此认定“高Q快”已经是可重复的人员类型，更不能直接宣称融合会更好。

## Semi与scope独立细分

新批报告的错误预标注机会284份，其中45份报告错误未改、239份修改后错误是否纠正未知。旧批另有156份强错误机会，其中25份错误原样保留；两种证据来源分列，不把新报告当成独立复核。不能把所有未改预标注视为盲信，也不能把“改过”视为“改对”。来源包括用户修改trap、自然错误trap，以及原模型输出中已登记的错误机会。未登记记录保留未知。

scope规范化`in_scope/out_of_scope`及旧单元素数组。全库存9845份回答用于描述选择倾向；正确性仅使用独立绑定、语义相容的历史任务裁定：全库存93份，当前保留记录89份，均为in-scope机会且回答相符。它不能证明OOS误收能力；新批没有相容任务gold。旧版1578份图片标签对照不再称正确率。Semi/scope不进入Q总分。
