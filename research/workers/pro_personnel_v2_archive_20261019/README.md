不重复入库：

3. 大体积逐对比较、完整团队几何缓存、部分重复展示素材等。这些不全是重复数据：完整状态是独特的历史计算输出，原件及逐文件哈希仍保留在原包中。核心归档保留生成它们的冻结输入、精确成员请求和代码，可重新计算；原运行时间和日志不能承诺逐字节重现。

没有删除仓库原内容或四个原包。每一项保留、复用、别名或仅留原包的决定均可在文件去向表追溯；本目录不冒充完整四包的镜像。

## 不下载四包即可准备复现

在包含本目录的正常仓库克隆中，使用 Python 和 Git：

```bash
python research/workers/pro_personnel_v2_archive_20261019/bootstrap.py --workspace /tmp/pro-v2-replay
```

目标目录必须不存在。默认只校验哈希并恢复隔离工作区，不运行模型、不下载安装依赖，也不改变当前仓库。原脚本要求的 `work_v2_20261019` 与 `repo_main_20261019` 同级布局会自动创建。

需要实际重算时，可明确安装公开的固定版本依赖并运行：

```bash
python research/workers/pro_personnel_v2_archive_20261019/bootstrap.py --workspace /tmp/pro-v2-full --install-deps --stage all --execute
```

完整重算耗时较长；数值重放使用 Linux/WSL 或支持 `fcntl` 的 POSIX Python。浅克隆若缺少固定提交且当前文件已变化，需要先取得该提交。原图下载与网页重建为另外的可选步骤，详见 [移植审计与命令说明](PORTABILITY_AUDIT.md)。
