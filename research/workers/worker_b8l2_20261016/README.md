# 人员分类的 B8L2 接入与真实换人验证

2026年10月16日。已完成原版B8L2下的人员画像、分类候选比较和真实团队单人替换分析。当前证据支持保留连续画像；简单Q二分以及Q/T四格尚不足以稳定区分组合影响。研究目标是解释不同人员及其搭配怎样改变标注，而不是追求每个子类都收敛或人为制造明显差异。

本包仅负责人员模块。基础输入为`b8l2_shared_v6_20261016_v1`，最新用途已接入[共同用途v2](../../statistics/b8l2_usage_v6_20261016/CROSS_MODULE_INPUTS.json)，`b8l2_scene_usage_v6_20261016_v2`；评分仍为原`WQ-B8L2-20261015`。普通949份的成员、参考、评分和时间均经桥接核验保持一致，已有画像和组合结果保留，未重复拟合。新增门洞专项及27人完整台账见[用途v2接续报告](usage_v2/README.md)。原作答、GT、融合成员与几何未改变。历史931份结果不追改。

## 固定团队只换一人

沿用旧人员实验的642个真实团队、4076个单人替换对，确认真实成员、别名和几何一致；没有重新融合或复制人员。292个已有团队接入融合线的同成员评分，其余350个旧已生成状态调用同一冻结测量。旧有348个完整WQ终点均另算同旧参考B8L2；当前参考新增可算覆盖独立记录，不归因于换公式。

642个团队当前有607个条件数值。其中普通且人员、目标及留出限制清楚的尝试为399个、7图，374个有完整B8L2；25个无完整结果仍保留在尝试分母。原留出、uNb-36待核及rPc目标绑定未清分别单列。rPc条件数值不进入主组合收益。[逐团队分数](team_scores.csv)同时保留当前/旧参考、分项、资格、可算性及缺失原因。

优先解释固定7人基础、加入第8人的设计：7张普通图各2个基础团队，共14个基础团队；每个尝试17名真实加入者，总238次，229次完整可评价。Uw-09第二个基础团队仅8/17可算，未将失败成员删除后宣称整体改善。

|问题|实际结果|
|---|---|
|较高Q粗类加入者的平均B8L2比另一类更高？|14个基础团队中9正、5负|
|跨Q类别替换的底面变化比同类替换更大？|6/14基础团队；先按图平均后3/7图|
|Q/T四格跨类替换的底面变化更大？|7/14基础团队，尚无统一优势|

影响大小差别很大：较高Q类加入者的平均收益在7y-04两基础约+0.08、+0.22分，在yq-32约+1.21、+3.81分；X7-13两基础约−0.33、−0.11分。不能仅凭正负号称为明显、稳定的组合差异。

分类关系本身也敏感：固定历史931只换指标，4076对中699对的同类/跨类关系改变；固定当前949换指标改变571对；固定B8L2新增评分覆盖改变795对。它们是重叠替换对，不能当作独立实验次数或用该数量夸大统计证据。

详见[单人替换](replacement_pairs.csv)、[同基础比较](matched_base_comparisons.csv)、[加入者逐人证据](fixed_base_entrants.csv)、[加入者关联](fixed_base_associations.csv)。关联、类别均值差是描述性结果，不是目标图上拟合后通过独立验证的协同模型。

## 场景画像与四变量的接续

当前普通Q面板为简单647份/52图、中等113份/13图、困难189份/14图。达到完整样本最低覆盖者分别24、8、23人；这是比旧931面板更好的困难场景覆盖，但仍须逐折重新核支持。

|相同楼外评价作答上的比较|作答/建筑|场景专用连续Q|普通连续Q|场景专用更好的建筑|

困难场景专用画像有有限的总体增量，但只在4/8栋更好，且其粗二分仅下降5.53%，明显损失连续信息。它值得继续检查分项错误和跨场景变化，尚不足以宣布“擅长困难图”的稳定类型。中等场景的楼外有效覆盖仍很小。难度是人工辅助标签，部分参考过作答，以上不是独立的难度效度验证。[同作答对照](condition_general_comparison.csv)、[场景覆盖](conditional_coverage.csv)可核验。

S/B保留原意义：S为规则适用性判断，B为修改量及净改善。当前保留原已测量的S拒绝倾向、普通场景拒绝诊断、B修改量和旧OSPA30净改善，并与新Q/T关联；没有把行为B改名为B8L2。S两轴与当前Q相关约0.145、−0.044，B两轴约−0.338、0.524；这些相关不证明增量预测能力。当前S正确性及初始化—最终同参考B8L2净改善仍有独立缺口，不把未知裁决补成错误。[四轴证据](four_axis_evidence.csv)及[关联](auxiliary_correlations.csv)保持来源身份。
