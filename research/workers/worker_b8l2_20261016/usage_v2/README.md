## 门洞表现能否由普通Q解释

下表使用相同109份作答、8栋建筑，比较门洞专项连续画像和已经冻结的普通连续Q；预测目标均为同任务相对表现。误差下降以同任务相对值预测为0作基线，不是准确率。

|模型|建筑等权误差下降|解释|
|---|---:|---|
|门洞专项连续Q|15.93%|8栋中6栋优于零基线|
|门洞专项Q二分|12.13%|连续信息有所损失|
|普通连续Q迁移到相同109份|−40.51%|平均误差高于零基线|

门洞专项连续Q在6/8栋上比普通Q更好。旧WQ及同参考3D IoU的门洞连续画像分别下降15.99%、13.05%，保留在[完整结果](doorway_prediction_performance.csv)，不根据哪种分数更有利而择优。

另在全部180份非留出门洞上直接应用普通Q，建筑等权误差下降为−16.92%，按作答汇总则为+9.82%；建筑权重与作答权重给出不同方向，说明不能用单一汇总宣传普遍迁移失败或成功。它与109份的配对比较分母不同。详见[普通Q迁移](ordinary_to_doorway_performance.csv)及[相同作答对照](doorway_ordinary_matched_predictions.csv)。

这些结果支持继续研究“门洞条件下人员表现的变化”，但尚不证明天然存在门洞能力类别，也不能证明某类人员组合有普遍增益。覆盖集中、门洞参考与任务解释仍有条件性；本次没有新增门洞团队组合实验。
