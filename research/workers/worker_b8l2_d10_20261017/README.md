## 画像与分类的实际变化

每人效应仍在同图、同条件、同参考单元中调整任务组成，并留出整个目标建筑重新拟合。支持规则保持至少6个可比较任务、3栋建筑；零线只描述相对池内表现，不是永久能力等级。以下为建筑等权均方误差相对零基线的下降，不是分类准确率。

|面板|B8L2连续|B8L2粗二分|D10连续|D10粗二分|
|---|---:|---:|---:|---:|
|原949份，评价948份|24.84%|15.12%|23.52%|13.08%|
|原949加新增41份，评价990份|24.90%|14.39%|23.58%|12.43%|
|当前1048份，评价1048份|24.98%|13.36%|23.69%|12.85%|
|去回退绑定1004份，评价1003份|24.76%|14.62%|23.48%|12.27%|

两指标各自终点不同，不能用误差下降大小判定哪种质量指标正确。[逐折预测](predictions.csv)已检查每个比较的B8L2/D10对象集合一致；[性能表](prediction_performance.csv)同时保留建筑等权和作答汇总口径。

当前B8L2/D10人员效应秩相关约0.9922，但W011从−0.328到+0.138、W017从−0.214到+0.382，跨过相对零线。固定旧949只换指标时只有W011跨线。固定B8L2仅加入新批次，W017由+0.329变为−0.017；之后旧库存补路由使其约为−0.214。不能把高秩相关解释为分类完全不变，也不能把边界跨线解释为能力突变。[逐人排序与类别敏感性](profile_sensitivity.csv)、[互斥建筑两半](disjoint_halves.csv)保留细节。

当前1048份中44份使用已发布的`local_evidence_insufficient_floor_iou_fallback`路由。没有在本模块重选目标；另外将这些记录整体移除重算，24人的完整样本粗类均未改变，但连续效果及楼外表现有所变化。这只检验对该回退子集的敏感性，不证明目标语义独立正确，也不证明其它路由不确定性已消除。

## 冻结真实团队的并列敏感性

新增19图与旧团队图没有重叠。本包复用原642个真实团队和4076个单人替换对，保留**2026年10月16日的团队成员、参考及用途边界**，只重组D10并接入新画像；没有重跑融合，也没有借新版路由自动认证原受限团队。仍有399个冻结普通尝试、374个完整终点；25个无完整输出不删除。

14个固定7人基础团队加入第8人的设计仍为238次尝试、229次可评价。为区分分类变化与评分变化，保存了交叉比较：

|建立加入者类别的画像|用B8L2评价，较高类收益为正|用D10评价，较高类收益为正|
|---|---:|---:|
|当前B8L2画像|8/14|7/14|
|当前D10画像|11/14|10/14|

跨类换人底面变化更大的基础团队，B8L2类别为7/14，D10类别为6/14；Q/T联合类别分别为8/14与5/14。不能从正例数变化选出“更好的分类”，更不能认为分数上涨就是融合改善。

4076对中，固定当前样本换B8L2/D10改变712对同类/跨类关系；固定B8L2只加新批次改变200对，再补旧库存路由改变394对。这些替换对重叠，不是4076次独立实验。详见[替换关系敏感性](replacement_label_sensitivity.csv)、[固定基础交叉比较](fixed_base_associations.csv)、[逐对结果](replacement_pairs.csv)。
