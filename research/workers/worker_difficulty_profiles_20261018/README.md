## 怎样识别难图优势

先保留每人每档绝对B8L2／D10均值、中位数、低尾、同图名次及图／建筑数。每个比较任务严格为`image_id + condition + reference_id + reference_version`，不把不同绑定空间当共同参照。

同图相对位次 = `(平均并列名次−1)/(同任务人员数−1)`，由低分到高分排列；0最低、1最高，全同分为0.5，单人任务留空。逐任务位次对人取平均；另保存建筑等权位次。它不是准确率、不是当前固定效应相对Q的替代，也仍受同任务人员池组成影响。分差另外保存为“本人分−其他同任务人员平均分”，避免只有排名而丢掉幅度。

难图优势 = 难图平均位次−非难图平均位次。非难图在此处合并简单和中等，采用各人实际任务权重；完整三档始终分别展示，避免把中等也很强的人员误说成只擅长困难。每侧至少6个可比任务、3栋建筑才给候选标签。这是沿用支持量的探索门，不是保证可靠性的统计定理。

候选规则：难图位次≥2/3且差值≥0.10为难图相对优势；两侧均≥2/3且不满足前项为各难度整体较高；非难图≥2/3且反向差≥0.10为非难图相对优势；其余差值≥0.10只称位次上升／下降，不自动称好手。否则未见明显偏好。界限是可解释的初始分组规则，未优化、未校准，不是永久人员标签，也未用于挑选融合团队。

## 难度信息是否真的增加预测价值

复用现有任务截距＋人员效应拟合器。比较一个总体人员效应与按简单／中等／困难分别拟合的人员效应；每个测试建筑均从所有训练中排除，旧原留出不进入训练或本轮交叉验证。两模型只在共同支持人员且同任务至少2人的集合比较，统一中心化。每人训练至少6任务、3栋；不同难度的人员效应零点不跨档直接比较。

943／1048份、81图支持共同比较，105份因分档支持／共同任务不足不参加预测误差比较，仍留在全量描述与覆盖表。误差先在图内平均，再在建筑内图等权，最后建筑等权。

|B8L2范围|可比记录／图／楼|难度专门画像相对总体画像的误差变化|改善建筑|
|---|---|---:|---|
|全难度|943／81／19|上升1.35%|9／19|
|简单|676／53／15|上升0.86%|7／15|
|中等|48／10／8|上升8.72%|4／8|
|困难|219／18／9|下降4.88%|3／9|

D10困难下降2.72%，4／9楼改善；总体上升1.38%。困难均值收益集中在少数建筑，不能宣称普遍改善；中等细分训练较薄，是暂不强制全体按三档各建独立画像的理由。当前证据支持把难度表现作为人员细分标签继续研究，同时保留总体Q，不支持全面替换总体Q。

本轮比较的是个人相对质量预测，尚未证明难图优势人员的融合一定更好。下一步在总体Q/T主类内增加难度标签，再与Semi纠错／盲信、scope既有机会证据并列考察；真实选队需使用目标建筑外信息，不能用本图分数或本页全样本类别挑人后在同图证明有效。暂不穷举所有多维交叉而制造大量单人类。

## 输出字段与检查

- `records.csv`：1911逐份，保留object/worker/image/condition/reference/version、难度、原训练资格、分数、同图位次、同任务人数、peer_delta、来源与同目标有效时间及时间规则；不填未知。
- `worker_difficulty_cells.csv`：以panel＋worker_id＋difficulty唯一，支持量、分位数、两种位次平均和有效时间中位数；未有作答的格子不生成伪零值。
- `difficulty_preferences.csv`：普通Manual每人一行，难图／非难图表现、差值、候选标签、删楼极值与可评折数。这里`n`是作答数，独立任务数见cell，不把楼重采样当独立人员。
- `predictions.csv`：metric＋object_id唯一，目标建筑与同任务、两模型在同一人员集合上的中心化预测及平方误差。
- `validation_coverage.csv`：metric＋building＋difficulty唯一，尝试与实际比较分母。
- `validation_summary.csv`：metric＋difficulty唯一，建筑等权误差与改善建筑数。
- `summary.json`与页面数据脚本是同一负载，schema为`worker_difficulty_profiles_20261018_v1`，带明确来源；这是新分析，不覆盖旧输出。
