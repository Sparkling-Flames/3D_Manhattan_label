# 扩大人数后的单人可替换性研究

2026-10-18。按用户后续要求，人员质量只保留**绝对Q与相对Q**；T是效率维度，Semi和scope不进入本轮人员质量或类别。研究从四人整组比较扩展到6、8、12、16人，固定背景仅换一人，观察质量、结构与不确定性是否更有规律。

**本轮已实际完成3840行请求、3839个不同真人集合、2560个单人替换对。**同类与跨类替换共用同一锚点A和相同背景，不再把背景一起更换造成的变化归给被替换人员。[数据与几何执行证据](../../fusion/worker_exchangeability_fusion_20261018/README.md)、[全部结果摘要](summary.json)。

## 1. 先冻结的分类与设计

沿用上一轮8图／8建筑固定面板（6普通、2门洞），不按本轮结果另选图。三种分类分别解释：

|方案|来源与划分|不能作的解释|
|---|---|---|
|AbsQ3|真实1048份普通Manual训练中，目标建筑外每人的原尺度平均Q；按支持人员的1/3、2/3分位分三档|原尺度均值仍受每人任务组成影响，不是任务标准化能力|
|RelQ3|既有目标建筑外任务调整相对Q，按1/3、2/3分位分三档|相对档次不是绝对合格线，也不是天然三类|
|RelQT4|相对Q正负×既有来源T快慢|T不是质量加分；“快”不保证更准确或同目标成本更低|

支持规则保持至少6个任务、3栋建筑；未知保持未知。绝对Q和相对Q不合成一个分数。完整描述画像中24名支持者的AbsQ3与RelQ3有22人同档，但楼外划分及具体成员仍须逐折使用。[逐人画像](person_profiles.csv)、[楼外画像](fold_profiles.csv)、[绝对Q分界](absolute_class_thresholds.csv)。额外保留两种Q三档×T六格的支持标签，未将未执行六格实验冒称完成。

每个支持至少2人的类别抽2套三元组：锚点A、同类B、跨类C；每套再抽2个背景，均排除A/B/C。比较背景+A、背景+B、背景+C，形成同类A→B和跨类A→C两个配对臂。跨类C可能更高或更低，方向显式保留，没有挑高收益方向。相同三元组／背景重复使用同一个剩余人员排列的嵌套前缀，分别取5、7、11、15名背景人员，避免增加人数时额外更换原背景。

共320条背景链，每条4个人数点，即1280个配对块。所有人员与随机种子在输出前冻结，见[TEAM_REQUESTS.json](TEAM_REQUESTS.json)。当前“高Q且快”完整描述为3人，8个楼外目标池为2–4人（B6-11、rPc-06为4，uNb-21为2，其余3），因此只研究他们在大队中的替换席位，**没有制造6–16人的纯高快队伍**。

## 2. 高Q且快有局部规律，但不是完全可互换

下表在各人数点使用同一块同／跨类两臂均可计算的机会，先逐图平均再图等权；每个人数点均有8图，但可用背景数量不同。V为替换后真实融合底面的1−IoU，越小表示变化越小，不表示更正确。

|人数|高快同类替换V|从高快换至其它类V|同类替换平均绝对ΔQ|跨类替换平均绝对ΔQ|
|---:|---:|---:|---:|---:|
|6|0.0500|0.0735|1.93|3.41|
|8|0.0372|0.0790|1.48|3.38|
|12|0.0197|0.0253|0.92|1.79|
|16|0.0312|0.0685|1.04|4.54|

这支持“高快类内在本轮样本中平均更可替换”的描述。它不等于完全相同：使用两臂完整几何均有效的共同分母，高快同类的严格完整几何相同率分别为0%、4.17%、3.13%、0%。节点数相同、节点内容相同、完整连接几何相同分别记录，不能互相替代。

也不能把跨其它三类的平均统称“高快更好”。[高快方向表](high_fast_summary.csv)明确区分高快−高慢、高快−低快、高快−低慢；例如12人时高快−低慢在5张质量可比图的均值为−1.05分，仍有3图正、2图负。高快−高慢各人数的均值多为正，但逐图仍有负例。分数变化也不替代人工对结构取舍的判断。

其它方案并非都有同样规律：AbsQ3和RelQT4总体在各人数点的同类替换V均小于跨类，而RelQ3总体在四个人数点均相反。各方案抽取的人对和背景不同，**不能据此宣布绝对Q已胜过相对Q**；但结果足以反对“细分后一定类内稳定”的预设。[按图／人数／锚类结果](by_image_k_class.csv)、[总体结果](summary_by_k.csv)。

## 3. 更多人不保证单调稳定

严格比较人数变化时，使用4个人数点、同／跨两臂全部可计算的固定背景链。V的共同链为AbsQ3 76条／8图、RelQ3 77条／8图、RelQT4 104条／8图；Q的共同链为62条／7图、61条／6图、83条／6图。不能用V的可用链代替Q的分母。

|方案|固定链同类V：6→16人|固定链跨类V：6→16人|
|---|---:|---:|
|AbsQ3|0.0502→0.0349|0.0623→0.0479|
|RelQ3|0.0750→0.0454|0.0630→0.0339|
|RelQT4|0.0413→0.0506|0.0592→0.0566|

部分替换变小，但没有总体单调规律。高Q快的单点表也不是“12人足够”的阈值证据。一个明确反例是Uw-09的16人队，仅将低Q快类W010换为W012，节点数同为4，底面V仍为0.467，B8L2变化+11.74分；同类标签、节点数以及人数多都没有保证输出不变。见[review_cases.json](review_cases.json)。

## 4. 观察上可互换，能否迁移到另一背景

复用预先固定的两个随机背景：以背景0发现“完整几何严格相同”或“底面V≤0.01”的交换，再看背景1。0.01只是一把探索标尺，不是已批准的稳定阈值；背景间可能共享很多人员，仍是同图同人员对，**不是独立外部验证**。

- 严格相同发现机会21条，另一背景19条完整可比，17条仍严格相同；其中18条发现机会的两份原答底面本已相同或浮点等价。它们重复人数／方案，不能写成21个独立成功人对，更不能据此宣布发现全局人员类。
- 范围变化很小也不保证迁移：发现背景V≤0.01的交换，在另一背景观察到最高V约0.755。保留所有发现机会、另一背景不可计算和实际变化分布，未按验证结果重新挑选发现组。
- [跨图支持表](cross_image_exchange_support.csv)有680个人员对×人数单元，其中344个至少支持2图，最多5图；只报告支持数和逐图变化，未强行聚类成新人群。

[背景迁移逐条表](background_transfer.csv)、[迁移分母与结果](background_transfer_summary.csv)。这轮逆向观察说明：可互换性可能是“人员对×当前图片×当前背景”的关系，未必是人员永久属性。

## 5. 本图原答相近比全局人员档次更直接，但两类簇不能混称

已接入191份原答、2185个原答范围对，全部8图BEV有效；1350对同点对数的原答有结构距离，其余835对结构距离留空。[原答簇说明](CLUSTER_NOTES.md)区分：

- 范围相似簇：只按原答底面1−IoU完整链接；0.20为展示尺度，0.10／0.30保留敏感性。
- 整份标法结构诊断：先按点对数分层，再复用既有环序对应的角度距离和完整链接；9°为展示尺度，6°／12°保留敏感性。不是新验证的跨图人员类。

有111个原答对范围距离≤0.20但点对数不同，不能把范围相似直接称为相同标法。当前描述中，同结构簇交换的逐图平均融合V在6／8／12／16人为0.025／0.019／0.020／0.015，跨结构簇约0.078／0.070／0.067／0.061；类别相同有解释空间，但它使用当前图原答形成，不能当作仅由楼外人员画像获得的预测。

原答连续范围距离与融合V的逐图Spearman均值约0.35、0.26、0.25、0.25，各图含负值，且大量人对／背景重叠；不按重放行数做独立样本显著性检验。[连续关联](annotation_distance_association.csv)、[本图簇的换人结果](annotation_relation_by_image_k.csv)。
