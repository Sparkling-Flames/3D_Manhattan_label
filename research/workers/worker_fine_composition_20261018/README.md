# 人员粗分、细分与真实组合：v1首轮定向收尾

2026-10-18。本包直接研究用户关心的“类别构成怎样改变融合内容、质量和不确定性”。保留连续Q/T用于解释，实际执行Q二分、Q×T四格和Q三档；不是只讨论分类方法。未使用模拟标注，未调整评分、参考、人员资格或融合算法。

**已完成：**173图既有14845个团队请求的重新归类；8图／8建筑、2门洞与6普通图片的528行定向请求、502个真实不同成员集合。定向部分含432行四人队伍设计（144种图内构成×3个成员集合，跨方案去重为430个四人集合）及96行顺序前缀（24条路径）。实际融合由[融合复算包](../../fusion/worker_composition_fusion_20261018/README.md)执行。所有请求均有返回，失败不补零。

## 1. 分类究竟是什么

人员效应沿用[2026-10-17冻结楼外画像](../worker_v1_composition_20261017/fold_person_profiles.csv)。Q来自1048份普通Manual训练；针对每张目标图，使用该建筑以外拟合的效应，仍要求至少6个可比较任务、3栋建筑。T为既定来源active-time的相对效应；不是目标空间专属耗时。普通Q迁移至门洞是本轮观察对象，不宣称已有稳定门洞人员类型。

|方案|划分规则|解释|
|---|---|---|
|Q2粗类|Q效应大于／小于0|相对训练池表现高／低；不是绝对合格线|
|QT4细类|Q2×T效应正负，T<0为较快|在Q粗类中区分快慢；T不支持时保持未知|
|Q3替代细分|每折支持充分人员Q效应的1/3、2/3分位阈值|低／中／高三档；边界相同者不拆分，不视为天然三类|
|Q3边界敏感性|将阈值改为25%、75%|只重新标记同一人员／成员集合，不按结果重新选队|

完整描述画像中24人支持Q：B8L2的Q2为10高／14低；Q3为8／8／8，这是规则造成的分配，不是数据证明三类同样大小。27个登记身份中3个无Q支持继续保留；QT4另有3个无T支持，不能把“未知”当低质量或慢。逐人名单见[person_classes.csv](person_classes.csv)，实际选队用[fold_classes.csv](fold_classes.csv)，每折分界见[class_thresholds.csv](class_thresholds.csv)。

当前B8L2与D10完整画像Q2/QT4中的W011、W017跨类，Q3名单相同；1/3–2/3改25%–75%时W006、W008、W013、W021换档。定向432行同一队伍按各自方案从B8L2改D10分类，78行构成标签改变；评分和人员重选不是同一操作。本包只做固定成员的分类／评分敏感性，没有把D10重选实验冒充已完成。

**画像版本边界：**分类在融合结果产生前冻结，仍引用修复历史坐标之前的1048份训练画像；后续几何修复应用于实际融合，不静默回写旧画像。本轮唯一改变R01424／`8ffe08f072e2b12e`，不在该1048份训练中；修复后仍因参考用途限制不进入主Q，因此训练成员／数值未变，无需为这项修复重新拟合。后续若更新训练，可在本包相同成员集合上追加标签迁移和重新选队两种对照。

## 2. 设计与支持范围

先枚举173个真实可用Manual池的Q2/QT4/Q3及边界敏感性四人构成，记录可形成的具体成员集合数。选图规则只看支持：先门洞2图、再普通6图，每建筑1图，按可行构成数、池人数递减，平局按图号；原留出池不进入这8图主面板。初稿发现整池留出数误填为四人队成员数后，在融合结果分析前改正并将原留出e9-19替换为wc2-15。最终8图为：

- 门洞：q9vSo1VnCiC-13、uNb9QFRL6hY-21。
- 普通：7y3sRwLe3Va-04、B6ByNegPMKs-11、UwV83HsGsw3-09、X7HyMhZNoso-13、rPc6DW4iMge-06、wc2JMjhGNzB-15。

四人构成中，Q2的所有可行配比都抽样；QT4/Q3的每种配比形态（4、3+1、2+2、2+1+1及四类各1）选支持集合最多的代表，另将每个有至少2个可替换集合的纯类纳入。每个选中构成按固定种子无放回抽3个不同真人集合。全部可能构成及未抽样位置见[composition_support.csv](composition_support.csv)，全池选择表见[pool_support.csv](pool_support.csv)。**混合构成是形态代表，未穷举全部具体配比。**“高Q且快”完整描述画像为3人，8张目标图的楼外池则为2–4人：B6-11、rPc-06为4，uNb-21为2，其余为3。恰好4人仅形成1个四人纯类集合，未满足至少2个可替换集合的纳入规则，因此没有该纯类对照；不是删除不利结果。

三种问题分别交付：

1. 同图、同k换类别构成：`between_composition_by_image.csv`与纯类对照。
2. 同图、同k、同构成换真人：`composition_cells.csv`与432个换成员对。
3. 同最终成员改变进入顺序：每图固定一个包含多类的四人终点，正序、反序、固定随机序，共24条路径。最终同集结果相同是固定集合算法的定义，不是“顺序已收敛”的实验发现。

## 3. 已有真实结果，而非预期结论

432行四人设计中367行完整几何、353行主质量可用；按实际成员集合去重是430组、366组完整、352组主质量。其余保留no_connection、invalid_floor或用途受限状态。每种构成3组中至少2组有主质量才进入下表的对应图比较；主质量值和失败率应一起阅读。

|对照（B8L2均值差）|普通图片|门洞图片|含义|
|---|---:|---:|---|
|Q2高4−低4|−0.93，4图，2正2负|+12.14，2图均正|普通池内高Q组合未保证更好|
|Q3高4−低4|+1.79，3图，2正1负|+21.90，2图均正|有条件差异，不能据均差更大宣布Q3优于Q2|
|Q3中4−低4|−0.88，5图，3正2负|−4.49，2图均负|个体Q档次与融合结果不必单调|
|QT4低Q快4−低Q慢4|−1.80，5图，2正3负|+9.44，2图均正|速度标签的组合表现依赖图片；不是快更好或慢更好|

上述各行可比图片数不同；不能互相直接做分类优劣排名，也不能把重叠团队当独立样本。8图一图一建筑，只作定向描述；门洞只有2图，不推广为普遍门洞规律。逐图数值、失败和D10见[pure_class_contrasts_by_image.csv](pure_class_contrasts_by_image.csv)和[汇总](pure_class_contrast_summary.csv)。

固定构成并没有消除换人的不确定性。例如Uw-09的Q2“3高1低”、Q3“1高1低2中”、QT四类各1，在所抽成员之间的最大融合底面1−IoU分别约0.837、0.628、0.620；这些是相同构成的实际不同几何，不只是分数抖动。人选仍会改变角点数量、共享观测点的归属及空间范围。[member_replacement_pairs.csv](member_replacement_pairs.csv)保留这些结构变化；其中`changed_coidentity_pairs`表示共享观测点的同簇关系改变，不能直接称为必要墙体遗漏。

另已比较3312个跨构成队伍对，2464对有可比底面；相同构成432对中327对有可比底面。按图等权描述，普通6图QT4的同构成／跨构成1−IoU均值约0.085／0.157，Q3约0.101／0.130，Q2约0.170／0.160；门洞2图分别QT4约0.176／0.211、Q3约0.128／0.196、Q2约0.239／0.231。**细类确实提供了可观察的结构差异，但当前各方案抽到的人员集合、类别大小不同，不能用这些数值直接选出最优分类。**逐图分母见[structure_variation_by_image.csv](structure_variation_by_image.csv)，共享人员及原始成对证据见[between_composition_pairs.csv](between_composition_pairs.csv)。

顺序方面，24条路径的1→2、2→3均因现算法的二人完整连接延后而没有完整底面变化量，仍保留全部48条状态。3→4有23/24对可计算，平均底面1−IoU约0.0614。不能把缺失过渡补成零或把最后相同终点当作分类有效的证据。

时间另有明确覆盖：432行四人设计仅113行来源时间完整、47行同目标时间完整。已知和及缺失人数均保留，不能据部分已知时间比较总成本或宣布速度／质量最优组合。

## 4. 与旧广图结果的关系

本包重新消费2026-10-17全部14845团队请求；没有把机会性优先顺序实验改称均衡成员抽样。只看B8L2、k4、全员类别已知、同构成至少2个主质量集合：Q2有212个图内单元／90图／20楼，QT4有55单元／36图／15楼，Q3有162单元／83图／18楼。它们的同构成分数范围均值分别8.46、4.71、7.78分，**面板与构成不同，不能据此说QT4最稳**。

旧广图表保留原几何版本，未用本轮修复覆盖历史失败；定向8图结果使用融合复算包申明的已修复输入。两类结果分列`cohort`，避免把不同版本和不同抽样目的混合。

- [fixed_member_classification_sensitivity.csv](fixed_member_classification_sensitivity.csv)：同成员B8L2/D10分类与Q3边界敏感性，不偷换为人员重选。

本轮已使粗分／细分／换构成／换成员／顺序成为可浏览真实结果。当前还不能称为最终人员类型：未来新增人员会改变支持和阈值；此次只有三次具体成员抽样、8图固定面板及k4主对照；scope／Semi机会不足没有硬塞进细类。下一步应先人工看这6例及整体图，核对空间取舍与结构变化的解释，再决定是否增加特定配比／人数。当前不需要为完成这份v1阶段结果补标v2，也不需要先更换总分。
