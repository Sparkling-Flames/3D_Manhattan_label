# Pro任务：人员综合质量与可靠性画像（数据v1）

请独立研究并尽可能实算：在我们已有人员Q/T分类基础上，怎样合理区分“实际标注质量”和“任务不同造成的分数差”，并利用Semi纠错、scope判断、严重错误剔除记录，形成可解释、有实际用途的人员画像及分类。不要默认用户、前序Pro或Codex的判断正确，也不要因为分类尚不永久稳定就拒绝提出和检验可用方案。方法由你根据数据和证据选择，以结果为导向，不要求遵循预设算法步骤。

## 我的目标和最新原意

我们研究不同图片、人员及其组合如何影响原作答分歧和共识形成。人员分类要合理、可解释，能帮助分析固定人数改变构成、固定构成更换具体人，以及按真实排列逐人加入的过程；不要求找到天然且永久的人群，也不预设增人一定更接近GT。

目前全部已有数据和后续分析都属于**数据v1**。未来补标还要等，不把v2或再采数据作为本轮开工前提。已有评分包或历史目录里的v2/v6等是各自修订号，不是第二批研究数据。

单份几何质量继续用B8L2主线、D10敏感性，保留分项与同参考3D IoU；本任务重点是人员评价，不要求重造单份布局评分。已有主观打档只作辅助，comment及具体错误语义更重要，不要求逐例拟合我的感受。

我新提出三点：

- 每个人标的图不同。既要看相对GT的原尺度绝对质量，也要看调整任务后的相对质量；不能只比较不同任务池的均分。当前人员Q已有同图／条件／参考调整和楼外验证，请先核实，不要当成完全没做的新提案。
- Semi中，曾记录有人面对错误预标注却未修改。它可能比单纯改动量更能说明纠错表现，但“未改”不自动等于错，“改过”也不自动代表修好了。还应区分实际初始化、错误种类／严重度、最终质量与净改善；初始化本来很好的作答没有同样的提升空间。
- 我曾剔除一些错得离谱的作答。这些数量及比例可能反映严重失误，仅分析清洗后剩余作答会漏掉这部分。不要把GT错误、参考缺失、场景不适用或整人历史排除无区别算成逐条个人错误。

初步倾向把绝对／相对质量、Semi纠错、scope及严重失误归到“标注质量与可靠性”大板块，速度单独作为效率，修改幅度作为行为描述。这是待检验组织方式，不要求把所有维度相加成一个总分；若你认为应改结构，请给出更合理的方案和证据。

## 希望最终回答并交付什么

1. 给出明确可用的人员评价框架：各指标测什么、哪些重复、哪些有增量、如何处理任务差异与证据不足。绝对Q与相对Q来自同一成绩，不能未经论证重复加权；相对强不等于绝对好。若提出综合分，说明具体用途及权衡，并与保留多维画像比较，不强求必须做总分。
2. 恢复并核验实际初始化未改动和人工剔除证据，以稳定object_id连接逐人台账。给出可计算指标的人员覆盖、分母、缺失、原因和不确定性；已知错误未修、定向审核线索、普通未改动、历史整人排除分别解释。未审核不算正确；同一事件重复comment去重，漏纠错同时被剔除时保留重叠，不机械双扣。
3. 用已有数据比较原有Q/T、绝对／相对Q及有证据支持的扩展候选。给出逐人画像／类别及重要变化，完成可行的实证验证，不只写方法综述；不强制等人数分组，也不把没有机会表现某项能力的人记0。任务组成调整优先使用同图同条件同参考的真实重叠，不能单靠三档难度均值“校正”一切。
4. 评价不只看单人Q预测：还要看效率、严重错误或纠错表现，以及对人员构成／换人差异的解释。预测或选人使用目标建筑外信息，原有留出保留；训练标签本身不能充当同样本验证。组合行与重放次数不算独立图。能复用现有真实团队和路径就完成配对比较；缺少几何或曲线时明确哪些结论尚未验证，不用终点插值制造过程。
5. 最终提出本轮可以采用的方案、应保持诊断的指标、确实需要补证据的部分。给出可读结果表、来源／字段定义、代码、运行回执和少量能改变判断的边界检查。支持负结果和有条件结论，不为显著性反复试分类，也不笼统以“样本不足”终止全部工作。没有可读工具返回的部分只能标未验证，不能宣称完成。

当前3222份规范作答／261图；共同质量1911份，其中1699普通、188门洞、24其它；人员普通Q训练1048份／24人／87图／19建筑。人数和用途以实际读取文件为准，不混成一个分母。旧阶段更小的表作为v1历史子集保留，不升级成当前全量。

现有全样本Q×T描述四格：B8L2高快3／高慢6／低快7／低慢5，另3人时间不足；D10为5／6／5／5，另3人不足。用于组合研究必须采用相应楼外名单。当前连续Q有效不代表粗类无意义，Q/T四格没有一致的单人Q预测增益也不等于无效率／组合用途。

`model_unchanged_audit`105条线索：100坐标未变、4改动、1非Semi未检查；100中36 confirmed_trap、31 confirmed_nontrap、33 unknown。这不是完整Semi分母，也不是100条已确认漏纠错。历史574份Semi表有多种来源，旧OSPA30净改善不能改名为当前B8L2/D10净改善。

库存85条`excluded_by_review`和133条`historical_not_accepted`仅是状态计数，须查原因；后者含整人历史排除。现有`old_cleaning_excluded`是合并统计，不能直接当个人严重错误率。保留数量、总提交中的已知错误占比、可比可判断机会中的错误率和审核覆盖；定向审核有选择性，别直接外推总体。

门洞符合资格时可以评分，OOS仅诊断；GT错误和现有排除仍有效。被剔除记录可进入失误行为研究，不自动恢复融合票或主Q资格。多空间沿既定绑定，不能选择最高质量参考；同房沿已有完整人工分类。新增指标不改变既有清洗、参考和B8L2/D10分数。
