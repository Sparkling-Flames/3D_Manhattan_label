怎样交换角点顺序并记录？
  1. 打开交互3D，在“标注来源”里选择你要核对的同一份布局；新窗口不会自动跟随这里的来源选择。
  2. 右侧“角点组预览顺序”：点选一组后前移／后移；也可在完整排列中输入原始组编号，点击“应用预览”。例如四组中交换第2、3组，输入 1,3,2,4。移动的是完整上下端点组，组编号从1开始，原始点ID另列。
  3. 对照全景点位与3D，再用“恢复原序”比较。重排后右侧拟合暂停，不代表调整失败或新顺序正确；上下配对无法读取时不能用整组换序补救。
  4. 切换来源或刷新前，点击“导出独立预览顺序记录”。回到本问卷，勾选“3D异常，怀疑点序／点对读取有问题”，在备注写布局名称、尝试顺序、观察理由及导出文件名。
