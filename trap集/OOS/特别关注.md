# OOS 目录说明

当前 `OOS/` 目录用于保存 OOS gate candidate pool。

## 当前状态

- 当前目录下共 10 个任务
- 当前按 latest export 的 `scope` 看，目录与 `scope` 已对齐
- 当前没有活动中的 `directory bucket != current scope` mismatch

## 当前角色边界

- 这里的任务用于 `scope / gate` 能力审计
- 它们不是 manual geometry anchor
- 也不是 semi trap 的默认几何主池
- 当前仍然只是 OOS candidate pool，不等于 OOS final quota / binding

## 当前使用提醒

1. 是否属于 OOS，以 latest export 里的 `scope` 为主，不以旧目录位置单独决定。
2. low-priority 的 OOS 样本含义是“是否算 OOS 仍较不确定”，不是“无法标注”。
3. low-priority OOS 样本应继续保留在 registry 里，但不应自动进入 final selection。
4. 当前 OOS truth layer 已可抽取、可审计，但还不能写成 OOS gate 已 final ready。
