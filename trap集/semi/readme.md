# semi 目录说明

本目录用于保存当前 `PreScreen_semi` 的自然候选任务。

## 当前解释规则

1. 目录里有的 task，表示当前找到了对应的自然候选案例。
2. 目录里没有某个 family，不等于该 family 在协议上不存在；也可能只是当前没有稳定自然案例。
3. 当前目录只是 semi natural candidate pool，不等于 final semi freeze。

## 当前 thesis-facing 默认理解

- `模型标注质量好`：当前主要作为 `control` 候选
- `跨门扩张 / 过度解析 / 角点错位 / 角点重复`：当前 default core natural trap family
- `漏标`：当前保留为正式 extension family，不进入默认 core trap 配额，但在 natural-failure bank / appendix / lifecycle audit 中不能忽略
- `模型预标注失败`：当前只保留为 low-priority / optional / audit case

## 当前不应误读的地方

- 不要把 `semi` 理解成“全都是误导性 trap”
- 不要把当前目录直接当成 final semi selection
- 不要把 `模型预标注失败` 自动抬成 default core family
- 不要把目录里暂时缺失的 family 自动解释成协议删除

## 当前最准确的说法

> `semi/` 现在表示的是 natural candidate registry；最终哪些进入 control、哪些进入 trap、哪些只保留 audit，还要以后续 final freeze 为准。
